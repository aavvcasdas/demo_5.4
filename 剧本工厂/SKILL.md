# 剧本工厂

**给谁用**：写「人生副本 / 剧本人生」这类第二人称口播剧的人。
**产什么**：一份能念、能拍、能拆条的剧本（`剧本.md`）+ 结构指纹（`结构指纹.json`）+ 体检（`体检.md`）。
**判什么**：口播剧 = 文案驱动 + 戏剧驱动。它既要口播的秒级节奏，也要戏的动作交换。**只满足一半就水**。

> 旧系统的病：2.9M 字规则、0.18% 是人生副本手艺；拆解报告 1.4 万字/篇却不产出可迁移骨架；成品是分行散文，没有 beat 时钟、没有台词交换。本工厂反过来做：**规则少而狠，资产可复用，产出入场即带秒表**。

## 六道工序（不许跳）

| 工序 | 输入 | 产物 | 过不去就别往下走 |
|---|---|---|---|
| G0 判型 | 题目/需求 | 判型卡一行：“口播剧 · 骨架 SK-xx · 目标时长 Ns” | 判不出驱动源就停 |
| G1 取骨架 | 对标视频 / 拆文库 / 原创 | `结构指纹.json`（骨架 ID + 功能位 + 加价阶梯 + 兑现类型） | **没有骨架不许开写** |
| G2 定钩子 | 骨架 + 题眼 | 3 个不同类型 hook 备选（T1-T8）+ 封面三行 | 3 个备选缺一不可 |
| G3 排 beat 时钟 | 骨架 + hook | `剧本.md` 的 beat 表（每 beat：秒窗 + 功能 + 谁施压 + 兑现什么） | beat 合计秒数与目标差 >15% 就重排 |
| G4 写逐字稿 | beat 表 | `剧本.md` 全文（口播行 + 台词行 + 镜头提示） | 台词占比 <25% 直接退回重写 |
| G5 念稿体检 | `剧本.md` | `体检.md` + `体检.json` | 有 BLOCK 必须修；PASS 不等于批准 |
| G6 改编（可选） | 已通过的本 + 新要求 | `改编剧本-v1.md` + 对照表 | 锁定项被动过就返工 |

## G0 判型（一句话）

- **口播稿（文案驱动）**：观众要的是“说了什么”。做法照 `references/判型卡.md` 的 A 线。
- **剧本（戏剧驱动）**：观众要的是“谁做了什么”。
- **人生副本 = 口播剧**：形态是口播（第二人称、连续旁白、单人可念），驱动是戏（有人在争一件事）。**判型写错的具体症状**：写成说明文（只有信息没有交换）或写成小说（只有氛围没有换气）。

## G1 取骨架（三条入口，选一条）

1. **扒片**：有对标视频 → 按 `references/结构指纹协议.md` 出指纹；不得编造未见事实。
2. **蒸馏**：`python3 剧本工厂/scripts/distill.py` 把 `拆文库/` 的原文蒸馏成资产 → 从 `资产/开场原句库.md` 学钩子构造、从 `资产/指纹/` 取幕结构；选骨架见 `references/骨架库.md`（SK-01…SK-06，每个骨架都标注了来源条目，可回原文核对）。
3. **原创**：只有题 → **先从骨架库选骨架**（骨架是“戏怎么运转”，不是题材），再换题壳。

**借骨架的边界**：借功能位、加价阶梯、兑现类型、结尾债务、节奏比例；**不借**具体事件、原句、人物关系与方言梗（见 `references/高保真改编.md` 的锁定/替换表）。

## G2 定钩子

- 同一骨架给 **3 个不同类型**的 hook（钩子类型见 `references/钩子库.md`，含真实原句对照），用户选一个。
- 口播剧的第一个 beat ≤ 6 秒；3 秒内必须出现**具体的人/动作/数字**中的至少一个，只有概念不算钩子。
- 钩子不许把词典放在门口：热词、自造词、行业黑话第一次出现必须由剧情自己解释。

## G3-G4 写稿（硬约束，写的时候同时满足）

- **beat 时钟**：每 beat 一个秒窗，窗口 ≤ 22 秒；窗口里必须发生一次“施压→回应”。
- **台词内联**：台词占口播字数 ≥ 35%；旁白只做三件事——接时间、进内心、给判词。**旁白不许替人物打架**。
- **加价**：对手至少施加两次，且第二次换形不换义（拒绝行动→质疑身份→抬高门槛→限制关系→加代价）。同义争吵不算加价。
- **兑现**：高潮要演出可见结果——有人改口、有人让位、有件东西换了持有人。配角可以施压和见证，**不许替主角完成最难的一步**。
- **口语**：分行 = 换气。行长中位 ≤ 12 字（上限 22）。字数 ÷ 4.2 = 秒。测不到就去念。
- 写完全文看一遍 `references/口播语法.md` 的禁用清单（AI 腔、网文腔、日历句、裸数字）。

## G5 体检

```bash
python3 剧本工厂/scripts/fuben_check.py 剧本工厂/样片/001_年夜饭桌/剧本.md
```

- **BLOCK**：时长契约、首钩子窗口、台词占比、AI 硬禁词——必须修，修完重跑。
- **WARN**：逐条判断，不许“批量忽略”。
- **PASS**：只说明**可测项**没问题。好看度、事实、念起来顺不顺、配音实测时长，`体检.md` 里列在“不测的项”，**不因缺测而算通过**。
- 体检绑定正文 sha256：正文一改，旧体检自动失效，必须重跑。

## G6 改编（系列化产能）

按 `references/高保真改编.md`：先抄结构指纹 → 建对照表（锁定/替换/风险）→ 换壳重写 → 逐项回查。默认总时长 = 母版 ±15%，超了必须重分配动作与停顿，不是改个数字。

## 产出目录

```
剧本工厂/作品/NNN_短题/
  剧本.md          逐字稿（beat 时钟 + 口播行 + 台词行 + 镜头提示）
  结构指纹.json     来源骨架 + 功能位 + 阶梯 + 兑现 + 债务
  体检.md / 体检.json
  改编剧本-vN.md     可选，系列化时
```

## 边界

- 稿子是给真人念的，不是给模型表演的：**没有实测过配音时长的稿子不许写“成片时长”**，只写“估算”。
- 不伪造事实、病例、后台数据；引用热梗要写清出处层级（原句/变体/自造）。
- 本工厂只产文字资产（剧本、指纹、体检），不做配音、剪辑、发布。

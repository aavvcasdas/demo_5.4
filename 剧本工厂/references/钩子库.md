# 钩子库

> 三个来源拼的：`yaojingang/yao-open-prompts`（口播黄金结构与「前 3 秒注意力机制」）、`1-SKILL/jiaoben`（6 条 hook 公式 + 平台 hook 窗口）、`hongfamonvAI/hook-lab`（hook 类型标签：curiosity gap / shocking stat / bold claim / question / pattern interrupt）。
> **原句只作研究**：下面每条真实原句都来自本仓 `拆文库/` 的原文开场，用于理解构造方式；写新稿必须换主题换句子，只借注意力机制。

## 硬常量

| 项 | 值 | 说明 |
|---|---|---|
| 首钩窗口 | **3 秒开口 / 6 秒说完** | 3 秒内必须出现**具体的人、动作、数字**至少一个。只有概念（“人生啊”“你有没有想过”）不算钩子 |
| 每 15 秒一次钩子 | 每个 beat 窗口 ≤22s，窗口末端必须留一个“想听下一句”的缺口 | 钩子链，不是一直欠账 |
| 备选数量 | **3 个不同类型** | 同一骨架出 3 个 hook，用户选；不许同一类型换形容词 |
| 热词自解释 | 自造词/热梗/行业词第一次出现，必须由剧情当场解释 | 旧稿“不懂即死”的教训：把词典放门口等于劝退 |

## 八种钩子类型

### T1 时间锚 + 五感（本系列主力，占比最高）
- **公式**：`具体时间点 + 一个身体能感到的细节 + 一个未完成的动作`
- **真实原句**：`15岁那年冬天/你还是县一中的初三学生/每天下午5:50/放学铃一响`（01）；`凌晨2点十三分/电话在震动/你没有开灯`（03）
- **为什么有效**：不请求注意，直接把人按进现场；观众为了“这是谁的几点”留下。
- **适配骨架**：SK-01 / SK-04 / SK-06
- **失败模式**：时间后面没有身体感受，变成日历（“三年后 你去了北京”）。

### T2 反常识 / 重新定义
- **公式**：`大家都以为X + 其实Y + Y 在你这儿长什么样`
- **真实原句**：`从小到大/你就是人群里的那个异类/其他人都是难以理解的生物`（17）
- **适配骨架**：SK-03 / SK-05
- **失败模式**：只有金句没有场景；后半段接不上兑现。

### T3 损失先行 / 结果先行
- **公式**：`一个已经发生的坏结果 + 时间/数字 + 你不知道的那一步`
- **真实原句**：`凌晨2点半/你失眠了/因为房租已经拖了两个月`（04）
- **适配骨架**：SK-04
- **失败模式**：损失是编的、兑现时无法回收。

### T4 反常请求 / 异常动作（冲突入场）
- **公式**：`关系里最亲近的人 + 对你说一句反常的话 / 做一个反常的动作`
- **真实原句**：`朋友眼中的人生赢家/晚饭桌上/老婆放下筷子/对你说`（34）
- **样例**：样片 001 `进门前 你妈在厨房拉住你 / 待会儿有人问你工资 你就说两个字 / 够花`
- **适配骨架**：SK-02 / SK-05
- **失败模式**：反常没有代价（观众不知道违反它会怎样）。

### T5 身份圈定（别人眼里的你）
- **公式**：`别人给你贴的标签 + 一个只有标签里的人才会做的具体动作`
- **真实原句**：`你有一个打呼噜跟水牛叫一样的室友`（32）；`你有一个现成刀枪炮的父亲/这股味道是从你6岁那年开始变得具象的`（16）
- **适配骨架**：SK-01 / SK-05
- **失败模式**：标签是群嘲（贬损人群），评论区反噬。

### T6 数字锚点
- **公式**：`一个具体数字 + 它绑定的动作/物 + 一个反差`
- **真实原句**：`22岁/你大学毕业/找了一份月薪5,000双休的工作/下午5点半`（10）
- **适配骨架**：所有骨架
- **失败模式**：数字不绑动作的裸句（旧病 §17.2）。

### T7 未解释的异常（悬念）
- **公式**：`一个不对的地方 + 一个不动声色的动作 + 不解释`
- **真实原句**：`世界上只剩下你一个人/早晨7点半/你醒了/没有刺耳的闹钟/没有楼下汽车的引擎轰鸣`（12）
- **适配骨架**：SK-03 / SK-04
- **失败模式**：藏信息藏到观众看不懂（理解眼下动作必需的信息不许藏）。

### T8 提问 / 直给承诺
- **公式**：`把观众心里那句话说出来 + 立刻欠一个答案`（慎用，口播剧里最多 1 次）
- **真实原句**：`赚够200万回小县城/不上班的人生到底有多爽`（46）
- **失败模式**：连用两次以上变成营销号。

## 三备选规则（G2 执行）

1. 选骨架 → 读它的「结构指纹」→ **出 3 个不同类型**的 hook + 各自的第一句台词。
2. 打分只看两件事：**3 秒内有没有具体物**、**它能不能接到骨架的第一步施压**。接不上兑现的钩子，再漂亮也淘汰。
3. 选定后写进 `剧本.md` 的 `B1`，并把落选的 2 个记进 `结构指纹.json`（备选理由：为什么被淘汰）。

## 钩子 → 标题 / 封面三行

- 标题＝钩子的**最短变体**，封面三行与首钩**同源不同写**（学 `ahang008/ah-xhs-cover-title` 的拆法：结论前置约 40% / 递进悬念约 25% / 祈使直给约 20%）。
- 三行不许复述钩子原句：第一行给标签，第二行给张力，第三行给落点或悬念。
- 样片 001：钩子＝“妈让你只说两个字：够花”，封面三行＝`饭桌上第七次被问工资 / 你把筷子放下了 / 有些数报出来 就变成别人的事`。

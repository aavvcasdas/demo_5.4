# 兑现与加价

> 借 `liuyunlong2021-wq/jc-xiachen-duanshipin-jiaoben` 的结构指纹体系：人物功能位、阻力与证据阶梯、四类阶段奖励、追更债务、自然争议；借本仓旧文档里已采纳的 `zenstory-ai/drama-skills` 两条：**有效阻力迫使人换策略**、**反应必须承担后果**。
> 这条直接治“水”：水的戏 = 有压力没有加价，有反应没有后果。

## 1. 人物功能位（先配位，再写戏）

| 功能位 | 作用 | 口播剧里的样子 |
|---|---|---|
| 诉求者 | 提出本集唯一能复述的目标 | 你（或你替一个人争） |
| 门槛守卫者 | 控制资源/信息/接触权 | 二姨、教练、房东、组长、门卫 |
| 对照装置 | 用另一个人抬高标准 | 表弟、同事、邻居家孩子 |
| 打圆场者 | 把矛盾说小，反而抬高赌注 | 妈、同事、对象 |
| 可争取决策者 | 态度变化＝阶段奖励 | 二姨夫、外婆、HR、房东 |
| 依赖者 | 让选择有代价（不是台词工具） | 弟弟、外婆、孩子、病人 |

**配位规则**：非必要不加角色。一个角色只干一件事；干两件事的，要么合并要么删。

## 2. 加价阶梯（对手至少两次，且换形不换义）

按顺序挑，别原地重复：

```
拒绝行动 → 质疑身份 → 抬高门槛 → 限制关系 → 增加现实代价
```

- 每一轮都要改变**风险等级**或**筹码**，不能只是换个说法接着吵。
- 判断句：这一轮之后，主角如果还做和上一轮一样的事，会不会更贵？不会 → 这轮白写。
- 反例：`你怎么这样` / `你太过分了` / `我不管` —— 同义争吵，零加价。

## 3. 证据阶梯（兑现前的可信度）

从弱到强：`持续行动 → 具体照料 → 可见相似/旧物 → 拒绝不当利益 → 可核验材料 → 目标人物确认`。

- 证据强度不得超过剧情已知事实：口头承诺不能升级成当场出示。
- 口播剧常用“**看不见的偿付**”：主角做过的事没人知道，直到这一刻被说出来（样片 001：垫付的押金与陪床）。

## 4. 四类阶段奖励（让观众有得赚）

1. **得到型**：相认、被相信、获准入场。
2. **失去型**：交出东西、被切断、被迫离开。
3. **部分接纳型**：被让出位置、被留下联系方式、拿到临时帮助。
4. **解释型**：回收开场的谜，补上动机。

每一幕结尾至少兑现一个；**兑现之后留一拍人物反应**（改口、让位、递东西），不要立刻切走。

## 5. 兑现的演法（不是喊出来）

- 兑现 = 可见变化：**有人改口**（不是被说服，是被现实改写）、**有人让位**、**一件东西换了持有人**。
- 侧面反应必须承担后果：他原本能做什么，现在为什么不能做了？
- 配角不许替主角爽：最难的一步必须主角自己做。旁人可以见证、可以付代价。
- “全员震惊”不算兑现；“二姨夫把酒杯推过来，说这杯我敬你”才算。

## 6. 追更债务与自然争议

- 结尾留下的债：缺席者何时回应、身份如何核验、责任归谁、阶段接纳会不会反转。
- 争议要从剧情事实里长出来（责任 vs 边界、动机 vs 证据、亲权 vs 照料）；**只写观众会吵的那件事，不伪造评论**。
- 口播剧不打“下集见”的字幕，用固定人物的旧账和主目标前进一步形成追更。

# 验收表

> 三层验收，缺一层都不算完成。**机检 PASS ≠ 通过**——旧链路就是在这里翻车的：`05_机检.json` 全绿，用户看完说“看不懂”“流水账”。

## 第一层 · 机检（`scripts/fuben_check.py`，只判可测项）

| 项 | 通过线 | 类型 |
|---|---|---|
| 时长契约 | 字数÷4.2 与目标差 ≤10%（>20% BLOCK） | 可测 |
| 首钩窗口 | B1 窗口 ≤6s，且含具体人/动作/数字 | 可测 |
| beat 长度 | 每个窗口 ≤22s | 可测 |
| 台词占比 | ≥35%（<25% BLOCK） | 可测 |
| 行长 | 中位 ≤12 字（P90 ≤22） | 可测 |
| 空间 | ≥2 个空间词 | 可测 |
| 日历句 / 裸数字 | 0 容忍（WARN） | 可测 |
| AI 腔硬禁词 | 0（BLOCK） | 可测 |
| 施压句 | ≥2 处 | 可测（代理指标） |

**体检不看**：好看度、事实真实性、表演与镜头可行性、术语是否被听懂、实际配音时长。不测的项会写进 `体检.md` 的“不测的项”，**不因缺测而算通过**。

## 第二层 · 念稿（必须真的做一遍）

1. **出声念**：一口气卡住的地方就是分行错了；笑着念不出来的台词就是书面语。
2. **计时**：从第一句念到最后一句，掐表；与目标差 >10% 就改字数或改语速档。
3. **念对手台词**：如果二姨和三叔很难听出区别，返工角色口吻。
4. **听一遍回放**（可 TTS）：热词第一次出现时，装作不知道它意思，能不能从上下文猜出来？猜不出 → 补解释。

## 第三层 · 人判（用户/观众）

问三句话，答不上来就是不通过：

1. **开场 3 秒**：你会不会想听第四句？
2. **中段**：有没有哪 15 秒你是等着看结果的？
3. **结尾**：你能不能用一句话复述“这片子卖了什么”？

用户说“不好看”，**优先改开头、加价、兑现**，不许转去修工具、调格式、加配图。

## 绑定规则

- `体检.json` 记录正文 `sha256`。**正文一改，体检即失效**，必须重跑；不许拿旧报告给新稿背书。
- 提交给别人看的时候同时给：`剧本.md` + `结构指纹.json` + `体检.md`（含 sha）。
- 单份剧本的返工上限：同一问题最多返工两轮；两轮没解决，回去换骨架，不要在原地磨句子。

# 骨架库（人工校准 · 六个）

> 骨架 = 故事怎么运转的施工图：功能位怎么配、对手怎么加价、兑现什么、结尾留下什么债。
> 每个骨架都标注**来源条目**（可直接回 `拆文库/<条目>/原文/原文.txt` 核对），但**只借骨架，不借事件**。
> 机器初判的全量指纹在 `资产/指纹/*.json`；下面是人工校准过的六个，够写绝大多数选题。

---

## SK-01 · 时间锚编年（沉沦 / 翻身 / 平淡一生）
- **来源**：01 无辣不欢、05 县城精神小伙、29 愤怒的普通人、46 赚够 200 万回小县城。
- **形态**：时间锚开场 → 3-6 幕，每幕换一个时间戳与处境 → 判词收束。
- **功能位**：诉求者（你）｜环境即对手（行业、身体、家庭压力）｜阶段见证者（同伴、师傅、母亲）。
- **加价方式**：**代价递增**——同一件渴望，每幕的价码更高（身体、关系、尊严、退路）。
- **兑现**：得到型或失去型，必须落在具体动作上（体检单、退租、最后一班车）。
- **结尾债**：那句判词留给观众自己接（“值不值”）。
- **适配**：讲述型选题、变迁类选题；**不适用**于有明确对手的当场冲突。
- **禁区**：禁把编年写成账本（一行一事、事事等重）；每幕必须有“变化”，不是“又过了一年”。

## SK-02 · 门槛盘问 · 多轮加价（当场冲突）— 样片 001 用的就是它
- **来源**：16 县城刀枪炮的父亲（门槛/身份被反复扒）、17 外耗型人格（话术拆解），功能位配法蒸馏自本仓 `兑现与加价.md`。
- **形态**：反常请求/冲突入场 → 对手四次加价 → 主角用一件**别人不知道的偿付**把规则掀翻 → 反应落地。
- **功能位**：门槛守卫者（提问者）｜帮腔｜对照装置｜打圆场者｜可争取决策者。
- **加价阶梯**：数字 → 关系 → 资产 → 当众定性（“挺好的怎么不敢说个数啊”）。
- **兑现**：解释型 + 部分接纳型（真相说破 + 有人改口让位）。
- **结尾债**：关系需要重新校准，但已经挡不住了。
- **适配**：饭桌、相亲、同学会、家长会、面试、群聊冲突。
- **禁区**：主角的反击不能靠钱压人（观众讨厭爽得没道理）；靠的是**信息差 + 代价**。

## SK-03 · 情景连播 · 等距微反转（拆条友好）
- **来源**：17 外耗型人格（系列首个 sitcom：序 + 四幕同构 + 判词；幕间零因果，可任意重排）。
- **形态**：序（一句立人设）→ 3-5 幕，每幕一个国民场景、一次同构拆解 → 判词。
- **功能位**：每幕一个“话术持有者”（推销员、前台、摊主、保安）。
- **加价方式**：**换场景不换机制**——同一个机制在不同场景的变体（授权、火候、归因、杠杆）。
- **兑现**：每幕一个 V 形（小谷 → 反击 → 立刻结账），四幕等距供爽。
- **结尾债**：不需要——它就是产品单元（可拆条）。
- **适配**：反套路教程、消费维权、社交防御、职场应付。
- **禁区**：不要在幕与幕之间加因果（会毁掉拆条）；四幕必须同构，否则不叫连播。

## SK-04 · 代价递增 · 单线追逼（扎心）
- **来源**：21 大学生接触 PG、09 贷款买房合集、15 卖肾买 iPhone4。
- **形态**：异常/损失先行 → 主角做一系列“看起来没错”的选择 → 每步代价变大 → 兑现落在代价本身。
- **功能位**：诉求者（你）｜诱惑者（第一幕给好处的人）｜收网者（后面加价的人）｜代价承担者（家人）。
- **加价阶梯**：甜头 → 借口 → 隐瞒 → 不可逆。
- **兑现**：失去型为主（真实感来自失去）；如果想给出口，出口必须是**代价已经发生之后的选择**，不是“突然被救”。
- **结尾债**：你付出了什么，观众自己算。
- **适配**：警示类、成长类、家庭压力类。
- **禁区**：不要写成说教；教训必须由一个具体动作完成（删掉联系人、退掉票、去还钱）。

## SK-05 · 身份错位 · 旁观者反转（温情）
- **来源**：28 长得不好看但很爱你的女友、32 打呼噜的室友、35 高壮男男友、19/20 被嘲笑的身体特征。
- **形态**：别人眼里的“你”（标签先行）→ 3 幕相处细节 → 一个反转视角（原来是对方在默默做什么）→ 温情收束。
- **功能位**：标签持有者（旁人）｜被标签的你｜揭示者（一个动作，不是一句话）。
- **加价方式**：误解累积（每幕多一个人误解，或多一层误解）。
- **兑现**：理解型 + 部分接纳型（在场的人改了看法，不需要全员道歉）。
- **结尾债**：留给关系里的下一步动作（一次邀约、一顿饭）。
- **适配**：亲情、友情、爱情、室友、同事。
- **禁区**：不许用“其实他得了重病”这种剧变代替误解的兑现。

## SK-06 · 判词收束层（叠加在任何骨架上的结尾）
- **来源**：16/17 的判词家族（“制定规则的人”“活阎王”），12/34 的反向动作收束。
- **三种收法**：① 判词（一句，不加解释）② 器物收口（同一件东西第二次出现，含义变了）③ 反向动作（把开场的动作做反）。
- **判定**：删掉最后 3 行，如果观众仍然“得到结论”，说明你写的是解释，不是收束。

---

## 选骨架的两条界限

1. **一个本只能有一个主骨架**；SK-06 是收尾层，可以叠加；SK-01/03 同用要拆成“每幕内部用 03、幕间用 01”，否则节奏打架。
2. 骨架决定的是“加价方式”和“兑现类型”。**选题不决定骨架**——同一个饭桌题可以写成 SK-02（冲突）或 SK-04（代价）。

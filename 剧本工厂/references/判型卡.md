# 判型卡

> 来源：从 `longmao-001/kesheng_skill` 的「形态＝驱动源」（口播稿＝文案驱动／剧本＝戏剧动作驱动）借来一条判定，改写成口播剧能用的两问。
> 为什么必须判型：**判错型，后面每一步都在错的路上努力**。旧链路的剧本“水”，一半是判型没做完就开写。

## 两问判型

**第一问：观众留下来是为了“说什么”，还是为了“发生什么”？**

| | A · 文案驱动 | B · 戏剧驱动 |
|---|---|---|
| 观众要 | 听到一个说法、一个解释、一个结论 | 看到一场交换、一次翻盘、一个揭晓 |
| 主产物 | 口播稿（论点 → 论据 → 结论） | 剧本（谁要什么 → 谁挡 → 谁改变） |
| 检验句 | “这句话说得对吗/新吗？” | “这一步他会怎么做？” |

**第二问：这条片子有没有对手？对手要不要争？**

- 有对手、且对手在争资源/面子/关系/位置 → 戏。
- 没有对手，只有“处境”和对处境的感想 → 文案。

## 人生副本的判型结果

**人生副本 = 口播剧（B 型驱动 + A 型形态）**

- **形态是 A**：第二人称、连续旁白、单人可念、按秒排。
- **驱动是 B**：一定有人在为一件事施压；主角一定做了选择并承担后果。
- 所以它同时需要两套硬约束：口播的**换气与秒表**（见 `口播语法.md`）+ 戏的**功能位与加价**（见 `兑现与加价.md`）。

## 判型写错的四个症状（自查）

| 症状 | 说明 | 退回哪里 |
|---|---|---|
| 只有信息没有交换 | 通篇在介绍“你的人生”，没有人问你要东西 | 回 G1 取骨架 |
| 只有氛围没有动作 | 感官写得很足，但整整 20 秒没有一件“发生的事” | G3 重排 beat |
| 对手是空气 | 有对手但从不施压，或只会说书面语 | G4 重写对手台词 |
| 旁白穿戏 | 旁白代替人物打架（“你把他怼得哑口无言”） | G4 改写成台词与动作 |

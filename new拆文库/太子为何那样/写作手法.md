# 写作手法分析 ·《太子为何那样》

> 维度：POV / 双视角 / 伏笔回收 / 僚机结构 / 错位喜剧 / 章节节奏。每项含位置、效果、可复用条件。

## POV 策略

| 维度 | 分析 |
|------|------|
| POV 类型 | 第一人称限知「我」（龙池檀/桃荼），全程以贪吃咸鱼龙的声口叙事 |
| 选择效果 | 极致代入甜宠日常；女主不知自己真实身份，读者与其同步被蒙，服务身份反转 |
| 信息操控 | 女主认知=「龙族私生公主」，与真相「饕餮遗孤」错位；男主所知全盘对读者隐瞒，留到番外释放 |
| POV 切换 | 正文单「我」；番外（行 1194 起）转男主「令真」第一人称，双视角闭合 |
| POV 代价 | 男主前情（打碎饕餮蛋、被逼婚、吃醋）无法正文直叙，靠番外补，避免正文 info-dump |

## 双视角闭合（女主正文 + 男主番外）

| 手法 | 位置 | 效果 | 可复用度 |
|------|------|------|----------|
| 男主视角番外补全前情 | 行 1194–1358 | 回收「卧底晗娣」「通行牌」「母后骗局」三条暗线，闭环冷漠悬念 | 高（第一人称 carrier 文通用） |
| 破壁「演员表」收束 | 行 1361 | 用话本子式「演员表」打破第四面墙，喜剧声音收口 | 中（轻甜/沙雕向） |

# 势力：金樽谷

| 字段 | 内容 |
|---|---|
| 名称 | 金樽谷 |
| 类型 | 妖灵聚居地 / 山门（兼具司法与收容职能） |
| 核心人物 | **雪明川**（谷主，额心一点银色飞霜）、**狐七郎**（爱算命的紫尾狐，屡劝谷主"不要多管闲事"）、**阿婴**（仙鹤所化的少年，贪玩）、傅瑶（三尾狐，谷中排行十二）、千岫（千年碧蛙）、谢烟（松烟砚台所化的半仙，完成任务后回谷） |
| 立场倾向 | **中立偏干预**。谷主自称不涉人间事，却反复破例：收容残魂、执行"一命换一命"、对逆天改命者施刑。狐七郎代表谷内的**不干预派**，与谷主的破例形成内部张力。 |
| 与其他势力关系 | 与**百灵潭**（春妖）：互不统属，同为妖灵/仙人收容地；雪明川曾吐槽"九重天未与谢烟之事算账"。与**白狐/黑狐两族**（第 18 章）：由谷主出面料理两族因果。与**人间朝廷**：不介入，仅在第 35 章提及宁家的"战神契约"出自金樽谷战将（鬼将军）。 |
| 关键事件 | ①第 7 章：雪明川踏雪而来，揭破枕妖编织的梦境，把沈羡娘与乔云焕两缕残魂养在**玄潭的两朵幽莲**中，叹"两个可怜人"。②第 8 章：傅瑶三尾尽显要血洗皇宫，雪明川与狐七郎赶到制止，以压碎的香丸（阿桂最后魂力）洒在焦木上使**枯木逢春**。③第 18 章：出面料理白狐黑狐两族的因果，提出**阳寿相渡、一命换一命**。④第 20 章：收拢千岫最后一缕元神，带顾云深回谷，执**十年百鞭之刑**（顾云深以血肉滋养她的元神）。⑤第 21 章：应蓝儿之请降临，以松烟砚台画还蓝儿被割去的舌头。⑥第 29 章：催促谢烟了结凡尘、告知洛修羽只剩三年寿命，最终许她以命换命，并把她的真身（松烟砚台）带回谷中置于案头日日以仙气滋养。⑦第 30 章：应白霜之请，让双生红豆重新结于自己窗前、日日输送灵力使其再生神元。 |
| 内部规则 | ①谷主有**执刑权**（十年百鞭之刑）。②谷外灵气流失则神元衰减，双生红豆因此漂泊数百年。③谷主可裁定"一命换一命"，但会事先声明代价。 |
| 出场章节 | 第 7、8、18、20、21、29、30 章（共 7 篇） |
| 原文未明确 | 谷的具体方位、规模、成员总数；谷主的年龄与修为等级；玄潭与幽莲的数量上限。 |

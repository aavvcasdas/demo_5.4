# 势力：名剑山庄

| 字段 | 内容 |
|---|---|
| 名称 | 名剑山庄 |
| 类型 | 武林门派 / 世家 |
| 核心人物 | **闻人庄主**（庄主，闻人芷之父，窥破白霜血液之秘后将其囚禁）、**洛无衣**（大弟子，奉师命骗白霜出谷为师妹治病，后在相处中真心爱上她）、**闻人芷**（大小姐，患昏睡数月的怪病，自小爱慕洛无衣） |
| 立场倾向 | 反派（以师门利益压过个人道义）。庄主为救女儿不择手段，把"医者"当资源囚禁。 |
| 与其他势力关系 | 与**千霞林古墓**（白霜、赤叶）：本无往来，因闻人芷的怪病而派人骗白霜出谷。与**金樽谷**：白霜最终留在金樽谷，洛无衣也随之留下。 |
| 关键事件 | ①两年前闻人芷得了昏睡数月的怪病，庄主命最器重的大弟子洛无衣"坑蒙拐骗也要把白霜婆婆带出古墓"。②洛无衣在林中迷路被群狼围住，一袭红裳白发从天而降驱散狼群，他倒在白霜怀中脱口一句"芷儿，你居然没死"——那其实是慌乱中的**脱口之谎**，却因此骗取她的好奇与信任，赖在古墓徐徐图之。③四个月后他带白霜离开，踏进名剑山庄时铁笼从天而降，师父拍着他的肩说"不枉为师等了你四个月"。④白霜为闻人芷诊治，庄主透过另一扇密门全程窥探，看见她**割破手腕对准闻人芷的唇喂了几大碗鲜血**——那血带着幽香能医百病、解百毒、增功力、延年益寿；庄主趁她睡着又关她进笼，说"她这辈子都休想离开名剑山庄一步"。⑤洛无衣扔剑跪下求他放过白霜，换来的交易是**一场大婚换一份自由**；于是他在铁笼前说出那些绝情的话，出来后靠在墙上一拳拳打得血肉模糊。⑥婚礼搞砸后他被囚禁，半年逃了七次、被捉回抽个半死，吞毒自尽时闻人芷终于崩溃放他走；深秋他以**一人独挑名剑山庄上下**的代价与师门决裂。 |
| 内部规则 | ①庄主之命高于弟子个人道义。②以**铁笼**囚禁"有用之人"。③弟子违命者囚禁 + 鞭刑，逃一次捉回抽一次。 |
| 出场章节 | 第 30 章《白霜无衣》 |

# 势力：苍云堡

| 字段 | 内容 |
|---|---|
| 名称 | 苍云堡 |
| 类型 | 江湖门派 / 堡 |
| 核心人物 | **苏今庭**（堡主，苏四少主）、**桑琴**（左护法，自幼被苏所救、死心塌地追随）、**厉随风**（右护法，当年荒林中背桑琴走出的少年）、**谷婉月**（苏的青梅、两代堡主夫人）、**齐赫**（弑师夺位者，抢走谷婉月，后被苏杀回）、**老堡主**（以月牙印记选接班人） |
| 立场倾向 | 内部倾轧。堡主以"堡"的利益与旧情压过护法的个人幸福，是**江湖版的结构施压者**。 |
| 与其他势力关系 | 与**鬼衣谷**：桑琴与厉随风最终隐居于此（与第 15 章宋筝、岑不语的鬼衣谷为同一地名，两篇关系原文未明确）。与**齐赫一脉**：血债血还的仇敌。 |
| 关键事件 | ①桑琴自幼被苏今庭所救，死心塌地追随，却屡被他为负青梅竹马谷婉月而牺牲——**先被迫试药保谷胎，后又被夺去与苏的孩子**。②**冒领救恩**：当年荒林中背她走出绝望、在她背上烙下月牙印记的少年，实为厉随风而非苏今庭。③真相大白后桑琴以**第四片五叶罗**配雪蟾引功力大增，挟谷婉月救出被下毒囚于地牢的厉随风，二人远走。④**番外（第 51 章）**：苏今庭耗时七年寻得二人隐居之地鬼衣谷，借七年前设局诛杀齐赫的真相剖白悔意，终以"成全"之心遥望一家三口，服五叶罗遁去。⑤老堡主当年因厉随风救同伴而贬其为普通弟子，埋下冒领救恩的伏笔。 |
| 内部规则 | ①以**月牙印记**选接班人。②左/右护法为堡主之下的最高位。③五叶罗为堡中秘药，第四片可引功力大增。 |
| 出场章节 | 第 50 章《陌上桑琴归》、第 51 章《桑琴番外·少年弟子江湖老》 |
| 原文未明确 | 苍云堡的所在地、弟子总数；五叶罗的完整功效与总片数（仅知"第四片"）；苏今庭服五叶罗后的去向。 |

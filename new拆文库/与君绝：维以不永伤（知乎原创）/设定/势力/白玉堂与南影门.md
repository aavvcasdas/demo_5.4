# 势力：白玉堂（含南影门、朱雀司）

| 字段 | 内容 |
|---|---|
| 名称 | 白玉堂 / 南影门 / 朱雀司（三者合并为一个条目：白玉堂是民间抗敌组织，南影门是其上线的秘密机构，朱雀司是其朝堂对手） |
| 类型 | 民间义军组织 + 秘密机构 + 朝廷特务机构 |
| 核心人物 | **苏御**（白玉堂堂主，真实身份为永安王）、**穆衍之**（朱雀司年轻官爷，真实身份为南影门卧底**鬼面军师**，褚御史门生）、**冯瑜**（南影门老督公，托付穆衍之忍辱负重者）、**徐怀庸**（朱雀司督公、宦官，主降派头目，通敌卖国）、**褚清云**（褚御史千金，红袖楼头号花神，后为永安王妃，加入白玉堂） |
| 立场倾向 | 白玉堂：主战、抗敌。**南影门**：幕后统筹，以忍辱潜伏的方式护国。**朱雀司**：主降、通敌（徐怀庸一派）；穆衍之是其中的卧底。 |
| 与其他势力关系 | 与**息良**（使臣哈刚）：外敌，逼签割地。与**南陈朝廷**（宁帝）：犹豫主和，被逼宣战。与**褚御史**：主战派核心，已故，是褚清云仇恨的源头，也是穆衍之与褚清云的旧缘。 |
| 关键事件 | ①褚清云家破人亡沦落红袖楼做头号花神，撞见被朱雀司追捕的白玉堂堂主苏御闯入厢房，将其藏入床底；带队搜捕的年轻官爷竟是父亲门生穆衍之，她以所养巨蟒**灵君**吓退官兵，甩门一句"你又不娶我"。②息良使臣哈刚包场戏楼逼辱清云，穆衍之舍身相护、灵君中乱箭而亡，苏御以王的身份救场成婚。③万佛寺遇刺，穆替清云挨刀。④清云尾随发现庵堂里藏着**南影门弟兄的妻儿**，方知穆当年的"背叛"是老督公冯瑜所托的忍辱负重。⑤清云打扫庵堂触机关，沿地道直通白玉堂堂口，见轮椅斗篷鬼脸面具，揭出穆衍之正是**鬼面军师**。⑥酒楼谈判日，穆引燃身上火药与徐怀庸、哈刚同尽；苏御开第二锦囊悟其"置之死地而后生"之计。⑦第三份锦囊里，穆终吐露自己原是曾偷看秋千上她的老师的爱徒，那句"藏在心底"的喜欢至死未及亲口说。 |
| 内部规则 | ①以**锦囊**逐级交代后手（三份锦囊）。②堂口以地道与庵堂相连，庵堂掩护遗属。③鬼面军师身份仅老督公与本人知晓。 |
| 出场章节 | 第 60 章《花神引》（另：第 3 章顾襄平的"督门"、第 60 章朱雀司与之同名不同机构，原文未明确二者关系） |
| 原文未明确 | 白玉堂与南影门的成立时间、成员总数、堂口数量；苏御的永安王封号来源；三份锦囊的完整内容（仅知第二、第三份已开）。 |

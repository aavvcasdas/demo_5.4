# 势力：百灵潭

| 字段 | 内容 |
|---|---|
| 名称 | 百灵潭 |
| 类型 | 异界水域 / 亡魂与妖灵的收容地（含相邻水域**有间泽**） |
| 核心人物 | **春妖**（第九任潭主，一身幽蓝、绝美诡艳，被"幽明额环"锁魂）、**齐灵/齐灵子**（有间泽仙人，常与春妖对弈、打赌）、**浮衣**（蛇女）、**乌裳**与**孔澜**（百鸟之王夫妇）、**无垠**（潭中人）；收容者：芊芊（白骨新娘）、素欢（新鬼）、卿平（半人半鬼）、段陵（假面）、阿苏（流云梳器灵） |
| 立场倾向 | **收容与旁观**。春妖不主动介入人间，但会为将死/已死之人提供一次"了却心愿"或"看见真相"的机会；齐灵子则以打赌旁观人间（第 37 章与春妖赌碧丞是否会归来）。 |
| 与其他势力关系 | 与**金樽谷**（雪明川）：互不统属、互相知晓；两处同为残魂的归宿。与**天宫/九重天**：春妖本是被贬的忘川仙人，天帝曾下赦旨归还至灵水魄，他拒绝回天。与**人间**：不介入，仅在亡者魂魄漂入时收容。 |
| 关键事件 | ①第 10 章：寒生误闯百灵潭，目睹春妖被百鬼掏心；春妖亲口交代来历——百灵潭由**忘川河水倾泻而成**，潭主被"幽明额环"锁魂，**每月受一次百鬼掏心之苦，只有找到下一个替身才能解脱**；他是第九任，此前八人的魂魄都被囚在潭中幽莲里。②第 16 章：芊芊死后成为潭中的白骨新娘，每年祭日重现蚀骨之痛；春妖问她是否往生被拒，百年后带她看**昆仑镜**里的另一半真相。③第 24 章：卿平的肉体封在冰棺中被**长明灯**留住五十四年，灯灭后春妖携其魂魄离开秘室。④第 28 章：段陵寄存七十七年的记忆由春妖保管于昆仑镜，期满之日踏幽莲而来唤"段陵，七十七年之期已至"。⑤第 36 章：收留溺亡成新鬼的素欢，准她回人间查死因。⑥第 37、42 章：齐灵子以昆仑镜旁观，并与春妖打赌；春妖助沈慈取北伏天青鸾两羽。 |
| 内部规则 | ①潭主受"幽明额环"锁魂，每月受百鬼掏心一次。②魂魄可被锁进器物（阿苏锁进流云梳）。③亡者可拒绝往生而留在潭中（芊芊、段陵）。④记忆可寄存于昆仑镜。⑤新鬼须经潭主准许方可回人间。 |
| 出场章节 | 第 10、16、23（提及）、24、28、36、37、42 章（共 8 篇） |

# 势力：罗刹堂与孤堂雁（含北鹰军）

| 字段 | 内容 |
|---|---|
| 名称 | 罗刹堂 / 孤堂雁 / 北鹰军（三者合并为一个条目：同属川城抗日地下力量，人员高度重叠） |
| 类型 | 民间抗日堂口 + 情报/易容小组 + 后期成建制的军队 |
| 核心人物 | **姚景舒**（罗刹堂堂主，"妖财神""风流圣手"，方清酌发小）、**方清酌**（即卓青，方家三少，罗刹堂副堂主、孤堂雁牵头人，后期为北鹰军统帅）、**杜小棠**（杜家易容翘楚，孤堂雁牵头人）、**朱老板**（凤仙楼掌柜，市井掩护点）、**掌石人**（罗刹堂市井暗桩） |
| 立场倾向 | 抗日志士。以市井身份（戏班、凤仙楼、暗桩）掩护，行窃情报、营救义士、清除汉奸之事。 |
| 与其他势力关系 | 与**日军（佐藤平野）**：主要敌人；佐藤以尸为饵将计就计围剿堂口，后被北鹰军炸死皖河。与**淮园**（佐藤平野所建）：卓青借教戏潜伏的情报目标。与**凤仙楼**：市井掩护点，朱老板受托赈灾、掩护卓青扶姚景舒。 |
| 关键事件 | ①凤仙楼初遇，老孔当众揭穿佐藤月乃佐藤平野玷污名伶祝红月所生，旋被日本兵枪杀。②卓青受命入院教戏，与佐藤月朝夕生情，借机窃取日军情报。③佐藤平野性侵亲子、虐杀义士、悬尸立威；卓青与罗刹堂、孤堂雁联手营救，杜小棠被擒后**易容日兵尸体假死**，佐藤月塞钥匙助其逃。④密室中卓青身份败露后撤离川城。⑤三年后佐藤月被软禁北平，于生辰当日服毒自尽，遗书坦露早识破先生身份、夹在父与师之间的万劫痛苦；首尾呼应的环形叙事以佛偈收束。⑥卓青后成**北鹰军统帅**，炸死佐藤平野于皖河。 |
| 内部规则 | ①以**暗号**接头（掌石人与卓青对暗号引其入地下堂口）。②以市井身份掩护：戏班教戏、凤仙楼掌柜、暗桩。③易容术为孤堂雁的核心能力（杜家易容翘楚）。 |

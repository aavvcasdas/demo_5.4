# 势力：神箭师门

| 字段 | 内容 |
|---|---|
| 名称 | 神箭师门 |
| 类型 | 军中技艺门派（以箭术传家，依附于侯府） |
| 核心人物 | **师将军**（师门之首，李氏的丈夫、师招云之父，救侯爷时中伏，被侯爷一推而一剑穿心）、**李氏**（师将军之妻、侯爷的青梅竹马，为保女儿忍下血仇带骨灰离去，弥留时嘱女儿带着傅少爷活下去、永不回侯府）、**师招云**（神箭师门唯一后人，十三岁携母离府） |
| 立场倾向 | 忠义。门风是"神箭师门纵是孤儿寡母也绝不受人欺辱"，代价是世代为侯府赴险。 |
| 与其他势力关系 | 与**舒家侯府**：本是依附关系，师将军为救侯爷而死；后因大夫人泄密与追杀而决裂。与**大渝**（汗王）：敌方，连破东穆十二城，其巫蛊师唯有神箭师门能远程射杀。与**傅家**：收留师招云母女，因此被灭门。 |
| 关键事件 | ①师门为救侯爷深入腹地中伏、全军覆没；侯爷一念魔障、在阵法惑心之下鬼使神差推了一把，师将军一剑穿心，临死还说"阵法诡异，侯爷莫要自责，只请照顾好她们母女"。②大夫人在灵堂把真相吐给李氏，李氏为保住女儿这师门最后的希望忍下血仇，带骨灰悄然离去。③大夫人仍派人追杀，穷途末路时母女遇见在后山作画的**傅家少爷傅颐之**；他把她们藏进傅家密道，杀手循迹而来，傅家上下无一幸免、大火烧尽，他在黑暗中一口咬住她捂着自己嘴的手，醒来人便疯了。④师招云擦净弓箭要出门寻仇，却被拉住衣角的"天黑了，好恐怖，不要丢下我"绊住，终于扔了弓抱住他大哭，从此隐姓埋名、把弓箭锁进箱底**每年加一道锁**。⑤七年后舒尧臣寻到小院，许她"不为侯府只为百姓而战、事成后把大夫人交给她处置"，她才出山；大婚第二日换上银甲率军出征，**三箭齐发射杀三名巫蛊师、连夺十一城**。 |
| 内部规则 | ①箭术传家，唯一能"穿过千军万马不近身射杀高台之人"。②以**羽箭**为信物（刻"岂曰无衣，与子同袍"）。③遗愿制：若死于战场，尸骨做成骨箭，永远陪伴要保护的人。 |
| 出场章节 | 第 27 章《神箭师门》 |

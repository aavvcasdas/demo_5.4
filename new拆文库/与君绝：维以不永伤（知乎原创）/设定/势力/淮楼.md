# 势力：淮楼

| 字段 | 内容 |
|---|---|
| 名称 | 淮楼 |
| 类型 | 杀手组织 / 江湖门派 |
| 核心人物 | **北渚淮**（创建者兼楼主，戴银丝面具，练"流风回雪"走火入魔毁容）、**舒青**（即楚舒、楚舒青，淮楼第一杀手，楚秀山庄遗孤，七岁被楼主带回训练，后任楼主）、**孟婆**（阎罗座下，老人脸少女身的侏儒，靠澜西舍利永葆青春）、**皎儿**（兰家遗腹子，被剖腹取出后抛给舒青） |
| 立场倾向 | 反派组织。以**北渚之咒**为存在目的：让兰、楚两家世代相残，使诅咒延续。 |
| 与其他势力关系 | 与**兰家**（云林）：舒青查出灭门凶手是兰家，一夜血洗兰家满门。与**楚秀山庄**：楚舒是本庄遗孤。与**月狱**（素明影）：同为江湖黑暗势力，淮楼追杀的兰家刀谱与月狱追索的梵妖互不统属，但在第 31 章同处渝水城。 |
| 关键事件 | ①**北渚之咒的来历**：兰家刀法与楚家剑术百年前本是一家，同出"流风回雪"；北渚家仆谋害主人后平分绝技，被推下悬崖的北渚小儿子活下来，把诅咒一代代传到北渚淮手中。②北渚淮创建淮楼，令兰楚两家互相残杀应了咒；又从兰家大肚婆腹中**剖出遗腹子**抛给舒青。③北渚淮自断经脉而死，要舒青继承楼主之位、把孩子养大并告诉他真相，让诅咒代代延续。④舒青跪地落泪、软剑一寸寸刺向胸口，却被婴儿嘹亮的啼哭惊醒，从此脱离淮楼、世上再无杀手舒青。⑤舒青体内被下了**苗疆七杀蛊**（七个控制七情六欲的傀儡），用了三年才拔尽——那三年他半夜出门、回来一身灰，正是自己体内打出的七杀人偶骨灰。⑥孟婆伪装学生"小雪"潜伏渝水城，为剖开皎儿的背夺取绘在其皮上的兰家刀谱，被楚舒一剑刺穿，任务失败后被剥了自己的皮做成灯笼；陆凡从灰烬中拈出**澜西舍利**（鬼符真正的解药）。 |
| 内部规则 | ①七岁带入、训练十年即成第一杀手。②以**蛊**控制成员（七杀蛊）。③任务失败者由上级剥皮示众。④楼主之位以"抛给继承者一个婴儿"的方式传承。 |
| 出场章节 | 第 31 章《凤凰囚笼》 |
| 原文未明确 | 淮楼的总坛位置、成员总数、成立时间；"流风回雪"的具体招式名录。 |

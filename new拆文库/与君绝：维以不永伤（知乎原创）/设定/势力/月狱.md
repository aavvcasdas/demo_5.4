# 势力：月狱

| 字段 | 内容 |
|---|---|
| 名称 | 月狱 |
| 类型 | 杀手/刺客组织（以"双妖"制度为核心） |
| 核心人物 | **素明影**（影妖，现任阎罗，本为富家小公子，被鬼探十三带回月狱，练邪功后心性大变）、**梵千音**（即陆凡，梵妖，月狱首对双妖之一，五年前"死"后化名陆凡隐居渝水城做教书先生）、**鬼探十三**（阎罗的双生弟弟，带回素明影并在灌哑药时救下他与梵千音，后死于梨花树下）、**老阎罗**（废了双生弟弟的武功与脸并顶替其位，后被素明影的罗伞吸干百年功力）、**孟婆**（见 `淮楼.md`） |
| 立场倾向 | 反派组织。以追杀令与契约控人；对脱离者永不赦免。 |
| 与其他势力关系 | 与**淮楼**：同为江湖黑暗势力，互不统属；月狱追索梵千音，淮楼追索兰家刀谱。与**伽若寺**：其方丈的师弟是苗疆蛊师，所授之法可拔七杀蛊。 |
| 关键事件 | ①**双妖制度**：梵千音与素明影是月狱首对双妖，自训练营相伴——梨花树下蹲着哭的红衣孩童、"我叫梵千音，有我在就不会让你饿死"、两人用一根棍子抬起巨石砸断欺负人的虎爷双腿。②灌哑药那日梵千音打翻药碗跪在阎罗面前说"我就是他，他就是我"，两人因此都被留下。③五年前梵千音"死"，素明影执掌月狱、一路往上爬只为**取消追杀令保住他**。④素明影以"地藏王"身份抱红伞现身渝水城，留下刻着"素明影"的铃铛；陆凡最终把铃铛挂在大门前、额间勾墨莲，梵妖归位。⑤决战：陆凡以水井下早已打好的地道脱身，并浇满火油引爆院子假死；素明影跪在废墟上撕心裂肺，说自己在梨花树下扎了新秋千、把住所收拾得一尘不染、每天都在等他回来。 |
| 内部规则 | ①以**毒针**（刻"影"字）清除目标周边。②六辰雾（红伞机关喷出）为攻击手段，可灼伤双目。③脱离者须以假死解除追杀令。④孟婆以澜西舍利永葆青春（与淮楼共用同一设定，二者关系原文未明确）。 |

# 金手指：与君绝：维以不永伤（知乎原创）

> **总判定**：本书为短篇合集，**不存在主角专用、跨篇统一的金手指**。金手指按篇独立存在，且**绝大多数是"带价码的交易型道具"而非"无代价的外挂"**——这与全书"任何获得都必须先标价"���元规则一致。
> **合并规则应用**：同一篇内相互关联、共同作用的元素合并为一个条目（如"蓝孔雀羽 + 春妖的交易"是一个整体）；完全独立的能力来源才拆分。

## G-01 蓝孔雀羽（一羽一愿）

| 字段 | 内容 |
|---|---|
| 类型 | artifact（神器/道具） |
| 名称 | 蓝孔雀羽 |
| 出处 | 第 10 章《春妖》，百灵潭主春妖所赠 |
| 描述 | 春妖在寒生误闯百灵潭、目睹他被百鬼掏心后赠她蓝孔雀羽，约定**一羽一愿、五次交易**，并事先声明"最后一次交易后要取走沉重的酬劳"。寒生的五次使用：①去掉脸上火疤、脱胎换骨；②为凉州城祈来大雨，救下八十一个献祭童男童女；③被绑上祭台时自救并让全城失忆（后被加封"祈音圣姑"）；④救下为她斩杀赤炼奴、命在旦夕的东华大皇子聂褚怀；⑤穿红彤嫁衣登上城楼纵身跃下，因她料到春妖会来救，第五次交易达成、春妖得以脱离"幽明额环"锁魂。代价直到第（九）节才揭：不是财物，而是**灵魂被囚于潭中幽莲**——春妖是第九任潭主，此前八人的魂魄都在里面。他不愿再害人，宣布终止交易、独自承担责任。 |
| 核心机制 | **愿望交易 + 延迟标价的代价**：先无条件给，代价留到读者已经投入感情之后再收。酬劳每次交易前重申一次，压力逐次累积。 |
| 当前能力 | 五次用尽；第五愿使春妖脱离额环、获得自由（代价是寒生化星辰、他自己拒绝回天、重戴额环守潭）。 |

## G-02 浮烟扇 / 流云梳（寿命换美貌）

| 字段 | 内容 |
|---|---|
| 类型 | artifact（神器/道具） |
| 名称 | 浮烟扇 + 流云梳（**合并为一个整体**：二者相伴千年有了灵性，分别是扇妖白扇与其夫君阿苏的真身） |
| 出处 | 第 23 章《白扇》 |
| 描述 | 扇妖白扇以浮烟扇与流云梳做买卖：**予女子美貌皮囊，换取五年到二十年不等的寿命，明码标价童叟无欺**。收过最贵的一笔是二十年——北陆南疆最丑的姑娘换来一生渴求的美丽，觅得如意郎君、做了三年贤妻良母后死于大病，弥留时望着虚空中的她苍白一笑说"我不悔"。她收寿命不是为自己，而是为了复活夫君：**阿苏**（天上忘川仙人的影子所化，与白扇相伴千年；百灵潭寒夜为护白扇被天雷击中魂飞魄散，春妖施法强留一缕魂魄锁进流云梳）。规则是**凡人十年换阿苏一年修为**，梳上已积数百年仍远远不够。终局白扇为不凡挡下天师一掌，弥留前把全部灵力与一颗本元珠渡给阿苏让他有了实体，自己消散如烟。 |
| 核心机制 | **明码标价的交易 + 累积式进度条**：每次交易都可直接量化（寿命年限 ↔ 修为年限），读者能算出还差多少，期待与绝望同源。 |
| 当前能力 | 交易终止；阿苏以女童实体存活，由不凡带着走遍江南塞北寻白扇。 |

## G-03 妙手宋家"红颜"禁术

| 字段 | 内容 |
|---|---|
| 类型 | bloodline（血脉/传承禁术） |
| 名称 | 红颜（妙手宋家禁术） |
| 出处 | 第 16 章《芊芊》，传承者芊芊（宋姑娘） |
| 描述 | 妙手宋家的禁术以**传承者的鲜血**为引：第一盒"红颜"抹上一点点便能让人面目一新。芊芊被休后为在梁都立足，三个月内以千金高价卖出一盒又一盒；为在数千家同行中脱颖而出，她把一份的量稀释成无数份融入各处胭脂，功效只剩正宗红颜的**万分之一**——**绝色坊每卖出一盒胭脂，都是在卖她的心血**。先祖告诫早已写在前文："朝如青丝暮成雪，红颜一夜化枯骨。"她明显感到尽头将至：慢慢拔掉新长出的白发，镜里的脸日渐消瘦。终局她在自己的新房里等着"红颜白骨"降临——崔子钰掀开红盖头时看见一具裹着美丽嫁衣的森然白骨。死后她成为百灵潭中的**白骨新娘**，每年祭日月光倾洒，红嫁衣下的皮肉就要重新腐蚀一遍。 |
| 核心机制 | **以生命力为燃料的能力 + 价码前置**：先给告诫（代价），再让角色主动走向代价；燃料耗尽即不可逆死亡。 |
| 当前能力 | 传承者死亡；以"白骨新娘"形态在百灵潭守望百年，每年承受一次蚀骨之痛。 |

## G-04 枕仙 / 枕妖（梦境重生）

| 字段 | 内容 |
|---|---|
| 类型 | rebirth（重生）——**伪装成重生的骗局** |
| 名称 | 枕仙（实为枕妖，乌木枕吸灵力所化的少年） |
| 出处 | 第 7 章《枕仙引梦》 |
| 描述 | 沈羡娘在小黑屋中濒死、满腔恨意时，枕仙应声出现，给她一次"重生"的机会。她睁眼回到十五年前的雪夜，却逐步发现这个七岁的乔云焕体内装着二十二岁的乔云焕——**他也重生了**。两人重新相依、把铺子做大、说好成亲。直到金樽谷谷主雪明川踏雪而来，才揭破真相：他们根本没有重获新生，这里只是**枕妖以乌木吸取灵力化形后编织的一场梦境，借梦蚕食将死之人的寿命**。枕妖自称"枕仙"，辩称只是为将死之人送一场美梦。沈羡娘选择留在梦里："与其死在凄惨的现实里，不如死在温暖美好的梦中。"两人一同死在破碎的梦里，残魂被养在玄潭的两朵幽莲中。 |
| 核心机制 | **金手指先无条件给，代价留到读者已经投入感情之后再收**，且由"局外的权威角色"宣布框架反转。 |
| 当前能力 | 枕妖逃走；梦境崩塌；两缕残魂养在金樽谷玄潭幽莲中。 |

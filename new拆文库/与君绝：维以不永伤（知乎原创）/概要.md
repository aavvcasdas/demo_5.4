## 全书概要（plot-aware，约 950 字）

《与君绝：维以不永伤》是知乎作者**羊娘则灵**的专栏短篇合集，正文 865,511 字，由 **64 篇彼此独立的短篇**拼成（其中第 47、51、54 章以「番外」命名，分别附于第 46、50、53 章）。全书无「第 N 章」，一章即一篇；篇与篇人物不继承、因果不继承、时间线不继承，跨篇只复用两组世界观锚点——**金樽谷**（谷主雪明川，出现于第 7、8、18、20、21、29、30 章）与**百灵潭**（潭主春妖，出现于第 10、16、23、24、28、36、37、42 章）。

故事框架是**多线交织的合集型变体**：不以人物或时间线交织，而以「母题 + 结构公式」交织。核心驱动是让一个把全部筹码押在另一个人身上的人，在一次不可逆的自我处置中完成情绪结算；主轴矛盾是**深情 vs 结构**——权力结构（宫廷/朝堂）、规则级不可能（人妖殊途/命格/诅咒）、家国大义与现实落差。全书**无跨篇升级**，升级只发生在篇内：伤害按「轻视 → 剥夺 → 身体损毁 → 性命/记忆剥夺」递进，认知按「误判 → 半知 → 全知」递进。

按题材母题聚合为 7 个剧情单元：**宫廷错付与自毁**（13 篇，篇幅最重、母题最核心）、**妖灵仙侠与异族情缘**（15 篇，世界观最重）、**江湖市井与恩仇儿女**（12 篇）、**宅斗与身份反转**（8 篇）、**权谋复仇与卧底清算**（6 篇）、**现代都市情感**（6 篇）、**乱世家国与牺牲**（4 篇）。

主线（宫廷线）以「立恩义 → 结构施压 → 篇末反转 → 不可逆结算 → 余韵留白」为固定五段：夏则灵以奶救活南梁太子慕容初，反被夺走名分、胎儿与所爱之人，最终以禁术回溯撞树自尽，只在新一世留下一句谐音「杨娘」；归长乐顶名入东穆宫为后，被灌绝育药、被毒废双腿，终以阴阳子母壶自毒死在卫华泽怀中；左秋漪把废太子况云养大并嫁他，却早知是他换掉了自己的孩子，直到幻境中被带回才说出「唯一爱过的人是你，我也不后悔」；连华被太傅洛槐英救下又推向大漠，宫变后身着嫁衣跃下城楼；岁冬荣替妹入东宫，在竹林爱上实为双生胞弟的「叶枯」，最终以浸毒的白子自尽；钟离雪两世被负，重生后休夫、下毒、放手，换回谢晏如一句「不值得」。

副线各有自己的引擎：妖灵线以「规则先标价」制造宿命（蓝孔雀羽一羽一愿、浮烟扇以寿命换美貌、《鸢经》秘术耗心头血），终局几乎都以消散、化形或守望收束——与书名「维以不永伤」（唯有不忘，方能止痛）同构；权谋线以「恨反派 → 敬卧底 → 痛代价」的三级落差运转，赢家一律在赢的同一刻付出最大代价；宅斗线把「身份即谎言」用成和解型掉马（郑昭当众抖落长发、冯敏之闯喜堂牵手奔出）；乱世线以主动赴死交付悲壮（杨念替柳如是赴画舫、纪左扬与日军同归于尽、曦元灵元散尽）；现代线以「放下/救赎」为高虐作缓冲。

写法上，全书共用一套稳定公式：**开篇 200 字内给一个可视觉化的具体伤口 → 立恩义 → 2-3 次递进加压 → 末段 1,200-2,000 字集中揭示最大设定 → 不写重逢，只写回声**。编排上刻意错开题材，同一单元连排最长 3 篇。全书 2,117 个情节点中虐待基调（悲伤+压抑+恐怖）占 47.0%，暖基调占 25.8%，爽+热血仅占 3.2%——**虐感供给极高、爽感供给极低**，这是它最鲜明也最需谨慎模仿的特征。

# 第26章 摘要：国舅多金

> 原文 18,595 字 | 篇内小节标记 `（N）`×20 | 全文第 8443-9011 行

**概要**：郑国舅抠门名满京都，腰间挂着五个特制铜板，说是"寓意五谷丰登，一生管饱"，五个铜板一响满街摊贩唯恐避之不及。他是太后入宫前的孽债，被郑太师卷张破席扔出去，七岁才在乱世中被找回郑家；辅政大臣郑丘以太后堂兄为首结党营私遮天蔽日，小皇帝在另两位辅政大臣支持下与之抗衡，郑丘求权、太后求子，两人一拍即合要把这个流落市井的郑昭推上皇位。他百般推脱——说无才无能便被请来囊括文武的师傅，说散漫不羁便被送进普华寺吃一个月萝卜皮，说小气巴拉太后却说总比奢靡亏空国库好，最后咬牙自称"好男风"，偏偏这话被走进青鸾宫的小皇帝听了去。他其实真的不愿与侄子你死我活：九岁那年他揪着六岁的小面团在假山下打了一架，输的人反倒抢先喊了"快，叫舅舅"，此后十年那份心思越发见不得人。小皇帝淋雨病倒那夜他守在龙榻边，鬼使神差地啄了一下那张酷似肖美人的脸；此后修屋顶时那只递修具的白皙的手、夜市里盯着卖艺壮汉傻笑被递手巾"擦擦口水"、西越女王的使臣当朝跪下吻靴求婚、那幅"隔人群一见倾心"的画像，一桩桩把他的心思逼到明处。他当朝二喊"好男风"，领下万两黄金的悬赏，亲赴驿馆做了一夜"和亲相公"，换来西越"在位一日便一日臣服"，声望暴涨后大病一场。小皇帝旋即带他去破庙看乞丐，说西北边境百姓比他们还苦，顺手借走了他腰间那串铜钱；朝堂上粮草被劫、国库耗空要百官捐，他一根手指被嘲笑"一文钱"，最终咬牙吐出"臣要捐——一笔军粮"。铜钱还回来时最小的那枚刻着"金雀"——他便是江南商贾之首的金掌柜。小皇帝许他一个愿望，还不等他想好，黎族公主进京、大婚在即的噩耗传来；他爬上屋顶抱着酒坛喝得满心苦涩，那人却如谪仙般踏月而来。屋顶对饮他终于说出愿望"你不要娶那个黎族公主了行不行"，随即改口，只道平生三愿，第三愿"日月同空，相守不弃"——那是小皇帝当年偷看普华寺纳福袋知道的。他问若有朝一日不得不伤害你你会恨我吗，答是"会"，那人却在夜色里抚去他的泪说"我会加快这一天的到来，亲自把你从深渊里解救出来"。此后他夜探假公主住处中了黎族禁药噬骨香，千钧一发被一剑惊寒救下，醒来已成百姓口中"慧眼识出假公主、智擒真刺客"的孤胆英雄；殊不知从西越到粮草再到刺客，全是小皇帝推波助澜把他送向民心顶峰。郑丘与太后终于动手，九月十七太后寿辰便是兵戎相见之日；他怕死，更怕两边互相弄死，三更时分交出两封密信，那是给西越女王与江南总堂主的最后布置。寿宴上郑将军献出"天子剑"高喊"昭儿，接剑"，大批将士涌入宝华殿；千钧一发他跳到中央大喊"我是女的，我做不了皇帝"，解下发带抖落长发、当众举起裹胸布。小皇帝这才缓缓收网——四路诸侯中两位被拖在城郊，另两位率铁骑涌入，黑衣人掷下奇兵首领的两颗人头跪称"雀公"。穷途末路的郑将军扼住他的脖颈，他用小皇帝送的那把"云痕"匕首刺穿了舅父的腹部，崩溃大哭。原来她本不是想女扮男装，被找到时正穿着乞儿服和乞丐抢馒头，从此一路走到没有退路的地方。永和十二年叛乱平定，她被册封为皇后，宫中有日月楼、日月池、日月斋，而那身白玉五件套的来历，是许多年前先帝驾崩的守灵夜，少年偷溜进别院偏房拿走了她地上的一块白布。

**关键事件**：
1. 抠门国舅被太后与郑氏一族推上储位，百般推脱后自称"好男风"。
2. 他与小皇帝自九岁打架相识，十年间存了见不得人的心思。
3. 西越女王当朝求婚，他二喊"好男风"领赏，做一夜"和亲相公"换边境安宁。
4. 小皇帝借走他的铜钱逼他捐出一笔军粮，还钱时刻下"金雀"二字。
5. 他实为江南商贾之首金掌柜，天下第一富与天下第一抠是同一个人。
6. 黎族公主进京大婚，他在屋顶对饮说出"你不要娶她"的心愿。
7. 他道出第三愿"日月同空，相守不弃"，并问对方会否恨他，答"会"。
8. 他夜探假公主中噬骨香，被小皇帝一剑救下，反被传颂为孤胆英雄。
9. 郑丘与太后逼宫，他交出密信布置后路，静待九月十七。
10. 寿宴上"天子剑"一出兵戎相见，他当众自曝女儿身。
11. 小皇帝收网，诸侯倒戈、奇兵覆灭，他用"云痕"刺死郑将军。
12. 叛乱平定，她被册封为皇后，日月同空终成真。

**逐章写法公式**：

- **情绪流向**：起：滑稽（抠门、铜板、一文钱的争执）→ 承：暧昧与推拉（打架初遇、太华殿的吻、修屋顶、夜市口水）→ 转：连环局（和亲、捐粮、刺客、民心）→ 合：摊牌（寿宴自曝、兵戎相见、匕首刺舅、日月同空）
- **节奏配比**：抠门与身世 16% / 舅侄暧昧 20% / 和亲与捐粮 20% / 大婚与屋顶 12% / 假公主营救 12% / 寿宴摊牌与结局 20%
- **本章结构公式**：让一个市井混混被塞进皇位候选（立错位） + 让他对敌对的侄子存了心思（立矛盾） + 用三件国事把他一路抬到民心顶点（立声望） + 让所有布局者在最后一天同时收网（总爆点） + 让他的性别成为破局的那张牌（身份反转） + 让"日月同空"从不可能变成日常（闭合）
- **本章核心技巧**：**把每一个笑话都做成伏笔**——"擦擦口水"的手巾引出西越女王的误会画像、"借去观赏"的铜钱引出金雀身份、"你再瘦点就能钻进钱眼里"引出守灵夜偷走的裹胸布；作者不让任何一个笑点只服务于当下，每个包袱都在十几节之后被重新兑现一次，喜剧节奏与悬疑回收共用同一批事件。
- **卡点与伏笔**：结尾卡点：题眼兑现（"其实太阳和月亮一直都在同一个天空……她是金雀，他是黄雀"）。埋设/回收伏笔：①五个铜板（开篇埋 → 被小皇帝借走 → 刻"金雀"归还 → 结局"钻进钱眼里"回收）；②"好男风"（青鸾宫埋 → 朝堂二喊 → 结局女儿身揭晓回收）；③白玉五件套（微服私访埋 → 结局守灵夜偷裹胸布改制的真相回收）；④"云痕"匕首（护城河赠予埋 → 寿宴刺穿郑将军回收）；⑤"日月同空"（普华寺纳福袋埋 → 屋顶三愿 → 小皇帝月下呢喃 → 日月楼日月池日月斋回收）；⑥西越女王（和亲埋 → 密信求援 → 结局"御夫之道"回收）；⑦"雀公"（黑衣人跪称埋 → 金雀身份回收）。

# 第 54 章 · 迟鸢番外·小媳妇是我的

## 概要
大二暑假卓岩归心似箭回古镇欲挽回迟鸢，却发现易南星已捷足先登拍宣传片、以绣名风筝与诗句步步紧逼，二人在筝坊门口上演"宰狼"闹剧，迟鸢淡然看戏只待来年春鸢满天。

## 关键事件
- 卓岩暑假急回古镇，被卓老爷子拿扫把骂弄丢孙媳妇、被易南星拐跑。
- 易南星前后脚到古镇，扛机器替迟家筝坊拍宣传片，深得镇上夸赞。
- 卓岩坐筝坊门口架腿吃冰棍"磨牙宰狼"，迟鸢见他自然熟稔毫无扭捏。
- 卓岩咬牙质易南星"兄弟妻不可欺"，易反呛"娃娃亲你压根没认过"。
- 卓岩亮杀手锏——迟鸢第一只刻名风筝，易南星从容亮出绣"南星"的精美风筝。
- 易南星背诗"最须珍重眼前人"暗讽，二人对杠吵闹，迟鸢摇笑着望蓝天等春风。

## 关键信息与扩写技法
| 技法 | 说明 |
|------|------|
| 喜剧反差 | 前章悲情放手，此章轻松逗趣，情绪调色平衡收尾 |
| 道具对垒 | "卓岩名筝" vs "南星绣筝"具象化胜负手 |
| 诗眼收束 | 用三句诗点题"珍重眼前人"，不直说教 |
| 旁观视角 | 迟鸢全程淡定看戏，强化其已真正放下 |

## 逐章写法公式
- **情绪流向**：急切 → 吃醋 → 互呛 → 各显杀手锏 → 释然望春
- **节奏配比**：铺垫挨骂(20%) + 门口对峙(40%) + 风筝对垒(25%) + 诗句收束(15%)
- **结构公式**：扫把骂归 → 捷足先登 → 架腿宰狼 → 兄弟互呛 → 双筝对决 → 背诗点题 → 望春收尾
- **核心技巧**：用"小媳妇"称谓反差玩梗，把前章沉重化作甜闹余韵
- **章尾卡点与伏笔**：迟鸢望"来年二月风筝满天"，与全书"纸鸢"母题呼应收束

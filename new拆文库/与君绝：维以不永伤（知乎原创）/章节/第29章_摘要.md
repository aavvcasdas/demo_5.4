# 第29章 摘要：女师谢烟

> 原文 14,045 字 | 篇内小节标记 `（N）`×11 | 全文第 9666-9953 行

**概要**：开篇便是那句告别——"小徒儿，再会无期了，以后会有另一个姑娘给你糖吃，你要待她好……洛修羽，你的锦绣人生，我还给你了。"故事倒回谢烟初到流云城那年：城主贴告示遍寻天下有才之士参加贤师招募大会，选出三人做三个孩子的启蒙师父，十年后由十长老会考定下一任城主。招募令最后一日来了个明眸皓齿、腰别竹笛的紫衣少女，漫不经心地随手揭下红榜，被围观者嘲笑不知天高地厚，她却只抬头望天自语"十年便十年，亦不过弹指一挥间，早点办完事我就能早点回金樽谷了"。大会上她学富五车、过目不忘，将前太傅与世外高人一齐比了下去，夺魁后得以优先择徒。台上的三公子洛修羽是个心智受损的傻子——两年前奶娘带他上山摘花，他被找到时已倒在大树下不省人事，额角多了一大团墨渍般的黑印，昏迷大半月醒来后便痴痴傻傻；生母只是卖酒娘子又早逝，他在府中全无倚靠，跟着两个哥哥念书总跟不上，受尽讥讽与欺凌。洛城主办这场大会，所求不过是一位学识渊博又耐心善良的老师，替他那傻儿子多争一份庇佑。可月下择徒时，谢烟越过大公子与二公子，径直走向那个傻笑的小包子，用竹笛在他头上一敲："从今天起，我便是你的师父了。"他叩拜后抬头问"师父，你有糖糖吃吗"，她袖中荧光一闪变出几颗糖果，摸着他的小脑袋说"有师父护着你"。半年后两位兄长趁她采药把傻弟弟吊在树上用柳枝抽，她一声怒吼把两位公子也吊起来狠狠抽打，以"子不教父之过"堵回他们各自的师父，直到洛修羽抱住她的腿软软求情才歇手，回屋又给他抹药、要他写完两页字帖才给一颗糖。十年寒来暑往，奶娃娃长成玉树临风的少年，黑印淡去、灵识回归，谢烟却容颜未改，洛城主愈发器重他，两个哥哥与两位师父焦虑难安。一个想攀高枝的婢女夜半摸进洛修羽房中，却撞见紫衣少女俯在床头、不断有缭绕黑烟自少年脸上漫出，惊叫"妖女吸食三公子的阳气"，施法被打断的黑烟钻回少年脸上，谢烟被震开吐血。她被当成妖女关进铁笼，洛修羽脸上黑雾昏迷不醒，十日不醒后两位公子用长鞭抽她、举起烧红的铁烙要烫她的脸，他却在此刻现身喝"住手"，周身黑雾消散、比从前更聪慧，推开众人护在她身前说"无论她做什么，我都信她"，抱起一身血污的她走出府门——她活了几千年，第一次心跳纷乱。风波平息后少年每天采一束鲜花送到她房中，洛城主却先斩后奏为他定下风陵城主之女秦笙。屏风后她冷声要他避嫌、说娶了秦小姐人生便圆满了，他红着眼历数护他教他搂他给糖的都是师父，"师父给的糖，是这世间最甜的东西，徒儿尝过了就不愿再接受别的了"，拉开屏风说若此生要与一女子携手到老，只希望那个人是师父；她却摇头说"你的人生里本就不该有我的，这一切原就是个错误"。初夏飘雪，金樽谷谷主雪明川问她为何还不清去最后一丝墨毒——原来她本是谢琼山念尘尊者书房中的一方松烟砚台，浸染仙气化作少女，偷跑出山时被尊者一拂尘打回原形从半空坠落，正巧砸在溪边那个天赋异禀的孩童头上，仙福太重的仙墨成了凡人承受不起的墨毒，令他灵识有损成了痴儿。解铃还须系铃人，她接下任务来到流云城，十年间每夜为他吸去额上墨毒，只差最后一次他便能彻底恢复、夺魁继位、娶秦家小姐，命途扭回正轨。她答应明日动手，说"人世走这一遭，我无怨无悔"，雪明川却道他恐怕不会跟任何人白头到老——他的寿命只剩下三年了。她当场失控："这根本就是戛然而止吧！"当夜她驾马车带昏睡的他连夜出城，特意不用法术仍被雪明川拦截；面对"逆天改命"的诘问她答"天道荒谬，何妨不能逆天改命"，雪明川终是长叹，许她以一命换一命：散尽数千年修为灌注他体内保住心脉，代价是打回原形、变回一方松烟砚台，重新忍受数千年寂寞，而他会把她的真身带回金樽谷置于案头日日以仙气滋养。花灯盛会的最后一夜，她带他戴面具溜上街，时间忽然凝固、花灯与行人均被定住，她揭开他的面具抚上那张脸，指尖触过额角最后一小块黑印使之彻底消失，踮起脚把一颗糖含在嘴中贴上他的唇，紫衣消散如烟。初夏时节，却仿佛有雪花飘落。

**关键事件**：
1. 紫衣少女谢烟揭下贤师招募红榜，被众人嘲笑却夺魁。
2. 她放弃大公子二公子，选择痴傻的三公子洛修羽为徒。
3. 两位兄长吊打洛修羽，她以"子不教父之过"把他们也吊起来抽。
4. 十年后洛修羽长成少年、黑印淡去，谢烟容颜未改。
5. 婢女撞见她夜半施法，她被当成吸食阳气的妖女关进铁笼。
6. 洛修羽十日不醒，两位公子鞭打她并要烫她的脸。
7. 洛修羽苏醒现身护师，当众说"无论她做什么我都信她"。
8. 洛城主为他定下秦笙，她躲在屏风后要他避嫌。
9. 他表白只愿与师父携手到老，她说"你的人生里本不该有我"。
10. 真相：她是松烟砚台，坠落时砸中幼年洛修羽致其墨毒入体。
11. 雪明川告知他只剩三年寿命，她驾车带他连夜出逃。
12. 她以散尽千年道行、打回原形为代价换他一生顺遂。
13. 花灯夜最后一吻后她消散如烟，只留一颗糖与一句"我还给你了"。

**逐章写法公式**：

- **情绪流向**：起：俏皮（随手揭榜、"早点办完事回金樽谷"）→ 承：宠溺与狠厉（择徒、给糖、吊打兄长、十年相伴）→ 转：误会与袒护（妖女风波、鞭烙、苏醒护师）→ 合：不可得（定亲、避嫌、表白、真相、三年寿命、以命换命、最后一吻）
- **节奏配比**：揭榜与择徒 18% / 护徒十年 18% / 妖女风波与袒护 18% / 定亲与表白 14% / 砚台真相与三年寿命 18% / 花灯诀别 14%
- **本章结构公式**：让她以玩笑姿态领下一份十年苦差（立人设） + 让她挑中最没用的那个孩子（立选择） + 让她用最狠的手段护他、用最柔的手段养他（立情） + 让她被当成妖物而他第一个站出来（立信） + 揭穿毁掉他的人正是她自己（身份反转） + 让她用千年道行换他本该拥有的人生（闭合）
- **本章核心技巧**：**把"赎罪"伪装成"师徒情深"整整八节**——十年相伴、夜半施法、以糖为约，读者与洛修羽一样只看见一位护短又俏皮的师父；直到松烟砚台的来历被补出，此前所有异常（容颜不变、黑烟缭绕、不肯吐露身份）一次性获得解释，而"赎罪"与"动情"两条线从未分开发生，她越是把他教得好，就越是在把自己推向必须离场的那一刻。
- **卡点与伏笔**：结尾卡点：凝固的告别（时间定住、花灯与行人静止、紫衣消散如烟，初夏却仿佛有雪花飘落）。埋设/回收伏笔：①"早点办完事回金樽谷"（揭榜埋 → 答应雪明川随他回去 → 真身被带回谷中置于案头回收）；②竹笛（腰间别笛埋 → 点额收徒 → 出逃时摸向竹笛三次回收）；③糖（"有糖糖吃吗"埋 → 每日一颗 → 写完字帖才给 → "以后会有另一个姑娘给你糖吃" → 最后一吻含糖五次回收）；④额角墨印（择徒夜埋 → 每夜吸墨毒 → 铁烙之前淡去 → 指尖轻触彻底消失四次回收）；⑤"子不教父之过"（吊打兄长埋 → 十年后两位公子鞭打她时她反唇相讥回收）；⑥松烟砚台（第八节埋 → 打回原形 → 雪明川带回金樽谷日日仙气滋养回收）；⑦初夏飘雪（雪明川现身埋 → 拦截马车 → 结尾初夏却仿佛有雪花飘落三次回收）。

# 第19章 摘要：川城红雪

> 原文 15,802 字 | 篇内小节标记 `（N）`×10 | 全文第 6009-6376 行

**概要**：父亲被日本人打死后，孟宣仪背着骨灰坛来到川城许公馆，凭写着"崇西宣仪，琴瑟永鸣"的檀木扇投奔未婚夫许崇西，被护卫推倒在雪地里。许崇西当众否认婚约、砸碎骨灰坛而去，纪左扬撑伞走来，蹲下捞起碎瓷唤她"宣仪小妹"。半月后许大帅认下故人之女，孟宣仪代行家法打得许崇西卧床半月。她把仇恨练进飞镖，纪左扬改教她使枪。帮派夜袭那夜纪左扬送二人出城后独自引开追兵，山洞里许崇西说出九年前真相：许帅只赎回纪左扬，把亲儿子抛下悬崖喂狼。许大帅战死于弘田一郎手中，弘田围灵堂索要拳谱，纪左扬当场演示拳法投敌、监造炮楼；炮楼落成前他醉闯她房中要她留下，被她以枪逼退。轮船开走当日他引爆预埋火药与日军同尽，川城落下一场红雪。

**关键事件**：
1. 孟宣仪雪中背着父亲骨灰坛投奔许公馆，被护卫拦在门外。
2. 许崇西当众否认婚约，推搡中砸碎骨灰坛离去。
3. 纪左扬撑伞相认，唤出"宣仪小妹"与京城旧事。
4. 许崇西讥讽纪左扬不过是许家养的一条狗，纪左扬以"虎父无犬子"回敬。
5. 许大帅回府认下故人之女，孟宣仪代行家法把许崇西打得卧床半月。
6. 许崇西恶作剧报复，反被孟宣仪掐死的蛇吓得尖叫。
7. 孟宣仪把仇恨练进飞镖，纪左扬改教她使枪并当众护她名节。
8. 帮派夜袭，纪左扬独自引开追兵，山洞里许崇西讲出九年前被父亲放弃的绑架往事。
9. 许大帅阵亡，弘田一郎围灵堂索谱，纪左扬当场演示孟家拳投敌，监造炮楼。
10. 醉闯房中逼她留下被她以枪抵喉逼退；轮船开走当日他与日军同归于尽，川城落下红雪。

**逐章写法公式**：

- **情绪流向**：起：屈辱与狼狈（雪地被辱、骨灰坛碎裂）→ 承：甜与暖（撑伞相认、代行家法、晨光教枪）→ 转：撕裂与背叛（夜袭引开追兵、山洞真相、灵堂投敌、炮楼鞭影）→ 合：决绝与悲壮（以枪逼退、赠枪诀别、炮楼同尽、川城红雪）
- **节奏配比**：落难投亲 14% / 公馆斗气 22% / 生死与真相 24% / 投敌与误解 24% / 同归于尽 16%
- **本章结构公式**：让她在最狼狈时被一把伞接住（立羁绊） + 让她亲手执行对他的惩罚（立爽点） + 让他独自引开追兵（立恩义） + 让她亲耳听见他被父亲放弃的往事（立裂隙之因） + 让他当着她的面投敌并亲口说"不需要你们懂"（立误解） + 用预埋的火药把误解一次性翻转成牺牲（立悲壮）
- **本章核心技巧**：**"全程坐实、结尾一次翻转"的汉奸叙事**——投敌的每一步都用主角亲眼所见的暴行与本人亲口的狠话焊死，只在过程中留下"面色淡淡"和"除夕前必须建好"两处不起眼的裂缝；等结尾由他自己的回忆把裂缝撑开，前文所有残忍动作全部被重新结算成布局。
- **卡点与伏笔**：结尾卡点：牺牲钩——炮楼炸响、川城落下红雪，轮船上的人哭得撕心裂肺，故事在此闭合，读者只能回头重读他每一次冷脸。埋设/回收伏笔：①竹伞与披风（第（一）节撑伞捞碎瓷埋 → 第（九）节风雪中立于假山下回收 → 第（十）节"身姿如竹，一如昔年川城雪"再回收）；②檀木扇扇面八字"崇西宣仪，琴瑟永鸣"（开篇埋 → 许大帅认亲回收 → 灵堂前许崇西临昏倒前念出回收）；③"杀豺狼虎豹得用枪才行"（教枪时埋 → 以枪抵喉时回收 → 赠枪时再回收）；④"这炮楼必须得在今年除夕前建好"（鞭打老汉时埋 → 引爆前自答"不然川城百姓怎么能安稳过个好年"回收）；⑤狼与麻袋（跳车夜许崇西胡话埋 → 山洞讲述回收）；⑥"还没能再叫他一声哥哥"（山洞埋 → 轮船上许崇西的未尽之语回收）。

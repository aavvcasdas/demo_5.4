# 第35章 摘要：胭脂将

> 原文 13,287 字 | 篇内小节标记 `（N）`×9 | 全文第 12658-12962 行

**概要**：苏瑕被老太君自山林救回将军府，自幼与宁家七郎宁为誉相看两厌却被指定婚配，新婚夜宁为誉冷漠分床并悄然奔赴战场。苏瑕以将星之姿骑豹领兵、戴龙纹面具替夫破阵，却在除夕夜目睹宁为誉崩溃打翻同心羹、跪求老太君放过自己，由此揭开惊天真相：老太君为破宁家战神契约将鬼将军索命的早死厄运转移给命格至阴的苏瑕，宁为誉为守毒誓只能装嫌赶她。苏瑕饮下融符咒的别离酒完成契约转移还宁为誉自由，解长命锁系其颈，持枪奔赴最后一战，留一句下辈子你还记得我吗。

**关键事件**：
1. 苏瑕被救入将军府，与宁为誉相厌却被老太君指定婚配，新婚夜分床。
2. 宁为誉嘲苏瑕名"瑕"为玉上斑点，苏瑕大哭，少年慌乱安慰只是不想娶你。
3. 璇华郡主设蝙蝠洞陷阱困苏瑕，飞蝠噬咬，苏瑕失一豹被宁救出，青梅情断。
4. 大婚夜宁为誉透露将上战场，要苏瑕离府，太君点破他怕她成寡妇才推开她。
5. 苏瑕骑豹领奇兵戴面具破阵救宁，军帐亲吻质问，宁反要她带豹远走。
6. 苏瑕偷面具伪装主帅胜仗，宁怒斥军法可处决，老太君亲临升其为副帅。
7. 除夕同心羹前宁为誉崩溃打翻羹汤跪求太君放过苏瑕。
8. 真相揭：太君为破战神契约将鬼将军索命厄运转移给命格至阴的苏瑕。
9. 宁为誉被逼发毒誓告真相则奶奶身死，故装厌恶赶她，实怕她代死。
10. 苏瑕饮符咒别离酒完成转移还夫自由，解长命锁系其颈，持枪赴最后一战。

**逐章写法公式**：

- **情绪流向**：起：欢喜冤家（山林救回、相看两厌、新婚分床）→ 承：温情暗生（蝙蝠洞救命、将星上阵、面具破敌）→ 转：惊天反转（除夕崩溃、契约真相、装厌真相）→ 合：悲壮诀别（别离酒、解锁、赴战）
- **节奏配比**：欢喜冤家 20% / 蝙蝠洞与战场 25% / 温情上阵 18% / 真相揭露 22% / 诀别赴战 15%
- **本章结构公式**：以讨厌外壳立欢喜冤家（埋误判） + 用蝙蝠洞与战场把两人逼到生死相依（立情） + 以除夕同心羹崩溃炸开真相（反转） + 用战神契约全收前文所有温情为祭品（坠底） + 别离酒完成转移做悲壮收束（和解）
- **本章核心技巧**：反向铺垫＋契约阴谋的延迟揭示——男主所有推开都是保护，所有温柔仪式都是谋杀，揭破时前段每一幕被重新结算
- **卡点与伏笔**：结尾卡点：苏瑕持枪出帐"宁混蛋，下辈子你还会记得我吗"悬于赴战前。埋设/回收：①龙纹面具（神力传说埋 → 苏瑕戴之破敌回收 → 揭示是契约载体）；②同心羹（温馨仪式埋 → 除夕打翻回收 → 揭为转移催命符）；③长命锁（嘲名埋 → 解系宁颈回收 → 画像无暇呼应）；④十招银枪（比试埋 → 战场苏瑕使宁家枪回收）；⑤两只小豹子（陪伴埋 → 蝙蝠洞失一回收 → 仅余大弟）；⑥鬼将军（金樽谷提及埋于真相段回收）

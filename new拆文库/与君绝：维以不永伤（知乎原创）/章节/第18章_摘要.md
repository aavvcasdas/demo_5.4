**关键事件**：
1. 生辰当日梅岳绾到镖局归还当票，亲手放姜涉自由。
2. 回溯大雪那年的当铺：一句"眉毛漂亮"改变了他的整个人生。
3. 找不回父亲、全家逃走之后，他把仇恨尽数转嫁到她身上。
4. 谷瑶儿的出现改变了他被囚困的日子，他进镖局学艺。
5. 首次押镖时他试图逃跑摔断双腿，被她日夜照料挽回。
6. 补汤风波后他搬去镖局，却在她被孩子围困时冲出来护住她。
7. 背上说出真相：她的白是白狐的因果报应。
8. 屏风辞行，她把人放走；他揣着没送出的梅花簪离城。
9. 听得浔阳城破，他折回寻她，找遍尸堆仍无所获。
10. 重逢时她已近乎痊愈、即将嫁给平乱将军樊平生。
11. 药是黑狐血，一日不可断；他是间接害死梅家的凶手。
12. 他一命换一命，消散于风雪，把她托付给樊平生。

**逐章写法公式**：


- **情绪流向**：起：惊艳与断然（对镜梳妆、还票放人）→ 承：绵长错位（雪夜典当、十年冷眼、补汤误会）→ 转：真相与追返（白狐因果、城破、遍寻不见）→ 合：换命诀别（抢亲、断药、散作飞雪、多年后镜前画眉）
- **节奏配比**：少年过往 28% / 相拥与误会 24% / 真相与追返 26% / 换命与尾声 22%
- **本章结构公式**：用一个"看不见天日的女主"配一个"被卖来的男主" + 让偶然的一句话成为灾难的起点 + 让善意与伤害长期错位 + 让历史仇怨落到第三方（白狐一族）身上 + 让男主在不自知中站到仇家那边 + 用一命换一命解开所有死结
- **本章核心技巧**：**让一句赞美成为全书的因果起点**——"那个小哥哥的眉毛好漂亮啊"，既是她心动的起点，也是他被买的起因，更是多年后他在喜堂上说的那句"我给你画一辈子眉"的回收点。
- **卡点与伏笔**：结尾卡点：余韵钩（镜中人喃喃"似乎忘了些什么"，耳边响起稚嫩的"那个小哥哥的眉毛好漂亮啊"）。埋设/回收伏笔：①当票（开篇还 → 抢亲时塞回她手里）；②梅花簪（辞行时揣着没送 → 山洞里插上她发间）；③竹骨伞（开篇 → 被孩子们抢 → 被他外袍罩住）；④糖（幼年递糖 → 断气前的最后一口）；⑤眉毛（开篇那一赞 → 结尾画眉收束）。

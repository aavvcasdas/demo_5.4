# 第3章 摘要：平生一顾

> 原文 11,569 字 | 篇内 `（一）`～`（十）` 十小节（标题即主题句） | 全文第 507-806 行

**概要**：宋御史之女宋久恩在父亲问斩当日去求未婚夫梁泊之借免死金牌，梁泊之改口称她"宋小姐"、以"我做不了主"推脱，其新欢慕容珠更当众逼她下跪磕头、套进马拴当马骑、鞭打到十指鲜血淋漓，最后以"什么免死金牌？我有答应过你吗"毁约。宋久恩赶到刑场只见父亲的尸首，暴雨中权宦顾襄平撑着伞走向她，说了第一句话："如果你愿意，我给你一个家，行吗？"——他是被净身入宫的世家子，与慕容丞相在朝堂分庭抗礼。他以"为宋御史报恩、给死敌添堵、找个知根知底的人以绝后患"三点理由娶她，并承诺报父仇"不是一命还一命，而是十倍相抵"。他用小狐狸"恩恩"暖化她，在相府赏花大会上以狐狸为名当众反击慕容珠，随后奉旨抄没相府、搜出勾结外族罪证；梁泊之则亲手甩开死牢中的慕容珠、跳过其亲骨肉、监斩百余口。终局梁泊之造反获胜、带回顾襄平的棺木，宋久恩换上本要在除夕夜穿的新衣，与夫君并肩躺入棺中——她终于可以每一年的除夕都一起过了。

**关键事件**：
1. 父亲问斩当日宋久恩求梁泊之借免死金牌被拒，被慕容珠逼着下跪磕头。
2. 慕容珠让她当马骑、沿途鞭打、当众毁约"什么免死金牌？我有答应过你吗"。
3. 宋御史问斩，顾襄平撑伞走向她，说出"如果你愿意，我给你一个家，行吗？"。
4. 顾襄平以求报师恩、给死敌添堵、以绝后患三点理由娶她，并许诺十倍相抵报父仇。
5. 大婚夜梁泊之潜入要带她走，被她以"你再走近一步，我就喊人"拒绝。
6. 顾襄平送小狐狸"恩恩"，两人以"夫君"相称，感情升温。
7. 赏花大会上慕容珠以"让腹中孩儿认你做干娘"羞辱，顾襄平携狐狸闯入当众反击、抓鞭反抽其面。
8. 顾襄平奉旨抄没相府，梁泊之弃亲骨肉、监斩相府百余口。
9. 普华寺中梁泊之要带她走、声称"今年的除夕夜一定是我陪你一起过"，顾襄平踹门而入。
10. 山道下棋"落子为定，你希望谁赢"，顾襄平迷晕她，坦白十二年前一见倾心。
11. 顾襄平身世揭底：十二年前顾家满门获罪，他被要求净身入宫，靠顾家人脉保全男儿身。
12. 梁泊之造反获胜运回棺木，宋久恩换新衣与夫君并肩躺入棺中。

**逐章写法公式**：

- **情绪流向**：起：绝境（求人被拒、下跪）→ 承：至暗与羞辱（当马骑、父死）→ 转：反击与甜（婚礼、小狐狸、打脸、抄家）→ 合：告别与殉情（下棋、揭底、入棺）
- **节奏配比**：绝境铺垫 27% / 甜与报复 35% / 告别与收束 38%
- **本章结构公式**：先把女主按到泥里（悔婚 → 当马骑 → 父死） + 给一个"名不正言不顺的保护者"（假太监丈夫） + 用他的权力完成公开打脸（狐狸 + 抄家） + 让她的旧爱成为最后的刽子手（监斩 → 造反 → 运棺） + 用死亡把她还给保护者
- **本章核心技巧**：**"倒序加身份"的三次赋值**——同一句"如果你愿意，我给你一个家，行吗？"先作为陌生人的善意出现，再作为权宦的交易出现，最后作为十二年前的旧情出现；每次加一层身份，这句话就重一分。全篇的情绪回报全部压在这一次赋值上。
- **卡点与伏笔**：结尾卡点：反转钩 + 余韵钩——梁泊之撞开棺木，发现宋久恩与顾襄平并肩躺着，终句"她被全世界抛弃了，只有他带她回了家"。埋设/回收伏笔：①车帘后的手（第 22 行埋 → 第 47 行撑伞回收）；②"真是久违的味道"（第 94 行埋 → 第 265 行回收为十二年前尝泪）；③小狐狸恩恩（第 100 行埋 → 第 137-146 行打脸工具 → 第 214 行同赴终局）；④暗器盒（第 209 行埋 → 未及使用，作为"她已能自保"的证明）；⑤"除夕夜一家人一起过"（第 216 行埋 → 第 293-297 行回收为按年重逢）。

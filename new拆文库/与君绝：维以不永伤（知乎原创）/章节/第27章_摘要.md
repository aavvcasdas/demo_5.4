# 第27章 摘要：神箭师门

> 原文 11,142 字 | 篇内小节标记 `（N）`×9 | 全文第 9014-9333 行

**概要**：开篇便是一句遗愿——"如果我不幸死在了战场上，请把我的尸骨带回去，做成一支骨箭，永远陪伴在少爷身边，保护他一生一世。"舒尧臣寻到小院时正是落日斜沉，昔日名震天下的神箭师门传人师招云正捧着一碗饭，柔声哄一个傻子张口。七年前她十三岁，背着弓箭抱着骨灰坛搀着母亲踏出侯府，在漫天风雪中说"不靠天，不靠地，更不求人"，撂下"神箭师门纵是孤儿寡母也绝不受人欺辱"转身离去。他们本是九岁就定下的婚约——舒尧臣一句"我愿意"盼了三个月，初见时那背弓抱拳的孩童竟比他还高半个头，两人互相看不上，从九岁打到十五岁，直到他生辰那夜踹门撞见她在洗澡，春梦之后她一拳打来，却摔给他一支刻着"岂曰无衣，与子同袍"的羽箭。可还没等他表明心迹，师门为救侯爷深入腹地中伏、全军覆没的消息传来。如今大渝承平二十九年开春来袭已连破东穆十二城，老侯爷病故、舒尧臣接掌飞翎军，敌方巫蛊师浑身是毒、躲在战车高台上放蛊，他灯下睹物思人想出对策——普天之下只有神箭师门能穿过千军万马不近身射杀高台之人。他递出那支摩挲了七年的羽箭请她出山，她伸手要接时，身后那双手遮住了她的眼："天黑了，睡觉了，阿云要讲故事了。"她猛地清醒，惨白着脸拒绝——"我若上了战场，我家少爷就没人照顾了。"她告诉他那人不是傻子，有名有姓，叫傅颐之，若没有傅家，神箭师门唯一的后人早就死在七年前，随即讲了那个借刀杀人、白骨地狱的故事：侯爷与她母亲李氏本是青梅竹马，被舒母强行拆散，重逢时李氏已嫁给他最得力的部下；侯爷一念魔障、多有照拂，被妒心极重的大夫人看在眼里，师门出征时他看着师将军那张脸竟闪过"若他死了是否就能再续前缘"的念头，阵法惑心之下鬼使神差推了一把，一剑穿心，师将军临死还说着"阵法诡异，侯爷莫要自责，只请照顾好她们母女"。大夫人在灵堂把这真相吐给李氏，李氏为保住女儿这师门最后的希望忍下血仇，带着骨灰悄然离去。大夫人却仍派人追杀，穷途末路时她们遇见在后山作画的傅家少爷傅颐之；他把她们藏进傅家密道，杀手循迹而来，傅家上下无一幸免、大火烧尽，他在黑暗中一口咬住她捂着自己嘴的手，醒来人便疯了。李氏弥留时只嘱她带着傅少爷好好活下去，千万不要再回侯府。她擦净弓箭要出门寻仇，却被拉住衣角的"天黑了，好恐怖，不要丢下我"绊住，终于扔了弓抱住他大哭，从此隐姓埋名、把弓箭锁进箱底每年加一道锁。舒尧臣许她不为侯府只为百姓而战、事成后把大夫人交给她处置，接他们回府软禁了大夫人；侯府挂上红灯笼迎来迟了七年的大婚，新郎却是傅颐之——她说抱歉，我的一生一世已经给我家少爷了。大婚第二日她换上银甲率军出征，"神箭师门，战无不胜"的喊声中傅颐之踉跄扑到战马下死死拉住她的盔甲，被侍卫架开后一口鲜血喷出，凄厉唤着"阿云——"。五个月后三箭齐发射杀三名巫蛊师、连夺十一城，而坐在门口遥望的他已等不到她了：他根本没傻，全家被灭后真疯一场，清醒后却宁愿从未醒来，夜半握刀对着睡熟的她怎么也狠不下心，恨她害得满门被灭、恨她不离不弃、更恨自己下不了手，只能一日日装疯卖傻。侯府别院那场大火烧死了被软禁的大夫人，马厩里少了一匹马，回光返照的他驾马奔回与她住了七年的小院——即便是死也不想死在外面，做个叫她无处可寻的孤魂野鬼。决战前夕她在营帐里说出那句骨箭的遗言；他躺在长椅上看着夕阳一点点爬过窗棂，相濡以沫，不如相忘于江湖。

**关键事件**：
1. 舒尧臣寻到小院，见师招云正给一个傻子喂饭，问她多久没碰弓箭。
2. 七年前她十三岁携母携骨灰离府，撂下"绝不受人欺辱"。
3. 两人九岁定婚约，互相看不上，打到十五岁。
4. 他撞见她洗澡后春梦，她一拳打来却赠他刻字羽箭。
5. 师门为救侯爷全军覆没，七年后再无音信。
6. 大渝来袭、巫蛊师难近，舒尧臣请她出山射杀高台之人。
7. 她以"我家少爷没人照顾"拒绝，道出那人名叫傅颐之。
8. 真相：侯爷一念之差推了师将军一把致其穿心而死。
9. 大夫人泄密后又派人追杀，傅家因收留她们被灭门。
10. 傅颐之受刺激疯癫，李氏遗命女儿带着他活下去、永不回侯府。
11. 她放弃复仇锁起弓箭，隐姓埋名照顾他七年。
12. 她为让傅颐之得到照顾而嫁给他，随军出征立下战功。
13. 他根本没傻，一直装疯卖傻，放火烧死大夫人后归家赴死。

**逐章写法公式**：

- **情绪流向**：起：苍凉（喂饭的傻子、尘封的弓、故人重逢）→ 承：意气与错失（少年斗嘴、春梦、羽箭、全军覆没）→ 转：血债（一念之差、灭门、密道、装疯）→ 合：各行其道（大婚嫁傻子、出征、火烧别院、长椅上的夕阳）
- **节奏配比**：重逢与离府前史 18% / 少年打闹 16% / 血债真相 24% / 傅家灭门与相依 18% / 出征与诀别 16% / 装疯与赴死 8%
- **本章结构公式**：让最锋利的门第沦为喂饭的仆（立落差） + 让婚约对象成为请她出山的人（立矛盾） + 让真正的仇人是最该感激的恩主（身份反转） + 让她为救下的活人放弃死者的公道（取舍） + 让那个活人其实清醒地恨了她七年（二次反转） + 让两人各奔战场与故乡，谁也没等到谁（闭合）
- **本章核心技巧**：**把"报恩"写成比"复仇"更重的枷锁**——师招云放弃复仇不是因为原谅，而是因为傅颐之拉住了她的衣角；此后每一次她想拿起弓，都被"天黑了，好恐怖"拽回，弓上的锁一年加一道；作者让她用照顾一个人的日常去偿还另一族人的命，债永远还不清，所以她连擦弓都要哭一场。
- **卡点与伏笔**：结尾卡点：双向落空（他躺在长椅上没能等到她，她在营帐里许下骨箭的遗言，两句遗愿互不知晓）。埋设/回流伏笔：①"把我的尸骨做成骨箭"（开篇题记埋 → 决战前夕营帐遗言回收）；②"岂曰无衣，与子同袍"（十五岁赠箭埋 → 七年后寻人 → 战场请援三次回收）；③"不靠天，不靠地，更不求人"（十三岁离府埋 → 她拒绝出山、拒绝侯府两次回收）；④弓箭与锁（离府背弓埋 → 尘封箱底每年加一道锁 → 出征重握回收）；⑤"天黑了，好恐怖"（傅颐之疯语埋 → 出征拉马 → 装傻真相三次回收）；⑥刀子（夜半握刀埋 → "少爷，谁给你的刀子"回收）；⑦大火（傅家灭门大火埋 → 别院烧死大夫人的大火回收）。

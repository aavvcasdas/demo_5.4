# 第8章 摘要：狐仙十二

> 原文 13,015 字 | 篇内 `（二）`～`（十）` 九个标记（首段无标记） | 全文第 2078-2366 行

**概要**：傅瑶是金樽谷狐族的三尾小狐（家中排行十二），为追心上人"十六郎"（宣帝）而进宫做瑶贵人。三年过去，宣帝从不留宿、从不碰她，后宫盛传她有狐臭。长乐宫那棵前朝桂花树的花灵化形成"阿桂"陪她——他容貌与宣帝七八分相似，脾气温柔到连"教训坏女人"都只是把人家的书签顺序打乱。阿桂用自己的灵力，一个月才做成一颗香丸压制她身上的狐味，可服下香丸那一夜，宣帝仍推开她离开。太后母家的李淑妃栽赃她以巫蛊害龙裔，她被贬冷宫；冷宫里照看她的老嬷嬷临终吐露宫闱秘辛：长乐宫桂花树下埋着十数年前被活埋的**六皇子慕长平**，那夜康妃（今太后）牵着十六皇子的手，逼他看着六皇子被活埋。傅瑶终于醒悟：十几年前在花灯节救她的其实是六皇子，玉铃上刻的"长平"是他的名字，她认错了人、爱错了人——与她日日相伴的阿桂，就是附在桂花树上的六皇子残魂。她赤脚狂奔回长乐宫，正撞上太后请来的天师以诛妖阵烧炼桂花树的第四十九天。阿桂的最后一缕残魂在她指尖湮灭，只落下半截焦木。傅瑶三尾尽显、要血洗皇宫，狐七郎与金樽谷主雪明川赶到；雪明川捏碎香丸洒在焦木上，焦木逢春。终局傅瑶以两条狐尾炼成灵丹滋养桂花树，只剩一尾，长守狐狸洞中等待花开。

**关键事件**：
1. 李淑妃以"诊出喜脉"上门羞辱傅瑶，她情绪失控露出狐耳狐尾，阿桂（桂花花灵）现身安抚。
2. 傅瑶回忆她与宣帝的因缘：十几年前她偷酒被侍卫射伤，被"十六皇子"救下、养伤、赠玉铃。
3. 阿桂以一个月一颗的香丸压住傅瑶的狐味，宣帝却仍在当夜推开她；傅瑶在冷月下痛哭。
4. 李淑妃因阿桂的恶作剧动胎气，栽赃傅瑶下药行巫蛊；傅瑶被贬冷宫，交还珠钗、自去瑶贵人身份。
5. 冷宫老嬷嬷吐露秘辛：桂花树下活埋着六皇子慕长平，康妃（今太后）牵着十六皇子看着他被活埋。
6. 傅瑶醒悟"长平"即六皇子之名，阿桂即六皇子残魂，她从头到尾爱错了人、也辜负了真正的那个人。
7. 傅瑶奔回长乐宫，撞见天师以诛妖阵焚烧桂花树第四十九天；阿桂魂魄湮灭，落下半截焦木。
8. 傅瑶三尾尽显要血洗皇宫、扼住宣帝脖颈；宣帝称"我夺了六哥的江山，早该有此下场"。
9. 狐七郎与雪明川赶到；雪明川以压碎的香丸（阿桂最后魂力）洒在焦木上，枯木逢春。
10. 终局：傅瑶以两尾炼灵丹养桂花树，长守狐狸洞；宣帝病逝、太后被逼死、李淑妃疯癫。

**逐章写法公式**：

- **情绪流向**：起：委屈（三年不得宠、被李淑妃羞辱）→ 承：温柔陪伴（阿桂的香丸、恶作剧、表白与拒绝）→ 转：真相（六皇子秘辛、错认了人）→ 合：暴怒与救赎（诛妖阵、焦木逢春、守树）
- **节奏配比**：宫廷委屈铺垫 26% / 阿桂陪伴与心动 30% / 真相揭底 22% / 暴怒与收束 22%
- **本章结构公式**：给女主一个"不可能被爱的理由"（狐臭/异类） + 给一个温柔的影子（花灵） + 让影子替她付出（香丸耗灵力） + 用一段宫闱秘辛把影子认领为"命中注定" + 在真相抵达的同一刻毁掉他（诛妖阵） + 用"枯木逢春"留一线慈悲
- **本章核心技巧**：**"错认 + 错付"的双层遗憾**——她错认了救命恩人（把六皇子当十六皇子），也因此错付了三年深情（把阿桂当外人）。两层错认由同一枚玉铃贯穿，最终形成"明月是他，流萤也是他"这一句全篇的题眼。**结构上最值得学的是：把最大的真相交给一个将死的边缘人物（老嬷嬷）来交底**，既合理又能把"临终吐真言"的情绪加成叠上去。
- **卡点与伏笔**：结尾卡点：世界观的慈悲反转（焦木逢春 → 傅瑶以两尾炼丹守树 → 梦中他俯身吻她）。埋设/回收伏笔：①玉铃与"长平"二字（第（三）节埋 → 第（七）节揭为六皇子之名）；②阿桂与宣帝容貌相似（第（二）节埋 → 第（七）节揭为亲兄弟）；③香丸（第（三）节埋 → 第（九）节变成救活焦木的关键）；④老嬷嬷的独白（第（五）节埋 → 第（六）节全案交底）；⑤雪明川与狐七郎（第（九）节介入 → 引入金樽谷系列世界观）。

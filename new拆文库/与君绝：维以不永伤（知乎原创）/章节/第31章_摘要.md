# 第31章 摘要：凤凰囚笼

> 原文 34,950 字 | 篇内小节标记 `（N）`×20 | 全文第 10327-11333 行

**概要**：两个退隐江湖的"大佬"各自伪装，一个做了东街私塾的教书先生，一个做了西街摆摊卖猪肉的，为省钱合租一个院子，一住三年。楚舒有一双干净的手和一把冷冽的刀，被待嫁姑娘们唤作"西街朱郎"，却淡漠得连名字也不愿多说；陆凡白面书生，志向不过是教书喝酒攒钱娶媳妇，还在门前挂了自己写的对联——上联"凤凰囚笼"，下联"野鸡翔舞"，横批"长欢"。他渐渐发现楚舒常半夜出门、回来一身汗与灰，跟踪到后山必被绕丢，玩笑说他是野猪精、盗墓贼，摸向他衣上灰尘时楚舒却骤然变色"别碰"。红衣美人打着红伞走过东街，楚舒察觉一丝浓烈的杀气，随后又见她从城郊树上跌进陆凡怀里，自称"地藏王"，留下一枚铃铛要他想起了"素明影"是谁就挂在大门前——陆凡转头认定这漂亮姑娘脑筋不清楚，把铃铛扔进了矮柜底。可三天后楚舒浑身是血地带回一个三四岁的娃娃皎儿，陆凡一边上药一边编排他"被家里追杀的私生子"，从此院里多了一口人。皎儿夜里翻墙咬死王阿婆家的公鸡吸血，又摸进陆凡房中要咬他，被楚舒点穴后道出真相：他不是中邪，是中了月狱的鬼符。陆凡做了个带锁的木头小车子把皎儿塞进去，红衣美人却踏风而来连车带人卷上树，点破楚舒是"当年名震江湖的淮楼第一杀手"，说孟婆已盯上了他。不久学生小雪深夜叩门，说姐姐翠婷患了失心疯——那是在云绣坊做活、总在他摊子上买一点点肉却磨蹭很久的翠婷，疯了以后只听楚舒的话，日日坐在他身后痴痴看他卖猪肉，惹得张媒婆来撮合"朱郎配翠娘"，被楚舒一刀剁在砧板上吓退。可这个"小雪"根本不是女孩：真小雪是个男生女相、从小爱扮女孩的孩子，那秘密只有落水时被陆凡救起时撞破过；眼前的"小雪"是孟婆，她哄被下了鬼散的翠婷偷走钥匙，自己早在白日撞进陆凡怀里时就调换了真假钥匙，只为剖开皎儿的背——闻名天下的兰家刀谱就绘制在兰家遗孤的皮上。楚舒破空一剑刺穿孟婆，她拒不交出解药，撞剑逃走；楚舒抱着昏睡的皎儿第一次露出深重的绝望："这孩子不是我的儿子，他是我的罪孽。"真相倒回淮楼：第一杀手舒青本是楚秀山庄遗孤楚舒青，七岁被戴银丝面具的楼主带回训练，十年后查出灭门凶手是云林兰家，那一夜他血洗兰家、连老弱妇孺也不放过，回楼才知自己被下了药；楼主摘下面具是一张腐蚀的脸，哭笑着说出北渚之咒——兰家刀法与楚家剑术百年前本是一家，是北渚家仆谋害主人后平分了独门绝技"流风回雪"，被推下悬崖的北渚小儿子活了下来，把诅咒一代代传到北渚淮手中。北渚淮一手创建淮楼，叫兰楚两家互相残杀应了咒，又从兰家大肚婆腹中剖出遗腹子抛给舒青，随即自断经脉而死，要他继承楼主之位、把孩子养大并告诉他真相，让诅咒一代代延续。舒青跪地落泪，软剑一寸寸刺向胸口，却被婴儿嘹亮的啼哭惊醒——他触到那张柔软的脸，一笑释然，从此世上再无杀手舒青。他其实是被北渚淮下了苗疆七杀蛊，体内住着七个控制七情六欲的傀儡，那三年里半夜出门回来的一身灰正是他自己体内打出的七杀人偶骨灰，靠伽若寺方丈那位苗疆蛊师出身的师弟所授之法，用了三年才拔尽。翠婷终因鬼散深入肺腑在一个黄昏死去，与弟弟合葬后山无碑无字；后山之上地藏王抛下一盏用人皮做成的灯笼——孟婆任务失败，被剥了自己的皮。陆凡烧掉灯笼，从灰烬里拈出一颗幽蓝的澜西舍利，那才是鬼符真正的解药，孟婆当时喊的是"解药没有"而非"没有解药"。解了鬼符的皎儿拜陆凡为师，楚舒决意带他离开渝水城；陆凡先是说不一起走，随即哈哈大笑说"我当然得和你们一起走"，还顺走了楚舒包袱里自己送的那件衣裳。可就在陆凡去学堂辞行的最后一天，老先生与红毛鹦鹉并排死去，他跪下叩首时指尖弹茶试出脖子后一根刻着"影"字的毒针，又在阿哲颈上看见同样的针正慢慢变红——他明白自己再也走不了了。次日清晨他目送楚舒的马车远去，回头把铃铛挂在大门前，洗澡换上那件本就是他旧衣的华服，在额间勾了一朵墨莲，镜中人顷刻气质大变如谪仙。素明影果然来了，抱着红伞坐起身，出口竟是男声——他是月狱的影妖，陆凡便是当年与他并肩的梵妖梵千音。陆凡说"我现在最怕的是你"，怕他的欲望无休止、怕他一点一点杀掉自己的阿影；素明影歇斯底里地反问"是你先杀了我的千音"，陆凡只说"你的千音五年前就死了，现在我只是陆凡"，换来他一句放过学生的承诺。红伞机关喷出六辰雾，千钧一发之际窗下软剑破空，去而复返的楚舒裹住陆凡掠飞月下，自己双眼却被毒雾灼得失明。楚舒凭听觉舞起流风剑法挡下万针，陆凡终于出手——澹如秋水，四两拨千斤，梵妖归位；可六辰雾已渗透楚舒全身，他背起他飞入夜空，把人藏在树上点了穴道、堵住耳朵，撕开锦帕在他耳边留下最后一句："凤凰囚笼，野鸡翔舞——盼你一生自由，一世长欢。"陆凡摘叶作笛把素明影引回院子，探向"长欢"二字露出暗藏的五根乌弦——宫商角徵羽，消失五年的梵音今夜奏响。弦声把素明影一次次拖进幻境：梨花树下蹲着哭的红衣孩童、"我叫梵千音，有我在就不会让你饿死"、两人用一根棍子抬起巨石砸断虎爷双腿、鬼探十三看着他掐死饿狼时说"他比狼还狠"、第一次杀人后在他怀里发抖、灌哑药那日梵千音打翻药碗跪在阎罗面前说"我就是他，他就是我"、鬼探十三死在梨花树下后被阎罗抱在怀里的双生弟弟往事、以及那句"我们逃出去吧"。幻境粉碎，素明影一掌击下，陆凡吐血，自知今夜只有一死。晨曦中楚舒听见一声巨大的爆炸——院里早被浇满火油，陆凡在半空决然一笑，把他奋力推出，说"我宁可做一个自由的魂魄，也不愿行尸走肉地活着"。素明影跪在废墟上撕心裂肺地喊着千音，说他还没来得及告诉对方，自己在梨花树下扎了新秋千、把住所收拾得一尘不染、每天都在等他回来，他那样努力地往上爬只是为了取消追杀令保住他。而事实上陆凡根本没有死——他在院里那口水井下早打了地道，此刻正坐在江面的乌篷船上，被楚舒嘲"算无遗漏实在可怕"，又被问"你不怕你的阿影为你殉情"，他大怒踹去，随即望向蓝天白云骄傲地喃喃"他才不会呢"，然后正色问楚舒："到了新地方安居下来后，你还卖猪肉吗？"

**关键事件**：
1. 退隐的两个江湖大佬合租三年，一个教书一个卖猪肉。
2. 红衣美人留下铃铛，要陆凡想起"素明影"是谁。
3. 楚舒浑身是血带回孩子皎儿，被陆凡当成私生子照看。
4. 皎儿吸食禽血并夜袭陆凡，楚舒道出他中了月狱的鬼符。
5. 红衣美人卷走车子，点破楚舒是淮楼第一杀手、孟婆已盯上他。
6. 学生小雪带来失心疯的姐姐翠婷，翠婷痴恋卖猪肉的楚舒。
7. 钥匙失窃，陆凡识破"小雪"是孟婆，兰家刀谱藏在皎儿背上。
8. 楚舒一剑刺穿孟婆，她拒不交解药逃走，楚舒称皎儿是自己的罪孽。
9. 真相：舒青是楚秀山庄遗孤，被北渚淮利用，血洗兰家后得知北渚之咒。
10. 北渚淮自尽，要舒青抚养兰家遗孤、让诅咒延续；婴儿的啼哭救了他。
11. 七杀蛊与三年拔蛊的真相；翠婷死，姐弟合葬后山。
12. 地藏王送来孟婆的人皮灯笼，陆凡烧出澜西舍利——鬼符的解药。
13. 老先生与红毛之死暴露"影"字毒针，陆凡知道自己走不了。
14. 他挂上铃铛、换回旧衣、画上墨莲，与素明影相认：他是梵千音。
15. 六辰雾中楚舒归来相救失明，陆凡背他逃走并藏在树上诀别。
16. 陆凡以五根乌弦奏梵音，三次幻境回溯两人的少年岁月。
17. 他引爆浇满火油的院子，与素明影的追捕同归于尽（实为金蝉脱壳）。
18. 陆凡从水井地道脱身，与楚舒、皎儿乘乌篷船远去。

**逐章写法公式**：

- **情绪流向**：起：烟火（合租、卖肉、逗鸟、媒婆）→ 承：暗涌（半夜出门、红伞、带血的孩子、鬼符）→ 转：清算（孟婆现身、淮楼往事、北渚之咒）→ 合：诀别与脱身（换装相认、六辰雾、藏树诀别、梵音、爆炸、乌篷船）
- **节奏配比**：市井日常 18% / 皎儿与鬼符 14% / 孟婆之局 16% / 淮楼与北渚之咒 18% / 相认与六辰雾 18% / 梵音幻境与脱身 16%
- **本章结构公式**：让两个最危险的人过最琐碎的日子（立反差） + 用孩子的怪病把江湖的血腥牵进院子（立危机） + 让伪装者混在最信任的人里（身份反转） + 让男主的过去以倒叙方式清算一次（补因果） + 让他为保全朋友主动赴死（高潮） + 再翻案说他根本没死（反转收束）
- **本章核心技巧**：**双线伪装，揭晓时刻错开整整十节**——楚舒的杀手身份在第六节由红衣美人点破，陆凡的梵妖身份直到第十四节才由他自己换装承认；作者让两条身份线各自独立运行，中间隔着孟婆之局与淮楼往事两段完整的大倒叙，读者先以为"杀手室友"是全部真相，再被"书生室友才是更狠的那个"推翻一次。
- **卡点与伏笔**：结尾卡点：开放式远行（"到了新地方安居下来后，你还卖猪肉吗？""嗯，可以考虑"，不做任何收束）。埋设/回收伏笔：①"凤凰囚笼，野鸡翔舞"（第三节埋 → 赴死前回院再看 → 诀别耳语 → 结尾自由生活四次回收）；②铃铛（第四节埋 → 扔进矮柜 → 挂上大门 → 素明影循铃而来三次回收）；③"素明影"之问（第四节埋 → 美人反复追问 → 第十四节自认回收）；④那身衣裳（第十二节陆凡送楚舒 → 楚舒收进包袱 → 楚舒折好带走 → 陆凡临行前摸出穿上 → 楚舒回来找它五次回收）；⑤墨莲与乌弦（第十四节埋 → 幻境中梵千音的青衫与秋水眼眸回收）；⑥"影"字毒针（第十三节埋 → 阿哲颈上的针 → 陆凡走不了回收）；⑦水井（日常埋 → 结尾"你何时在水井下打了个地道"回收）；⑧梨花树与秋千（幻境埋 → 素明影说"我扎了个新秋千"回收）。

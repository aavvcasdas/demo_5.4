# 第32章 摘要：相门娇

> 原文 17,605 字 | 篇内小节标记 `（N）`×13 | 全文第 11336-11708 行

**概要**：东穆一人之下万人之上的丞相凡子衿，娶了一位目不识丁的夫人。婚事是陛下钦赐，原本定的是伯阳侯家四女儿，大婚前不久她心疾突发、嫁衣都来不及试便撒手而去，剩下的千金中只有庶出的五小姐白秋宜尚未婚配，圣旨不可违便由她顶上。皇城人都说一朵鲜花插在牛粪上，马车里的白秋宜却抬起袖子闻了闻自语"哪有我这么干净的牛粪"。新婚第一夜她见到的不是夫君而是小姑子凡子婳——徐州商贾闹事，凡子衿连夜赶去处理。白秋宜有门好手艺，从小不离身的"百宝箱"里装满小刀木削，她雕的桃子当即收买了小姑子，又把府里要扔的缺角太师椅拦下修好，落在婢女眼中却成了"乌鸦飞上枝头也变不了凤凰"的笑话。隔天一群人捧着妆盒珠钗来让她修，她手忙脚乱全应下，只说"不碍事，反正闲着也是闲着"。春日午后风筝断线坠到府外，她捞起裙子钻进狗洞去捡，一头撞上洞外腰间佩刀的清秀少年，凡子婳却在她身后尖叫"哥哥你回来了"——她错认了。真正的凡子衿从少年身后走出："阳春三月，佳人出洞，这可真是个别致的相迎方式。"他一袭玄衣负手而立，蹲下身当众抹掉她鼻头的灰："怎么弄成这样，跟只花猫似的，即便是我新婚之夜留你而去，你也不用如此急不可耐吧。"同回的还有徐州商会会长的千金沈小姐，凡子衿对她极好，安排最好的庭院、每日送珍贵礼物，她却统统扔出去骂"滚，你害死了我爹"——他要的其实不是她的真心，而是一本牵涉九王爷的证据账簿。白秋宜只喜欢他的笑容，也为自己的目不识丁心虚，凡子衿却当夜找她沏茶说"目不识丁又如何，我凡子衿的夫人哪怕连自己名字都不会写，也照样是这府中最尊贵的女人"，并亲口许诺要教她读书写字、把她从前在侯府受的亏欠一一补回来。他其实什么都知道：四姐不是心疾亡故而是与情郎私奔，只是"我娶的是伯阳侯的女儿，老四与老五又有什么区别"。沈小姐又一次摔了礼物，白秋宜鬼使神差地想替他做点什么，用上好的金叶檀木做了一整套茶具送去，凡子衿却脸色一变，当着沈小姐的面给了她一记耳光——那木头是他特意带回给沈小姐做琴用的。她夺门而出，当夜叶昭替相爷送来伤药，说那些哄骗她的婢女已受惩治，又说金叶檀木只有香云山才有，沈小姐不过是寻由头发难。白秋宜却说"并非只有香云山才有，我知道哪里还有"——皇城西郊的山崖下长着极少量的金叶檀木，采之稍不留神便跌下万丈深渊。两人谁也拗不过谁，一同去了三天，回来时一身血污，她背上绑着一截正好够做七弦琴的木头递给凡子衿："还给你，我不欠沈小姐的了。"他把金叶檀木弃在地上，拦腰抱起她走向马车，在车里说"永远不要同我这种人赌气，因为不值得，你也看不到最终的结局"。不久沈小姐交出东西后跳井自尽，凡子衿没流一滴泪；而此前她曾在院里叫住白秋宜，说"你永远不要爱上凡子衿，他这个人没有心的，除了亲妹妹，谁都不过是他手中的一枚棋子……他给的温柔，就是毒药"。白秋宜自此沉迷木工、对凡子衿冷淡，只与凡子婳和叶昭亲近，为叶昭做鞋袜、缝佩剑的穗子，凡子衿看在眼里不动声色。扳倒九王爷后他半夜摸进她被窝圆了房，少年侍卫就守在屋外握剑的手颤抖不止。白秋宜有了三个月身孕，怕梦醒；可凡子衿行事疏狂树敌太多，其中便有她的父亲伯阳侯。祭祀大典前半月他陪她回娘家，她把凡子衿替她求来的往生锁放进母亲灵牌后，锁背刻着四行她看不懂的诗句——那其实是一首影射当今陛下的反诗。叶昭在大典前三日的雪夜告诉了她真相：大典上陛下亲临，会有安排的证人当众揭发，那枚往生锁就是陷害伯阳侯府最重要的一环。她要连夜取回，刚踏入夜色院中铃响，凡子衿走出来说"阿昭，你终究还是背叛了我"，随即下令"把夫人带过来，将叛者当场诛杀"。雪夜刀光中他最后把她按进怀里捂住耳朵："不要去看，不要去听，大雪会冲刷掉一切痕迹。"血花流到她脚边，她凄厉地喊着阿昭。此后她被软禁在那间庭院，疯了一样刻叶昭的模样被烧毁，改刻一只鸟；大典前夜凡子衿说木已成舟，第二天黄昏却呼吸急促地追问"你是怎么办到的"——她说"我做了只鸟儿，它飞出了窗外，飞去了伯阳侯府"。她先一步递上和离书，字迹是他一笔一划教出来的，他撕得粉碎说"不管生生死死都是我凡子衿的人"；她腿下流出鲜血，说在来见他之前已喝了一碗药，"这个孩子，留不住了"。两年后相府垮台、凡子衿获罪入狱，白秋宜带着一口棺材走进死牢，棺里躺着一具活人大小的木雕，唯独缺一双眼睛。她刻着眼睛问他怪不怪自己，他说"成王败寇，落子无悔"；她坦承这一生只爱过他一人，他笑意终于到了眼底："如果再来一次，当年春风三月里，我也依旧希望娶的那个人是你。"木雕上有异香，凡子衿如坠梦中。醒来时小船漂在神木山的湖心，他躺在她怀里——她以木代人、偷天换日，牢里自有另一个"凡子衿"替他受刑。原来她与母亲都是神木一族的后人，先祖是一只能让雕刻活过来的木灵，当年那只为白家通风报信的木鸟、如今替他赴死的木雕，都是她耗尽灵力所刻；而那个孩子，并非被她一碗药打掉，是她动用灵力救家族时身子受损才失去的。她的路到尽头了，只留一丝希望给他说，元神湮灭后把肉身置于神木之中，去金樽谷找那位神通广大的谷主说不定有生机。她低下头，最后对着怀里的男人轻轻一吻："凡子衿，你终于为我……有了心。"

**关键事件**：
1. 目不识丁的庶出五小姐白秋宜替嫁，成为丞相凡子衿的夫人。
2. 新婚夜夫君赴徐州，她与小姑子凡子婳作伴，靠木匠手艺赢得亲近。
3. 她在狗洞外错认夫君，凡子衿一句"佳人出洞"与抹灰之举令她心动。
4. 凡子衿为徐州账簿讨好沈小姐，白秋宜误以为那是纯粹的情意。
5. 她用金叶檀木做茶具讨好沈小姐，反被凡子衿当众打了一记耳光。
6. 她与叶昭去西郊山崖九死一生采回金叶檀木，"不欠沈小姐的了"。
7. 沈小姐交出东西后跳井，临终前告诫她"他给的温柔就是毒药"。
8. 凡子衿深夜圆房，白秋宜有孕，却仍被当作用往生锁陷害伯阳侯府的棋子。
9. 叶昭为救她背叛凡子衿，在雪夜被当场诛杀。
10. 她刻木鸟飞去伯阳侯府通风报信，救下家族并递上和离书、打掉孩子。
11. 两年后相府垮台，她带棺材入死牢，以木雕替身救出凡子衿。
12. 真相：她是神木一族后人，木鸟与木雕都是她耗尽灵力所刻。
13. 她元神将散，留下金樽谷的一线生机，在他怀中吻别。

**逐章写法公式**：

- **情绪流向**：起：自嘲（牛粪、狗洞、花猫）→ 承：沉溺与掌掴（教字、心动、茶具、耳光、崖底取木）→ 转：清醒与背叛（沈小姐之死、圆房、反诗、雪夜杀人）→ 合：以命相救（刻鸟、和离、死牢木雕、神木山吻别）
- **节奏配比**：替嫁与心动 20% / 茶具与崖底 16% / 沈小姐与圆房 14% / 反诗与雪夜 18% / 和离与垮台 14% / 死牢与神木山 18%
- **本章结构公式**：让最不般配的两个人被圣旨绑在一起（立错位） + 让她用自己的笨拙一点点靠近他（立情） + 让他为了棋局把她和她的家族都摆上棋盘（立狠） + 让她在被利用到极点后反过来搅乱他的棋局（反转） + 让他在输掉一切后才被她救（身份反转） + 让她的血脉成为全部奇迹的根，也带走她自己（闭合）
- **本章核心技巧**：**让"木头"与"人心"互为反题贯穿全篇**——母亲的遗言"人会辜负你，木头却不会"是全书的题眼，白秋宜一遇伤心就回到刻木头；她替所有人做木器，最后做的两件木器（木鸟、木雕）却都越过了"不会动的木头"的界限，一件救了家族、一件救了夫君，而代价是她自己。作者让物件的性质在最后三节发生变化，此前所有关于"手艺"的日常描写全部变成伏笔。
- **卡点与伏笔**：结尾卡点：留一线生机（"去金樽谷找那个神通广大的谷主，说不定能有生机……活着才能等到我醒来的一天"）。埋设/回流伏笔：①"哪有我这么干净的牛粪"（开篇埋 → 她在他面前承认自己"的确是坨牛粪"回收）；②百宝箱（随嫁妆埋 → 婢女刁难 → 软禁时送来 → 死牢刻木雕四次回收）；③狗洞（捡风筝埋 → "佳人出洞" → 结尾她带他离开皇城三次回收）；④金叶檀木（做琴埋 → 她做成茶具被掌掴 → 崖底取回 → 做成新琴 → 沈小姐抚琴五次回收）；⑤"他给的温柔就是毒药"（沈小姐埋 → 白秋宜在雪夜回想 → 递和离书时引述三次回收）；⑥往生锁（回娘家埋 → 反诗真相 → 大典被搅回收）；⑦木鸟（刻鸟埋 → "它飞去了伯阳侯府" → 神木血脉真相回收）；⑧神木山（母亲遗言埋 → 她说"我终于回家了" → 小船漂在湖心回收）。

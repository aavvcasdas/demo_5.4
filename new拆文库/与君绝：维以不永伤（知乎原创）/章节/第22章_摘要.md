# 第22章 摘要：吾皇

> 原文 12,790 字 | 篇内小节标记 `（N）`×8 | 全文第 7126-7415 行

**概要**：叶裳被藏在夕音女皇寝宫的密室里，坐在轮椅上透过气孔窗冷眼看着丞相元昭与女皇在床榻上亲热——她本是元昭的未婚妻，如今只是女皇口中那个"声音"。东穆女强男弱，律例规定身患顽疾、体有残缺者不得为帝；当年六王爷逼太医院院首元昭父亲毒哑夕音公主，元父掉包成猛效补药骗过他，祭祀大典上夕音反将一军公示"男子不得为帝"的诏书夺位，盛怒的六王爷派杀手将避难的元家满门杀绝，只有元昭与叶裳因途中下车采一味紫红小花躲过一劫。此后元昭化名赵远揭皇榜入宫，救下中了六王爷慢性奇毒、声节尽毁而失声的女皇，又发现叶裳的声音与女皇一模一样，遂与女皇联手：由叶裳藏在御座下密道里，按女皇案几下的手语发声，瞒过满朝文武。两年间元昭凭此一路升至丞相，与六王爷分庭抗礼，却也胃口越来越大，要的不只是复仇而是整个东穆江山；当他在女皇面前一棍棍打断试图逃走的叶裳的双腿时，她的心就死了，只祝他心想事成、高枕无忧。又一个刺客夜袭之夜，杀手十一误撞花瓶开启机关滚进密室，叶裳举匕首时看见他面罩下的眼睛怔住，被反夺刀制住；她替他止血，说"我比谁都想让他死"。她以梨花白与澜湖旧事演了一场醉戏勾起元昭情意，换来一张叮嘱腿疾的纸条，随即烧成灰。十一开价：说出你的故事，我便救你出去。密室里她讲了自己如何被叶家收养、如何与元昭在祠堂立誓，也讲了徐州水患后与她相依为命的邻家男孩小石头——官府赈灾时他去抢粮再没回来，她被元昭父亲救走赐名"裳"，原路回去找他只拾到片刻着"叶子姐姐"的叶形石片。十一背着她逃出深宫，说要带她回自己开满桃花的家乡、给她做桃花糕，还说她面善；她服下以为是元昭送来的毒酒，在他肩头摩挲着石片闭上眼。醒来却是元昭——毒酒是女皇背着元昭送的，他追上救回她，把十一关进死牢，并一气之下杀了擅自动他的女皇。叶裳答应最后一次用声音助他禅位，条件是放十一远走；元昭许诺登位后立她为后。禅位那日她隔着轻纱宣读完诏书，目送十一的马车远去道一声珍重，随即口吐鲜血——她在给十一的离别饭里下了"同裘草"，生同裘死同穴，只为他真能信守承诺。元昭终究食言，官道上的十一捂着胸口吐血，从包袱里的那块石片认出她就是自己的叶子姐姐；寝宫里叶裳说同裘草无药可解，元昭崩溃痛哭，她伸手仿佛看见家乡渡口桃花纷飞里，小石头与阿昭都停在年华最好的模样。

**关键事件**：
1. 叶裳藏身密室，透过气孔窗看元昭与女皇亲热。
2. 六王爷逼元父毒哑夕音公主，被掉包骗过，转而屠杀元家满门。
3. 元昭化名入宫救下失声女皇，发现叶裳声音与之相同，设下"替声"之局。
4. 两年间元昭升至丞相，野心膨胀，当众打断叶裳双腿。
5. 刺客十一误入密室，叶裳救他并说"我比谁都想让他死"。
6. 叶裳以醉戏换元昭情意，与十一达成"讲故事换出逃"的交易。
7. 叶裳讲出徐州水患后与小石头失散、被元家收养的往事。
8. 十一背她出宫，她服下毒酒；元昭追回并杀了送毒酒的女皇。
9. 叶裳以最后一次替声换十一活命，元昭许诺立她为后。
10. 禅位宣读后她口吐鲜血——早服下同裘草与十一共死。
11. 元昭食言，十一死在官道上并认出她是叶子姐姐。
12. 同裘草无药可解，元昭痛哭，她临终望见渡口桃花里的小石头与阿昭。

**逐章写法公式**：

- **情绪流向**：起：死寂（密室窥视、麻木冷眼）→ 承：微光（杀手闯入、"我比谁都想让他死"、出逃）→ 转：回溯（元家灭门、替声两年、断腿之日）→ 合：诀别（毒酒、同裘草、渡口桃花）
- **节奏配比**：密室现状 14% / 杀手闯入与演戏 20% / 前史回溯 26% / 出逃与真相 18% / 禅位与同死 22%
- **本章结构公式**：把她置于最耻辱的位置（立处境） + 让一个外人闯进来给她出口（立希望） + 用她的口述把全部前史补齐（补因果） + 让救她的人正是她弄丢的亲人（身份回收） + 让她用自己的死验证对方是否守信（终极赌局） + 以她输了赌局收尾（闭合）
- **本章核心技巧**：**以"讲故事"为交易换取自由，把前史全部装进对话里**——全篇四分之一的篇幅是密室中叶裳对十一的自述，前史不是作者补叙而是角色亲口说出，既完成了出逃的动机，也让十一的身世在同一段自述里被悄悄埋好，等石片出现时读者与他同时认出。
- **卡点与伏笔**：结尾卡点：宿命钩（她临终望见渡口桃花里的小石头与阿昭，停在年华最好的模样）。埋设/回收伏笔：①气孔窗与手语（第一节埋 → 御座下密道发声、禅位隔纱宣读两次回收）；②梨花白（第三节"阿昭最爱喝的梨花白"埋 → 毒酒与纸条回收）；③叶形石片刻"叶子姐姐"（第六节埋 → 官道上十一从包袱里摸出回收）；④"说带你走就一定会带你走"（第六节童年口癖埋 → 第七节十一背着她说同样一句回收）；⑤"我祝你心想事成，高枕无忧"（序章埋 → 第五节断腿回放回收 → 元昭"再也睡不好一个觉"回收）；⑥体残不得为帝（第四节律例埋 → 打断双腿、她坐轮椅、女皇被架空三次回收）；⑦同裘草（离别饭埋 → 禅位后吐血回收）。

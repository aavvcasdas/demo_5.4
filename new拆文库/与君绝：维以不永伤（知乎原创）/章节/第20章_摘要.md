# 第20章 摘要：碧眼千岫

> 原文 17,062 字 | 篇内小节标记 `（N）`×12 | 全文第 6379-6756 行

**概要**：千年碧蛙千岫离开金樽谷游历人间，贪凉睡在顾府后院井底，一觉三年，醒来时被井边白衣小公子顾衡深的读书声留住，此后两年每日黄昏隔井相伴，被他唤作"小青蛙"。为能站在他身边，她冒险以一己之力渡三道天雷，最后一劫被赶来的顾衡深以身相护，他挡下天雷当场吐血，把她送回井底后死去，她重伤昏睡五年。醒来时顾家已衰败到山穷水尽，顾衡深孤注一掷以全部家当赌玉，她蒙面现身，凭一双能透视原石的碧眼让他弃废石、选污泥圆石，开出血玉凤凰，顾家因此起死回生，她也以"玉娘子"之名留在他身边，暗中对月修炼想恢复那张渡劫后坑洼如癞蛤蟆皮的脸。西郊遇袭她耗尽灵力救回他，脸刚恢复光滑却被随后赶到的徐婧瑶顶了功，自己打回原形无人看见；待她回来，他推门撞见木桶里丑陋的她，当场呕吐，从此隔屏风说"人与妖终归殊途"，转而与徐婧瑶定亲。她临走前在月下以灵力点亮他颈上玉珠作贺礼，被徐婧瑶主仆窥见"不是人"，徐家遂请栖霞观老天师设局：徐婧瑶装病，药引正是千年碧蛙的一双绿瞳。顾衡深亲手剜出她的双眼，徐老板与天师进门夺走碧瞳，她被关进铁笼待炼化成玉。顾衡深端饭时在笼前恸哭，才认清西郊救他的一直是她。秋雨里失明的她仍念诗唤"小公子"，他崩溃道出真相——当年那个小公子早已死在雷雨中，眼前的人是孪生弟弟顾云深，天煞孤星的命格让他被接回顾家顶替兄长；他态度骤变，恰恰是因为对她动了心却不敢冒充哥哥领这份情。大婚夜他灌醉徐婧瑶取钥匙救她出逃，她伏在他背上抚过他的脸，说"原来我一开始就找错了人"，含笑消散。金樽谷谷主雪明川踏雪而来，收拢她最后一缕元神，带顾云深回谷；十年百鞭之刑，他以血肉滋养她的元神，刑满之日她重获新生，他弥留之际只求她唤一声"顾云深"。

**关键事件**：
1. 千岫睡在顾府井底三年，被顾衡深的读书声留住，获名"小青蛙"。
2. 她独自渡天劫，顾衡深替她挡下第三道天雷后身亡。
3. 五年后顾家败落，顾衡深以全部家当赌玉，千岫碧眼识玉助他开出血玉凤凰。
4. 西郊遇袭她耗尽灵力救他，功劳被徐婧瑶顶替。
5. 他撞见她的丑陋原形，隔屏风说"人与妖殊途"，转而与徐婧瑶定亲。
6. 月下赠珠施法被徐婧瑶窥破，徐家设局装病索药引。
7. 他亲手剜出她的双目，她被关铁笼待炼化成玉。
8. 他得知真相：眼前人是孪生弟弟顾云深，兄长早已死于那场雷雨。
9. 大婚夜出逃，她含笑消散，雪明川收拢一缕元神。
10. 十年百鞭之刑后她重生，他弥留时求她唤一声"顾云深"。

**逐章写法公式**：

- **情绪流向**：起：清甜（井底共读、一声"小青蛙"）→ 承：倾覆与重生（天雷夺命、赌玉翻身、碧眼复兴）→ 转：最狠的背叛（撞破原形、剜目入笼、真相揭穿）→ 合：赎罪与归还（大婚夜出逃、十年百鞭、元神归来）
- **节奏配比**：少年相伴 12% / 赌玉翻身 18% / 嫌弃与定亲 16% / 剜目入笼 20% / 真相与消散 18% / 十年刑满 16%
- **本章结构公式**：让她为一个不存在的人修成人形（立执念） + 让她救了他却被别人顶功（埋错位） + 让他因为爱她而推开她（立矛盾） + 让他亲手毁掉她最珍贵的东西（坠深渊） + 告诉他连被爱的资格都是借来的（身份反转） + 用十年刑期把这笔账还回去（赎罪闭合）
- **本章核心技巧**：**身份错位＋延迟揭示的双层错位**——她以为他仍是那个小公子，读者也以为是同一个人；等"顾云深"三字落地，此前所有温柔、所有残忍都被重新结算一次，而当年的救命之恩与后来的剜目之痛落在同一个人身上，恩与仇不做切割。
- **卡点与伏笔**：结尾卡点：宿命钩（谷主问"你是否愿意跟我回金樽谷"，接十年百鞭之刑的倒叙回答）。埋设/回收伏笔：①"七月在野，八月在宇"（开篇读书声埋 → 铁笼中失明的她重念回收）；②"小青蛙"（顾衡深所唤埋 → 顾云深"再也叫不出那声小青蛙"回收）；③凤凰血玉（赌玉埋 → 顾家复兴回收）；④颈上玉珠（定亲礼埋 → 月下施法点亮回收 → 徐婧瑶窥破触发剜目局）；⑤癞蛤蟆皮（渡劫重伤埋 → 沐浴撞破回收 → 剜目后消失回收）；⑥孪生弟弟（开篇"天煞孤星"命格与顾家五年霉运埋 → 第九节自陈回收）；⑦金樽谷（开篇她离开之地埋 → 雪明川邀回回收）。

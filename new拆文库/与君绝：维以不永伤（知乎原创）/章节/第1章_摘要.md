# 第1章 摘要：羊娘则灵

> 原文 10,883 字 | 篇内 `（一）`～`（十）` 十小节 | 全文第 4-284 行

**概要**：夏则灵本是仲夏所生、自带煞气的羊灵，六岁太子慕容初在皇家狩猎场抱她逃出猎人追捕，反把她释出的煞气吸入体内，从此大病、偏头痛、性情暴戾。她化名御膳房宫女入宫，以"可解百毒的羊奶"救活他，成为南梁太子的贴身奶娘。两人相依十数年：他把她当作唯一能安抚他的存在，把试奶的内侍叶书来当作夺走她的敌人；她则在皇后"从来情深，奈何缘浅"的劝退下，为保住他的储位而答应与假太监叶书来"对食"。慕容初在婚礼上掀盖头、强暴她、宣告"我不会娶你"；出征漠北后，因她怀胎三月（实为七月、体质特殊查不出脉象）而刑讯，下令杖打她腹部，逼她亲手阉割叶书来。叶书来当众自宫求"保孩子"，被慕容初一剑刺死。夏则灵终于在营帐中以长针收回煞气、启用禁术回溯时光，把自己送回避祸的起点——她主动撞树自尽，煞气未再转移给那个孩子。新一世里，十五岁的慕容初选妃时指着一个叫"杨娘"的女子说："你不觉得杨娘这个名字很好吗？"

**关键事件**：
1. 十二岁孤女夏则灵以"奶"救活六岁太子慕容初，被皇后钦点为贴身奶娘。
2. 试奶内侍叶书来与夏则灵隔屏风相伴四年，以歌声化解尴尬；十岁的慕容初宣布"羊娘是我一个人的"。
3. 慕容初因煞气性情大变，唯独在夏则灵面前温顺；抓错人事件后鞭笞叶书来。
4. 皇后以八字"从来情深，奈何缘浅"劝退夏则灵；叶书来告白"我是个真男人"（假太监身份伏笔）。
5. 慕容初雨宫前跪求两天两夜，商帝踹子、呕血；醒来后天翻地覆——夏则灵与叶书来已成对食之礼。
6. 慕容初掀盖头、强暴夏则灵，宣称不给她任何名分。
7. 太子大婚换取出征机会；临行前说"别再吃药了，给我生个孩子吧"。
8. 漠北雪洞寻回互抱取暖的夏则灵与叶书来；怀孕三个月引发刑讯。
9. 叶书来为保胎儿当众挥剑自宫，被慕容初一剑刺入心窝而死。
10. 夏则灵以长针收回煞气、启用禁术"回溯时光"，回到永昌十五年狩猎场，主动撞树自尽。
11. 新一世慕容初选妃时选中"杨娘"，称这个名字"像在哪里听过似的"。

**逐章写法公式**：

- **情绪流向**：起：荒诞温暖（喂奶救太子、受封奶娘）→ 承：甜与依恋（屏风歌声、观星台夜谈）→ 转：窒息与恐怖（强暴、杖胎、自宫、刺杀）→ 合：悲悯升华后落入怅然（禁术回溯 → "杨娘"）
- **节奏配比**：慢铺垫 31% / 关系加压 37% / 爆点与真相 29% / 悬念留白 3%
- **本章结构公式**：以奶救他（建立恩义） + 煞气入体（埋下病根） + 独占欲爆发（三次升级：鞭笞 → 强暴 → 杖胎） + 献祭式极端行动（叶书来自宫） + 禁术自毁（改写起点）
- **本章核心技巧**：**"以恩生毒"的闭合环**——女主的善意（喂奶/救人）与她的设定毒性（煞气）是同一件事，因此男主所有的恶都可以被重新解释，读者无法站队。配套动作是"反派自知"（他觉得脑中住着恶魔）与"温情台词说恐怖内容"（"我们回家，好好过日子"）。
- **卡点与伏笔**：结尾卡点：信息差钩——"杨娘"这个名字读者一眼认出，两位当事人却不知，期待回响而非期待连载。埋设/回收伏笔：①叶书来"真男人"（第 116 行埋 → 第 170 行补家世 → 第 206 行"假太监"被当众揭穿）；②煞气与羊灵（第 17-18 行"牧羊孤女身负异禀"不可靠叙述 → 第（九）节回收）；③观星台（第 61 行埋 → 第 256 行回收为"她搂住他说世上没有比太子更善良的人"）；④"羊娘"称谓（贯穿全篇 → 第（十）节变"杨娘"）。

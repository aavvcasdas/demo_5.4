# 第28章 摘要：春日墙头段家郎

> 原文 13,262 字 | 篇内小节标记 `（N）`×9 | 全文第 9336-9663 行

**概要**：段陵被迫入赘叶家那天，把新婚当作生命中最耻辱的日子，红盖头下的叶禾却羞涩含笑，把这一天当作最美的一天。盖头揭开时他眼中是冰冷怨毒，捏着她的下巴嘲讽"好一个叶大小姐，好大的本事"，一字一句说这一生唯一后悔的就是那日在树林里救下她，"我宁愿你死在那里——也好过你如今毁掉我整个人生"。叶禾是富甲一方的叶老爷老来得女，性子温柔腼腆，父亲怕自己百年后她无人倚仗，替她物色上门女婿；段陵打马而过在树林救下与家仆走散的她，叶老爷开口提亲，那少年却以"心有所属，非卿不娶"八个字挡回，于是叶老爷捏住段氏家族生意的命脉，又安排一个美貌戏子哄走了段陵那位青梅竹马，把他逼上绝路入赘叶家。这些曲折叶禾婚后才断断续续知晓；她甚至不敢告诉父亲，段陵至始至终没碰过她，说生下的孩子要姓叶他觉得恶心。第三年春天叶家大厦倾塌——段陵以彼之道还施彼身，暗渡陈仓几年，把账目一点点转移，地契店铺全改姓段，叶家老小与仆人通通被赶出去，唯独留下叶禾：不是出于情意，只是要亲眼看着她从云端跌下。叶老爷一夜苍老，说"别怪他，是爹错在先"，叶禾跪求段陵留下父亲，他想起婚后不久自己骗她去听戏、中途离席去找旧情人柳妹，却被对方狠狠甩开手，酩酊大醉三更回府时，叶禾披衣提灯坐在风里等他，只说"夫君，小心点"，被推开后仍提着灯走在前面引路说"夫君，这边"，他心烦意乱之下到底答允了。此后他隔三差五带女人进门要她作陪，却在花园里撞见一群头牌花魁抢走她的东西嘲她弃妇时怒喝"住手"，夺过来塞给她才发现那是一双为他做的、针脚拙劣却细密的鞋底；他心头一暖，却因她紧接着开口替父亲求医而冷下脸："你知道你做的东西我碰都不会碰的"。两年后叶老爷身体越来越差，除夕夜他带她上城楼看烟花又中途丢下她。她终于鼓起全部勇气夜入他房中从背后抱住他，说只想要一个孩子、有了孩子就搬去陪爹、他也可以再娶；他霍然转身狠狠甩开她怒吼"滚"——他恨她不是真心想要他的孩子，只是想要个依靠，甚至不惜劝他纳妾。入赘纪念日那天他关起房门叫了一群莺莺燕燕大肆歌舞，门外叶禾疯了般拍门哭喊，他摔碎酒杯"不要再跟我提夫人两个字"；一觉醒来府里已挂满白灯笼，昨夜叶老爷撒手人寰。灵堂里她说，昨晚去找他，只想求他在父亲面前做场戏，说会好好照顾她，"可爹说的没错，是我太傻，不该奢望……如果那年在树林里，我没有遇上你，该有多好"。七十七年后，百灵潭里有个常年戴面具、离群索居、睡在棺材中的"假面"，蛇女浮衣天天去送请柬天天被风吹出来，却也天天来，直到满月酒那日她带着好酒好菜终于被收下，在洞中蜕皮化出双腿；潭主春妖踏幽莲而来唤他"段陵，七十七年之期已至"，取出昆仑镜还他寄存多年的回忆。浮衣在镜中看完了那一整段爱恨，跪请同行，春妖把一物交到假面手心说"上穷碧落，我始终不希望你会用上"。原来叶禾心死后拟了一封又一封休书，段陵却撕得粉碎哀求"忘记一切，从头来过"，她抽手而去；他每天去看她，红着眼说"我们生个孩子好不好"，她淡淡答"现在不想要了……总要不到也就不想了"。后来她压抑成疾一病不起，他停了一切生意散尽大半家财带她踏遍北陆南疆求医，得到一本残缺古书——蓬莱海中岛的仙人墓里有长生之药，仙岛每七十七年退潮一次，今年正好是重现之年。他散尽最后家财雇船启程，海上风暴中牢牢护住她说"别怕，有我在"；九死一生登岛后，同行者被墓中金银所惑自相残杀，他阻止不了身受重伤，抱着她滚下窄道跌入密室——中央一口黑棺，棺顶嵌着一颗明珠，长生之药就在里面。他取药递到她嘴边，她问"那你呢"，接过药丸放入嘴中，却忽然扑上去吻住他，用舌尖把药丸送进他口中："夫君，原谅我自私一次，我到底没有勇气承受失去你的痛苦。"他慌乱翻书，在被血染糊的书页上辨出"仙人棺里得永生"一句，奋力推开棺木，里面却空空如也，机关触动海水注入；叶禾躺进棺木推开他，凄声喊着"夫君，好好活下去，若是有心，你七十七年后再回来找我，我会一直等着你"。海水淹没岛屿，他被百灵潭的无垠救起，戴上面具睡进棺材，把记忆寄存在昆仑镜里。七十七年后他终于推开那口棺盖——里面只有一具白骨。古书上被血染糊的前一句是"明珠不灭浮屠阵，仙人棺里得永生"：明珠灭了，药已被他吞下，那只是一场她早已看穿却不肯说破的、为让他活下去而编造的七十七年谎言。面具滑落，他仍是那个春日树林里打马而过的翩翩少年，却再听不到她唤一声夫君；他吞下春妖给的药躺进棺中永世长眠，"君既为侬死，独生为谁施"。浮衣抓住棺木不愿离开，双腿不知不觉化为蛇尾，盘踞在棺上流下一滴泪——看戏的人，戏看久了就出不来了。

**关键事件**：
1. 段陵被逼入赘叶家，新婚夜当着盖头下的叶禾说出"宁愿你死在那里"。
2. 叶老爷捏住段氏生意命脉、拆散他与青梅竹马，逼他入赘。
3. 第三年段陵以彼之道还施彼身，叶家倾塌，唯独留下叶禾。
4. 叶禾提灯等门、为他做鞋底，他却冷言"我碰都不会碰的"。
5. 她夜入房中求一个孩子被怒吼赶出，两人都误解了对方。
6. 入赘纪念日他闭门笙歌，门外哭喊未应，当夜叶老爷撒手人寰。
7. 灵堂上她说"如果那年没有遇上你，该有多好"。
8. 七十七年后百灵潭的假面收到蛇女浮衣的请柬，春妖前来归还寄存的回忆。
9. 浮衣在昆仑镜中看完全部往事，跪请随假面出海寻妻。
10. 叶禾病重，段陵散尽家财带她寻海中岛的长生之药。
11. 古墓中她以一吻把唯一的药丸送进他口中，自己躺进棺木定下七十七年之约。
12. 七十七年后开棺只见白骨，她早已看穿真相却编了这场让他活下去的谎言。
13. 他吞药永世长眠，浮衣化为蛇身盘踞棺木不肯离去。

- **情绪流向**：起：屈辱（盖头下的怨毒、宁愿你死）→ 承：卑微与错过（提灯等门、鞋底、求子、笙歌门外）→ 转：诀别（灵堂、病重、古墓、吻中送药）→ 合：七十���年的空棺（白骨、谎言、永世长眠、蛇女入戏）
- **节奏配比**：入赘与羞辱 16% / 败家与卑微 20% / 灵堂诀别 12% / 百灵潭与昆仑镜 16% / 求药与古墓 22% / 开棺与长眠 14%
- **本章结构公式**：让他把新婚当成奇耻（立恨） + 让她把新婚当成至幸（立爱） + 让他用毁掉她全家来报复（加码） + 让她用一次次卑微的示好撞上他的冷脸（错位） + 让他失去她后才懂得追（反转） + 让她把唯一的生路让给他并编一个七十七年的谎（终极牺牲） + 让他在谎言揭穿后选择永世长眠（闭合）
- **本章核心技巧**：**时间差叙事——把结局放在叙事的中段，把原因留到最后**——开篇先给"最耻辱的日子"与"最美的日子"的对照，第四节就跳到七十七年后的百灵潭与面具怪人，再用昆仑镜把中间二十余年的爱恨整段回放；读者先知道他等了七十七年、再知道他为什么等、最后才知道等到的只是一具白骨，三次反转全部靠叙事顺序而非新信息完成。
- **卡点与伏笔**：结尾卡点：入戏者无法抽身（浮衣化为蛇身盘踞棺木，海水涌起，她再也走不出这座古墓）。埋设/回收伏笔：①"我宁愿你死在那里"（新婚夜埋 → 灵堂"如果那年没遇上你该有多好"回收）；②树林相救（开篇埋 → 灵堂悔语 → 面具下仍是那个打马少年三次回收）；③鞋底（花园被抢埋 → "我碰都不会碰的" → 开棺时他仍穿着旧日模样回收）；④面具（第四节埋 → 抱白骨时滑落露出年轻如昔的脸回收）；⑤棺材（假面睡棺埋 → 叶禾躺入棺木 → 他跳入棺中永眠三次回收）；⑥七十七年之约（古墓埋 → 春妖"七十七年之期已至" → 开棺兑现回收）；⑦"明珠不灭浮屠阵"（被血染糊的书页埋 → 结尾真相回收）；⑧春妖交给他的一物（离开百灵潭时埋 → 开棺后吞下回收）。

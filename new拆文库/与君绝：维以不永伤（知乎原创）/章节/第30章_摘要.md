# 第30章 摘要：白霜无衣

> 原文 14,774 字 | 篇内小节标记 `（N）`×11（原文末两节序号重复）| 全文第 9956-10324 行

**概要**：开篇便是倒叙——"她离开古墓，随他去了师门，等待她的却是一个冰冷的大铁笼。"洛无衣要带白霜离开千霞林时，红发白衣的赤叶追出来嘶声喊"白霜你疯了吗"，她跃下马奔向他，拉住他的衣袖唤"哥哥"，说见过他师父很快便回来，赤叶却蓦地拂袖大怒："别叫我哥哥，我才不是你哥哥。"故事倒回初见：洛无衣在林中迷路被群狼围住，马已被咬破喉咙，一袭红裳白发从天而降驱散狼群，他倒在白霜怀中第一句话竟是"芷儿，你居然没死，你可知我寻你寻得好苦"，又抚着她的白发问"芷儿，你为谁白了头"——那其实是慌乱中的脱口之谎。传闻云岭千霞林的古墓里住着妙手神医白霜婆婆与赤叶先生，洛无衣误入后才发现他们既非老者亦非夫妻，他赖在古墓四个月，整日叫她"芷儿"，白霜每次说"赤叶是我哥哥"都会被赤叶气急败坏地打断。后来他终于接受她不是芷儿，在后山花海讲了自己与芷儿天人相隔的旧事，白霜不谙情事却柔声安抚，不知从何时起他竟真的放下过去；他清晨舞剑、带鲜花、下溪摸鱼、教她唱江南小曲、月下并肩看星，直到半夜避开赤叶带她去后山捉萤火、试探着牵住她的手。赤叶发现后勃然大怒："他不过是看你长得像他的旧情人，拿你当替代品罢了"，又厉声问她敢不敢让他为她一辈子留在古墓；洛无衣一时怔忡，赤叶便趁机将他推出古墓合上墓门，秋雨滂沱中死死按住挣扎的白霜。第二天墓门打开，她看见的是跪在风雨里淋了一夜的他——"我想好了，我愿意为了白霜留在古墓，一辈子也不离开"。他说自己是名剑山庄大弟子，想带她回去禀明师父主持大婚再回到古墓；一路跋涉她哼着小曲患得患失，他请来郎中却被她笑着戳穿忘了"白霜赤叶"的名号，可他没发现她已长睫生霜、呵气成冰、白发又长了一截。踏进名剑山庄的铁笼从天而降，师父拍着他的肩说"不枉为师等了你四个月"，她才知一切都是骗局：芷儿是师父的女儿闻人芷，两年前得了昏睡数月的怪病，庄主命最器重的大弟子坑蒙拐骗也要把白霜婆婆带出古墓；他迷路遇狼后临时编出那句"芷儿你居然没死"，用一个拙劣的谎言骗取她的好奇与信任赖在古墓徐徐图之，却在朝夕相处中真的爱上了她——雨中跪一夜那句"愿意留在古墓"是千万句假话里唯一的真。他在客栈放飞信鸽想先坦诚再求她救人，师父却布下埋伏抢先一步。她只问了一句"芷儿是谁"便将他打入万劫不复，可当她看见他跪地声泪俱下，那只微凉的手还是抚上了他的脸："你当真，当真……不会再骗我？"她被放出来为闻人芷诊治，关上门不许任何人窥探，从清晨到黄昏出来时满头冷汗、白发已拖到地上，芷儿醒了，房里却传来"我要大师兄"的尖叫——闻人芷自小爱慕他，而他只当她是妹妹。白霜独自回房睡去，梦见三人站在花海看霞光万丈，醒来却又是那个冰冷牢固的铁笼。这一次他居高临下地笑着说出"我又骗了你，我怎么可能跟你回古墓，为你待在那个鬼地方一辈子"，说自己与师妹早有婚约，骂她哥哥教过她人心险恶她却偏不听、"落得今日只能怪你自己太蠢"；她抬起似苍老十岁的脸，一口鲜血喷溅而出，此后再不看他一眼，只喃喃"我要回家"。今年冬天的第一场雪里，穿着喜服的洛无衣亲自把她送下山道说"请务必……珍重"，随即掉转马头回去拜堂；她独自向来时路行去，却被一群黑衣人追至悬崖——他们奉命要把她捉回去关进地下室，做闻人芷一辈子的药庐。中箭跌下马的她撕心裂肺哭喊"哥哥，哥哥救我，哥哥带我回家"，一袭白衣踏风而来，赤发飞扬的赤叶令所有人跪倒在地，将她拉入怀中踏风而去，只骂了一句"痴儿活该"。她在古墓里养了大半年才恢复，常坐在花海发呆说"再给我一段时间，我能把他忘了的"；赤叶终于扣住她的肩头说别再叫我哥哥、我想做你的夫君举案齐眉白头到老，她却玩笑般嘀咕"可是哥哥，我已经白了头啊"。当洛无衣再次出现在古墓门前时几乎只剩一口气——他以一人独挑名剑山庄上下的代价与师门决裂。真相这才揭开：诊治时庄主透过另一扇密门全程窥探，看见她割破手腕对准闻人芷的唇喂了几大碗鲜血，那血带着幽香能医百病、解百毒、增功力、延年益寿；庄主趁她睡着又关她进笼，说"她这辈子都休想离开名剑山庄一步"，洛无衣扔剑跪下求他放过白霜，换来的交易是一场大婚换一份自由。于是他在铁笼前说出那些绝情的话，出来后靠在墙上一拳拳打得血肉模糊，送她下山时连一句多的话都不敢说；拜堂良辰他发现宾客少了好些师弟，从闻人芷口中问出真相后连喜服都来不及脱便狂奔到崖顶，只看到一地鲜血。婚礼搞砸后他被囚禁，半年逃了七次、被捉回抽个半死，吞毒自尽时闻人芷终于崩溃放他走——深秋他以独挑山庄上下换得自由，日夜兼程奔向千霞林。可他赶到时已油尽灯枯，倒在白霜怀里说完真相便断了气。尸身被洗净后与她并排躺在古墓床上双手紧握，她仰面对赤叶说"我准备好了，我当真不后悔"，执意化出百年元丹救活他。原来她的真身是一颗红豆，与赤叶本是一株双生红豆，你中有我我中有你，所以一个白发红裳、一个红发白衣，眉目出奇相似；他们在古墓吸收千霞林灵气为生，离谷太久便流失神元、冷彻入骨、长睫生霜，最终结为一具冰雕——这才是赤叶当初拼死阻拦的理由。他相伴她百年、爱了她百年，她却总叫他哥哥；白霜遇险时他喉头一腥感应到异样，立刻动身赶去在冰天雪地里救下她，却听她说"我已经白了头啊"，只能泄气地把她拉进怀里骂"傻丫头"。她昏睡前他凑在她耳边说了最后一句："总笑你痴儿，而我……又何尝不是呢。"她醒来时心口依旧温热——赤叶没有取出她的神元，洛无衣活了过来，枕边却静静躺着一颗殷红似血的红豆。她捧着红豆跪在金樽谷求雪明川，狐七郎在一旁劝阻说神元尽灭只剩空壳救不活，雪明川却说这株双生红豆原本长在他窗前、受他灵力滋养，因阿婴一时贪玩叼出谷外漂泊数百年才有此劫，便让红豆重新结于窗前、日日输送灵力，假以年岁自可再生神元。白霜就此留在金樽谷，洛无衣也留下了——他吸收了赤叶的神元已非凡俗，却再也得不到她一眼。她站在窗前望着那颗随风摇曳的红豆说，人总是在失去后才明白自己真正在乎的是什么，她真正离不开的唯有赤叶；他红着眼说你守着他、我守着你就好，愿用性命替他们看守这株红豆。飞雪纷纷，红豆的光芒一年年愈发强烈，狐七郎躺在树上喝酒摇头笑"痴儿，痴儿，何苦来哉"——他不会知道，很久以后，他也为了一个人，成了他嘴里的那个"痴儿"。

**关键事件**：
1. 洛无衣带白霜离谷，赤叶追出，拒受"哥哥"之称。
2. 回忆初见：他为群狼所困被白霜所救，脱口谎称她是"芷儿"。
3. 古墓四个月，后山花海与捉萤火牵手，两人情根深种。
4. 赤叶以"愿不愿意一辈子留在古墓"逼问，将他推出墓门。
5. 他在风雨中跪一夜，答允为她留在古墓。
6. 到名剑山庄后铁笼从天而降，骗局揭穿：芷儿是师父之女、怪病需白霜医治。
7. 她问"芷儿是谁"，他跪地求原谅，她仍选择信他。
8. 她割腕喂血救醒闻人芷，却被再次关进铁笼。
9. 二次欺骗：他宣称与师妹早有婚约，骂她太蠢，她吐血只念"我要回家"。
10. 喜服送别后黑衣人追截，欲将她做成闻人芷一辈子的药庐。
11. 悬崖边赤叶赶来救走她。
12. 赤叶表白被"我已经白了头啊"挡回。
13. 真相：庄主窥破她血液之秘，洛无衣以一场大婚换她自由。
14. 他与师门决裂奔回古墓，伤重而亡，她化百年元丹救活他。
15. 赤叶代她神元尽灭化为一颗红豆，雪明川许其结于窗前重生。

**逐章写法公式**：

- **情绪流向**：起：焦灼（赤叶追出、拒称哥哥）→ 承：甜与疑（狼群初见、花海、萤火、跪雨）→ 转：崩塌（铁笼、骗局、二次欺骗、悬崖）→ 合：迟来的真相与永远的缺席（独挑山庄、以死谢罪、元丹、红豆、窗前守候）
- **节奏配比**：离谷与初见 14% / 古墓相伴 20% / 铁笼与骗局 20% / 二次欺骗与悬崖 18% / 真相与决裂 16% / 红豆与守候 12%
- **本章结构公式**：先用结局画面开场（立宿命） + 让救命恩人其实是猎人的诱饵（身份反转） + 让他说过三次谎而每一次都更接近真心（叠加反转） + 让她两次被关进同一个铁笼（循环打击） + 让最反对她离谷的人是为她而死的人（终极反转） + 让三个人各守一份无望（闭合）
- **本章核心技巧**：**让骗局的每一次揭穿都比上一次更狠，且每一次都留一点真**——第一次揭穿（他原是来骗她出谷的）留真"雨中跪一夜是真心"，第二次揭穿（他与师妹有婚约、骂她太蠢）留真"其实是为换她自由"，第三次揭穿（他以死谢罪）留真"他独挑师门决裂"。作者让男主连说三次谎言，每次都更难听，却在最后一次全部翻案，读者对他的恨与怜被安排成两条不能同时成立的线。
- **卡点与伏笔**：结尾卡点：旁观者的flag（"他不会知道，很久以后，他也为了一个人，成为了他嘴中的那个『痴儿』"，与狐七郎"绝不会陷在情情爱爱里"对撞）。埋设/回收伏笔：①"为谁白了头"（初见埋 → 赤叶表白时她答"我已经白了头啊" → 红豆真相三次回收）；②铁笼（开篇倒叙埋 → 山庄铁笼 → 二次铁笼 → 地下室之约四次回收）；③"别叫我哥哥"（开篇埋 → 每次被叫哥哥就拂袖 → 双生红豆真相回收）；④割腕喂血（诊治埋 → 密门窥探回收 → 血液之秘成为囚禁理由）；⑤长睫生霜（途中埋 → 第二次铁笼中再现 → 离谷即枯的设定回收）；⑥喜服（送别时埋 → 拜堂良辰发现少人 → 婚礼搞砸回收）；⑦红豆（真身埋 → 赤叶化豆 → 结于雪明川窗前 → 白霜窗前守候四次回收）；⑧"愿君多采撷，此物最相思"（赤叶耳边低语埋 → 红豆光芒回收）。

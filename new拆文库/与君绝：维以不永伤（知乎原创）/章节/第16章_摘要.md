# 第16章 摘要：芊芊

> 原文 11,957 字 | 篇内小节标记 `（N）`×11 | 全文第 4898-5203 行

**概要**：绝色坊老板娘芊芊在柜台后拨着算盘，被妆师谢尘戏称为"钱钱"，这天却等来了梁都首富洛家的大小姐与她的夫君、新科状元崔子钰——半年前他写下休书入赘洛家，从此飞黄腾达。故事倒回三年前：她穿着大红嫁衣过小桥踏进一贫如洗的崔家，白手起家经营胭脂铺供他读书，却在为张员外送香粉时晕倒在烈日下，失去了悄悄降临三个月的孩子；太夫说她很难再有孕，他在院中坐了一宿，一遍遍发誓"我绝不会负你"。他试卷被替换、上诉无门后遇上洛小姐，转而在梁都写下休书、与我彻底斩断。被休的那夜她在夜市买醉遭地痞拖拽，谢尘一身白袍将她救下，之后以"我叫谢尘，为红颜绝色而来"应聘进她的绝色坊，留在她身边。洛小姐一病不起，查明是绝色坊胭脂中掺了奇毒，绝色坊被封、上下入狱，崔子钰请旨全权查办；芊芊被软禁崔府后才偷听到真相：毒是他下的，洛家父女都死在他手里。他拿出户籍与信笺说谢尘是菩提老人的徒弟，接近她只为宋家那道被封为禁术的秘方，并提出一场赌——赌人心的可贵，赌注是她自己。他把两条路摆在谢尘面前：一是获罪问斩，二是拿了秘方离开梁都、永生永世不再见她。芊芊在城楼上看着他接过秘方策马出城，心彻底死去，当晚穿上自己画的新娘妆嫁给崔子钰，在新房里静静等着"红颜白骨"降临——妙手宋家的禁术以她的鲜血为引，每卖出一盒胭脂都是在卖她的心血。她死后成为百灵潭中的白骨新娘，每年祭日重现蚀骨之痛，一守就是百年；直到潭主春妖让她看见昆仑镜里的另一半真相：谢尘那日赶去的是紫云山，找师父菩提老人研制解她的毒的解药，只是迟了一步。此刻镜面上白袍如旧的他，正带着解药奔向自以为充满希望的前方。

**关键事件**：
1. 洛小姐携状元夫君崔子钰到绝色坊挑衅，谢尘当众称芊芊为未婚妻。
2. 三年前她嫁入崔家、开胭脂铺供他读书，为送货晕倒失去孩子。
3. 崔子钰高中被窃、上诉无门，转而在梁都入赘洛家并写下休书。
4. 谢尘救起买醉的她，以妆师身份留在绝色坊。
5. 洛小姐中毒身亡，绝色坊被封下狱，真相是崔子钰借刀杀人。
6. 崔子钰以谢尘的身份与宋家秘方为饵，逼她赌一场。
7. 她看着谢尘接过秘方出城，当晚嫁给崔子钰，化为一具白骨新娘。
8. 百年后昆仑镜现出真相：谢尘那日是为解药赶去紫云山。

**逐章写法公式**：

- **情绪流向**：起：热闹（绝色坊斗嘴、账本与算盘、"钱钱"的调侃）→ 承：旧创揭开（洛府门前的羞辱、失去孩子、那句"我绝不会负你"的誓言）→ 转：连环局（下毒、下狱、赌注、城楼上看到他策马离城）→ 合：白骨与镜中希望（红颜化骨、百灵潭百年、昆仑镜里奔向别处的他）
- **节奏配比**：慢铺垫 26% / 快冲突 28% / 献祭与死亡 26% / 真相留白 20%
- **本章结构公式**：先把死亡的时间钉死 + 再倒叙这段感情如何从春日走向秋日 + 让两个男人分别夺走她的名分与希望 + 让她用禁术换回全部身家却只剩一身枯骨 + 留最后一面镜子揭示她错怪了谁
- **本章核心技巧**：**让同一句话在两个时间点读出两种意思**——"我叫谢尘，为红颜绝色而来"，初见时是情话，真相揭开时是任务书，而两者同时为真。
- **卡点与伏笔**：结尾卡点：余韵钩（"镜面上的谢尘唇角微扬，衣袍在风中飞舞，一声'驾'，奔向他充满希望的前方"）。埋设/回收伏笔：①"又踏杨花过谢桥的谢，何处无尘埃的尘"（第（三）节埋 → 第（七）节与结尾两度回扣）；②失去的孩子（第（二）节埋 → 第（六）节崔子钰"没能保住我们的孩子"回收）；③红嫁衣（开篇埋 → 第（九）节穿上 → 第（十）节"红颜白骨"回收）；④长欢香（第（一）节赠给洛小姐 → 第（六）节毒案回收）；⑤"世间繁华万千，何必执着一木"（第（四）节谢尘劝她 → 结尾他奔向她成悖论式回收）。

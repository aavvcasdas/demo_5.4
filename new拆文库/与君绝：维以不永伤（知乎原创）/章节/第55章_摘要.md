# 第 55 章 · 依依青梅晓

## 概要
潘岳九岁丧母，与世妹杨容姬青梅竹马，桃花仙以三愿换走古镜；多年后潘岳为拒郡主装病毁容、与杨容姬成婚，却因醉心功名渐行渐远，杨容姬放走桃魅、替他许下第三愿，于雪夜病逝，潘岳至死牢前才懂她反复问的"长虹贯日"原是珍惜眼前。

## 关键事件
- 潘岳丧母，杨容姬捂眼让他哭；桃花树下遇桃花仙，以三愿换走商周古镜。
- 西郊被绑，杨容姬冒认"潘家少爷"被灌哑药，潘岳背她下山用磷粉花边留记。
- 杨容姬声节尽毁，潘岳跪杨父定亲，用第一愿使其重开口。
- 张孟阳怀恨将潘岳画像递胖郡主，潘岳装病毁容吓退郡主，杨容姬明志"唯潘岳不嫁"。
- 婚后潘岳河阳种桃，却设阵逼桃魅助己升官，杨容姬偷镜放魅被他掌掴。
- 杨容姬病逝，潘岳方知第三愿已被她替许；八王之乱满门抄斩，桃花仙道出真相，长虹贯日点醒迟悟。

## 关键信息与扩写技法
| 技法 | 说明 |
|------|------|
| 神话映照 | 桃花仙三愿贯穿，将功名贪念与深情守护具象化 |

| 反差痴情 | 杨容姬"笨一点才好"反将护夫，对比潘岳执念 |
| 迟悟收尾 | 死牢前才揭第三愿，悲剧美感拉满 |

## 逐章写法公式
- **情绪流向**：纯真相伴 → 患难相护 → 拒婚成婚 → 名利迷失 → 死别迟悟
- **节奏配比**：前史青梅(25%) + 绑架救赎(20%) + 拒婚成婚(20%) + 仕途迷失(20%) + 病逝点醒(15%)
- **结构公式**：丧母遇仙 → 绑架失声 → 许愿重声 → 装病拒婚 → 种桃逼仙 → 放仙掌掴 → 雪夜逝别 → 长虹点醒
- **核心技巧**：用"长虹贯日"一句话作母题，每次出现推进一层理解
- **章尾卡点与伏笔**：长虹贯日意象收束，呼应幼时采花避雨见虹，点明"珍惜眼前"

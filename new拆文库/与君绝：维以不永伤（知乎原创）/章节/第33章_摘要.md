# 第33章 摘要：岁岁东宫

> 原文 11,444 字 | 篇内小节标记 `（N）`×8 | 全文第 11711-12007 行

**概要**：冬荣成为太子妃纯粹是个意外——岁家上下原本以为这个娴静的大女儿会嫁给棋盘。大婚正热闹筹办时，与太子青梅竹马的二小姐夏灵却留下一张字条，跟着岁府一个英俊侍卫跑了；侯爷与夫人连夜入宫奏明补救，在盛夏那场倾盆大雨中，冬荣穿上红嫁衣、抱着心爱的棋盘懵懵懂懂地入了宫。对外只说夏灵忽染恶疾撒手而去，由胞姐冬荣入宫与太子缔结良缘。新房里太子一杯复一杯地饮酒，内力游走间酒杯应声而碎，抓起酒壶痛饮后信手掷出——酒壶正砸中偷偷掀开盖头的冬荣额头，鲜血顺着额角流下。太子陈煜的酒登时醒了大半，踉跄上前扶住她涩声问"太子妃无碍否"，声音发颤脸色苍白，因为没有人知道这位完美无缺犹如神祗的太子殿下有个致命的弱点：晕血。于是冬荣在嫁入东宫的第一夜被个软绵绵的身子扑倒在床上，说的第一句话是"太医，宣太医，太子晕倒了"。此后两人相敬如宾，冬荣只一心研究棋局。转机发生在入秋——陈煜携她去皇后宫中听戏，半途侍从来报说找到了夏灵的消息，他激动地拂袖就走，叫她自己去听戏；第二天沮丧归来，消息是错的。可那之后的冬荣却一反常态地抱着棋盒拉住他要下棋，"来来来，咱们来下盘棋，这回规矩可得事先说好，省得你到时又耍赖"，那样鲜活生动、不再毕恭毕敬唤他太子的模样叫陈煜怔了一怔。原来他离开那夜，冬荣在宫中迷路，无意摸进后山竹林，发现一片花海、一处小院，和一个与他长得一模一样的人——那人月白素带、长袍墨发、赤脚坐在屋顶上对月吟诗饮酒，一见她便舒眉笑开"是你？"。那一夜他邀她下棋，说有法子破她不败之名，规矩却故作神秘；待她的白子将黑子尽皆包围、一吞江山时，他才狡黠一笑："我的规矩便是棋色相反，所以，白子胜我即胜，你输了。"他说这是他们之间的秘密，身为太子责任太重，只有回到这小小花苑才能做回自己，冬荣问"就像守住你晕血那个秘密一样吗"，两人一击掌。此后竹林约见、月下对弈，回宫又做回太子妃，关系一跃千丈。她更喜欢山间的他——会捉萤火、溪边摸鱼、屋顶唱歌、耍赖悔棋；有一回她在东宫下棋时学他的无赖样眨着眼笑闹"重来重来，这盘不算"，东宫的陈煜却惊愕瞪眼"太子妃竟也会"，她的笑容僵在脸上，从此分不清哪一个才是他的本性。陈煜生辰宴上姬人袖中滑出软剑行刺，冬荣为他挡下一剑，陈煜的手也被剑气划伤，她却还记得捂住他的眼睛不叫他见血光。半月后窗前出现做了标识的竹叶，那是两人的暗号；她提灯踏入竹林时秋雨不期而至，两人躲雨笑成落汤鸡，情动之间一道惊雷划过，他猛地清醒想后退，她却脸色大变一把推开他——陈煜的手上该有一道浅疤，眼前这双手却干干净净洁白如雪。"我是谁也不要的枯叶蝶，是被这天地抛弃的可怜虫，是棋盘上一着不该存在的废棋"，身份败露的他没有惊慌，只有深深的茫然。恰在此时夏灵回来了：那侍卫带她远走高飞，情意却被现实磨尽，最后一次争吵后将她打晕卖进妓馆，她九死一生逃回都城，得知姐姐代嫁成了太子妃便把满腔恨意转到冬荣身上，直到陈煜扣住她甩开怒喝"全是你自己一手造成的……要不是冬荣替你入宫，你全家上下早就受到株连"，离去很远仍听见她撕心裂肺的诅咒："岁冬荣，我诅咒你一辈子得不到真心所爱之人！"山间那人不愿说身份，只说可唤他叶枯。冬荣大病一场闭门两月，在新年第一场雪里终于又提灯踏入竹林——"叶枯，我叫叶枯，叶子的叶，一岁一枯荣的枯""冬荣，我叫冬荣，冬天的冬，一岁一枯荣的荣"，两人重道名姓，当作一切从头开始。竹林岁月与世无争，她想着等陈煜忙完就坦白、请他休了自己。可开春圣上病重、两派剑拔弩张，大渝使臣好棋，礼部办起棋道大赛，谁赢了他便应允一次谈话——那谈话就是大渝的支持。陈煜激动地拥住她要她出战，许她大功告成后一个要求；大赛前一夜她去竹林说叫他等她回来，他紧紧搂住她喃喃"我等你"。半月后她一路过关斩将夺魁，太子妃的名号传遍东穆；可当她赶到后山，花海尽皆枯萎、一地焦土，竹屋里坐着的是饮茶的陈煜——"不用找了，不会再有叶枯了。他就是我，我就是他，确切地说，他是我苏醒在黑夜里的一重人格。"他说幼时目睹宫中争斗、被母后日夜强调太子身份，压力之下生出叶枯；如今大局已定他心中没有恐慌，叶枯便在她赢下比赛的那一刻死了。为了坐实这套说辞，他从怀中取出一层晶莹的东西贴于双手，那道浅疤瞬间消失，与她记忆中叶枯的手一模一样。此后她成了母仪天下的皇后，却摔了棋盘、此生再不碰棋——她曾在棋道大赛上夺魁，无心害死了他。多年后她为陈煜诞下两公主一皇子，夏灵疯癫而死后她又拿起棋盘，邀陈煜去后山的竹屋再下一局；星月下她淡淡道出夏灵临终那句"陛下亦是极苦的……还得忍受双生胞弟离去的残酷事实"，陈煜霍然抬头煞白了脸。真相这才揭开：东穆皇室规定妃嫔诞下双生儿则任何一个都不得为储君，几十年前那个雷电之夜，皇后在与德贵妃争斗的穷途末路中含泪一手捂死了自己的小儿子，把他葬在后山竹林、在坟头种下花海盖起竹屋，又为他取名"烨"、将生辰八字偷偷烧在坟头。陈烨被葬下时其实未死绝，吸天地灵气带着不甘死去的心，成了一只不死不活半人半鬼的魅，魂灵寄托在花海上孤苦长大。他极爱下棋，那夜冬荣闯入竹林时他坐在屋顶回头望见她，枯槁的生命一下有了色彩，不知不觉爱上了她；他不敢说出真相只说叫叶枯——叶即烨，是他母亲取的名，枯是他多年孤苦如枯槁般的生命。那年她去参赛后他满心等她回来，却被哥哥请来的道士烧死在花海里，尸骨无存。陈煜编出双重人格的说辞骗了她十几年，以为岁月漫长总能叫她忘却陈烨喜欢上自己，却算不到幼时对夏灵无心吐露的烦恼会在夏灵临终前被和盘托出。皇后出殡那天举国哀丧，陈煜身披缟素送她最后一程——那一夜真相铺开时她嘴角已漫出鲜血，她早在自己下的白子上抹了毒，浸过毒汁的白棋在棋局游走间钻入她体内，无力回天终能解脱。她说原本黑子也是要浸泡的，但她到底不忍心，他是几个孩子的生父、是整个东穆的国君；她对他亦有情，是多年相伴下来的亲情，可唯一爱过的只有她的叶枯、她可怜的陈烨。风吹长发她望向夜空唇边含笑，这一生下过那么多盘棋，闭上眼只记得一盘——星月下黑子被白子包围，她即将胜利时，执黑子的那人却对她狡黠一笑："我的规矩便是棋色相反，所以，白子胜我即胜，你输了。"

**关键事件**：
1. 妹妹夏灵私奔，嗜棋的冬荣在暴雨之夜抱着棋盘替嫁入东宫。
2. 新婚夜太子掷出的酒壶砸破她的额头，露出他晕血的致命弱点。
3. 两人为守住晕血的秘密而亲近，却仍相敬如宾。
4. 陈煜为寻夏灵中途离去，冬荣却在宫中迷路撞进后山竹林。
5. 竹林里出现一个与陈煜一模一样的人，邀她下棋并设下"棋色相反"的规矩。
6. 两人以秘密为契，竹林月下对弈，关系一跃千丈。
7. 冬荣分不清山间不羁的他与人前自持的他究竟哪个是本性。
8. 生辰宴刺客行刺，她为他挡下一剑，陈煜的手被剑气划伤。
9. 秋雨夜她从手上无疤识破假陈煜，对方自称"枯叶蝶"。
10. 夏灵被侍卫卖进妓馆后逃回，把恨意转到姐姐身上并诅咒她。
11. 山间那人名唤叶枯，新年雪夜两人重道名姓从头开始。
12. 冬荣在棋道大赛夺魁为陈煜赢得大渝支持，赛后却发现花海成焦土。
13. 陈煜以"双重人格"说辞骗她，并以假皮遮去手上的疤。
14. 她成皇后却摔碎棋盘；多年后从夏灵的临终之言查出血案真相。
15. 真相：陈烨是被皇后捂死的双生胞弟，化魅后爱上她，被陈煜请道士烧死。
16. 她以浸毒的白子自尽，此生只记得星月下那一盘棋。

**逐章写法公式**：

- **情绪流向**：起：荒诞（替嫁、酒壶、晕血）→ 承：甜与疑（竹林对弈、两种面目、挡剑）→ 转：崩塌（识破身份、夏灵诅咒、焦土花海、双重人格）→ 合：追查与赴死（多年后再弈、双生真相、化魅往事、浸毒白子）
- **节奏配比**：替嫁与晕血 16% / 竹林初遇与对弈 20% / 两种面目的困惑 14% / 识破与夏灵 12% / 大赛与焦土 16% / 多年后的真相与自尽 22%
- **本章结构公式**：让最不合适的女人坐上太子妃之位（立错位） + 让她在宫中迷路撞见一个不存在的人（立奇遇） + 让同一个人以两种面目与她相处（立悬疑） + 让她赢下一盘棋的同时失去那个人（反讽高潮） + 让官方解释骗她十几年（延宕） + 让她查出血案真相后自己赴死（闭合）
- **本章核心技巧**：**用"棋"承载全部情感结构**——她因棋而嫁、因棋遇他、因棋动心、因棋赢下大赛、又因那场胜利害死他，最后摔棋不碰、再拾棋查真相、以浸毒的棋子自尽。作者让同一件道具在九个节点上反复出现，每次性质都变一次，读者跟着这枚棋子走完她从懵懂到心死的全过程。
- **卡点与伏笔**：结尾卡点：题眼回收（"闭上眼却只记得一盘……白子胜我即胜，你输了"，与竹林初遇那一局遥遥相扣）。埋设/回流伏笔：①棋盘（开篇抱着嫁入宫埋 → 竹林对弈 → 大赛夺魁 → 摔碎 → 再拾 → 浸毒白子七次回收）；②"重来重来，这盘不算"（山间耍赖埋 → 她在东宫学样闹出尴尬 → 结尾只记得那一盘回收）；③手上的疤（挡剑划伤埋 → 秋雨夜无疤识破 → 陈煜贴假皮遮疤三次回收）；④"一岁一枯荣"（冬荣之名埋 → 叶枯自报姓名"一岁一枯荣的枯"回收）；⑤竹叶暗号（约定埋 → 每次陈煜出门后出现 → 新年雪夜再约三次回收）；⑥夏灵的诅咒（岁府埋 → 夏灵临终吐露 → 冬荣死于爱情回收）；⑦双生儿的规矩（多年前埋 → 皇后捂死小儿子 → 陈烨化魅 → 陈煜杀弟四次回收）；⑧花海与竹屋（竹林初见埋 → 焦土 → 她重新种上 → 真相为坟头所建四次回收）。

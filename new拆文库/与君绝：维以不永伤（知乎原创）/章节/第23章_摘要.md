# 第23章 摘要：白扇

> 原文 13,831 字 | 篇内小节标记 `（N）`×16 | 全文第 7418-7816 行

**概要**：扇妖白扇以浮烟扇与流云梳做买卖——予女子美貌皮囊，换取五年到二十年不等的寿命，明码标价童叟无欺。她收过最贵的一笔是二十年：一位北陆南疆最丑的姑娘换来一生渴求的美丽，觅得如意郎君、做了三年贤妻良母后死于大病，弥留时望着虚空中的她苍白一笑，说出"我不悔"。白扇郁郁难抒，月下湖边唤出流云梳里那个五六岁的女童身影——那是她的阿苏。多年前百灵潭寒夜，阿苏为护她被天雷击中魂飞魄散，主人春妖施法强留一缕魂魄锁进阿苏的真身流云梳，从此她踏上收集寿命的漫漫长路：凡人十年换阿苏一年修为，梳上已积数百年却仍远远不够。小道士不凡追一只尸鬼缠上了她，讥她害人性命，却在一场场并肩中越靠越近。乌衣巷里未老人先衰的余娘跪求重回桃花娇颜，只求再见考取功名的相公一面，白扇破例做了亏本买卖；谁料归来的孟兰生已被尸鬼王附身，甩下休书还要取她性命，不凡的五雷火却误刺进被抓去挡剑的余娘胸前，余娘伏在丈夫尸体上含笑说起十年前那朵桃花，闭眼而去。白扇白衣染血，与不凡结成追凶同盟。此后风月馆里年老色衰的旧花魁绿微、一见钟情不凡的新花魁葵儿、偷走降妖符纸的老鸨尸身，一环环把尸鬼王逼到明处。葵儿一路跟着他们，以为白扇是不凡的娘子，跪求一个名分，白扇冷冷说"他是道士，我是妖"；伽兰天师寻来后夜半偷袭白扇，招招杀机直取她颈间流云梳，被不凡挡下，转头却诱使葵儿偷走玉梳。白扇昏前一句"你的师父好像有些不对劲"，点破伽兰练功走火入魔、被尸鬼王趁虚而入的真相。二人寻到白骨洞时葵儿已被吊起放干血，临死道歉说自己只是想有个家。决战中白扇拼死夺回流云梳，天师一掌击来不凡飞身护住她；天师短暂夺回神智掷出符纸命徒弟杀了自己，随即又被控制扑来，白扇飞身挡下那一掌，鲜血四溅。不凡含泪念出"五雷火，结"，伏龙剑穿过师父身体，大火中传来"凡儿，做得好"。白扇弥留前把全部灵力与一颗本元珠渡给阿苏让她有了实体，说出最深的秘密——阿苏不是妹妹，是她的夫君；天上那位看守忘川的仙人与自己的影子相爱，浮烟扇与流云梳相伴千年有了灵性，被贬百灵潭后阿苏在天劫中为护她魂飞魄散。她消散如烟。此后年轻男子带着小女孩走遍江南塞北，包袱里两坛骨灰、一把扇子，说姐姐去了很远的地方，一处处地寻，总有一天能再见她一面。

**关键事件**：
1. 白扇以寿命换美貌，最贵一笔二十年，那姑娘三年欢愉后病亡却说"我不悔"。
2. 阿苏魂魄被锁在流云梳中，白扇收集数百年寿命仍不够。
3. 小道士不凡追尸鬼缠上白扇，讥她害人性命。
4. 余娘跪求再见相公一面，白扇破例做亏本买卖。
5. 孟兰生被尸鬼王附身甩休书杀人，五雷火误刺余娘，她含笑而死。
6. 白扇与不凡结成追凶同盟，追捕尸鬼王十日。
7. 风月馆一役逼出尸鬼王，葵儿对不凡一见钟情并一路相随。
8. 伽兰天师夜半偷袭白扇直取流云梳，又诱葵儿偷走玉梳。
9. 白扇点破师父被尸鬼王附身，二人寻到白骨洞，葵儿被放干血而死。
10. 决战中不凡含泪以五雷火诛师，白扇为挡一掌身死。
11. 白扇临终渡灵力与本元珠给阿苏，说出阿苏实为她的夫君。
12. 男子带阿苏走遍四方，两坛骨灰一把扇，只盼再见一面。

**逐章写法公式**：

- **情绪流向**：起：冷艳（买卖、明码标价、不悔的女子）→ 承：亏欠（余娘之死、白衣染血、同盟追凶）→ 转：暖意与裂隙（阿苏唱歌、葵儿表白、偷梳背叛）→ 合：清算（白骨洞、五雷火诛师、消散如烟、携妹远行）
- **节奏配比**：买卖与阿苏前史 20% / 余娘线 18% / 追凶同盟 18% / 风月馆 16% / 师父真相与决战 20% / 结局远行 8%
- **本章结构公式**：让她靠剥夺他人寿命救人（立悖论） + 让她为一个必死的等待破例（立善） + 让一个道士缠上她并逐步靠近（立情） + 让师父成为最狠的对手（身份反转） + 让她为救他挡掌而死、把执念交托出去（闭合） + 让幸存者带着两坛骨灰继续找她（余韵）
- **本章核心技巧**：**用"买卖"当叙事骨架，把每个委托都写成一次执念的标本**——余娘、绿微、相国夫人、二十年寿命的丑姑娘，四个主顾各占一小节且都指向"女子对美貌的执念"，主线追凶只在她们之间穿行；读者在看单元故事的同时，白扇自己的执念也被摆进同一排标本里，最后一句"她的魔障，便是阿苏"把主角归类和她的主顾归成一类。
- **卡点与伏笔**：结尾卡点：开放式远行（"我们一处处地寻，总有一天能找到姐姐"）。埋设/回收伏笔：①浮烟扇与流云梳（开篇交易道具埋 → 结尾阴阳子母梳的性别设定回收）；②"我不悔"（第二节丑姑娘埋 → 余娘含笑而死、白扇消散两次回收）；③桃花（余娘回忆埋 → 她临终合眼回收 → "再见一面就好"回收）；④伏龙剑（第三节交手埋 → 烤兔、五雷火诛师回收）；⑤降妖符纸（风月馆被偷埋 → 天师掷符命徒弟杀己回收）；⑥"你的师父好像有些不对劲"（第十一节耳语埋 → 白骨洞真相回收）；⑦月梧花（结尾南疆赏花埋，与本书它篇呼应）。

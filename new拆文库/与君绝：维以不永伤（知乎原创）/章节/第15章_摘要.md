# 第15章 摘要：鸢姑宋筝

> 原文 14,100 字 | 篇内小节标记 `（N）`×12 | 全文第 4539-4895 行

**概要**：八岁的宋筝躲在屏风后，第一次见到来鸢城订购贺礼风筝的十五岁少年姚清让——他深爱的师妹穆妍悔婚另嫁魔君冷亭月，他要一只大红色、特别喜庆的风筝去贺喜，说到"喜庆"二字便捂脸哭得昏天暗地。鸢城筝坊的鸢姑必须终生不嫁才能继承秘术，宋筝却被派去招待他，听见他说属兔、从前每年都收到穆妍做的兔子木雕，便偷偷赶工扎了一只绣着"清让"二字的兔子风筝作生辰礼。风筝没能飞起来、断线坠地，他却说这是最棒的礼物；廊下他为旧情痛哭，她许下"春天采花，夏日捕萤，秋雨看书，冬雪煮酒，这些我统统都能陪你去做"。四年后他带着穆妍的女儿穆甜儿重来，此后年年春天住几个月，她及笄后拒尽提亲，十八岁接过《鸢经》成为终生不嫁的鸢姑，他却在第十二年春末赶来求亲，半夜带她私逃筝坊——目的地却是鬼衣谷，他要拿"妻子"换回被误抓的穆妍母女。地牢里岑不语夺走她锁了十二年的木匣，里面是那只没能飞起来的兔子风筝，姚清让仰天又哭又笑。宋筝为岑不语讲了十二夜的故事换下死期，却在最后一餐的酒里下药，把昏睡的他绑上以心头血催动的巨大蛟龙风筝，喊着"长风破万里，送你上青云"把他送上晴空，自己绞断线倒在血泊里。三年后她被岑不语以三成把握的禁术救活，姚清让年年在山外苦等，最终听见她说：曾经默默卑微喜欢着你的那个宋筝已经死了，还是被你亲手杀死的。

**关键事件**：
1. 姚清让为穆妍出嫁来订贺礼风筝，哭倒在筝坊。
2. 宋筝偷偷扎兔子风筝作生辰礼，风筝断线坠地却被他珍重收下。
3. 廊下立约：四季之事她都能陪他去做。
4. 此后年年春日相聚，她及笄不嫁、十八岁接任鸢姑。
5. 第十二年他来求亲，却把她骗到鬼衣谷替穆妍母女顶罪。
6. 岑不语夺出木匣里的废风筝，姚清让才读懂她的心意。
7. 宋筝以《鸢经》秘术耗心血把他送上青云，自己绞线赴死。
8. 三年后被救活，她把他拒在门外，转身走向岑不语。

**逐章写法公式**：

- **情绪流向**：起：轻盈（鸢城春风、兔子风筝、兔子木雕）→ 承：绵长暗恋（年年春日、木匣、泛舟被拒）→ 转：骗局与杀机（鬼衣谷、夺匣、牢中告别）→ 合：燃烧与新生（蛟龙风筝、三年后的拒绝、回头走向岑不语）
- **节奏配比**：少年暗恋 32% / 年年春日与接任鸢姑 24% / 鬼衣谷骗局 22% / 献祭与获救 12% / 终极拒绝 10%
- **本章结构公式**：让她从八岁开始爱一个人（长时间单向） + 给她一条"爱上就得放弃继承"的规矩（加锁） + 让他在最像希望的时刻把她当替罪羊（致命一刀） + 让她用当初最失败的那件信物完成最盛大的救赎（物件回收） + 让她活下来但不再爱他（终局）
- **本章核心技巧**：**让最失败的信物变成最盛大的救赎**——当年飞不起来的兔子风筝，最后化为燃尽她心头血的蛟龙风筝；同一条风筝线，前一次牵不起他的注意，后一次牵住了他的命。
- **卡点与伏笔**：结尾卡点：反转钩（岑不语贴到她耳边说了句什么，她绯红着脸骂"下流！"）。埋设/回收伏笔：①"风筝要登记在册、要收钱"（埋 → 她不收他的钱，才有私自制风筝与后来锁进木匣的次品）；②兔子风筝（第（二）节失败 → 第（八）节被夺 → 第（十）节化为蛟龙）；③四季之约（第（二）节立约 → 第（九）节"不重要了" → 结尾"余生这些事会有另一个人陪她去做"三度回扣）；④《鸢经》秘术（第（五）节接任时埋 → 第（十）节燃心血催动）；⑤穆甜儿的童言（第（四）节点破 → 第（十二）节"她被旁人拐走了"回收）。

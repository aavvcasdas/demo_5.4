# 第24章 摘要：妆师卿平

> 原文 13,236 字 | 篇内小节标记 `（N）`×11 | 全文第 7819-8140 行

**概要**：卿平是百灵潭里半人半鬼的存在——凡尘一位君主用奇珍异宝硬吊着她一口气，肉体封在冰棺中成了活死人，灵魂飘到百灵潭。五十四年后长明灯终要熄灭，潭主春妖允她往生前了却两桩心愿：再去息良见他一面，再向一位故人说声抱歉。故事倒回她接任母亲晴仪的妆师一职入息良宫时——邻国东穆的小王子慕容斐被送来与三公主"和亲"，名义上是驸马，实为抵十座城池的质子，十四岁的他被心智不足、肥硕暴戾的三公主吊在宫门鞭打。卿平几次想迈步都被母亲"闲事莫理、宁可清贫也要平安"的叮嘱压住，直到慕容斐一口血水吐在公主脸上比出"死肥婆"的唇形，她跪下说"若打死了驸马，公主会沦为新寡"，三公主竟大笑放过。当夜她提灯提食盒去喂他粥、替他上药，少年问她名字，她回头一笑："我叫卿平，白衣卿相的卿，平平安安的平。"此后两人相依为命，母亲去世的雨夜里他推门拥住崩溃的她，说"你还有我，你等我长大"。后山她遇见树上云衫墨发的施云，他用妆盒与素白人偶画出了母亲的容颜，让她抱了一次"母亲"，人偶化作漫天花瓣后她如获新生，从此日日喊着"施云——"拜师学艺。施云从她的手艺与身世里认出她是揽月岭闻人氏的独苗，却只在她为慕容斐牵肠挂肚时躺地长叹。三公主卧病，慕容斐衣不解带侍奉，却在她给卿平画梅花妆、肥硕的手揽住卿平腰肢时咬紧了牙。大婚前夜他拥住哭着的卿平说"过了明天一切都会好起来"，眼底却是杀机。喜宴上三公主饮汤后心悸暴毙，太医彻查无果；只有卿平从那盒胭脂里看出——被掺入的香粉与汤中药羹相融才刺激了旧疾，是慕容斐借她亲手画的喜妆下的手。她夺门奔向后山痛哭，施云只说"帝星转移，你那位小兄弟绝非池中物"。此后数慕容斐讨好君王、累积战功、坐山观虎斗，终与九皇子对峙；承华十七年老君王驾崩，遗诏只有八个字"天佑息良，神巫指路"。卿平求施云相助被拒——他历满六次天劫便可位列仙班，此番天劫将至本要避去百灵潭，而帝龙相争他插手不得。她于是带来好酒好菜将他灌醉，偷走妆盒。开坛那日她为太庙神巫金身描眉施妆，金身缓缓升空显灵，举国跪呼"天佑息良，神巫指路"，大局就此而定；她也力竭晕倒，醒来已被新帝册封为后。可她终生解不开自己是骗子与小偷的心结，郁郁成疾；弥留时慕容斐跪在床前哭着说"我说过要让你过好日子"，又取来南疆黎族圣物长明灯，抱着她坐进冰棺，从初见那一夜说起。五十四年后灯灭，春妖携她的魂魄离开秘室，身后传来老君主一声撕心裂肺的"姐姐"。她回到后山声嘶力竭地喊施云，却再无人应答。春妖耳边响起那人说过的话——他是揽月岭三少主、半仙之体，明知酒里有药仍故作醉倒，明知交出妆盒必力竭而崩仍要成全她；天劫中他拖着伤痕累累的身子附在神巫金身上，强撑最后一口气升入半空，只为她描眉时离她最近的一次。他本体是一株红鸢花，漫天红雨里花魂为她开到荼蘼，天知地知他知，而她永不知。

**关键事件**：
1. 长明灯将灭，半人半鬼的卿平请求见他一面并向故人道歉。
2. 质子慕容斐被三公主吊打，卿平一句"公主会沦为新寡"救下他。
3. 她夜半送粥上药，两人自此相依为命，母亲去世雨夜他拥住她。
4. 后山遇施云，他以人偶画出母亲的容颜，卿平拜他为师。
5. 慕容斐借她画的喜妆毒杀三公主，一举摆脱质子处境。
6. 施云点破慕容斐绝非池中物，此后他累积战功与九皇子对峙。
7. 老君王遗诏"天佑息良，神巫指路"，帝位交由神巫决断。
8. 施云因天劫与天规拒绝相助，卿平灌醉他偷走妆盒。
9. 开坛日她为神巫金身施妆，制造显灵奇迹，慕容斐登帝、她被立为后。
10. 她终生背负欺骗师父的心结，郁郁而终，被长明灯留住五十四年。
11. 灯灭魂归，她回后山喊施云无人应答。
12. 真相揭开：施云是揽月岭三少主，明知是局仍成全她，本体红鸢花为她开到荼蘼。

**逐章写法公式**：

- **情绪流向**：起：苍凉（冰棺、长明灯将灭、往生前的两个请求）→ 承：相依（宫门鞭打、夜半送粥、雨夜拥抱、后山学艺）→ 转：共谋与背叛（毒杀三公主、盗盒造神迹、帝后殊荣）→ 合：偿还与永失（郁郁而终、灯灭魂归、后山无人应答、红鸢花魂）
- **节奏配比**：冰棺前史 8% / 宫中相依 22% / 后山学艺 16% / 毒杀与夺位 22% / 神巫显灵 16% / 灯灭与真相 16%
- **本章结构公式**：先给结局再讲故事（立宿命） + 让被弃者遇上唯一肯护他的人（立情） + 让一位仙人以师父身份陪在她身边却不开口（埋暗线） + 让她为救前者骗走后者的命根子（立债） + 让荣华与心结同时兑现（反讽） + 让债主早已不在、道歉永远无处投递（闭合）
- **本章核心技巧**：**两条情感线共用同一件道具**——妆盒既是施云教她手艺、画出"母亲"的恩物，也是她偷走后制造神巫显灵、害他力竭而崩的凶器；作者让"她学会这门手艺"与"她用这门手艺毁掉师父"发生在同一个物件上，恩与债不分开计算，最后她终生不敢再用那个妆盒，物件本身成为她不敢触碰的良心。
- **卡点与伏笔**：结尾卡点：单向成全（"天知，地知，他知，而她，永不知"，道歉永远无法投递）。埋设/回收伏笔：①"白衣卿相的卿，平平安安的平"（开篇倒叙埋 → 冰棺中老君主重复、结局呼喊回收）；②长明灯（开篇将灭埋 → 第五节黎族圣物 → 五十四年后灯灭回收）；③母亲的妆师身份与"闲事莫理"的叮嘱（第二节埋 → 她终究为了慕容斐破了戒回收）；④素白人偶与妆盒（第四节埋 → 神巫金身施妆 → 她终生不敢再用回收）；⑤"闻人氏的独苗"（第五、六节施云喃喃埋 → 结局揽月岭闻人氏被逐往事回收）；⑥"等我长大"（第三节雨夜埋 → 他位极帝王仍跪床前哭"我说过要让你过好日子"回收）；⑦花瓣（第四节人偶化花埋 → 结局红鸢花魂开到荼蘼回收）。

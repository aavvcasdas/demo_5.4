# 第11章 摘要：念念山河

> 原文 19,764 字 | 篇内 `（二）`～`（十五）` 十四个标记（首段无标记） | 全文第 3164-3689 行

**概要**：明容是相爷府的二小姐，幼年大病后成了离不开药罐的病秧子。十五岁生辰前，老相爷听信术士之言，为她"冲喜"，从送来的世家子弟里选了出身将军府、不得宠的庶子端木羽做童养夫。两人屏风相隔同住一室，端木羽抱着剑一夜未眠，说他"想当个大将军"。两年间她从夜夜强忍疼痛不出声，到被相爷训斥后的端木羽得到"虎骑营"的机会；她拖着病体去虎骑营探望、当众替被欺辱的他讨回颜面，也在皇家园林被小太子况宁一次次"掐脸"戏弄。端木羽随军赴大同一战，三十六人只回五人，夜里发梦魇时她从身后环住他。允帝驾崩后况宁登位，在犒赏将士的庆功宴上，端木羽当众请求"解除与明家二小姐明容的婚约"，明容被天子迎入宫中封容妃。三年后一场"清剿长乐侯"的肃清中，端木羽成了被人人称"玉面修罗"的飞翎将军，并在淮南王的逼迫下一剑刺死三朝元老明相（实为老人自己撞上剑、以死成全大局）、明氏一脉入狱。册后大典上端木羽翻盘——他自始至终是宁帝的人，三年潜伏、与虎谋皮就是为了这一日收网。真相全揭：明容的病不是病，是明雪及其母家与帝后合谋用十年慢毒制造出来的"假病"；况宁当年执意带她入宫，是为了把她从"天衣无缝"的暗箭中挪到明处。乱局中端木羽被死士偷袭重伤，踉跄奔进冷宫想见她最后一面，却被她以那把刻着"小舟从此逝，江海寄余生"的木剑刺入腹部——她已因相府之难疯癫，认不出他。终局明容失去全部记忆重获新生、被册为后，况宁给她的儿子赐名"羽"，并带她去皇陵看那块只写"飞翎将军"四字的墓碑。

**关键事件**：
1. 老相爷为明容冲喜择婿，选中将军府不得宠的庶子端木羽；明容说"我应当活不过及笄那一天"。
2. 两人屏风相隔同住一室，第一夜端木羽抱剑未眠，说出"我想当个大将军"与母亲坟前的誓言。
3. 明容夜夜强忍发病不出声，被误会后说"夫君，抱歉"；相爷放还剑、送端木羽进虎骑营。
4. 明容拖病去虎骑营探望，当众替被世家子弟围攻的端木羽讨回颜面："凭他是我的夫君"。
5. 小太子况宁多次掐脸戏弄明容；皇家园林中他开玩笑"要不本太子不娶你表姐，娶你如何"。
6. 端木羽赴边关与大渝一战，三十六人只回五人；夜里发梦魇被她从身后环住。
7. 允帝驾崩，况宁在灵前立誓"护住你，不会再失去"；明容因此病倒、临近十五岁生辰几乎死去。
8. 况宁登位后，明容大病奇迹痊愈；庆功宴上端木羽当众请解除婚约。
9. 明容被迎入宫封容妃（与表姐明雪同入宫，后位暂空）。
10. 端木羽投身淮南王门下，喊出"夺妻之恨，屈迫之辱，不可不报"。
11. 长乐侯通敌案爆发，端木羽奉淮南王之命大肆清剿，得名"玉面修罗"。
12. 淮南王的火终究烧到相府，明相被一剑穿透、明氏入狱。
13. 明容闯宝华殿质问、被况宁下令关入元芜宫；相府数百口不日问斩。
14. 册后大典上况宁发射信号弹，端木羽亮剑翻盘，"你竟是宁帝的人"。
15. 与虎谋皮的三年真相：三人当年密谈一夜定下大局；端木羽潜伏淮南王身边为宁帝拔除贵族势力。
16. 明相之死的真相：老人自己撞上剑、以死成全大局，外人看来是端木羽杀了他。
17. 真相全揭：明容的病是明雪母家与帝后合谋十年慢毒造成的假病；况宁当年带她入宫是为了把她从暗箭中挪到明处。
18. 端木羽重伤奔入冷宫，被疯癫的明容以木剑刺死；明容失去全部记忆、被册为后，儿子赐名"羽"。

**逐章写法公式**：

- **情绪流向**：起：相看两厌（冲喜、屏风、抱剑）→ 承：相护相知（虎骑营、战归梦魇、星与天上的约定）→ 转：夺妻与潜伏（悔婚、玉面修罗、杀明相）→ 合：收网与被弑（翻盘、真相、木剑穿腹）→ 余韵：忘尽前尘的新生（册后、赐名羽、皇陵）
- **节奏配比**：铺垫相处 26% / 相知与夺妻 22% / 潜伏与清剿 26% / 真相与终结 20% / 余韵 6%
- **本章结构公式**：给一位"注定早死"的病小姐 + 给她一个被强塞进来的野心少年 + 让两人从相厌走到相依（照料 → 送军营 → 相护 → 星之约） + 用一个"悔婚"把关系炸开 + 让男方以"叛徒"的皮潜伏三年 + 由女方亲手杀死他 + 最后由男方带她遗忘重生
- **本章核心技巧**：**"双面间谍 + 迟来真相"的巨型回溯**。全篇前 3/4 让端木羽完整扮演负心人（悔婚、投靠权奸、杀岳祖父、玉面修罗），把所有恨拉满；最后 1/4 用第（十三）节整节回溯把"三年前夜谈定局"补完。技巧上最值得学的是**把两处最关键的真相（她中毒 / 他潜伏）合并在同一节释放**，让"愧疚"与"敬重"在同一时间点炸开；同时用"明相自己撞剑"与"木剑穿腹"两个自毁式动作，把悲剧推到不可挽回。
- **卡点与伏笔**：结尾卡点：余韵钩（她在皇陵问"他是谁"，况宁答"是你的一位故人，也是我的一位故人"；以及"冬之夜，夏之日，百岁之后，归於其室"）。埋设/回收伏笔：①"我想当个大将军"（第（一）节埋 → 第（十三）节卷宗回收为真志向）；②屏风与两张床（第（一）节埋 → 撤屏风成婚的约定贯穿全篇）；③木剑与"小舟从此逝，江海寄余生"（第（十）节埋 → 第（十四）节成凶器）；④"等我死了，夫君也会去天上找我吗"（第（五）节埋 → 第（十四）节临终"最后一眼"回收）；⑤明容的病（开篇埋 → 第（十三）节回收为慢毒）；⑥况宁的掐脸（第（二）节埋 → 第（十三）节回收为补偿心理）。

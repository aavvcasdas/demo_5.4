# 第 52 章 · 妙音花嫁

## 概要
宋凉宛自十三岁一见纪元甫便痴心不改，历经百样人生求学、丰城瘟疫生死相随、龙头寨劫法场相救，终与坐轮椅的纪师爷定下婚约，而当年破庙乞儿兄弟龙烈一脉亦就此别过。

## 关键事件
- 宋凉宛十三岁寿宴听《百鬼夜行》口技，屏风后初见轮椅少年纪元甫，一顾终生。
- 缠师学艺，纪元甫令其"先体百样人生"，宋失踪一月混乞丐堆化名芋头，归来骗过纪。
- 纪抱宋入怀落泪，二人定"圆子与芋头"之约。
- 纪赴丰城赈灾瘟疫，宋扮小侍卫混入运粮队，途中遇当年乞儿兄弟龙烈劫道相认。
- 丰城惨状，纪染水痘厉喝驱宋回淮都，宋被拖走誓"死在一起"。
- 纪病重将被火焚，宋发射信号弹率龙烈劫法场，以天陇山药方救活纪与全城。
- 月下龙烈问心，宋明言只随纪元甫，龙烈释怀。
- 回淮都定亲，纪却接密差剿匪龙头寨；宋迟赴见山已焚，纪耳语地道早撤、龙烈留书。
- 宋配合哭戏大嚎"不嫁你了"，虚实之间保全兄弟情。

## 逐章写法公式
- **情绪流向**：少女心动 → 痴缠求索 → 生死患难 → 误会别离 → 反转保全
- **节奏配比**：相遇定情(25%) + 旅途身份戏(25%) + 瘟疫危机(30%) + 剿匪反转(20%)
- **结构公式**：寿宴惊鸿 → 拜师百态 → 离别前奏 → 运粮遇匪 → 丰城抗疫 → 法场劫人 → 月下定心 → 归乡定亲 → 剿匪假哭
- **核心技巧**：用"口技/身份扮演"呼应女主百变性格，让喜剧外壳承载深情
- **章尾卡点与伏笔**：龙烈"终遇一人"之叹、菩提老人带走金世陵季幼棠，为后文角色命运埋线

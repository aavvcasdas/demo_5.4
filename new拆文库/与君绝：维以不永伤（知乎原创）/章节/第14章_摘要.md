# 第14章 摘要：帝女连华

> 原文 12,377 字 | 篇内小节标记 `（十）`×1（原文未给（一）—（九））| 全文第 4228-4536 行

**概要**：东穆是女强男弱的国度，苏瑶长公主在揽月节的满城月梧花下看中了树下执壶品茗的男子卫希，一句"我喜欢你，你跟我走"将他带回宫中立为王夫，卫希却在登位大典前一夜率乱党谋反，被处以五马分尸。苏瑶由此恨上与他酷似的帝姬连华，七岁那年她误闯大殿，被酒醉的女皇以鞭子和金钗划破左脸。少年太傅洛槐英闯殿以身相挡救下她，又不顾血统禁令私下教她天文地理兵法帝策，问她"想过当储君吗"，她答"愿意"。他转赠的一串扇珠被采音公主拿来构陷，伴她长大的奶娘被活活杖毙，大殿上洛槐英说出"连华公主亦臣所爱"替她解围，她仍被罚面壁三月，却在禁足期满后听见他当殿求娶采音，又被苏瑶同席赐给了满脸络腮胡的边将归漠寒，远赴大漠。三年里她替归漠寒剃去胡须、画出破大渝鱼鹰阵的阵法，与他定下"剃一辈子胡须"的婚约；第三年采音与已成为王夫的洛槐英以"女皇病重想见她"为由来到边关，当夜粮草被烧，她被掳至破庙失贞，而始作俑者正是洛槐英本人。她被锁进马车押回都城，才知道采音将借女皇寿辰发动宫变，而洛槐英是华国唯一幸存的六皇子卫英，卧底东穆只为复国。寿辰夜宫变成功，他把苏瑶、归漠寒、采音三颗人头扔到她脚下，说"你是卫希之女，是华国人，只有我们才是一家人"。后来卫英称帝立她为后，她却在烈烈大风中穿上嫁衣奔上城楼，留下一句"你尚有故国可寻，我却早已无家可归"，纵身跃下。

**关键事件**：
1. 苏瑶在揽月节以月梧花定下卫希，卫希谋反后被五马分尸。
2. 七岁连华误闯大殿被鞭打划脸，洛槐英以身相挡救下她。
3. 洛槐英私下授课，问她是否愿当储君，她答"愿意"。
4. 扇珠构陷致奶娘杖毙，大殿上洛槐英说出"连华公主亦臣所爱"。
5. 新年庆宴洛槐英当众求娶采音，苏瑶同席把连华赐婚归漠寒。
6. 大漠三年：剃须、破鱼鹰阵、定下婚约。
7. 边关被掳破庙失贞，幕后人是洛槐英。
8. 寿辰夜宫变，三颗人头落地，洛槐英自陈是华国六皇子卫英。
9. 卫英得天下后立她为后，她身着嫁衣跃下城楼。

**逐章写法公式**：

- **情绪流向**：起：温柔（雪地里撑伞遥遥相望、醒来那句"公主还疼吗"）→ 承：血腥与背叛（奶娘杖毙、庆宴上的假求婚）→ 转：重建与再毁（大漠三年的新生被破庙一夜打断）→ 合：彻底倾覆（宫变、三颗人头、跃下城楼）
- **节奏配比**：少年相依 22% / 扇珠构陷与远嫁 26% / 大漠新生 20% / 破庙与宫变 24% / 结局闪回 8%
- **本章结构公式**：给她一个唯一肯为她挡鞭的人（立爱） + 让他当众把她的名字换成别人（立恨） + 让她在最远的地方重新活过来（给希望） + 在她最幸福的前夜夺走她最珍视的东西（毁希望） + 在她一无所有时赐她一顶后冠（终极反讽）
- **本章核心技巧**：**每一段温柔后面都跟着一笔更狠的账**——伞下的等待、肩上插着的金钗、"不屈的那一句" 都被后文证明带有目的性，作者不让任何一处善意独立存在，读者每回望一次就要重新结算一次。
- **卡点与伏笔**：结尾卡点：宿命钩（"那一年的华国元始，卫英得到了天下，却失去了她"）。埋设/回收伏笔：①"我喜欢你，你跟我走"（开篇埋 → 结尾"你们eps aún回不到最初"回收）；②左脸浅疤（开篇埋 → 大漠庆功宴"脸上那道浅疤在火光映照下别具一番英气"回收）；③扇珠（洛槐英所赠 → 奶娘被栽赃杖毙 → 触发 vot宫变布局的导火索）；④"我会去求陛下赐婚"（元芜宫埋 → 庆宴求娶采音回收）；⑤胡子（开篇"大胡子盖住整张脸"埋 → 剃须露脸、"替我剃一辈子胡须"回收）。

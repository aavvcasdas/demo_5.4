# 第5章 摘要：丑颜听笙

**概要**：红袖馆花魁冰娘之女听笙右半脸生有血色胎记、自幼被母亲厌弃，在妓馆打杂。赵小侯爷赵钰为气走未婚妻珠澜郡主，当众宣称"娶妓院里一个打杂的下人也不会娶你"，被陆相逼着真娶了听笙。新婚夜他被轰出门、她赤脚在冷风中坐了一夜，此后被撵到废弃杂物室，染上风寒。赵府讲席先生洛闻（轮椅、面具、断腿毁容、医术高明）为她治病，她拜他为师学医，两人在竹院琴声中暗生情愫。赵钰醉后强吻她被她扇耳光，后被父亲祠堂鞭打；听笙躲在帘幔后听到他那句"有娘生没娘养的孩子"，现身接住他，被他在恍惚中认作亡母。赵钰染"痫疾"（实为前朝第一使毒高手下的奇蛊七泠丸），太医束手，听笙坚持施针救治并分发药草香囊，赵钰奇迹痊愈。马场上赵钰的狐朋狗友把听笙绑在马尾拖行重伤、珠澜郡主纵容其惨况，洛闻为她解除冰娘所施的毒并治好容貌，露出绝美真容。真相逐层揭开：洛闻是前朝暗卫，听笙才是被三个暗卫（范林、洛闻、冰娘）拼死护出的前朝小公主，坊间"小皇子"之说只是障眼法。义军夺回故国后听笙登基，随即把皇位传给洛闻（新帝"字闻"），与赵钰归隐山林；洛闻一生未娶，只在宫中建了一座种满翠竹药庐的别院。

**关键事件**：
1. 赵钰为气珠澜郡主当众扬言娶妓院下人，被陆相逼迫真娶了丑女听笙。
2. 新婚夜被轰出门、赤脚冻一夜，被撵到杂物室，染风寒。
3. 讲席先生洛闻为她诊病，她拜师学医，竹院琴声暗生情愫。
4. 赵钰醉后强吻被扇耳光，被父亲祠堂鞭打；她现身接住他，被认作亡母。
5. 赵钰染"痫疾"（实为奇蛊七泠丸），听笙坚持救治，他奇迹痊愈。
6. 马场上听笙被绑马尾拖行重伤，珠澜郡主冷眼纵容，赵钰目眦欲裂。
7. 洛闻为她解毒疗伤，治好容貌，露出绝美真容。
8. 赵钰提到前朝小皇子身上有长生锁，听笙发现自己胸前正挂着那枚锁。
9. 洛闻身份暴露（偷地形图被围、负伤逃走），听笙与赵钰私放他出府。
10. 赵侯爷"大义灭亲"、陆相借机进言，赵府一百零三口入死牢。
11. 反军破宫，宫人请出听笙更衣——洛闻当众跪请公主登基。
12. 真相揭底：范林、洛闻、冰娘是先帝临终托孤的三名暗卫；听笙登基后传位洛闻，与赵钰归隐；洛闻一生未娶。

**逐章写法公式**：

- **情绪流向**：起：屈辱（新婚夜被轰出、杂物室受寒）→ 承：救赎与暗恋（洛闻治病、学医、琴声相知）→ 转：苦尽（赵钰痊愈、容貌恢复、私放刺客）→ 合：身份反转后的一种"选择"（她选赵钰、洛闻独守）
- **节奏配比**：屈辱铺垫 24% / 相处与相知 34% / 危机与揭底 26% / 收束余韵 16%
- **本章结构公式**：给女主一个"丑"（胎记） + 给两个男人两种"疼"（洛闻的守护 / 赵钰的钝痛） + 用一场疫病让小侯爷被迫长大 + 用一枚长生锁把身世掀翻 + 用"她选择归隐、他选择一生不娶"完成双线收束
- **本章核心技巧**：**双男主的"能力差"与"情感差"互为反转**——洛闻（能治好她、能复国、能给她皇位却给不了名分）／赵钰（不能救她、总在伤她、却能给她一个正常人的家）。终局她选了后者，前者一生不娶。**选择权交给女主，而不是让强者通吃**，是本篇高出同类"白月光/朱砂痣"文的地方。
- **卡点与伏笔**：结尾卡点：余韵钩（赵钰哼《解忧曲》、"娘怎么追着爹打了起来"）与赵钰番外式的"其实那年在赵府……"留白。埋设/回收伏笔：①血色胎记（第（一）节埋 → 第（七）节揭为冰娘所施之毒 → 第（八）节治好）；②洛闻的手"修长、微凉、指尖薄茧"（第（三）节埋 → 第（八）节抱她 → 第（十二）节揭为从小抱她的暗卫）；③长生锁（第（八）节埋 → 第（十二）节回收为公主信物）；④七泠丸与雪丹（第（五）节埋 → 第（六）节解药）；⑤《解忧曲》（第（三）节埋 → 第（十二）节新帝独坐时回响 → 第（十三）节赵钰会哼）。

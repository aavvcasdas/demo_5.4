# 情绪模块：与君绝：维以不永伤（知乎原创）

> **权威范围**：读者需求 / 情绪引擎 / 套路框架运转 / 可复现模块。`拆文报告.md` 与 `剧情/故事线.md` 只引用本文件摘要。**禁止把原文具体桥段当模板照搬。**
> **口径**：基于 `_章节摘要汇总.md`（全量 64 篇逐章摘要）+ 7 个剧情单元文件；模块 ID 与各剧情单元的「情绪模块ID」字段一一对应（EM-001～EM-006）。

|---|---|---|---|---|

| **迟来追悔（只留追不回来）** | 第 1、2、9、11、14、16、28、33、58、61、64 章 | 抽掉"追回来"环节；追悔者活着承受，且悔悟晚于惩罚 | 悔悟不换回原谅，避免廉价闭环 | 需要前期给足"他其实也痛"的证据，否则只像虐而无因 |
| **与虎谋皮（卧底/潜伏揭底）** | 第 3、6、11、14、19、34、57、60 章 | 反派表象累积到全篇后 1/3 → 由第三方或回溯整段交代布局链条 → 仪式性翻盘 → 代价立即到达 | 恨→敬→痛的三级落差，一次交付三种情绪 | 布局链条必须完整可回溯（第 11 章给了三年前夜谈定局），否则揭底像硬拗 |
| **身份即谎言（掉马震惊）** | 第 2、5、6、13、17、20、26、40、46、57、62 章 | 埋 3 条以上"读者读过却未在意"的破绽 → 由第三方推理或公开场合亮明 → 两种走向：毁灭 / 和解 | 优越感（我知道你不知道）+ 重看冲动 | 破绽必须是"只有她能做到、另一个做不��"的行为差异（第 13 章甘蔗），不能靠旁白暗示 |
| **只守不圆（守望不重逢）** | 第 7、10、15、16、20、23、24、28、29、30、36、53、58、61 章 | 结局只写"他/她仍在等/已自由"，不写重逢 | 与书名「维以不永伤」同构：唯有不忘，方能止痛 | 需要前面给足甜的份额，否则守望只是空洞的虐 |
| **结构施压（不是他坏，是位置逼他）** | 第 2、9、11、14、26、41、44、57 章 | 给男主一个制度性理由（储位、母族、旧情、党争、改革），使其每次选择都"有道理" | 读者无法站队，恨意转化为更复杂的痛 | 结构理由必须具体（一碗绝育药、一份账簿、一次公投），抽象成"身不由己"就失效 |
| **半句话回扣** | 第 2、6、13、16、28、33 章 | 同一句台词/同一个场景拆成两半，前半在前段，后半在篇末补出 | 最低成本的催泪：让读者自己完成拼接 | 前半句必须"看起来完整"（第 2 章的酒评、第 6 章的作品自白），否则读者不会记住 |

## 可复现模块卡

### EM-001 以命相偿

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 一个人在已经输掉一切之后，仍然用自己的方式把账算完 |
| 情绪链 | 缺口（他会为我破例） → 加压（每次取舍都以她为代价） → 触发（最后一根稻草） → 爆发（她主动处置自己，且与前文某个恩义动作同构） → 余波（他终于知道，但来不及） |
| 戏剧单元 | 「被剥夺者在最大损失之后，用一个不可逆的自我动作完成结算，且该动作与她当初给予恩义的动作同源」 |

## 重组与复现指南

1. **先选读者需求，再选模块卡**，不要从原文桥段倒抄。本书 64 篇只用了 6 个模块反复变奏——模块少、变奏多，才是合集型作品的正确结构。
2. **保留情绪链和功能位**，替换人物、场景、动机、道具、事件素材。
3. **复现到新书大纲时，至少改变**：冲突对象、公开/私密场景、触发证据、余波方向中的三项。
4. **若人设与模块冲突，以人设驱动重构模块**；不要为了套套路扭曲角色。例如 EM-001 只适用于"愿为他人承担"型人设，换成自私型主角必须改走 EM-002。
5. **配比警告（来自本书的教训）**：本书 50% 的篇以死/消散收束，爽感供给极低。新书复现时应把 EM-001 控制在 30% 以内，用 EM-003（和解走向）与故事线 6/7 的"放下/救赎"作缓冲。

# 剧情单元：江湖市井与恩仇儿女

> 本书为 64 篇独立短篇合集，本单元为**跨篇题材母题聚合**：各篇以江湖、镖局、赌坊、书院、战场、市井为背景，讲述快意恩仇与儿女情长的纠葛。

| 项目 | 内容 |
|------|------|
| 标题 | 江湖市井与恩仇儿女 |
| 类型 | 战斗 / 爱情 / 成长 |
| 概要 | 本单元共 12 篇，背景落在江湖与市井，覆盖海盗（第12章）、风筝坊（第15章）、战场（第17、35章）、蟋蟀市井（第25章）、箭师（第27章）、杀手私塾（第31章）、比武招亲（第39章）、苍云堡（第50、51章）、赌坊玉行（第63章）、市井姻缘（第52、55章）。主角多是江湖儿女——女海盗、鸢姑、女将军、箭师传人、杀手、堡主、赌坊当家、琢玉郎。母题与宫廷单元同源（错付、隐忍、代价），但施压者从「权力结构」换成「师门/家族/江湖规矩/情敌/命格」：师招云为护神箭师门自毁、楚舒为赎罪带皎儿离开、段渠自焚换女儿、息宁月抽鞭断情、宋衡与顾华棠双死。终局多写「放下/相忘/守望」——息宁月回海、桑琴与厉随风远走、任随云与苏潋归淮城。母题：**江湖儿女的恩义，一笔一笔都要还**。 |
| 核心目标 | 让读者在「快意恩仇 + 儿女情长」的双线里，获得武戏的爽感与文戏的心疼 |
| 核心冲突 | 个人情爱 vs 师门/家族/江湖规矩/命格的不可违逆 |
| 关键信息功能 | 本单元负责让读者确认「江湖人讲究的恩义与代价」、误判（顶替/换脸/叛徒）、并在终局接受「相忘于江湖」或「守望」的收束 |
| 读者需求 | 热血（战斗）、优越感（以小搏大）、关系补偿（守望/成全）、被理解（迟到的真相） |
| 情绪模块ID | EM-001（以命相偿）、EM-002（与虎谋皮）、EM-005（只守不圆） |
| 套路框架位置 | 「以小搏大 + 身份反转」；「恩义相抵」作为江湖版的结构施压 |
| 桥段标签 | 以小搏大, 顶替身份, 换脸, 反杀, 恩义相抵, 只守不圆 |
| 章节范围 | 第12、15、17、25、27、31、39、50、51、52、55、63章（共12篇，约15.9万字） |

## 情节点索引（按篇）

### 第12章 海上女匪
- 息宁月扣下段渠做杂役、大半年生情
- 随回段家受老太君冷遇、只求「一心一意」
- 一年后段渠迎娶表妹琴贞
- 穿红袍持长鞭闯喜堂、喝完喜酒扔休书「是我休你」
- 抽他一鞭以「恩断义绝」了却毒誓、回海

### 第15章 鸢姑宋筝
- 八岁见姚清让、他哭穆妍悔婚
- 偷偷扎兔子风筝作生辰礼
- 及笄后拒尽提亲、十八岁接《鸢经》成终生不嫁的鸢姑
- 第十二年他赶来求亲、半夜带她私逃筝坊
- 目的地鬼衣谷、拿「妻子」换回穆妍母女
- 宋筝以心头血催动蛟龙风筝送岑不语上天、绞断线倒在血泊
- 三年后被禁术救活、姚清让苦等、终听见「那个宋筝已经死了」

### 第17章 念生为裘
- 白念生夜浴拿下讨豹奶的「池娘」（男扮女装战俘池良）
- 罚滋事士兵、让孩子搬进自己帐篷
- 北松雪夜突袭、左胸中箭坠崖、因心脏偏右捡回一命
- 山洞五天五夜、许诺「卸甲归田」
- 池良穿上她铠甲引开追兵
- 密令搜孩子、白念生当众亲池良「这辈子就娶她一个」
- 真相：太平是陈国遗脉、池良是国舅萧慕云
- 放走他们、交帅印跪请死罪、被鞭笞三百
- 孙太医揭「白将军是女的」、姬长婓以皇后之位留她
- 决意最后一战、池良示意神箭手一箭毙命、箭入左胸重获新生

### 第25章 蟋梦人生
- 宋衡九岁斗遍川城、十三岁赢回童养媳顾华棠
- 五岁随娘进宋家、九岁被宋淮撞瞎左眼
- 顾华棠三年后逃了、坠崖生还
- 江神医「以血换血」、宋衡做十年血库
- 娘被大夫人毒死、宋衡吐血「宋明章你骗得我好惨」
- 顾华棠换眼给他、火中别离
- 宋衡成吟游诗人、重逢「顾华棠，跟我回家」

### 第27章 神箭师门
- 舒尧臣寻到师招云、她正哄「傻子」傅颐之
- 九岁定婚约、从九岁打到十五岁
- 师门中伏覆灭、师将军被侯爷一剑穿心
- 舒尧臣递出羽箭请她出山、被「天黑了」打断
- 傅颐之全家被灭、真疯后装疯
- 舒尧臣许她「不为侯府只为百姓」、大婚却嫁傅颐之
- 三箭射杀三名巫蛊师、连夺十一城
- 傅颐之回光返照奔回小院、相濡以沫不如相忘于江湖

### 第31章 凤凰囚笼
- 两个退隐大佬合租院子三年
- 楚舒带回娃娃皎儿、红衣美人（孟婆）纠缠
- 翠婷中鬼散发疯、孟婆换钥匙要剖皎儿的背
- 楚舒一剑刺穿孟婆
- 真相：楚舒（舒青）血洗兰家、北渚之咒、皎儿是兰家遗孤
- 孟婆被剥皮、陆凡得澜西舍利解鬼符
- 素明影（影妖）找来、陆凡是梵妖梵千音
- 六辰雾灼瞎楚舒、梵妖归位、陆凡自爆「盼你一生自由」
- 陆凡其实没死、乌篷船「你还卖猪肉吗」

### 第39章 小贼与流萤
- 裴旷「顺手牵马」初遇流萤、结伴赴比武招亲
- 流萤是庄主捡回的二小姐、被割面皮做姐姐柳月的替身暗卫
- 大婚夜裴旷识破新娘非流萤
- 柳月以取红鸢花为条件放人
- 一年后流萤携花归来、遭「裴旷」变心背弃、武功被废
- 真相：眼前是游侠卢修换脸顶替、真裴旷逃出密室
- 卢修携柳月坠崖、二人终得团圆

### 第50章 陌上桑琴归
- 桑琴是苍云堡左护法、自幼被苏今庭所救
- 屡被他为负青梅谷婉月而牺牲（试药保谷胎、夺子）
- 右护法厉随风默默守护
- 真相：当年背她出绝望、烙月牙印记的是厉随风
- 桑琴以第四片五叶罗配雪蟾、挟谷婉月救出厉随风
- 二人远走、终得自由相守

### 第51章 桑琴番外
- 苏今庭七年寻踪、潜入鬼衣谷撞见酷似桑琴的女童
- 桑琴持剑现身、冷拒旧情
- 苏今庭当桑琴面嚼五叶罗、揭开当年布局真相
- 当年借谷婉月设局中局、桑琴滑胎真因是绝望服五叶罗
- 厉随风归家、一家三口温馨、苏遥望后悄然离去

### 第52章 妙音花嫁
- 宋凉宛十三岁一见纪元甫、痴心不改
- 历经百样人生求学、丰城瘟疫生死相随、龙头寨劫法场相救
- 终与坐轮椅的纪师爷定下婚约
- 当年破庙乞儿兄弟龙烈一脉就此别过

### 第55章 依依青梅晓
- 潘岳九岁丧母、与世妹杨容姬青梅竹马
- 桃花仙以三愿换走古镜
- 为拒郡主装病毁容、与杨容姬成婚
- 醉心功名渐行渐远、杨容姬放走桃魅、替他许下第三愿
- 杨容姬雪夜病逝、潘岳至死牢前才懂「长虹贯日」是珍惜眼前

### 第63章 常羡人间琢玉郎
- 苏潋幼年被卖任家厨房、被灶火烫伤半边脸
- 任随云救下、教她读书、抹药治伤
- 学医归来任家已塌、携画像寻三年
- 千虹赌坊见「厉大当家」（化名潜伏复仇的任随云）
- 任拒不认她、当众斩老千者两指绝其念
- 苏潋开医馆善后、自认未婚妻
- 雷夜钻他被窝、吻疤定情「我不要脸我就要你」
- 成亲日任以迷香送她出城、她金钗抵喉折返
- 鹤翁两杯酒考验、任抢饮两杯护她、鹤翁悔悟出家
- 归淮城、赌坊改医馆善堂、小舟回家手未松

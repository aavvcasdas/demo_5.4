# 剧情目录索引

> **口径声明**：本书为知乎短篇合集（64 篇独立短篇，正文 865,511 字，含 5 篇番外）。本目录的剧情聚合**覆盖全部 64 章（64/64）**，基于 `_章节摘要汇总.md`（全量逐章摘要）重跑。每篇短篇是独立故事，本目录按「题材母题」聚合为 7 个剧情单元，每篇有唯一主归属（逐章覆盖率 100%，情节点不跨单元重复计数）。

| 文件 | 权威范围 | 下游用法 |
|---|---|---|
| `节奏.md` | 关键信息推进、爽点循环、情绪触动点、爆发节奏 | 产出 `rhythm_reference` |
| `情绪模块.md` | 读者需求、情绪引擎、套路框架、可复现模块卡 | 产出 `selected_emotion_module` |
| `故事线.md` | 故事框架与故事线摘要 | 投影摘要，不覆盖权威文件 |
| `散落情节.md` | 未归入剧情单元的孤立情节点兜底 | 复核用，不参与下游节奏迁移 |
| `拆文报告.md`（上级目录） | 人类阅读报告 | 投影摘要，不覆盖权威文件 |

冲突时以 `节奏.md` / `情绪模块.md` 为准；两个文件用 EM/RH/TR ID 互相引用。

# 剧情单元：宫廷错付与自毁

> 本书为 64 篇独立短篇合集，本单元为**跨篇题材母题聚合**：各篇共享「女主以全部善意托举一位帝王/储君/权贵，男主因权力、大义或旧情反复以她为代价，她以不可逆的自我处置（自毁/自尽/自毒/失忆）完成结算」的叙事引擎。各篇人物、时间线不互通。

| 项目 | 内容 |
|------|------|
| 标题 | 宫廷错付与自毁 |
| 类型 | 主线（母题）/ 爱情 / 权谋 |
| 概要 | 本单元是全书篇幅最重、母题最核心的一组，共 13 篇，均发生在宫廷/朝堂背景下。女主的共同起点是「出身卑微或身份错位」——奶娘（第1、9章）、被顶名的皇后（第2、13章）、失宠帝姬（第14章）、替身声音（第22章）、妖后（第44章）、国巫（第45章）、哑后（第64章）——她们以命相托，男主（太子、帝王、太傅、将军、琴师）却在「储位/江山/复仇/旧情」与「她」之间反复二选一，且每次选择都以她为代价：绝育、断腿、杖胎、失贞、毒杀、囚禁、嫁衣坠楼。终局几乎全部以女主的不可逆自我处置收束——夏则灵禁术回溯撞树自尽、归长乐饮毒死、连华跃城、叶裳服同裘草、岁冬荣毒棋自尽、虞小柔病逝、君不怜饮毒、钟离雪假孕自残堕胎；少数以「失忆重生/最终团聚」作缓冲（明容失忆被册后、姜莞赴豫州团聚）。母题：**深情不是被辜负，而是被计价**。 |
| 核心目标 | 让读者看着一个「把全部筹码押在帝王身上」的女人，从「他能为我破例」走向「他终将负我」，并在终局获得一次情绪结算 |
| 核心冲突 | 女主的「无私给予」 vs 男主「被结构性压力逼出的取舍」（储位、母族、江山、旧情） |
| 关键信息功能 | 本单元负责让读者确认「帝王的深情永远晚于权力的账本」，并反复体会「她早就知道会输却还是押上全部」的悲剧必然性 |
| 读者需求 | 替代性渲泄（把「付出被辜负」的不甘一次性结算）、认知惊喜（篇末反转）、关系补偿（有人用一生记得她）、被理解（他最后终于承认只爱她一人） |
| 情绪模块ID | EM-001（以命相偿）、EM-003（身份即谎言）、EM-004（半句话回扣）、EM-005（只守不圆）、EM-006（结构施压） |
| 套路框架位置 | 「迟来追悔」的极端变体——抽掉「追回来」环节，只留「追不回来」；与「权臣架空—隐忍—仪式翻盘」结合，使翻盘后的赢家立即付出最大代价 |
| 桥段标签 | 迟来追悔, 献祭式极端行动, 以死明志, 掉马震惊, 帝权夺嫡, 太后干政, 身份冒用 |
| 章节范围 | 第1、2、9、11、13、14、22、33、44、45、48、49、64章（共13篇，约17.2万字） |

## 情节点索引（按篇）

### 第1章 羊娘则灵（情节点 P1-P21）
- P1-P2 羊灵入宫以奶救太子、受封贴身奶娘（立恩义）
- P4 太子宣布独占羊娘（独占欲）
- P9 皇后八字劝退「从来情深，奈何缘浅」
- P13 承诺不走与对食成婚
- P14 掀盖头与强暴「但我——不会娶你！」
- P16-P18 漠北雪洞、刑讯杖胎、叶书来自宫被刺死
- P19-P21 禁术回溯、撞树自尽、新一世「杨娘」

### 第2章 枕酒为后
- 破庙相依七年 → 丞相寻回扶为傀儡帝
- 绝育药、狩猎场断腿、柔妃南疆奇香致残
- 韦子七夜游「天空的味道」
- 立后大典斩归汝荣、屠归氏满门
- 阴阳子母壶自毒，临终见紫裳

### 第9章 秋漪云
- 西园软禁、左秋漪请命入园服侍
- 七岁坠崖断腿、赵清持搜救
- 十二岁与元相密谋光复、十五岁斩三皇子登基
- 红枣汤流产真相（况云亲手所交）
- 赵清持死别、左秋漪守孝一年
- 临终「唯一爱过的人是你……我也不后悔」

### 第11章 念念山河
- 冲喜选端木羽做童养夫、屏风同室
- 十年慢毒假病、皇家园林况宁掐脸
- 端木羽随军大同、玉面修罗清剿
- 册后大典翻盘、明相撞剑
- 端木羽被木剑刺腹、明容失忆重生被册后、赐名「羽」

### 第13章 慕南为后
- 萧家双生文曲/武曲命格、萧冉终身扮男
- 司慕南大选太子妃
- 边关、药泉脱胎换骨
- 互诉三个秘密「唯爱皇后一人」

### 第14章 帝女连华（情节点 P1-P30）
- P1 月梧花下「我喜欢你，你跟我走」
- P3-P4 金钗划脸、洛槐英以背相挡
- P9-P10 奶娘杖毙、「连华公主亦臣所爱」
- P13-P14 庆宴求娶采音、赐婚归漠寒
- P16-P18 大漠剃须、鱼鹰阵、「剃一辈子胡须」
- P20-P21 破庙失贞、采音「新婚贺礼」
- P24-P26 寿辰夜宫变、三颗人头
- P28-P29 身世反转（亲生女儿）、破庙真凶
- P30 红嫁衣跃城「你尚有故国可寻，我却早已无家可归」

### 第22章 吾皇
- 密室替声、元昭化名赵远入宫
- 六王爷灭门、元昭与叶裳幸存
- 元昭打断叶裳双腿、十一误入密室
- 叶裳下同裘草、禅位后口吐鲜血
- 元昭食言、十一认出「叶子姐姐」

### 第33章 岁岁东宫
- 夏灵私奔、冬荣代嫁入东宫
- 陈煜晕血、竹林初遇「叶枯」
- 挡剑、竹叶暗号、身份败露
- 陈烨被道士烧死、陈煜编双重人格骗局
- 毒棋自尽，临终「唯一爱过的只有我的叶枯」

### 第44章 西宫妖后
- 虞小柔暗卫出身被推上后位、担「妖后」恶名
- 裴其轩湖边醉舞撞破她仍是处子
- 裴灵君猎场遇刺、其轩登基
- 上元夜一夜夫妻、有孕
- 产子后逝于南郊庵堂，年仅二十九

### 第45章 巫神的驸马
- 君不怜九岁童躯、强纳莫小玉为巫驸
- 细作混宫、君不怜借杀细作布天罗地网
- 莫小玉误会、心魔误算害死莫元衣
- 君不怜最后一愿托魏帝、饮毒酒而逝

### 第48章 晏晏宫墙
- 晏初迷失大漠被捉为姜国驸马
- 姜莞眼疾自卑、晏初揭破「以丑为美」
- 逃亡被冲散、姜莞被囚去双足与孩儿
- 晏初率军杀回、母妃以死相逼
- 姜莞赴豫州寻晏初，一家终将团聚

### 第49章 琴师与公主
- 浮晴结巴→话唠、怕雷、九岁丧兄（韦皇后毒杀）
- 安狐琴音相伴、夜夜同眠
- 浮晴决意远嫁行刺皇后
- 安狐以断弦为暗器血刃韦后、成全她后死去
- 七年后金钗遗书揭示安狐是退隐杀手

### 第64章 哑后钟离雪
- 前世被方景儿毒哑、坠楼自尽
- 重生洞房花烛、打翻交杯酒休夫
- 谢晏如亦重生（献魂换世）
- 老王爷逼婚、谢以后背挡剑
- 谢谎称宁屿坠崖死、老王爷毒发身亡
- 钟离雪假孕自残、谢饮毒酒死「不值得」

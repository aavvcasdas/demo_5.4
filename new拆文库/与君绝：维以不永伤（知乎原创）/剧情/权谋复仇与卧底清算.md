# 剧情单元：权谋复仇与卧底清算

> 本书为 64 篇独立短篇合集，本单元为**跨篇题材母题聚合**：各篇共享「以复仇/权谋为主线，男主或女主卧底、隐忍、布局，在仪式性场合翻盘，而最大代价由爱人/自己支付」的叙事引擎。

| 项目 | 内容 |
|------|------|
| 标题 | 权谋复仇与卧底清算 |
| 类型 | 权谋 / 复仇 |
| 概要 | 本单元共 6 篇，以「复仇/权谋翻盘」为第一驱动力，感情线服务于复仇线的「代价」功能。三篇（第3、6、60章）的核心是「隐忍式复仇」：宋久恩借权宦顾襄平十倍报复负心人与慕容丞相、夷香换脸雕骨设局诱仇人自相残杀、穆衍之卧底白玉堂为老督公忍辱负重；两篇（第41、57章）的核心是「以权谋换改革、以自毁换大义」：魏于蓝借揭发岳父换麒麟择士通过、柴云初顶替假太子最后与梁帝同尽；一篇（第5章）是「复国复仇」：前朝公主听笙夺回故国后传位归隐。共性终局是**赢家立即付出最大代价**——顾襄平战死、夷香毒发、穆衍之引燃自爆、魏于蓝饮毒随妻、柴云初绑炸药同尽。母题：**复仇能清算仇人，不能清算代价**。 |
| 核心目标 | 让读者在「恨反派→敬卧底→痛代价」的三段落差中完成一次权谋与情感的复合结算 |
| 核心冲突 | 复仇者/卧底者的「布局」 vs 被牺牲的爱人/自己「不可逆的代价」 |
| 关键信息功能 | 本单元负责让读者误判（男主是负心人/反派）→ 揭底（他是卧底）→ 追悔（他已付出代价），并体会「赢」与「失去」同时到达的锋利因果 |
| 读者需求 | 安全感（恶人清算、秩序复原）、认知惊喜（卧底揭底）、替代性渲泄（代价的不可逆） |
| 情绪模块ID | EM-002（与虎谋皮）、EM-003（身份即谎言）、EM-006（结构施压） |
| 套路框架位置 | 「扮猪吃虎 + 一网打尽」的组合，代价转移给爱人；「复国复仇」与「卧底清算」的仪式性翻盘变体 |
| 桥段标签 | 扮猪吃虎, 反杀, 一网打尽, 潜伏多年, 复国复仇, 以死明志 |
| 章节范围 | 第3、5、6、41、57、60章（共6篇，约7.8万字） |

## 情节点索引（按篇）

### 第3章 平生一顾
- 宋久恩父斩当日求免死金牌，梁泊之改口「宋小姐」、慕容珠逼跪当马骑
- 顾襄平撑伞「如果你愿意，我给你一个家」
- 三点理由（报恩/添堵/以绝后患）娶她，承诺「十倍相抵」
- 赏花大会以小狐狸「恩恩」反击慕容珠、抄相府搜出通敌罪证
- 梁泊之造反获胜、带回顾襄平棺木；宋久恩换新衣与夫君并肩入棺

### 第5章 丑颜听笙
- 赵钰为气走郡主当众宣称娶妓馆打杂的听笙
- 洛闻治病、拜师学医、竹院琴声生情
- 赵钰染七泠丸奇蛊、听笙施针救治
- 马场拖行重伤、洛闻解除冰娘之毒、露真容
- 真相：听笙是前朝小公主、三暗卫拼死护出
- 义军夺国、听笙登基传位洛闻（字闻）、与赵钰归隐；洛闻一生未娶

### 第6章 雕骨生香
- 雕骨师荀容每夜一单、重塑贵人之骨获宠
- 皇后委托：让褚怀重新爱上她
- 寿宴抚《拂香》、被讨入府、立王妃
- 真相翻转：死者不是夷香而是荀容；夷香换脸雕骨成「荀容」
- 诱褚怀剥皇后皮、锁密室自相残杀
- 抱琴奏最后一曲、毒发死于宋临阁怀

### 第41章 迢迢旧时书
- 龚清漪雪中救马厩少年魏于蓝、伴他寒门逆袭成魏少傅
- 魏于蓝筹划「麒麟择士」打破门第
- 借揭发岳父龚太傅贪墨通敌、满门抄斩换改革通途
- 龚清漪游街百日、失子疯癫、公投之日投最后一票使麒麟择士通过
- 饮断肠草果子酒自尽；魏于蓝灵堂饮尽果子酒随她而去

### 第57章 长笙歌
- 丰国遗孤「况长笙」实为御厨孤儿柴云初顶替太子
- 被迦衣谷误救、与姚霁蛰伏八年暗生情愫
- 因贪恋厨子身份屡陷两难
- 为护姚霁甘作梁帝驸马诱捕她
- 绑炸药与梁帝同尽、留诀别信揭穿假太子身世

### 第60章 花神引
- 褚清云家破沦落红袖楼、撞见苏御闯入藏其入床底
- 得知苏御乃永安王、立誓加入白玉堂
- 穆衍之（父亲门生）舍身相护、万佛寺挨刀
- 揭出穆衍之是鬼面军师、当年背叛是老督公所托
- 酒楼谈判穆引燃火药与徐怀庸、哈刚同尽；第三锦囊吐露「藏在心底」的喜欢

# 剧情单元：妖灵仙侠与异族情缘

> 本书为 64 篇独立短篇合集，本单元为**跨篇题材母题聚合**：各篇共享「人×妖/异族相爱，因寿命、诅咒、身份、命格等设定级的不可能而不得圆满，终局以消散/化形/守望收束」的叙事引擎，并承载本书的神怪宇宙（金樽谷、百灵潭）。

| 项目 | 内容 |
|------|------|
| 标题 | 妖灵仙侠与异族情缘 |
| 类型 | 谜团 / 爱情 / 修炼 |
| 概要 | 本单元是全书世界观最重的一组，共 15 篇，涵盖人妖恋、妖与妖、仙与妖、半人半鬼、异族情缘等变体。核心设定是「人妖殊途」的不可跨越：妖因寿命/修为/诅咒无法与凡人相守，或凡人因命格/身份无法承受妖的深情。多数篇落在作者的神怪宇宙里——**金樽谷**（第7、8、18、20、21、29、30章，谷主雪明川、狐七郎反复出现）与**百灵潭**（第10、16、23、24、36、37章，潭主春妖反复出现）。终局几乎都以「消散/化形/守望」收束：沈羡娘与乔云焕共死入莲、傅瑶以两尾换焦木逢春、寒生化星辰、芊芊成白骨新娘、白扇渡灵力给阿苏后消散、谢烟打回砚台原形、白霜与赤叶结冰雕、素欢还阳、珠澜还双目薄翼、觅澜失爱人而独活。母题：**唯有不忘，方能止痛（维以不永伤）**，与书名同构。 |
| 核心目标 | 让读者在一段「注定不可能的深情」里，既获得奇观与甜，又在结局体会「命不能违」的怅然 |
| 核心冲突 | 妖/异族与凡人的「相爱」 vs 寿命、诅咒、命格、规则「设定级的不可能」 |
| 关键信息功能 | 本单元负责让读者确认「人妖殊途」的规则、误判（身份/转世/顶替）、并最终接受「只守不圆」的结局；同时承载金樽谷/百灵潭跨篇世界观 |
| 读者需求 | 认知惊喜（身份/转世反转）、关系补偿（守望不重逢）、被理解（她/他早知道却仍押上） |
| 情绪模块ID | EM-001（以命相偿）、EM-003（身份即谎言）、EM-005（只守不圆） |
| 套路框架位置 | 「转世轮回/宿命悲剧」正统用法，变体是结局只写守望不写重逢；「人妖殊途」作为不可抗辩的规则免除人物无能的指责 |
| 桥段标签 | 人妖殊途, 转世轮回, 双盲恋人, 只守不圆, 化形/消散, 以命换命 |
| 章节范围 | 第7、8、10、16、18、20、23、24、29、30、36、37、42、43、62章（共15篇，约20.9万字） |

## 情节点索引（按篇）

### 第7章 枕仙引梦
- 沈羡娘小黑屋濒死、枕仙应声给重生
- 回十五年前雪夜、发现乔云焕也重生
- 口误「陆太师」识破、真相揭开（被除名、陆太师棋子、推倒致不育）
- 雪明川踏雪揭破：是枕妖编织的梦境、蚕食寿命
- 沈羡娘选择留在梦里、两人共死；雪明川养残魂于玄潭幽莲

### 第8章 狐仙十二
- 傅瑶为追十六郎入宫做瑶贵人、三年不碰
- 阿桂（花灵）相伴、做香丸压狐味
- 李淑妃栽赃巫蛊、被贬冷宫
- 老嬷嬷临终吐露：桂花树下埋着六皇子慕长平
- 醒悟认错人、阿桂残魂在诛妖阵中湮灭
- 雪明川枯木逢春、傅瑶以两尾炼丹救树、一尾守洞

### 第10章 春妖
- 寒生棺材子无影、误闯百灵潭撞见春妖
- 蓝孔雀羽一羽一愿（去火疤/祈雨救童/自救失忆/救聂褚怀）
- 春妖坦白：额环锁魂、第九任潭主、前八任魂囚幽莲
- 寒生穿红彤嫁衣跃城、第五笔交易达成
- 前世觉醒：春妖与寒生本是同一人（忘川仙人与其影子）
- 司卯残魂转生聂褚怀、觉醒自碎元神、寒生化星辰
- 春妖拒回天、重戴额环守潭三百年

### 第16章 芊芊
- 芊芊供崔子钰读书、晕倒失子
- 崔子钰中状元、写休书入赘洛家
- 谢尘「为红颜绝色而来」应聘
- 洛小姐中毒、绝色坊封、崔子钰请旨查办
- 真相：毒是崔子钰下的、洛家父女死在他手里
- 芊芊城楼嫁崔子钰、成白骨新娘守百年
- 昆仑镜：谢尘赶去紫云山找解药、迟了一步

### 第18章 白诡梅娘
- 梅岳绾通体雪白、还当票给姜涉
- 昔年梅老爷买姜涉送她作伴、他恨她害自己
- 白狐因果：梅老爷射瞎白狐、白狐咬她
- 姜涉辞城寻亲、听说反军攻浔阳掉头杀回
- 梅岳绾救樊平生、断药白头
- 雪明川揭真相（黑狐血、樊平生是白狐之弟）
- 姜涉戴梅花簪消散、托谷主把姑娘交给樊平生

### 第20章 碧眼千岫（情节点 P1-P39）
- P1-P2 井底一睡三年、被读书声留住、「小青蛙」
- P3 以身挡天雷、顾衡深身亡
- P5-P8 赌玉、碧眼识玉、开出血玉凤凰
- P15-P16 撞破原形、「人与妖终归殊途」
- P20-P24 月下赠珠被窥、徐家设局、剜目
- P28-P31 雨中小公子、孪生弟弟顾云深真相
- P34-P35 大婚夜出逃、碧光消散
- P36-P39 雪明川收元神、十年百鞭刑、弥留求「叫我一声顾云深」

### 第23章 白扇
- 白扇以浮烟扇流云梳做美貌换寿命的买卖
- 阿苏天雷中魂飞魄散、锁进流云梳
- 小道士不凡追尸鬼缠上她
- 余娘亏本买卖、孟兰生被尸鬼王附身
- 伽兰走火入魔、葵儿偷玉梳、白骨洞决战
- 白扇渡灵力给阿苏、说出最深秘密（阿苏是夫君）
- 白扇消散如烟、男子携小女孩走遍江南塞北

### 第24章 妆师卿平
- 卿平半人半鬼、肉体封冰棺、灵魂飘百灵潭
- 倒回：接任妆师入息良宫、慕容斐被送为质
- 卿平喂粥上药、相依为命
- 施云（红鸢花妖）用妆盒画母亲容颜
- 三公主暴毙、是慕容斐借喜妆下毒
- 卿平灌醉施云偷妆盒、神巫金身显灵、被册后
- 郁郁成疾、长明灯五十四年、春妖收魂

### 第29章 女师谢烟
- 谢烟揭榜、夺魁择徒、选了傻子洛修羽
- 十年每夜吸墨毒、洛修羽恢复
- 婢女撞破「妖女吸阳气」、被关铁笼
- 雪明川揭真相：谢烟是松烟砚台化形、墨毒是她砸的
- 洛修羽寿命只剩三年、谢烟逆天改命
- 散尽数千年修为打回原形、花灯夜贴唇喂糖消散

### 第30章 白霜无衣
- 洛无衣林中遇狼、白霜驱狼、误认「芷儿」
- 名剑山庄铁笼、全是骗局（师父命他带白霜出谷）
- 白霜为闻人芷诊治、割腕喂血
- 洛无衣假绝情送她下山、黑衣人追至悬崖
- 赤叶相救、真相揭开（双生红豆）
- 洛无衣独挑山庄决裂、油尽灯枯而死
- 白霜化百年元丹救他、赤叶化红豆、白霜守谷

### 第36章 一嫁素欢
- 素欢成亲前溺亡成新鬼、飘入百灵潭被春妖收留
- 回渝州寻死因、方知妹妹顶替嫁安云岫
- 安云岫误吞雪蕊元丹变傻却能见鬼
- 雪鸣借鬼节助查真相：素欢心死自尽
- 雪鸣渡元丹给素欢还阳、自己化白兔消散
- 素欢复活、与安云岫花灯重逢

### 第37章 茧人歌
- 碧丞射落茧儿、立誓泼天富贵、只得拖油瓶
- 十年相依、捉妖扬名
- 入丹国娶相府千金、瞄准神巫珠澜接班人
- 珠澜设局榨取茧儿（仙彤衣/夜明珠/薄翼）、茧儿白头自剜双目
- 碧丞祭台掷刀护她、珠澜归还、有间泽重生

### 第42章 暗卫沈慈
- 沈慈随质子谢长夜八年、放走赤羽鱼人衡
- 谢长夜一箭射伤衡、与郡主订婚、推沈慈入死局
- 衡两度舍命救她、冰湖劫走「王妃」
- 沈慈耗心头血为失翼的衡绣双翅、翅成身逝
- 谢长夜望着霞光双飞身影跌跪

### 第43章 蛊女谣
- 紫冉因幼时破庙一碗粥、玉葫芦认定救她的是秦铮
- 秦铮有未婚妻萧玥、多年冷落
- 欢喜（玉葫芦真主段风澜）被萧家设计烧死
- 紫冉发狂被毒瞎毁容、一夜白头
- 秦铮吐露玉葫芦是亡友遗物、紫冉悟欢喜即当年小公子
- 紫仪率族攻入救出、欢喜报信归来、执子之手

### 第62章 龙女觅澜
- 龙女觅澜乘巨蟒闯沈灵溪大婚宴、展玉环求娶
- 沈称失忆只记得她名
- 真相：真沈灵溪病逝、双生弟沈灵甫做替身
- 沈灵甫旧毒发作、觅澜割腕喂血
- 地牢冬夜、伪装顺从、借狩猎塞谋逆证据
- 菩提山成亲四月、沈灵甫毒发以死换生、龙女独活

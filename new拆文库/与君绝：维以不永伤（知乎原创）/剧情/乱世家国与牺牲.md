# 剧情单元：乱世家国与牺牲

> 本书为 64 篇独立短篇合集，本单元为**跨篇题材母题聚合**：各篇以明末/民国乱世为背景，个人情爱与家国大义激烈冲突，主角以生命完成家国或情义的牺牲。

| 项目 | 内容 |
|------|------|
| 标题 | 乱世家国与牺牲 |
| 类型 | 危机 / 爱情 |
| 概要 | 本单元共 4 篇，是全书唯一一组以「家国」为第一背景的篇：第4章（明末秦淮，柳如是×杨念）、第19章（民国川城抗日，孟宣仪×许崇西×纪左扬）、第34章（民国男旦卧底，卓青×佐藤月）、第38章（民国昌军×竹灵，顾青雪×曦元）。共性母题是「个人在乱世里的大义选择」：杨念替柳如是赴画舫引爆火药、纪左扬独留炮楼与日军同归于尽、卓青潜伏淮园窃情报、曦元耗灵力降雪助战灰飞烟灭。终局几乎全以「牺牲/殉国/消散」收束，唯第19章留「红雪」余韵、第34章以佛偈环形收束。母题：**乱世里最干净的感情，往往要以最惨烈的方式兑现**。 |
| 核心目标 | 让读者在「家国危亡」的宏大背景下，感受个人牺牲的重量与悲壮 |
| 核心冲突 | 个人情爱/性命 vs 家国大义/民族存亡 |
| 关键信息功能 | 本单元负责让读者确认「牺牲的必然」、误判（卧底/汉奸）、并在终局体会「大义面前儿女情长只能让步」的悲壮 |
| 读者需求 | 悲壮/热血（家国情怀）、替代性渲泄（牺牲的不可逆）、认知惊喜（身份揭晓） |
| 情绪模块ID | EM-001（以命相偿）、EM-002（与虎谋皮） |
| 套路框架位置 | 「卧底/潜伏 + 以身殉国」；牺牲式终局是宫廷/江湖单元「献祭」的乱世变体 |
| 桥段标签 | 卧底潜伏, 以身殉国, 替身赴死, 家国大义, 只守不圆 |
| 章节范围 | 第4、19、34、38章（共4篇，约5.4万字） |

## 情节点索引（按篇）

### 第4章 江山又小雪
- 小太监小豆芽流落秦淮花船、被蔡老板「一记耳光换一粒金豆儿」羞辱
- 柳如是扇回蔡老板、收他为弟、赐名「杨念」
- 与陈子龙血书之约「驱逐外敌之日，便是我凤冠霞帔嫁你之时」
- 桃花宴秀才作淫诗、柳如是掀桌掌掴「他是我弟弟」
- 陈子龙投身军旅、城破殉城、留「下辈子我一定会娶她」
- 柳如是嫁钱谦益集结力量、扬州十日、钱谦益开城降清
- 钱谦益把柳如是「献」给清将哈朗陪夜
- 柳如是绑火药上画舫同归于尽、杨念打晕她换上女装替她赴约
- 腰间引爆火药、戏腔自陈「我是守城至最后一刻的大明将士……小兵杨念」

### 第19章 川城红雪
- 孟宣仪奉遗命背父亲骨灰坛投奔未婚夫许崇西
- 许崇西当众否认婚约、失手砸碎骨灰坛
- 纪左扬撑伞相认「宣仪小妹」
- 许大帅认亲、让她代行家法打许崇西
- 帮派夜袭、纪左扬驾车送走、山洞听见九年前绑架真相（许帅丢亲生儿子喂狼）
- 许大帅阵亡、弘田一郎围灵堂索拳谱、纪左扬「我也能凭记忆誊抄」投敌
- 监造炮楼被骂汉奸、雪夜醉闯她房被她以枪逼退
- 炮楼落成、把许家送上轮船、独留楼中引爆炸药与日军同归于尽
- 川城爆炸声中落下一场红雪

### 第34章 皎月照伶人
- 卓青（方家三少方清酌男扮女装）潜伏淮园接近佐藤平野之子佐藤月
- 凤仙楼初遇、老孔揭穿佐藤月身世被枪杀
- 入院教戏、与佐藤月朝夕生情
- 佐藤平野性侵亲子、虐杀义士、悬尸立威
- 卓青与罗刹堂、孤堂雁联手营救、密室身份败露后撤离川城
- 三年后佐藤月被软禁北平、生辰当日服毒自尽
- 遗书坦露早识破先生身份、夹在父与师之间的万劫痛苦
- 首尾呼应的环形叙事以佛偈收束

### 第38章 赖有西园明月
- 顾青雪十七岁留学归、夜探被封西园初遇守宅竹灵曦元
- 被唤幼时旧称「阿囡」、与青梅竹马白秀岚几番纠缠
- 与曦元于教舞、雨奔、绿衣曲梵婀铃中情愫渐深
- 马场曦元舍身护主、顾青雪拒婚、西园定情
- 家族阻挠雨中错过、十年后与白秀岚成亲、婚礼夜曦元重现共舞后两度消失
- 白秀岚看破红尘出家为静仪师太
- 日军入侵、顾青雪北上谈判、养女昔缘（曦元之女）现身
- 白庵大火静仪殉国、曦元（三百岁竹灵）耗灵力降雪助战、城楼一跃救主后灵元散尽灰飞烟灭
- 老人终老西园望月落泪、一世求而不得以环形留白收束

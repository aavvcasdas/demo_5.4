# 故事线：与君绝：维以不永伤（知乎原创）

> **口径声明**：本书为知乎短篇合集，64 篇独立短篇（正文 865,511 字，含 3 篇以「番外」命名的第 47/51/54 章）。本文件基于 `_章节摘要汇总.md`（全量 64 篇逐章摘要）落盘，覆盖 64/64 篇。
> **权威分工**：本文件是「故事框架 + 故事线摘要」的**投影**，节奏/触动点以 `节奏.md` 为准，读者需求/可复现模块以 `情绪模块.md` 为准；冲突时以后两者为准。

## 故事框架

| 项目 | 内容 |
|------|------|
| 框架类型 | **多线交织（合集型变体）**——不以人物/时间线交织，而以「母题 + 结构公式」交织：64 篇各自独立，共用一套叙事引擎与一套篇末反转模型 |
| 核心驱动 | 让一个「把全部筹码押在另一个人身上」的人，在一次不可逆的自我处置（自毁/消散/守望/放下）中完成情绪结算 |
| 主轴矛盾 | **深情 vs 结构**：个人情感 vs 权力结构（宫廷/朝堂）、规则级不可能（人妖殊途/命格/诅咒）、家国大义、现实落差 |
| 升级机制 | **无跨篇升级**（合集无等级/地位递进）；升级发生在**篇内**——伤害强度递进（轻视 → 剥夺 → 身体损毁 → 性命/记忆剥夺）与认知递进（误判 → 半知 → 全知） |
| 叙事节奏模式 | 反差钩开篇（200 字内一个可视觉化的伤口）→ 关系升温/立恩义 → 结构施压 → 篇末反转或献祭 → 余韵留白（单篇即一个小循环） |
| 判断依据 | ① `_progress.md` 章节边界表：64 篇首尾相接、无重无跳，每篇独立成章；② 全 64 篇摘要的「出场人物」表互不重叠（除金樽谷/百灵潭系列角色）；③ 7 个剧情单元文件的「各篇速查表」显示每篇有自己的主角、代价与终局；④ 跨篇仅世界观锚点角色复用（雪明川 7 篇、春妖 8 篇） |
| 预期剧情数 | 64 篇 → 按「30-100 章：5-15 个」的引导表，实际聚合为 **7 个剧情单元**（在预期范围内）；每个单元内以「篇」为最小叙事弧 |

## 框架识别自检

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 覆盖率 | **100%**（64/64 篇） | 7 个剧情单元覆盖章号 1-64 全覆盖，无重无漏（见 `README.md`「各单元覆盖章号清单」） |
| 粒度检查 | **通过** | 单元粒度 = 题材母题组（4-15 篇/组），非单一事件亦非宏观主题；最小叙事弧下放到「篇」而非「单元」，避免单元过粗 |
| 独立性检查 | **通过** | 每条单元有独立核心目标、独立冲突对象（帝王/规则/仇家/师门/家国/现实）、相对独立的角色群与自己的紧张-缓和节奏；篇与篇之间无因果依赖 |
| 数量检查 | **通过** | 实际 7 个 vs 预期 5-15 个，落在范围内 |
| 章节编排检查（合集特有） | **通过** | 按章序题材**刻意交错**：同一单元连排最长 3 篇（第 50-52 章 江湖市井，含第 51 章桑琴番外），其余连排 ≤2 篇；避免同调性情绪连续堆叠 |

## 故事线

> 说明：合集无跨篇人物线，故「故事线」按**母题/功能**定义，每条故事线由若干剧情单元的若干篇组成。**每篇唯一主归属**于一个剧情单元；同一篇可同时被多条故事线引用（母题交叉），但情节点只在剧情单元内计数一次，不重复计入覆盖率。

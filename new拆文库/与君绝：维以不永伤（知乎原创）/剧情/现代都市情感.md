# 剧情单元：现代都市情感

> 本书为 64 篇独立短篇合集，本单元为**跨篇题材母题聚合**：各篇以现代都市为背景，讲述当代人的情感纠葛与自我成长。

| 项目 | 内容 |
|------|------|
| 标题 | 现代都市情感 |
| 类型 | 爱情 / 成长 / 日常 |
| 概要 | 本单元共 6 篇，是全书唯一一组现代背景的篇：第53-54章（迟鸢×卓岩×易南星的校园纸鸢故事及番外）、第56章（岑素素×穆海的现代白蛇/佛学故事）、第58章（横漂少年凌栩×化妆师岑微的追悔）、第59章（单亲妈妈程菀×出狱画师许云澈的互相救赎）、第61章（陈晚禾×温嘉屿的蜜饯铺重逢）。母题与古言单元同源（错付、追悔、救赎、放下），但剥离了妖灵/权谋设定，转向「现实情感的错过与重逢」：迟鸢放下卓岩、凌栩「哭泣小丑再不会笑」、程菀与许云澈「互相给个家」、陈晚禾「糖葫芦已变苦」后放下。终局偏「放下/救赎」而非「自毁」，是全书中情绪最缓、最贴近现实的一组。母题：**错过就是错过，放下才是体面**。 |
| 核心目标 | 让读者在现代背景里体会「追悔/救赎/放下」的当代情感命题，作为古言虐恋的缓冲与对照 |
| 核心冲突 | 个人情感 vs 现实（前程、家暴、破产、误会、身份差距） |
| 关键信息功能 | 本单元负责让读者确认「追悔无用/放下是解脱」、误判（硬币笑脸/壁画真相）、并在终局获得「救赎/重新开始」的暖意 |
| 读者需求 | 情感补偿（救赎/团圆）、被理解（迟到的真相）、陪伴感（日常暖意） |
| 情绪模块ID | EM-004（半句话回扣）、EM-005（只守不圆） |
| 套路框架位置 | 「迟来追悔 + 放下」的现代变体；「互相救赎」替代古言的「守望」 |
| 桥段标签 | 迟来追悔, 互相救赎, 放下执念, 追妻火葬场, 破镜重圆 |
| 章节范围 | 第53、54、56、58、59、61章（共6篇，约6.9万字） |

## 情节点索引（按篇）

### 第53章 迟迟揽星河
- 迟鸢背负青鸾风筝远赴 Z 大寻卓岩履行娃娃亲
- 卓岩移情秦萌、迟鸢与易南星并肩传承纸鸢
- 迟鸢放下执念学会放手
- 卓岩追悔时「小媳妇」早已走远

### 第54章 迟鸢番外
- 大二暑假卓岩归心似箭回古镇欲挽回迟鸢
- 发现易南星已捷足先登拍宣传片、以绣名风筝与诗句步步紧逼
- 二人在筝坊门口上演「宰狼」闹剧
- 迟鸢淡然看戏、只待来年春鸢满天

### 第56章 面朝法海，春暖花开
- 岑素素连丢三条内裤、凶手竟是「佛系美少年」穆海
- 真相是她自己梦游晾晒
- 穆海为完成父志修复壁画而读佛学
- 岑素素从兴师问罪到知他黄毛校霸过往
- 共揭史馆长猥亵丑行、高原寺庙洞室读懂他的丧父之痛
- 露台十指相扣许下相伴

### 第58章 小丑说他曾来过
- 凌栩与化妆师岑微相恋、凭小丑硬币「好运」从群演跃升男一号
- 为攀女星沈琪辜负岑微
- 多年后岑微以《横梦》女主身份被顾岩求婚
- 凌栩才知当年硬币笑脸全是岑微掌心偷偷翻转的善意谎言
- 痛哭「哭泣小丑再不会笑」

### 第59章 你迟来的许多年
- 程菀带女儿果果逃离家暴前夫
- 遇白发邻居许云澈（冤案白坐十四年牢、出狱自学法律重做画师）
- 他屡次护她脱险、替她震退诬陷与施暴前夫
- 雪夜相拥「互相给个家」
- 领证那日双双迎来店长晋升与国家赔偿的双喜

### 第61章 捡到那个瘸腿男人
- 陈晚禾母亲病危、卖祖传冰糖葫芦秘方遇温嘉屿
- 他推一叠美元只取一串葫芦「酸过之后一定甜」
- 母亲逝后陈开晚禾蜜饯铺、记下温经过铺前十二次
- 云市经济危机温破产又车祸瘸腿、青梅女友被送出国
- 陈免单相认、寻老军医、雪沟里背他前行
- 温东山再起后与未婚妻订婚离去
- 生日宴陈现身塞葫芦与带锁日记便退请柬离去
- 温追到江南家乡退婚求复合、陈已放下
- 温被关门送客、立雨中立誓不走

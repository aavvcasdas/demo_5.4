# 剧情单元：宅斗与身份反转

> 本书为 64 篇独立短篇合集，本单元为**跨篇题材母题聚合**：各篇以府邸、书院、商家为背景，核心矛盾落在「家庭/身份」层面——入赘、代嫁、女扮男装、姐弟、太监之身、庶女庶子等身份错位，以及由此引发的宅斗与反转。

| 项目 | 内容 |
|------|------|
| 标题 | 宅斗与身份反转 |
| 类型 | 爱情 / 成长 / 权谋 |
| 概要 | 本单元共 8 篇，聚焦「身份」在家庭/朝堂内的错位与反转。两类核心设定：一是**性别身份反转**（第26章国舅女扮男装、第40章少卿女扮男装、第46-47章太监实为女），二是**家庭身份错位**（第21章姐弟畸形情愫、第28章入赘报复、第32章庶女代嫁相门、第35章将军府鬼将军契约）。共性母题是「身份本身即谎言/陷阱」，真相揭晓时要么毁掉当事人、要么促成和解：莫君庭强暴姐姐后以命换命、郑昭当众脱发亮女儿身、许禾晏亮女儿身替主解毒、凡子衿获罪后白秋宜木雕换命。终局偏「和解/重生」的多于「自毁」——郑昭被册后、许禾晏与况恒和解、白秋宜偷天换日、苏瑕以契约转移还夫自由。母题：**身份是别人给的枷锁，也是自己解的钥匙**。 |
| 核心目标 | 让读者在「身份错位→被轻视→反转/和解」的弧线里，获得掉马震惊与情感补偿 |
| 核心冲突 | 主角的真实身份/本心 vs 家庭、朝堂强加的身份与规则 |
| 关键信息功能 | 本单元负责让读者误判（主角的身份）、在揭晓时获得认知惊喜，并体会「身份既是枷锁也是钥匙」的双重性 |
| 读者需求 | 认知惊喜（性别/身份反转）、优越感（被打脸者）、情感补偿（和解/重生） |
| 情绪模块ID | EM-002（与虎谋皮）、EM-003（身份即谎言） |
| 套路框架位置 | 「掉马震惊」的正向变体（身份揭晓促成和解而非毁灭）+「顶替身份」 |
| 桥段标签 | 掉马震惊, 性别反转, 将错就错, 顶替身份, 女扮男装, 身份冒用 |
| 章节范围 | 第21、26、28、32、35、40、46、47章（共8篇，约11.2万字） |

## 情节点索引（按篇）

### 第21章 花奴挽柔（情节点 P1-P35）
- P1 花圃重逢沦为花奴的莫挽柔
- P2-P4 七年前好心送笔送金、「何不食肉糜」、缠上宋舒白
- P5-P6 婚约传闻、连夜逃婚
- P7-P8 莫家满门抄斩、姐弟相依
- P13-P16 土地庙之约、宋舒白犹豫未赴、莫君庭买酒潜入强暴姐姐
- P20 高台认子、自请除冠断亲
- P22 芸娘被虐杀（铁棍捅下体、割舌）
- P28-P31 柴房铁架、割舌灭口、莫挽柔目睹难产
- P33-P35 雪明川降临、莫君庭以命换命、「因为那是人间」

### 第26章 国舅多金
- 郑昭抠门名满京都、腰间五铜板
- 郑丘与太后逼她夺位、百般推脱
- 好男风、赴驿馆做「和亲相公」
- 捐军粮、金掌柜身份
- 寿宴献「天子剑」逼宫、她跳中央「我是女的」解发带亮裹胸布
- 郑将军扼喉、她用「云痕」匕首刺穿舅父
- 永和十二年叛乱平定、被册后

### 第28章 春日墙头段家郎
- 段陵被迫入赘、叶禾羞涩含笑
- 他捏下巴嘲讽「我宁愿你死在那里」
- 叶老爷逼段氏、拆散青梅、逼他入赘
- 第三年叶家倾塌、段陵暗渡陈仓改姓段
- 叶老爷苍老、叶禾跪求留下父亲
- 他带女人进门要她作陪、花园撞见头牌嘲她弃妇
- 叶老爷病逝、叶禾心死拟休书
- 他散尽家财带她求长生药、蓬莱海岛仙人墓
- 叶禾吻他送药、躺棺「七十七年后再回来找我」
- 七十七年后推开棺盖只有白骨、「君既为侬死，独生为谁施」

### 第32章 相门娇
- 白秋宜庶女代嫁相门、凡子衿新婚夜离府
- 修太师椅、钻狗洞撞见小姑子
- 凡子衿蹲下抹她鼻头灰「别致的相迎方式」
- 金叶檀木、沈小姐、一记耳光
- 三天采金叶檀木、一身血污「还给你」
- 沈小姐交东西后跳井、临终「他给的温柔就是毒药」
- 反诗往生锁、叶昭叛变被诛
- 白秋宜做木鸟报信、递和离书、喝药打胎
- 凡子衿获罪、白秋宜木雕换命、偷天换日
- 神木一族、孩子是她救家族时失去的
- 最后「凡子衿，你终于为我……有了心」

### 第35章 胭脂将
- 苏瑕被老太君救回将军府、与宁七郎相看两厌被指定婚配
- 新婚夜宁为誉冷漠分床、悄然赴战场
- 苏瑕以将星之姿骑豹领兵、戴龙纹面具替夫破阵
- 除夕夜宁为誉崩溃打翻同心羹、跪求老太君放过自己
- 真相：老太君为破战神契约将早死厄运转给苏瑕
- 苏瑕饮下融符咒的别离酒完成契约转移、解长命锁系其颈
- 持枪奔赴最后一战、留「下辈子你还记得我吗」

### 第40章 我家冯少卿
- 冯敏之女扮男装、为替亡故未婚夫苏景言续写信仰束胸入朝
- 与淮安王爷孟灵修积怨已久
- 假山强吻、红袖坊拿人、同府抄律、柴房危吻
- 孟遭弹劾雪地跪罚、冯背他踏雪辩冤
- 孟向允帝请赐婚、设抢婚赌约
- 冯闯入喜堂牵他手奔出「这一局，王爷赢了」

### 第46章 女宦
- 许禾晏七岁替兄入宫做「太监」小禾子
- 与同被软禁的九皇子况恒相依为命
- 太子逼况恒钻胯、许禾晏替主钻胯夺下怡妃判决文书
- 太子设媚药局、许禾晏亮女儿身替主解毒
- 太子被废、况恒入主东宫
- 韩柔求对食遭拒后「自尽」溺湖
- 新婚夜金钗问罪、况恒道出韩柔金蝉脱壳已送归家乡

### 第47章 女宦番外
- 帝后微服至江南小镇、赶在元宵前探望韩柔
- 捕快鹿三提鸡被赶出、自来熟喊「大妹子大妹夫」
- 两鸡受惊飞逃、况恒被推着与鹿三月下抓鸡
- 故人重逢又哭又笑、许禾晏瞧出韩柔与鹿三端倪
- 叹「最是人间温柔时、岁岁长相见」

## 开篇判断

**开篇钩子类型与效果**：三章皆为**反差钩**基底，叠加悬念/冲突钩。效果判定为**强**，可复现的技术是"一句话身份陈述 + 一句反常识补语 + 200 字内一个可视觉化的现场"。

**主角立人设手法**：行为（冒死喂奶 / 独居酿酒 / 下跪磕头）+ 台词（"这是奴婢的奶" / "冷宫里有酒吗" / "那是我丈夫，给我一个家的男人——比你像男人"）+ 他人评价（"羊娘"的调笑 / 柔妃"好姐姐"的酸意 / 慕容珠"死皮赖脸"的辱骂）三线并行，**全部通过冲突现场交付**，不写内心独白式的自我说明。

**世界观铺设方式**：三章都不在开篇做设定说明，而是**用一场具体事件把规则演出来**——后宫"入口之物必经试吃"由"屏风内外备奶唱歌"演；"对食"由一场抢婚演；"免死金牌"由一次反悔演。最大的设定（羊灵/煞气、紫尾狐、假太监）一律延迟到篇末 1,200-2,000 字内集中揭示。

## 早期可借鉴点

1. **设定即悲剧成因**（第1章）：让世界观设定（煞气）与情感悲剧（"他恨她其实是被她害"）**同源**，而不是设定管设定、感情管感情——比常见的误会型虐恋高一整档。
2. **同一句台词跨小节拆成两半**（第2章）：先给"我从没喝过这么让人回味悠长的酒"，隔两千余字补上"也从没喝过这么适合与心爱之人共饮的酒"——最低成本、最高效的回扣式催泪。
3. **改口即背叛**（第3章）：一个称呼的变化（"久恩"→"宋小姐"）承担全部的关系破裂信息，零解释、零心理描写。
4. **温情台词说恐怖内容**（第1章）：高潮施暴后紧跟"好了，羊娘没事了，我们回家，我们以后好好过日子"——比继续施暴更能制造二次重击。
5. **道具三件套各留一记终局**：轮椅/酒/紫尾狐、小狐狸/暗器盒/棺木新衣——**终局用到的每一样东西，前半篇都出现过一次**，规避机械降神。
6. **名字谐音收尾**（第1章）：把整段孽缘压缩成一个字的谐音（羊娘→杨娘），既闭环又不落入"重生重逢"的俗套。

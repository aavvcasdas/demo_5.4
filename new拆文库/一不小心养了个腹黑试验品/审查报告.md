# 审查报告：一不小心养了个腹黑试验品

> 审查模式：solo（降级，不 spawn 子代理，subagent recursion guard 触发后维持 solo）
> 适用标尺：zhihu（知乎盐言：第一人称 / 情绪拉扯 / 反转 / 结尾余韵 / 格式 / 开头钩子 / 字数 8000-13000）
> 说明：本审查只读不改源文，所有改动建议指向「发布前清洗」而非「文本修订」。

## 一、基础检查

### 1. 格式检查
- 章节以阿拉伯数字（1-50）编号，无章节标题；番外以「叶熙番外：」标注并另起编号（1-5），结构清晰可读。
- 正文与番外之间以「（正文完）」「（全文完）」标记，边界明确。
- 源文件首尾存在盗版推广页脚（见 S3），不属于正文格式问题，属发布前需剥离的外部污染。
- 判定：正文格式合格；外部页脚与文件内重复副本为阻断性发布障碍（见 S3/S4）。

### 2. 设定一致性检查
- 时间线：au病毒背景（2070年）→ 孵化叶熙 → 三年养育 → 逃脱 → 别墅两月 → 抑制剂成功 → 回实验室 → 结婚 → 番外婚后。主线时间自洽。
- 能力设定：叶熙"七个月学语言/一年精通黑客/体能超常/化腿"在正文以伏笔逐步揭示，番外自白收束，前后无矛盾。
- 细节校验：节33叶熙称"两年前就想离开"与"三年养育"近似（孵化后约两年即具备逃脱能力），属合理时间模糊，非硬伤。
- 设定冲突：未发现正文与番外相互打架的设定漏洞；番外是对正文的"认知重述"而非"设定新增"，一致性良好。
- 判定：设定一致性通过。

### 3. AI 味与禁用词检查
- 源文为人工创作（盗版转载带推广页脚），行文口语化、有鲜活对话节奏与具身感官描写（蛇尾冰凉触感、浴池水汽、唇边血迹等），非 AI 生成腔。
- 扫描一级禁用词（仿佛/犹如/一丝/一抹/不禁/瞳孔收缩/心中一动/不容置疑/自然而然等）及最毒句式（不是A而是B/，带着/眼中闪过/命运齿轮）：0 命中。
- 判定：AI 味 0 命中，禁用词为自然语用，不判缺陷。审查以 S3/S4 提示剥离页脚与外部污染，而非判文本缺陷。

## 二、Findings（统一 Schema）

### S1 格式 / 章节标识
- **category**: format
- **location**: 全文（节1-50 + 番外1-5）
- **evidence**: 章节仅以数字编号，无标题；番外以「叶熙番外：」单列。
- **issue**: 无标题不利于盐言类平台的章节预览与读者跳读；但作为单篇短篇发布可接受。
- **fix**: 若拆条发布，建议补章节小标题；单篇发布维持现状即可。

### S2 设定一致性 / 时间模糊
- **category**: consistency
- **location**: 节33（"两年前就想彻底离开"）vs 整体三年养育线
- **evidence**: 「如果不是因为姐姐在这，两年前我就想彻底离开这里了。」
- **issue**: "两年前"与"三年养育"存在约一年模糊，可能让读者略微出戏，但属合理时间近似，非硬伤。
- **fix**: 可不改；若追求严谨，可将"两年前"改为"早就能"，避免具体数字引发的核对。

### S3 外部污染 / 盗版页脚（阻断性）
- **category**: format / hygiene
- **location**: 行1-10（开头推广）、行935-944（第一次结尾后）、行945起至文末（第二次重复副本+页脚）
- **evidence**: 「添加微信号：nf2249（进资源群）……」「淘宝双11每日领现金红包活动 打开淘宝app首页搜索：红包到手555」「本文档只用作读者试读欣赏！请二十四小时内删除」
- **issue**: 源文件夹带盗版推广页脚，且故事正文在文件内**完整重复两遍**（行13-933 为第一份含番外，行951-1886 为第二份重复+页脚）。页脚与重复副本均非正文，发布前必须剥离。
- **fix**: 发布前删除所有「━━━」分隔线包裹的推广块；仅保留单一正文副本（行13至行933「全文完 备案号」为止）。重复副本不计入有效字数。

### S4 平台适配 / 盐言标尺偏差（重点）
- **category**: platform-fit
- **location**: 全文体量 + 题材调性
- **evidence**: 正文单一副本约 2.6 万字（文件含重复计 5.2 万字）；zhihu 盐言标尺建议 8000-13000 字。
- **issue**:
  1. **字数严重超标**：实际正文约为盐言上限的 2 倍，番外占比高，单篇发布易超出平台篇幅预期。
  2. **题材调性偏差**：盐言主流为情绪向（救赎/治愈/拉扯），本文为暗黑强制爱+「多巴胺激素制造伪爱」的操控叙事，番外揭示的操控感偏惊悚，与盐言温和情绪向存在偏离。
  3. **文件重复**：同文件内两遍正文，需先去重再统计有效字数。
- **fix**:
  - 发布前先按 S3 去重，得到单一 2.6 万字正本。
  - 若投盐言：建议拆分为「正文（强制爱主线，约2万）+ 番外（揭秘，约6千）」两篇，或压缩中段饲养日常至 1 万字内；番外作为独立「反转特辑」投放。
  - 若保留暗黑调性：更适配番茄/七猫的「疯批男主」赛道，而非盐言温和向；建议在发布时标注题材预警（操控/强制爱）。

## 三、综合结论

**CONCERNS（需发布前处理）**：
1. 【阻断】源文件含盗版推广页脚且正文重复两遍（S3）——必须清洗去重后方可使用。
2. 【高】字数超盐言标尺约 2 倍、题材调性偏离盐言温和向（S4）——建议拆分或换赛道投放。
3. 【低】"两年前"时间模糊（S2）——可选微调。

**PASS（无需改动）**：
- 设定一致性自洽（S2 主项通过）。
- AI 味 0 命中、禁用词自然语用，文本本身质量合格。
- 钩子/反转/人物/结尾四项达到短篇优质水准，认知反转设计是核心亮点。

**一句话**：文本质量与反转设计优秀，但受「盗版页脚+文件重复+体量超标+题材偏离盐言向」四类发布障碍制约，清洗去重并按平台标尺拆分后方可上线。

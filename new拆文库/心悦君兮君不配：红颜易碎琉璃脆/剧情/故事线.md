## 篇内故事线（43 篇）

### 第1章 玉阶寒
- **驱动线**：苏璃要嫁给沈玉 → 必须赶在阮容容回来前睡了他
- **冲突线**：雇顾北寒勾引阮容容 → 二人真相爱 → 苏璃替他们收场
- **情感线**：苏璃自幼喜欢沈玉 → 沈玉只爱阮容容 → 沈玉为密信叫"阿璃" → 小产后永久冻结
- **结局线**：鸩杀顾北寒（实为放走）、放走阮容容，被判鸩酒失去孩子；从此做皇后不碰沈玉。"那扇门关上，就不会再打开了。"
- **主题**：爱的错位、成全、终身拒付

### 第2章 探芳音
- **驱动线**：百音要在被当作幌子的婚姻里活下去
- **冲突线**：秦逸为娶百小羽而娶她 → 五年布局被揭破 → 逼她和亲
- **情感线**：百音爱的是"救命恩人"（假的）→ 元瓒是真恩人 → 波族十年后动心
- **结局线**：秦逸破城被擒，元瓒"以后只想做个与你风花雪月的王"。
- **主题**：恩情顶替、体面、爱错人

### 第3章 声声慢
- **驱动线**：沈岁穗要护住慕容烨不被构陷
- **冲突线**：大皇子构陷三皇子 → 她替皇帝挡刀被封美人 → 为阻止慕容烨弑父而毒杀皇帝
- **情感线**：她在冷月宫自污"我为太后之位" → 慕容烨带她出逃 → 静太妃与将士以命相逼
- **结局线**：成衣店一拜天地，她给他下药、自己饮鸩；回溯浣衣坊初见。
- **主题**：自我牺牲、不可靠叙述、制度性悲剧

### 第4章 琉璃春
- **驱动线**：笙笙要嫁一个"只爱她一人"的人
- **冲突线**：追史轲琅失败 → 追杜渡失败 → 皇兄下药把她和临玔关在一处
- **情感线**：临玔自幼暗恋她 → 她误以为童年"我讨厌你"断了他的心 → 表白
- **结局线**：婚礼与洞房，全甜收尾。
- **主题**：双向暗恋误会、先婚后爱

### 第5章 九歌难
- **驱动线**：沈筝要为大梁送出一份布兵与城防图
- **冲突线**：完颜煌从羞辱到动情 → 沈筝两次怀孕两次算计 → 自焚死
- **情感线**：桑吉（叙述者）从厌她到敬她；完颜煌从未放下戒心，也从未真正舍得
- **结局线**：沈筝自焚烧成骨架，摇篮藏图送出；完颜煌战死，脖子上藏着她的骨灰。
- **主题**：谍战牺牲、视角欺骗、信物

### 第6章 纳青劫
- **驱动线**：纳青要统一草原七部，成为唯一能站在弩齐身边的人
- **冲突线**：妹妹纳兰抢她所爱 → 择婿混战 → 定北王以山海关为条件索人
- **情感线**：弩齐爱纳兰，却在关键时刻选择纳青
- **结局线**：大胤立国、纳青为后；八年后狱中揭破——喇嘛预言说的是她。
- **主题**：预言顶替、强女主、迟来的真相

### 第7章 锁深深
- **驱动线**：钟姒要在失忆与恢复记忆之间活下来
- **冲突线**：她曾是囚禁谢禹一年的加害者 → 被谢禹囚于旧地 → 前朝旧部的利用
- **情感线**：装失忆的痴心徒弟 → 七夕灯会反被算计 → 怀孕被一句"你也配"击穿
- **结局线**：借新帝之手离京生子，三年后被谢禹找到；番外补完爱意。
- **主题**：加害者与受害者反转、记忆

### 第8章 隔山海
- **驱动线**：季羡渔（季临渊）要在废后与重掌兵权之间做出选择
- **冲突线**：季家军败于定幽城 → 借"病亡"金蝉脱壳 → 收复失地与风波镇死战
- **情感线**：李元晟以"阿郕"之名把她拖回局中；她只承认君与臣
- **结局线**：替公主上花轿平乱；十里亭送别"阿郕，自此一别，再不相见"。
- **主题**：双身份、君臣与旧情、女将军

### 第9-10章 共沉沦
- **驱动线**：宋意央要在废掉的婚约里活下来
- **冲突线**：突厥和亲 → 柳茹设计 → 以假身份赴云州查案 → 太守送姬送女
- **情感线**：从"怕他"到"喜欢他"；玉扳指唤醒十岁记忆
- **结局线**：陆霁出征北越重伤，她难产得子等了一年；御花园重逢。
- **主题**：权臣虐恋、物件唤醒记忆、先婚后爱

### 第11章 关山月
- **驱动线**：宋钧要报宋家灭门之仇
- **冲突线**：坠马致残 → 被送去和亲 → 郡主设局 → 张厚德遗信揭底 → 穆肃御驾亲征
- **情感线**：穆肃的承诺落空；李知退的爱只在"退"里
- **结局线**：潜入函谷关射偏那一箭，服月莹自尽未死；李知退退兵并与她和离，"你可不可以不恨我了"。
- **主题**：复仇、瘸腿、知退

### 第12-13章 何殇离
- **驱动线**：何殇离要成为这万里江山的主人
- **冲突线**：被萧承嗣用毒控制、被父亲当刀送进宫 → 刺死萧珩 → 萧承嗣夺位被翻盘 → 她称帝 → 萧珩诈死归来
- **情感线**：萧珩早知她是刀，仍求她的心；"昭离"这个名字藏着他幼年的旧人
- **结局线**：她两次刺他，两次都被他反过来救回；冷宫坦白与"朕恨不能暖死你"。
- **主题**：刀、弑君、女帝、名字的情感指向

### 第14章 丁香结
- **驱动线**：云芸（现代意识）要在两年的婚约里保持清醒
- **冲突线**：六妾是眼线 → 玉真是副将遗孀 → 乌婉珠设局下毒纵火 → 司空灼率兵造反
- **情感线**：从拒绝承认到发现"倒追三年的人本来就是她"
- **结局线**：司空灼穿火救人全身烧伤，她高烧后记忆复原；乌婉珠与废帝烧死。
- **主题**：接盘、记忆、口嫌体正直

### 第15章 殿前欢
- **驱动线**：沐青玥要一个"不会被赶出去的家"
- **冲突线**：嫁给权臣太监祸璃 → 太后与丞相争斗 → 丞相除夕清君侧
- **情感线**：她全程在演（赐婚是她设计的、流言是她散的）；祸璃早知却仍爱她
- **结局线**：一簪杀丞相，被祸璃跪拜尊为女皇；祸璃出征射杀禤云飞，五十岁同游、五十三岁长眠江南。
- **主题**：扮猪吃虎、女皇、布局者

### 第16-17章 顾无言
- **驱动线**：褚瑶要活成自己
- **冲突线**：婚礼因皇帝驾崩作废 → 同夜娶烟芜 → 被冤害烟芜 → 贬入皇家林苑

- **结局线**：宁妃替她扫清后宫并毒发身亡；烟芜咬舌自尽；她求两份休书，约定"下辈子你追我"。
- **主题**：避子汤、主动退场、自由

### 第18章 朱砂痣
- **驱动线**：顾幺幺要报顾家灭门之仇，也要还王淮安的债
- **冲突线**：毒杀谢玄（未遂）→ 逃往岐山 → 北疆长生林 → 岐山骗局 → 满岁宴
- **情感线**：谢玄明知是刀仍求爱；王淮安以灵魂永世禁锢为她筹谋；星煜顶着王淮安的脸
- **结局线**：她挡下那一剑，以命与储君为质换王淮安重入轮回。
- **主题**：灵魂交换、复仇、轮回

### 第19-20章 误芳华

- **结局线**：魏婉娴疯癫；她在婚宴见到"王景"擦肩而过。

### 第21章 笼中雀

## 故事线关系

- **并行**：43 篇互不共享人物与时线，全部为并行独立线。
- **交织**：无跨篇人物交织；仅「跨篇母题」在主题层同构（见上「五种变体」）。
- **依赖**：无跨篇情节依赖；每篇自闭环。

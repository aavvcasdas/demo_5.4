# 情绪模块：心悦君兮君不配：红颜易碎琉璃脆

> 权威范围：读者需求 / 情绪引擎 / 套路框架运转 / 可复现模块。禁止把原文具体桥段当模板照搬。

## 读者需求 / 情绪引擎

| 读者需求 | 本书满足方式 | 证据章节/情节点 | 持续追读机制 | 可迁移边界 |
|---|---|---|---|---|
| 道德豁免的代入 | 女主先做"不体面"的事，再用自贬独白给理由 | 第1章（主动睡/雇凶）、第3章（"我也觉得自己恶心"）、第15章（设计赐婚） | 读者替她辩护 | 可保留"先行为后理由"；必须替换具体行为与人物 |
| 不被误解的渴望 | 女主从不辩解，真相由第三方/物件揭破 | 第1章、第11章（遗信）、第16-17章（避子汤） | 等待"被看见" | 可保留"拒辩→被揭"；替换揭破者 |
| 独占真相的快感 | 读者与女主共享真相，男主/公众不知 | 第1章（阮容容孩子）、第5章（藏图）、第15章（布局） | 信息差碾压 | 可保留信息差；替换真相内容 |
| 尊严的最终结算 | 用"拒付/退场/和离"完成尊严结算 | 第1章（终身拒付）、第16-17章（休书）、第23章（和离） | 结算句收尾 | 可保留"拒付"；替换结算形式 |
| 自由的具体形态 | 女主最终主动退场或远走 | 第3章（饮鸩）、第30章（离宫）、第47章（半隐居） | 意难平的余味 | 可保留"主动退场"；替换退场方式 |

**情绪引擎（全书通用）**：

```
女主算清代价 → 她仍然下手 → 男主误判她的动机 → 她拒绝辩解
→ 代价降临 → 真相由第三方或物件揭破 → 男主补救，但她已经不肯要了
```

三个关键零件：① 她早就知道代价（消除"她好蠢"感）；② 她不辩解（全书女主几乎从不自辩）；③ 已经不要了（补偿来临时她已关机——**本书真正的虐点不是没得到，是得到时已经不想了**）。

| 框架/套路 | 在本书中的位置 | 运行方式 | 为什么有效 | 失效风险 |
|---|---|---|---|---|

## 可复现模块卡

### EM-001 道德不体面的女主开场法

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 一个"会被骂"却让人想替她辩护的女主 |
| 情绪链 | 冲击（她怎么这样）→ 理解（原来如此）→ 站队（她没错） |
| 戏剧单元 | 女主在开篇主动做一件不体面/越界的事，3 行内给出不得不的理由 |
| 关键触发物 | 越界行为、代价、自贬独白 |
| 复现步骤 | 1. 第一句让女主处于"会被骂"位置 2. 3 行内给出理由 3. 用自贬独白替代辩解 |
| 可替换项 | 越界行为类型、代价、人物身份 |
| 不可照搬 | "我和沈玉睡的那天"、雇凶勾引白月光等具体桥段 |
| 关联节奏 | RH-001 / TR-001 |

### EM-002 身体反应替代心理描写

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 不用一个情绪词就让人心疼 |
| 情绪链 | 动作 → 读者自行翻译情绪 → 共鸣 |
| 戏剧单元 | 全程不写"我难过/生气"，只写攥腰带、听笛、闻香、肚子拧成结 |
| 关键触发物 | 一个可重复的身体动作或感官细节 |
| 复现步骤 | 1. 找一处情绪高点 2. 删掉所有情绪词 3. 换成一个身体动作 |
| 可替换项 | 动作类型、感官通道 |
| 不可照搬 | 原文的具体动作链（攥腰带+团成一团） |
| 关联节奏 | RH-001 / TR-002 |

## 重组与复现指南

1. 先选读者需求，再选模块卡，不要从原文桥段倒抄。
2. 保留情绪链和功能位，替换人物、场景、动机、道具、事件素材。
3. 复现到新书大纲时，至少改变：冲突对象、公开/私密场景、触发证据、余波方向中的三项。
4. 若人设与模块冲突，以人设驱动重构模块；不要为了套套路扭曲角色。
5. **本书特有提醒**：43 篇同构度极高，跨篇组合 EM-001+EM-004+EM-010 即得一篇"标准虐恋短篇"骨架；新书若逐篇照搬会撞梗，应每篇至少换掉 2 个模块的组合方式与 3 项具体素材。

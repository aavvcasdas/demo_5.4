## 本书结构特别说明（必读）

本书是**知乎专栏合集**，43 篇互不共享人物与时线。因此：

- **「故事线」按篇成立**，跨篇只做**母题级**聚合，不强行连成单一主线。
- **「跨章伏笔地图」按篇成立**（篇内伏笔），不做跨篇伏笔。
- **「节奏 / 情绪节奏总览」可跨篇统计**（因为 43 篇的情绪公式高度同构，这正是本书最大的可复用价值）。
- **「剧情单元」按篇划分**：每篇是一个独立的完整故事，天然满足剧情独立性四标准（独立目标、独立冲突、相对独立角色群、独立节奏）。

> **篇数口径说明**：`_progress.md` 记为「44 篇」，经全量章节边界复核，实际独立篇目为 **43 篇**（7 篇二分 + 2 篇三分 + 34 篇单章；「44 篇」系原进度文件将二分/三分口径混记所致）。本目录以 **43 篇**为准，覆盖第 1-54 章全部。

## 索引使用建议（给下游写作）

1. 先读 `剧情/情绪模块.md` 的「可复现模块卡」——这是本书最值钱的部分。
2. 再读 `剧情/节奏.md` 的「全书情绪节奏总览」——确定自己作品的爽点/虐点排布。
3. 选单元：古言婚恋 → U-01/U-04/U-37；复仇流 → U-05/U-16/U-31/U-36；女强 → U-08/U-11/U-13；穿书 → U-22/U-25/U-38。
4. 写作技法参考 `文风.md` 的「分层模仿建议」。
5. **不要照搬具体桥段**：本书 43 篇同构度极高，直接搬会撞梗；应搬运"结构与情绪逻辑"，替换人物、场景与事件素材。

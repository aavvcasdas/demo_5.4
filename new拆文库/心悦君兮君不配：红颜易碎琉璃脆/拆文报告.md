## 读者需求 / 情绪引擎（摘要）

> 完整版见 `剧情/情绪模块.md`。

- **表层需求**：题眼承诺（爱而不得）、知乎体 300 字冲击、单篇自闭环。
- **深层需求**：道德豁免的代入、不被误解的渴望、独占真相的快感、尊严的最终结算、自由的具体形态。
- **情绪引擎**：
  ```
  女主算清代价 → 她仍然下手 → 男主误判她的动机 → 她拒绝辩解
  → 代价降临 → 真相由第三方或物件揭破 → 男主补救，但她已经不肯要了
  ```
- **三个关键零件**：① 她早就知道代价（消除"她好蠢"感）；② 她不辩解（全书女主几乎从不自辩）；③ 已经不要了（补偿来临时她已关机——**本书真正的虐点不是没得到，是得到时已经不想了**）。

## 写法技巧清单

> 覆盖模板要求的 7 项：一笔两用 / 延迟揭示 / 视角欺骗 / 对比锚点 / 行为循环 / 身体反应替代心理描写 / 跨章回扣。

| 技巧 | 本书用法 | 原文锚点 |
|---|---|---|
| **一笔两用** | 同一物件/场景在同篇内承担两种相反功能 | 摇篮（父爱→藏城防图，第5章）｜镣铐（她给他戴→他给她戴，第7章）｜一簪（头饰→凶器，第15章）｜红衣（屈辱→正名，第39章） |
| **延迟揭示** | 核心真相压到 60%-95% 处才揭破 | 预言指向（第6章）｜王淮安顶罪（第18章）｜吉服（第21章）｜痴傻伪装（第35章）｜桂花糕（第46章） |
| **视角欺骗** | 用叙述者偏见或误判遮蔽真相 | 桑吉（明说"我讨厌她"，第5章）｜沐青玥（"我只想苟活"，第15章）｜何莲（"小白莲"，第37章） |
| **对比锚点** | 用一个人/一件物作为主角对照 | 阮容容（雅 vs 苏璃，第1章）｜王淮安与星煜（同貌不同人，第18章） |
| **行为循环** | 同一动作反复出现，每次含义不同 | 沈玉喊"阿璃"（只在他需要她时，第1章）｜沐青玥唤"祸璃"（第15章）｜萧珩抱她（取暖→惩罚→乞求，第12-13章） |
| **身体反应替代心理描写** | 全章不写情绪词，只写身体 | 攥腰带（第1章）｜生理性眼泪（第11章）｜靠香味认人（第18章） |
| **跨章回扣** | 物品/意象在不同章节承担不同功能（本合集为"跨篇回扣"） | 玉扳指（第10章）→吉服（第21章）｜匕首（第12章刺→第13章扔回）｜糖糕（第15章）→红豆粽子（第16章） |

### 另附：本书独有的高频写法（不在模板清单内）

1. **"结算句"收尾**：全篇不解释的账，用 ≤10 字的一句台词结清，形式多为拒绝。（EM-010）
2. **对称动作结构**：一跪还一跪（第15章）、一锁还一锁（第7章）、一刀还一刀（第12-13章）。
3. **名字承担情感指向**：给一个称呼赋予唯一使用场景（"阿璃""昭离"）。
4. **反派不认错**：全篇反派几乎无一承认自己错了，只换一个错误解释。

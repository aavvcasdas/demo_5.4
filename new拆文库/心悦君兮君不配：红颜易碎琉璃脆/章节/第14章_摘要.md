# 第14章 摘要：丁香结

**概要**：现代女性"我"一觉醒来发现自己是礼部尚书独女云芸——落喜花河后失忆，性情大变，忘了对战神将军司空灼三年的倒追。她认定这是"接盘"，拒绝承认这份爱情，新婚夜便与司空灼立下"两年后和离"之约。司空灼带回怀孕女子玉真，后宅另藏六个小妾，她冷眼旁观、甚至去春风馆物色下一个夫婿。真相一层层揭开：六个小妾是皇帝安插的眼线；玉真是他副将的遗孀；小表妹乌婉珠早已被司空灼自己送进宫当荣妃（因为她曾想毒杀云芸）；而她做过三只名叫"鲁班七号、东皇太一、安琪拉"的玩偶，证明当初倒追三年的云芸其实就是她自己。小皇帝（她曾藏在狗洞里放走的人）劫持她父母，司空灼与三王爷谋反破宫；乌婉珠用"百花枯"毒与她同归于尽并纵火，司空灼抱着她与父母硬生生穿火而出，全身烧伤。一场高烧让她找回全部记忆，也终于明白当初自己为何轻易原谅他。

**关键事件**：1. 新婚夜立"两年之约"，她拒绝一切婚事礼仪。2. 司空灼带回怀孕的玉真并连续七夜睡在她房里打地铺。3. 他撕了她藏在枕下的春风馆花名册，坦白六妾是皇帝眼线、玉真是副将遗孀。4. 阿河讲出云芸三年倒追的往事与九里山挖瑞草的旧事（生死关头她跪在乌婉珠面前、又独自上山挖药）。5. 玉真在司空灼面前自摔诬陷她，被司空灼当场揭破"你腹中的胎儿是副将的遗子"。6. 司空灼率兵造反，途中她父母被小皇帝的人掳走。7. 破宫后发现小皇帝就是当日钻狗洞的"彥页"。8. 乌婉珠用涂毒钥匙骗她接触，又洒磷粉纵火。9. 司空灼抱她和父母穿火逃生，全身烧伤。10. 高烧退后记忆恢复——倒追三年的云芸本来就是她自己。11. 番外：她与司空灼的儿子"饭团"、玉真的儿子"饺子"长大成为生死之交。

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 云芸就是她本人 | 全篇用"接盘"设定让读者接受"我不爱他"，最后靠三只现代游戏角色命名的玩偶（鲁班七号/东皇太一/安琪拉）作为铁证反转 | 延迟揭示 + 现代梗做物证 | 恍然 / 心疼 | 用只有主角能认出的"时代错位物证"来完成身份反转 |
| 司空灼的深情 | 从不写他说爱，只写行为：撕花名册、打地铺、亲自登门提亲、穿火救人被烧伤 | 行为替代告白 | 甜 / 心疼 | 把"占有欲"写成"自我克制"（打地铺七日不动手） |

**逐章写法公式**：

- **情绪流向**：起：抗拒（新婚夜谈判）→ 承：嘴硬心软（打地铺、撕花名册、花名册约会）→ 转：旧事揭底（九里山、倒追三年）→ 合：火场 + 记忆回归
- **节奏配比**：慢铺垫 30% / 快冲突 22% / 爽点爆发 22% / 悬念留白 26%
- **本章结构公式**：**穿越/接盘设定制造情感隔离** + **婚姻谈判立约定** + **外部障碍（怀孕女子 + 六妾）逐个正名** + **反派羞辱反转（玉真自摔）** + **旧事补完（倒追三年/九里山）** + **政权级冲突（造反、劫父母）** + **火场救人 + 记忆归来**
- **本章核心技巧**：**用"信息劣势"驱动甜宠**。主角全程不知道旧事，读者跟着她一点点拼图，每拼上一块就多一分心软；这种"读者与主角同步发现男主的好"的节奏，比一开始就全知更能维持长线追读。可迁移：**把男主的深情做成一系列待解锁的证据链**。
- **卡点与伏笔**：结尾卡点：番外收束（孩子的友谊），闭环；埋设/回收伏笔：① 第 7 行"我小羊苏西敲你妈"→ 第 220 行玩偶名"鲁班七号、东皇太一、安琪拉"共同证明其现代身份；② 第 35-50 行她坚持要和离 → 第 513 行记忆恢复后解释自己为何轻易原谅他；③ 第 39-43 行"你曾经喜欢你的小表妹"→ 第 516 行"是司空灼亲手把乌婉珠送进宫去的"；④ 第 122-125 行相国寺的狗尾巴花 → 第 261-264 行"风筝落在他的马车上""手帕荷包都收藏在小库房里"；⑤ 第 292-305 行钻狗洞的男子 → 第 422 行他是小皇帝；⑥ 第 188-201 行九里山挖药 → 第 476 行由乌婉珠当众说出，成为司空灼情绪崩塌的扳机；⑦ 第 323 行玉真"重起轻放"的假摔 → 第 341 行她自己站起来拍灰

# 第4章 摘要：琉璃春

**概要**：大梁公主笙笙（近二十岁，顽劣骄纵）想嫁新晋状元史轲琅，被皇兄以太傅临玔之言挡回；她转头看上杜老将军之孙杜渡，用尽手段倒追皆失败；宫中设宴她策划"灌醉杜渡、和衣同床、让皇兄抓包"的生米煮成熟饭，却误入被下迷情香的房间，房里的人是临玔，二人于药性中圆房；事后从皇兄口中得知这是皇兄一手安排，且临玔正在议亲——她以为他要求娶杜蓉，哭着闹着不许，临玔把她抱进怀里说"我想要娶的是你"；她也终于想起童年那句"我讨厌你，临玔"的由来；最后一场婚礼收束，全篇以甜宠与搞笑为主基调。

**关键事件**：1. 求赐婚被拒，与临玔在莲池对峙，引出"我长得不好看？"的伏笔。2. 追史轲琅失败（老鼠被太监拍死、荷包被丢在地上）。3. 杜府寿宴偶遇杜渡、撞见临玔与杜蓉琴瑟和鸣，第一次吃醋。4. 宴席上策划灌酒，误中迷情香与临玔圆房。5. 得知是皇兄指使，并误听"议亲"消息，哭闹抗议。6. 临玔当面表白求婚，二人定情。7. 童年"我讨厌你"的误会揭破。8. 婚礼（终章）。

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 女主喜欢临玔却装不在乎 | 用"看俊男才子"清单、追杜渡、塞荷包等一整套反向外壳把真实心意包住 | 信息差 + 反向行为 | 好奇 / 甜 | 让主角用与心意相反的行动推进剧情，读者比主角先知道答案 |
| 临玔早就喜欢她 | 从第 74 行"捡起荷包放入怀中"开始，到第 492 行"原来他喜欢的一直是我，从小就喜欢了"为止，中间只在细节（梨子酒、玉珍鸡、火中推门）落笔 | 延迟揭示 + 对比锚点 | 甜 / 心疼 | 表白前先铺 15-20 处只读者可见的男主动作 |
| 迷情香事件的推手是皇兄 | 事后追查小林子、被揍、撞到皇兄装傻"哎呀，昨晚有发生什么朕不知道的事？" | 反应层放大 + 喜剧收束 | 搞笑 / 释然 | 严肃事件（下药）用喜剧人物（皇兄）收尾，可消除不适感 |

**逐章写法公式**：

- **情绪流向**：起：嚣张轻快（求赐婚被拒）→ 承：笑闹受挫 + 一点酸（追人失败 / 撞见杜蓉）→ 转：慌乱失控（迷情香 / 圆房 / 误听议亲）→ 合：大哭后告白、甜到收尾
- **节奏配比**：慢铺垫 24% / 快冲突 22% / 爽点爆发 34% / 悬念留白 20%
- **本章结构公式**：**主角动机错位（想嫁别人）** + **重复失败三次（史轲琅→杜渡→杜府）** + **外力破局（皇兄下药）** + **反向误会（误听议亲）** + **男主主动告白** + **童年伏笔回收** + **婚礼兑现**
- **本章核心技巧**：把"男主单方面暗恋"写成"女主一路求而不得、直到最后一刻才解开误会"。读者的甜感不来自恋爱过程，来自"两人明明双向奔赴却互相以为单向"的错位——**误会是糖的容器**。
- **卡点与伏笔**：结尾卡点：婚礼洞房，甜宠定格（无下章钩）；埋设/回收伏笔：① 第 25-32 行临玔问"我长得不好看？"→ 第 209 行「为何公主不喜欢我？」再逼一次 → 第 470 行正式表白（三级推进）；② 第 74 行临玔捡荷包入怀 → 婚礼前后情感回归；③ 第 241 行送梨子酒（知道她不宜喝烈酒）→ 体现预知式关心；④ 第 502 行童年"我讨厌你，临玔"→ 第 493-505 行完整回收，是所有克制与疏远的根源；⑤ 第 508 行"要求婚期提前一个月"→ 第 510 行婚礼当天的鼓乐喧天

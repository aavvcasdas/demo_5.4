# 第21章 摘要：笼中雀

**概要**：兵部尚书家获罪、男子流放女眷没官，唯有嫡次女沈玉乔被太子李庭柏伪造"失足而亡"的假象救下，改名"皎月"，藏在一处院阁里做了他见不得光的外室。这位"端方君子"在帷帐之内毫无君子模样，除了宠她，也从不给她名分，还拒绝了好几个太子妃人选。她趁一次出游被允许出府的机会，在街上撞见即将成婚的竹马林则安；林则安随后易容成医徒混进院阁，递给她一张逃跑路线图——理由是"太子不日就会迎人入主东宫"，她若留下，只会成为别人攻击太子的把柄。她照图易装、藏在运尸商队的夹层里逃出城，躲进郊外小道观。二皇子的人马还是截住了她，目的是逼李庭柏承认私藏罪臣之女；林则安赶来认下"是我私藏她的"，而康平郡主（皇帝赐给林则安的未婚妻）当场把一瓶药灌进她嘴里。李庭柏斩杀了二皇子的人、只留两人回去报信。沈家后来翻案，她被送回苏州外祖家养病（因为假死药伤身），而沈玉婷"得急病死了"。李庭柏早就按她的尺寸备下了一套吉服，却只说"收起来，用不上"，随后启程下江南。

**关键事件**：1. 她被伪造死亡、改名皎月，成为太子外室。2. 出游时在街上与林则安相遇。3. 林则安易容成医徒混入，递上逃跑路线图。4. 她设计让桃杏昏睡、换了她的衣服，藏进运尸商队出城。5. 李庭柏发现她逃走，"一字不留，也一物不带"，下令查是谁在帮她。6. 二皇子的人截住她，准备逼李庭柏认罪。7. 林则安到场认下私藏；康平郡主灌她假死药。8. 李庭柏当场斩杀二皇子的人，只放两人回去报信。9. 沈家翻案，她被送回苏州养病，沈玉婷急病而亡。10. 李庭柏的吉服"用不上"，他启程下江南。11. 番外：他到苏州看她，处处保持距离；临行前夜他遇刺，她赶到驿站，他说"你来了"。

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|

**逐章写法公式**：
- **情绪流向**：起：软（笼中日常里的屈辱与依赖）→ 承：疑（故人出现、试探）→ 转：逃（易装出城、被截、被灌药）→ 合：空（翻案、离京、吉服封存）
- **节奏配比**：慢铺垫 30% / 快冲突 24% / 爽点爆发 18% / 悬念留白 28%
- **本章结构公式**：**以"人人称他君子、唯她知道不是"开场** + **用日常细节写屈辱与依赖并存** + **旧人出现递出逃生可能** + **一次成功出逃** + **被第三方势力截住成为政治筹码** + **旧人抢认罪** + **第三方（郡主）下手完成"死"** + **男主血洗收场并留活口** + **旁白补出生路与翻案** + **番外重逢**
- **本章核心技巧**：**"知情权差"制造怜悯**。她全程不知道沈家正在被翻案、不知道吉服是为她做的、不知道自己喝的是假死药——三处信息都由旁白或太监口中补出，读者比她先知道，因此每一次她的自嘲（"我如今只佩服沈玉乔"）都更让人心酸。**让主角持续错过好消息，是长篇虐文的稳定催泪法**。
- **卡点与伏笔**：结尾卡点：驿站重逢"你来了"，开放式收束；埋设/回收伏笔：① 第 23-24 行伪造"失足而亡"与改名皎月 → 第 378 行太监确认她的身份原名；② 第 43-44 行李庭柏轻拍左腿、她坐上去 → 建立两人只有她能懂的身体默契；③ 第 56-59 行"永昌伯的嫡长子也快要娶亲了"→ 第 94-96 行街上相遇，第 268-275 行陈情书；④ 第 161 行林则安戴着沈玉乔返送的镯子与玉佩 → 唯一凭据；⑤ 第 227 行"你穿成亲吉服一定很好看"→ 第 376-383 行吉服与"用不上"；⑥ 第 390-408 行翰林书塾往事：她赤足踏水捡帕子 → 解释他为何从一开始就选了她

# 莲雪

- **archetype**：protagonist
- **出场**：第26章（无名氏）
- **身份背景**：穿书成宋冰瑶无名丫鬟的叙事者，后为皇后
- **核心经历**：熟知剧情，为改小姐与自身命运巴结假名"沐姑娘"的贵人（先皇嫡子墨青钰）；挡剑救主被赐名莲雪；替小姐模仿字迹通信，让墨青钰爱上"信里的姑娘"；渣行败露后，墨青钰以宋家小姐身份娶她为后
- **性格特质**：自嘲"终究是这故事的无名氏"；穿书求生
- **能力特长**：穿书先知（熟知剧情）、模仿字迹
- **人际关系**：墨青钰（新皇/丈夫）、宋冰瑶（小姐）、宋文博（哥哥）
- **成长弧线**：从无名丫鬟到皇后（史书只留"皇后宋氏"）
- **别名**：无名氏、丫鬟、小丫头、皇后宋氏
- **关键转折**：1. 挡剑赐名 2. 冒名写信 3. 封后

# 褚瑶

- **archetype**：protagonist
- **出场**：第16-17章（顾无言）
- **身份背景**：开国元老之女，后为皇后
- **核心经历**：一眼万年爱上翊王，追得满上京人尽皆知；成婚当日老皇帝驾崩、翊王继位、同娶烟芜；被要求"识大体"；老太后病逝后病倒，因烟芜宫门外生产被一巴掌打懵、贬入皇家林苑；三年后回宫，烟芜临终揭避子汤秘密；重绣"软玉和红豆"帕，求两份休书，约定"下辈子你追我"
- **性格特质**：直白皮实、追夫不成反被规矩驯化；全书最"不像女主"的女主
- **能力特长**：被偏爱（老太后、宁妃、皇帝藏在小动作里的偏爱）
- **人际关系**：翊王/皇上（丈夫）、烟芜（表妹/情敌）、宁妃（唯一同类）、老太后（净土）
- **成长弧线**：从争宠的活人到主动退场的死人
- **别名**：我、阿瑶、瑶儿、皇后娘娘
- **关键转折**：1. 贬入皇家林苑 2. 烟芜揭避子汤 3. 求两份休书

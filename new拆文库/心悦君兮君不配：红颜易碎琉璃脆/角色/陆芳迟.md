# 陆芳迟

- **archetype**：protagonist
- **出场**：第27章（太子妃）
- **身份背景**：将军府大小姐，与孪生兄陆云争长相酷似
- **核心经历**：借皇命兄为太子伴读之机女扮男装入东宫亲近太子尹无珏；因送美人画像被罚抄经、月事告假露怯、城郊挡刀吐真名与爱意；伤愈换回女身；替闺蜜代嫁太傅子，却花轿错抬入尹无珏洞房，方知对方早认出她
- **性格特质**：垂涎已久却胆怯；露怯与逞强并存
- **能力特长**：龙凤胎酷似外貌（代兄伴读）
- **人际关系**：尹无珏（太子/丈夫）、陆云争（孪生兄）、宋心瑶（闺蜜）
- **成长弧线**：从女扮男装亲近到错抬洞房得专宠
- **别名**：陆云争（男装）、芳迟、臣
- **关键转折**：1. 城郊挡刀吐真名 2. 换回女身 3. 错抬入太子洞房

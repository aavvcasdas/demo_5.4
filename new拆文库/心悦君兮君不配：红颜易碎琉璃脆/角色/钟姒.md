# 钟姒

- **archetype**：protagonist
- **出场**：第7章（锁深深）
- **身份背景**：前朝皇后
- **核心经历**：叛军破宫那日失忆，被旧日师父谢禹带回国公府软禁；凭身体记忆察觉异样；将情敌林晴月主仆推落废井时恢复全部记忆——她十四岁爱师父，为他囚禁一年、强行欢好、刺字；他破宫本为杀她；她继续装失忆勾引；七夕被旧部"救"走反被将计就计；怀孕被"你也配"伤透，借新帝离京生子；三年后谢禹找到她承认爱她
- **性格特质**：偏执、主动、厚脸皮、演技极佳；加害者与受害者的合体
- **能力特长**：傀儡术（茶中下药）、装失忆的演技
- **人际关系**：谢禹（师父/囚禁者/爱人）、林晴月（情敌）、新帝（谢禹之父）
- **成长弧线**：从加害者到受害者再到母亲
- **别名**：我、娘娘、前朝皇后
- **关键转折**：1. 落井恢复记忆 2. 被锁进当年她锁他的铁链 3. 三年后重逢

# 秦樾

- **archetype**：protagonist
- **出场**：第52章（千千结）
- **身份背景**：嫁死对头徐燕时（换亲）
- **核心经历**：本欲搞垮夫君，却在飙戏试探中渐露真心；凌安公主（冒充）携赵王设局，凭略通医道挟持赵王取其谋反证据；助徐燕时与三殿下（面具姐夫）平叛；真相揭开——徐燕时乃八年前宋国战败含冤灭门的大将军之子，蛰伏八年沉冤；游湖方知自己早被阿姐与三殿下设计替嫁，而徐燕时暗恋她多年、三年前备下秋千蝴蝶求婚；湖上相拥
- **性格特质**：飙戏试探、渐露真心
- **能力特长**：略通医道（挟持赵王）
- **人际关系**：徐燕时（丈夫）、凌安公主（冒充者/反派）、赵王（反派）
- **成长弧线**：从搞垮夫君到互表心意
- **别名**：阿樾、二小姐
- **关键转折**：1. 挟赵王取证 2. 揭徐燕时身世 3. 秋千蝴蝶求婚

# 谢京华

- **archetype**：protagonist
- **出场**：第35-36章（谢京华）
- **身份背景**：谢家小姐，十六艳压京都、十七落水变痴傻
- **核心经历**：落水变痴傻、谢家被牵连辞官离京；在荆州暗中布局揭二皇子谋反；花楼弹琴现身与裴晏重逢；赴封州救父被擒成囚车；与裴晏定"出去便成亲"；终被皇帝赐婚迎娶
- **性格特质**：痴傻是伪装，一直在暗中布局
- **能力特长**：布局（痴傻隐藏 + 谢家势力）
- **人际关系**：裴晏（右相次子/痴等者）、谢钦（父）、王潇（皇家暗门替身）
- **成长弧线**：从痴傻离京到布局揭反再到成婚
- **别名**：谢姐姐、京华、谢芳华
- **关键转折**：1. 花楼重逢 2. 被擒成囚车 3. 皇帝赐婚

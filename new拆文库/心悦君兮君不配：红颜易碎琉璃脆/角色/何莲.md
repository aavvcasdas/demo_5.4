# 何莲

- **archetype**：protagonist
- **出场**：第37章（黑心莲）
- **身份背景**：豆腐坊女（本名何怜），似俪贵妃被太后赐名选入宫，实为废后干女儿
- **核心经历**：借温柔"小白莲"姿态博皇帝叶行佑宠；层层离间帝与俪贵妃；假孕六月流产嫁祸俪贵妃夺六宫权；俪贵妃吞金而亡后生子封太子；临终揭其乃废后干女儿、入宫只为替干娘复仇，掰耳珰灌毒弑君
- **性格特质**：白切黑，柔弱伪装下是复仇者
- **能力特长**：似俪贵妃的容貌、离间手段
- **人际关系**：叶行佑（皇帝）、俪贵妃（情敌/被嫁祸者）、废后（干娘）
- **成长弧线**：从入宫到夺权再到弑君
- **别名**：何怜、莲贵人、莲嫔、莲妃、莲贵妃
- **关键转折**：1. 假孕嫁祸 2. 俪贵妃吞金 3. 掰耳珰弑君

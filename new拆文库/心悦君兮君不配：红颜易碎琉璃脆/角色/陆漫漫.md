# 陆漫漫

- **archetype**：protagonist
- **出场**：第31章（陆漫漫）
- **身份背景**：现代绝症女子借时光机穿越，落水被七皇子萧允救起
- **核心经历**：萧允因对女子肌肤过敏、唯她不过敏，欲娶她延嗣；二人先婚后爱；查出原主阿绿被武安侯世子元湛以蛊术欺骗致死的真相并替其复仇；历经立太子、生子、破谣言，萧允登基为后
- **性格特质**：现代思维、主动
- **能力特长**：时光机穿越、"唯她不过敏"的体质
- **人际关系**：萧允（七皇子/丈夫）、元湛（武安侯世子/仇人）、阿绿（原主）
- **成长弧线**：从绝症穿越女到替原主复仇再到皇后
- **别名**：七皇妃、太子妃、皇后娘娘、阿绿（原主）
- **关键转折**：1. 落水被救 2. 查蛊术真相 3. 替阿绿复仇

# 沈岁穗

- **archetype**：protagonist
- **出场**：第3章（声声慢）
- **身份背景**：大秦浣衣坊宫女，后为皇后
- **核心经历**：为护三皇子慕容烨不被构陷，替他挡刀、替皇帝挡死，从美人爬到皇后；为阻止慕容烨弑父而毒杀皇帝；把自己演成"为夺太后之位不择手段的毒妇"，用死把他推回皇位
- **性格特质**：冷静到近乎自我放弃；把伤害只算在自己头上；不可靠叙述者（自贬与行为相反）
- **能力特长**：朝堂操作（一句"天竺刺客"解围、散立储谣言）、藏毒的护甲、表演能力
- **人际关系**：慕容烨（三皇子，恨意与爱意同体）、皇上（先皇，宠溺的审问者）、静太妃（道德执行者）
- **成长弧线**：从浣衣坊宫女到皇后，再到自污赴死
- **别名**：我、娘娘、皇后
- **关键转折**：1. "儿臣见过母后" 2. 护甲藏毒毒杀皇帝 3. 成衣店一拜天地后饮鸩

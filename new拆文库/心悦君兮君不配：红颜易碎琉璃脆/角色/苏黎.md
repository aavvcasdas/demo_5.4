# 苏黎

- **archetype**：protagonist
- **出场**：第39章（庶女毒）
- **身份背景**：庶女，为报复长姐苏醒当年踩背之辱入府
- **核心经历**：刻意勾引姐夫太子宋煜谦争宠；当众打脸丫鬟珠珠、苏醒禁足；温泉和好后扬言做穿红衣的正妻；宫宴遇救命恩人十四叔宋禹恒，被宋煜谦当筹码让出换禁卫军；红衣明媒正娶嫁宸王，生女之遥；宋禹恒战死皓安门，苏黎殉情
- **性格特质**："小疯子"人设，报复与真情并存
- **能力特长**：勾引手段、宋禹恒真心
- **人际关系**：宋煜谦（太子/姐夫）、宋禹恒（十四叔/丈夫）、苏醒（长姐/仇人）
- **成长弧线**：从报复到殉情
- **别名**：小疯子
- **关键转折**：1. 被让出换兵权 2. 红衣出嫁 3. 殉情

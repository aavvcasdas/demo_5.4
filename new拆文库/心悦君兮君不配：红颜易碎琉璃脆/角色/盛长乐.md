# 盛长乐

- **archetype**：protagonist
- **出场**：第33-34章（清平乐）
- **身份背景**：隋国四公主，流落多年恢复身份
- **核心经历**：欲报复当年将她拽入深渊的仇人；擒荆行入地牢折磨，却萌生"让他爱上我"之念；强娶同榻；屋顶定情、借婚礼刺杀嫁祸薛家、揭荆行血泪身世；七夕前暗令屠荆家，荆行持九仙琉璃灯归知真相灯碎离去；有孕血崩而亡
- **性格特质**：以折磨与报复为乐，却动了真情
- **能力特长**：公主身份、影卫（阿七阿八阿九）
- **人际关系**：荆行（被折磨者/爱人）、荆黎（救命恩人）、江明若（荆行恋人/执念）
- **成长弧线**：从复仇到爱再到殉情
- **别名**：四公主、长乐、乐儿
- **关键转折**：1. 强娶同榻 2. 暗令屠荆家 3. 灯碎离去、血崩而亡

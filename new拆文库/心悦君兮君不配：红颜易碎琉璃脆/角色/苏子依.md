# 苏子依

- **archetype**：protagonist
- **出场**：第22章（与子同衣）
- **身份背景**：14岁被唐王爷送进宫的卑微孤女，后为昭华公主
- **核心经历**：被钟泽收留教字；从阿韫处得知钟浅旧事；与钟思哲由恶作剧相识、坠山涧生情；钟泽亲征前赐她昭华公主之位监国；二爹上门辱她，钟思哲护她受掌掴；钟泽重伤昏迷秘归，钟思哲借冲喜求婚，二人成婚
- **性格特质**：卑微却自陈出身护君；被偏爱而不自知
- **能力特长**：监国（自陈卑贱护钟泽清誉）、识字、讨食
- **人际关系**：钟泽（皇帝/收留者）、钟思哲（世子/丈夫）、阿韫（番邦公主）
- **成长弧线**：从弃女到监国公主再到王妃
- **别名**：昭华公主、小东西
- **关键转折**：1. 赐封监国 2. 宫门受掌掴 3. 冲喜求婚成婚

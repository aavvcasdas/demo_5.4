# 沈菀

- **archetype**：protagonist
- **出场**：第28-30章（红颜尽）
- **身份背景**：姜国皇后（小字绾绾），实为宁嘉皇后
- **核心经历**：困长春宫五年，因宋淮安独宠淑贵妃受尽冷落；侍女瑾儿被杖杀；宋淮安以假"不生丹"骗她向淑贵妃下跪，致沈母身死；早产血崩而亡；"死后"失忆救起坠崖的宋淮安（化名"平安"），二人重逢相恋；大婚前梦回前世——她便是长岭救帝、换袍坠崖失忆的宁嘉皇后；恢复记忆下毒未果，查明生母被淑贵妃调换假丹毒害，与帝恩断义绝；离宫远走江南
- **性格特质**：病弱失忆却坚韧；恩断义绝的决绝
- **能力特长**：宁嘉皇后前身（前世记忆）、假死
- **人际关系**：宋淮安（皇帝/丈夫）、淑贵妃（哑女/仇人）、沈徵（父）、顾听澜（暗恋者）
- **成长弧线**：从冷宫弃后到失忆重生再到恩断离宫
- **别名**：绾绾、沈小姐、宁嘉皇后、皇后娘娘
- **关键转折**：1. 假丹骗跪 2. 梦回前世 3. 查明假丹毒害恩断

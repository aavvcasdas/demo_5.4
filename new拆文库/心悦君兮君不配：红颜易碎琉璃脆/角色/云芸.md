# 云芸

- **archetype**：protagonist
- **出场**：第14章（丁香结）
- **身份背景**：礼部尚书独女（现代女性意识）
- **核心经历**：落喜花河后失忆、性情大变，忘了对战神将军司空灼三年倒追；立"两年后和离"之约；冷眼旁观六妾与玉真；玩偶名铁证（王者荣耀英雄名）证明倒追三年的云芸就是她自己；小皇帝劫持父母，司空灼穿火救人全身烧伤；高烧后记忆复原
- **性格特质**：现代意识流吐槽 + 恋爱脑自嘲；口嫌体正直
- **能力特长**：现代知识与意识、借司空灼兵权
- **人际关系**：司空灼（战神将军/丈夫）、玉真（副将遗孀）、乌婉珠（小表妹/荣妃）
- **成长弧线**：从拒绝"接盘"到找回记忆、承认爱情
- **别名**：我、阿芸、夫人、小姐、云芸/苏西
- **关键转折**：1. 立和离之约 2. 玩偶名铁证 3. 穿火逃生后记忆复原

# 宋意央

- **archetype**：protagonist
- **出场**：第9-10章（共沉沦）
- **身份背景**：大邺公主（封号如意）
- **核心经历**：亲见二哥哥气死父皇，被拘禁留春宫，因权臣陆霁求情获自由；突厥求亲时陆霁夜闯寝宫问她愿不愿和亲；陆霁以军功求娶，柳茹设局她失手用银钗杀人，陆霁用柳茹的血染婚服；以假身份赴云州查案；玉扳指唤醒十岁记忆；陆霁出征重伤，她难产得子等了一年
- **性格特质**：求生欲极强、不争不抢、嘴上认怂心里记账；全书最"怂"也最清醒
- **能力特长**：装怂的本事、一副好皮囊、借陆霁权势
- **人际关系**：陆霁（权臣/丈夫）、二哥哥（篡位者/皇兄）、柳茹（情敌）
- **成长弧线**：从怕他到喜欢他，从"妻随夫姓"到等他归来
- **别名**：我、如意公主、央央、陆央央、殿下
- **关键转折**：1. 银钗杀人 2. 玉扳指唤醒童年记忆 3. 御花园重逢

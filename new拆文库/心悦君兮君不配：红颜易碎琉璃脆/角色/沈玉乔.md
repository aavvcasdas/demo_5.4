# 沈玉乔

- **archetype**：protagonist
- **出场**：第21章（笼中雀）
- **身份背景**：兵部尚书家嫡次女（罪臣之女）
- **核心经历**：被太子李庭柏伪造"失足而亡"救下，改名皎月做外室；出游遇竹马林则安；林则安易容混进递逃跑路线；易装藏运尸商队出城；被二皇子的人截住，林则安认下私藏、康平郡主灌假死药；沈家翻案，被送回苏州养病；李庭柏的吉服"用不上"，他下江南
- **性格特质**：表面顺从、内里求生；全书唯一走"逃跑"路线的女主
- **能力特长**：求生、易装、借三人合力
- **人际关系**：李庭柏（太子/外室主人）、林则安（竹马）、康平郡主（灌假死药者）
- **成长弧线**：从笼中雀到逃出再到"你来了"
- **别名**：我、皎月、月姑娘、玉乔、乔儿
- **关键转折**：1. 伪造死亡做外室 2. 逃跑路线出城 3. 吉服"用不上"

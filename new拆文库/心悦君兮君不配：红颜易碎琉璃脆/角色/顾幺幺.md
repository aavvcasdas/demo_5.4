# 顾幺幺

- **archetype**：protagonist
- **出场**：第18章（朱砂痣）
- **身份背景**：顾氏孤女，被容钦调教成杀手，后为皇后
- **核心经历**：潜伏南齐皇帝谢玄身边五年报仇；谢玄死前告白"朕输了"；逃宫被容钦堵截；遇与王淮安同貌的玩蛇少年星煜；闯北疆长生林，祭司揭王淮安以灵魂永世禁锢做交换；岐山发现"沉玉"即诈死的谢玄；谎称怀孕做皇后；满岁宴挡下星煜的剑，以命与储君为质换王淮安重入轮回
- **性格特质**：从杀手到皇后；一生只爱一个死去的少年
- **能力特长**：杀手训练、两大世家的培养
- **人际关系**：谢玄（皇帝/明知是刀仍求爱）、王淮安（以命为她筹谋）、容钦（调教者）、星煜（顶着王淮安的脸）
- **成长弧线**：从复仇到还债再到自我牺牲
- **别名**：我、幺幺、顾幺幺、皇后殿下
- **关键转折**：1. 谢玄死前告白 2. 祭司揭灵魂交换 3. 挡剑换轮回

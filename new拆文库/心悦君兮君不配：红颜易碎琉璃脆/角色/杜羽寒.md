# 杜羽寒

- **archetype**：protagonist
- **出场**：第48-49章（凤求凰）
- **身份背景**：穿进《暴君的宠姬》的现代女（杜胎穿）
- **核心经历**：奸臣爹逼她入宫做太后棋子，逃避仍被封贵妃；新婚夜"暴君"皇帝跪喊"奇变偶不变"暗号，二人发现同为穿越者；写下未来灭国节点，发现一年后叛军破宫、首犯甄将军，却无兵权陷死循环；借太后骗得暗卫，识破丽贵人内应，中秋宴设局赐死甄将军；请回苏太傅推行新政；皇帝坠马"重伤"、杜家被抄、她逃江南，方知皇帝装病只为让她恨他逃离；发现"绝症"实为乳糖不耐受与花生过敏，封懿后
- **性格特质**：现代思维、破局者
- **能力特长**：穿越者身份、"奇变偶不变"暗号
- **人际关系**：章允（皇帝/穿越者丈夫）、杜丞相（父/反派）、甄将军（叛军首犯）
- **成长弧线**：从逃避入宫到破局再到封后
- **别名**：贵妃珠、老婆、懿后
- **关键转折**：1. 暗号相认 2. 中秋赐死甄将军 3. 过敏乌龙封后

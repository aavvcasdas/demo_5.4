# 苏媛

- **archetype**：protagonist
- **出场**：第38章（太后怨）
- **身份背景**：晋国公孙女，被妖道言凤命抬为皇后，史上最年轻太后
- **核心经历**：新婚夜老皇帝驾崩，太子沈厉留她为太后（实为暗恋）；二人借选秀国宴眉来眼去；中秋夜沈厉潜入强宠；有孕后随王造反，破庙产子、沈厉跳崖（诈）随王死；终立后为独尊中宫；回溯元宵她曾救小乞丐即沈厉
- **性格特质**：在名分禁忌中挣扎
- **能力特长**：凤命预言、沈厉暗恋
- **人际关系**：沈厉（建安帝/暗恋者）、随王（兄/反派）、晋国公（祖父）
- **成长弧线**：从年轻太后到立后独尊
- **别名**：太后、绵绵、苏嫆
- **关键转折**：1. 留为年轻太后 2. 破庙产子 3. 立后独尊

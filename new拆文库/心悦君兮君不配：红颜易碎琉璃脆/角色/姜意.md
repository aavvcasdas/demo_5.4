# 姜意

- **archetype**：protagonist
- **出场**：第32章（妖妃传）
- **身份背景**：前朝公主（化名姜意），被遗老王全带入新帝李昭后宫
- **核心经历**：本欲"复国"却成先帝侍寝当夜崩逝的"妖妃"，被李昭册为贵妃；贪财爱美，与夜夜翻窗的"淮南王世子赵一典"周旋；揭穿赵一典即李昭；除夕摘星楼淮南王谋反，王全刺驾时她替李昭挨刀"假死"；醒来真相大白，二人并肩
- **性格特质**：贪财爱美却重情；替刀假死
- **能力特长**：前朝公主身份、王全教的情报术
- **人际关系**：李昭（皇帝/赵一典）、王全（前朝遗老）、皇后（李昭之姐）
- **成长弧线**：从复国到认命再到并肩
- **别名**：贵妃娘娘、漂亮姐姐、小婶子
- **关键转折**：1. 揭穿赵一典即李昭 2. 替刀假死 3. 真相大白并肩

# 纳青

- **archetype**：protagonist
- **出场**：第6章（纳青劫）
- **身份背景**：草原完颜部嫡长女，被当男儿养大
- **核心经历**：爱上叶赫部弃子弩齐，弩齐却爱妹妹纳兰；换信、以完颜部兵力财力为筹码招弩齐入赘；五年助他统一草原七部；弩齐在姐妹间选她；大胤立国为后；八年后狱中揭破——当年喇嘛预言的人是她
- **性格特质**：刚烈、果决、把爱写成交易；全书最"男频式"女主
- **能力特长**：能驯烈马、能射恶狼；近身搏击强于弩齐
- **人际关系**：弩齐（丈夫/汗王）、纳兰（妹妹，被预言顶替）、阿爹（隐去预言后半句）
- **成长弧线**：从放任自流的长姐到统一草原的皇后
- **别名**：我、长姐、完颜纳青
- **关键转折**：1. 换信逼弩齐 2. 弩齐选她 3. 狱中揭破预言真相

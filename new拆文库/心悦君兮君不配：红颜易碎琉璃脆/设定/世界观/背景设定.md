# 背景设定：心悦君兮君不配：红颜易碎琉璃脆

> **重要说明**：本书为知乎专栏合集，43 篇**互不共享世界观**。同属古言宫廷语感，但朝代名、人物、地图均不衔接（已出现国号：大燕、大梁/武朝、大秦、大夏、大邺、大凉、南齐、大晏、大周、安国、信国、大胤、隋国、姜国、晋国、大齐、庆梁国、楚尧国、北周、南梁、大雍、万象国、黑曜国、天华国、大凉、宋国、大雍等）。因此本文件按**跨篇母题级设定** + **43 篇的篇内设定**两层组织。
> **事实保真声明**：设定行末标注来源章节；原文未明确的一律写「原文未明确」，不做推断填空。

## 一、跨篇通用设定（43 篇共有的制度性前提）

| 设定项 | 内容 | 证据 |
|---|---|---|
| 政治形态 | 皇权 + 世家/权臣/外戚/宦官四角制衡；皇帝常为幼帝或病弱 | 第2、9、12、15、19、21、22、38章 |
| 婚姻制度 | 赐婚是最重要的政治工具；和亲用于换边安；侧妃/妾室/外室制度普遍 | 第1、2、6、11、16、19、20、23、41、44章 |
| 女性位置 | 女性无继承权，但可通过"掌握兵权的娘家""掌后宫的皇后""监国的太后/公主"获得实权 | 第8、12、15、22、24、25、40章 |
| 刑罚体系 | 赐死（鸩酒/白绫/毒药）、杖毙、流放、没官奴、抄家、悬尸城墙、水牢 | 第1、2、5、16、19、21、22、44章 |
| 信息通道 | 密信、飞鸽、奏折、丫鬟私语、宫宴、战报、斥候 | 全篇通用 |
| 医药设定 | 慢性毒、避子汤、迷情香、假死药、傀儡术、蛊术、绝子药为主要情节工具 | 第4、7、11、12、16、17、21、31、41章 |
| 超现实元素 | 仅个别篇出现穿越/时光机/双穿越/穿书，为叙事装置，不构成统一世界观 | 第14、26、31、38、48-49章 |

## 二、篇内设定（43 篇，第 1-21 章沿用深度拆解与早期摘要，第 22-54 章为全量补充）

### 第1章 玉阶寒（大燕朝）
- 皇长子沈玉、皇次子沈玦；将军府（苏勇镇守西陲，手握重兵）
- **青雪堂**：京中养剑客、接暗杀的机构；顾北寒为头牌
- 赐婚是皇帝安抚边将的手段；鸩酒是先帝赐死的旧物

### 第2章 探芳音（武朝/大梁，原文两处国号混用，属作者笔误）
- **波族**：西北边陲强族；**万朝节**：数百番邦使臣朝贺；**血手兵团**：大梁秘密精锐

### 第3章 声声慢（大秦）
- 三皇子慕容烨统兵征战四年；大皇子为长；「先皇最忌讳之事便是废长立幼」
- 天竺刺客行刺大秦官员；地名：静慈寺、璃王封地、冷月宫

### 第4章 琉璃春（大梁）
- 公主笙笙 + 皇兄（皇帝）+ 太傅临玔；杜老将军府、莲花池
- 原文未明确：是否存在女帝设定

### 第5章 九歌难
- **女真**（大皇子完颜煌）；**大梁**；**玉门关**（被女真打开）
- 女真南迁发战的原因是十五年前大草原干旱、缺水缺草

### 第6章 纳青劫（草原→大胤）
- **草原七部**：完颜、叶赫、蒲察、斡勒、徒单、温都
- **汉廷**（后为弩齐所灭，建大胤，八百年国祚）；**山海关**由定北王镇守
- 年份标尺：昭和二十八年开山海关 → 太初元年纳青为后 → 太初八年狱中揭底

### 第7章 锁深深（前朝/新朝）
- 前朝（钟姒为前朝皇后）→ 新帝起兵（谢禹之父为端王→新帝）
- **国公府**：钟姒娘家；皇子师承制度：谢禹以"太傅"身份藏匿教书

### 第8章 隔山海（大夏）
- **胡戎**（主将阿诗勒丹顿）；**季家军**世代镇守西陲
- 地名：定幽城、风波镇、函谷关、风华城（帝都）
- **玉家**：外戚，玉相为首；太子实为玉相之子

### 第9-10章 共沉沦（大邺）
- 二哥哥篡位杀父；**突厥**（联姻对象）；**北越**（后宣战）
- **永平侯府**（柳茹家）；云州（黄淅为太守）；工部侍郎路稳案

### 第11章 关山月（安国/信国/大信）
- **安国**与**信国**对峙；长风城、函谷关、乌克苏沙漠、伦纳河、月盈湖
- **宁王**（信国皇帝之弟，掌五万军队）

### 第12-13章 何殇离（大晏）
- **摄政王萧承嗣**（皇帝亲叔，掌几十万重兵）；**萧珩**（少年皇帝）
- 关键机制：**用毒控制**（月圆需服解药）；**傀儡术**（茶中药）
- 北族：芫姬、二皇子夙幸；西域：安西大公主（原名昭离）

### 第14章 丁香结（大周）
- 司空灼：战神将军，掌大周大半兵权；小皇帝纵情后宫
- **三王爷颜灏**（谋反扶持对象）；六妾为皇帝眼线；**瑞草**（解至阴至寒之毒）

### 第15章 殿前欢（大凉）
- **东厂**（祸璃为厂督，号九千岁）；**柳丞相**（太子外祖）

### 第16-17章 顾无言（未命名国号）

- **皇家林苑**：避暑胜地，实为流放地

### 第18章 朱砂痣（南齐）
- **三大世家**：顾氏、王氏、容氏；世家与皇权对立
- **北疆秘族**：隐世，同宗传宗接代、子嗣多生顽疾；祭司掌权杖
- **三味奇香**：生犀、解忧、荼芜；关键物品：天子印玺、扳指、碧玉笛
- 原文明示："世上哪里有什么岐山……自始至终，不过一个骗局"——岐山与鬼谷派是骗局，北疆秘族为真实存在

### 第19-20章 误芳华（未命名国号）

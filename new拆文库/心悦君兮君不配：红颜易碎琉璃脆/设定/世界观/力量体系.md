# 力量体系：心悦君兮君不配：红颜易碎琉璃脆

> 本书为古言宫廷题材（无修炼体系），故本文件登记的是**权力/武力/信息三类"实力"的度量与规则**，替代常规力量体系。
> 事实保真：原文未明确处标注。

## 一、权力层级（本书主导性的"力量"）

### 通用层级（43 篇共享语感）

```
皇帝 / 摄政王（最高，可赐死任何人）
  ↑
实权藩王·权臣·掌兵将领（可对抗皇权，但需"名正言顺"）
  ↑
宰相 / 首辅 / 世家家主（朝堂资源与人心）
  ↑
厂督 / 太傅 / 监军 / 大理寺（制度性暴力机构）
  ↑
皇后 / 贵妃 / 太后（后宫实权，可掌六宫、可协理朝政）
  ↑
皇子 / 太子 / 公主 / 郡主（名分高但受制）
  ↑
侧妃 / 侍妾 / 外室（无名分，可随时丢弃）
  ↑
宫女 / 丫鬟 / 死士 / 剑客（可被杖毙、可被随意交易）
```

### 权力的"合法性"机制（本书最核心的政治规则）

原文直接给出规则的段落：

- 「他不是个只想着莽撞夺江山的人，夺江山易，守江山难。若这江山夺得不顺理成章，今日他灭萧珩，明日难保不被他人灭。」（第12章第 157 行）
- 「他要等的，根本不是民心，是世家大族的人心……谁得到世家大族的心，谁才能千秋万代。」（第12章第 160-162 行）
- 「如今之计只有杀了岁穗姑娘，若是大皇子问起，皇上便说，发现岁穗姑娘逃脱，皇上追赶至此。」（第3章第 197 行）——**名义比事实重要**

**推论**：本书中"力量"的兑换公式是 **兵力 × 名义 × 人心**。仅凭兵力夺位者（萧承嗣）会输给掌握名义者（萧珩）；仅凭名义者（秦逸）会输给掌握兵力者（元瓒）。

## 二、武力层级（分散于各篇，非统一体系）

| 级别 | 表现 | 代表 |
|---|---|---|
| 超一流 | 一人可斩数十、可于军中穿梭不见踪迹 | 顾北寒（"大燕朝的第一剑客"）｜星煜（"身形如魅"）｜萧珩（内力深到"匕首没入柱子"） |
| 一流 | 战场万人敌、可单骑救主 | 季临渊｜宋钧｜李知退｜完颜煌｜弩齐 |
| 二流 | 近身搏击强于常人 | 纳青（"我的近身搏击功夫比起弩齐而言还要强上一些"）｜钟姒 |
| 无武力 | 以智谋、裙带、算计生存 | 百音｜沈岁穗｜何殇离（有功夫但"从不曾真的用在他身上"） |

**特点**：本书武力不是升级系统，而是**身份标签**——武力值决定角色能否"亲自下手"。**书中所有决定性的击杀都发生在"武力不对等"的场景里**（一簪、一匕首、一瓶毒），而非公平对决。

## 三、信息层级（本书真正的隐藏体系）

本书的胜负几乎全部由**信息差**决定。信息等级从高到低：

| 等级 | 掌握者 | 说明 | 例证 |
|---|---|---|---|
| S | 皇帝本人（有时） | 知道全局并主动操盘 | 荣德帝（"朕还年轻，别把朕当老糊涂"）｜李元晟｜祸璃｜萧珩 |
| A | 摄政王 / 权臣 | 知道大部分但会误判最高权力者 | 萧承嗣（看不出萧珩的替身局）｜容钦 |
| B | 主角（部分知情） | 知道一部分真相，被更大的局遮蔽 | 顾幺幺（不知道自己被用作棋子）｜季羡渔（不知道李元晟是阿郕） |
| C | 反派（局部知情） | 知道计划但不知道被反用 | 魏婉娴（不知道二皇子要斩魏家）｜齐河（不知道李庭柏的意图） |
| D | 旁观者 / 读者 | 与主角同步或略早 | 桑吉（叙述者）｜太监闲谈 |
| E | 被蒙蔽者 | 完全不了解全局 | 吴家、太监、宫女 |

**本书最常用的信息差结构**：**主角处于 B 级，反派处于 C 级，真正的 S 级是男主**。这解释了为什么本书所有男主都显得"什么都知道却什么都不说"——他们是 S 级信息的持有者，而"不说"本身是权力行为。

## 四、非人形/抽象对抗型说明

**本书不存在非人形反派，也不存在灵气复苏/末世/国运等抽象对抗型设定。** 所有冲突均为**人—人**或**人—制度**。

其中第3章、第8章、第11章属"**人—制度**"型（敌人是军心、是朝廷、是"安国十万大军不能姓宋"），已按制度对抗型处理，见 `剧情/剧情单元-复仇与清算.md` 的对应说明。

## 一、故事核（Stage 2）

**一句话核**：倒贴三年的妻子在新婚夜发现丈夫醉中错唤白月光之名，录音取证后清醒离开，最终被默默守护多年的真爱接住，而迟悟的丈夫已彻底出局。

**核心冲突**：表层是「替身妻子 vs 白月光前任」的情感占位战，里层是「卑微讨好型自我 vs 被认真对待的渴望」的成长命题。韩毅代表「将就式婚姻」的冷漠对照组，江辰代表「珍重型爱情」的救赎对照组。

**情感母题**：替身梗（读者代入憋屈）→ 觉醒（爽感）→ 被偏爱（嗑糖）。母题落点不在「报复渣男」，而在「我值得被认真爱」。

**价值落点**：迟来的真情毫无意义；爱要开口、要珍惜、要偏爱、要无愧于心（江辰婚礼致辞点题）。

## 四、情绪曲线与爆点（Stage 3）

**女主情绪曲线（第一人称内视角）**：
```
期待(新婚) ──↘ 心碎(错唤) ──↘ 死心(录音) ──→ 清醒(医院) ──→ 轻松(桂林) ──↗ 心动(表白) ──↗ 甜蜜(完婚)
```
曲线呈「断崖下跌后稳步爬升」：前半段一次性跌到底（新婚夜），之后不再反复摇摆，符合「觉醒文」不拖泥带水的爽感要求。

**读者情绪曲线**：代入憋屈（N2/N5）→ 爽感释放（N15 离开、N36 拉黑）→ 嗑糖（N48 主动吻、N49 昭告）→ 大团圆满足（N50）。

**爆点分布（4 处强钩）**：
1. **N2 新婚夜错唤**：开篇即爆，一句话奠定全篇「替身」设定。
2. **N5 录音取证**：女主从哭到冷静反击，爽感起点。
3. **N29 医院擦嘴**：白月光亲自喂刀，卑微感顶峰，反衬觉醒必要。
4. **N48 主动吻**：反转蓄力后的情绪释放，嗑糖顶点。

**爆点密度**：约每 12 节点一爆，短篇内张弛有度，无中段塌陷。

## 五、反转机制（Stage 4）

**反转类型**：认知反转（读者对「江辰」身份的认知被颠覆）。

**反转设计**：江辰以「前男友/哥们」身份登场（N22/N39），读者默认他是工具人配角；实则他是暗恋女主多年的真爱。双线反转嵌套：韩毅线「以为放不下林舒 → 最后说只爱笑笑」为假反转（迟悟无价值），江辰线「以为哥们 → 多年暗恋」为真反转（救赎落点）。

**伏笔（setup_clues = 4）**：
1. 同学聚会起哄「江辰当年暗恋你」（N41）。
2. 江辰家唯独放大那张同班集体照（N45）。
3. 送伞往事真相：图书馆贴名伞原以为韩毅送，实为江辰（N47）。
4. 江辰处理伤口时抓住主角手腕「他们说的，其实是真的」（N46）。

**反转回收质量**：四枚伏笔全部在 N40–N47 内回收，无闲置线索；反转服务于「被认真爱」母题，不是为反转而反转。

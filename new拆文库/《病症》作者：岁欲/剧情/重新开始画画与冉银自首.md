# 重新开始画画与冉银自首

| 项目 | 内容 |
|------|------|
| 标题 | 重新开始画画与冉银自首 |
| 类型 | 成长 |
| 概要 | 检查由韩老亲做：人格真伪鉴定通过——分离性身份障碍是真的，身体里共十三个（1 主 + 12 副）。她翻着那张人格记录表：六月龄的黑猫、存活 15 天的克莱因蓝蝴蝶、6 岁的小智、17 岁的孪生兄弟宋莱宋榭、43 岁的许惠柔、27 岁的夏尔澈、32 岁的牙医顾无白、41 岁卖橘子的老墨、28 岁的营养师游暗、23 岁血站的桑遣、30 岁的民警阿烈、22 岁的沈拂南；十二个副人格是在短短六个月里分裂出来的。她追问"那六个月你在哪里"，他当场急性应激、蜷在她脚边只挤出"别、别走"。两个月断联后她给莫奈打电话，说出"鹤遂陪着我"；她认出肖护伪装成救助流浪猫狗的宠物博主，那些伤是他自己弄的。暴雨夜他扛回两袋画具——全是她用过的牌子，一个都没记错——说"念念，重新开始画画吧"。她说"我不能只是活着，而是要为自己活着"，并提出要见冉银。母女隔着一臂远距离坐下，她说"去，自，首"；冉银辩解"我这可都是为了你"，被她一句"是我让你杀的人吗"顶回。她与莫奈回花楹镇跟踪肖护取证，被麻醉针射中前看见了他的眼睛。沈拂南以真面目登门，先想勾引她套证据，被一记耳光拆穿，只得让鹤遂出来。另一边，沈拂南视角的自述（98 章）补全了京佛时期的另一侧：路演、梦中被割腕、镜中的"放我回去"。最后，冉银在生日饭桌上为自己做了半桌菜，说出"吃完这顿饭我就去自首"，母女手牵手走进派出所——"我要自首。" |
| 核心目标 | 让女主完成"为自己而活"的转折，并让母亲这条冲突线以自首（而非和解宣言）收束 |
| 核心冲突 | 她与冉银的最后对峙；并行冲突是与沈拂南的证据博弈、与肖护的取证 |
| 关键信息功能 | 让读者**拿到**人格的量化清单（十三个）与分裂时间（六个月），并让读者**确认**她已从"为母亲画"切换到"为自己画" |
| 读者需求 | 自我觉醒的爽（"去自首"、重拿画笔）+ 认知满足（人格表）+ 虐（麻醉针） |
| 情绪模块ID | EM-003（自我觉醒） / EM-005（人格清单的量化冲击） / EM-006（自首式和解） |
| 套路框架位置 | "自我觉醒"不用宣言而用行为：换画家名、自己报警式地要求自首、独自回镇取证 |
| 桥段标签 | 自我觉醒、破镜重圆（未完成态） |
| 章节范围 | 第91-100章（共10章，约3.8万字） |

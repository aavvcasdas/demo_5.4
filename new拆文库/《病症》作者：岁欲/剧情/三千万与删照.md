# 三千万与删照

| 项目 | 内容 |
|------|------|
| 标题 | 三千万与删照 |
| 类型 | 危机 |
| 概要 | 呕血后是漫长的内出血与抢救：昏迷前他抱住她叫"念念"，醒来却擦着琴弓对冉银说"你想讹人的话还真是找错了对象"。雷夜里她透过门缝看见他打碎镜子和正在流血的指骨；他为被偷拍的她逼男护工交出手机并报警；她恢复自主进食。狗仔解渤腾找上她，开出"让委屈被看见 + 不菲赔偿"的条件，只要照片——她拒绝。她当场给他开价：一张十万、二百张两千万；他眼皮都不眨地回"税后二千万"，条件是打钱、当着面删。她一张张划过那些合照，被"人不能总活在过去"打断，撕碎名片。四年前被旅客拍下的喂猫合照冲上热搜，他一路滴血离开。她的储蓄卡收到三千万；音乐理疗室里他说"我能给的便只有钱"，她当着他的面删掉三百多张照片、清空最近删除，说"我们后会无期"。注：第 65、66 章正文逐字重复，摘要亦重复——本单元两章内容一致，属源文件现象。 |
| 核心目标 | 用一次"明码标价的感情清算"把两人关系降到全书最低点，同时让读者看见他仍在失控（自伤、滴血） |
| 核心冲突 | 她要真相 vs 他只给钱；她要尊严 vs 他给她三千万 |
| 关键信息功能 | 让读者**确认**他仍在乎（呕血时接住她、为她报警、滴血），却**无法解释**为什么态度反复——裂缝继续扩大 |
| 读者需求 | 屈辱与愤怒（三千万买断）+ 心疼（删照半小时）+ 好奇（镜中的他到底是谁） |
| 情绪模块ID | EM-002（以钱代爱的反补偿） / EM-005（自伤与镜子——人格裂缝） |
| 套路框架位置 | "反转打脸"延后：她当场没反转（照片被删），反转留给 81 章之后的多重人格解释；"维权反击"的反面教材——她拒绝用照片维权 |
| 桥段标签 | 反转打脸、维权反击 |
| 章节范围 | 第62-68章（共7章，约2.5万字） |

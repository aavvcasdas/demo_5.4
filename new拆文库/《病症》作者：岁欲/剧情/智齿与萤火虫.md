# 智齿与萤火虫

| 项目 | 内容 |
|------|------|
| 标题 | 智齿与萤火虫 |
| 类型 | 爱情 |
| 概要 | 周念的偏头痛久治不愈，鹤遂上门看她，在井边让她抬头张嘴，用三根手指一路摸到她左边下方最里面那颗横着长的智齿——偏头痛的根源。镇医院里，陈志强拿着一张蓝底二寸照找她问话，她认出那是语文老师李丽芳，也认出这正是父亲出轨线里的人。拔牙时她吓得坐起来喊他的名字，他伸出一只手臂说"抓着就不怕了"，并在麻药生效后低低徐徐讲起一个女生的故事：被母亲嫌弃、被上司 PUA、卖身求业绩、杀夫诈保、杀掉情夫与同事换取身份，最后把生下她的母亲推下悬崖。牙拔完，他向医生索要那颗牙齿："我要。"——那是半年后他十八岁的生日礼物。夜里他带她去郊外稻田看萤火虫，只因为她随口提过一次；他把故事讲完（书名《绝叫》），却被一只吸附在小腿上的蜱虫打断——周念崩溃大哭，说出父亲周尽商就是被蜱虫咬后死于病毒感染。医院急诊确认无碍后，他在昏暗巷中抱住她，落下第一声"念念"，答应"不会，永远不会"。 |
| 核心目标 | 把两人之间最重要的两件信物（智齿项链与萤火虫）一次性立起来，并把《绝叫》这个"杀夫骗保"的故事预先摆进读者脑中 |
| 核心冲突 | 她对"意外致死"的创伤（蜱虫）vs 现实再次送来蜱虫；外部是陈志强对李丽芳的追问（保险线的线索） |
| 关键信息功能 | 让读者**预置**一个故事模板（杀夫骗保），好在 8 章后认出周家的真相；同时让读者**误判**蜱虫只是意外 |
| 读者需求 | 甜（抓萤火虫、"我当了真"）+ 陪伴感（他记得随口一句话）+ 恐惧（蜱虫与父亲的死） |
| 情绪模块ID | EM-004（行动派式宠爱） / EM-001（蜱虫→杀夫真相的伏笔链） |
| 套路框架位置 | "信物"套路的最高密度段：一次单元内立起两件信物（智齿、萤火虫），且都由"他主动索取/主动兑现"完成，不做任何解释性独白 |
| 桥段标签 | 信物（表外补充）、双向奔赴（表外补充） |
| 章节范围 | 第41-42章（共2章，约1.1万字） |

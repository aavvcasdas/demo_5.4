# 四年后·京佛重逢与否认

| 项目 | 内容 |
|------|------|
| 标题 | 四年后·京佛重逢与否认 |
| 类型 | 主线 |
| 概要 | 四年后，22 岁的周念躺在京佛精神卫生中心，168 的个儿只有 58 斤，浑身只剩一层皮，器官全线告病；神经性厌食症是精神科死亡率最高的病（5%—20%），而她只关心"我什么时候能出院"——七十斤就能去找他要答案。莫奈已成五十多万粉丝的吃播博主。她反复看那条营销号爆料："影帝鹤遂被私生骚扰"，评论区让她去死。搜索引擎里是另一个人的四年：2014 年《屠佛少年》金鸡最佳男主、11 亿票房；2015 年《灭》金马金像双影帝；2016 年《六十六道》戛纳影帝；4287.6 万粉丝。她在微博留言"鹤遂，祝你生日快乐"。她质问给鹤广买别墅、每月给上百万生活费的鹤广，得到"他早把你给忘了"和一句致命的"那天他和生导谈的时候，我就在旁边"。病房里住了双相的裴巷与精神分裂的徐散，主任亲口交代要安排一位 VIP 患者与裴巷同房——清晨她伸手握住那只温凉的手，回头的人却用"周小姐？"和"还想握多久"把她钉回现实。他是为了下一部精神病人题材的电影提前一个月入院体验。她走到他面前索要答案：记不记得她、6 月 9 日为什么没来、为什么丢掉她的信——他答"那些都已经不再重要"，她笑着笑出眼泪，然后喷出一大口鲜血。 |
| 核心目标 | 让"他忘了她"在读者心里被坐实，同时留下若干无法解释的裂缝（手腕纱布、礼物、"心理干预理疗室"） |
| 核心冲突 | 她要一个答案 vs 他用"周小姐"的称呼与"不再重要"系统性否认 |
| 关键信息功能 | 让读者**误判**他是负心人（后被多重人格推翻），并让读者**察觉**若干不一致（他为何在此、为何受伤、为何说"周小姐"） |
| 读者需求 | 屈辱与心疼（当众否认、"私生"标签）+ 认知好奇（裂缝）+ 极致的虐 |
| 情绪模块ID | EM-001（失约缺口的第一次索债失败） / EM-005（裂缝即多重人格的入口） |
| 套路框架位置 | "马甲掉落"的延迟版：读者已知道他是顶流，但不知道这具身体里换过人；否认戏全部由副人格演出，为 78 章的揭底蓄压 |
| 桥段标签 | 马甲掉落、追妻火葬场 |
| 章节范围 | 第56-61章（共6章，约2.5万字） |

# 山火证据·让鹤遂回来·破冰

| 项目 | 内容 |
|------|------|
| 标题 | 山火证据·让鹤遂回来·破冰 |
| 类型 | 复仇 |
| 概要 | 霍闯送来一只迷你猪"线面"，请莫奈曝光仍在发生的校园霸凌；周念把四年前那段视频里的抽烟人影放大，认出是鹤广——再把山林、水库、4 月 9 日下午起火、烟头火因串起来，锁定当年烧了七天七夜、牺牲二十七名消防员的那场山火。她给沈拂南发一条短信："你想永远摆脱鹤广吗？"唯一条件是方法只和鹤遂谈。三日后沈拂南染着白金色头发登门，先想勾引她套证据被一记耳光拆穿；她用韩老说过的人格压制关系反将——"你在害怕什么"，并当面掐着脖子逼主人格现身："这如果是一场游戏，那么玩家只能是鹤遂。"换来的是他一句"不敢"。他走神、听不进正事，只说"你能不能陪着我"；画室里他隔着画一厘米停下手指，红了眼说"我只是高兴"。她把山火视频交给他去报警，出门即是风暴——整个花楹镇看着"疯狗"回来。派出所里他全程只答不多说，只在离开时问"确定是他放的火，能判死刑么？"。夜里他跳进南水河泡了三个小时找那颗被她"扔掉"的智齿，她终于从包里翻出项链——当年是骗他的。她问他愿不愿意做人格整合让沈拂南消失，"只要他消失，我们就还能是我们"；他答应"好，我会杀了他"。暴雨里她主动送上双唇。此后是迟来的日常：小商铺五子棋的赌注是货架上那包已停产的白兔奶糖，他第一次正儿八经地说"我这辈子，都只喜欢你一个"；保鲜膜里裹的原来是她当年送他的那颗橘子；暗巷墙角的"两下"；韩青实名举报善进学院的新闻被他听见时，眸底酿出寒意。 |
| 核心目标 | 让两人正式复合，并把鹤广的清算交给证据与制度 |
| 核心冲突 | 她要"让鹤遂出来" vs 沈拂南的抵抗；内部冲突是他"不敢"出来 |
| 关键信息功能 | 让读者**确认**赌约真相（"输的人永远消失"在下一单元才揭）与善进线索的第一次落地（韩青举报） |
| 读者需求 | 甜的迟到兑现（缝扣子、白兔奶糖、公开告白）+ 爽（报警取证）+ 好奇（善进） |
| 情绪模块ID | EM-002（迟来补偿转为双向） / EM-004（破冰） / EM-007（取证维权） |
| 套路框架位置 | "维权反击"三步走（录像 → 报警 → 问刑期）；"破镜重圆"用日常物件（纽扣、奶糖、橘子）而非宣言完成 |
| 桥段标签 | 维权反击、反转打脸 |
| 章节范围 | 第101-108章（共8章，约3.7万字） |

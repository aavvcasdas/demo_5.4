# 公开恋情·善进的六个月

| 项目 | 内容 |
|------|------|
| 标题 | 公开恋情·善进的六个月 |
| 类型 | 谜团 |
| 概要 | 关灯后的笑话、"二年起步"与"我能忍住"之后，凌晨 2 点 34 分他用四千万粉丝的大号公开她："我喜欢了她四年，她现在是我的女朋友 @一起逃亡吧"——一夜掉了九十万活粉。第一次之后，浴室里沈拂南暴怒咆哮，赌约的真相被掀开：输的人不是消失三个月，而是**永远消失**；他赌"你死在这个夏天"，她赌"你爱我"。韩青加来微信：高考结束那晚她亲眼看见鹤遂被人抬进善进学校，他爸爸跟在几个教官后面。周念把"善进学院"四个字对着他，他没有说一个字，只说"什么都别问，抱我行吗"。派出所询问室里，卢国强抱来一个纸箱：三百多张从不看镜头的照片、两本不同名字的无偿献血证（2012 年 11 月 13 日是他、2013 年 6 月 9 日借林强的身份证）、一整页"预计花销"清单（地下室 300/月、学费 10000/年、她的住宿费 1500/学期、生活费最低 2000/月……），以及四次共一千八的卖血。监控录像揭开那 197 天：没开灯的黑屋、赤身的少年、一句"周念在哪里""我要见她"、五个教官与再也没能站起来的那一跪、踩断的手与撒尿羞辱后那个"找"、十三天禁食与墙角刻下的"念""念念""周吴郑王的周，念念不忘的念"、一百二十六次电击，最后是替他向鹤广认错、把他救出去的沈拂南。日记本《我和身体共用者们的对话选段》里，十二个副人格逐一被归因为她：白裙子前的黑猫、他亲手掐死的蝴蝶、等一个会画画的人的小智、她惋惜过的奖状、她想开的宠物店、她拔牙时手重的牙医、她送过的橘子、她的营养与她的血、扒手偷走的那封信。"我的十三级病症无药可医，念念，你要救我，还是要毁灭我。" |
| 核心目标 | 把全书最后一个黑箱（那六个月）完整打开，并把十三个副人格全部归因为她 |
| 核心冲突 | 他"怕她看见那些东西后不要他" vs 她"我要在这里陪着鹤遂" |
| 关键信息功能 | 让读者**拿全**所有答案：6 月 9 日的失约、卖血的钱、善进的遭遇、人格的来源；同时**确认**被扒手偷走的信解释了"他为什么丢掉她的信" |
| 读者需求 | 认知满足（全答案）+ 极致的虐与心疼（监控录像）+ 被爱的确认（十三个副人格都因她而生） |
| 情绪模块ID | EM-001（失约真相的最终兑现） / EM-005（人格溯源） / EM-002（以命为注的补偿） |
| 套路框架位置 | "马甲掉落"的最终形态：掉的是创伤本身；谜底不是"谁做的"而是"他为了见你变成了什么" |
| 桥段标签 | 马甲掉落、复盘解谜、公开示爱（表外补充） |
| 章节范围 | 第109-115章（共7章，约3.2万字） |

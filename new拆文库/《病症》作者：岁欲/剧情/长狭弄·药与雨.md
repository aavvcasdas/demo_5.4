# 长狭弄·药与雨

| 项目 | 内容 |
|------|------|
| 标题 | 长狭弄·药与雨 |
| 类型 | 危机 |
| 概要 | 冉银去市里处理保险理赔，周念独自在家两天，第一次体会到"三餐不用在她注视下完成"的自由，却被新阳保险业务员陈志强找上盘问"你爸爸之前和其他的阿姨走得近吗"，她逐条驳回。深夜她撞见肖护一伙神色慌张逃出巷子，跑进漆黑小巷看见鹤遂侧身蜷在血泊里、腹部被捅——手边是一卷未拆封的保鲜膜。她用针织衫按住那道五厘米的伤口，在他耳边碎碎念"你别死啊鹤遂"，泪水落进他的耳廓。住院期间她替他挡下肖护父亲肖福的踹门问罪，第一次被人承认"我从来没有这么勇敢过"，并得到他覆顶的一句"嗯，你保护了我"。她用窗外被狂风摧折的蓝花楹固定他的姿势，画出冷色调油画，唯一暖色是她凭空添上的"回流的鲜血"，画角写下两个字《病症》。画作带回家被冉银一眼认出画中人，她靠"凭记忆画人"的既有人设骗过。单元末，他撞见她隔衣显形的每一块骨头，说"你已经很瘦了，所以多吃点"——她第一次主动想停止催吐却失败，用老人机发出四个字："我失败了。" |
| 核心目标 | 让两人的关系从"她单向靠近"变成"互相救命"，并把她的病症从私密行为推到"被他看见"的边缘 |
| 核心冲突 | 周念的催吐秘密 vs 鹤遂的观察与追问；外部冲突是肖护的刀、肖福的问罪、冉银的验收 |
| 关键信息功能 | 让读者**确认**两人已互为唯一（救命/挡祸），同时让读者**等待**她被看穿的那一刻；保鲜膜之谜作为全书最长的一根伏笔在此埋下 |
| 读者需求 | 安全感（他接住她、保护她）+ 心疼（一个人扛住所有）+ 期待（秘密何时暴露） |
| 情绪模块ID | EM-003（体重/身体的计分板） / EM-004（关系升温） |
| 套路框架位置 | "救赎"套路的对称化：上一段她救他（按压伤口、叫救护车），这一段他救她（挡肖福、第一次肯定她的勇敢），互为救命者后感情线才成立 |
| 桥段标签 | 信息差、自我觉醒 |
| 章节范围 | 第12-22章（共11章，约4.4万字） |

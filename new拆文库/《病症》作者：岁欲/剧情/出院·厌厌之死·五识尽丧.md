# 出院·厌厌之死·五识尽丧

| 项目 | 内容 |
|------|------|
| 标题 | 出院·厌厌之死·五识尽丧 |
| 类型 | 危机 |
| 概要 | 生雅娇与生东返到访病房，身穿高定西装的他被拉去拍照，摔倒在地无人理会，郁成一句"神经病一个"把她的处境写到最惨。她扶墙去求主治医生王学知出院被拒（"体重还没到七十"），她说"可是我不想治了"。走廊上她追问他当初是否有苦衷，只换来"我以为，我已经把话说得很清楚了"和一句"小事"；楼梯通道里他掐着她的下巴说"三千万都买不了你闭嘴"，随即扯断颈间黑绳，把那颗智齿扔还给她："不就是一颗破牙齿？"离开京佛一个多月后她回到花楹镇，家门被人泼了红油漆、摆着花圈和写着她名字的寿衣。肖护出狱了，在长狭弄羞辱她；三天后家门口出现一个箱底浸血的纸箱——被剥皮的厌厌已经咽气，她在宠物医院双膝跪地，然后瞎了。此后她的世界只剩红与黑：心因性失明、失去味觉（八宝粥喝成白粥）、除夕夜发现听力不中用、冻紫手脚也不觉得冷、香皂再无清香——五识尽丧。郁成上门索要智齿项链，"没有那条项链，我没办法参加下个月的奥斯卡颁奖礼"，她说早就扔掉了。 |
| 核心目标 | 把女主推到全书最低点（五识尽丧），并让"智齿项链"从感情信物变成一条待解释的线索（为什么要回？） |
| 核心冲突 | 她与世界（网暴、邻里、肖护）的全面失联；内部冲突是她已不打算活 |
| 关键信息功能 | 让读者**确认**苦难已达极限（为下一段"他回来了"蓄压），并让读者**追问**项链与奥斯卡的关联 |
| 读者需求 | 极致虐（厌厌之死、失明）+ 愤怒（网暴与寿衣）+ 悬念（他为何要回项链） |
| 情绪模块ID | EM-001（缺口到此最深） / EM-005（项链与奥斯卡的绑定 = 人格线的物证） |
| 套路框架位置 | "虐身虐心"不做无用消耗：每一次丧失都精确对应一个感官通道，为后面"五感逐一恢复"预设五个可交付的甜点 |
| 桥段标签 | 虐身虐心（表外补充） |
| 章节范围 | 第69-72章（共4章，约1.6万字） |

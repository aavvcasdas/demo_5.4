# 当众走向他·告白与手机

| 项目 | 内容 |
|------|------|
| 标题 | 当众走向他·告白与手机 |
| 类型 | 爱情 |
| 概要 | 快递驿站老板娘刘春花当街造宋敏桃的黄谣，鹤遂现身抢回快递并一句一字地警告她"再给我妈造黄谣"；周念在流言变形的当晚发出"你还好吗？"，最后送出十个字——"我相信你，也相信你妈妈"。校园线同步升温：他在学校外墙做防盗作业被女生围观，韩青当众讥讽莫奈、逼周念"过去找他说话"，打赌升级为"要到他的手机号"。周念在全校注视下走到木梯下，当众要号并免提拨通验证，他接起一句"……哪位？"引爆全场；随后他端走罗强给她的那碗冰汤圆并塞给对方二十块。雨天的巷口他第一次撑伞等她，房间里露出三本厌食症的书，她说出"每次催吐都有报复的快感"，他答"该看病的人是你妈"，并教她刺向母亲的阿喀琉斯之踵。她第一次赖床反抗冉银；为霍闯出头时他问"我们现在什么关系"，答案是"你以后能在我手术书上签字的关系"。黑网吧对峙后他承认"他说得完全没错"。手机店老板用下流话议论她，他用重拳换来一部一千八的手机；她注册微信号 ZNHS1314（周念鹤遂一生一世），拍下第一张合照。 |
| 核心目标 | 让两人的关系被公开确认（校内）与被彼此确认（告白），并把"刺向阿喀琉斯之踵"写成她的反抗纲领 |
| 核心冲突 | 全镇的污名与校园的敌意 vs 两人越来越难以掩饰的靠近；内部冲突是他不允许任何人说她不好 |
| 关键信息功能 | 让读者**确认**"我相信你"十个字的分量（他记了一辈子），并让读者**误判**他打架只是脾气（动机到单元末才半透） |
| 读者需求 | 优越感与爽（当众要号、免提验证、黑网吧一脚踹飞椅子）+ 甜（撑伞等她、告白、合照） |
| 情绪模块ID | EM-002（以小搏大的公开反证） / EM-004（告白与甜顶点） |
| 套路框架位置 | "打脸"桥段的两次变形：① 她当众走向被所有人嫌弃的他（打脸的是围观者）② 他当众接她的电话（打脸的是挑衅者）；"公开示爱"由第三方小孩（霍闯）戳破 |
| 桥段标签 | 打脸、公开示爱（表外补充） |
| 章节范围 | 第34-40章（共7章，约3.0万字） |

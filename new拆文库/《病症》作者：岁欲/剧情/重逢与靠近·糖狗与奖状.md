# 重逢与靠近·糖狗与奖状

| 项目 | 内容 |
|------|------|
| 标题 | 重逢与靠近·糖狗与奖状 |
| 类型 | 爱情 |
| 概要 | 出院后的鹤遂在南水街小吃店打工，对当众打招呼的周念全程冷待——"跟你有什么关系？""和你有关系？"两次硬顶。她打听出他三点下班，花八块钱转转盘转到一只糖小狗，追着他跑进小巷摔倒，他折返蹲下扶她。她耍赖要他收下糖狗，换来第一次进他的家门与他的房间：桌面玻璃下压满橘红色奖状（2013-2014 学习标兵、2015 三好学生、2016 高一男子 1500 米第一），她哽咽着说他不上学太可惜，被他逼到桌沿问"是不是我给你脸"，闭着眼等来的却是额头轻轻一弹——那是他第一次没有防备的笑。此后她每周以画画为借口找他：雨雾天里他擦门上的红油漆，她抢过抹布说"我的手又不是只能画画"；一只克莱因蓝蝴蝶落在他肩上，旁白预告他后来亲手杀死它、由它腐烂；宋敏桃说出他不肯念书的真相——为护母亲不被催收骚扰，且"不仅仅是因为催收"；两人在杏子树下写生，废稿画纸盖在他脸上，那双眼其实大部分时间都是睁开的，一直在听她画笔的沙沙声。 |
| 核心目标 | 把关系从"救命恩人与被救者"推到"互相进入对方的生活"，并让他的辍学之谜只揭开一半 |
| 核心冲突 | 他的"离我远点"式保护（要求保密来往）vs 她越来越难以压抑的靠近；内部冲突是他对"被夸"的过敏 |
| 关键信息功能 | 让读者**误判**他的冷待是厌恶（后被"变态辣炒面"推翻），并让读者**确认**奖状与辍学的落差，为他的"没有以后"埋线 |
| 读者需求 | 甜（糖狗、弹额头、追打拥抱）+ 心疼（擦门、奖状、半夜擦油漆）+ 安全感（"你可是第一个"） |
| 情绪模块ID | EM-004（甜—推开—更甜） / EM-001（他"没有以后"的预叙） |
| 套路框架位置 | "追妻火葬场"的前置反向版：冷淡方是男主，且冷淡是保护而非厌恶，靠第三方视角（闪回辣椒）让读者先于女主知道真相 |
| 桥段标签 | 追妻火葬场（反向运用）、日常甜（表外补充） |
| 章节范围 | 第23-29章（共7章，约2.7万字） |

# 黄谣·出庭·失约的火车站

| 项目 | 内容 |
|------|------|
| 标题 | 黄谣·出庭·失约的火车站 |
| 类型 | 危机 |
| 概要 | 暴雨里周念用他英语单词本的最后四线三格纸写了一封信，约定"等你带我逃出小镇那天才能看"。冉银报警称鹤遂"诱骗强奸"，警察破门把他按在地上带走；医院检查结果证明她清白，但第二天全镇都在说"那条疯狗强奸了周家乖乖女"。她拿到法院传票，隔着递来的 110 说出"你去自首吧"，冉银举菜刀切下自己的一根手指。法庭上她条理清楚地作证，肖护被判四年零八个月，右脸上留着鹤遂咬出的深坑。大巴上两人定下出逃计划：京佛美院、从县城到火车南站、6 月 9 日 23:15 的 K8939。她以联考 292 分、京佛校考双第一成为全镇的骄傲。6 月 8 日凌晨他递来两张淡红色火车票，交代完路线说"我还有一点事""检票前我肯定到"。次日她背着登山包、抱着那株万年青在站外台阶上等，从九点等到十一点，电话由无人接听变成关机；播报宣布停止检票。雨里一个路人随手扔掉一页纸——正是她写的那封信。她在台阶上等了一整个通宵，凌晨五点半栽倒在积水里，耳边全是幻听里的"我会带你逃出这个小镇""我们万年长青"。「上卷完」 |
| 核心目标 | 兑现前面所有承诺（出庭、考试、逃亡计划），然后在最后一刻让男主缺席，把全书主问题钉死 |
| 核心冲突 | 冉银的报警与黄谣 vs 两人的清白；终极冲突是"他到底会不会来" |
| 关键信息功能 | 让读者**误判**他失约（后由 119 章推翻：他被鹤广一棒打晕、信被扒手偷走），并让读者**等待**一个推迟 64 章才兑现的答案 |
| 读者需求 | 屈辱与愤怒（黄谣、强奸指控）+ 爽（庭审作证、双第一）+ 极致的失去（雨夜台阶） |
| 情绪模块ID | EM-001（全书总缺口在此成立） / EM-007（庭审维权的迟来必然） |
| 套路框架位置 | "打脸"桥段的滞后兑现：黄谣当场不反打，靠三章后的法庭判决与成绩反转；"破镜"在许诺的同一夜发生，甜（初吻 + 万年长青）被放在断裂前一章 |
| 桥段标签 | 打脸、偏心打脸、破镜难圆 |
| 章节范围 | 第53-55章（共3章，约1.5万字） |

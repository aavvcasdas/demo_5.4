# 杀夫真相与逃亡之约

| 项目 | 内容 |
|------|------|
| 标题 | 杀夫真相与逃亡之约 |
| 类型 | 谜团 |
| 概要 | 断联后周念生了一场经久难愈的心疾：厌食复发、体重从 82 斤掉到 74 斤、幻听与偏头痛齐来，莫奈送她的《绝叫》正是一个"不会再回来的人"讲过的故事。冉银逼她画画，争执中她剥开母亲把自己未竟的画家梦压在女儿身上的真相，冉银失控喊出"我把周尽商给杀了""蜱虫是我放的"。第二天冉银站在十九年前的太阳下讲完全部来龙去脉：才女画家与电工周尽商的婚姻如何被两千八的工资磨成一地鸡毛，李丽芳如何拿着怀孕检查单上门，她如何趁他熟睡把蜱虫放进被窝、喂感冒药、延误送医，又如何借上门推销的陈志强买下两份千万保额保单——一千六百万赔偿金明天到账。周念赤脚逃出家门，一路跑到南水街那扇木门前，跌坐在曾与他同坐的门槛上哭；罗强告诉她他不会再回来。她在南水河边被他抱起，却换来一句"换谁都一样"，于是转身跳进河里——他骂着"疯子"跳下来救她。上岸后她只给两个选择："要么带我走，要么让我死。"他俯身问"背你走，还是抱你走"。在他家里她洗去豆蔻香、穿上他的黑 T，说出"我妈妈也是"，他抱住她说"念念，你还有我"，许下"我会带你逃出这座小镇"。 |
| 核心目标 | 让女主的逃亡动机从"想和他在一起"升级为"必须逃离一个杀人犯母亲"，并把逃亡约定钉死 |
| 核心冲突 | 冉银（掌控 + 命案）vs 周念；以及她以死相逼 vs 他"不能带你走"的理性 |
| 关键信息功能 | 让读者**认出**第 41 章预置的《绝叫》模板，完成"故事→现实"的一次认知反转；同时让读者**确认**逃亡承诺已经成立 |
| 读者需求 | 认知反转（杀夫骗保就在自己家）+ 窒息 + 绝境中的安全感（"你还有我"） |
| 情绪模块ID | EM-001（逃亡承诺 = 下一次失约的债） / EM-006（窒息的爱与命案） |
| 套路框架位置 | "身份揭穿"用在母亲身上：揭穿的不是血缘而是道德身份；"复仇"情绪被转移到"逃亡"这个更弱者的选择上 |
| 桥段标签 | 身份揭穿、复仇、自我觉醒 |
| 章节范围 | 第49-52章（共4章，约1.5万字） |

# 灌油·79斤与秘密暴露

| 项目 | 内容 |
|------|------|
| 标题 | 灌油·79斤与秘密暴露 |
| 类型 | 成长 |
| 概要 | 莫奈请周念喝珍珠奶茶，两人在石桥上撞见冉银——奶茶脱手落地，塑料杯炸开。回家后冉银提来一桶 5L 食用大豆油，把桶口对准她的嘴强灌，逼她用油把奶茶全部吐出来，还留下"朋友是最没用的东西""总有一天你会理解妈妈的"。第二天称重，她靠灌水作弊仍只有 79.20 斤（自身仅 76 斤），幻听第一次出现，第一次出现"就这样病下去"的放弃感。公厕挂上"维修中"的牌子，她忍着随时要栽倒的感觉一路走到南水街，捂着胃拍响鹤遂家的大门——门从里面拉开，刚洗完澡的鹤遂再一次接住了她，而她当着他的面呕了出来。他逐样报出她早餐的内容，追问"你真能吃这么多？"，随后有条不紊清扫门口、在厕所里替她握住头发，两人昏黄灯泡下的对视成为她此生难忘的一瞬。他说"我很庆幸，发现的是我，而不是其他人"。雨后杏子熟了，他从一兜杏子里挑出最酸的那一颗给她，说"这比不上人的胃酸"——她承认自己有病，两人约定互相保守秘密；他给小黑猫取名"厌厌"（厌世的厌）。 |
| 核心目标 | 让她的秘密从"独自扛"变成"被他知晓"，并把病症从行为层面推进到器官层面（幻听、昏倒） |
| 核心冲突 | 冉银的灌油式控制 vs 周念仅剩的自救本能；核心转折是她的秘密对鹤遂暴露 |
| 关键信息功能 | 让读者**确认**冉银的控制已达暴力级（灌油），并让读者**拿到**"她病得更重了"的量化证据（79.20 斤 / 76 斤 / 幻听） |
| 读者需求 | 窒息与愤怒（灌油）+ 心疼 + 被理解（他第一反应是庆幸而非嫌弃） |
| 情绪模块ID | EM-003（体重与身体的计分板） / EM-006（窒息的爱） |
| 套路框架位置 | "偏心打脸"转"自我觉醒"的中间态：她还没有反抗能力，反抗先由身体完成（呕吐、幻听、昏倒） |
| 桥段标签 | 偏心打脸、自我觉醒 |
| 章节范围 | 第30-33章（共4章，约1.4万字） |

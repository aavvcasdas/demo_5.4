> 权威范围：读者需求 / 情绪引擎 / 套路框架运转 / 可复现模块。禁止把原文具体桥段当模板照搬。
> 重建说明：基于 119 章全量逐章摘要（3020 情节点）重建，模块来源标注到 `节奏.md` 的 RH/TR 或具体章节。

## 读者需求 / 情绪引擎

| 读者需求 | 本书满足方式 | 证据章节/情节点 | 持续追读机制 | 可迁移边界 |
|---|---|---|---|---|
| 被理解（我也有说不出口的病） | 全书不解释"厌食症"这个词，只给称重、催吐、灌油、幻听的动作链，让读者自己命名 | 第8、11、30、31章 | 每一次体重数字下降都是一次新的可量化心碎 | 可保留"用行为链代替诊断名词"；必须替换病症类型、数字体系与家庭结构 |
| 心疼（被亏欠的那一方） | 让男主在被误解时不辩解，真相由物证（智齿项链、献血证、监控录像）分期交付 | 第1、61、113、114章 | 每交付一件物证，就立起"还有一件没给"的新缺口 | 可保留"沉默的主角 + 分期物证"；必须替换物证形态与时间跨度 |
| 认知反转（他不是我以为的那个人） | 三层误判依次推翻：负心人 → 有人格 → 人格是因她而生 | 第55章 → 第78章 → 第115章 | 每推翻一层，读者会重新给前面 50 章的行为重新赋值 | 可保留"误判分层推翻"；必须替换病症名、人格机制与归因方式 |
| 迟来的补偿 | 补偿从不兑现为钱，而是兑现为身体（卖血、挨打、自伤）与身份（公开恋情） | 第113、114、109章 | 补偿每兑现一次，赌约的代价就更重一层 | 可保留"补偿以代价而非礼物呈现"；必须替换代价类型与公开方式 |
| 关系补偿（被坚定选择） | 两次"当众"：她当众走向他（36章）、他当众公开她（109章） | 第36、109章 | 第一次由她承担风险、第二次由他承担风险，形成对称 | 可保留"双向各承担一次公开风险"；必须替换场合与代价量级 |
| 安全感（有人无论如何都在） | 反复出现的"接住"动作：晕倒被接住、摔倒被扶起、跳河被救起、呕吐被托住 | 第11、24、31、51、62章 | 每次她下坠，都有同一双手 | 可保留"重复同一动作作为关系锚"；必须替换动作与触发场景 |
| 正义的迟到兑现 | 反派全部由证据与制度清算，不靠主角私刑 | 第54、97、105、119章 | 每个反派的倒计时不同，错开交付 | 可保留"取证—报警—判决三步走"；必须替换罪名与取证手段 |

## 故事框架与套路运行图

| 框架/套路 | 在本书中的位置 | 运行方式 | 为什么有效 | 失效风险 |
|---|---|---|---|---|
| 失约缺口（本书的总引擎） | 第55章成立，第119章解释 | 铺垫 54 章建立承诺 → 一夜失约 → 拖 64 章分期给答案 | 缺口越大，读者对每一次"接近真相"的付费意愿越高 | 铺垫不足就失约会变成作者耍赖；答案必须比缺口更重 |
| 追妻火葬场 | 第56-119章（反向：男主是冷淡方且冷淡有因） | 否认 → 迫害感 → 苦衷分层揭示 → 以命为注 → 重新选择 | 把"追"变成"解谜"，补偿行为本身就是证据 | 若苦衷轻于伤害，读者不会原谅；本书用 197 天 + 126 次电击把苦衷做到足够重 |
| 马甲掉落（延迟 40 章版） | 第61章埋裂缝 → 第78章命名 → 第91章量化 → 第115章溯源 | 同一具身体里换人，读者先以为是性格问题 | 掉的不是身份而是人格，反转层级比普通马甲深一级 | 需要医学/规则自洽，否则变成圆谎；本书靠仪器鉴定与人格清单自洽 |
| 以小搏大（公开反证） | 第36、109章 | 弱者在公开场合用一件无法反驳的物/事反证 | 旁观者数量越大，爽感越强 | 若无见证者或代价不对称，会变成霸凌 |
| 破镜重圆（双向成就版） | 第105-119章 | 复合后不黏合，而是各回各的位置（她上学、他进组） | 保留各自的价值坐标，关系才可信 | 若一方为另一方放弃全部，会回到依赖型旧模式 |
| 自我觉醒（物件版） | 第91-100章 | 换画家名、要求母亲自首、独自回镇取证，不用宣言 | 行为比宣言更难撤回，可信度更高 | 若觉醒后立刻成功，会显得廉价；本书让她先被麻醉针放倒 |
| 窒息的爱与自首式和解 | 第30、49、99章 | 施控者最终自我觉醒，惩罚权交给法律而非受害者 | 受害者不必承担"原谅"的道德负担 | 若写成受害者主动原谅，会失真；本书让母亲先自首、女儿才叫出那声妈妈 |
| 维权反击（取证—报警—判决） | 第54、97、105、119章 | 录像/监控/日记 → 报警 → 刑期 | 爽感来自"迟到的必然"，不来自暴力 | 若取证过程太顺，会失去紧张感 |

## 可复现模块卡

### EM-001 失约缺口（本书总引擎）

| 字段 | 内容 |
|---|---|
| 读者想看什么 | "他明明承诺过，为什么没来"——一个可以被推迟很久、但必须被兑现的答案 |
| 情绪链 | 承诺（甜顶点）→ 失约（急坠）→ 追索失败（屈辱）→ 分期线索（希望）→ 全答案（释然与更深的疼） |
| 戏剧单元 | 在最甜的那一夜让承诺方缺席，把"为什么"改造成全书的付费点 |
| 关键触发物 | 可替换功能位：承诺物（车票/信物）、失约现场（车站/门口）、追索对象（已变身的旧人）、分期线索（物证 n 件） |
| 复现步骤 | 1. 用至少一卷篇幅把承诺做成"唯一出路" 2. 失约当天不给任何解释视角 3. 让追索方当众被否认一次 4. 每 10-15 章交付一件物证 5. 最后一件物证同时解释"为什么"和"他做了什么" |
| 可替换项 | 承诺内容、失约场景、变身方式（成名/失忆/身份）、物证形态、间隔章数 |
| 不可照搬 | 火车站 + 智齿项链 + 万年青的具体组合；多重人格这一具体病因 |
| 关联节奏 | `节奏.md` TR-008（第55章）、TR-017（第119章）、RH-009 |

### EM-002 迟来补偿（代价型）

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 亏欠方拿出的补偿必须让"钱"显得廉价——他要交出的是身体、名誉或时间 |
| 情绪链 | 亏欠（已知）→ 用钱打发（被拒绝）→ 展示代价（震惊）→ 以命为注（恐惧）→ 双向成就（满足） |
| 戏剧单元 | 被亏欠者开出价码，亏欠者不砍价地加码，代价却由第三方物证（清单、伤疤、录像）揭出 |
| 关键触发物 | 可替换功能位：价码（金钱/条件）、代价物证（票据/伤疤/记录）、见证者（医生/长辈/同事） |
| 复现步骤 | 1. 先让亏欠方用最容易的方式补偿并被拒 2. 让被亏欠方主动开价，把羞辱感推到顶 3. 用一件不带情绪的物证揭出真实代价 4. 让代价与主题绑定（他的代价就是"想见她"） |
| 可替换项 | 价码形式、物证类型、代价内容（血/时间/名誉/自由）、揭出者身份 |
| 不可照搬 | 三千万删照、"预计花销"清单与四次卖血的具体组合 |
| 关联节奏 | `节奏.md` RH-010、TR-013、TR-016 |

### EM-003 身体计分板（自我觉醒）

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 一个能被量化的崩坏过程，以及崩坏者最终把计分权拿回自己手里 |
| 情绪链 | 数字被他人定义 → 数字持续恶化（可量化的心碎）→ 秘密被撞见 → 谷底（感官逐一丧失）→ 重新为数字命名 |
| 戏剧单元 | 用公开可见的计量（体重/分数/排名）承载私密痛苦，最后用"换名字"取回主权 |
| 关键触发物 | 可替换功能位：计量单位、监督者、作弊方式、恶化信号（幻听/昏倒）、回收动作（改名/重新参赛） |
| 复现步骤 | 1. 给痛苦找一个可被他人读取的数字 2. 每次数字恶化都配一个生活细节 3. 让最在意的人撞见作弊或恶化 4. 谷底之后用一个"重新命名"的行为收尾 |
| 可替换项 | 计量体系、监督者身份、感官丧失顺序、重新命名的载体 |
| 不可照搬 | 82 斤/79.20 斤/58 斤的具体数字链；五识尽丧的具体顺序 |
| 关联节奏 | `节奏.md` TR-004、TR-011 |

### EM-004 靠近—推开—迂回接受（信物锯齿）

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 一个"嘴上说不要、身体很诚实"的对象，且每次迂回都由一件小物件证明 |
| 情绪链 | 靠近（被骂）→ 推开（关门/冷待）→ 迂回证据（翻垃圾桶/加辣椒/偷偷看她）→ 读者先于女主知道 → 甜 |
| 戏剧单元 | 用第三方视角或闪回提前把"推开"翻转为"保护"，让读者的知情领先女主一步 |
| 关键触发物 | 可替换功能位：第一次给出的东西、被丢弃的地点、找回的动作、知情领先的揭穿方式 |
| 复现步骤 | 1. 让主动方给出一件廉价但唯一的东西 2. 让拒绝方当着面丢弃 3. 私下找回（不给主角视角） 4. 隔几章由第三人或闪回揭穿 5. 用"你可是第一个"之类的半句话确认 |
| 可替换项 | 物件、丢弃方式、找回方式、揭穿视角、锯齿次数 |
| 不可照搬 | 橘子 + 垃圾桶 + 保鲜膜的具体组合；"跳跳糖/青苹果味"的具体味觉符号 |
| 关联节奏 | `节奏.md` TR-002、TR-006、RH-003 |

### EM-005 人格揭底（延迟版马甲掉落）

| 字段 | 内容 |
|---|---|
| 读者想看什么 | "他到底是不是坏人"——道德判断被改写成信息缺口 |
| 情绪链 | 冷酷行为（读者判他有罪）→ 自相矛盾的裂缝（纱布/字迹/反应）→ 命名 → 量化 → 溯源 → 归因 |
| 戏剧单元 | 先让反常行为持续足够久，再让"同一个人"在不同场合留下互斥的痕迹，最后用权威第三方命名 |
| 关键触发物 | 可替换功能位：裂缝载体（伤/字迹/反应）、命名者（医生/长辈/对手）、量化清单、溯源物证 |
| 复现步骤 | 1. 让反常行为持续 10 章以上且不解释 2. 每 2-3 章留一件互斥物证 3. 由专业人士命名并量化 4. 用影像/记录做溯源 5. 把成因归因到主角身上（情感闭环） |
| 可替换项 | 病症或机制名、人格数目与功能位、命名者身份、溯源载体 |
| 不可照搬 | 分离性身份障碍 + 十三个副人格的具体设定；善进学院的具体遭遇 |
| 关联节奏 | `节奏.md` TR-012、RH-008 |

### EM-006 窒息的爱与自首式和解

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 施控者不是脸谱坏人，而是"确实爱你但确实毁了你"，且惩罚由制度而非受害者执行 |
| 情绪链 | 日常规训（低烈度）→ 暴力升级（灌油）→ 命案曝光 → 僵持（受害者不接钱）→ 施控者自我觉醒 → 自首 |
| 戏剧单元 | 让施控者最后一次为自己做一件小事，再把"去自首"说成家常话 |
| 关键触发物 | 可替换功能位：规训仪式、暴力事件、命案手段、受害者拒绝方式、最后一件为自己做的事 |
| 复现步骤 | 1. 给规训找一个可被执行的日常仪式 2. 让暴力事件由一件家常物品完成 3. 命案曝光时让受害者先逃而不是先报警 4. 让受害者用"不花一分钱"维持拒绝 5. 用一顿饭完成自首宣告 |
| 可替换项 | 规训内容、暴力手段、罪名、拒绝姿态、最后那顿饭的菜色 |
| 不可照搬 | 5L 大豆油、蜱虫杀夫、一千六百万赔偿金的具体组合 |
| 关联节奏 | `节奏.md` TR-004、TR-015 |

### EM-007 取证维权（迟到的必然）

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 反派不是被主角打倒，而是被自己留下的证据打倒 |
| 情绪链 | 恶行（当年）→ 恶行重演并被拍下 → 交出证据 → 报警 → 问"能判死刑么" → 判决 |
| 戏剧单元 | 受害者/旁观者取证，主角只负责递出去，暴力留给过去 |
| 关键触发物 | 可替换功能位：当年恶行的见证物（视频/照片）、拍摄者、递交对象（警察/媒体）、量刑台词 |
| 复现步骤 | 1. 让恶行在开篇即以景物或新闻形式出现 2. 中途让恶行以另一种面目重演（伪善账号） 3. 取证过程必须失败一次（被发现/受伤） 4. 交给制度并追问量刑 5. 判决放在收束章 |
| 可替换项 | 罪名、证据形态、失败方式、递交对象 |
| 不可照搬 | 山火 + 二十七名消防员的具体设定；麻醉针与虐猫的具体桥段 |
| 关联节奏 | `节奏.md` RH-007、RH-009、RH-011 |

## 重组与复现指南

1. 先选读者需求，再选模块卡，不要从原文桥段倒抄。
2. 保留情绪链和功能位，替换人物、场景、动机、道具、事件素材。
3. 复现到新书大纲时，至少改变：冲突对象、公开/私密场景、触发证据、余波方向中的三项。
4. 若人设与模块冲突，以人设驱动重构模块；不要为了套套路扭曲角色。
5. **本书最值得迁移的不是桥段而是两条结构**：① 把"承诺的失约"做成跨卷付费点（EM-001）；② 把"他是不是坏人"做成可以分期交付的信息缺口（EM-005）。两者组合时，答案是前者、载体是后者。

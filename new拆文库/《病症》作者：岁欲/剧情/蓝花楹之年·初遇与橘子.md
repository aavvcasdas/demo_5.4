# 蓝花楹之年·初遇与橘子

| 项目 | 内容 |
|------|------|
| 标题 | 蓝花楹之年·初遇与橘子 |
| 类型 | 爱情 |
| 概要 | 时间倒回四年前的四月，蓝花楹开得最好的一年。周念在冉银的量化教养下生活（体重只能是 82 斤、浮动不超 1 斤，每日到公厕催吐），却因画画天赋被称作"女版小梵高"。她在南水街目睹"疯狗"鹤遂被皮卡司机肖护两轮羞辱后抄铁锹砸窗、把人从车里拽出逼其道歉，又目睹他面无表情从掌心拔出碎玻璃。她求他做模特被骂"傻逼"，却塞给他一颗橘子，换来一场落荒而逃和一次被扔进垃圾桶。此后关系以"给—拒—迂回接受"推进：他嘴上说"离我远点"，却用光她赊账买来的药并去药店代付两块钱，又翻遍巷口垃圾桶把那颗橘子找了回来；他第一次叫对"周念"这个名字，又反口让她别再有交集。罗强揭开他的来路：四岁时被吸毒的父亲哄去"买烟"，便衣从烟盒里取出毒品带走父亲，全镇大人从此禁止孩子与他来往。另一条暗线加热——父亲周尽商去世半年、保额超千万的保险无一家赔付。 |
| 核心目标 | 让两个被污名化的人建立第一次连接，并把"她为什么偏偏靠近他"写成不可逆的选择 |
| 核心冲突 | 周念的靠近 vs 鹤遂的系统性推开（骂、关门、拒药）；外部冲突是肖护的围殴与冉银的审查网 |
| 关键信息功能 | 让读者**误判**男主只是暴戾的疯狗，再用喂猫、代付药钱、翻垃圾桶三次行为推翻误判；同时埋下保险线与鹤广线 |
| 读者需求 | 被理解（两个不被看见的人互相看见）+ 好奇（他到底经历过什么）+ 小爽点（砸窗拽人、一人打退六人） |
| 情绪模块ID | EM-004（靠近—推开—迂回接受的锯齿） / EM-007（以小搏大的打退六人） |
| 套路框架位置 | "救赎"套路的前半段：先让被救者拿出唯一的东西（橘子/药），再让施救者用行动而非语言回应；"疯狗"传言由第三方转述，主角一句不辩 |
| 桥段标签 | 救赎、双向奔赴（表外补充）、打脸 |
| 章节范围 | 第2-11章（共10章，约4.2万字） |

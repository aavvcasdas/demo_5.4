## 故事线一：主线·双向救赎与"他为什么没来"

- **类型**：主线
- **描述（发展阶段）**：
  1. **相遇与互为镜像（2-22 章）**：周念在冉银的量化教养下把进食变成受刑，鹤遂在南水街被称作疯狗。她先给出善意（橘子、药、作证），他以"给—拒—迂回接受"回应。核心冲突是两人各自与外部世界（母亲/全镇）的对抗；能力/资源演进体现为周念从顺从到第一次拒食，鹤遂从"离我远点"到主动问"你想怎么画"。主题母题：**被污名化者的相互辨认**。
  2. **靠近与救赎承诺（23-42 章）**：他托付喂猫、给她酸杏、为她读厌食症的书、许下"我要你好起来"。冲突转向内部（她的催吐与他的自毁）。主题母题：**救赎是行动不是言语**。
  3. **断裂与失约（43-55 章）**：宋敏桃母女溺亡、冉银逼退、杀夫真相曝光、逃亡约定成立，6 月 9 日鹤遂未到火车站，"上卷完"。冲突集中为命运级外力。主题母题：**承诺与失约**。
  4. **四年后与否认（56-72 章）**：他成了顶流影帝并当众说"不认识"，她被网暴、删照拿走三千万、出院后失去厌厌、五识尽丧。主题母题：**被抹除的过去**。
  5. **回归与真相分层揭示（73-100 章）**：他抛下奥斯卡回国救她，多重人格曝光，真相由"存在另一个人格"→"十三个副人格"→"那六个月在善进"逐层推进。主题母题：**苦衷不等于无伤害**。
  6. **整合与重建（101-119 章）**：山火证据、卖血清单、日记本、监控录像把最后一层真相摊开；人格整合启动，她以"小顺遂"之名重新参展，他走向她。主题母题：**各自成为更好的人**。
- **情绪引擎摘要**：全书用一个"推迟了 55 章才兑现答案"的失约缺口做总引擎，每揭一层真相先给痛、再给补偿（详见 `情绪模块.md` EM-001）。
- **套路运行方式**："追妻火葬场"被改造成"追妻 + 真相"双轨——男主的补偿行为（救人、卖血清单、监控录像）本身就是证据，追妻过程即解谜过程（详见 EM-002）。
- **主题**：救赎 / 记忆与身份 / 自我主权的夺回
- **包含剧情**：楔子·四年后的不认识 → 蓝花楹之年·初遇与橘子 → 长狭弄·药与雨 → 重逢与靠近 → 灌油·79斤与秘密暴露 → 当众走向他 → 智齿与萤火虫 → 南水河上的两具浮尸 → 杀夫真相与逃亡之约 → 黄谣·出庭·失约的火车站 → 四年后·京佛重逢与否认 → 三千万与删照 → 出院·厌厌之死·五识尽丧 → 他回来了 → 割腕·十三人格与三月赌约 → 重新开始画画与冉银自首 → 山火证据·让鹤遂回来·破冰 → 公开恋情·善进的六个月 → 人格整合·走向你的路
- **模块引用**：EM-001, EM-002, EM-003, EM-005

## 故事线二：感情线·从橘子到走向你的路

- **类型**：感情线
- **描述（发展阶段）**：
  1. **信物的交付与抛弃（2-11 章）**：橘子被送出→被扔进垃圾桶→被翻垃圾桶找回→被保鲜膜裹起。核心冲突是"她靠近、他推开"；资源演进是她从赊账买药到留下药在门槛。主题母题：**信物即未说出口的话**。
  2. **秘密共享（23-42 章）**：两人互相保守秘密（她的催吐、他的妹妹），关系从"朋友"被推到"你以后能在我手术书上签字的关系"。主题母题：**被看见**。
  3. **确立与失去（53-55 章）**：初吻与"万年长青"的承诺，紧接着 6 月 9 日失约。主题母题：**甜到顶点即预告散场**。
  4. **否认与反转（56-72 章）**："不认识"、扯断智齿项链扔还、三千万删照，感情线被降到零度以下。
  5. **重新破冰（96-119 章）**：缝扣子、白兔奶糖的赌注、"我女朋友"、凌晨 2:34 的公开微博、掌心里写下的七个字。主题母题：**重新选择同一个人**。
- **情绪引擎摘要**：用"甜—失去—更甜"的锯齿线，甜点永远紧跟一个散场预告（详见 EM-004）。
- **套路运行方式**：把"追妻火葬场"的补偿从物质（三千万）升级为身体（卖血、挨打记录）与身份（公开恋情）（详见 EM-002）。
- **主题**：救赎型爱情 / 信物 / 重新选择
- **包含剧情**：蓝花楹之年·初遇与橘子 → 重逢与靠近·糖狗与奖状 → 当众走向他·告白与手机 → 智齿与萤火虫 → 黄谣·出庭·失约的火车站 → 山火证据·让鹤遂回来·破冰 → 公开恋情·善进的六个月 → 人格整合·走向你的路
- **模块引用**：EM-002, EM-004

## 故事线三：成长线（周念）·从"为妈妈而画"到"为自己而画"

- **类型**：成长线
- **描述（发展阶段）**：
  1. **规训期（2-11 章）**：体重 82 斤、浮动不超 1 斤，进食即受刑，画画是为完成母亲未竟的画家梦。冲突对象是冉银；演进是"报复性催吐"带来的虚假主权感。
  2. **松动期（23-42 章）**：拒食、第一次做到餐后不吐、阿喀琉斯之踵的反抗纲领。能力演进体现在她第一次对母亲说"不"。
  3. **崩塌期（49-72 章）**：杀夫真相曝光、逃亡失败、通知书被撕、画画能力丧失、五识尽丧。这是成长线的负向谷底。
  4. **重建期（91-119 章）**：重拿画笔、以新名字"小顺遂"报名全国画家联展、主动要求冉银自首、在展会上以独立画家身份被认出。资源/地位演进：从"女版小梵高"的旧名声 → 主动弃用旧名 → 以新人身份被重新接受。
- **情绪引擎摘要**：把"体重秤数字"做成公开计分板，每一次数字下降都是一次可量化的心碎（详见 EM-003）。
- **套路运行方式**："自我觉醒"桥段不靠宣言，靠物件行为（撕通知书/藏素描本/换画家名）（详见 EM-003）。
- **主题**：夺回身体主权 / 天赋与自我 / 与母亲和解而不妥协
- **包含剧情**：蓝花楹之年·初遇与橘子 → 长狭弄·药与雨 → 灌油·79斤与秘密暴露 → 杀夫真相与逃亡之约 → 出院·厌厌之死·五识尽丧 → 重新开始画画与冉银自首 → 人格整合·走向你的路
- **模块引用**：EM-003, EM-005

## 故事线四：谜团线·多重人格与善进的六个月

- **类型**：谜团线
- **描述（发展阶段）**：
  1. **异常信号（61-72 章）**：手腕纱布、镜子碎片、两种字迹的纸条、栽倒时叫"念念"却醒来全不认账——先让读者以为他"冷酷"。
  2. **命名（78-81 章）**："我是沈拂南"、"你知道你的身体里有其他人格的存在吗"，谜团被正式命名。
  3. **量化（88-91 章）**：分离性身份障碍的诊断、十三个（1 主 + 12 副）人格清单、六个月分裂出 12 个副人格的时间锁。
  4. **赌约（93-110 章）**：三月赌约 → 真相是"输的人永远消失" → 他赌"你死在这个夏天"、她赌"你爱我"。
  5. **溯源（109-115 章）**：善进学院 197 天、黑屋/钢棍/禁食 13 天/电击 126 次、墙角刻字、日记本、十三个副人格逐一归因于她。
  6. **整合（116-119 章）**：催眠融合而非绞杀，第一个整合对象是沈拂南，条件是"让他继续拍戏"。
- **情绪引擎摘要**：把"他到底是不是坏人"这个道德判断改造成信息缺口，每揭一层都先推翻读者的前一层判断（详见 EM-005）。
- **套路运行方式**："马甲掉落"被拉长到 40 章——掉落的是同一具身体里的不同人格（详见 EM-005）。
- **主题**：创伤的具象化 / 身份主权 / 苦衷与伤害并存
- **包含剧情**：四年后·京佛重逢与否认 → 他回来了·东济与人格现身 → 割腕·十三人格与三月赌约 → 公开恋情·善进的六个月 → 人格整合·走向你的路
- **模块引用**：EM-001, EM-005

## 故事线五：冲突线·冉银的掌控与杀夫骗保

- **类型**：冲突线
- **描述（发展阶段）**：
  1. **量化教养（2-11 章）**：称重、进食顺序、催吐阻断，冲突以日常形态出现。
  2. **升级为暴力（30-33 章）**：5L 大豆油强灌催吐，首次出现幻听，体重跌至 76 斤。
  3. **真相（49-52 章）**：蜱虫是冉银放的、周尽商死于她手、一千六百万赔偿金，冲突从掌控升级为命案。
  4. **僵持（53-100 章）**：她切下自己的一根手指、砸碎手机、撕通知书；周念不花一分赔偿金。
  5. **和解与自首（99 章）**：生日饭桌上冉银为自己做了半桌菜，说出"吃完这顿饭我就去自首"，母女在派出所台阶上完成"妈妈"的回扣。
- **情绪引擎摘要**：母女关系始终在"她爱我"与"她在毁我"之间摆动，最后一次摆动落在自首而非原谅（详见 EM-006）。
- **套路运行方式**："偏心打脸"被改写为"掌控者最终自我觉醒"，惩罚权交给法律而非女儿（详见 EM-006）。
- **主题**：窒息的爱 / 代际投射 / 自首式和解
- **包含剧情**：蓝花楹之年·初遇与橘子 → 灌油·79斤与秘密暴露 → 杀夫真相与逃亡之约 → 黄谣·出庭·失约的火车站 → 重新开始画画与冉银自首
- **模块引用**：EM-003, EM-006

## 故事线六：清算线·鹤广、肖护与善进学院

- **类型**：复仇线
- **描述（发展阶段）**：三次清算彼此错开，最后一次把私人之恶升级为制度之恶。① 肖护：围殴（4-5 章）→ 捅刀（12-16 章）→ 出庭判四年零八个月（54 章）→ 出狱后虐杀厌厌（71 章）→ 被拍下虐待猫狗的证据（95-97 章）。② 鹤广：六岁替父买毒（6 章）→ 强暴宋敏桃（44 章）→ 卖房换毒资（49 章）→ 一棒打晕赴约的鹤遂（119 章揭示）→ 山火二十七名消防员（101 章查出）→ 死刑立即执行（119 章）。③ 善进学院：韩青实名举报（108 章）→ 查封与物归原主（112-114 章）→ 校长上头有人、家长要求复校（111、115 章留白）。
- **情绪引擎摘要**：反派清算不靠主角动手，靠证据链与制度流程，爽感来自"迟到的必然"（详见 EM-007）。
- **套路运行方式**："维权反击"桥段——取证（录像/监控/日记）→ 报警 → 判决，三步走（详见 EM-007）。
- **主题**：私恶与制度之恶 / 证据胜于暴力
- **包含剧情**：蓝花楹之年·初遇与橘子 → 长狭弄·药与雨 → 黄谣·出庭·失约的火车站 → 出院·厌厌之死·五识尽丧 → 山火证据·让鹤遂回来·破冰 → 公开恋情·善进的六个月 → 人格整合·走向你的路

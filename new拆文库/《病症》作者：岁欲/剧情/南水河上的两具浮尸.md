# 南水河上的两具浮尸

| 项目 | 内容 |
|------|------|
| 标题 | 南水河上的两具浮尸 |
| 类型 | 危机 |
| 概要 | 刘春花纠集镇上几个女人砸烂宋敏桃的按摩店，鹤遂当众掀开那面被传为皮肉生意的深红色帘子——里面只有一张铁制单人床和十一二岁、手指粘连、脖子歪斜的畸形妹妹宋平安，被铁链拴在床脚。冉银道出旧丑闻：宋敏桃十八岁被杀猪匠鹤广强暴，被父母逼着嫁给他。周念凌晨偷溜出门去找他，在门槛上听他说出妹妹的身世后十指相扣。隔天清晨宋敏桃与宋平安同时消失，两人找遍全镇无果，冉银堵门甩了鹤遂一耳光。次日两人在南水河边写生时，河面浮起两具被麻绳相系、脚踝拴着重物的女尸——正是母女二人；鹤遂跳河捞尸，没有一个镇民肯下水，周念不会游泳却跳了下去，用自己的"值得"换来众人出手。宋敏桃裤袋里有一封用塑料袋包好的遗书。当天结案火化，他抱着两个骨灰盒走进雨里。深夜冉银上门谈判，他答应"我会离周念远远的"；第二天他关上木门，在电话里说"我们不要再见面了"——而二楼窗后的人，看着她失魂落魄地走远才关窗。 |
| 核心目标 | 让男主失去全部家人，并让外部压力第一次成功切断两人的关系 |
| 核心冲突 | 全镇的言语暴力（造黄谣、砸店、围观）vs 这个家的求生；终极对抗是冉银的深夜谈判 |
| 关键信息功能 | 让读者**确认**"小镇即是凶手"（旁白明写），并让读者**等待**断联之后谁来先开口 |
| 读者需求 | 愤怒（围观者拍照、无人下水）+ 极致心疼（遗书、骨灰盒、雨中告别）+ 悬念（他会怎样） |
| 情绪模块ID | EM-006（群体的语言杀人） / EM-001（断联即下一次失约的预演） |
| 套路框架位置 | "极品亲戚 + 反转打脸"的变体：反转的不是身份而是道德——被传为皮肉生意的帘子后面是被拴了十年的残疾女孩；打脸延后到第 48 章由冉银完成（她是加害者） |
| 桥段标签 | 极品亲戚、反转打脸 |
| 章节范围 | 第43-48章（共6章，约2.1万字） |

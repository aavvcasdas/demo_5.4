# 人格整合·走向你的路

| 项目 | 内容 |
|------|------|
| 标题 | 人格整合·走向你的路 |
| 类型 | 主线 |
| 概要 | 她说"我们都要变成更好的人"：他回京佛进组跑行程，她休学结束回去读书，两人约定一起去做人格整合。生雅娇的订婚宴上她第一次见他穿西装，他说"真心相爱的两个人之间是不用觉得谁配不上谁的""你是我的女朋友这件事，一直都让我特别骄傲"；她在掌心里一笔一划写下七个字——周念只喜欢鹤遂。忌日那天两人深夜上山，他在母亲与妹妹碑前说"这么多年过去在我身边的还是她"。他承认自己看过她那条淹没在百万评论里的生日评论："我就是知道，那一定是你。"韩老的治疗方案是融合而非绞杀：沈拂南最想要的是继续拍戏，得到"融合后可以继续拍"的许诺后，他握住那只伸过来的手，一个半小时后融为一体。山火案因社会关注推进极快，鹤广死刑立即执行；会面厅里他说"真好，你终于可以去死了"，而真相也在此揭到底：2013 年 6 月 9 日，卖完血的他揣着她的信走向车站，已看见台阶上抱着万年青的她，被鹤广一棒打晕——那一棒同时把他送进了善进与电影圈。他红着眼说"我当时真的，就差一点点了"，她说"没关系，以后我们一定会很幸福的"。八月中旬全国画家联展，她以新名字"小顺遂"参展，《晚森流浪》围着一群人拍照；他请假从剧组赶来，在十米开外打电话说"你转身"，然后一步步走向她："念念，我这一生走过许多路，但我最喜欢的路，还是走向你的路。" |
| 核心目标 | 让两条主轴（她的自我重建、他的人格主权）同时闭合，并让清算线落地 |
| 核心冲突 | 他"只想待在你身边" vs 她坚持"你本来就该光芒万丈"；最后一层真相（那一棒）在此揭出 |
| 关键信息功能 | 让读者**拿到**最后一个答案（6 月 9 日的物理原因），并**确认**整合是融合而非消灭 |
| 读者需求 | 破镜重圆的甜 + 迟来的正义（鹤广死刑）+ 双向成就的满足 |
| 情绪模块ID | EM-002（补偿的完成态） / EM-007（清算落地） / EM-004（走向你的路） |
| 套路框架位置 | "破镜重圆"不靠原谅宣言而靠双向成就：她推他回高处，他走向她；"复仇"交由制度（死刑）执行 |
| 桥段标签 | 破镜重圆、救赎 |
| 章节范围 | 第116-119章（共4章，约2.0万字） |

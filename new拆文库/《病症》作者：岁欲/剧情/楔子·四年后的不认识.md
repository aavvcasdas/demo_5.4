# 楔子·四年后的不认识

| 项目 | 内容 |
|------|------|
| 标题 | 楔子·四年后的不认识 |
| 类型 | 主线 |
| 概要 | 二十二岁生日当天，周念被母亲冉银从南方小镇带到京佛精神卫生中心求医。她在火车站广场的幕墙屏广告上认出已成顶流的鹤遂，又凭一个背影第二次认出他；他正为电影《昼春》做"乔装素人上街"的路演，摘下口罩后只对她说三个字"不认识"。周念扑上去拽出他颈间黑绳上的一颗用银丝缠绕的人类牙齿——她十七岁拔下的智齿，被他做成项链戴了四年。她被保安拉开摔在地上，被围观者议论"精神不太正常"，冉银赶来向众人解释"我女儿精神不太正常"。她在干呕与意识溃散前只留下一个结论：鹤遂忘了她。末行转场"夏天来了，周念和鹤遂也来了"，把时间推回四年前。 |
| 核心目标 | 让读者在 3600 字内接受一个问题：他曾是她最重要的人，如今当众否认她——为什么？ |
| 核心冲突 | 周念持物证（智齿项链）索认 vs 鹤遂当众语言否认（"不认识"）却仍低头盯着项链的破绽 |
| 关键信息功能 | 让读者**先拿到终局态**：她的病、他的红、两人的旧关系、以及"他忘了她"这个主问题；同时把智齿项链、《昼春》路演、冉银的"精神不太正常"三件伏笔一次投放 |
| 读者需求 | 认知反转（强者当众否认弱者 + 弱者拿出无法反驳的物证）+ 心疼 + 强悬念 |

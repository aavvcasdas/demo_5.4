# 势力：新阳保险

| 项目 | 内容 |
|---|---|
| 名称 | 新阳保险（保险公司） |
| 类型 | 商业机构 / 功能型势力（调查方） |
| 核心人物 | 陈志强（业务员；登门推销、拿着笔记本按条目提问）、理赔审核部门（未具名） |
| 立场倾向 | 商业自保：以"涉嫌骗保"为方向做尽职调查，试图拒赔；一旦被说服或拿到材料即可赔付 |
| 与其他势力关系 | 与冉银是保险合同相对方（后被冉银反向利用）；与李丽芳（周尽商的出轨对象）构成调查线索；与花楹镇派出所无交集 |

## 运作方式

- **承保**：两份人身意外险，保额合计**超千万**（每份一千万），由冉银在陈志强提着两桶菜油登门磨了一上午后买下（第42、50章）。冉银自己亦买了一份同额一千万的保险（第12章周念反驳时说出）。
- **调查**：业务员按笔记本逐条提问——"你父母平时关系怎么样""他们平时吵架吗""你爸爸之前和其他的阿姨走得近吗"（第12章）。第41章陈志强又拿着语文老师李丽芳的蓝底二寸照找周念问话。
- **拒赔与赔付**：周尽商死后半年无一家理赔（第7章）；冉银反复去市里争吵、摔手机（第22章），最终"搞定了保险公司那群难缠的人"，**一千六百万**赔偿金于第50章次日到账。

## 对剧情的作用

1. **家庭线的经济引擎**：赔偿金是冉银全部行为的现实动机，也是周念拒绝 inherit 的具体对象（"不花一分赔偿金"）。
2. **命案线的调查方**：它的调查把"病死"重新定义为"可疑死亡"，与第49-50章的真相互为因果——周念从第12章的反驳者变成第50章的知情者。
3. **预置模板的落点**：第41章男主给她讲的《绝叫》正是"杀夫骗保"故事，保险线是把这个故事落回现实的中介（第50章周念当场认出这一点）。
4. **人物对照**：陈志强这一"按章办事"的机构人与冉银这一"利用规则"的个人形成对照，同时让读者明白——**制度在这里既被利用，也最终成为清算的通道**（第99章冉银自首）。

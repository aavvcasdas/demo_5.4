# 势力：花楹镇舆论场（镇民集体）

| 项目 | 内容 |
|---|---|
| 名称 | 花楹镇舆论场——由镇民、街坊、同学家长构成的"集体角色"（非组织，但具备组织级杀伤力） |
| 类型 | 地方社群 / 无形势力（全书最主要的反派之一） |
| 核心人物 | 刘春花（快递驿站老板娘，以"浑"著称，带头造黄谣并砸店）、刘悍（驿站老板，痛风跛脚）、罗强（同学/传声筒）、韩青（同学/霸凌者）、李丽芳（语文老师）、邻里围观者、镇上家长 |
| 立场倾向 | 随风向摆动：对弱者一致排挤，对成功者一致追捧；不需要证据，只需要一个说法 |
| 与其他势力关系 | 是善进学院在小镇的"生源供给方"（第112章"小镇上也有不少孩子被送去过"）；与男主一家有直接血债（第49章旁白明写"满镇子的人都是杀死宋敏桃和宋平安的凶手"） |

## 运作方式

1. **绰号系统**：给每个人贴一个标签并让标签替代本人——"疯狗"（鹤遂）、"女版小梵高"（周念）、"鹤千刀"（鹤广）、"乖乖女"（周念的早期标签）。
2. **流言变形**：同一件事在传递中逐级失真。宋敏桃造黄谣一事"从'造黄谣'一路变形到'带着儿子一起欺负原配'"（第34章）。
3. **集体行动**：纠集砸店（第43章）、门口泼红油漆（第27、71章）、送花圈与写着名字的寿衣（第71章）、见死不救（第47章浮尸当日无一个懂水性的镇民下水，直到周念跳下去才有人动）。
4. **风向反转**：男主成名后"所有人都突然开始爱他"，说他"从小就长得特别好看、也很可怜"，还有人后悔之前没对他好一些（第57章）；女主成为顶流女友后，当初冷嘲热讽的人也换了脸色（第117章）。

## 对剧情的作用

1. **上卷的第一反派**：它比任何一个具体人物都更早、更持久地压迫两位主角，也是男主"不出声、只咬人"这一性格的直接成因。
2. **把"恶"去人格化**：本书最狠的暴力不来自单一反派，而来自"所有人照常生活、照样笑得开心，照样选中下一个要杀死的对象开始议论"（第49章）。
3. **为主题提供落点**：男主后来被全镇爱戴，恰恰反证"被认可"本身不具道德意义——第116章周念让他往高处走，与第57章全镇的改口形成对照。

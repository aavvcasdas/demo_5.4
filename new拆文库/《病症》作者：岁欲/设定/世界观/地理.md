# 地理：病症

> 全书为**现实题材**，地理按现实中国南方小镇—省会—一线城市三级分布。所有地点均出自章节摘要，可回查；距离与方位原文未给出的写「原文未明确」。
> 主要区域：**花楹镇（南方小镇）**、**云宜（市）**、**京佛（一线城市）**，外加一处海外场景（洛杉矶）。

## 一、花楹镇（女主故乡，上卷主场景，第2-55、71-72、96-108、117章）

南方小镇，四月蓝花楹开得"染紫半面天"，五月进入湿冷难缠的梅雨季；镇外有座曾被山火烧秃的青山（第2章），火灾后当地采取禁火措施，祭奠只摆放纸衣纸元宝与电子红蜡烛、不许焚烧（第117章）。

| 地点 | 功能 | 关键事件 |
|---|---|---|
| **北清巷** | 周念家所在（院子、堂屋、画室、二楼卧室、井） | 灌油催吐（第30章）、家门口被泼红油漆摆花圈寿衣（第71章）、他深夜砸门（第74章） |
| **南水街** | 白卵石街面的主街：宋敏桃按摩店、快递驿站（刘悍）、黑网吧、小吃店、旧货市场、手机店、屠宰场、"鑫鑫爱宠"宠物店、五金店 | 砸车（第2章）、长狭弄围殴（第5章）、他在小吃店打工（第23-24章）、黑网吧对峙（第39章） |
| **长狭弄** | 窄巷，两人第一次肢体接触处；小黑猫"厌厌"的栖身处 | 撞进怀里与唇擦喉结（第5章）、六人围殴（第5章）、喂猫与被旅客偷拍（第33章）、肖护出狱后在此羞辱她（第71章） |
| **南水河 / 石桥 / 石阶** | 河岸垂柳、长青苔的石阶、镇上石桥 | 陈志强问话（第12章）、两具浮尸（第46-47章）、她跳河以死相逼（第51章）、他泡三小时找智齿（第105章） |
| **鹤家（南水街尽头巷尾）** | 木门、菜圃干裂的院子、杏子树、他的房间（黑白灰三色衣柜、玻璃下压满奖状） | 泼油漆与擦门（第27章）、第一次进他的房间（第25章）、杀牛刀守住房子的真相（第52章） |

| **镇高中 / 操场外墙** | 女主就读、他回校做防盗作业（两米半高水泥墙、横面木梯、碎玻璃） | 八百米与当众要手机号（第35-36章）、高考送考（第55章） |
| **公厕** | 女主每日催吐处 | 第4、31章（第31章挂"维修中，禁用"直接把她推向鹤家） |
| **郊外农田 / 荒山 / 坟山** | 稻田、土山包里的坟 | 捕萤火虫（第42章）、清明/忌日扫墓（第117章） |
| **镇派出所** | 卢国强（亦作卢强国）、段武 | 报案失踪（第57章）、强奸指控的审讯（第53章）、报警山火证据（第105章）、善进旧物归还（第112-114章） |

| 地点 | 功能 | 关键事件 |

## 三、京佛（一线城市，下卷主场景，第1、56-72、116、119章）

十一月中旬气温仍稳在 32℃ 以上，空气黏腻；是座很难下雪的城（上次下雪是二十年前的九零年代，只会下冰雹雨）。

| 地点 | 功能 | 关键事件 |
|---|---|---|
| **京佛火车站 / 广场 / 幕墙屏** | 全书开篇与四年后重逢的同一地点 | 楔子的"不认识"（第1章）、《昼春》户外路演（第1章） |
| **京佛精神卫生中心** | 女主住院（一级护理、王学知主治）、后调普通病区四人病房；有心理干预理疗室、音乐理疗室、天桥、楼下花园 | 重逢与否认（第56-70章）、他提前一月入住体验角色（第61章） |
| **京佛美院** | 国内顶级艺术类院校、一流 985，每年超三万人报考、录取不超 1500 人 | 她的校考第一（第55章）、通知书被撕（第57章） |
| **莫奈的别墅** | 双层大挑空，二楼直播间 | 外出散心（第59章） |
| **会展中心 / 酒店 / 海边** | 全国画家联展；生雅娇订婚宴（中午五星级酒店、晚上海边） | 第119章 |
| **工作室 / 剧组** | 男主演艺工作的场外空间 | 第116、119章（位置原文未明确） |

## 四、洛杉矶（海外，第73、77、98章）

- **好莱坞星光大道杜比剧院**：第 90 届奥斯卡金像奖颁奖礼现场，剧院门口每十米立一尊超两米高的金人雕像；男主在此失踪，盥洗台与白色洗手池上留下血手印与镜上的【放我回去】。

# 第66章 病症 摘要

**概要**：京佛入冬，周念在住院部楼下的花园里晒太阳，看阳光从红梅枝桠间筛落。护工与她搭话，问她最近总教小昭画画、是不是以前学过，她答"没有，随便画画而已"，被追问为何没走这条路时只笑说"试过，走不通"，并随口诌了个"学艺术太烧钱了"的借口；护工说起自己儿子也在本市的美院、联考校考都是擦边及格靠运气，周念缓慢眨了下眼、声音变轻地说"京佛美院""挺好的，挺好"，而护工并不知道眼前的人曾同时拿下13年美术联考与京佛校考双第一。护工去上厕所后，一个穿灰色翻领毛衣、系黑围巾、三十五岁上下的男人坐到她身边，递上"月炎工作室 创始人·解渤腾"的名片，自称娱乐圈记者，被她一口称作狗仔。她识破他腿上的手机正在录音，他关掉录音反夸她聪明，随即说看过她在鹤遂路演现场问对方认不认识自己的视频、网上都在骂她但他相信她，并准确报出她是厌食症、来自花楹镇、鹤遂也出自那座小镇。他说明来意是挖鹤影帝的料，暗示始乱终弃的旧事，说能让她的委屈被大家看见、还能拿到不菲的经济赔偿，最后落到"口说无凭，有照片为证最好了"。周念想到手机里存着上百张与鹤遂的亲密合照，睫毛颤了颤，仍在一分钟后起身回绝"我没有你想要的东西"；他临走指着名片说等她的电话，还补一句"随时"。回病房后她把名片拍给莫奈，得知解渤腾是近年最厉害、从不曝假料的狗仔，莫奈劝她拿照片去让解渤腾和鹤遂交涉分成，她回"我要是真想这么做，完全可以直接当面和他谈"，并说出现在和她同住一个病房、就住她旁边的人正是鹤遂，莫奈震惊之余说真希望他也得精神病。话没说完，鹤遂提着小提琴进门，一眼看见名片，问她"解渤腾找上你了"，又端杯问她"所以你有么"，周念抚着万年青的绿叶对他微微一笑："我有没有，你不是很清楚吗？"（本章正文与第65章逐字重复。）

**关键事件**：1. 护工问起画画与"试过，走不通""京佛美院" 2. 解渤腾落座、递名片、被称狗仔 3. 录音被当场拆穿、他反夸她聪明 4. 他准确说出她的病与花楹镇的来处 5. 他暗示始乱终弃并提出"有照片为证最好" 6. 周念想起上百张合照仍拒绝 7. 莫奈劝她卖照片分成、她说可以直接当面谈 8. 鹤遂看见名片问"所以你有么"

**逐章写法公式**：

- **情绪流向**：起：淡（冬日花园、护工闲谈、一句"走不通"） → 承：警（陌生人落座、递名片、录音被拆穿） → 转：硬（赔偿与照片的诱惑被回绝） → 合：锋（"所以你有么"与"我有没有，你不是很清楚吗"）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：冬日花园与护工闲谈（用旁人的成绩反衬被埋掉的天才） + 拄拐老人的衰败感（定主角此刻心境） + 解渤腾落座递名片（引进外部变量） + 拆穿录音（夺回主动） + 报出病情与花楹镇（亮调查深度） + 摊明来意与赔偿承诺（把诱惑摆全） + "有照片为证最好"与上百张合照（亮筹码） + 拒绝与"随时"（留一个口子） + 与莫奈的微信（借朋友视角补足对手量级） + "可以直接当面和他谈"与同病房坦白（完成反转） + 名片被看见（两线交汇） + 反问收章
- **本章核心技巧**：把"外部势力出现—抛出交易—主角拒绝"的三段式压缩进一场花园闲谈，让所有关键事实（病情被查、来处被查、筹码在手里）都靠对话与一处细节交代，再把重锤留到最后一句反问上
- **卡点与伏笔**：结尾卡点：她的反问没有答案，照片是否存在、鹤遂是否会先出手都悬置；埋设/回收伏笔：解渤腾名片 → 第67章被撕碎、热搜随后爆发；上百张亲密合照 → 三千万买断与当众删除的起点；13年双第一 → 与录取通知书被撕的旧事互相咬合；万年青 → 反复出现的意象物件；花楹镇被外人查证 → 两人来处已成公开线索
- **时间线**：京佛入冬后的花园自由活动时间，延续至当日回病房

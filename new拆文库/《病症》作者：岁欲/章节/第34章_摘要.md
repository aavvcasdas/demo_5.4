# 第34章 病症 摘要

**概要**：二〇一三年是全国各地成立快递驿站的一年，其中一个驿站就开在宋敏桃的按摩店旁边，老板是个四十出头、络腮胡浓密却一根头发都没有的男人刘悍，因常年喝酒吃海鲜落下痛风、走路常一跛一跛；他常光顾按摩店，洗脚按摩都指名要宋敏桃，宋敏桃忙他就回自家店多等一会儿，这让他老婆刘春花多有微词。刘春花名字秀气人却泼辣，胜在一个"浑"字——你讲道理她咒你全家，南水街没人吵得过她；她不止一次专挑宋敏桃打扫门口时拐弯抹角地骂，措辞不堪。宋敏桃不爱闹架，匆匆扫完地就回店。中午饭点刘悍跛着脚来叫她，说她有个快递、地址写的是她店子，她跟着过去站在驿站门口等着，刘春花立刻亮着嗓门出来，把手里的饭桶重重放在桌上，阴阳怪气地指责她"勾引我家男的三天两头往你店子里跑"——宋敏桃招来这种恶意，起因只是她长得太过美艳、身材惹火，不知情的人完全想不到她有个十七岁的儿子。宋敏桃面不改色像没听见，刘悍心虚地催她快走，刘春花更不乐意，抢过快递当场追问"你到底是做的哪门子生意"，说按摩店里扯着一张红帘子，早有人说帘子后面摆着一张床，"什么生意需要用到让帘子挡着的床"；她嗓门大得像喇叭，南水街本就热闹，一瞬间吸引来大批视线，宋敏桃始终没开口，只呆呆站着像条任人宰割的鱼。话没说完，刘春花手里的快递突然被人抢走——谁都没看清鹤遂是什么时候出现在宋敏桃身后的，他穿白t灰裤、戴一顶帽沿压得极低的纯黑鸭舌帽，四周顿时阒静；他长腿迈两步站到刘春花面前才缓缓抬头，寒锐的眼锋从帽檐下显出，太阳穴爆出一根青筋，这张脸只有刘春花一人能看见，威胁也是独给她的——"我，警，告，你。你要是再给我妈造黄谣，我就让你没办法再开口说话。"以泼妇出名的刘春花瞬间怂了。他推了一把宋敏桃的肩膀说"回店里"，离开前又扫过刘春花的脸说"你也是个女人，积点口德"。回到按摩店，鹤遂坐在靠门的第一张洗脚椅上拆那个黑色包装，拆开是三本书；宋敏桃眼里有了希望，赶紧劝他既然还愿意看书就回去念书、说自己能照顾好自己，他反问"像刚才那样傻站着由人羞辱，就是你口中的照顾？"，又抽出一本给她看、说"不是和学习相关的书，杂书而已"，没给她再开口的机会就起身走了。羞辱一事越传越开，从"造黄谣"一路变形到"带着儿子一起欺负原配"，流言像瘟疫传到周念耳朵里时已是最后一个版本；冉银在饭桌上批判情绪很重、甚至忘记给周念夹菜，说"破坏别人家庭的女人真是该死"，周念罕见地接了嘴说"万一鹤遂妈妈是被诬陷的"，被一句"你才多大，你压根不懂这些"驳回，冉银又拿那张和墙一样宽、长到坠地的红帘子当反证。周念回房吐空胃里的东西、刷了牙，坐在书桌前拨弄不倒翁，满脑子想鹤遂会不会因妈妈的事很困扰，终于拿着小灵通躲进厕所发了三个字加一个问号——"你还好吗？"；五分钟后鹤遂只回了一个"？"，她咬唇绞尽脑汁想怎么回复。同一时间，鹤遂也坐在书桌前用黄色荧光笔勾画一本厚书的重点、写备注，一边留意手机；震动响起后他立马放下笔解锁点进短信，看到的是【我相信你，也相信你妈妈。】十个字——周念用了十分钟编辑，让鹤遂记了一辈子；他盯着短信看了很久，手指好几次落在返回键上都没按下去，感觉像阴暗的内心被揭开潮湿苔藓逐渐晾干，经年滋养的细菌在那缕光线下逐个死去，"死去的是他的一部分，活过来也是他的一部分"。

**关键事件**：1. 刘春花当街羞辱宋敏桃、逼问红帘子 2. 鹤遂现身抢回快递并威胁刘春花 3. 快递里是三本书、拒绝回校的反问 4. 流言三度变形与冉银的批判 5. 周念发短信"你还好吗？"、鹤遂回一个"？" 6. 十个字"我相信你，也相信你妈妈"与他的变化

|---|---|---|---|---|

**逐章写法公式**：

- **情绪流向**：起：污浊（泼妇骂街、围观） → 承：压迫（宋敏桃像任人宰割的鱼） → 转：燃（鹤遂现身、独一份的威胁） → 合：暖（书与短信、十个字带来的改变）
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：驿站与刘家夫妻的背景铺开（给冲突备好动机与惯例） + 当街羞辱与围观（把母亲推到最低点） + 鹤遂抢快递与威胁（本章爽点，一次性立住他的凶名与孝） + 三本书与拒绝回校（把爽点转成人物悬念） + 流言变形与两条短信（用外部舆论与私人短信对照组关系）
- **本章核心技巧**：让同一个"护"字分两层写——他用威胁护母亲，她用一个问号护他，最后落到十个字的短信；冲突与温柔在同一章并置，温柔因为前文的脏而显得更亮
- **卡点与伏笔**：结尾卡点："我相信你，也相信你妈妈。"十个字让他记了一辈子（感情线的转折标记）；埋设/回收伏笔：红帘子后面是什么 → 镇上给宋敏桃定的罪名，也为后面揭穿留口；他买的三本"杂书" → 他真正在做什么尚未交代；"你还愿意看书却不回去念书" → 辍学的原因再次被点，但依然没给答案

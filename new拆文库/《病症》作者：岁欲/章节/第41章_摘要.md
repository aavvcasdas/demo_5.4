# 第41章 病症 摘要

**概要**：周念的偏头痛一直没有缓解，白天疼、晚上睡觉更疼，严重影响到日常生活；期末将至、发作频率增加，她很难集中注意力复习，更别提画画，刚拿起画笔就疼得只想去躺着，也因此连续两个周末没去找鹤遂。又一个周末，鹤遂在微信上问她今天要不要过去，她说偏头痛不想出门，隔了会他又问她"那我来找你？"；她从床上爬起来在家里上上下下找了一圈、确认冉银不在家去了市里，才回复"可以"。冉银最近去市里越来越频、脸上愁容越来越重，周念对保险金的事反而不怎么挂心。她算着鹤遂快到了，换好衣服下楼给他开门——光是房间到大门这一段距离她就得扶着左边脑袋走，走不了两步就疼得发出"嘶"的一声。开门后鹤遂第一句话就问"头还疼？"，她维持着扶头的姿势说最近疼得更厉害了，他问她有没有去医院看过，她说上周才照过脑CT、没什么问题，医生只说偏头痛原因很多、女性更容易得、和遗传与情绪等多方面有关。两人走到井边，他让她坐下，她坐上去觉得烫、回头看了眼黑漆漆的井嘀咕"不会掉下去吧"，他笑着说掉不下去，她还是怕，伸手小心攥住他的衣服下摆；他在桶里洗完手后直起腰，一只手轻轻勾住她的下巴，问她哪边疼，她答左边，他便说"抬头""张嘴"，下一秒把微凉湿润的手指伸进她的口腔里。她浑身一紧，他让她别紧张，三根手指在她嘴里，她慌乱得只能盯着他的腕骨看、脸上一阵接一阵燥热，还想到他这手戴手表一定很好看；他的手指很慢地一路往里抚摸她的牙齿、从上到下从外到里，神情极为专注，最后食指指腹停在她左边下方最里面的那颗牙齿上说"找到了"——"周念，你这里长了颗智齿，横着长的"。他把手指抽出来，似笑非笑地问她还要拉多久、他要洗手；洗着又问她想说什么，被偏头痛折磨成金鱼脑的她先说忘了，接着想起是想夸他的手戴手表好看，他说"可能？"——叙述点出后来戴在鹤遂腕上的手表数不胜数、全是高奢品牌、品牌方对他很满意、粉丝夸他的手绝绝子，他早就忘记2013年那个夏天曾有个女生坐在小镇民居的井沿上夸他的手好看。她问到正题，他确认偏头痛是这颗智齿引起的、必须拔掉，她怕疼，纠结很久后问他"我要是去拔牙的话，你陪我吗"，他反问"你想我陪么"，她想都没想就说想，他便说"择日不如撞日"，招招手说"走"。一点心理准备都没做，她就稀里糊涂跟着他出门，两人一前一后隔着一段距离、不那么引人注意地朝医院走去。周末的镇医院人满为患、挂号队伍从窗口排到门口，他让她去旁边坐着、自己帮她排队；她坐在钢制长椅上被病气、消毒水味和喧闹吵得头疼，闭眼休息时旁边响起一道耳熟的声音"周念小姑娘"——是上次在南水河边找她谈过话的新阳保险公司的陈志强。她冷淡地说该说的上次都说了，他还像块魔芋一样粘着不走；她下意识看向鹤遂的方向，正好对上他的目光，他脸色一冷、径直从队伍中抽身走过来挡在她身前说"她并不想和你说话"。陈志强从公文包里抽出一张照片，说不是问爸爸的事、是正好在找人想问问她认不认识；周念越过鹤遂的身子看清那张蓝底二寸照——烫着波浪短发的胖女人、大脸盘子、肿泡眼，她愣了一下说"我认识，鹤遂，这人你也认识的"，说这是学校教语文的李丽芳老师、之前教过他；鹤遂淡淡嗯一声，陈志强眼里掠过一抹异色后很快消失，笑着说没别的事就离开了，周念低声嘀咕他一个卖保险的找李老师干嘛，鹤遂随口说可能就是为了卖保险。这次插曲让鹤遂不得不重新排队，近二十分钟后才拿到口腔科的挂号票，他轻轻揉了一把在长椅上等得昏昏欲睡的她。二楼口腔科的牙片显示她左边下牙最里面确实长了一颗横着的智齿，医生说不拔会一直引发偏头痛、还会把旁边的好牙抵烂。拔牙时她怕得刚躺上牙椅就坐起来喊他的名字，他站在旁边耐心地说"我在"，并伸出一只手臂说"抓着就不怕了"，她像抓住救命稻草一样紧紧抓住他紧实的手臂；他说要不等会给她讲个故事转移注意力，随后在她打麻药、闭眼准备拔牙时低低徐徐地讲了起来——有个女生出现在一个不受宠的家庭，妈妈只爱弟弟、从来只会夸奖弟弟，弟弟却死于一场车祸，女生偶然间发现弟弟是被霸凌才自杀的，她把这点告诉母亲、拿弟弟留下的字条给母亲看，母亲非但不相信反而骂她伪造字条；后来女生的爸爸抛弃妻女卷款离家，女生也离家求生融入社会，进入到一家保险公司工作，却遇到黑心上司——不仅被哄骗当了上司的情妇，上司还不停PUA她、让她想方设法提升业绩，女生渐渐走向一条不归路，先是通过卖身求业绩，又被虚荣心挟裹着陷入消费主义陷阱，最终成了一个妓女。故事讲到这里，那颗横着长的智齿已经被医生拔出；麻药生效加上被故事吸引，周念竟一点都不觉得痛，反而兴致勃勃地追问"然后那个女生怎么样了"，医生塞了棉花叮嘱她咬着别说话，鹤遂勾唇一笑"让你先别说话"就不再讲了，而是转头跟医生说"那颗牙齿别扔"，被问是不是要那颗智齿时，他神色冷淡但看向牙齿的眸光很专注地说"我要"。从医院出来时天色已晚、薄暮如画，两人沿着粼粼南水河往回走；她的左脸肿了，说话还不太利索，鹤遂在半道上买了根雪糕故意在她面前吃，还欠揍地笑她"像不像个小老太婆"，她捂着脸含糊地骂他，他倒着走挑眉笑得更坏，她急了伸手去拧他胳膊，他偏偏不躲、由她拧，还满脸宠溺地笑看她，她一下就没了脾气。叙述点出这是最好的时光也是最坏的时光——好在这是一七岁的鹤遂，他的世界里还没有万人瞩目和无边荣潮，内心只有一座被烧光的荒山，而周念是一场及时雨，生机勃勃的一切都是周念给的，她是他灰暗生命里唯一的光；坏在这是十七岁的周念，她会把所有的美好和恩赐都留在这一年，只身前往一个未知、可怖、冷漠的、被鹤遂彻底忘却的以后。她模糊不清地问他拿她的智齿要干嘛，他回身在夕阳里冲她浅笑，摸出那颗洗净装进小袋的牙齿示意："这个会是半年以后——""我的十八岁生日礼物。"

**关键事件**：1. 偏头痛连累日常、鹤遂上门看她 2. 井边检查口腔、查出横生的智齿 3. 陈志强拿着李丽芳的照片来问话 4. 鹤遂陪她拔牙、讲那个关于女生的故事 5. "那颗牙齿别扔""我要"与十八岁生日礼物 6. 雪糕的取笑与"最好的时光，也是最坏的时光"

**逐章写法公式**：

- **情绪流向**：起：疲惫（偏头痛、两个周末没见） → 承：甜（井边的口腔检查、智齿揭晓） → 转：悬与怕（陈志强的照片、拔牙与那个故事） → 合：暖而痛（雪糕的取笑、智齿作为生日礼物 + "最好与最坏"的预叙）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：上门看望与井边检查（把病症推进到可治愈的病因） + 陈志强的照片（保险线与新悬念插入） + 医院排队与拔牙（用故事置换疼痛） + "我要那颗牙齿"（埋伏笔） + 雪糕斗嘴与十八岁生日礼物的揭晓（甜点收尾，同时给出"最坏"预告）
- **本章核心技巧**：全章以"他的手指"串起三段——摸出智齿、让她抓住手臂、最后从袋里掏出那颗洗净的牙齿；同一只手既诊断又安抚又留着她的东西，人物关系不靠台词推进而靠这条触觉线
- **卡点与伏笔**：结尾卡点："这个会是半年以后——我的十八岁生日礼物"（智齿的去向与半年后的节点）；埋设/回收伏笔：陈志强拿李丽芳的照片问话 → 保险线的真正目的未明；鹤遂讲的那个女生的故事 → 前史／影射仍未点破；"他早就忘记她夸过他的手" → 与"被彻底忘却的以后"呼应

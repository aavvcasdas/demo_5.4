# 第83章 病症 摘要

**概要**：周念上次如此真切感受到鹤遂的体温还是在四年以前，她醒来时依旧有不真实感——男人双臂放松地环在她腰间、脸一整晚亲昵地贴着她后颈，窗外阴雨连绵。鹤遂通常比她早醒，这天却是例外，直到客厅传来紧促的按铃声他才一下醒来；他随手取出一件黑色体恤往头上套，说"等我回来抱你去洗漱"，还笑着戳穿她装睡。周念如今耳朵灵敏，在卧室里就听见他骤然如冰的嗓音"你还敢出现在我面前？"，紧接着是剧烈的碰撞声和厮打声。她赤脚摸索着往客厅走，途中踢到柜脚、左脚脚背肿起，仍继续往前。来的人是鹤广——穿翻领皮夹克、金戒指金项链齐全、脸上黄气依旧、颧骨挂不住肉，一副刻薄毒相；他谄媚地喊"你毕竟是我儿子嘛"，讨要他两个月没收到的高额生活费。鹤遂揪着领子把人提起来摔撞在门上，一字一顿"我，问，你，谈，什，么"，每说一个字就把鹤广往门上重撞一下；随后把人甩进屋，踹肩膀、踹腹部，蹲下时眼里写满厌恶憎恨和近乎癫狂的狠厉，骑上去说"老子今天打不死你"，随手拿起身旁茶几上的花瓶。就在花瓶要砸下去时，周念清软的一声"鹤遂"让花瓶悬停在半空；她说"你不能打死他""你不能因为一个烂人毁了自己"，鹤遂高举手缓缓垂下，把花瓶放回原处、里面的向日葵毫发无损，只踢了鹤广一脚说"滚"。鹤广临走前放狠话"好得很鹤遂，你给我等着"，保安随后前来解释是鹤广自称患者家属才被放上来。鹤遂靠在沙发上烟一根接一根地抽，看见她左脚的红肿后立刻揿灭烟、抱她到沙发涂药膏。周念借机问他为什么今天这样对鹤广——毕竟在京佛他还给鹤广买别墅、每月拿高额生活费供他挥霍；鹤遂沉默几秒后说"都说了那不是我"，并说鹤广算是间接害死他妈和他妹妹的凶手、"他死了我都不会给他买口棺材"。周念从完全不信转为有所怀疑，主动问出那个名字：沈拂南。他否认伤她的话是自己说的，并求她再给回那条智齿项链；她说扔在了南水河，他说"我不能没有它，就像我不能没有你一样"。她质疑沈拂南是否真实、说他作为奥斯卡影帝骗人易如反掌，他提出可以去做测试——"人会撒谎，可仪器不会"。周念一根一根抽回自己的手指，说出"不重要了"、"我们都是回不去的我们，中间有着渡不过的河"，最后以"那是你的事情"回应他的"我不能没有你"。

**关键事件**：1. 阴雨清晨与他的晚醒、按铃声 2. 鹤广上门讨要生活费、被按在门上一字一撞 3. 花瓶悬停于周念的一声"鹤遂" 4. "你不能因为一个烂人毁了自己" 5. 鹤广放狠话与保安解释 6. 涂药时追问京佛买别墅之事、"都说了那不是我" 7. 问出"沈拂南"这个名字与智齿项链被扔进南水河 8. "人会撒谎，可仪器不会"与"我们都是回不去的我们"

**逐章写法公式**：

- **情绪流向**：起：暖（不真实感的清晨、被环住的腰） → 承：恶（鹤广上门、按在门上的连撞） → 转：停（一声"鹤遂"与悬停的花瓶） → 合：冷（"都说了那不是我"与"那是你的事情"）
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：阴雨清晨与他的晚醒（用环境交代时间跳跃） + 按铃声打断（用一个外部事件开启冲突） + 赤脚摸索与踢肿脚背（用她的行动代价承担旁观位置） + 鹤广登场的外貌速写（用刻薄相强化来者不善） + 领子撞门与"我，问，你，谈，什，么"（把冲突推到肢体极点） + 讨要生活费与"打钱哪有打你有意思"（点明冲突起因） + 骑上去与拿起花瓶（把暴力推到不可挽回的临界） + 一声"鹤遂"使花瓶悬停（用最小干预完成转折） + "你不能因为一个烂人毁了自己"与花放回原处（把停手写成可见结果） + "滚"与"你给我等着"（收束冲突并留下威胁） + 保安解释与抽烟（用余波写他的低气场） + 看见红肿、抱上沙发涂药（用照护动作打开对话窗口） + 追问京佛之事与"都说了那不是我"（把双人格从传闻推为自认） + 问出"沈拂南"与项链的去处（把被否认的责任具体化） + "仪器不会撒谎"（给验证方式设下承诺） + "回不去的我们"与"那是你的事情"（用比喻完成拒绝并收章）
- **本章核心技巧**：把"双人格"这条主线的可信度一次性抬高——不是靠鹤遂自证，而是让他先以暴力展示与京佛时期完全不同的面孔，再由他自己说出"都说了那不是我""他也算是个间接害死我妈和我妹妹的凶手"，最后让他主动交出名字"沈拂南"并提出"仪器不会撒谎"；读者与周念同步从"完全不信"走到"有所怀疑"
- **卡点与伏笔**：结尾卡点：她说"那是你的事情"，他只留下"可是念念，我不能没有你"——他的绝望尘埃落定，而她的下一步态度悬而未决；埋设/回收伏笔：鹤广临走前的"你给我等着" → 第84章两分钟录像与勒索短信的直接引信；鹤遂右腹部第二道来源不明的刀疤在此章未解 → 由第84章沈拂南一句"你就不怕我学你一样？"回收；智齿项链被扔进南水河 → 他追问具体位置，暗示他可能真的去捞；"他死了我都不会给他买口棺材" → 与鹤广当年对宋敏桃、宋平安之死的间接责任挂钩；"人会撒谎，可仪器不会" → 测试承诺留待后续兑现；"我的命一样苦"式的自嘲在本章出现于"都说了那不是我"的平静里 → 暗示风光者另有其人
- **时间线**：本章为第82章雷暴之夜的次日上午至午后（阴雨天）

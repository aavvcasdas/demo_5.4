# 第114章 病症 摘要

**概要**：周念伏在鹤遂肩头泣不成声，段武递来抽纸，鹤遂一边抚她的背一边接纸，还回头给段武一个谢谢的眼神，随即提议"要不我们先回去，下次我自己过来"——他那么害怕面对与善进有关的一切、那么需要她陪着，却见她一哭就毫不犹豫地让步，宁可独自去面对痛苦也不愿见她掉眼泪。周念哭得岔气坚持"我要陪着你"，卢国强搓着脸劝她先回去、怕接下来的谈话她更受不了，她立刻坐直、用手背抹净眼泪说"我要在这里陪着鹤遂，我哪里也不去"，并握住他的手以表决心。切入正题后，卢国强问他在善进待了多久，他答"197天"——其他人最长不超过一个月，他被关了整整六个月。被问里面是什么样的，他眉心抽搐、条件反射般闭上眼睛，缓了一会儿才挤出"像地狱一样"；再被要求细说时他大口喘气、额头冒冷汗，周念连忙给他拍背，卢国强抬手说你说不出来也没事，他们已经看过了监控。周念脱口"我要看"，卢为难地看了鹤遂一眼，她明白当事人不同意就看不到，便红着眼说"我想知道你都经历了什么"。鹤遂垂眼长久沉默，忽然提起两人决定在一起那晚南水河畔的对话——"念念，不管我是什么样，都别离开我""我不会"，然后狼狈地哑声说"我怕你看了以后，会收回说过的话"；她再次答"我不会"，他便露出赴死般的神色说"那看吧"。段武操作投屏，加载圈转到78%时，鹤遂蹭地站起说"我出去抽根烟"，在走廊里急颤着手点烟，眼尾被烟雾熏红，一想到将出现在屏幕上的画面就头皮发麻。画面亮起：一间没开灯、连一扇窗都没有的黑屋，唯一光亮来自门上的长方形小窗，屋里没有床也没有任何东西，只有一个蹲厕的坑白晃晃浮在暗色里；角落里有什么动了动，卢国强两个字确认"是他"——屏幕角落里蜷着的少年鹤遂没有穿衣服，颈骨和肩胛骨微微浮凸，连一条内裤都没有。卢国强说才被送进善进的孩子都会被扒光衣服关小黑屋，"他们不是在教育学生，而是在训狗"。门被打开，一个穿暗绿迷彩服、手持长钢棍的教官走进来，听见脚步声的少年抬头撑地、五指张开、手背青筋毕现，开口第一句嘶哑地问"周念在哪里"；教官说等他改造好、学会感恩父母好好听话就能出去见想见的人，少年眼里狠厉尽显："她还在火车站等我，放我出去。"教官冷笑，少年骤然暴起，一拳砸在他脸上、顺势夺过钢棍朝他脑袋挥去："我——要——见——她！！！"教官本能抬臂一挡，凌厉惨叫中食指变形折断，倒地呻吟。鹤遂持棍快步朝外走，走到门口却猛然僵住、开始缓慢后退——踩着他后退脚印进来的，是另外五个同样穿迷彩服的教官。倒地的教官愤怒指着他喊"给我打——往死里打""把他的手也给老子打断"。前五分钟他凭一根钢棍与五人五五开，额头流血糊住眼前也不后退；五分钟后有人从背后踹他腿弯，他脊背剧烈一颤跪倒在地，就此再也没能站起来，五人蜂拥而上拳打脚踢，他抱头蜷缩着发出愤怒绝望的咆哮，有人边踢他的头边骂"在善进就没有硬骨头，再硬的骨头也能给你熬碎"。钢棍一次次落下，他痛到痉挛抽搐仍被抓着头发用头撞墙；被问"错了没"，他冷笑着朝对方脸上吐了一大口血沫，那人将他掀翻、一脚踩在他臂弯，硬生生踩断了他的手；临近末尾，有人解下皮带对着他的头撒尿，用最恶毒的字眼羞辱他，再问"还找不找那什么周念了"，满脸血污的他仍以不屑的顽固姿态笑着答"找"。周念终于绷不住放声嚎啕，哭声引来门外的鹤遂，他推门进来时正看见屏幕上狼狈至极的自己；他低哑地说自己就是害怕她看见这样的自己会嫌弃、然后不要他，自责自己那么没用、任由别人在头上撒尿都无能为力，还让她在火车站等了一整个晚上——周念这才明白他为什么反复强调"不管我是什么样，都别离开我"。段武看不下去催她"你赶紧抱抱他吧"，周念抱住他说"我只会心疼你，怎么会嫌弃你不要你"，他发出劫后余生般的叹息。卢国强随即说挨打只是冰山一角，据调查他还经历过长时禁食和电击：画面上他以肉眼可见的速度消瘦，不被给任何食物、只许喝冲厕所用的脏水，最长一次禁食记录13天，最瘦时体重只有80斤——以189的个子看几乎是一具行走的骨架。他不分昼夜地昏睡，清醒时就用小石子在墙角刻字，字迹被监控清晰捕捉："念""念念""周，念""周吴郑王的周，念念不忘的念"；也是从这时起他开始出现幻听，对着空气暴呵"能不能闭嘴""别和我说话"，周念问是不是其他人格开始出现，他低低地嗯一声，说每次抬头只看见一片昏暗的空荡荡，才意识到自己病了。段武问所以他们就开始电击，下一幕他被绑在黑色皮床上，四肢瘦得随意可折、胸膛如展开的两扇排骨，头上胸上贴着电极片，通电后浑身剧烈痉挛却动弹不得，只能捏紧拳头、蜷紧脚趾发出撕心裂肺的哀嚎；十秒后他无法控制地小便失禁，身旁的他别开眼不敢看，只在桌底把她的手握得很紧很紧。卢国强问接受过多少次这样的电击，他故作平静地答"126次"，并说后期几乎每天一次、每天都逃不过被自己尿泡湿身体。问到怎么出来的，他说身体里冒出很多其他人格，是"其他一个人，不是我"去向鹤广认错、答应听话照做才被放出去——沈拂南用绝佳的演技跪在鹤广面前哭得情真意切、画了一堆养老的饼，鹤广信了，兴高采烈领他回家。卢国强又从纸箱里拿出一本日记，说他们在里面没看，让他和照片一起带走。离开询问室下楼时，周念在楼梯平台从背后一把将他抱紧，哭着问"我能不能永远和你在一起"，他答"只要你愿意，我就永远都在"；她问你为我做过那么多为什么什么都不说，他抚着她的脸说"傻不傻，爱不是用说的"，她捧着他的脸一本正经地说"你是全世界最好的你"，并说不堪的从来不是他而是那些魔鬼，他们会统统去坐牢，而他会在阳光下坦荡地活着。

**关键事件**：1. "要不我们先回去"与她的坚持留下 2. 一百九十七天与"像地狱一样" 3. "我要看"监控 4. 南水河畔的旧约与"那看吧" 5. 黑屋里的裸身少年与"他们是在训狗" 6. "周念在哪里"与"我要见她" 7. 五个教官与再也没能站起来的那一跪 8. 踩断的手与撒尿羞辱后那个"找" 9. 十三天禁食、八十斤与墙角的刻字 10. 一百二十六次电击 11. 沈拂南替他向鹤广认错 12. "爱不是用说的"

**逐章写法公式**：

- **情绪流向**：起：心疼（她的崩溃与他主动的退让） → 承：紧张（197天、"像地狱一样"与观看权的交锋） → 转：恐怖与热血交替（一敌五的高光、五人围殴的崩塌、踩断手与撒尿后仍答"找"） → 合：悲伤转暖（禁食、刻字、电击的余波与楼梯上的"你是全世界最好的你"）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：让她留存（先把陪伴权争下来） + 让他同意（用旧约换一次被看见的许可） + 投屏回放（把最重的伤害交给监控画面，用画面代替自述） + 楼道收束（把审判权交还给她，用一句定性结束）
- **本章核心技巧**：全程用"物证+监控"代替回忆——派出所的纸箱、照片、献血证、清单、监控、日记本依次登场，最惨烈的部分不以闪回叙述，而以"在场的人一起看屏幕"呈现，让人物的反应层实时叠在画面上。
- **卡点与伏笔**：结尾卡点：纸箱里那本"他们没看"的日记被带走却尚未翻开，下章期待是日记里写了什么；埋设/回收伏笔：南水河畔"不管我是什么样，都别离开我"（本章回收并重新表决）；善进学院 = 沈拂南口中"那个地方"（坐实）；沈拂南=替他认错、把他救出善进的人格（对照第112章的"帮我逃出来"）；"火车站等了一整晚"（回收第111章）；墙角刻字"周吴郑王的周，念念不忘的念" ↔ 他反复害怕被嫌弃；第三个红色小本（第113章遗留，本章未再提）；日记本 → 待下章。

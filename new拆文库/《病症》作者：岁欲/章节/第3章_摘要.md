# 第3章 病症 摘要

**概要**：周念没有离开，鹤遂也没多看她一眼，是他先移开目光。他把铁锹放回五金店摊上并向老板道谢。周念看着他逆光站着，掌心斜插着一块碎玻璃、一半陷进血肉，随后他面无表情徒手把碎玻璃拔出、抛进垃圾桶，眼睛都没眨。这个动作让她产生一个荒唐念头——月底人物绘画大赛"画谁都可以"，她偏偏想画眼前这个凛冽的少年。同学罗强拦住她，用说书般的口吻科普"疯狗"的来历：他亲眼见过鹤遂父亲拿杀猪刀架在儿子脖子上，鹤遂不眨眼、臭着脸挑衅让他砍死自己。周念听完更好奇、更想去和他说话。她上前问"你好，能……能给你画一张吗？"，被冷漠无情地回两个字："傻逼。"她不会骂人，也不觉得不占理的自己该生气，索性从袋里挑出一个橙黄橘子塞进他没受伤的手里，笑得超甜："对不起啊，是我打扰你了。"鹤遂怔住、盯着橘子发呆，随后飞快转身跑掉。罗强惊叹"你绝对是第一个让疯狗掉头就跑的人"。周念因此失眠整夜，半夜三点还在想他到底跑什么。而另一边，鹤遂到家才发现自己拿着个橘子跑了一路，第一件事就是把橘子扔进垃圾桶，然后去洗澡——沾血的橘子静静躺在垃圾桶里，没有再被看一眼。

**关键事件**：1. 鹤遂徒手拔碎玻璃 2. 周念产生"偏偏想画他"的念头 3. 罗强科普"疯狗"与杀猪刀旧事 4. 周念求画被骂"傻逼"，塞橘子后鹤遂落荒而逃 5. 橘子被扔进垃圾桶

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| "想画他"的动机必须落在一个动作上 | 不写她被外貌吸引，只写她把碎玻璃从肉里拔出、连眼睛都没眨、抛进垃圾桶"准确无误"——她因此产生"荒唐的念头" | 用一个动作触发动机 | 期待 | 让女主的爱慕始于男主的强悍与忍痛能力，而不是脸 |
| 全镇共识作为反预言 | 用罗强之口说两人"不是一个世界的人""永远不可能有相交点"，再补罗强的绰号科普 | 反预言式铺垫 | 期待 | 越是强调不可能，读者越期待他们相交 |
| 女主的反制手段是"递东西" | 被骂后她"不会骂人"，于是从袋里挑出最好的橘子塞过去，并以道歉收场 | 行为定义人设 | 甜、心疼 | 让温柔角色在被伤害后用给予回应，人设一次性立稳 |
| 掷物成信物的处理 | 橘子第一次交付就被扔进垃圾桶，与文案中"存到冰箱第三层放到腐烂的橘子"形成状态落差 | 信物状态的落差 | 悬念、心疼 | 信物不要一次就珍贵，让它的"被抛弃"成为日后被珍藏的对照 |

**逐章写法公式**：

- **情绪流向**：起：尴尬（目光错开） → 承：好奇（拔玻璃、科普） → 转：意外（傻逼→橘子→他跑了） → 合：悬空（橘子被扔）
- **节奏配比**：慢铺垫 60% / 快冲突 20% / 爽点爆发 15% / 悬念留白 5%
- **本章结构公式**：收上章对视 + 拔玻璃（动机触发） + 罗强科普（人物补全） + 上前求画被骂 + 塞橘子与逃跑（反转） + 男主视角扔橘子（冷收）
- **本章核心技巧**：把全书第一次"交锋"做成一场错位的攻守——她给，他逃；同一颗橘子，在同一章里分别被"送出""拿着跑一路""丢进垃圾桶"，用一次物品的三段状态完成关系定调
- **卡点与伏笔**：结尾卡点："沾血的橘子静静躺着垃圾桶里，没有再被看一眼"；埋设伏笔：杀猪刀旧事（人格分裂成因的暗示）、"第一个让疯狗掉头就跑的人"

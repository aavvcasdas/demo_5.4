# 第99章 病症 摘要

**概要**：周念在灼阳之下听完沈拂南的话，明明是盛夏烈烈的天气，她却感觉到骨头缝里流窜的寒气，抬手按住左边胸口，惊悸和震撼都没有散去；沈拂南很满意她此时的表情，主动松开她的手腕，悠哉退到枯井旁坐在井沿上，脚边是常年无人使用而积灰严重的水桶——当年就是在那个位置，鹤遂俯身弯腰摸到她口腔里作痛不止的智齿。他替自己点燃一根烟打破沉默，说该你知道的你都知道了，周小姐，做个决定；她只觉得双脚离地几万里、晕眩感很明显，哑着嗓子问做什么决定。他反问"你觉得呢"，说我把那个疯子为你做的都告诉你了，你决定要不要回到他身边、尽快结束这一场闹剧；她又想到沈拂南和鹤遂的那个赌约——输的人会消失三个月，便轻声问我要是回到他身边，你就会消失是吗，他脸上毫无惧色，反而笑着说鹤遂不需要你自我牺牲，他要的可不是你为了救他而和他在一起，他要你真的爱他。这世界上只有两个人真的了解鹤遂，一是周念，二是和他共用一个身体的沈拂南；她当然明白他话里的意思，还没来得及开口，他便意味深长地啊一声说"我明白了"，随后以得胜者的姿态说你被他的行为感动、也对他还有感情，但你不会再和他在一起了。她呼吸一紧，水盈盈的眼里铺开灰暗，有种被人窥探到内心的仓促和羞耻；他起身绕着她走了三圈，说归根结底你现在和他的差距太大，即便红的是他，只要他带着这身皮囊出去就是万众瞩目的巨星，而她永远都只是一个平平无奇的小镇姑娘，两人之间早就有一道跨不过去的现实鸿沟。沈拂南说得一个字都没错，她垂在身侧的手指蜷紧、指尖发白，眼底的泪水越蓄越多；他抽身站好、姿态闲散地冲她微笑说"周小姐，那咱们后会无期"，抬脚与她擦肩而过。她哽咽着开口让他等等，转过头看着他的背影说"我还有话想对他说"；他从鼻腔里哼出一丝冷笑问说什么，她嗫嚅着苍白的唇没能发出声音，他转过半张轮廓分明的脸冷冷地说你要是想告别那就免了，你不觉得对他太过残忍，又说倒也不是同情他，只是不想在这个鸟不拉屎的地方浪费太多时间，她看着他踏出木门槛的背影，没有再尝试开口。郁成等在门外，门打开时他看见眼里冷漠、周身气场强大的男人，还有院子里站在一堆枯叶中间的瘦弱周念，犹豫着问遂哥你一个人走吗；沈拂南眉梢一挑说"你是鬼？"，郁成忙解释说我的意思是周小姐不一起吗，他语气骤冷说你要是想和她一起你就去，郁成一头雾水却不敢多嘴，默默替他拉开车门。周念看着那扇缓缓合上的木门，深知就此一别不知道多久才会再见——要是沈拂南一直拥有身体的掌控权，他就永远不会再回来，起码按赌约她至少三个月都不会再见到鹤遂；她还想再见他一面，做一个好好的告别，为她这段荒诞不经的经历，也为他们之间那场互为救赎之光的青春。走出南水街时，她看见前方石桥上有一道熟悉的身影——冉银撑着遮阳伞，穿着玫红色的碎花裙子，头发在脑后盘作一个漂亮的髻，打扮得非常周正端庄，还涂了口红，在她印象中冉银已经很久没涂过口红。冉银把伞举过她的头顶说"七斤，你回来了"，又说今天是妈妈生日，问她能不能陪妈妈吃一顿饭，在家已经做好了；有些恍惚的她没有拒绝，冉银喜出望外、开心得几乎落泪，连说好几个好。到家后冉银把她带到画室——画室被打扫得一尘不染，每一根画笔都被擦得发亮，连一粒灰尘都看不见，说你既然已经决定重新画画，那我就想着把画室打扫出来，不能用的颜料都扔掉了、我买了新的；她抿抿唇没说话，转身离开画室，她不见得会留在这个小镇。堂屋的八仙桌上摆满菜肴，她细细一看发现一半是她以前常吃的菜、一半是她不爱吃的菜，冉银看着那半边笑笑说"这些都是我爱吃的"——干烧冬笋、爆炒肥肠、杏仁银肺汤等等，一起生活这么多年，这还是周念第一次知道冉银爱吃什么菜。冉银说从前只顾着照顾你的饮食，你吃什么我就跟着吃什么，都没有特意为自己烧过一顿饭，今天这一半的菜都是我为自己做的；她坐下想了想，还是说了句生日快乐，冉银眼里瞬间沁满泪水却没有让眼泪落下来，说谢谢宝贝、妈妈今天真的很开心，吃完这顿饭妈妈也会让你开心的。被问"让我开心？"时，冉银替自己夹了一块笋，用特别轻松的语气说"吃完这顿饭，我就决定去自首了"，周念脑中瞬间空白——这个消息来得太突然，让她没有任何反应时间。冉银眼里带着泪水笑着说，那天去东济医院看她回来后特别开心她开始好转、身上和脸上都长了不少肉，所以一直在想自己到底是希望她有出息、出人头地变成大人物，还是希望她健康喜乐，身为一个母亲还是更希望宝贝健康喜乐；她鼻尖猛地一酸，冉银的眼泪滴在那片冬笋上，一边咀嚼一边还在笑，说所以你变不成毕加索梵高那样的名人也没关系了，只要你活着、是开心地活着，笑容能常常出现在你的脸上，那就足够了。饭菜的颜色在她眼里被模糊成一片水影，眼泪顺着脸颊流成两条河，在下巴处相汇再继续滴落；冉银接着说"七斤，你说得一点都没错，一直以来是我太自私，是我抓着自己的执念不放"，又说自己先是一个独立的人、才是你的妈妈、才是周尽商的妻子，这么多年都没能明白这一点，把思想强加在她身上、希望她去完成自己没能完成的梦想。她夹了一个肉丸子大大咬了一口，憋着眼泪轻声说"好吃"——原来当年莫奈不是在说客套话，冉银烧的菜是很好吃，对她来说也是妈妈的味道；人哪有彻头彻尾的善恶，冉银一念之差踏错设局杀死周尽商、有着变态的掌控欲，但谁都无法说她不爱周念，只是她的爱太让人窒息，饶是如此她依旧是世界上最爱周念的人——冉银生她时发生羊水栓塞，在手术台上抢救了29小时、输血超过7万毫升才被从鬼门关拉回来，这一案例至今还被医院当作经典宣传，99%死亡率的羊水栓塞她居然成了那1%，只是从未对她提起过。这是周念第一次在冉银面前心甘情愿地吃完一整碗饭、菜也吃了不少；在去派出所的路上她主动牵了冉银的手，就像小时候害怕迷路时一样，只是这一次她是怕冉银迷路，怕她有了去路、忘了归路。来到派出所的台阶前，冉银转身笑着摸了摸她的头又摸了摸她的脸蛋，眼神里尽是依依不舍，却没有说她以为会听到的好好画画、抽时间探监之类的话，只捧着她的脸笑得特别温柔地说了一句"好好吃饭"；她眼泪夺眶而出的那一瞬间，冉银迈着轻松的步子踏上派出所的台阶，穿着玫红色碎花裙的背影美丽飘逸，仿佛回到年轻时候，走向的不是监狱而是一种真正的解脱和自由。就在背影快要消失时，周念突然放声喊了句"妈妈"，冉银后背一僵、陡然转身，眼里积蓄着满盈盈的泪水——她已经很久没听见周念叫过她一句妈妈；周念冲上楼梯跑到她面前拉起她的手说"我陪你去和警察说"，冉银满脸泪水、笑容却灿烂如三月阳光，哽咽着说好。接警前台的民警看向手牵手走进来的这对母女问有什么事，冉银眼里是坦荡的光、脸上带着从容的微微笑意，不疾不徐地说了出来："我要自首。"

**关键事件**：1. 枯井旁的最后通牒 2. "他要你真的爱他" 3. 被说中的"你不会再和他在一起了" 4. 跨不过去的现实鸿沟 5. 后会无期 6. 石桥上的玫红碎花裙 7. 为自己做的那一半菜 8. "吃完这顿饭我就去自首" 9. 99%死亡率的羊水栓塞 10. "好好吃饭" 11. 那声"妈妈"与"我要自首"

**逐章写法公式**：

- **情绪流向**：起：紧张（枯井旁的最后通牒与当面被拆穿） → 承：压抑（现实鸿沟与会后无期） → 转：心疼（生日饭、为自己做的那一半菜） → 合：悲伤中带释然（自首、那声妈妈与"我要自首"）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：被逼做决定（用最懂他的人拆穿她的退缩） + 切断联系（后会无期与三个月的时间锁） + 一顿生日饭（把母女关系的所有账一次结清） + 送她去自首（用称呼与牵手完成最后一次身份交接）
- **本章核心技巧**：用一桌菜完成人物和解——一半是女儿爱吃的、一半是母亲为自己做的，多年被压抑的自我与多年被强加的期待在同一张桌上摆开，自首的决定则夹在夹菜的动作里说出。
- **卡点与伏笔**：结尾卡点：冉银走进派出所说出"我要自首"，案件如何定性、刑期多少尚未交代，下章期待是自首的后续与周念如何面对；埋设/回收伏笔：沈拂南与鹤遂的赌约（输的人消失三个月）→ 三个月的时间锁；"他要你真的爱他"（给她的真正考题）；枯井与智齿（回收旧场景）；冉银重新打扫的画室 ↔ 她"决定重新画画"；周尽商之死（自首对象）；"好好吃饭" ↔ 他"迟早把你喂到四十九公斤"的目标；莫奈曾说冉银菜很好吃（本章验证）；三个月后与鹤遂的重逢待续。

# 第109章 病症 摘要

**概要**：身上只有清淡皂香的鹤遂把话说到"为爱做鸭"，周念今年二十二岁、在这件事上毫无经验，索性闭眼摆出赴死的决绝模样说"那……那你来吧"。鹤遂被逗笑，扒开她的眼皮、弹了一下她的额头，说"你这是想直接把我送进去是吧""二年起步"，并解释强奸罪是二年以上十年以下；周念嗫嚅"我也没说不愿意……就是有点儿没准备"，他便翻倒在她身旁躺下、搂住她的肩膀说"那就等你有准备"。他察觉她纠结后主动说"我能忍住"，又说"念念，我们还有很多时间"；周念暖意涌上心头，主动回抱住他。关灯后她缩脚时不小心把缠在他腰上的浴巾蹬掉了，他慢悠悠地说"你把我浴巾蹬掉了"，又笑着问"周念，你不会是故意的吧"，随后握住她的手腕、抓起她的手放进被子里，说"真相是需要探索的"，两人同时僵住，他呼吸骤重，低声说"我是让你摸浴巾，而不是——"。周念翻身背对他要睡觉，他温柔地从背后抱住她、亲她的后颈，说"睡吧"，又提起"做人格整合的时候，我想你陪着我"，她说好，并承诺"每次都陪着你"。半睡半醒间，周念借着月色看见他倚在桌沿低头按手机、打字速度很快。后半夜她被渴醒，为了不吵醒熟睡的他，轻手轻脚到厨房找水；打开手机手电筒时瞥见一条新通知——【鹤遂艾特了你】。她点进那条微博，看见他用有四千万粉丝的大号在凌晨2:34公开她："热搜有看到，谢谢你们对我的关心，她没有纠缠我，是我一直喜欢她并且在追求她，我喜欢了她四年，她现在是我的女朋友@一起逃亡吧"。她怔在楼梯上，震惊于他竟知道那是她的账号、又如此毫无顾忌地公开她。评论里炸开了锅，有人替她从前的行为道歉、有人扒出她是画画的天才。周念到客厅拉开电视柜，从柜子角落里摸到一片薄薄的软包装——一个套，随即上楼，掀开被子主动趴到熟睡的鹤遂身上，说"我不想睡觉了"。

**关键事件**：1. "那你来吧"与"二年起步" 2. "我能忍住"与"我们还有很多时间" 3. 蹬掉的浴巾与"我是让你摸浴巾" 4. "做人格整合的时候我想你陪着我" 5. 半夜的【鹤遂艾特了你】 6. 凌晨2:34的公开微博 7. 电视柜角落里的那个套 8. "我要和你，永远"

**逐章写法公式**：

- **情绪流向**：起：烫（"那你来吧"） → 承：笑（"二年起步"与浴巾） → 转：暖（"我们还有很多时间"） → 合：惊与决（凌晨2:34的微博与电视柜里的套）
- **节奏配比**：慢铺垫 25% / 快冲突 5% / 爽点爆发 25% / 悬念留白 45%
- **本章结构公式**：皂香与"那你来吧"（把暧昧推到临界） + "二年起步"（用玩笑按住场面） + "我能忍住"与"很多时间"（用克制写深情） + 关灯与蹬掉浴巾（用道具制造尴尬） + "我是让你摸浴巾"（把尴尬升一级） + "我想你陪着我"与"每次都陪着你"（把承诺放进睡前） + 半睡半醒里的打字身影（埋下伏笔） + 半夜的【鹤遂艾特了你】（延迟揭晓） + 凌晨2:34的微博全文（用一次公开落实安全感） + 评论区的三类反应（用第三方声音补成效） + 电视柜角落里的那个套（把主动权交回女主） + "我不想睡觉了"与"我不后悔"（把决定权交给她） + "我要和你，永远"（用一个短句收尾）
- **本章核心技巧**：整章由三次"谁主动"的交接构成——他先按住自己、再按住她；她先被按住、最后反过来主动；三次交接全靠具体道具（浴巾、手机、安全套）和一句台词完成，没有一次靠内心独白
- **卡点与伏笔**：结尾卡点：周念拿着那个套主动趴到他身上说"我不想睡觉了"，本章在事前情话处收束，之后的走向留给下一章；埋设/回收伏笔：凌晨2:34的公开微博 → 第110章郁成说"一晚上掉了九十万活粉"；他的手机在半夜响过一声 → 她当时以为是错觉，后被微博验证；"做人格整合的时候，我想你陪着我" → 第118章东济的治疗；"我们万年长青" → 与第119章"我们之间，距离恒定"的呼应；@一起逃亡吧这个账号 → 第117章他解释是靠直觉认出她的评论
- **时间线**：本章紧接第108章当夜，自就寝前延至次日凌晨四点

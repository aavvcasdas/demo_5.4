# 第51章 病症 摘要

**概要**：周念从未想过会有这么一天，她会像逃离鬼窟似的逃离自己的家——以最快的速度冲出画室、下楼、奔过堂屋，穿过院子时两只拖鞋都因跑得太快跑掉了，她不敢弯腰去捡，生怕稍有遗顿就会被赶上来的"女鬼"抓住，赤着两只脚飞快地跑出院子。只有七十多斤的她体力根本难以支撑跑出太远的距离，却不知道被从何而来的信念支撑着不停地朝前跑，哪怕气喘吁吁、一步一猛喘也不肯停下——她总觉得那披头散发、伸着手朝她飘来的女鬼始终在她身后十米，且女鬼没有脚。混乱的脑子里始终只有一个答案：南水街，那条去过无数次的小巷，小巷的尽头，哪怕她心里很清楚那个人早已不在南水街、已经离开小镇且不会再回来。过一座石桥时，她右脚的脚底踩到锋利的物体，尖锐的刺痛让她踉跄着摔倒在地，她喘了两口气又咬着牙强迫自己站起来，一瘸一拐地继续往前，石桥上由此现出斑斑血意；好不容易来到南水街那条熟悉的小巷口，她眼里燃起一点希望，旁边按摩店的门上贴着转租的广告纸，她垫着伤脚扶着墙缓慢往前，停在熟悉的木门前时已经狼狈得不成人样——赤着的双脚沾满灰尘泥土，脚踝上只剩薄薄一层皮肤，白色连衣裙被灌进巷子的风吹得摆动，站在裙中的她已经撑不起裙子本身。她抬手敲门，无人来应，再加快频率敲得更响，仿佛这样就会有一张熟悉的脸来给她开门；敲到最后精疲力竭，她不记得敲了多久，半边身子靠着门，脱力的身体缓缓坠落——之前他总会接住下坠的她，一次又一次。她跌坐在与他曾在深夜同坐过的门槛上，希冀的光完全湮灭，绝望地抱住双膝埋着脸哭。面前突然传来脚步声，她心脏一悸、迅速抬头，看清来人后眼里的微光重新寂灭——是罗强。罗强耸肩说"不然还有谁。鹤遂吗"，又盯着她看了好一会儿说"他不会再回来了"；周念捏着自己的脖子觉得有什么卡着让她呼吸困难，手往下滑到胸口，那里有像拧痛又像放射性刺痛的强烈痛感，她分辨不清，只觉得明明知道他不会回来，再一次从别人口里听说时还是会难受到生不如死。罗强看她不穿鞋搞成这样，说要送她回家，她一听到"回家"这种字眼心里就忍不住觳觫，坚持拒绝并扶着门站起来，差点跌倒，罗强伸手扶她又被她不动声色地躲开；他不坚持，目送她扶着墙一瘸一瘸离开，在她右脚抬离地面时看见了她血肉模糊的脚底。周念没有家可以回——那不是家，是一个驯养臣服的牢笼，也是滋生恶念的地狱，她漫无目的地在大街上游荡，不少人看见她纷纷侧目；不知不觉走到南水河边，河岸边垂柳依旧、没入水里的石阶长满青苔，她低头看见自己沾满血迹的右脚，想用河水洗掉血迹以免走在路上太引人注意，于是走下石阶靠近河水。就在她的脚踩在湿润柔软的苔上、脚趾已被河水淹没时，后方突然传来急促的脚步声，一阵风扬起她耳边的碎发，她在风里闻到熟悉的皂香——白色舒肤佳的味道；腰间突然多出一只冷白色的大手将她圈紧，下一秒她双脚离地悬空，整个人被抱着连上数级阶梯直到河岸上。双脚刚沾地，周念迫不及待地转身，对上一双黑白分明的眸子，是她辗转不能寐时想过无数次的那双眼——是他。她失控地伸手用双手抓住他的一条胳膊，眼圈红红地说"鹤遂，你别走，你不要走"，他面无表情地回"放开我"，她说"我不放"，他说"周念，你知道这样没用"；她比谁都清楚这样没用，了解他那么孤冷内傲、下定决心的事八头牛都拉不回，却仍说不愿放手，哽咽着说"你要去哪里，我都跟你走"。鹤遂眯着眼问她知不知道自己在说什么，沉默许久后像拿定主意般用手去掰她的手指说"我没办法带你走，周念，我之前已经把话说得很清楚了"；她绝望反问"可你明明还是关心我的，不然你刚刚为什么要把我抱上来""你是怕我也会想不开，选择投河自杀对不对"，他嗓音淡淡地回"别多想""我只是不想看见任何一个人再死在这条河里，换谁都一样，我都会这么做"。听到这句，她握着他的手一点点松开，他抽回手臂、深深看她一眼便决绝地转身离开；周念心如死灰，既然换谁都一样、她并没有什么特别，那她就搏一搏在他心里到底算什么——她毫不犹豫地转脚，比他还决绝地一瘸一瘸朝南水河奔去，顶着一张苍白而绝望的脸纵身一跃，白裙裙摆在虚空中翻飞，两秒后河面溅起一朵巨大的水花。听见落水声的鹤遂脚步骤然一僵，咬牙骂了一句"疯子"便迅速转身飞奔，一跃入水朝她游去；他看见水里的周念闭着眼、双手自然浮着、没有任何挣扎地往下沉，好像就是准备这样悄无声息地死在这条河里。当一只手被抓住时，周念知道自己赌赢了。上岸后鹤遂的第一件事就是发火，他生气时也很隐晦，只是单膝蹲在她面前用手轻轻掐着她的下巴迫使她看向他，眸光沉沉地低声警告"不要再做这样的事情"；周念迎着他的目光浅浅一笑说"只要你离开我的视线，我就会往南水河里跳"——她在明目张胆地威胁他，这惹得他很恼火，第一次觉得她嘴角的梨涡那么刺眼。僵持许久后他松开她的下巴凉声问"你到底想做什么，周念"，她咳嗽着吐出好几口水，唇上已完全没有血色，仍笑着用最清软又最绝望的声音说"鹤遂""要么带我走，要么让我死""你选一个"。

**关键事件**：1. 赤脚逃出家门、以"南水街"为唯一目的地 2. 石桥割伤脚底、一路血迹走到木门前 3. 敲门无人应、跌坐在曾与鹤遂同坐的门槛上哭 4. 罗强出现并告知"他不会再回来了" 5. 南水河边被鹤遂抱起、逼问与"换谁都一样" 6. 周念跳河逼他回头、被救上岸以死相胁

**逐章写法公式**：

- **情绪流向**：起：慌（赤脚逃出、身后十米的女鬼） → 承：空（敲门无人、门槛上的哭） → 转：痛与冷（罗强的告知、河边的抱起与"换谁都一样"） → 合：狠（跳河、被救、以死相胁）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：赤脚逃家（把家写成牢笼） + 石桥割伤与一路血迹（用代价写决心） + 空门与门槛上的哭（回收两人共坐的位置） + 罗强报讯（把"不会回来"再确认一次） + 街头游荡与河边洗血（把她推到最无依的境地） + 皂香与抱上岸（用气味连接两人） + 抓手逼问（把关系摊到桌面上） + "换谁都一样"与松手（把女主逼到绝境） + 跳河与捞人（以命下注） + 掐下巴与威胁（由她定下规则）
- **本章核心技巧**：整章只做一件事——把女主的"去处"从家换成人；前半章用一条血迹把她引向一间空屋，后半章用一股皂香把他从水里引回来；结尾不靠和解而靠一句胁迫式条件把两人重新绑定，关系由被动等待转为一手定夺
- **卡点与伏笔**：结尾卡点："要么带我走，要么让我死。你选一个"——男主必须当场给出选择，答案落在下章；埋设/回收伏笔：按摩店门上的转租广告纸 → 宋敏桃的店已彻底易主；小白裙与七十多斤的消瘦 → 康复线的谷底；"这不是家，是驯养臣服的牢笼，也是滋生恶念的地狱" → 她对家与母亲的最终定性；白色舒肤佳的皂香 → 他的气味标识，两人第一次见面时即已出现；"换谁都一样"这句冷话 → 后面必然被推翻；罗强的出场与"不然还有谁。鹤遂吗" → 镇上对他去留的共识

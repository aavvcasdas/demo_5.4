# 第107章 病症 摘要

**概要**：两人回家时线面早已饿疯，跑到厨房里找吃的、撞翻调料架，搞得一地狼藉。鹤遂蹲下身收拾，问"霍闯那小子怎么想的，送你一头猪"，周念说"可能是怕我一个人太孤单"；这话让他身上散出强烈的低气压，他耷着长睫掩住歉意，说"我以后都不会再让你孤单一个人"。周念问他线面还养不养，他反问她"你想养吗"，还说"那就养着，顺便也把我养着"，并说自己"就好一口软饭""我只吃你周七斤的软饭"。周念去衣柜拿睡裙，睡裙上是动画片《成龙历险记》里的小玉，两人一人一句地对起台词；她说起小时候母亲不让她看动画片、有时间只让她画画，这部动画还是她在上下学途中的路边商店看的，鹤遂沉默一会儿后摸摸她的头说"以后我陪你看"，还说"我希望你喜欢我，不是因为只接触过我，而是在你见过很多人后还是只喜欢我"。洗澡时莫奈打来电话，周念让他帮接并说自己正在洗澡；鹤遂只说了一句"念念在洗澡"，电话那头沉默了很久，莫奈用强装的平静语无伦次地说了一通便利落挂断。周念一出浴室就见鹤遂坐在她的书桌前用26键快速打字，她问莫奈说了什么，他说"她可能误会了"，随后把她拉到自己双腿之间，慢条斯理地把话说完——误会他们"在做"。周念装懵说"哦，可能以为我们在作画"，被他点出"做.爱的做"，还把膝盖屈起抵在她身上。她脸红着赶他去洗澡，他反问"有这么急"，又说吃软饭也要有吃软饭的觉悟，走向厕所前讨要一块她喜欢的舒肤佳香皂，被她说"你洗干净点"后凑到她耳边轻声说"好的老板"。

**关键事件**：1. 撞翻的调料架与"我以后都不会再让你孤单一个人" 2. "顺便也把我养着"与只吃她的软饭 3. 小玉睡裙与"以后我陪你看动画片" 4. 莫奈的来电与"念念在洗澡" 5. 书桌上的26键与"她可能误会了" 6. "作画"与"做.爱的做" 7. 舒肤佳香皂与"你洗干净点"

**逐章写法公式**：

- **情绪流向**：起：乱（线面撞翻调料架） → 承：歉（"怕你一个人孤单"与低气压） → 转：逗（软饭论、动画片、电话误会） → 合：烫（"做.爱的做"与"好的老板"）
- **节奏配比**：慢铺垫 30% / 快冲突 5% / 爽点爆发 10% / 悬念留白 55%
- **本章结构公式**：线面撞翻调料架（用家务开局、把情绪放低） + "怕你一个人太孤单"与低气压（用一句话点着他的愧疚） + "顺便也把我养着"与软饭论（用台词接力把气氛拉回轻松） + 睡裙与动画片台词（用共同记忆补童年） + "以后我陪你看"与"我希望你喜欢我"（埋题旨） + 莫奈来电与"念念在洗澡"（用一个误会制造笑点） + 书桌前的26键与"她可能误会了"（把误会转成暧昧） + "作画"与"做.爱的做"（同音双关升级） + 屈起的膝盖与"你不说话我就当你默认"（把暧昧推到身体层面） + 赶他去洗澡与讨要舒肤佳（用家常动作收尾） + "你洗干净点"与"好的老板"（用一句口误封章）
- **本章核心技巧**：整章几乎没有外部冲突，全靠对话推进——先用一句"怕你一个人孤单"把气氛压下去，再用"软饭""动画片""在洗澡""作画"四段对话一路把气氛抬起来，情绪曲线靠对话的明暗交替完成
- **卡点与伏笔**：结尾卡点：周念那句"你洗干净点"被鹤遂顺势接成"好的老板"，把"今晚"的悬念直接摆在读者面前，下一章紧接浴室花洒声；埋设/回收伏笔："以后我陪你看很多的动画片" → 与第116章"陪我一起变好"同类的承诺；"我希望你喜欢我，不是因为只接触过我" → 第116章"只有你会因为我是我而爱我"的回收；莫奈的误会 → 第108章她追问"你们现在是什么关系"、第109章微博公开；舒肤佳香皂 → 第108章他赤裸上身再要一块
- **时间线**：本章紧接第106章归家当夜，自入门收拾厨房至就寝前

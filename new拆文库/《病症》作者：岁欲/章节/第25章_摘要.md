# 第25章 病症 摘要

**概要**：周念趴在地上不肯起来，仰着脸慢慢问他"你真的很讨厌这只小狗吗……还是说很讨厌我"，鹤遂握着她的肩膀要她先起来，她犟着说除非他收下这只小狗。他看见她拿糖狗的那只手肘杵在青石板缝间被挤出两道深痕，便伸手拿住了竹签，手指与她的手指碰到一起。周念从地上被他一只手提起来，立刻绕到他前方挡住路，问他是不是自己哪里惹他不开心，说"我不想失去你这个朋友"；鹤遂重复"朋友"二字后冷笑，说"你应该不缺朋友"。周念认真道歉——她猜是因为自己回了短信后没有再回复，请他不要生气，他退一步问"摔到哪里没有"，低低嗯一声承认不生气了。她当着他的面一点一点撩起裙摆看膝盖，鹤遂不知何时已经转过身去，直到她说膝盖摔破了才回身看那道渗血的伤口，又冷嘲"多摔几次，直接把腿摔断就知道痛了"。他走出几步后停下转身问她还不跟上来，两人一前一后走过青石板，影子一长一短偶尔重合；到鹤家门口她才明白是要带她处理伤口。她因想到鹤广而不敢进门，鹤遂直接说"鹤广不在""就算他来也不怕，我会赶走他"。鹤家院子什么都没种、菜圃干裂，堂屋陈设简单到空，他的房间却整洁得没有一丝褶皱——这也是第一次有女孩子进他的房间，他没告诉她。他把她上次买的药摆出来，让她把糖狗插进笔筒里，自己蘸碘伏擦她的伤口，动作轻到她要屏住呼吸才能确认他在认真。擦药时他忽然问"你中午为什么请罗强吃炒面"，听完她解释"我和他关系很一般的，我和你关系才比较好"后，只说了一句"你不早说"；她追问"你做了什么"，他答"没做什么"。几小时前的小吃店，他确实端着一份炒面站在锅前，指着那碗鲜红小米辣对老板说"客人嘴巴重，要变态辣"。

**关键事件**：1. 耍赖要挟与糖狗被收下 2. "你应该不缺朋友"与她的道歉 3. 膝盖摔伤、被带回家处理 4. 首次进入鹤家与他的房间 5. "你中午为什么请罗强吃炒面"及"你不早说" 6. 闪回揭穿辣椒是他加的

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|

**逐章写法公式**：

- **情绪流向**：起：撒娇（趴地要挟） → 承：委屈（"你应该不缺朋友"、道歉） → 转：温柔（擦药、被带回家） → 合：微妙与好笑（"你不早说" + 闪回加辣）
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：耍赖与收礼（用小事完成关系让步） + 拦路道歉（把上章的"没回复"说清） + 带回家处理伤口（进入他的私域，一次性铺开家庭信息） + 擦药时的追问与"你不早说"（吃醋外化） + 闪回加辣（章尾补刀）
- **本章核心技巧**：用一次"带回家擦药"把男主的私人空间、家庭状况、对女主的独占欲在同一场景里全部交代，再用章尾闪回把本章所有冷脸反转成吃醋
- **卡点与伏笔**：结尾卡点：闪回"要变态辣"（把男主的小心眼摊开，下章由周念追问）；埋设/回收伏笔：糖小狗被插进笔筒 → 留在他的房间里；药盒与头孢 → 指向下章"吃头孢喝酒"的追问；鹤广 → 尚未正面出场的威胁；她不敢让人知道两人来往 → 指向冉银这条压力源

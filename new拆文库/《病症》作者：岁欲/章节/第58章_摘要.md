# 第58章 病症 摘要

**概要**：太阳西沉，远处高楼被渡上一层浅淡橘光，周念站在病房门口的窗前发呆；如果在花楹镇，这么眺望远处是能看见连绵不绝青山的，她无端想到四年前镇外那座被烧光的荒山——如今这么长时间过去，业已绿意葳蕤、草木新盛，连一座荒芜的山都能重新活过来，她却还在原地被困在一个无边牢笼里面。那天本意不想给护士添麻烦的她还是添了麻烦：输液管里回血厉害，等她注意到时手背上已经肿得相当厉害、高高的像座小山丘，换留置针时她不停道歉，温柔的护士说她长得好漂亮、让她一定要快点好起来。冉银拿着一盒医院的盒饭进来，只买了一份给自己，因为周念需要管饲、用不着吃饭；她关上门便按着太阳穴吐槽现在的小姑娘追星太疯狂、走哪都能听到叽叽喳喳的议论——周念不用想也知道，一定是鹤遂来过一趟的消息在医院里传开了。冉银坐到小桌前，语气很不屑地说"也不知道那种人有什么好喜欢的，倒退回去四年，他都只是个人人喊打的小混混。哪晓得踩了什么狗屎，撞了大运演了电影"；不管鹤遂变得如何光芒万丈，在冉银心里他始终是那个把她女儿毁了的混蛋，每次谈起他，言语间总是充斥着不屑、贬低、嘲讽和阴阳怪气。周念翻了个身侧躺在病床上、用背对着冉银说"你吃完饭就走"，冉银问"我走哪"，她说"随便去哪，宾馆酒店多的是，不用在这里陪着我"；冉银说何必花那多余的钱，周念轻轻笑了一下、笑意深长地说"你不是很有钱吗"，彼此都心知肚明那是一千六百万的巨款。她接着说"那些钱不要用在我身上，但至于你用不用，那不关我的事，我也不关心"——这是她和冉银之间一条不成文的规定：她不会花一分赔偿金，不论吃穿用度、学费还是看病的钱，至今用的都是以前画画得奖的奖金和卖画作所得。冉银打开盒饭平静地劝她没必要这样、积蓄总有花完的一天、花完就不生活了、不给她看病了吗，周念疲倦地闭上眼睛说"不看了""真到那一天，让我去死就好了"——对她来说死亡不是一件什么可怕的事情，是解脱，是新生，是逃亡到理想国度的唯一火车票。约半小时后吃完盒饭的冉银还不愿离开、说要等她今天的液体输完再走，怕她睡着留意不到，周念很坚持地说"我自己会注意"，她只想一个人待着，冉银只好离开；病房里只剩下她一个人，静得可怕，能听见吊瓶里的点滴声，她闭着眼睛满脑子都是那双冷漠无情的眼。晚上十点多输完最后一瓶药水，拔针时护士让她不困的话可以下床走走，她慢吞吞掀开被子下床，行动速度就像个七老八十的老太婆，常规病号服穿在她身上格外肥大；她拿起自带的那个小水壶到厕所装了水，回来给床头柜上的一株植物浇水——粉红色的花盆，松软泥土里长着的植物是深浓的绿、宽厚肥壮的叶片一簇一簇挨着，被叶片拥在中间的是几颗团在一起红色浆果形状的果实，红得特别喜庆惹眼。养了这株万年青四年，这还是第一年结果；也是亲自养了以后她才知道，这万年长青的好东西也不是株株都能结出果实，非得要养得相当好或者年头长的才结果，像之前家中那几株就从未结过果、现在已经枯死了。或许每一株万年青也有它们的命——周念本是一个不信命的人，但这四年光景坎坷陆离，病痛折磨她、绝望吞噬她，当一个人身体受尽苦楚、灵魂备受煎熬时，是不得不信命的。浇完水她坐到床沿上，拿手机打开了搜索引擎搜索"私生是什么意思"，答案是私生是指侵犯明星私生活和工作的粉丝、死缠烂打地为了满足自己的私欲，喜欢跟踪、偷窥、骚扰明星，强行入侵他人生活；难怪莫奈不愿意直接告诉她，她苦笑了一下——这果然不是什么好词。过往与鹤遂相处的点点滴滴疯狂涌进脑海：他给她抓萤火虫、陪她去拔牙、给她煮番茄鸡蛋面吃，会摸她的头、牵她的手，还会抱她，甚至在她十八岁生日那天在月光照不到的阴暗角落亲了她、隐忍地浅尝辄止。然而现在她只是想和他说说话就被打作私生、被无数人辱骂攻击；她不难过他如今变成闪耀发光的顶流影帝，他这样很好，比在南水街当一条人人喊打的疯狗好太多，真正让她难过的是他看她的眼神怎么可以带着厌恶，以及他还当着所有人的面说不认识她、完全否认和她认识过，也间接否认了与她的那一段小镇过往——他是真的忘了她，还是装作不认识、单纯不想搭理她。她用病服的袖子擦掉眼泪，委屈地小声抽泣，安静的病房里所有声音都被放大。哭了很久后，她下载微博并注册，又想到四年前鹤遂送给她人生中第一部智能手机、也就是现在手里这一部：电子产品更新换代迅速，周围人从苹果5用到苹果8，她手上始终是当年那款一千块出头的安卓机，系统已经很卡、从微信返回桌面都能卡两秒，其间换过两块电池和几次屏幕，大学室友不止一次问她怎么还不换手机，她每次都说"还能用"；手机卡得要命，注册个微博账号用了整整五分钟。她在搜索栏里打出他的名字，跳出来的第一个结果就是——鹤遂，4287.6万粉丝，27关注，56.33亿转赞评，微博认证"演员"；最新的一条微博是凌晨0:13分发出的，"第二十二年，我未曾忘初心，感谢陪伴"，附着六宫格照片，转发破百万、评论破百万、点赞破了一千万。那是一组精心拍摄的照片：光影偏灰调的空间里，男人穿一身高定黑西装、长腿交叠坐在单人黑沙发里，气质清冷出尘却盖不住骨子里散出来的狠厉感，六张照片正面、侧面、仰拍、俯拍各个角度都找不出死角，189的长腿相当吸睛。周念把照片放大一张一张来回看了好几遍，有一张是他直视镜头的，给她一种在和他对视的错觉；她捂着发闷的胸口又用袖子擦了擦眼泪。评论区里好热闹，那么多人祝他生日快乐——"哥哥22岁生日快乐""家人们谁懂啊啊啊啊，六张照片是哥哥给我们的生日福利""呜呜呜鹤门永存！老公快来我怀里过生日"；这一刻周念恍惚觉得自己也不过是这些茫茫人流中的其中一个，她很普通、也毫不特别，还是一个病秧子，就算发出一条评论都会被迅速覆盖淹没、他根本不会看见。就算是这样，她还是发了一条评论，没有叫他哥哥、也没有叫他老公，只是很简单的一句"@一起逃亡吧：鹤遂，祝你生日快乐"。

**关键事件**：1. 手背上的回血肿包与护士的鼓励 2. 冉银对鹤遂的不屑与"你不是很有钱吗"的对峙 3. 不花一分赔偿金的规矩与"让我去死就好了" 4. 四年第一次结果的万年青 5. 搜索"私生"的含义与过往点滴的涌回 6. 卡顿的旧手机与微博注册 7. 鹤遂的4287.6万粉丝与生日微博 8. 一条注定被淹没的"祝你生日快乐"

**逐章写法公式**：

- **情绪流向**：起：静（夕阳、荒山复绿、手背的肿包） → 承：硬（"你不是很有钱吗"、不花一分赔偿金、让自己去死的打算） → 转：软（浇万年青、查私生、旧手机、过往点滴） → 合：痛（4287.6万与那条被淹没的评论）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：窗前的荒山对位（写停滞） + 回血与护士的善意（插一点外部温度） + 冉银的不屑与盒饭（写母亲的立场不变） + 一千六百万与不花的规矩（把坚持写成原则） + "让我去死就好了"（把死亡改写成车票） + 赶走母亲的独处（把空间留给她自己） + 浇万年青与结果（让信物讲时间） + 搜索"私生"（认知的二次伤害） + 旧手机与微博注册（用器物写执念） + 4287.6万与六宫格（用数据写距离） + 一条评论（以最小的动作收尾）
- **本章核心技巧**：全章几乎没有任何事件，全靠物件与数据撑起来——手背的肿包、一盒盒饭、结果的万年青、四年前的安卓机、4287.6万粉丝、一条写着自己微博名的评论；女主的思念与绝望分别落在自来水壶和搜索框里，情绪由"她主动做的几件小事"推进
- **卡点与伏笔**：结尾卡点："@一起逃亡吧：鹤遂，祝你生日快乐"——一条注定被淹没的评论已经发出，微博ID与她四年前的约定同名，下章期待为他是否会看见；埋设/回收伏笔：万年青第一年结果 → 关系意象的延续与可能的对照；"私生"的释义 → 舆论性质的定性；那部一千出头的旧安卓机 → 他送的第一份礼物，她始终不换；"心理干预理疗室"（第57章）→ 本章仍未解释；"第二十二年，我未曾忘初心" → 与她的回忆构成呼应；微博ID"一起逃亡吧" → 与第54章"带我逃吧"的回扣；这一栋楼全住精神病患者 → 她的诊疗环境
- **时间线**：本章为2017年11月，与鹤遂22岁生日（11月13日）前后相接

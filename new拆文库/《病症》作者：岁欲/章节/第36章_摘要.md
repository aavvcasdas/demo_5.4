# 第36章 病症 摘要

**概要**：烈日红火的天蓝得像擦干净的镜子，周念从榕树浓荫下走出、被太阳拉出一条窄长的影子，在无数双眼睛的注视下沿着足球场边沿朝外墙走去。那一年学校的足球场还只是最原始的黄土地，她一抬手挡着太阳、眯着眼走到木梯下方时并没有引起鹤遂的注意——他正拿着刮板从胶桶里勾湿水泥抹在墙顶、慢条斯理抹平。她静静等他把那一坨水泥抹完才轻声叫他"鹤遂"，他拿刮板的右手明显顿住、不可置信地回头，低眼看见穿蓝白夏季校服、扎高马尾、站在阳光下皮肤近乎透明的周念正明亮地看着他。他把刮板搭在桶沿上，索性懒懒坐到一级木梯上，一条长腿悬空、一条随意踩在下方梯级，垂着眼睫好整以暇地等下文。知道背后有不少人盯着，周念如芒在背，开口时嗓音有点抖："你、你好"——装作两人从不认识；鹤遂没有任何反应，她心里生出一种像回到第一次搭讪时的奇妙感受，怕他下一秒就冷冰冰叫她滚，又立刻自我安慰"现在的鹤遂不会那样凶她"。她小心翼翼地问"能给我你的手机号吗"，他微微挑了一下眉（意思是你不是有我的手机号）；随后他漫不经心地抬眼，注意到她身后百来米处榕树下站着一堆人正在看这边，便浅勾唇角认真地答"不能"，又懒懒补上"除非你答应我一个要求"；骑虎难下的她只能被敲诈一个要求，问是什么，他说"先欠着"，随后慢条斯理地报了一遍手机号。知道背对着那群人看不见她的脸、这么远也听不见，周念放心大胆地说"明天我想去找你"，慢半拍又补了"画画"两个字；鹤遂用手指抹掉滚到喉结上的汗珠，重新低眼看她、嗓音低郁勾人地说"明天见"。周念心跳仿佛漏了一瞬，迅速错开视线、结巴着说"我要回去了""明，明天见"，转身逃离；鹤遂看她走出老远才收回视线，只觉得她时而胆大却经常害羞，矛盾得要命却让人讨厌不起来，反而觉得真可爱。回到老榕树，韩青追问"你要到了？"，听到肯定答复后不信地说"那可不是普通男生"，质疑她撒谎并要求她拿出手机号；周念平静地说"他说了一遍，我记住了"，又主动说"你可以找个手机来试试看"，周围声音一下安静下来。韩青真去借了偷带手机的男生的手机递来，周念操作很慢，一个数字按下去要等一秒才按下一个，十一位号码出现在屏幕上后她摁下拨打键、又摁下免提——几乎每个人都下意识地抬头远望外墙上已经收工跳下木梯的鹤遂：他正要抬手去拿胶桶，动作突然顿住，垂下胳膊把手伸进黑色休闲裤口袋，慢条斯理掏出手机、低头滑动两下，再把手机放到耳朵旁边；周念手里的手机传出少年低沉懒散的嗓音"……哪位？"，不少女生瞬间瞪大眼睛嚷起来"真的是鹤遂！！！""救命，声音好好听……"。周念没有说话就直接挂断，问韩青"这样可以了吧？你以后就不要再找莫奈的麻烦"，韩青触了霉头、僵持两秒后冷冷哼了一声甩手离开；周念又研究了半天怎么删通话记录，问莫奈后才把那一条删掉、把手机还给男同学。这时罗强端着一碗冰镇米酒汤圆过来请她吃，她看到糯米制品差点两眼一黑、下意识拒绝，罗强却坚持说这是他自己做的、用保温桶从家里带来，她眼里对食物的恐惧在悄无声息地弥散。还没等她再次拒绝，一只冷白色的大手横进两人中间端走了那碗汤圆——鹤遂仰头大口喝着，喉结滚动间透出致命的吸引力；他漫不经心地对罗强说"这么多年邻居，买你一碗汤圆喝，不过分吧"，随后掏出一张二十的拍在罗强胸口，又说"味道还行"，在罗强嚷到一半时意味深长地追问"是什么？怎么不往下说"，还故意瞥了周念一眼，罗强心虚地涨红脸、攥着二十块灰溜溜地走了。鹤遂扛着木梯从人群中离开，不带走任何一个女生喜慕的眼光；大家都以为他来这一趟只是为了喝碗冰汤圆解渴，只有周念一个人知道他是为她而来——为了不让她喝下那碗汤圆，她感到一种浓烈的安全感，是被鹤遂保护的感觉。

**关键事件**：1. 周念当众走到木梯下索要手机号 2. "不能，除非你答应我一个要求"与"先欠着" 3. "明天见"的约定 4. 免提拨号验证、鹤遂当面接听"……哪位？" 5. 韩青认输离开 6. 鹤遂端走罗强的米酒汤圆并塞给他二十块

**逐章写法公式**：

- **情绪流向**：起：紧张（走出树荫、逆着目光走向他） → 承：局促（他面无表情、她自己给自己打气） → 转：甜（"明天见"） → 合：爽与安心（免提打脸 + 他替她挡下汤圆）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：当众走近与索号（把上章赌局接上） + 他的面无表情与"不能"（先给压力再给甜） + "明天见"的约定（把关系推进一格） + 免提验证打脸（本章公开爽点，替朋友收尾） + 抢喝汤圆与二十块（用日常插曲完成无声保护）
- **本章核心技巧**：全章把"不能公开相认"的规矩用作张力源——他当众不认她、却当众接下她的电话，再用一碗汤圆把照顾藏进"邻居买卖"里，规矩没被打破，感情却已做给所有人看
- **卡点与伏笔**：结尾卡点：他"先欠着"的那个要求（下章或后续必须兑现）；埋设/回收伏笔：她要到手机号的赌约 → 直接回收上章韩青的条件；糯米汤圆 → 再次触碰她的病症雷区；罗强与鹤遂"这么多年邻居" → 两人的旧关系首次点明

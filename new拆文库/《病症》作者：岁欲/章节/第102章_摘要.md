# 第102章 病症 摘要

**概要**：三天过去，周念没有收到沈拂南的任何消息。期间她与莫奈通电话，转达霍闯想请她曝光校园霸凌的请求，莫奈想都没想就答应，并说自己查出胰岛素抵抗、打算不做吃播改做减肥博主；莫奈又问起周念报名全国画家联展的结果，周念说协会的原话是画很好但"人比较新"还需要考虑，她告诉他们自己是用一个新名字报的名，"我想从头开始"。挂了电话她收拾被小猪翻倒的小葱箱子，小猪一抬头把土渣全蹭到她脸上。这时有人急促拍门，门外站着染成白金色头发、没有任何伪装的沈拂南——她一听他开口就知道来的人是沈拂南而不是鹤遂，眼色骤冷，重申事情只和鹤遂谈；沈拂南说不方便在门口说话，她只好让他进门。他打量着破败的院子说"你这小镇生活，挺丰富"，小猪还在他昂贵的皮鞋旁拉了一泡屎。周念去厨房洗脸，一转身被他从背后逼近，他捏住她的下巴说"要不然你跟我？我带你回京佛，住我那儿"，作势要亲她；她转过脸，他把她的脸扳回来，说"我说我想亲你，你信不信"。周念警告他不想再摊上官司就放开她，他反而更用力，低脸直逼她的双唇。她抬手挡住嘴，他的唇落在她掌心，再慢0.5秒就会亲上；她随即推开他，重重甩了他一个耳光，并当着他的面拆穿他的算计——放鹤遂出来只是第二选择，他的第一选择是亲自勾引她、让她甘愿交出能摆脱鹤广的证据。她重新洗手搓着掌心问他"你想好了吗？让鹤遂出来和我谈"，或者直接离开。

**关键事件**：1. 三天无消息 2. 莫奈爽快答应曝光并转型减肥博主 3. 联展报名被评"人比较新"与"我想从头开始" 4. 白金发色的沈拂南登门 5. "要不然你跟我"与没落下的吻 6. 一个耳光 7. 周念拆穿"第一选择是利用自己"

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|

**逐章写法公式**：

- **情绪流向**：起：闷（三天无消息） → 承：暖（莫奈的义气与周念的重新开始） → 转：危（沈拂南登门、逼近） → 合：快（耳光与亲手拆穿）
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：三天无消息（立等待的缺口） + 莫奈答应曝光与转型（把外线推进） + 联展"人比较新"与我想从头开始（交代女主的自我重建） + 小猪翻箱与蹭土（用日常缓冲张力） + 白金发的沈拂南登门（把对手送到女主主场） + "这不是说话的地方"与进门（用现实顾虑合理放行） + 院子里的打量与小猪拉屎（用荒诞消解他的气场） + 厨房逼近与"要不然你跟我"（把算计推到肢体） + 挡嘴与耳光（当场反击） + 拆穿他的第一选择与逐客（用一句台词收束）
- **本章核心技巧**：把对手的"高大"先用一只猪的排泄物削掉，再让他在没有摄像机的地方暴露最赤裸的一步算计，最后用一记巴掌和一句拆穿让女主占住道德与节奏的双重上风
- **卡点与伏笔**：结尾卡点：周念问"你想好了吗？让鹤遂出来和我谈"，"或者你可以选择直接离开"——沈拂南是就此让步还是另生手段悬置；埋设/回收伏笔：沈拂南以真面目出现在小镇而无伪装 → 他不怕暴露、只想尽快拿到证据；联展新名字报名 → 后续"小顺遂"这个画家名的伏笔；韩老说的人格压制关系（周念交代） → 下一章她用这话套沈拂南；小猪"线面" → 贯穿后续日常戏；周念搓掌心的动作 → 她嫌恶被他碰到
- **时间线**：本章为给沈拂南三天期限后的第三天，同日上午至中午

# 第31章 病症 摘要

**概要**：被灌大豆油催吐的第二天正好是周三称体重的日子。周念几乎一整晚没睡，却也不焦躁翻来覆去，只是双眼无神地盯着天花板；一只米粒大的蚊子停在她左边眼睑下方把嘴插进皮肤里，她不拍也不赶，像一具电池耗尽的机器人，满屋子豆油的味道怎么也不散，她觉得自己魇在一个沉闷厚重的油桶里。七点整冉银夹着黑色体重秤推门进来让她上厕所称体重，她照前两周的办法不进任何排泄、把水开到最小捧水喝了足足五分钟，估计喝下约三斤水，这样"三斤的重量足够她再一次侥幸过关"；镜中的她消瘦苍白、腰细得不超过一张A4纸、整个腹部严重凹陷、两侧肋骨突出，只有灌满水的胃部稍稍外凸。站上体重秤时她的心跳止不住加速，数字却以7开头——79.20斤，去掉约三斤水，她自身体重只有76斤；她这才明白昨晚那种"病得更重了"的感觉是真的，也终于解释了她最近头晕越来越厉害、走路越来越累、上课和画画难集中注意力、夜里入睡困难，甚至出现一万根针同时高频震动的幻听。冉银盯着体重秤要她解释，听到"我不知道"后把责任推给那个转校生，断定是莫奈给她吃了脏东西，宣布"我不允许你和那个转校生再有什么来往"，周念替莫奈辩解"她很好"被打断"人心隔肚皮""我吃的盐比你吃的米都多"，最后冉银拿秤失望离开，和往常一样不在意她苍白如纸的脸色与骨凸肉薄的身体；幻听再次响起，她捂耳反而让针颤声在掌心放大，最终放弃抵抗，"就这样下去，就这样病下去"。换季时节女生们课间聊A4腰、反手摸肚脐、锁骨养金鱼，莫奈凑过来羡慕地说"她们都没你瘦，而且你是最漂亮的""我甚至恨不得魂穿你"，又说自己胖了两斤、走路磨腿；周念问她"最瘦就是好吗"，心里只觉得悲哀——她不想要最瘦也不想要人羡慕，她只想正常一点，只觉得自己是个怪物；当莫奈用短短的手指圈住她的手腕还有空余、劝她不要再瘦，说"健康状况下的正常瘦最好啦"时，她感到深深的无力，因为她身体和心理没有一个是健康的，旁人只看得见她的表面光鲜，看不见皮囊里的灵魂在溃烂流脓。打翻的墨水洇开在桌上，她觉得那流淌的是她的灵魂底色。79斤带来的是更残忍的三餐受刑，周六早上她塞下两张火腿蔬菜鸡蛋饼、一大碗火麻仁稀饭、一碗紫菜虾皮馄饨、一盘清炒芦笋和一杯豆浆，靠想别的女生吃什么、想莫奈、想鹤遂来分散注意力——一到周末她的脚就忍不住往南水街、往他家那条小巷走。出门后她一路疾走奔向公厕，却发现公厕立着"维修中，禁用"的牌子；巷弄不能吐、河里更不能吐，她忍着随时要栽倒的感觉一路走到南水街，最终捂着胃拍响了鹤遂家的大门，心想"鹤遂是她最后的希望"。门突然从里面拉开，靠在门上的她直接摔进一双臂弯里——刚洗完澡、头发还在滴水的鹤遂再一次接住了她，问她"怎么了"；她只说得出"借用一下厕……"，还没说完就呕了出来。

**关键事件**：1. 称体重前的灌水作弊 2. 79.20斤、自身体重仅76斤 3. 冉银把病因归给莫奈并禁止来往 4. 幻听再起与"就这样病下去" 5. 莫奈的羡慕与"最瘦就是好吗" 6. 公厕维修、她冲到鹤遂家门口，被接住后当场呕吐

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|

**逐章写法公式**：

- **情绪流向**：起：空洞（整夜未眠、蚊子叮在眼睑上） → 承：惊恐（79斤、幻听、母亲的质问） → 转：无力（莫奈的羡慕与"怪物"的自判） → 合：绝望中的冲刺（公厕维修、冲到鹤遂家门口、当场呕吐）
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：称重仪式与数字揭晓（把病症量化到危险值） + 母亲的归罪与禁令（外部压力续接，切断友谊线） + 校园身材话题与莫奈的羡慕（用他人的价值观反衬女主的痛苦） + 三餐受刑式日常（把病写成每天的流程） + 公厕维修与冲门（用一次突发困境把她推到男主门口）
- **本章核心技巧**：全章把"下坠"做足（数字、幻听、被禁友情、进食酷刑）之后，用一块"维修中"的牌子把女主逼到唯一去处，让最后的救援由一次生理失控（当场呕吐）触发——出口与暴露同时到来
- **卡点与伏笔**：结尾卡点：她在鹤遂面前当场呕吐、秘密即将暴露（下章处理他发现真相）；埋设/回收伏笔：79.20斤与"76斤" → 病症已进入危险区间；"一万根针的幻听" → 病症升级的标记；冉银禁止与莫奈来往 → 友谊线被切断，转学/学校线将受压；周末"脚忍不住往南水街走" → 她对鹤遂的依赖已成习惯

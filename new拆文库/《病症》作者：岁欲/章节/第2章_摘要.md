# 第2章 病症 摘要

**概要**：时间倒回四年前四月，蓝花楹开得最好的一年。周念在母亲冉银的严格管控下生活：九小时睡眠、七点前不得下床、小名"七斤"、食物只作人体供能。她被要求参加人物肖像类省级绘画大赛并必须拿第一。她外出写生，画被山火烧秃的山脊与人间烟火的反差，围观者赞她"女版小梵高"。回家途中，白色皮卡碾过积水弄脏她的白裙，车停在巷口——开车的是鱼泡眼肖护，他两轮言语羞辱蹲在路边抽烟的鹤遂，甚至把烟灰弹到他脸上留下烫伤。当肖护辱及鹤遂的母亲时，鹤遂碾灭烟头起身，抄起五金店外的铁锹追上正要起步的皮卡，跳上前盖砸碎挡风玻璃，把手伸进破洞揪住肖护衣领把人整个扯出来，逼他当众道歉。周念看着这一切，被这个"像一只被放进羊圈的狼"的少年震住；他却在事后扭头直直看过来，四目相对间"风吹来远山灰烬的味道"，周念想逃，却"又在他的目光里被定住了脚"。

**关键事件**：1. 立女主的规训式日常与病症 2. 山火余烬与写生 3. 肖护两轮羞辱并弹烟灰烫伤鹤遂 4. 鹤遂抄铁锹砸窗拽人逼道歉 5. 两人第一次四目相对

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 女主的厌食是教育出来的 | 用母亲的原话"食物根本不是用来品尝的，而是用来人体供能的"+"入口的食物需要称重"+"进食就是在受刑"三个层次完成 | 用台词说明制度 | 窒息 | 病症成因必须由施加者亲口说出，才显得不可逃 |
| 两人的社会位置是对照 | 同一条街上，"女版小梵高"与"疯狗"两个绰号并列；周念自己评他"在人群中，就像一只被放进羊圈的狼" | 绰号对照 + 比喻定位 | 好奇 | 用镇民的绰号完成两个主角的定位，一句话省掉大段介绍 |
| 男主的暴力有节奏 | 羞辱段落写长（"八风不动地稳着"）、爆发段落写短（碾压烟头→跳车前盖→砸窗→拽人），长度差制造意外感 | 忍耐写长、爆发写快 | 爽、震 | 暴力爽点的关键是前面的忍，不是后面的打 |
| 两人对视的意象锚点 | "四目相对的那一刹那，风吹来远山灰烬的味道"——一次对视同时承担时间、地点、情绪三重功能 | 环境替情绪发言 | 期待 | 对视要配一个只属于他们两人的感官细节 |

**逐章写法公式**：

- **情绪流向**：起：窒息（规训日常） → 承：平静（写生） → 转：爆发（砸窗拽人） → 合：悬停（被目光定住）
- **节奏配比**：慢铺垫 55% / 快冲突 45% / 爽点爆发 10% / 悬念留白 5%（重叠计）
- **本章结构公式**：规训日常（控制制度） + 写生（天才身份） + 皮卡与巷口的人 + 羞辱升级 + 暴力释放 + 四目相对的钩子
- **本章核心技巧**：用半章拼积木式铺垫，把女主的病、母亲的控、男主的暴三条线一次立完，最后用一次对视把两条平行线强行接上
- **卡点与伏笔**：结尾卡点："偏偏又在他的目光里被定住了脚"；埋设伏笔：山火与27名消防员、鹤遂被烫伤的鼻梁月牙疤、"女版小梵高"的名声

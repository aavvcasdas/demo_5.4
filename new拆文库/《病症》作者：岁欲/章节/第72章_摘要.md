# 第72章 病症 摘要

**概要**：周念的卧室里，窗前的书桌被挪开换成了床，床侧对着窗，这样她就能靠光线落在眼皮上的变化判断白天还是黑夜——光带来昏蒙的红色，夜里只剩黑色，除了红与黑她再看不见任何颜色，昔年对色彩有着高度敏感与极强把握的天才少女最终也没逃过神陨的命运。她不再画画，也没日没夜地躺着。冉银带她去医院检查，医生说眼睛并没有器官性病变，属于心因性失明，吃药打针都没用，必须多注意情绪、放松心态，说不定哪天睡醒就又能看见了；周念只在听着，完全没往心里去，她比谁都更清楚自己没办法好起来，对失明反而接受得很坦荡。年关将至，小镇上热闹非凡，她却既不爱出门也无法出门，失去厌厌后她的身体一点点垮掉，大腿已瘦到和正常人手臂一般粗细、肌肉全部萎缩，成了一具活骷髅，有一次出门还把邻家小孩吓得哇哇大哭；冉银给她准备了电动轮椅，更多时候她只是待在院子里坐在轮椅上晒太阳，精神状态不好，时常分不清现实与梦境。有一天郁成上门，冉银认出他是鹤遂的助理、拦在门口，他仍越过她走到轮椅前自我介绍，转达"遂哥说你从他那里拿走了一样私人物品，现在需要你进行归还"——是一条上面有一颗牙齿的项链。周念笑了，说"我还以为是什么东西，原来只是一颗破牙齿"，并指出当初是他自己亲手扯断项链扔到地上，如今却派人来要回他扔掉的东西；郁成只想着来之前那句嘱咐"不论如何，都要把那条项链给我带回来"，仍以"物归原主"相求，被她笑得流下眼泪，并回"那是从我嘴里拔出去的牙齿，要论所属权的话，那也合该是我的东西"。郁成走到院角接鹤遂的电话，说了她不肯给、还好像瞎了精神也不太好；那边沉默之后隐约传来一声隐忍的叹息，他仍冷冷要求"一定要把东西带回来"，并解释"没有那条项链，我没办法参加下个月的奥斯卡颁奖礼"，面对郁成的不理解只说"你不用理解"。郁成回头再开价，周念藏在毛毯里的指甲已扣进肉里出血，反问"他是不是觉得，所有东西都可以用钱来衡量"，最后说东西早就扔掉了、请他回去，郁成只能空手离开。冉银骂够了鹤遂，端来一碗热食，周念吃了很小一口后说"已经连续一周吃白粥了"，才知道那是八宝粥、之前一周也没吃过白粥——她失去了味觉，只反复说"没关系"，冉银在她面前哭出声。除夕夜她潦草地喝了两口汤就回房躺着，午夜听着外面的烟火鞭炮，后知后觉地发现那些声音其实没变小，只是她的听力不中用了；翻身时被子滑落，她穿着单薄的秋衣秋裤睡了一整晚，第二天手脚已冻得青紫，她却没感觉到冷；向冉银要来一块香皂深深吸了一口，也没闻见熟悉的清香。视觉、听觉、嗅觉、味觉、触觉五识尽丧，没人再记得周念也曾是个风光无两的画画天才，也没人知道她的遗憾是回不去的天才少女、是没有心的沉重□□、是在悲哀尘世的孤独灵魂——她走在一条名为失去的路上，在暮色里摇摇晃晃，回头望时，隐约看见这条不归路上依稀曾有过一个眉眼深邃的少年。

**关键事件**：1. 靠红与黑分辨昼夜与心因性失明的诊断 2. 活骷髅般的身体与把邻家小孩吓哭 3. 郁成上门索要智齿项链与"物归原主" 4. "没有那条项链，我没办法参加下个月的奥斯卡颁奖礼" 5. "又是钱？"与"东西我早就扔掉了" 6. 八宝粥与失去味觉 7. 除夕夜发现听力不中用、被子滑落冻紫手脚 8. 香皂没了清香、五识尽丧

**逐章写法公式**：

- **情绪流向**：起：静（红与黑、躺着不画） → 承：垮（活骷髅、轮椅、被小孩吓哭） → 转：争（索要牙齿、物归原主、又是钱） → 合：空（五识尽丧、走在失去的路上）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：书桌换床与红黑辨昼（用最基础的感官残留写失明） + 心因性失明的诊断（给出可逆的可能，制造期待） + 活骷髅的身体与吓哭小孩（把崩坏写到外观） + 郁成上门与"他拍你"式的旧账（引入外部索取） + 智齿项链的归还之争（用权的辩论写人物立场） + 电话里的"奥斯卡"条件（埋下不解之谜） + "又是钱？"与"早就扔掉了"（把交易逻辑顶回去） + 八宝粥与失去味觉（第一识关闭） + 除夕鞭炮与冻紫的手脚（第二、三识关闭） + 香皂失效（第四识关闭） + "走在失去的路上"（收在回望）
- **本章核心技巧**：用"感官逐项关闭"造一条不停下坠的阶梯，每关掉一识就配一件极普通的日常物（粥、鞭炮、被子、香皂），让读者在琐碎里目击崩塌；中间插一段索要牙齿的对话，把男主那边"不可解释"的执念留在读者心里
- **卡点与伏笔**：结尾卡点：五识尽丧、她只剩"行走在失去的路上"，而鹤遂要到项链的执念仍未解释；埋设/回收伏笔：智齿项链与奥斯卡颁奖礼的绑定 → 第73章他在颁奖礼现场失踪、第78章在洗手间被刺（镜上血字"放我回去"）；"他是不是觉得所有东西都可以用钱来衡量" → 与第68章三千万买断形成对账；心因性失明"说不定哪天睡醒就能看见" → 为第80章味觉初现与第81章听觉恢复留出机制；电动轮椅与家里楼梯改造 → 第74章改造过的楼梯出现在可验证的细节里
- **时间线**：本章接第71章失明之后，跨年关前后约一个月，至除夕夜与次日清晨

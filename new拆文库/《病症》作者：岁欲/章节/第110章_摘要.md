# 第110章 病症 摘要

**概要**：周念再醒来已是第二天中午，昨晚是她的也是鹤遂的第一次。线面在院子里饿得发出尖锐嘶鸣，把绵长呼吸打断；她睁眼才发现自己窝在男人怀里、像八爪鱼一样扒在他身上，第一眼看见的不是他的脸，而是被顶起来的空调被，鹤遂语气欠欠地说"它有自己的想法，跟我没关系"。他提到鹤广以前是杀猪的，周念问他多久会被抓住，他只说"不清楚"。周念起床时痛得五官扭曲，鹤遂抱她去洗澡，说"洗澡是配套服务"；她注意到他背上两道抓痕，他气定神闲地说"是线面昨晚闯进来给我抓的"，反过来把她暗骂成猪。她看见自己身上遍布的红痕，小声嘀咕"感觉像是被狗咬了一样"，被他一句"什么？你再说一遍？"噎回。洗澡时他站在她身后突然没了动静，说"我又想当狗了"，吓得她涨红脸说"不行，还痛"，他笑着改口"那亲一下总可以吧"，在热气里把她吻到缺氧。此时郁成打来电话并已经到了门口，周念下楼开门时门外全是狗仔和粉丝；郁成从人堆里挤进来，抱怨遂哥半夜突然公开恋情让整个工作室炸了、一晚上掉了九十万活粉。周念拿着他带来的衣服进屋，浴室里突然传来沈拂南暴怒的咆哮：他质问鹤遂"言而无信""你他妈的敢骗我""你和她睡了是吧"，并质问鹤遂是不是沉溺温柔乡、要推翻两人之间的约定、不想做那个彻底消失的人。周念由此捕捉到关键字眼，才明白鹤遂此前告诉她的"输的人消失三个月"是骗她的，真相是"输的人永远消失"。鹤遂在里面说"我没有输，她爱我，她还愿意要我""输的人是你"；沈拂南骂他不懂感恩、说是他把他们所有人从"那个鬼地方"救出来——这是周念第二次听到"那个地方"。鹤遂嗓音骤寒，说"我说过，我赌你死在这个夏天"。等里面安静下来后周念敲门，鹤遂出来并问她想吃什么；她不理他，他最终问"你都听到了？"，并伸手拉她、被她躲开。她怒说"你现在能不能别碰我"，他反而一把把她拉进怀里任她打，说"打，随便打，打死我都行""你能消气就行"。周念哭着问"你凭什么那样轻易选择去死"，鹤遂捧住她的脸，说选择去死不是一时冲动而是深思熟虑后的决定，因为赌注是她的爱，"我只赌你爱我"。

**关键事件**：1. "它有自己的想法" 2. 背上的抓痕与"是线面抓的" 3. "我又想当狗了" 4. 门外九十万活粉的代价 5. 浴室里的暴怒与"你言而无信" 6. "输的人永远消失"的真相 7. "那个鬼地方" 8. "我赌你死在这个夏天" 9. "你凭什么那样轻易选择去死" 10. "我只赌你爱我"

**逐章写法公式**：

- **情绪流向**：起：羞（荒诞的早晨） → 承：乱（门外的九十万与楼下的郁成） → 转：炸（浴室的暴怒与赌约真相） → 合：沉（"我只赌你爱我"）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：线面嘶鸣与"它有自己的想法"（用荒诞接住亲密后的早晨） + 杀猪与鹤广与"不清楚"（把主线旧人带出一次） + 抱去洗澡与"配套服务"（用玩笑维持轻松） + 抓痕与"是线面抓的"（用回敬制造笑点） + 红痕与"像是被狗咬了一样"（把亲密的痕迹摆出来） + "我又想当狗了"（把玩笑推成暧昧） + 郁成来电与开门（用外部闯入打断私密） + 门外的人潮与九十万活粉（量化公开的代价） + 浴室的暴怒（把反派推到台前） + "输的人永远消失"的推翻（本章最重要的信息） + "那个鬼地方"（埋长线疑问） + "我赌你死在这个夏天"（留时间锚） + "你都听到了"与"别碰我"（把冲突转到两人之间） + "打，随便打"（用承受化解她的怒） + "你凭什么那样轻易选择去死"与"我只赌你爱我"（把男主的生死观一次说完）
- **本章核心技巧**：用"隔着一扇门"完成信息投送——女主站在门外把反派在愤怒里喊出的真相一条条接住，既让反派替作者交代设定，又让女主的情绪转变有充分的过程可看
- **卡点与伏笔**：结尾卡点：鹤遂把选择去死的理由说完、"我只赌你爱我"落地，赌约是否允许她翻案、沈拂南是否肯被整合都悬置；埋设/回收伏笔："输的人永远消失"（推翻三个月版本） → 第118章沈拂南成为第一个被整合的人格；"那个地方" → 第111章由韩青点破是善进学校；"我赌你死在这个夏天" → 与鹤遂"我赌你爱我"的赌约互为表里；九十万活粉 → 第116章郁成再算一次行程与违约金的账；鹤广多久被抓 → 第118章落网；线面咬不咬人的回敬 → 贯穿全书的宠物梗
- **时间线**：本章为公开恋情次日中午至当日下午

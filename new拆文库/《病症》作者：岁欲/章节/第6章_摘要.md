# 第6章 病症 摘要

**概要**：鹤遂当着周念的面关上家门。周念留在原地想的不是委屈，而是"他到底经历过什么，才能做到这样的冷漠"。罗强给她讲了鹤遂的完整来路：四岁时被吸毒的父亲鹤广哄出门，拿着两百块钱去"林叔叔"的烟酒铺买"烟"，实际是替父购买毒品，被暗处便衣警察从小孩手里取走烟盒，随后带他回家当场抓走鹤广（转戒毒所两年），姓林的毒贩因贩毒过量被判死刑；此后小鹤遂被全镇大人警告自家孩子不许与他玩，"上梁不正下梁歪"的孤立把他变成不爱说话、不爱笑、脸上永远挂着超脱年龄的成熟与冷漠的人。周念听完把药留在他家门槛上。当晚鹤遂妈妈宋敏桃回家被门槛上的药绊到，拿上楼问儿子，鹤遂否认，但最终仍是用这包药处理了伤口——宋敏桃替他上碘伏时提出"阿遂，回去念书吧"，被他一句"我要睡了"堵回。另一线：周一早自习，周念班里转来新同学莫奈（与法国画家同名），坐她旁边，家住北清巷；同学韩青借生日聚会当众点出冉银曾跑到 KTV 讲"我家周念和你们不一样"的旧事，解释周念被孤立的原因；放学路上同学议论鹤遂"高一上学期读完就休学了"，版本不一。

**关键事件**：1. 罗强讲述鹤遂四岁替父买毒的来路 2. 周念把药留在鹤遂家门槛 3. 药最终被用上，宋敏桃劝鹤遂复学被拒 4. 转学生莫奈登场并与周念结伴 5. 韩青点破周念被孤立的家庭根源

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 鹤遂冷漠的成因 | 不写他的心理，改由邻居罗强"唠这件事"，用四岁孩童买烟的完整事件（两百块、拆了塑封的烟盒、便衣冲出、毒贩死刑）作为解释 | 他人转述 + 完整事件链 | 心疼、压抑 | 男主黑色童年的最好写法是"别人讲给别人听"，主角本人全程不在场 |
| 被集体孤立的后果 | 用一句社会判词概括——"上梁不正下梁歪"，再接三连否定"不爱说话、不爱笑、永远挂着超脱年龄的表情" | 社会判词 + 行为递降 | 心疼 | 用一句俗语代表整个环境的恶意，比描写具体欺凌更省力也更真实 |
| 周念的共情是生理反应 | "心口像是被人覆上一块吸满水的棉花，湿冷厚重得让她难以维系心脏跳动" | 身体反应替代心理描写 | 心疼 | 把同情写成体腔感受，不用"她很心疼" |
| 善意的迂回落地 | 周念把药"留在了鹤遂家的门槛上"，再由宋敏桃绊到、捡起、递上、最终用上 | 延迟揭示 + 巧合链 | 期待、温馨 | 被拒的善意通过第三方转手完成，让关系保持未接触状态又不浪费铺垫 |
| 复学话题是母子关系的主症 | 宋敏桃上碘伏时突然插入"阿遂，回去念书吧"，鹤遂"眼神都没眨"，用"妈，我要睡了"终止对话，门外一声"幽幽叹息" | 以一句突兀要求暴露长年僵局 | 压抑 | 用一句被硬切掉的对话写母子裂痕，比争执更有效 |

**逐章写法公式**：

- **情绪流向**：起：冷（门关上） → 承：痛（买毒事件） → 转：暖（药被用上） → 合：涩（"我要睡了"与叹息）
- **节奏配比**：慢铺垫 50% / 快冲突 5% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：关门拒斥收上章 + 童年创伤完整揭露（人物动因补课） + 门槛留药（善意迂回） + 母子对话（第二重家庭病症） + 新角色莫奈登场（校园线开） + 韩青拆穿孤立原因（女主处境落地）
- **本章核心技巧**：把男主的身世一次讲透（四岁买毒 → 抓父 → 被孤立 → 变冷漠），用"受害者是被利用的小孩"这一身份彻底翻转读者对他的判断；同一章内插入"门槛上的药被用上"给读者即时回血
- **卡点与伏笔**：结尾卡点：鹤遂休学原因的三个版本并列、无一定论（下章由鹤遂本人口中稍作回收）；埋设伏笔：莫奈与法国画家同名、家住北清巷、父母离异各自有家（她的身世将成为后文与周念的镜像）、宋敏桃"回去念书吧"的请求

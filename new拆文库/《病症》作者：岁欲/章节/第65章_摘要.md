# 第65章 病症 摘要

**概要**：京佛入冬，周念在住院部楼下的花园里晒太阳，看阳光从红梅枝桠间筛落。护工同她搭话，问她最近总教小昭画画、以前是不是学过，她只答"没有，随便画画而已""试过，走不通"，并随口诌了个"学艺术太烧钱了"的借口；护工说起自己儿子也在本市的美院读、联考校考都只是擦边及格全靠运气，周念很缓慢地眨了下眼、声音变轻地说"挺好的，挺好"，而护工始终不知道眼前的小姑娘曾同时拿下13年美术联考和京佛校考双第一。护工去上厕所后，一个穿灰色翻领毛衣、系黑围巾、看上去三十五岁左右的男人坐到她身边，递上"月炎工作室 创始人·解渤腾"的名片，自称是娱乐圈记者，周念直接叫他狗仔。她一眼看穿他腿上的手机正在录音，他不恼反笑，关掉录音，说看过她在鹤遂路演现场问对方认不认识自己的视频，网上都在骂她，但他相信她，还准确说出她是厌食症而非别的精神病、她来自南方小镇花楹镇、鹤遂也来自那座小镇。他摊明来意：能挖到出道至今毫无黑料的鹤影帝的料才是真本事，并暗示"始乱终弃"的故事，说自己是来帮她、能让她的委屈被看见、还能拿到不菲的经济赔偿，只是"口说无凭，有照片为证最好了"。周念想起自己手机里存着上百张与鹤遂的亲密合照，睫毛颤了颤，一分钟后站起来说"很抱歉，我没有你想要的东西"；他不信，临走前指着名片说等着她的电话，还补了句"随时"。回到病房后她把名片拍给莫奈，得知解渤腾是近几年最厉害、从不曝假料的狗仔。莫奈劝她把照片交出去、让他去和鹤遂交涉分成，她回"我要是真想这么做，完全可以直接当面和他谈"，并坦白鹤遂现在就住在她旁边、是为拍戏来观察一个双相患者。莫奈震惊又替她不值，说真希望他也得精神病。话音未落鹤遂提着小提琴进门，一眼看见那张名片，问她"解渤腾找上你了"，又端着水杯问她"所以你有么"，周念抚摸着一片万年青的绿叶对他微笑："我有没有，你不是很清楚吗？"（本章正文与第66章逐字重复。）

**关键事件**：1. 护工问起画画与"京佛美院""挺好的，挺好" 2. 解渤腾递名片、自称狗仔、被识破正在录音 3. 他说相信她、准确报出她的病与花楹镇的来处 4. 他暗示始乱终弃、承诺赔偿，并提出"有照片为证最好" 5. 周念想起手机里上百张合照后仍然拒绝 6. 莫奈说解渤腾是从不曝假料的最强狗仔并劝她卖照片分成 7. 周念坦白鹤遂就住在她旁边的病床 8. 鹤遂看见名片问"所以你有么"，她答"我有没有，你不是很清楚吗"

**逐章写法公式**：

- **情绪流向**：起：冷（冬日花园、护工闲谈与一句"走不通"） → 承：警（陌生人落座、名片、录音） → 转：硬（他抛出赔偿与照片、她想起上百张合照却仍拒绝） → 合：锋（他把名片看进眼里问"所以你有么"，她以反问回敬）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：花园晒太阳与护工闲谈（用闲话反衬被埋掉的天才） + 白发老人与日暮感（给出主角此刻的心态底色） + 解渤腾落座递名片（把外部变量引进场） + 当面拆穿录音（先立威） + 他抛出"我相信你"与花楹镇的信息（亮出调查深度） + 始乱终弃的暗示与赔偿承诺（把诱惑摆全） + "有照片为证最好"与上百张合照（把筹码摊开） + 她的拒绝与"随时"（留一个可回头的口子） + 与莫奈的微信对话（用朋友视角补齐狗仔的量级） + "直接当面和他谈"与同病房的坦白（用平语气完成反转） + 鹤遂进门看见名片（把两条线接到一起） + "我有没有，你不是很清楚吗"（以反问收章）
- **本章核心技巧**：整章是"外部势力上门"的经典结构——先用闲谈把主角的落魄与旧日高度并置，再让一个掌握信息的陌生人抛出可换利益的方案，最后用主角的拒绝和一句反问把选择权攥回自己手里；外部势力的出现同时把男主推到必须表态的位置
- **卡点与伏笔**：结尾卡点：她那句"我有没有，你不是很清楚吗"没有给出答案，鹤遂是否担心照片外流、会不会先出手都悬置；埋设/回收伏笔：解渤腾的名片与"我等着你的电话" → 后续会被撕碎（第67章）后又把事态推向热搜；周念手机里上百张亲密合照 → 后续三千万买断与当众删除的起点；13年美术联考与京佛校考双第一 → 与冉银撕碎录取通知书的旧事互相咬合；万年青 → 反复出现的意象物件；花楹镇被外人查证 → 两人的来处已成为公开线索
- **时间线**：京佛入冬后的花园自由活动时间，延续至当日回病房

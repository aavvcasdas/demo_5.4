# 第71章 病症 摘要

**概要**：离开一个多月后，周念重新呼吸到花楹镇的空气，南水河依旧潺潺，茶馆桌上摆着的盐水毛豆还是一样分量，废旧戏台上的斑驳痕迹也没有改变分毫；她呼出一口白气，脚步缓慢地往北清巷走。一路上镇子上的人同她和冉银打招呼，转过身就开始指指点点，说她出去治病回来还是瘦得像根杆儿，说她其实是去找鹤遂、抓着人家问认不认识她结果被当面说不认识，说她不检点自爱、被睡了被玩弄够了然后被扔掉。四年前那场黄谣风暴从未停息，如今她成了一座坍塌楼宇，人们便不畏惧踩着废墟羞辱她，周念垂着眼睫听着冉银回头把人破口大骂也只是继续往家走。走到家门口她愣住，木门上被人泼了红色油漆，写着"不要脸""离鹤遂远一点""去死"，门前还摆着花圈、祭奠用的纸元宝与黄色钱纸，甚至有一件写着"周念"两个字的寿衣。冉银怒骂着要把人全抓起来，把花圈推翻踏烂、把寿衣纸鞋撕得粉碎，周念却站着不动、表情木然，仿佛寿衣上写的名字并不是自己。家里没有汽油，冉银去加油站买回一桶、又打了两桶水，周念不听劝、自顾自拿起抹布蘸汽油擦门上的红油漆，手臂越来越酸疼，也想起很久以前她在南水街的雨雾天里同样擦过门上的油漆，那时站在她身边的不是冉银，而是另一个人。擦了两小时后她终于躺下，觉得躯骨像一副为她量身定做的棺材，随即陷入仇恨、暴雪与惨白月光的梦境。她睡了一天一夜，冉银推门说有一位叫霍闯的朋友来看她；霍闯看见她趴在床边往地上吐酸水，带来水果和营养品，说厌厌还在等她去喂，又问她鹤遂哥哥为什么说不认识她——明明以前他好喜欢她，他读初中时都能看出来。临走时霍闯想起来转告，说他有一个朋友的表哥之前和鹤遂在一个厂里打过工，鹤遂找他表哥借过身份证；周念眸光微闪，没有接话。冉银端来不加糖的银耳，她只喝了两勺便不愿再喝——当年的厌食是对掌控的报复，如今则是严重的分离感，她觉得身体与她并非一个整体，饥饿与痛苦都与她无关，她很清楚等待自己的是什么结局，却一点也不害怕。傍晚她换上外出的衣服、拿上一小包猫粮，起身时踢倒一个纸箱，滚出数不清的白色舒肤佳香皂，全是新的，满屋淡淡的皂香像他从未离开；她把香皂一块块捡回箱中，再去长狭弄喂已经长成漂亮黑猫的厌厌。就在她蹲着和猫说话时身后站了个人，她回头看见一张四年未见的脸——脸上的疤像被强硫酸腐蚀过的深坑，是肖护。他说"我只是想告诉你，我出来了"，又嘲笑她当初画画的天才少女如今搞成这副德行、说她帮鹤遂作证人家却说不认识她"好贱"，最后说出极下流的羞辱；她气得发抖喊"你滚"，他涎笑两声离开，她扶着墙缓了很久，蹲下把厌厌紧紧抱在怀里、眼泪滴进黑毛里。担心受怕地过了三天后，一个冉银出门买菜的清晨，家门被敲响，门外没有人，只放着一个箱底浸出鲜红血液的纸箱；她极缓慢地打开，看见褶在一起的黑色毛发、血淋淋的皮肉筋膜，皮肉从中间被分离，一声极微弱的"喵"从箱中传来。她抱起纸箱发疯般冲出北清巷，哭着拦下一辆红色摩托哀求送她去市里，一路合拢箱盖怕猫着凉，在八十码的风里听见箱中一声微弱的"喵呜"；赶到宠物医院后医生打开箱盖摇了摇头——厌厌已经咽气，眼睛还睁着，一分钟前那声喵呜原来是它在和她告别。周念双膝一软跪在地上，忍着不发出声音，哭着哭着眼前一黑、模糊得厉害，她揉了揉眼发现还是模糊的，于是——她瞎了。

**关键事件**：1. 归镇路上被当街议论的旧谣 2. 家门上的红油漆、花圈与写着她名字的寿衣 3. 蘸汽油擦门与南水街的旧记忆 4. "躯骨是一副为她量身定做的棺材" 5. 霍闯来访与"借过身份证"的信息 6. 一箱全新的舒肤佳香皂 7. 肖护出现、说出"我出来了"与下流羞辱 8. 装着厌厌的血纸箱与"所以——周念瞎了"

**逐章写法公式**：

- **情绪流向**：起：旧（熟悉的街道与毛豆分量） → 承：辱（街头议论、花圈寿衣、肖护的羞辱） → 转：暖（一箱全新的香皂、长狭弄的黑猫） → 合：塌（纸箱里的厌厌与"所以——周念瞎了"）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：归镇的景物描摹（用不变写回不去的落差） + 街头议论原话（把旧谣当众复述） + 家门上的红油漆与花圈寿衣（把死亡预告摆到眼前） + 擦门与南水街旧忆（用同一个动作接起旧人） + 量身定做的棺材（用一句自比写心态） + 霍闯来访与厌厌的牵挂（引入唯一的暖） + "借过身份证"（埋一条关键线索） + 银耳与厌食动机换代（交代身体的下坠机制） + 一箱全新的舒肤佳香皂（用旧物的气味写未散的人） + 长狭弄喂猫（给出人物仅存的温柔） + 肖护现身与羞辱（把外部威胁推到顶点） + 三天后的血纸箱与送医（把最后一根支撑抽掉） + "我瞎了"（用失明收章）
- **本章核心技巧**：把返乡写成一次"旧账清算"——街上的人言、门上的油漆、写名字的寿衣、出狱的旧仇家，一层层把外部恶意叠上来；当读者以为她终于在一只猫和一块香皂里得到喘息时，作者用一只血纸箱把这点暖全部打碎，并让身体的最后一扇窗（视觉）当章关闭
- **卡点与伏笔**：结尾卡点：她刚刚失明，仰赖的只有残存的听觉与嗅觉，生存状态彻底悬空；埋设/回放伏笔：肖护"我出来了"与出庭作证的旧账 → 与厌厌被虐杀直接相关；鹤遂曾向镇上人的表哥"借过身份证" → 指向他四年间身份与行踪的隐情；一箱全新的舒肤佳香皂 → 与他过去用的廉价香皂形成跨章回扣；"那时她身边站的不是冉银，而是另一个人" → 南水街擦油漆的旧场景；厌厌被绝育的时间点（八个月） → 两人共养的猫成为关系的实体证据
- **时间线**：本章接第70章周念离开京佛，返乡当日，延伸至当夜、次日与之后约一周

# 第79章 病症 摘要

**概要**：鹤遂找到周念时，她已经被转移到轮椅上抽血——血管太细、贫血严重，在东济护士相当专业温柔的情况下都挨了两针，三小管血抽完后她的脸色更苍白了。他要来一块消毒过的热毛巾，敷在她抽血的手臂内侧，可她感受不到热，只觉得有什么东西压在手臂上，伸手一探摸到他的手指和毛巾后便下意识把他的手拨开、一言不发，抗拒的姿态很明显。之后她陆续做了脑CT、肺CT、头部核磁共振和心脏彩超等检查，被送回33层顶楼那间约三百平的VIP套房，卧室里有落地窗，能俯瞰云宜的江景与整座城市的灯火。护士替鹤遂换药时解开他的衬衫纽扣，露出染血绷带下还没拆线的腹部伤口，缝线正在出血、恢复情况并不乐观，他态度冷淡地应了声"嗯"，像压根没往心里去。卧室沉寂下来后，她知道他就和自己待在同一个空间里，也听见他开口说"念念，我不可能眼睁睁看着你去死"；她回"可我现在和死并没有什么区别"，并坦言自己每天都想好多次各种各样的死法——摔死、流血过多而死、被车撞死、溺死。听到"溺死"两个字，他打了个冷噤，当年宋敏桃与宋平安浮尸水面的画面一闪而过。她烧心得厉害，不能平躺只能靠着，自己挣扎起身时再一次挥开他伸来的手；靠上枕头后又剧烈咳嗽、呼吸困难，他急忙按铃并问她哪里不舒服，她坚持把话说完——"我就是想看看，苦难的极限到底在哪里""也想看看，我这具身体的极限在哪里，因为变成如今这样，都是我咎由自取"。他膝盖一软伏在她手边，嘶哑地哽咽求她别说了；她摇头说自己那天不该去找他说话，还说"就是你砸烂肖护车的那天，那么我们就不会有任何开始"，让他彻底明白她后悔和他认识、后悔和他的一切。她说变成现在这样都是活该，怪她太过相信他、怪她把他当救命稻草；话音落下，他扇了自己一记响亮的耳光，接着是第二个、第三个，数不清多少个，一个比一个重、一个比一个响，她没有阻止，也不作反应。两名护士进来时愣了一下——她们认得出那就是销声匿迹大半个月的影帝鹤遂，此刻正跪在周念床边，两边脸颊上遍布清晰错乱的指印。他保持平静请护士看她呼吸困难的状况，护士先给她上呼吸机，并请他去会议室等检查结果。会议室里，韩老拿着检查报告告诉他：她全身上下都是病，多处脏器衰竭、功能不全才导致五感丧失，这个病的死亡率最高可以到20%，如果再不对她治疗就会成为那20%中的一个；她还有严重的抑郁。他深深垂头、肩膀发颤地无声哭泣，一滴泪落在黑亮的桌面上。韩老建议他也做心理测试、说自己治疗过几个多重人格的病人、人格整合效果都很不错；他摇头说"不行，他还不能死""他还有存在的价值"，并承认身体里除了沈拂南还有别人，交流方式是写在纸上，和他们上次说话是四年前、和沈拂南则是半个月以前。谈回治疗，韩老说目前会用静脉营养维持生命、配合抗抑郁药物，并强调再好的药也只是辅助，从病根入手、尽量让她心情轻松愉悦才最有用；临走前问他治好她以后会不会也治治自己，他只答"也许"。韩老走后，郁成转告生东返的催促——京佛那边已经在筹备开机、让他尽快回去；他答"我不会回去"，并说"辜负所有人所有事都无所谓""没有什么比她更重要，我再也不会离开她"。躲在一旁拐角处的周念摘掉氧气罩下床想离开，却在陌生的巨大病房里举步维艰，摸着墙壁挪了半天才刚到客厅拐角，正好听到这些话；鹤遂回头看见她，什么都没说便一把将她打横抱起送回卧室。她说"不管你这次做什么，我们都回不去"，他答"我知道""你要是真的想离开，就赶紧好起来，重新恢复五识从这里走出去，到时候我也不拦你"，她只说"希望你说到做到"，而他没有回答——因为他很清楚自己在撒谎，他根本做不到、不会放任她离开。刚把她放回床上，郁成又冲进来转告生导的电话与"马上过来找你"的威胁，他冷冷回"我没空""随便"，动作却极尽温柔地替她拨开脸庞的一缕发丝，颤抖着说"我不敢奢求别的""我只想要你长出新的血肉""念念，我要你好起来"。

**关键事件**：1. 抽血挨两针与那块敷不上手的热毛巾 2. 各项检查、三百平的顶楼VIP套房 3. 换药时露出的未拆线伤口与"不能再撕裂了" 4. "我每天都会想好多次各种各样的死法"与"溺死"引出的旧画面 5. "就是你砸烂肖护车的那天"与"怪我自己把你当救命稻草" 6. 连扇自己耳光、脸颊上的指印 7. 韩老的诊断"撑不过…死亡率最高20%"与"他还不能死""写在纸上""四年前""半个月以前" 8. "我不会回去""没有什么比她更重要"与"我只想要你长出新的血肉"

**逐章写法公式**：

- **情绪流向**：起：拒（热毛巾、拨开的手） → 承：崩（死法清单、呼吸困难、自扇耳光） → 转：判（韩老的诊断与"她的病根"） → 合：誓（"我不会回去"与"我要你好起来"）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：抽血与热毛巾（用一件小事写拒绝） + 连串检查与三百平套房（把场景升级到顶层） + 换药时露出的伤口（把男主的身体状况摆明） + 死法清单与"溺死"闪回（把旧伤翻出来） + 呼吸困难与"都是我咎由自取"（把责任全部认下） + 自扇耳光（用声音完成惩罚） + 韩老的诊断（把倒计时交给医学） + "他还不能死"与"写在纸上"（把人格线交底） + "我不会回去"与"没有什么比她更重要"（把他的选择锁死） + 抱起她与"希望你说到做到"（两人的条件对撞） + "我只想要你长出新的血肉"（用一句祈愿收章）
- **本章核心技巧**：把"拒绝"与"誓言"放进同一个空间——她拒绝吃饭、拒绝触碰、拒绝被他救，他则用抽血、换药、跪求、自扇耳光、放弃事业来不断加码；中间用医生的一纸诊断给这段关系加上倒计时，让"救她"从一句情话变成一场有期限的抢救
- **卡点与伏笔**：结尾卡点：他撒了谎——她若好起来他也不会放她走，"希望你说到做到"的承诺注定要破；埋设/回收伏笔：未拆线的腹部伤口与"不能再撕裂了" → 与第76章她踹裂伤口呼应；"写在纸上""四年前""半个月以前" → 与第64章"字迹不同的纸条"、第69章"两种笔迹"逐一对上；"他还不能死，他还有存在的价值" → 指向沈拂南在剧情里的功能；宋敏桃与宋平安浮尸水面 → 与第7/12章的死因冲突同源；"生导马上过来找你" → 为第80章生雅娇与生东返闯入病房埋线
- **时间线**：本章接第78章下午的入院检查，延伸至当日傍晚与入夜

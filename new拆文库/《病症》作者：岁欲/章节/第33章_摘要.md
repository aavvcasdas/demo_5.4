# 第33章 病症 摘要

**概要**：再访鹤家时院中那棵杏子树上已经坠满熟透的杏子，鹤遂扛着矮桌出来给她放画具，见她仰头盯着杏子便问"想吃？"，拿起长竹竿说打点下来；周念说没有，只是在想事情，被追问"想啥"时答"想你"，随后解释自己真正在想的是——他怎么都不问她为什么会这样。鹤遂说"有什么好问的？万一把你问哭了，我还得哄你"，她没好气地说自己没那么容易哭，被他回敬"我口气重点就能把你吓红眼而已"。她坐小凳上给他画素描，他举竹竿打杏子，一颗杏子砸在速写本上拉出一道扭曲的线，她威胁"你再这样，我就把你画得巨丑"，他耸耸肩说"这种昧良心的事，你要真愿意干，我也不拦你"。相处久了，周念发现他根本不是外界传言的狠厉冷漠，反而洒脱随性、善良恣意，甚至有点幼稚。随后他用井水洗了一兜杏子端来，从中挑了一个递给她说"尝尝？"，并在她开口拒绝前抢先说"这个杏子，你今天得吃"；她第三次犹豫后接下，咬了一口——那是她人生十七岁这个夏天吃过最酸的一颗杏，酸得五官失控、根本难以强咽。鹤遂平静地说"因为这是我特意挑的"，从一兜杏子中为她挑出最酸的那一颗，然后说"可这比不上人的胃酸"——她登时怔住，想到他出现在厕所时她正大口大口吐着胃酸和胆汁；他接着说"周念，一个酸杏都吃不了的你，是怎么忍受的？""像今天这样的情况，你不是第一次"。周念神思恍惚，甚至想不起自己到底是从什么时候变成这样的——是周尽商去世以后吗？不对，是更早以前。她低声请求"你能替我保守秘密吗"，他漫不经心地说"知道了"；她随即提出也要知道一个他的秘密，他却说她早就发现了——"现在站在你面前，这样的我，本来就是一个秘密"，意思是在这个小镇上他是众人口中的疯狗、人人避之不及，没有人知道他暴戾皮囊下的真实样子，而在他之前从未有人走进过他的生活；两人就这样说好互相保守秘密。鹤遂照旧搬躺椅躺在她旁边，她安静地画着举竹竿打杏子的他；她问他以后想干什么，他说"没想过"，又说"我是个没有以后的人"，周念听得心疼，故作轻松地说"会有的，鹤遂"。叙述点出：谁都没想到后来的鹤遂不仅有以后，还是璀璨无比的以后，只是可惜这样的以后里面没有周念。临走前她注意到他上楼换了衣服鞋子、说要"去喂猫"，便提出一起去；他拒绝同行，说"出门别和我走在一起"——她知道这是在保护她，也承认说到底还是自己内心懦弱。出门后他走在后方、始终与她保持十来米距离，穿黑色帽衫、帽子戴着只露出下颌线，人来人往的南水街上没人发现他踩过她的脚步、和她走的是同一条路。到了人少的地方她才转身招手让他快走，他笑她"你怎么像个贼"，她答"我们这样子偷摸摸地来往，可不就是像贼吗"，并在心里暗暗下决心总有一天要彻底勇敢、让所有人知道她和鹤遂是朋友。在长狭弄她终于问出小黑猫的名字，他说"它叫厌厌"，"厌世的厌"；猫从瓦檐上奔下来狼吞虎咽地吃他倒的猫粮，他说带回家过但它老往外跑，"它更喜欢自由"。一位背登山包的旅客经过，拿起相机拍下巷弄里侧脸浅笑的少女、背对镜头穿黑色帽衫的少年和中间的小黑猫，并问能不能发到微博上；周念看着照片忍不住翘起嘴角，鹤遂敷衍地说了句"随便"。叙述提醒，这张被随手拍下的照片多年以后会掀起一场舆论风暴。回家后周念把画有他素描像的速写本带回房、藏在衣柜最下方，和他那件黑色卫衣放在一起——这些物件连同她内心深处的悸动成为她青春里最深处的秘密；那天晚上她前所未有地睡了个好觉。

**关键事件**：1. "想你"的对答与他不追问的态度 2. 特意挑出的最酸的那颗杏与"这比不上人的胃酸" 3. 互相保守秘密的约定 4. "我是个没有以后的人" 5. 一前一后走南水街、被旅客偷拍 6. 小黑猫的名字叫"厌厌"

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 男主的关心方式是"不追问" | 用她的疑问发起：她直接问"你怎么都不问我为什么会这样"，他答"有什么好问的？万一把你问哭了，我还得哄你" | 反应层放大 | 甜、心疼 | 用"不追问"作为关心，把体贴写成反直觉的选择，比安慰台词更有力 |

| 人物的"预叙"承担悲伤 | 她说"会有的，鹤遂"，紧接着叙述直接跳到"后来的鹤遂不仅有以后，还是璀璨无比的以后。只是可惜这样的以后，里面没有周念" | 预叙 | 悲伤 | 在最温柔的一句台词后立刻插入结局式预告，情绪落差由叙述完成 |
| 关系必须藏在暗处 | 他提出"出门别和我走在一起"，她承认"说到底，还是她内心懦弱"；随后写他一前一后隔着十来米、踩过她的脚步走在同一条路上 | 对比锚点 | 压抑、甜 | 让"不能并肩"与"走同一条路"并置，用物理距离写关系的状态 |
| 蝴蝶效应式的伏笔 | 旅客偷拍并询问可否发微博，她笑、他敷衍"随便"；叙述直接点出"在多年以后，会掀起一场怎样的舆论风暴" | 预叙 + 物件植入 | 好奇 | 让一个第三者在日常场景里留下影像证据，为多年后的公共事件提前埋线 |
| 猫的名字补全人物 | 她不问名字只叫"咪咪"，他答"它叫厌厌""厌世的厌"；再说带回家过但它老往外跑，"它更喜欢自由" | 命名即人设 | 心疼 | 让角色给动物取的名字、以及他放它自由的选择，替他说出他的自我认知 |

**逐章写法公式**：

- **情绪流向**：起：松弛（杏子熟了、斗嘴） → 承：好奇（他为什么不问） → 转：震撼（酸杏、胃酸、互相保守秘密、"没有以后的人"） → 合：暖与隐忧（喂猫、被偷拍、藏起的速写本）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：打杏子的日常斗嘴（先把两人的相处写成熟络） + 最酸的杏与胃酸的对比（用身体经验完成一次开导与一次戳穿） + 互相保守秘密的约定（关系升格为同盟） + "没有以后的人"与喂猫（交出他的自我认知与生活细节） + 旅客偷拍（埋下跨年伏笔）
- **本章核心技巧**：把全章最重的话（"这比不上人的胃酸""我是个没有以后的人"）都放在十分平常的场景里说——一颗杏子、一张躺椅、一只野猫，重量由内容承担、场景保持松弛，悲喜不靠语气靠落差
- **卡点与伏笔**：结尾卡点：速写本与黑卫衣一起被藏进衣柜最下层（秘密的实物归位）；埋设/回收伏笔：旅客拍下的照片 → 多年后的舆论风暴；"厌厌"的名字 → 他的自我投射；猫"更喜欢自由" → 与他后来必然的离开呼应；"我是个没有以后的人" → 与后文"璀璨无比的以后里没有周念"对照

# 第26章 病症 摘要

**概要**：午后的光落在鹤遂房间的桌上，周念看见桌角那盒她上次买给鹤遂的头孢，打开数出里面少了三颗，便问他是不是吃过头孢后又喝了啤酒——上次在按摩店门口提醒他时，他还说不如死了免得被她烦；鹤遂坐在床沿答"没有，我妈做啤酒鸭用的"，而她一听到吃的就忍不住恶心，眉间一闪而过的厌恶被他眯眼收进眼里。她随即注意到桌面玻璃下压满橘红色奖状：2013至2014学年年级第一的学习标兵、2015年校级三好学生、2016年运动会高一男子1500米第一名，一张接一张。她心里五味杂陈地问他为什么不上学，鹤遂身子一僵又放松，沉脸说"你该走了"；她起身前还是忍不住哽咽着说他不读书太可惜、难道想一辈子在小吃店打工。鹤遂逼近她，把她困在桌沿与胸膛之间，俯身与她的视线齐平问"是不是我给你脸，所以才敢让你对我指手画脚"；周念怯怯低头，委屈到极处反而说"我就是说了，那你打我吧"。他憋着笑故意说"我真打了"，闭着眼的周念等到的是额头上轻轻一弹。她憋红脸骂他拿她寻开心，又伸手推了他胸口一下说不理他了，鹤遂被推得后退两步却始终挂着笑——那是她第一次见到他没有防备的笑。她夸他笑起来比明星还好看，他的笑意却迅速消失，说"好看是没用的"，因为他从小到大听过太多"是真好看，可惜是条疯狗"。周念伸手用两根手指把他的嘴角往上推，说多笑会变好运，硬是给他推出一个笑容，最后他还是没防备地笑了。出门前她问下周末还能不能来找他，用"找你画画"当借口，他答应了，同时要求她别告诉任何人两人在来往，说"对你不好"；周念因为害怕冉银，什么都没说，只低低嗯了一声。

**关键事件**：1. 头孢少三颗引出"啤酒鸭"的回答 2. 玻璃下压满的奖状与他辍学的疑问 3. 被逼到桌沿的质问与"那你打我吧" 4. 弹额头与第一次无防备的笑 5. "好看是没用的"与"可惜是条疯狗" 6. 约定下周末见面，但要求保密

**逐章写法公式**：

- **情绪流向**：起：平静（午后、数药片） → 承：心疼（奖状、辍学之谜） → 转：压迫与放松（被逼到桌沿、弹额头、他第一次笑） → 合： bittersweet 的约定与沉默（保密要求 + 她的顾虑）
- **节奏配比**：慢铺垫 35% / 快冲突 30% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：数头孢引出日常对话（用物件开启场景） + 发现奖状并追问辍学（把人物过去一次性抛出又关闭） + 逼到桌沿的质问与"那你打我吧"（冲突升到最高） + 弹额头与两次笑（用预期违背降温并给甜） + 出门前的约定与保密要求（把甜转成带风险的隐忧）
- **本章核心技巧**：把同一场戏做成"加压—卸压—再挂钩"的三段式——先用奖状和辍学把人逼到墙角，再用一次弹额头把张力全部卸掉换成甜，最后用一个保密条件把甜重新变回压力
- **卡点与伏笔**：结尾卡点：他说"别告诉任何人""对你不好"（下章起两人的来往进入地下状态，冉银成为随时会引爆的威胁）；埋设/回收伏笔：头孢少三颗 → 回收上章的药盒与啤酒疑问；玻璃下压着的奖状 → 他的辍学原因留待后续揭示；"是真好看，可惜是条疯狗" → 他的外号与成长经历的来源

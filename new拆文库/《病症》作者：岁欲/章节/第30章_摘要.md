# 第30章 病症 摘要

**概要**：一个寻常的夜晚，周念收拾好桌面转身看见莫奈站在过道里，手里提着两杯蜜雪冰城的珍珠奶茶，说是请她喝的。周念毫不犹豫地接过，因为她很珍视这个朋友；上一次喝奶茶还是初一或更早，那时都是周尽商瞒着冉银偷偷买给她，现在偷偷买零食给她的人已经不在了，她也不再喜欢任何食物。两人出校门后尽量往亮堂的地方走，莫奈兴致勃勃地讲京佛——半夜三点都灯火通明、通宵不关门的店随处可见，但路边常有烂醉的酒鬼和没素质的男人；她注意到周念只是拿着奶茶还没插吸管，周念便撕开吸管插上，说听得入神忘记了。前方石桥前后无灯，桥上站着一个人影，看不清男女；为了不让莫奈看出端倪、也不让好朋友伤心，周念用力吸一大口奶茶、嚼着珍珠作出欣喜的表情说"好好喝啊莫奈"，莫奈很高兴地说下次请她喝黑糖口味。两人说笑着踏上石桥，周念与那人擦肩而过时不经意扭头看了一眼，浑身汗毛竖起——奶茶脱手落地，塑料杯炸开、咖色液体溅在两人鞋上，石桥上站着的竟是冉银。冉银绷着唇先看她、再看地上那杯奶茶、最后把视线凝定在她脸上像某种符咒；周念觉得自己像个被抓现行的贼，双脚前流淌的奶茶就是她作案后留下的工具。莫奈出声问好并自我介绍是这学期新转来的，冉银则微笑着问"奶茶是你给周念买的吗"，听后说"你可对我们家周念真好"；周念早已冷汗淋漓、脸色苍白、嘴唇哆嗦，恐惧像寄生在血管里的病毒游走全身。冉银说"走，回家吧"，走下石桥时在暗里回头瞪着地上那杯奶茶，模样活像一只鬼。离家越近周念的恐惧越强，冉银让她在堂屋等，随后提着一桶5L的食用大豆油进来，直接让她跟着上楼进厕所；她把拧开红盖的油桶放在洗手台上说了句"喝"，解释"你得喝下去，我要你用油把刚刚喝的奶茶全部吐出来"。周念想说明自己不用喝油也能吐、被"不要和我解释"打断，冉银又接连说"七斤，别叫妈妈失望""妈妈都是为你好""帮你总能喝了吧"，句句是问却句句不给回答的机会，最后把桶口对准她的嘴，甚至伸手塞进她嘴里逼她张嘴，掰开她的嘴抬高油桶强灌。周念被迫往下咽，油从两边嘴角流到脸上和脖子上、滴到地上，她头晕目眩、踩到满地的油滑倒，狼狈摔在马桶前，跪着把油和奶茶珍珠全部吐出来——还出现了之前从未严重到这种程度的幻听。冉银站在她背后说外面的东西很脏、奶茶里全是植脂末和添加剂、那个转校生根本想害她，还说朋友是最没用的东西、她有妈妈就够了，最后摸着她的头说"总有一天你会理解妈妈的"；周念吐得满脸泪和汗，只说出一句"我都吐干净了"，心里知道的是自己好像病得更重了。

**关键事件**：1. 莫奈请奶茶、周念装出喜欢的样子 2. 石桥上撞见冉银、奶茶落地 3. 冉银对莫奈的和善盘问与周念的恐惧 4. 回家被逼喝5L大豆油、被强灌 5. 跪在马桶前呕吐并第一次出现幻听 6. 冉银的"朋友无用论"与"你会理解妈妈的"

**逐章写法公式**：

- **情绪流向**：起：温暖（朋友请奶茶） → 承：平静中的隐瞒（装作爱喝、讲京佛） → 转：恐惧爆发（石桥撞见冉银、回家被灌油） → 合：绝望（幻听 + "病得更重了"）
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：睡前一杯奶茶（用友谊把情绪抬高） + 石桥撞见母亲（在最放松处投放最怕的人） + 母亲对外的和善盘问（把恐惧压在礼貌之下） + 堂屋与厕所的灌油（把病症惩罚成具体刑场） + 幻听与"病得更重了"（给病症做一次跨级的标记）
- **本章核心技巧**：把全章前四成写成平缓的女生友谊日常（奶茶、京佛、说笑），让恐怖从"擦肩而过的那一眼"开始，之后不再有任何回旋，一路把焦虑推到呕吐与幻听——温度越高，坠落越重
- **卡点与伏笔**：结尾卡点：幻听第一次出现、"自己好像病得更重了"（病症新的阶段）；埋设/回收伏笔：周尽商瞒着冉银买奶茶 → 回收她的进食障碍根源；冉银"以后少和她来往""你不需要朋友" → 莫奈这条友谊线被明令切断；石桥上冉银为何出现在那里 → 她对周念行踪的掌控

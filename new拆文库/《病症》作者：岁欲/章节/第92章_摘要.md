# 第92章 病症 摘要

**概要**：周念买了新手机、办了新电话卡，与外界断联已经两个月整；这段时间她时常想到莫奈和霍闯，却很少想到冉银，偶尔想到的那天食欲就会特别不好、所有恶性记忆瞬间涌上心头，让她在盛夏的天里手脚冰凉。装卡开机后她做的第一件事是站在阳台给莫奈打电话，看着远空缓缓下沉的夕阳；莫奈接起后很礼貌地问"你好，哪位"，她趴在护栏上，泪花比声音先出来，只轻轻叫了一声"莫奈"，那边沉默三秒后传来一记长长的哭声。莫奈抽搭着问"整整两个月都联系不上你，担心死我了"，周念说自己"在别的医院接受治疗"，又说"好多了，现在有72斤了"；莫奈说要请假两天来看她、问她在哪个医院、问"谁陪着你，冉阿姨吗"，周念温吞地答"鹤遂陪着我"，把莫奈惊得半晌没说话，随即意识到"该不会鹤遂突然隐退消失的这段时间，都和你在一起吧"，周念只云淡风轻地回"以后有机会慢慢和你说"。挂断电话转身时，她发现鹤遂正靠在阳台的推拉门上环手等着，并先解释"我刚到这，没听你打电话"；擦肩进屋时她注意到他身上穿的不是病服，而是一件黑t和灰裤，就像以前他最常穿的那样，恍惚间仿佛17岁的鹤遂就站在她面前。她坐到沙发上摆弄新手机、下载软件时，注意到他来到她面前只是站着不说话，脚上穿着一双黑色板鞋；她问"你有话要说吗"，他答"我要出去一趟"，她没有问他去哪、也没有问他还会不会回来，只说"今晚可能会下雨，我今早看电视上天气预报说的"。鹤遂离开后窗外夜色彻底降临，她漫无聊赖地换着台时，莫奈发来一张截图并附"这不是那谁吗？？？""他搞宠物救助？"——截图上是一张半边疤的脸，是肖护。周念起求证心下载了抖音，看完他账号里仅有的十五个视频：他在管道旁、垃圾场、阴沟里发现受伤的流浪猫狗，猫狗身上都有着人为造成的伤痕（被开水泼、被烟头烫、被剥皮），他带它们去宠物医院治病，结尾总是抱着猫狗善良地笑着。周念一眼看穿这是伪善，回莫奈"那些小猫小狗都是他故意弄伤的，这就是他做的一场戏"——他没有停止过作恶，伤生害命是一种恶、伪装善良也是一种恶，他用这类视频赚取流量、利用网友的善良号召所谓的爱心捐款；愤怒过后她迎来一场无休止的平静，明白自己的愤怒取不了任何作用，身体里那把生锈的刀再次开始挥动。晚餐送来两人份，她的那一份是营养餐、鹤遂的只是一份番茄炒蛋盖浇饭；她想起他说过宋敏桃忙着赚钱照顾宋平安、总有顾不到他的时候，他从小吃东西就随意、两个大馒头就能对付一天。看视频后她生理性不适、老想吐，胃口格外欠佳，却仍慢吞吞地喝汤吃菜——现在的她总对自己说"好好吃饭，好好活着"，既然在鬼门关闯了一遭没死成，那就说明上天另有安排，她不是信命，而是决定要敬畏生命，催吐似乎已经是很久远的事情。饭后她下楼到花园溜达消食，绕开味道像腐败海鲜的石楠花，经过一株很像鹤家小巷那一株的海棠，阔别小镇两月竟有些想念；刚进楼外面就下起瓢泼大雨，她回病房拉上窗帘，洗过澡已是晚上十点，鹤遂还没回来，她躺在床上睡不着又窝到沙发上换台。就在云宜电视台夜间新闻播到"善进书院目前处在一个停办状态"时，鹤遂带着一身潮湿进了屋：浑身淋得透湿，脸上的黑色口罩已吸满水，没有一根头发是干的。她注意到他肩上扛着两个硕大的黑色帆布口袋，其中一个的边角被撑出她最熟悉的直角轮廓；他把口袋放到茶几上发出咚的一声闷响，慢条斯理地解开结，露出木质边框的微黄，又把另一只从底部抄起、直接掀翻——琳琅缤纷的颜色占据着她的双眼，赤橙黄绿青蓝紫、朱砂、铅白，多到看不过来。他抹了一把脸上的水，越过茶几拿过她手里的遥控器把电视关掉，喉结滚动了一下，看着她的眼睛温声说"念念，重新开始画画吧"。

**关键事件**：1. 两个月断联与打给莫奈的电话、72斤 2. "鹤遂陪着我"与莫奈的震惊 3. 黑t灰裤与恍惚中的17岁 4. "我要出去一趟"与"今晚可能会下雨" 5. 肖护的十五个视频与"这就是他做的一场戏" 6. "好好吃饭，好好活着"与敬畏生命 7. 花园、石楠与那株海棠 8. 暴雨夜扛回两袋画具、"重新开始画画吧"

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |

| 两份晚餐排出地位差 | 她的营养餐列出五样："红豆汤，荷兰豆炒肉片，玉米莲藕排骨汤，胡萝卜饭，清炒红苋菜"；他的只有"一份番茄炒蛋盖浇饭" | 菜单对比 | 其他 | 用两份菜单的丰俭差写照顾者与被照顾者的位置，不用一句评论 |

**逐章写法公式**：

- **情绪流向**：起：暖（打给莫奈的电话与72斤） → 承：怒（肖护的十五个视频与一场戏） → 转：静（两份晚餐、饭后散步与那株海棠） → 合：动（暴雨夜的两袋画具与"重新开始画画吧"）
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：新手机与两个月断联（用一件旧断点重启外部世界） + 打给莫奈与那记哭声（用一通电话交代她还有人惦记） + "好多了，现在有72斤"（用一句斤数报康复） + "鹤遂陪着我"与莫奈的沉默（把最意外的信息轻放） + 黑t灰裤与17岁的恍惚（用一件旧衣把过去拉近） + "我要出去一趟"与天气预报（用迂回的关心写她的不追问） + 莫奈转来的肖护截图（用一条外部消息撕开新事端） + 十五个视频的清单（把伪善写成可逐条点数的作品） + "这就是他做的一场戏"（用一句断言定案） + 愤怒之后的平静（把无力感装进身体里的一把刀） + 两人份的晚餐与番茄炒蛋盖浇饭（用菜单差写照护关系） + "好好吃饭，好好活着"（把康复落在一顿饭的速度上） + 花园、石楠与海棠（用两株植物写嗅觉恢复与乡愁） + 十点未归与"也许沈拂南在半道醒来"（用一句假设把风险挂起） + 新闻里的"善进书院停办"（用一句旁白式的播报埋线） + 暴雨夜的两个帆布口袋（用外形轮廓先给暗示） + 解结、掀翻与那一堆颜色（把揭晓拆成四步） + "念念，重新开始画画吧"（用一句请求收章）
- **本章核心技巧**：整章在"重启"上做文章——先是重启对外联系（新卡、新手机、打给莫奈），再重启身体的基本功能（72斤、好好吃饭），最后重启她曾经最珍贵的那件事（画画）；中间插入肖护的十五个视频作为唯一的外部冲突，让这个本该温柔的重启日带上"世上还有人持续在作恶"的底色，最后用两袋画具把整章的情绪拉回到两人之间
- **卡点与伏笔**：结尾卡点：两袋画具倒在茶几上，他说"念念，重新开始画画吧"——她是否答应、他这一趟出去做了什么、新闻里的善进书院与他有何关联都悬置；埋设/回收伏笔：肖护的伪善账号与"利用网友善良号召所谓的爱心捐款" → 旧恶重现在新平台，直指后续的舆论线；第91章人格记录表里小智手里那支"全新未削过"的铅笔 → 与本章两袋画具、"重新开始画画吧"形成呼应；鹤遂穿的"黑t和灰裤，就像以前他最常穿的那样" → 他有意回到十七岁的模样；"今晚可能会下雨"与她拉上窗帘把夜雨关在外面 → 他确实淋成透湿回来，天气预报成了两人之间唯一的暗语；云宜电视台夜间新闻里"善进书院目前处在一个停办状态" → 一个没有解释的地名播报，留待后续；"也许沈拂南在半道醒来，掌控着身体主权，让他再也回不来" → 她第一次主动给多重人格的可能留出位置；霍闯这个名字在本章被提起 → 与莫奈并列的旧关系有待展开
- **时间线**：本章为第91章之后、与外界断联满两个月的当日傍晚至当夜

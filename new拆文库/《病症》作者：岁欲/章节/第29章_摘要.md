# 第29章 病症 摘要

**概要**：关于鹤遂辍学的原因，外面传的版本五花八门，真正知道内情的只有宋敏桃一个人，这个话题也一直是家中的禁忌——她每次尝试谈念书的事，鹤遂都用三言两语把她打发。宋敏桃望着窗外小镇四周的巍巍青山叹了很长一口气，眼里流淌着悲凉和空茫；她把视线收回，落到周念那条沾满斑驳红油漆的牛仔裙上，问她是不是帮着阿遂一起擦的门，然后诚恳地道谢"你真是个好孩子"。她随后说出实情：门被泼油漆不是第一次，她甚至记不清是第几次，每一次阿遂都会说"你进去，我来弄"或者"去开你的店，别碍事"，有时候他半夜起来检查门上有没有被人泼油漆写字，发现就一个人大半夜擦，在天亮她出门前把油漆全部擦干净。她说阿遂是为了她才不肯继续念书的——他怕她一个人在家被催收的找麻烦、店子也开得不清净，不顾她的劝阻坚持退学回家，"也不仅仅是因为催收的事情……但总归是为了我"。周念没有深问还有什么原因，她觉得一个家庭若是不幸绝不会只因某一件事，就像鹤遂如今浑身长满稠密的刺，也绝非只因旁人一句谩骂或某次殴斗，"深渊里的毒蛇不会只有一条"；她看着玻璃桌面下压着的奖状说"鹤遂不念书，真的很可惜"，宋敏桃说自己晚上一想到这事就失眠。楼梯响起嘎吱声，宋敏桃抹去眼角泪珠说"他听见会不高兴"；鹤遂进门问在聊什么，周念抢先答"阿姨让你别欺负我，否则会骂你"，他没有细究。宋敏桃走后，鹤遂又绕着吃的问题问她"要不要吃点别的什么"，周念神经一紧，以要画画为由推掉；她先离开房间，他留在原地出神地看着桌上那盘没动过的青团和牛奶。两人下楼到院中，周念选在杏子树底下画画，鹤遂先一步提起她的画箱和画板，又搬来矮长桌和木椅子按她的要求对准井摆放；她说"你这样子，会让我每周都想来找你画画的"，他回"你想得美"。他撩起黑t下摆擦汗，露出冷白的小腹、分明的腹肌和右腰一道狰狞的疤，周念一把捂住眼睛，他捉住她的手腕作势要把她的手拉开、说"上次在医院掀我病号服怎么不见你害羞？再看看？"，她羞得跺脚挣扎，被拽下手后才发现他早就把衣服放下来了、只是在逗她。她绕桌追打他，不小心踢到桌腿踉跄，跑出去两步远的鹤遂立刻折回接住她，她扑进他怀里被他圈住腰；她听见他吞口水、看见他喉结滑动，他随后平静地问"你是不是抱得有点久？"，两人仓促分开。周念当天画了一幅红色系抽象油画，和裙摆上的油漆红同色，正好用来向冉银解释；鹤遂搬来躺椅睡在她旁边，用一张废稿画纸盖住脸说"我睡会，有事叫我"。叙述点出这本是两人最美好的时候——彼此的伤疤都还没被揭开；也点出废稿画纸下面那双眼大部分时间都是睁开的，他是清醒的，偶尔闭眼，都在听周念画笔的沙沙声。

**关键事件**：1. 宋敏桃说出"门被泼油漆不是第一次"与半夜擦门的细节 2. 辍学原因：为护母亲不被催收骚扰 3. 鹤遂再度试探吃食、周念以画画推脱 4. 杏树下的写生、腹肌事件、绕桌追打与意外拥抱 5. 红色抽象油画成为应对冉银的掩护 6. 他用废稿画纸盖脸"睡觉"，其实一直睁着眼

**逐章写法公式**：

- **情绪流向**：起：沉重（宋敏桃叹气、拒绝谈念书） → 承：心疼（半夜擦门的细节、为母亲退学） → 转：甜（杏树下写生、腹肌的打闹、意外拥抱） → 合：暖中夹暗（红油画、盖在脸上的废稿画纸与睁着的眼）
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：母亲的转述（补全男主处境的日常版本与辍学动机） + 周念拒绝追问（用人物判断代替作者补全） + 鹤遂二次试探吃食（病症压力续接） + 杏树下写生与打闹（把关系甜度推到本卷顶点） + 事后视角收尾（预告美好将尽）
- **本章核心技巧**：把最重的信息（为母亲退学、半夜独自擦门）交给母亲用回忆口吻讲出，再把最甜的写生场景放在同一章后半段承接——用一次沉重交代为一次彻底松弛做底，最后一句反手标注"这已是最好的时候"
- **卡点与伏笔**：结尾卡点：废稿画纸下"大部分时间都是睁开的眼睛"与"似乎一切都还来得及"（预告后面的下坠）；埋设/回收伏笔：催收与"不仅仅是因为催收" → 辍学的完整真相仍未给出；牛仔裙上的红油漆被红油画盖住 → 冉银这条线暂时被糊弄过去；他反复递吃食 → 病症即将被识破

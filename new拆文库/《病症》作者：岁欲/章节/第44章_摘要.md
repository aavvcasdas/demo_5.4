# 第44章 病症 摘要

**概要**：周念被人群挤在按摩店门口看着废墟，冉银提着新鲜牛肉和一条现杀的鲈鱼从旁边出现，问她怎么在这里看热闹；周念谎称外面太热正准备回家画，冉银没起疑，反而指着蹲在灯箱旁抽烟的鹤广骂"鹤千刀"，说他自家老婆的店被砸成这样只会蹲在旮旯里抽闷烟。拦住那群闹事女人的只有鹤遂——他踩过碎木板和浓稠的红油漆、一步一个血印挡在她们面前，重复"帘子后面要是没有你们想看的东西，一个都别想走"，几个女人不敢动便掏出手机报警。铁床上的女孩突然嘶吼挣扎，铁链甩在床脚和地砖上刺响，众人这才看见她的一只脚被铁链拴在床脚上；宋敏桃冲过去抱住她泪流不止，女孩在母亲怀里冲着门外咆哮，只能发出破碎音节、连最基本的语言功能都已丧失，围观者迫不及待掏出手机拍下这一幕。冉银嫌再看下去误了饭点叫周念回家，路上一路唠叨她没带伞，又顺口说出宋敏桃的旧事：宋敏桃当年被鹤千刀强奸、被父母逼着嫁给他，才有今天一个辍学的儿子、一个畸形的女儿。周念由此听到那桩小镇人尽皆知的丑闻——宋敏桃刚满十八，帮父母卖豆腐、割猪草，年轻杀猪匠鹤广第三回来宋家时趁着宋父宋母在街上卖豆腐、家里只有她一人，丢下开膛破肚的猪把她拖进猪圈深处强奸，半小时后勒紧裤腰带满脸红光地走出来继续剐猪；宋敏桃不敢声张、几度寻死，直到肚子一天天大起来被父母逼问出实情，父母没有带她去报警，反而对外宣称两人自由恋爱并马上结婚，她就这样被迫嫁给了强奸自己的男人。回家后周念发现鹤遂抓的那瓶萤火虫已经全部死亡，她捧着瓶子看了很久，觉得鹤遂就生活在瓶子中，短瞬的光亮后是永恒的黑暗，决意要一直陪着他，于是趁冉银熟睡在凌晨偷偷溜出家门，独自走过一条又一条伸手不见五指的小巷，站在鹤家门前发微信告诉他"我在你家门口"。鹤遂气喘吁吁地拉开木门，身上没穿衣服、只说"我睡觉不穿衣服"，问她现在几点，得知是凌晨一点后严肃地说"你下次再这么晚一个人跑出来，我会生气"。两人并肩坐在门槛上，周念说自己只会一味从他身上汲取能量和温度、觉得自己自私过分，鹤遂回了"念念，你只用出现在我的生活里，就已经是老天爷给我的无上恩赐"，并把家里从不外说的秘密告诉她：妹妹叫宋平安，今年十二岁，是宋敏桃在鹤遂五岁那年怀上的二胎，因家中拮据没做过产检、生下来才发现是一只眼睛睁不开、手指粘连的畸形儿，一周后鹤广使唤六岁的鹤遂帮忙买毒品被抓、真相才浮出水面，宋敏桃不愿女儿随他姓、取名宋平安寓意一生平安，对外只说生了个死胎，把女儿藏在按摩店那张深红色绒面帘子后面用铁链拴着养——一份母爱被小镇传成了情色交易的遮羞布。周念听完觉得鹤遂的家像炼狱，说不出安慰的话，只伸手与他十指相扣，他反客为主用力握紧了她的手。

**关键事件**：1. 冉银出现、周念谎称准备回家画画 2. 鹤遂一步一个血印拦下闹事女人、对方反手报警 3. 铁链拴脚的妹妹当场嘶吼、围观者拍照 4. 冉银道出宋敏桃被强奸逼婚的旧丑闻全貌 5. 萤火虫全部死亡与凌晨偷溜出门 6. 鹤遂讲出妹妹宋平安的身世与深红色帘子的由来 7. 门槛上十指相扣

**逐章写法公式**：

- **情绪流向**：起：混沌与失血的白（人群、废墟、视线动荡） → 承：怒与荒唐（鹤遂一个血印一个血印地拦人、对方报警） → 转：震（铁链、抱女的母亲、冉银说出强奸逼婚的旧案） → 合：静与暖（萤火虫全死、凌晨偷溜出门、门槛上十指相扣）
- **节奏配比**：慢铺垫 20% / 快冲突 25% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：冉银撞见与撒谎（守住两人关系的秘密） + 鹤广蹲着抽烟与被骂（把缺席的父亲摆进现场） + 鹤遂拦人与对方报警（写恶人先告状） + 铁链与母亲的抱（把妹妹的处境物化） + 冉银口述强奸逼婚（一次性补全母亲的身世前史） + 猪圈旧案完整倒叙（把丑闻落成具体的一天） + 萤火虫全死（用意象宣布男主的处境） + 凌晨偷溜出门与开门（用不安全的行为写决心） + 门槛问答与宋平安身世（集中释出全部秘密） + 十指相扣（以动作收束）
- **本章核心技巧**：全章把"看客"这个位置反复利用——周念在人群里看废墟、看铁链、看母亲抱女，最后她不再看，改为半夜走到当事人门口坐下来并握手；同一章内先写"什么都做不了"，再写"我陪你说会话"，无力感被一个小动作翻转
- **卡点与伏笔**：结尾卡点：长夜与十指相扣收章，秘密已说尽、两人确立"出现在彼此生活里"的位置，下章期待落在妹妹与母亲今后的处境；埋设/回收伏笔：鹤广（鹤千刀）毒瘾与"六岁鹤遂帮买毒品被抓" → 父亲线的主因；宋敏桃被强奸逼婚的旧案 → 母亲的人生前史与镇上敌意的根源；铁链拴脚的妹妹宋平安 → 需要被解救的长期线索；深红色帘子被妖魔化的由来 → 已回收（第43章的传闻在此解释）；萤火虫全部死亡 → 意象回扣；冉银"画具箱里放着一把折叠遮阳伞"的细节 → 母女日常的隐瞒习惯；"辍学的儿子" → 鹤遂学业中断的线索
- **首次出现**：鹤广（鹤千刀）、宋平安

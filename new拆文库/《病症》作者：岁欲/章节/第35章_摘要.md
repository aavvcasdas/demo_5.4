# 第35章 病症 摘要

**概要**：鹤遂打零工的地方总不固定，周念在上下学路上时不时能在各种地方看见他——旧货市场的家具店里他扛运东西，肩上搭着灰布巾，周念亲眼见他独自背起一整个大冰箱，汗如雨下、肩膀被压得微弯，眼里那份冷韧却不减半分；搞装修的店面里他坐在木梯上刷墙或提着油漆桶，身上总覆着白灰，脸色比平时更沉闷，看上去比同龄人成熟寡言；有时他坐在手机店的维修小桌里，拿着周念不认识的工具戳弄一块小芯片。每次看见他她都会停下脚步默默看他，而他也总能发现不远处的她，却每次只轻描淡写扫一眼就收回视线、眼里全是漠然，像完全不认识她——只有周念知道，他是担心和她多一秒的视线交错就会惹来旁人非议，不想给她惹麻烦；她就为此站在原地笑得像个傻子。五月末的一个下午有体育课，正出教学楼时好几波女生飞快窜过，喊着"快快快，等下看不到了""没想到他居然真的回学校了啊""就在操场"，周念推断出那个人只能是鹤遂，便和莫奈一路快走到操场。学校晚上进过贼，贼从没有防盗措施的外墙翻进来偷走了校长办公室的新电脑，校长联系了镇上搞防盗的师傅；那堵两米半高的水泥墙外搭着横面木梯，鹤遂踩在梯上、人比墙高出半个身子，站在所有人都能看见的高度，身前两个桶一个装和好的水泥一个装碎玻璃；他穿纯黑背心，暴露在日头下的脸、肩膀、手臂、手指没有一处不白到发光，流畅的胳膊肌肉线条让脸皮薄的女生红了脸，有胆大的女生趁乱嚷"这么热还不脱吗？？？"引来一片尖叫起哄。周念站在百米之外远远看着，心里好感慨，看他被女生围着"感觉就像是吃下了一粒酸杏"，即便他不为所动只专心糊水泥、插玻璃，那颗酸杏还是在她心口融化了；莫奈说他"好像个明星""身上很有那种当受万人瞩目的耀眼感"，周念说不太懂这句话——叙述点出她以后会懂，而当她真的懂得时，她连站在百米之外看他的资格都不再有。体育课上女生们都心不在焉地往后方外墙看，轮到女生跑八百米时太阳更加热辣，体能跟不上的周念一开跑就稳定垫底；经过外墙处她余光注意到梯上的鹤遂侧身看向她的方向，抬头就与他目光相接，虚空里似有一痕隐秘的火花闪过，她心虚地匆匆低头，胸口却一瞬岔气剧痛，只好捂着胸口改跑为走——余光里他瘦高的身影纵身跳下稳稳落地，黑色板鞋的鞋尖正对着她的方向；莫奈回头看见她捂胸口便倒回来扶她，就在被扶住时，周念注意到那双黑色板鞋掉转了方向，他重新爬上了横面木梯。她让莫奈别管自己、去向体育老师请假，老师看她脸色就温和地让她去树荫下歇着喝水。她站在老榕树的浓荫底下休息，莫奈跑来报喜说差点没及格、就差一秒，周念刚说"那真是万幸，不及格就惨了，会影响期末评优"，韩青突然插话讥讽她"玩无辜小白花引人注目的小把戏""只有你莫奈才会当真"，身后跟着一同玩的李莉莉和曾小雨；莫奈抢先反驳，韩青就夹着嗓子学她"啊，好痛哦~~跑不动了哦~~"，又讽刺她能靠画画加成评优、不需要体测分。周念上前一步、瘦弱的身体站在莫奈面前，声音清软又坚定地说"我如果真的想吸引鹤遂的注意力，我会自己过去和他说话，而不是用你口中的把戏"；韩青立刻逼近激她"你敢不敢现在就过去，如你所说，过去找他说话"，周念噎住——当着这么多人的面，她确实如鲠在喉；韩青见她犹豫便笑说"怕啦？我就知道你不敢"，周念用最平静的声线打断她说"我去"，并反问"如果我去的话，你以后是不是可以停止这种无聊的行为"，韩青愣了下后应下；周念刚抬脚又被叫住，韩青加码"说话可不算什么，你得要到他的手机号，否则不算"，周念脑海里自动浮现出一串熟悉的十一位数字，仍是那句"去就去"，随后在一众纷杂的目光中朝鹤遂所在的方向走去。

**关键事件**：1. 三处打零工的场景与他刻意不看她 2. 鹤遂回学校在外墙做防盗作业被女生围观 3. "吃下一粒酸杏"与"受万人瞩目的耀眼感" 4. 八百米上的目光相接与黑色板鞋掉转方向 5. 韩青的当众讥讽与莫奈的维护 6. 打赌升级为"要到他的手机号"，周念当众走向鹤遂

| 男主的处境与同龄人的差距 | 连写三处零工（扛冰箱、刷墙、修芯片）都配一个具体动作与体态，再补一句"同龄人现在是坐在教室里的，书卷墨香，前程似锦，和他完全不一样" | 平行并列 + 对比锚点 | 心疼 | 用三处不同工种的短镜头并列，再加一句对照句，人物处境不必解释 |

**逐章写法公式**：

- **情绪流向**：起：心疼（三处打工场景与刻意的漠视） → 承：微酸（围观、尖叫、"像吃下一粒酸杏"） → 转：紧张（八百米岔气、目光相接、鞋尖掉转） → 合：决意（当众打赌，走向他）
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：三处零工短镜头（补全男主生存状态与被保护的关系） + 学校外墙作业与女生围观（把男主推到公开视野，制造女主吃醋与"耀眼感"预言） + 八百米的目光相接与岔气（用身体事故完成一次隔空互动） + 韩青的三人讥讽（把冲突从私下驱到公开） + 赌局升级与走向他（用一次当众走近收束本章并抛向下一章）
- **本章核心技巧**：把关系置于"公开场合不能相认"的规矩下反复施压——他跳下又爬回、她只能在百米外站着看，最后用一个赌局强行把两人拉到同一个镜头里，规矩与期待同时到达临界点
- **卡点与伏笔**：结尾卡点：周念当众走向鹤遂、还答应要讨到他的手机号（下一章两人在全校注视下的会面）；埋设/回收伏笔："受万人瞩目的耀眼感" → 预言她将失去站在百米之外看他的资格；"吃下一粒酸杏" → 回收上一章的最酸杏；打零工多而杂 → 他的经济与辍学生存状态

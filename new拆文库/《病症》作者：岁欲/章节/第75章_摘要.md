# 第75章 病症 摘要

**概要**：天色阴寐，深重的云层在小镇上方浮移，明明还是清晨，周家院子里却有了薄暮将至的光景。冉银见周念只穿着睡衣到院中，先说"今天的天气这么凉，怎么就穿个睡衣就出来了"，说完自己就察觉不对劲——鹤遂在房间里，周念怎么换衣服。一根头发被风吹进周念眼里，鹤遂伸手想替她拂开，她却先一步抬手把头发拨开，他那只冷白色的大手就悬停在耳边；她把手伸进正前方的虚空里，努力去感受此刻的风，因为她的发丝正在不停扬动，可惜她既感受不到冷热，也感受不到风。鹤遂由此低声问出"你感受不到风"，冉银拿着外套和薄毯从堂屋出来，阴阳怪气地补刀"没有触觉的人，哪里还感受得到风""连最基本的冷热都感受不到，该加衣服还是脱衣服都没办法分清"；周念则平静地说"其实还不够彻底""失去的只是身体触觉，还没让我失去心里触觉"。鹤遂走到轮椅前缓缓蹲下、仰着脸看她，眼圈的红在暗色天气里格外明显，说"念念，都是我不好，是我的错"，伸手想握她的手时被她蜷起手指缩了回去。她叫他"鹤先生"，说完全没必要把气氛搞得这么悲情、她既不怪他也不恨他、请不要再为难她，又说他这般装腔作势的纠缠就是一种为难、不知道他摆出这幅深情姿态是给谁看；冉银听得暗暗长舒一口气、表情变得得意痛快。他辩说"那不是我"，被她冷冷回"嗯，那是鬼"；冉银当场反问"当着所有人的面说不认识七斤的人不是你？说那些伤人话的不是你"，并替她披上外套、盖好毛毯。周念问他是不是回来看她死没死，说自己是影帝过去唯一的污点、没了他就可以真正清清白白；他说"不是的念念，我回来是——"却被她"总不该是为了我吧"一句截断。冉银煽风点火说就算他真为了她回来也没用，说她又瞎又五识尽丧，他狗屁用都没有、反倒看着惹人心烦；鹤遂听到"五识尽丧"后不敢相信地追问除了视觉和触觉，是否连味觉和嗅觉都没了，冉银便再添一把柴，说很快听觉也要彻底消失，让他趁人还没完全失聪把忏悔的话一次性说个够。此时霍闯推门进来，一眼看见蹲在轮椅前的男人便瞳孔地震，愣十几秒后回头把门关好，轻声确认"还真的是你，鹤遂哥哥"，并看见他单眼皮被血丝染红、睫毛湿浸、眼下淡青，像是好几宿没睡。霍闯当面指出，他若被人知道在这里，会给周念带来怎样的麻烦，并把他那句"不认识"造成的后果一件件摆出来——周念被他的极端粉丝网暴，家门口被泼红油漆，粉丝让她去死，还送了花圈和寿衣，寿衣上甚至写了周念的名字。鹤遂比谁都清楚自己给了她什么：他给她光、给她有且仅有的救赎，又给她暗、给她最极致的苦难，既是她的救世主也是她的灭世主。周念只是轻轻笑说"那些寿衣尺寸都不太对，对我来说，都太大了"。他被这句话刺痛，几次张口才找回颤抖的声音说"过去都是我不好，以后……以后我都不会离开你"，她随即反问"你口里的过去是什么过去"，并一件件数出来——是被三千万买断删掉的合照，是被扯断扔掉的智齿项链，还是那株被她扔在精神病院、估计早就枯死的万年青；最后她一字一顿地说"鹤先生，物消人散，我们之间没有过去"。这一刻他的内心进行着一场炙烤般的审判，而审判他的不是周念，是那个年少时对周念许下承诺的自己——是四年前说要带她一起逃亡的南水街疯狗，也是那个曾经满腔热忱的十七岁少年；他有着万死难辞的罪，无法得到她的宽恕，是他罪有应得。

**关键事件**：1. "你感受不到风"与伸手被自己拨开 2. "失去的只是身体触觉，还没让我失去心里触觉" 3. "鹤先生"三字与"装腔作势的纠缠就是为难" 4. 冉银披外套添柴、"五识尽丧"与"听觉也要彻底消失" 5. 霍闯进门认出他、点出他带来的所有麻烦 6. "寿衣尺寸都不太对，对我来说，都太大了" 7. "以后我都不会离开你"与"你口里的过去是什么过去" 8. "物消人散，我们之间没有过去"与他的自我审判

**逐章写法公式**：

- **情绪流向**：起：阴（晨间天色、睡衣与风） → 承：拒（缩回的手、"鹤先生""为难"） → 转：刺（霍闯点出寿衣与旧账） → 合：审（他自我审判，"我们之间没有过去"）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：阴天与睡衣的穿帮（用一句闲话点出他在场） + 头发与两只手的错位（把距离写进动作） + "你感受不到风"（让他第一次直面她的丧失） + "还没让我失去心里触觉"（把痛留在体内） + 蹲下与缩手（第一次求和失败） + "鹤先生"与"装腔作势"（用称谓和判词加倍否定） + "那是鬼"与冉银的追问（把否认顶回去） + "五识尽丧"（把伤情完整暴露给男主） + 霍闯进门与后果清算（引入最善良的证人来控诉） + "寿衣尺寸都不太对"（用一句轻话卸掉他的忏悔） + "你口里的过去是什么过去"与物证清点（把过去判为不存在） + 自我审判收章（收在人物的旧我）
- **本章核心技巧**：让男主在这一章第一次完整地看见自己造成的损伤——先是把他伸出的手挡回去，再让他从别人嘴里听到"五识尽丧""寿衣写上名字"这些事实，最后用她给"过去"列的三件物证把他所有辩解统一判废；全章的惩罚都不由女主执行，而是由他自己完成
- **卡点与伏笔**：结尾卡点：她说"我们之间没有过去"，他却已经在心里判定自己无法得到宽恕，两人之间的对立被他转身要做的事（给她治病）打破僵局；埋设/回收伏笔：那株被扔在精神病院"估计早就枯死"的万年青 → 与第62-64章万年青意象形成跨章回扣；"三千万买断删掉的合照" → 第68章删照片事件；"被扯断扔掉的智齿项链" → 第72章他反过来索要，矛盾点被再次点出；被红油漆、花圈、寿衣羞辱的旧事 → 第71章门口现场；霍闯追问"给周念姐姐带来怎样的麻烦" → 把鹤遂的隐退与入镇彻底锁死在暗处
- **时间线**：本章接第74章次日清晨，延续至当日上午

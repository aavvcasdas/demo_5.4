# 第89章 病症 摘要

**概要**：阳台上的光线被分成两段，一段照着周念、一段照着她对面的空白；盛夏上午已有明显的郁热，她旁边只放着一杯常温的苏打水——想喝冰的又怕胃受不了刺激。她盯着自己握杯子的手腕看，已经比入院时粗了一圈，现在的体重是65斤，她已经可以不用轮椅独立行走，只是还是容易累，心里想"原来爱真的可以令她长出血肉"。阳台门拉开后沈拂南抱怨"他还真是会给我捅娄子"——鹤遂把鹤广打了一顿倒是爽了，可视频曝光才几天他就掉了上百万的活粉，还连掉三个高奢代言；周念问他知不知道鹤广是个什么人就把人养着，他只说"我不关心""也不在意，我只要他安分，别影响我的发展"。周念由此想起那两具漂在河面上的浮尸，想起鹤广是强奸宋敏桃才有了鹤遂和宋平安、从母女俩失踪到火化都没露过面、还让年仅6岁的鹤遂去帮他买毒品，咬唇骂他"你真的很自私"，他勾唇笑着并不反驳，只承认自己足够自私且觉得自私的人才过得好。她听到"谁都比我好"时，沈拂南来了兴趣追问她见过了谁，还猜了一个名字"夏尔澈"，被她反问"夏尔澈是谁"后自行排除；隔着一层烟雾，她发现他和鹤遂抽烟的姿势都不同——鹤遂惯用食指和中指夹烟，他喜欢用大拇指和食指捏着。她终于说出"见到了老墨和一个哑巴"，沈拂南纠正说他们当中没有哑巴，"那个人格是一只蝴蝶"，这让她大为惊讶。他笑说她"有点儿可爱"，她一字一顿地回"你不明白，你也永远不会明白"——谁都不会明白她和鹤遂那段不为人知的曾经，不明白他为她捉过的萤火虫、让她吃下的那颗酸杏、戴上智齿项链时眼里涌出的光。她起身回客厅，听见沈拂南打电话叫对方"生爹"，说会尽快赶回去，心里明白他要带着鹤遂的身体离开；也就在这时，她想起在京佛的精神病院呕血晕倒时，掌握身体主权的分明是沈拂南，可失去意识之际叫她"念念"并抱住她的却是鹤遂——她的岌岌可危可以激发主人格出现。周念从餐厅搬来一根高脚凳放到阳台护栏前，一只脚踩上去、再两只脚都踩上，转过身对男人甜甜一笑"鹤遂。""你今天要么出来，要么就看我死。"高脚凳加上垫脚会让上半身完全处在护栏之外，她回头看33层的高度，地面上的人小得像蚂蚁，身后大片白色云朵好像一张白色的墓床；她说"如果再不出现，我会完成一个人的逃亡"，眼角渗出一滴泪。沈拂南先警告"你要死可以滚远一点死""他出不来，你别白瞎一条命"，随后抽烟看着她把后腰悬空、改由臀部抵着护栏，把头往后仰出栏外，最后又抬起一只脚在风中晃了晃。就在这一刻，一只大手猛地握住她的脚踝——她被拉进一个温暖宽实的怀里，上方落下男人杂乱无章的呼吸和发颤的低哑嗓音"周念，你是不是疯了？"她睁眼看见他因惊慌而滚动的喉结、失去血色的薄唇，和他那双深邃又深情、清冷又温柔的眼睛。她委屈地说"你真的挺狠心，非要等我快要死了，才舍得出来"，他一个字都讲不出，只把她的脸紧紧按在怀中、长指不停摩挲，冷汗顺着脸庞滴到她脸上。隔了很久他才平静些，快步把她抱回客厅、让她坐在他腿上，一只手臂紧紧锢住她。他说"我只以为我是死了""死在那天也挺好"，然后捧着她的脸让她与他对视："念念。如果我死在最爱你的时候，你是不是就能记我一辈子？"

**关键事件**：1. 65斤、脱离轮椅与"原来爱真的可以令她长出血肉" 2. 上百万活粉与三个高奢代言 3. 河面浮尸、鹤广之恶与"你真的很自私" 4. 夏尔澈这个名字与两种夹烟姿势 5. "那个人格是一只蝴蝶" 6. 萤火虫、酸杏与智齿项链的光 7. "生爹"的电话与京佛呕血时的记忆片段 8. 搬来高脚凳、跨上护栏与"要么出来，要么看我死" 9. 握住脚踝与"周念，你是不是疯了" 10. "如果我死在最爱你的时候，你是不是就能记我一辈子"

**逐章写法公式**：

- **情绪流向**：起：烦（阳台上的分界线与被养着的鹤广） → 承：刺（"你真的很自私"与夏尔澈、蝴蝶人格的闲聊） → 转：险（搬高脚凳、踩上护栏、"要么出来，要么看我死"） → 合：碎（被握住脚踝、抱回沙发，与"你是不是就能记我一辈子"）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：阳台光线的两段与被分开的两个人（用一个空间意象写两人同处一室却隔着一半空白） + 手腕、65斤与不用轮椅（用身体数据交代康复） + 沈拂南清点掉粉与代言（让反派自报损失） + "你知道鹤广是个什么人么"与回忆三件事（把旧恶一次性摆齐） + "你真的很自私"（用最平的指控代替怒骂） + "谁都比我好"与夏尔澈的名字（在闲聊里填人格名单） + 两种夹烟姿势（用习惯区分同脸两人） + 老墨、哑巴与蝴蝶（把第87章的谜底认领） + "我有点儿明白鹤遂为什么会喜欢你了"与"你不明白"（用一次错位的示好换来女主最重的一句否定） + 萤火虫、酸杏与项链的光（用三件小物交代私密往事） + "生爹"的电话与要赶回去（把离开的压力加上时限） + 京佛呕血的记忆片段（用一条旧线索证明主人格可为她的危险而动） + 搬来高脚凳与踩上去（把想法落成一个具体道具） + 一步步加注的危险动作（用五级动作推进悬念） + "要么出来，要么就看我死"（用通牒把赌局说清） + 蚂蚁与白墓床（用她自己的换算写决绝） + "他出不来，你别白瞎一条命"（让反派保持冷感，反衬赌注的真实） + 握住脚踝与那句"你是不是疯了"（用触觉完成救援并确认身份） + 抱回沙发与"如果我死在最爱你的时候"（用一句疑问式告白收章）
- **本章核心技巧**：把一场"逼人格出来"的戏写成可量化的加注过程——从放一杯水的阳台闲聊，到搬来一根高脚凳，再到五级递进的身体前倾，读者的紧张感靠动作的升级而非台词的分贝；同时把上一章留下的"哑巴"谜底（蝴蝶）与下一章的悬念（"生爹"要接他回去）都塞进同一段看似闲散的对话里
- **卡点与伏笔**：结尾卡点：他问"如果我死在最爱你的时候，你是不是就能记我一辈子"——她把答案留在了下一章；埋设/回收伏笔：蝴蝶人格 → 第87章落地窗前挥手臂的动作在本章被认领，为后续人格逐一现身铺路；夏尔澈的名字 → 被提起但未被见到，成为下一个人格的预告；"生爹"生东返的电话与"尽快赶回去" → 鹤遂的身体要被带离东济，成为后续冲突的引信；京佛呕血时主人格出现的记忆片段 → 确立"她的危险能激发鹤遂"这条可复用的机制；萤火虫、酸杏与智齿项链 → 两人私密往事的清单，其中项链已被扔进南水河；沈拂南掉的上百万活粉与三个代言 → 与解渤腾曝光的视频直接相连；"鹤广强.奸宋敏桃才有的鹤遂和宋平安"与"让年仅6岁的鹤遂去帮他买毒.品" → 补足鹤遂的童年创伤，与韩老所说的病因源头对接
- **时间线**：本章为第88章当日之后的盛夏上午至午后

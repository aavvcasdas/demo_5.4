# 第116章 病症 摘要

**概要**：一直到深夜，围在周念家门口的人潮才渐渐散去，只剩几个有职业精神的狗仔带着设备蹲在门口抽烟聊天、时不时瞄一眼紧闭的周家大门。卧室里周念正用电脑填写联展资料，听见楼道里鹤遂和郁成的谈话——郁成说遂哥你也不是第二次这样了、说不过去吧，他只平静地答"我也知道"，又说"只是她才是对我最重要的事情"；郁成长叹着数落：一会儿爱得要死一会儿又毫不在意，现在直接公开了还要怎样，接下来的杂志、代言、一支刚接的汽车广告、等着进组的电影都不管了，光是想到天价违约金就两眼一黑。鹤遂静静听完，忽然把话题带向旁处，问如果自己根本不是你一开始接触到的那个人、比如"换个灵魂"，你怎么想；郁成被逼得抓狂，直说我才不管你是谁、你发生了什么变化，我只需要你配合工作、走该走的行程，不然我和整个工作室都非常抓狂，"打工人很惨的好不好"。这时他裤袋里的手机响了，来电显示是娇娇，郁成扫一眼提醒他最好还是接，说大小姐估计正火冒三丈，别忘了她已经为他推迟过一次订婚日期、他这次回去可是答应过会准时出席订婚宴——他完全没有这方面的记忆，看来是沈拂南答应的。正当他要随手挂断，身后传来周念温软的一句"接吧"，他回头问你希望我接，得到肯定后仍说"接了说什么？我都不认识她"，接一个陌生人的电话再佯装熟悉，感觉非常怪异；周念想到当初被冷漠对待的自己是那么伤心，同为女生，如果一直喜欢的哥哥没能参加自己的订婚宴，一定会特别失落遗憾，便说她也只是想你参加一下订婚宴、你真不愿意也不勉强。他掂了掂手机慢悠悠地说对自己倒无所谓，主要是得考虑分寸感——"毕竟我是有女朋友的人"；她说我又不介意，你接啊。电话一接通，那边传来生雅娇不满的骄矜声：三天后是我订婚的日子，请问你什么时候打算回京佛？又追问"见色忘妹是吗"；周念用嘴型示意你就说你去，他便简洁地答"能来"。听筒里静了两秒，生雅娇接着问你还记得你问我的那个问题吗——那天他在阳台问她，要是有一天你变成另外一个人，我还会喜欢你吗；她说自己认真想了一下，只要我需要你的时候、比如配合我拍照发朋友圈、参加我的订婚宴，只要你能做到这些，那我就会一直喜欢阿遂哥哥。走廊很寂静，所有的话都落进周念耳中，她平静得脸上没什么表情——她看明白了，生雅娇不在乎鹤遂到底是谁，只是需要一个愿意抽点时间让她获得优越感的大明星哥哥。他应付两句挂断，周念主动说"我先和他聊聊吧"，郁成递给她一个求助的眼神，明显想让她劝劝鹤遂，随后愁着脸回旅馆。进屋后他注意到电脑界面，她说之前申请参加全国画家联展、刚收到邮件说通过了，让他填资料；他问什么时候、办在哪儿，她说八月底、具体时间还没定，办在京佛，他说"行，到时候我去看"，她诧异地问你来看，又嘟囔说他来的话会引起骚动，他懒散地说"当明星有什么好的，连去看看女朋友的画作都得瞻前顾后"。填好资料提交后，她认真地说也想和他聊聊这个问题：现在的他真的很好，站在高处被那么多人喜欢、个人价值被无限放大，宋阿姨看见现在的他也一定很高兴；提到宋敏桃，他的眼神暗淡几分。她接着说他本来就应该成为很耀眼的人，我们都不能选择原生家庭，也很少有人能有机会挣脱原生家庭的禁锢逃出来，而他有这个机会就要抓住、绝对不能再走回头路，并把尼采那句"他愈求升到高处和光明处，他的根愈要向下，向泥土，向黑暗，向罪恶"告诉他，说所以在经历过那么多苦难以后，他就是该往高处爬、往光明的地方去。他沉眸低低地说"我哪里都不想去，只想待在你身边"，被她犀利评价"你真的很恋爱脑"——放着大明星不当要和她窝在小镇腻腻歪歪，她绝对不允许；他被逗乐，问那我就想和你待在一起怎么办，她说不行、我吃不消。他转守为攻问她一点都不介意吗，举例子说"比如我会拍吻戏"，她神经一紧，想起他迄今还没拍过吻戏，纠结半晌不情不愿地嘟囔"那真的工作需要的话……那我就不看"；他冷嗤一声"你还挺大方"，她低头扣着手指说如果是因为自己限制他拍戏，感觉这种做法很不理智。他不再说话，她凑过去卖乖问不高兴啦、真生气啦，索性走过去大胆地跨坐在他腿上搂住他的脖子；没等她开口，他先说"你这样搞我，等下起来了你就负责弄下去"，她震惊反问，他挑眉说坐我身上还不算搞我，拉着她的手以引诱之姿往下带，她摸到烫手山芋想缩手却被紧紧按住，微别开眼说我们能不能先说正事，他声音哑了几度说"说完，我就要忙我的正事了"。她抓紧说出正事：我陪你去做人格整合，然后你还是回京佛去，该进组就进组、该跑行程就跑行程，而且再过两个月她休学也要结束、也要回去读书了，"我们都要变成更好的人"。他搂着她轻松转个圈把她放倒在柔软被面上，垂眼特别温柔地亲了亲她的眼角说"念念，只有你会因为我是我而爱我"；她没听懂，他解释生雅娇需要一个能让她随时炫耀的明星哥哥、满足那点小女生的虚荣感，郁成乃至那些人需要的是一个配合的影帝、只要能按要求拍戏跑行程的漂亮皮囊，而你不一样，你只会因为我是我而爱我，换成其他任何一个人都不行。她吸吸鼻子让他抬手，坐起来握住他腕骨精致的手腕、让他掌心朝上，一笔一划地在他的掌心里写字：写一个他念一个——"周……""念……"，一共写了七个字，组合起来就是：周念只喜欢鹤遂。

**逐章写法公式**：

- **情绪流向**：起：紧张（围堵未散与郁成的行程焦虑） → 承：轻松（打工人崩溃与接不接电话的拉扯） → 转：压抑转甜（生雅娇的有条件喜欢与她的平静看穿） → 合：甜中带热血（劝他往高处走、掌心里写下的七个字）
- **节奏配比**：慢铺垫 25% / 快冲突 10% / 爽点爆发 15% / 悬念留白 50%
- **本章结构公式**：外部压力（狗仔与违约金） + 一个陌生来电（把另一人格的旧债端上台面） + 两段对话（先谈她的事业与他的前程，再谈吻戏的分寸） + 掌心写字（把全章的爱意收进一个触觉动作）
- **本章核心技巧**：用"配角的有条件"反衬"主角的无条件"——生雅娇需要炫耀的哥哥、郁成需要配合的影帝，两种需求被并排放进同一章，最后一句"你只会因为我是我而爱我"因此不需要任何修饰。
- **卡点与伏笔**：结尾卡点：她已答应陪他去做人格整合、他回京佛进组，而"人格整合"的结果与沈拂南的去留尚未展开，下章期待是整合如何开始；埋设/回收伏笔：生雅娇推迟过一次的订婚宴（三天后，京佛）→ 待回收；沈拂南答应出席订婚宴（旧债）；全国画家联展八月底在京佛（新目标）；她的休学两个月后结束、要回去读书；宋敏桃（提到时他眼神暗淡，与"来不及"的遗憾）；"当明星有什么好的" ↔ 他从高处回归的取舍。

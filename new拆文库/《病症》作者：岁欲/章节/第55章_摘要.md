# 第55章 病症 摘要

**概要**：那年N省参加美术联考的考生有五万多人，周念以292分直逼满分的高分拿下联考第一名，三个月后又在京佛美院的校考中获得第一名的消息传来，越来越多人注意到这个来自小镇的女生；小镇上的人开始对她改观、重新喜欢起她来，和她现在的成绩相比之前的"污点"都变得不足挂齿，加上看她最近没再和那条疯狗来往，人们又纷纷让自家孩子跟她多学习。周念最近和鹤遂见面的时间屈指可数、交流大多在微信上——他在市里打工攒钱，觉得在小镇做事没几个钱，而且名声臭到极点、镇上愿意请他做事的几乎没有。高考前一天两人打视频电话，他脸上的倦容越来越重、眼皮底下永远有一层淡淡的青影，她说"你看上去真的很累"，他穿着工厂里普通的深蓝色厂服答"我没事""你明天好好考试"；桌上摆着他送的那株万年青，她每晚睡觉都要看看它才肯上床，摸着叶子说"我会好好考的"，他只回一个"乖"。她问他睡不睡下铺，得知厂里宿舍是一米二的上下床、他身材高大坐着都要微微驼背才不会顶到上铺床板；她想让他多休息说要挂电话，他却在镜头里笑着问"周七斤，不说晚安就想挂电话？"，她慢吞吞说了晚安。刚挂掉电话她就收到他发来的一张视频通话截图，截图里的她刚好是睁眼又没睁开、特别像在翻白眼，他发消息问"你看看你好不好笑？"；她生不起气来，因为在那张截图上发现他把她在的窗口放大，而他的目光始终看着她。她想到三天后两人就要走了，问"厌厌怎么办？就没有人喂它了"，他回"我已经处理好了"，并发来语音说让霍闯那个小屁孩有空就去喂一下、他会定期转猫粮钱给他，周念觉得心里暖暖的，认定他永远都这么靠谱。第二天高考，打了一周降雨弹的缘故雨下得特别大，镇高中外挤满水泄不通的家长、脚跟碰脚跟、伞檐撞伞檐，冉银也在其中，周念却始终没有回头看一眼；快要踏进校门时，口袋里的小灵通响了起来，是鹤遂——她记得他此时应该在上早班。人声鼎沸里，听筒里传来他简短的两个字"回头"，她回头看见在这潮湿的大雨天里，他没撑伞、只穿着一件黑色冲锋衣站在人流正中心，帽子戴在头上，眼睛和颧骨没入帽沿，下半张露在外面的脸因下颌线和精致鼻唇而太过惹人注目；他缓缓将头抬起，一双黑白分明的眸子浮现，隔着人群遥遥相望，缓缓张开薄唇说"念念，祝你高考顺利"，每一个字她都通过听筒听得真真切切，泪水模糊了她的双眼，她哽咽着重重点了点头。那天的鹤遂的确是早班，他请了三个小时的假，只为亲自给她说一声高考加油；看着周念进考场后他便快速离开人群、以最快的速度去车站坐车赶回厂里，超时会被扣钱。到市里后他摘下帽子在人行道上疾走，殊不知有人的目光一直落在他身上——一辆黑色路虎的副驾上坐着个四十五岁左右、穿黑色POLO衫、戴劳力士的男人，他看到鹤遂第一眼就招呼司机"慢点"，指着少年问"像不像我上次给你看的那幅画上的人"，司机想起来那是剧组要了授权要用在电影里的那副叫《病症》的油画，说那少年侧脸简直一模一样；被叫生导的人让司机停车，自己下车走上人行道，带着笑意等着少年一步一步走到他面前。6月8号高考结束，当天凌晨一点周念还睁着眼没睡、在等鹤遂的消息，直到枕头底下的手机震动，他说在她家门口；她连衣服都没换，穿着一条睡裙趿上拖鞋、用最轻的力气拧动门把，蹑手蹑脚地下楼出门，发现他手里拿着两张淡红色的火车票。借着月光能看清票上的黑色字体：云宜→京佛，2013年06月9日23点15分开，13车003号下铺，票价358元，限乘当日当次车，两张硬卧位置挨在一起。他要她好好记着每一句话，交代路线：明天下午吃完饭后找机会溜出来，到镇上车站坐车到县城，到县城车站后买一张到火车南站的票——"记住是南站，南站"，然后在南站等他到了以后一起检票。她问为什么不和他一起去火车站、自己一个人坐车有点害怕，他说"我还有一点事""放心，在检票前我肯定到"。他离开时她不知哪里涌上来一股冲动，快步跑过去从背后一把重重抱住他、双手紧紧勒着他的腰、把脸靠在他背上，说"就想抱抱你""你明天就可以看我写给你的那封信了"，他温温笑着答"好"。逃亡那天她早把东西收拾进一个登山包，对这个家没有任何留恋、没带走任何一样属于这个家的东西，只带了最基本的衣服（包括他的那件黑色卫衣）和画满他的素描本；最后回头看了一眼生活了十七年的房间，抱着怀里的万年青没有犹豫地合上房门离开，走出北清巷时在心里默默说再见——再见北清巷，再见花楹镇。一切都按计划进行，她从小镇坐车到县城车站，买了张到火车南站的汽车票、坐二十分钟就能到，心情亢奋得连车窗上没擦干净的灰痕都觉得可爱，并在车上发微信"我马上到火车站啦"，他回得很快"嗯，等我"。她九点不到就到火车站，没进候车厅、背着硕大的登山包抱着万年青在外面等，想让他一来就能看见她；站累了就坐在候车厅外台阶最边上的位置，粉红花盆的万年青摆在旁边陪她一起等，半小时、一小时过去，暮色降临，她不停捏自己的手指，看着一个个乘客走进候车厅、眼里露出焦急。闷雷炸开，所有人的脚步都变快，只有她还坐在原地；又等了半个多小时到十点半、再过十五分钟就要检票，她发微信"要到了吗？一会儿要开始检票了"，风越吹越烈，她拉开登山包拉链拿了件他的黑色卫衣出来穿上——身体暖和了，心里的温度却开始流失。候车厅广播播报k8939次列车开始检票时，她的右眼皮跳了两下，拨通电话却一直处在连线中无人接听，又接连打了两个还是没人接；她把包放在地上站起来在台阶上来回走，把两张火车票翻出来拿在手里，走下台阶停在空旷的小广场中间左右张望，等一道熟悉的身影。时间来到十一点整，还剩最后十五分钟，四周空荡荡的没有一个人，藏在他黑色卫衣袖口里的手指已经紧紧握紧；她再拨通电话，听筒里传来冷漠的机械女音"您拨打的电话已关机"，她这才真的慌了——这可是他要带她逃走的重要日子。不论她怎么打，手机一直都是关机，她捏着两张火车票在风里等了又等，最终候车厅的播报给她判了死刑："由云宜站发往京佛站的k8939次列车现已停止检票"。她散着头发失魂落魄地回到台阶上坐下，心里还残留一丝希望——他会来的，等他来了还可以重新买票，鹤遂怎么会骗她、怎么舍得骗她。雨落了下来，狂风卷着雨线咆哮；一个撑伞路过的青年男子边跑边看手里的一页纸、骂了句"哪个傻逼写信用英语纸，这写的什么玩意"就随手把纸揉成团丢在雨地里；周念的视线被那团纸吸引、看着实在熟悉，突然意识到什么便冲进雨里捡起纸团，回到台阶处颤抖着手小心翼翼地展开——四线三格上的字迹熟悉得令人心惊，出自她的笔下："我想要逃离，逃离这座小镇，逃离现有的全部认知，想到远方成为另一个我。独独不逃离我的所爱。鹤遂，与你之间，我们的距离恒定。"寥寥数行写尽一个少女最深沉的心事和最热烈的爱意；她的手抖得停不下来，眼泪落到被雨水浸湿的纸上，让本就模糊的字迹更模糊——他丢掉了她给他的信，他不会来了。已经知道结果的周念在火车站外的台阶上等了一整个通宵，看了整夜的雨、吹了不知多少阵风，自始至终怀里都抱着那颗他送的万年青。凌晨五点半暴雨依旧如注，她站起来活动发麻的双脚却感觉一阵头晕目眩，身子晃了晃后失去控制一头栽倒在台阶上、滚落在积水颇深的地面；她像一条缺氧的鱼张着嘴巴呼吸，冰冷的雨水一个劲砸进她的嘴里和眼睛里，噼里啪啦的雨声里她出现了幻听，泡在水里的她听见他的声音——"念念，我会带你逃出这个小镇""念念，我们万年长青"。

**关键事件**：1. 联考292分第一与京佛美院校考第一、镇上人的改观 2. 高考前的视频电话、厌厌的托付与视频截图 3. 高考当天鹤遂请假三小时冒雨送考"回头看" 4. 路虎上的生导认出《病症》画中人 5. 凌晨门口的火车票与出逃路线 6. 逃亡日独自候车、十一点电话关机、列车停止检票 7. 雨中捡回的亲笔信与等了一整个通宵 8. 凌晨五点半栽倒、幻听与上卷终

**逐章写法公式**：

- **情绪流向**：起：扬（联考第一、校考第一、镇子改观） → 承：暖（高考前的晚安、喂猫的托付、雨中"回头"） → 转：暗（生导的注视、火车票、独自候车） → 合：碎（关机、停止检票、雨中的信、通宵、幻听）
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：成绩与舆论反转（用硬数字完成平反） + 视频电话与喂猫托付（写日常的可靠） + 高考雨中送考与"回头"（把承诺提前兑现一次） + 生导认出画中人（埋下新的外部势力） + 凌晨的火车票与路线交代（把出逃写成可执行清单） + 离家与行李（用不带走的家写决裂） + 独自候车与倒计时（用时间刻度拉长焦灼） + 关机与停止检票（让计划彻底落空） + 雨中捡回的信（用物证替代理由） + 通宵与栽倒、幻听（以肉身崩坏和承诺回声收卷）
- **本章核心技巧**：全章是"希望"与"时间"的赛跑——从联考第一到车票信息，作者不断加码可验证的细节，把读者的期待值推到最高点；再在最后一小时里用关机、停止检票、丢掉的信三记连击把希望清零，且始终不给男主一句解释，留下整卷最大的悬念交给下卷
- **卡点与伏笔**：结尾卡点："上卷完"——男主失约的原因完全未交代，女主昏倒在暴雨里，下卷的开门问题即"他为什么不出现"；埋设/回收伏笔：《病症》油画的画中少年被生导认出 → 第42章电影授权在此接上，指向后续外部势力；火车票的票面信息（云宜→京佛、13车003号下铺、358元、6月9日23点15分）→ 可核对的失约证据；被英语纸写下却丢在雨地里的信 → 与第53章"压在玻璃桌面下的信"形成最刺的对撞；万年青 → 关系命名物，成为她唯一抱着的东西；"我让霍闯那个小屁孩喂猫" → 新角色霍闯；厌厌（猫）→ 离开后的小牵挂；黑色卫衣 → 他留下的衣物被她当作外套；冉银在考场外与"没有再和那条疯狗来往"的传言 → 母亲视角的误判；鹤遂在市里打工、名声臭到极点 → 他被卷入事件的处境背景
- **卷末附注**：本章末标注"——上卷完——"

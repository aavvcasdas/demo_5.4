# 第76章 病症 摘要

**概要**：阴色云层越压越低，风吹得几人频频眯眼，霍闯说"好像要下雨了"，周念便让他推自己回房间。霍闯推着轮椅后退几步、转了个弯往堂屋推去，同时劝鹤遂离开，说"周念姐姐她不想看见你"，冉银也跟一句"你在七斤跟前，只会让她情况更糟"。上楼时霍闯问她为什么一点反应都没有，她只反问"我应该有什么反应"，并听他说出自己从四年前就开始四处打听鹤遂的去向、这次去京佛治病也是为了找他；周念沉默不语，被抱到床上后把被子拉过胸口，反问他"你会对一棵树或者一座石桥有什么特别情绪吗"，再告诉他"现在他对我来说，就只是一棵树，一座石桥，或者别的随便什么东西，我不会有什么特别情绪，因为他一点都不重要"。门外的鹤遂脚步戛然而止，手僵停在距门把手三厘米的位置，感受到一种深深的无能为力。屋里的谈话继续，霍闯说他刚刚看见他很为难过的样子、都哭了，又说他记得当初的鹤遂哥哥是那么骄傲冰冷的一个人，没想到还有这么情绪外露的时候——她真的一点都不在意他了。旧日景象在他脑中重现：周念笑得梨涡浅浅、朝他手里塞了一颗带蒂巴的橘子；他躺在血泊里奄奄一息时，是周念在他耳边颤声求他别死；她说他是一件易碎品，她会挡在他面前不让肖护父亲伤害他；她会和他一起擦家门上的油漆，会不顾旁人目光勇敢地走在他身边——而他却毁了她。冉银端着煮得软烂的红枣燕麦到门口，他伸手要碗，在冉银说"你拿给她，她更不会吃"之后仍坚持地把碗端进房间。他舀了一勺、吹凉送到她嘴边说"念念，张嘴"，她毫无反应；瓷勺里的粥一点点冷掉，他换一勺热的再来一次，她干脆把脸转到另一边，这一转让他看见了胸口一根根清晰的骨头——她浑身上下只剩薄薄皮肤和骨头，瘦得完全没有人的样，那些骨头仿佛化成带倒刺的重鞭抽断了他的脊骨和双膝，让他噗地跪在地上。他拿着瓷勺的手在抖，说"念念，你张张嘴，好不好"，她只吐出一个字"滚"；他说"只要你肯吃，我就滚"，她问"我吃你就滚是吗"，他抿唇不答，因为他很清楚自己在撒谎。她突然坐起来、碰掉瓷勺，伸手去探碗的位置，指尖触到他微凉的长指后又迅速挪开，随后端起碗不管粥还烫、仰头就往下灌；他失声喊"周念"想夺碗，被她用两只手死死捧住，不咀嚼、不品尝，只让食物进到胃里。粥喝完碗已空，他颓然说"念念，你不要再伤害自己了，算我求你行不行"，她只问"我已经喝完了""所以你可以滚了吗"；他说"你知道我不会走的"，她笑说"可以""那我走"，利落地掀被下床却因虚弱站不稳，被他一把抱住。她尖叫"你别碰我"，两手胡乱推搡挥打，挠得他脖子上全是指甲的红痕，仍被他一把打横抱起放回床上；她后背刚沾床就用脚踹他、踹中他的小腹，他倒吸一口冷气、捂着右小腹单膝跪在床边。霍闯上前查看，看见他指缝间隐隐的鲜血，惊问他是不是受伤、要不要去医院；周念听见后只说"别死在我这里，我可承担不起一个当红影帝的死"，他居然还笑得出来，说"放心，暂时还死不了，就算要死，也要等你好起来后再死"。刚咽下去的燕麦粥随即在她胃里造反，她当着鹤遂的面把东西全部吐了出来；他回头看冉银，质问"她这样一吃就吐，你为什么不带她去医院"，得知"她不肯去"后问"那就眼睁睁看着她去死"，被冉银一句"可别忘了，让她变成这样的人是你"堵得哑口无言。这时楼下传来急促的敲门声，冉银下楼去开门，木楼梯很快响起吱吱呀呀的脚步声，郁成出现在门口，看见床上的周念、穿校服的霍闯和单膝跪在床边捂着腹部的鹤遂后愣住，终于忍不住嚷起来"我的遂哥啊，你这刀伤还没好就跑啊"——"刀伤"两个字让周念神色一凝。

**关键事件**：1. "他对我只是一棵树、一座石桥"与门外僵停的手 2. 旧日四幕重现与"他毁了她" 3. 红枣燕麦、"念念张张嘴"与跪地的膝盖 4. "只要你肯吃，我就滚"与仰头灌粥 5. 踹中右小腹、指缝见血与"别死在我这里" 6. 当着面吐掉整碗粥与"让她变成这样的人是你" 7. 郁成冲进门嚷出"刀伤" 8. "刀伤"两个字被周念听见

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 把一个人物化成景物 | 霍闯问她为什么没有反应，她反问"你会对一棵树或者一座石桥有什么特别情绪吗"，再答"现在他对我来说，就只是一棵树，一座石桥" | 具象贬抑 | 心疼 | 用比喻把关系降级成景物，比反复说"我不在意了"更彻底 |
| 门外的三厘米 | 她在门内说完那句话，门外"男人的脚步戛然而止。已经准备开门的手僵停在距门把手三厘米的位置" | 精确距离 | 心疼 | 用可量化的距离写被拒于门外的处境，读者能直接看见那个停顿 |

**逐章写法公式**：

- **情绪流向**：起：闷（将雨的云、推回房间） → 承：冷（"一棵树、一座石桥"、门外三厘米） → 转：崩（喂粥、下跪、"滚"、灌粥、踹中伤口） → 合：惊（吐光、"让她变成这样的人是你"、"刀伤"两个字）
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：将雨的云与推回房间（把场景收窄） + 霍闯与冉银劝他离开（用旁人的判断给关系定性） + "一棵树、一座石桥"（用比喻把关系判废） + 门外三厘米的手（用一个停顿写被拒绝） + 旧日四幕与"他毁了她"（用快剪建立罪感） + 端粥进屋与喂食失败（把求和落在最具体的一件小事上） + 看见胸口的骨头与下跪（用身体实况击穿他） + "只要你肯吃我就滚"与灌粥（把交易推向荒谬） + 踹中伤口、指缝见血（让身体代偿情绪） + 当面吐光与"让她变成这样的人是你"（把责任钉死） + 郁成的"刀伤"（用一句失言翻出新线）
- **本章核心技巧**：把"求和"写成一件极小的事——喂一口粥；他在这件小事上不断升级姿态（低求、蹲喂、下跪、撒谎承诺），她则用同一个字和一次呕吐把它全部作废；末尾让最不设防的配角说漏嘴，把视线从"感情"引向"他身上那把未愈的刀"
- **卡点与伏笔**：结尾卡点：郁成口中的"刀伤"与他在奥斯卡失踪、又带着未愈的伤现身直接挂钩，伤从何来完全悬置；埋设/回收伏笔：腰腹的刀伤 → 第77章在杜比剧院洗手间被匕首刺中、镜子上的血字"放我回去"；"只要你肯吃我就滚"的谎言 → 与他一贯的"妄语式让步"呼应；"让她变成这样的人是你" → 冉银第一次把责任摆明；红枣燕麦与糯米以外的忌口 → 第80章细节互相印证；门外的三厘米 → 与第75章"物消人散"形成连续的拒绝链
- **时间线**：本章接第75章当日上午，延续至当日上午稍后

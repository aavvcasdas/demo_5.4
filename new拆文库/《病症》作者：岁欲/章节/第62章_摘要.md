# 第62章 病症 摘要

**概要**：周念最初并没有意识到自己吐出来的是血，只以为吐出来的是刚吃下去没多久的药，直到她看见鹤遂脸上的血迹——其中几滴悬坠在他的睫毛上、眼角处，其余的正顺着他的鼻梁和脸庞滑落。她的喉管里起了一场大火，一路烧得五脏六腑火辣辣、尤其是胃，她痛得扭曲面容、狼狈地瑟缩着肩膀、额头冒出大片冷汗；冉银担忧地尖叫"七斤"，郁成被这一幕吓到说"我的妈呀"，而身处病房的人中只有鹤遂保持着绝对的镇定和平静，他面无表情地看着眼前奄奄一息的周念，脸上温热未散、鼻息间被腥浓血味充斥。周念看见他缓缓眨了一下眼——眨眼的速度在0.2—0.4秒之间，他却用足足两秒眨了那一下眼；等他重新睁眼时，她看见他的瞳孔在急遽地涨缩、颤动、缓缓张开，脸上居然出现了震惊和错愕的表情，仿佛和两秒前冷漠又平静的他完全不是一个人，区别明显得像是一枚硬币的正反面。她没来得及看清那是不是错觉，就被一阵强烈的眩晕感席卷，视线模糊、身体不受控制地发软，整个人像一座年久失修的楼宇般开始坍塌下坠；意识的余光里倏地出现一双冷白色的大手，下一秒她被牢牢接在一个温热的怀里。周念再次感觉堕进梦里，她在梦里看见十七岁的鹤遂、那时候的鹤遂会一次又一次接住下坠的她；她疲倦地闭上眼睛，闻见雪松的清冷男香，上方沉沉落下模糊的一声"念念？"，随后只觉得身体一轻、好像被人抱了起来，在彻底陷入昏迷前还听见了他焦急的嗓音"医生，医生——！"。给鹤遂上小提琴课的老师准点到了，只是学生还没到，郁成不好意思地道歉解释，说出了点突发状况、鹤遂弄脏了衣服正在病房的卫生间里洗澡。卫生间里洗完澡的鹤遂站在镜子前，卷起右边袖子把手腕和小臂露出来——只见腕骨到小臂处有一道五厘米长的伤口，沾了水的伤口被泡成一种触目的样子，皮肉外翻、猩红可见；他垂眸盯着伤口看了很久，而后缓缓抬头看向镜子中的自己，神色冷淡、眼神无比阴郁，看了两秒唇角扯出一抹嘲讽至极的冷笑；他收回视线，拿起一旁的纱布重新把伤口缠上、缠得格外仔细，再把先前拆下来的带血纱布随手扔进垃圾桶。出去时他发现有郁成等在卫生间门口、正一脸担忧地看着他；郁成说他刚刚很反常——看着他抱着14床那女的冲出病房时都惊呆了，可把她交给医生后又马上没事了；鹤遂看向14床、上面是空的，他抿了抿薄唇没有接话；郁成忍着没忍住，问他是不是之前真和那女的有点啥、真对不起人家了，他眸光一凝、情绪不明地反问"你觉得呢"，郁成立马闭嘴；随后他问老师在哪儿，得知被安排在一间没人用的理疗室等着，便让郁成带他过去。周念被推出急救室时已是两小时后，医生给她做了内镜止血，她本身就贫血严重、加上呕血量大，还额外输了一袋血。上完课拎着小提琴回病房时周念还在昏睡，他没看她，倒是看见周念母亲站在他的病床前等他；冉银一副兴师问罪的姿态双手抱在身前，等他一走近就说"你把我女儿气得吐了血，就没个说法吗"，鹤遂把小提琴靠墙放下、琴弓还拿在骨节分明的大手里，连看都没看她一眼，懒声问"你想要什么说法"；冉银冷声道他这人可真是奇怪，一边说着不认识她女儿、一边见她女儿吐血又火急火燎，问到底想做什么，他没理、自顾弯腰拿过琴盒，听她说"你想就这样算了是不可能的"也只拿了块鹿茸布慢条斯理地擦琴弓、眼皮都没抬地问"那你想怎么样"。冉银顿都没顿一下说"你得赔钱"，还笑着补了一句毕竟今时不同往日、他也不是从前那个三天两头家门口都遭泼油漆的臭小子，现在最不缺的应该也是钱。病房里另外两个患者裴巷和徐散都被这番刺人的话吸引看了过来，就连周念也在这时醒了，她还没睁眼就听见鹤遂的声音："我是有钱，但我不是有病，你想讹人的话还真是找错了对象，如果你非要就你女儿呕血一事赖上我，那我现在就可以通知我的律师过来，您觉得呢？"——最后一问更是赤直无比的挑衅，冉银登时被气得脸上煞白，骂他"少给我装出人五人六的样子""瘾君子的烂种也配摆谱，薄情寡义狼心狗肺的玩意，可真活该你当年死亲妈！"；空气的流动随着话音落下而静止，病房里一点声音都没有，几人的呼吸声都似乎被同时扼住。周念昏沉的脑子被激得清醒几分，哑声开口"你怎么能这样说鹤遂"；就在她都觉得他马上就要发作时，他却极轻地笑了一下、满面的不在乎，仿佛在听旁人的事"嗯，骂完了？"，冉银像一拳砸在吸水海绵上、气焰瞬消，僵持中病房里只有鹿茸布擦拭琴身的细微摩挲声。周念把目光投向他，他却专注地擦着小提琴、擦完琴又擦琴弓，反正不肯看她一眼，这让她陷入混乱——她分明记得呕血时是鹤遂一把抱住了她、还叫了她念念，难道都是错觉？真要不是错觉，那他为什么连看她一眼都不肯。冉银来到床边关切地问她好点没，她只扭头说"你回酒店吧"，又答"我不需要你看着"，随后把被子拉过头顶把自己藏了起来、拒绝一切沟通，直到听见冉银离开病房的动静才从被子里出来；对床很少主动和人说话的徐散主动搭话"看不出来，你对你妈妈还挺强势的"，周念还是第一次听人说她对冉银强势，一时竟不知道该哭还是该笑。冉银那番话勾起了她的回忆，她想到宋敏桃——时间过去太久，脑海里关于宋敏桃的长相已经模糊，她却清晰记得那天鹤遂捧着两个骨灰盒的无助和绝望；怕他会被冉银的话刺痛，她轻轻叫他"鹤遂"并说"你别往心里去"，没想到他的回答格外云淡风轻"我没有往心里去，因为我根本不在意"。她当场怔住，苦笑着说"没想到你都不在意了""每年清明我都会去给宋阿姨还有你妹妹扫墓，从来都没见你回来过，原来是你不在意了"；鹤遂没有再理她，拿出电影剧本靠在床头开始看，她也识趣地没有再问——他连宋敏桃的死都已经不在意，那还会在意什么？既然如此，那在她昏迷前所感觉到的种种也不过是错觉而已，他没有变化，还是那个高高在上的鹤遂。当天夜里后半夜开始打雷，在轰隆隆的雷声里，刚刚勉强睡着的周念听见一声刺耳的炸裂声、像某种东西碎掉的声音，她惊醒过来；又是一声轰隆雷鸣，她恐慌地坐起，下意识扭头看向旁边的13床——上面是空的，鹤遂不在床上；她再看向卫生间，门留着缝、泻出一道光亮，刚刚的炸碎声就是从里面传出来的。周念掀开被子下床、趿上拖鞋，轻手轻脚地朝卫生间走去；窗外电闪雷鸣、病房里诡谲四起，昏黑的环境里消毒水味弥漫，只有卫生间里亮着灯。她来到门口侧着头、小心翼翼地透过门缝往里面望，看见了里面的景象——站在盥洗台前的鹤遂，满地的镜子碎片，还有他正在流血的指骨；正当周念在想他为什么要打碎镜子时，鹤遂突然转头看向她。

**关键事件**：1. 呕血现场与鹤遂那双用了两秒才眨完的眼睛 2. 昏迷前的接住、"念念？"与"医生——！" 3. 手腕五厘米的伤口与镜前那抹冷笑 4. 郁成的追问与"你觉得呢" 5. 冉银索要赔偿、被"你有钱但我不是有病"顶回并辱骂 6. "我根本不在意"与清明扫墓的话 7. 雷夜里13床的空缺与卫生间里的镜子碎片、流血指骨

**逐章写法公式**：

- **情绪流向**：起：痛（吐血、火从喉管烧到胃） → 承：疑（两秒的眨眼、昏迷前的"念念"） → 转：冷（"你有钱但我不是有病"、"我根本不在意"） → 合：惊（雷夜、镜子碎片、流血的指骨）
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：吐血与全员反应（把冲突推到肢体） + 两秒的眨眼与硬币正反面（用生理反差透露真心） + 下坠与昏迷前的接住和"医生"（把救人的证据留给半意识） + 卫生间镜前的伤口与冷笑（在无人处交代新线） + 郁成的追问与"你觉得呢"（用旁观者确认疑点） + 急救与上课（用两小时与一节课完成时间跳跃） + 冉银的索赔与被顶回（用对仗台词写反击） + 辱骂亲妈与全体静默（把仇恨推到底） + 擦琴不说话与"我根本不在意"（用沉默与冷话切断她的期待） + 清明的扫墓（交出一件长年的行动） + 雷夜与碎镜、流血指骨（用声音与伤口收章）
- **本章核心技巧**：整章围绕"他到底在意不在意"做反复拉锯——用两秒的眨眼、昏迷前的"念念"、抱起她冲出病房这些第三方可见的证据说她没看错，再用"我根本不在意"与擦琴不看一眼把证据全部推翻；最后用雷夜卫生间里的碎镜与流血指骨，把答案从语言层面转到男主自己的身体上
- **卡点与伏笔**：结尾卡点：她透过门缝看见他打碎镜子和正在流血的指骨，"鹤遂突然转头，看向她"——他的自伤原因与被看见的后果都悬置；埋设/回收伏笔：手腕五厘米的伤口与"昨晚送你回去时都是好的" → 自伤时间点与他独自面对的东西；打碎镜子与流血指骨 → 情绪失控的直接物证；昏迷前的"念念" → 她认定的错觉，等待日后被证实；清明扫墓 → 她四年的固定行动；"我是有钱，但我不是有病"与律师 → 他处事的方式；14床与13床的相邻床位 → 两人被迫长期同处的场域；冉银骂的"当年死亲妈" → 与宋敏桃之死及鹤遂的旧创直接勾连
- **时间线**：本章为第61章当日吐血后至当夜

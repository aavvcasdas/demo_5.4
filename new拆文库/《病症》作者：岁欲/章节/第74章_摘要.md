# 第74章 病症 摘要

**概要**：周念花了很长时间才分辨出眼前这一幕不是梦——抱着她流泪的人正是那个当众说不认识她的鹤遂，是那个扯断智齿项链扔掉的鹤遂，是那个失诺没赴约、让她在火车站等了整夜的鹤遂。她浑身剧烈哆嗦、条件反射地挣扎，张着嘴却说不出话，他的手臂像钢条般把她死死禁锢，她说"放开我"没有得到回应，只好一个字一个字地说"你，放，开，我"。他终于有反应，脸还停在她颈间，一滴泪滑落到鼻尖，说"我不放"；那滴泪滴进她的锁窝，却没能让她动容，反倒叫她心里横出一股狠意——她偏头一口重重咬在他胳膊内侧，隔着薄软的黑衬衫把牙齿深陷进他的肌肉，直到另一种湿润从衬衫里冲出来，是她尝不出也认得出的血的味道。她没有松口，皱着眉咬得更重，腮帮酸软作痛，他仍不放开，只在她耳边反复地低低叫"念念"。僵持到最后是她先累了，松开嘴瘫在他怀里，说"别让我恶心你""请你离开"；他答"我不会走，我要陪着你""念念，这一次我再也不会离开你了"，她心灰意冷地说"可是我不需要了"。他颤抖着说不管她说什么都不会走、会守着她、眼下的身体最重要，她只答"我的身体不重要，也没有任何事情重要"；他捧着她的头让两人的脸贴在一起，她却像一个没有生命的木偶，让他终于明白她对他完全死了心——不再喜欢、不再爱、不再憎恨、也不再厌恶。他近乎乞怜地说"念念，你继续咬我吧，你别这样不理我""就算是恨我也好过这样"，她平静地回"我一点都不恨你""我没有力气来恨你，你也不值得我花一份力气来恨你"；他点头说知道，也不着急解释，一切都等她身体好起来再说。他把她放回床上、盖好被子掖好被角，手机响了几下很快挂断，随后在床边的地上坐下；她翻身把纤瘦的后背留给他，他看着她颈椎骨头一节节突起，抬手用指腹擦掉眼角的湿润，手再落到颈间却摸到空空如也，心突然就空了。他就这样在地上坐了一整晚、握着她的手，只在她熟睡时小寐了会儿。第二天她醒来时眼皮上是模糊的红色，手仍在他掌心里，他第一时间问"念念，你醒了"；她悄无声息地把手抽出，被他扶着起身时又下意识推开他的手，他看着悬在空中的手失神了两秒，随后不动声色地把轮椅挪到她伸手能碰到的地方、还握住后把手稳住没放下的刹车。她想不通他为什么在大半个月前从奥斯卡颁奖典礼上突然消失、又突然现身在她的卧室里，洗漱完停在门口听动静，听见他说"我没走"，便失望地操作轮椅出卧室。院子里的冉银正好在给果蔬浇水，看见周念身后跟着的鹤遂，一下想到昨晚的情形：夜很深、小镇已陷进沉睡，她正要上楼睡觉时听见院中无比急促的敲门声，开门看清来人时整个人僵住——是穿着黑色衬衣、风尘仆仆、扶着墙剧烈喘息的鹤遂，他只说"我要见她"；冉银说"不可能""我不会再让你伤害七斤"，他却冷冷道"我不是在求你让我见她，而是在通知你——我要见她，立刻就要"，并用一句"如果你不想蜱虫杀夫骗保的事情闹得人尽皆知，就马上让我进去"逼开了门。冉银由此确信当年南水街的那条疯狗回来了，更惊愕的是他竟然早就知道周尽商的事情——也就是说，四年前他就知道，四年前周念要和他逃跑的原因也是因为这个。他拨开她挡门的手大步走进院中，走着走着跑了起来，在夜色里朝楼上的周念狂奔而去。

**关键事件**：1. "我不放"与泪滴进锁窝 2. 咬在胳膊内侧直到尝到血味 3. "别让我恶心你"与"可是我不需要了" 4. "我一点都不恨你，恨一个人是很累的" 5. 在床边地上坐一整晚、摸到颈间空空如也 6. 第二天早上挪轮椅、稳刹车与抽出自己的手 7. 冉银回忆他深夜砸门的原话与"通知你" 8. "蜱虫杀夫骗保"与"四年前他就知道"

**逐章写法公式**：

- **情绪流向**：起：疑（分不清现实与梦） → 承：抗（挣扎、咬人、说"我不需要了"） → 转：空（"什么都不再有"、他摸到颈间空空如也） → 合：惊（冉银回忆里的深夜砸门与旧账被揭开）
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：确认不是梦（用五识尽丧做前置） + "放开我"与"我不放"（把僵持钉死在一句话上） + 咬出血味（用身体验证关系仍存） + "别让我恶心你"与"我不需要了"（把旧账一次结清） + "我一点都不恨你"（用否认的排比收口） + 床前地上坐一整晚（把陪伴压进一个静止动作） + 摸到颈间空空如也（物证式的空） + 次日的轮椅与刹车（用伺候动作维持两种立场） + 冉银回忆深夜砸门（把男主的行为反转成主动进攻） + "我早就知道"（用旧账揭出一层新动机）
- **本章核心技巧**：把"重逢"写成一场不对等的肉搏——一方哭着求靠近，一方咬牙把对方咬出血；等到语言彻底失效，作者改用两处静默的身体细节（他坐了一整夜、他摸到颈间空空）收束，再切到旁人回忆里把整件事的主动权翻到男主手里，让读者刚怜惜完他就开始戒备他
- **卡点与伏笔**：结尾卡点：他明知"蜱虫杀夫骗保"的事却隐忍四年，深夜砸门闯入、扬言要把她带走，他到底要做什么完全悬置；埋设/回收伏笔：颈间空空如也 → 智齿项链已不在他身上（第72章他仍要索回，形成矛盾点）；"蜱虫杀夫骗保"与周尽商之死 → 与第7/12章死因冲突同源的关键旧案；"四年前他就知道" → 当年周念求他带她逃跑的真正动因；他右手手腕的疤 → 旧伤与旧事；地上坐一整晚 → 与第16章"守着她"的姿态形成跨章回扣
- **时间线**：本章接第73章四月深夜，延伸至次日清晨，并在冉银的回忆中回放前一晚

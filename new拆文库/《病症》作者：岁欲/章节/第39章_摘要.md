# 第39章 病症 摘要

**概要**：雨意不停的氛围里，周念红了耳根，结结巴巴地回答鹤遂"就……就，就是好朋友啊"，把"好"字念得特别重，也不知道这样的回答他会不会满意；鹤遂眼里的温度在下降，露出似笑非笑的表情懒懒重复"朋友？"，她温吞地应一声"朋友"，他就顶着上颚笑了下说"朋友还没到随便帮忙的地步"，还故意装出转身要走的样子说"那你找别的朋友帮忙吧，比如罗强"。怕他真的会走，周念心切地伸手拉住他黑色冲锋衣的一角，说"你别走，你帮帮霍闯吧，再说这个时候你突然提罗强干什么呀"——她真不知道这件事和罗强有什么关系。鹤遂瞥一眼她的手便抬眼看她"罗强不是喜欢你？"，周念直接噎住、莫名有点心虚地问"你怎么知道"，他拖着尾音用手指了指自己的眼睛说"因为我长了眼睛"。她把他的衣角攥得更紧、手指被雨水打湿，赌气地问"那你说我们是什么关系，你才肯帮他"；鹤遂低着脸、眉眼间的雨珠往下坠，漆黑潮湿的双眼凝望着她，嗓音沉郁地说"你以后能在我手术书上签字的关系"。周念一开始没反应过来，直到脑子里茅塞顿开才惊觉那不就是夫妻关系——他的意思是要和她结婚，她的脸以肉眼可见的速度迅速涨红，紧张地攥着他衣角解释自己还没到法定结婚年纪、和他还不可以结婚；他忍不住轻笑"意思是到法定结婚年纪就可以？"，她羞愤地说他又在开她玩笑，他语气平静地扔下一句"周念，我没开玩笑"就抬脚朝雨棚走去，留下她一个人在原地心跳乱了又乱。半分钟后她跟上，霍闯报出抢钱的人在南水街的黑网吧，还问"姐姐，你不是不认识鹤遂哥哥吗"，周念平静地看他一眼答"之前那次的确不认识。不过经我努力，现在不仅认识，还挺熟的"。鹤遂深吸一口烟、把烟头踩灭在脚底说"走"；三人一同往南水街去，霍闯撑自己的小伞，她和他同撑一把伞，走出去没两步他便自然接过伞柄，说她"你撑老戳我头"。路上她兴致勃勃地讲了早上赖床的事并索求表扬，他一路专注听、顺便提醒她小心脚下翘起的石板，索要表扬时也毫不吝惜言词——在情绪价值这一方面他竭尽所能满足她。到了黑网吧门口，他让她在外面等说"里面乌烟瘴气的"，她坚持要跟进去，他叹口气像拿她没办法一样说"那你就在我身后"；烟味呛得她捂嘴咳嗽，他站下来等她、回头看她时眼神更无奈。他往后抹掉头上的连帽、慢条斯理滑开冲锋衣拉链，脱下衣服随手递给周念，问霍闯"哪个"，霍闯颤抖着手指出靠墙坐着的四个男生和那个戴眼镜穿红衣服带头的金建。鹤遂毫不犹豫走过去，长腿跨进座位中间坐在男生的鼠标线上；他拿起电脑桌上那包很新的软玉溪、在掌心敲出几只烟、低头咬住一只却不点燃，再把那包烟砸在眼镜男身上说"小朋友挺有钱啊？抽得起软玉"。他招手把霍闯拽到座位中间，引导性地问"那你抢你同学什么了"，金建嘴硬说没抢，霍闯豁出去带着哭腔喊"金建，你撒谎。你今天早上抢了我一百块钱，还打我一顿"；鹤遂眸光一暗、嗓音陡然结冰说"看来你记性不太好……那我帮你回忆回忆"，话一落就把金建坐的电脑椅踹出去两米远、直撞到后排才停下。网管脚步生风跑来哀求"大哥，别在这里打架行吗"，金建的三个同伴同时站起来气势汹汹，他倒被逗得直乐、挑衅地冲他们勾勾手指"——来，一起上"。周念早就心惊肉跳，走上前用只有两人能听到的声音说自己有点后悔叫他过来、让他不要打架；他伸手把她拉近到视线齐平，慵懒地问"怎么，你怕我受伤？"，她委屈得快要哭地很轻地嗯了一声——就在这乌烟瘴气的环境里，他硬是感受到温情，知道是自己内心在开始不可逆转地塌方。他温柔地握了下她的手又很快松开说"放心，这几个小屁孩伤不到我"，她逼他保证，说不受伤则已、"不然我就三天不理你"，他故作惶恐、眼里却是宠溺的笑，最后说"好好好，知道了"。网管窜到金建几人面前喊出"你们知不知道这是哪呀？这可是南水街！南水街谁是爹谁是地头蛇你们都不知道吗？是疯狗鹤遂呀"，几人一听就怂了；那场架最终没打起来，抢来的一百块已被花掉大半，几人只能各自掏钱东拼西凑凑出一百块还给霍闯，挨个道歉保证从此不再欺负他，然后灰溜溜离开网吧。出来后鹤遂穿好衣服、撑开伞主动朝周念靠近一步把她纳入伞下，两人并肩走进雨里；发现霍闯还跟着，他便停下来懒洋洋地问"还跟着？"，霍闯反问能不能一起走，他说"你现在还跟着，就是在恩将仇报"，霍闯立刻反应过来并追问"你是不是喜欢周念姐姐"；鹤遂没正面回答，只说"小屁孩懂什么喜不喜欢，快走吧你"，霍闯做了个鬼脸喊着"你就是喜欢周念姐姐"跑开了。原地只剩两人，她硬着头皮问"你怎么不回答他"，他垂着眼睫说"我怎么觉得是你很想知道"；她口是心非说哪有，他故意说那就不说了，她急了扯着他的胳膊晃、完全在不自知地撒娇说"鹤遂，你想，你就是特别想"，他被晃得连伞都举不稳，终于败下阵说"我想，我特别想"；她安静下来眼巴巴望着他，他霍地俯身把脸停在与她咫尺的距离，握着伞柄的指骨收紧，嗓音低沉慵懒，每个字都像裹着蜂蜜般落进她耳朵里："怎么办啊周念，我被那个小屁孩说中了。""他说得完全没错。"——字字不提喜欢，字字都是喜欢。

**关键事件**：1. "好朋友"的回答引出卖惨要挟 2. "你以后能在我手术书上签字的关系" 3. 黑网吧对峙：软玉溪、拽出霍闯、喊话对质 4. 一脚踹飞椅子与"来，一起上" 5. "你怕我受伤？"与"三天不理你"的保证 6. 网管喊出疯狗之名、一百块凑钱归还 7. "我被那个小屁孩说中了"

**逐章写法公式**：

- **情绪流向**：起：窘（"好朋友"的回答） → 承：慌（被退回命名、被提罗强） → 转：甜（"手术书上签字的关系"） → 合：爽与确定（网吧收场 + "我被那个小屁孩说中了"）
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：关系命名的攻防（把感情线推到临界） + 手术书签字的间接表白（本章第一个甜点） + 黑网吧对质（本章爽点：名号与规矩齐出） + "你怕我受伤？"（把爽点换成温情并承认内心变化） + 雨中独处的告白（用孩子的旁证收束）
- **本章核心技巧**：让同一个人在两场戏里演出两种强度——网吧里他是"南水街的爹"，伞下他是被说中就俯身承认的少年；凶名与温柔都靠外部人物的评价（网管、霍闯）接力说出，主角自己一句狠话与一句情话都不需要解释
- **卡点与伏笔**：结尾卡点："我被那个小屁孩说中了。他说得完全没错"（告白落地，感情线正式确立）；埋设/回收伏笔：霍闯的"你是不是喜欢周念姐姐" → 由第三方戳破窗户纸；"手术书上签字的关系" → 婚姻承诺提前挂出；黑网吧与网管的PTSD → 鹤遂的旧战绩被点明

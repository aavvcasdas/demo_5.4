# 第42章 病症 摘要

**概要**：暑假在太阳的炙烤下来临，蝉鸣不歇、树影无风不动，在燥热的静里传来周念那幅名为《病症》的人物画获得金奖的消息——冉银收到消息第一时间就推开她的房门要分享好消息，而周念当时正在用手机和鹤遂发微信，被惊得一头冷汗，以迅雷不及掩耳之势把手机塞在枕头底下，又坐起来整理被压出浅褶的连衣裙平静地问"怎么了"。冉银说"七斤，你又得金奖了"，周念对奖项没有特别的执著——在她心里只要拿奖冉银就开心，冉银开心她的日子就好过许多，所以她只是平平地应和"哦，那挺好的"；冉银又说那幅画被纳进全国金奖作品美展、正巧被一个电影导演看见，想买授权用在电影里、价格开得很高，还说要是画真出现在电影里就会有更多人知道她、以后的路会越走越顺。周念想到那幅画只在背面角落写了作品名、并没有署名，观众若不强烈好奇便看过就忘，只说"我都行"，冉银满意地去通知剧组。冉银要走时周念叫住她，看着母亲额头明显的淤青问那里为什么受伤，冉银下意识摸了下那处说昨天去市里和保险公司的人闹了场架、没什么大事，又折回来安慰她"妈妈一定会搞定新阳保险的人，让他们正常理赔"。周念并不担心理赔，只是心疼母亲肉眼可见地憔悴下去，问她"他们到底为什么不赔"，冉银气说对方纯粹不想赔，并提到自己当初不该贪陈志强送的两桶菜油、买他两份保险——那时她本没打算买，是陈志强三天两头到家里死磨硬泡、提着两桶菜油磨了一个上午，才从对方手里买了两份千万保额的人身意外险。冉银叮嘱她明天又得去市里、饭菜都冻在冰箱。连续好几周的周三，周念空腹上称的体重都刚好维持在82斤，冉银很满意，满意到不愿细究她吃饭越来越不老实；周念很清楚这要归功于鹤遂不停鼓励她、表扬她每一次小进步——她在一步步和食物和解，催吐次数从每天三次降到每天两次、再到每天一次，最后到两天可能才吐一次，她觉得自己马上就要彻底好起来，对未来越来越有信心。晚上十点周念正要关灯睡觉时接到鹤遂电话，她把自己藏进被窝、用气声说话怕被隔壁的冉银听见；他说"让你明晚出来"，她疑惑——两人几乎从没把见面定在晚上，而她又怕黑，尤其那次在深巷经历他的生死一线后对黑暗的恐惧更甚；他听出她犹豫，说"带你去看萤火虫"，她惊讶地问"你怎么知道我想看萤火虫"，沉默好一阵后他低低说"上次你提过一次"，她更惊讶地说自己只是随便说说，他想也没想地回"可是我当了真"。她问明晚在哪见，他反问"你不是怕黑？明晚我来接你"。挂电话后她脸红心跳，心想他总是一副万事不挂心的样子，却记得她怕黑、把她随口一句话放在心上——他从不和她说什么好听的话，永远是个行动派，沉默寡言却靠谱得让人格外心安。隔天晚上她带上素描本、铅笔和橡皮装进白色帆布包，等他说到了才关灯出门；开门后两人竟默契地都穿了纯白——她是白色连衣裙、他是白色短T，她用这个作为开场白问"像不像情侣装"，他吊儿郎当回"少占我便宜"；关门时他伸手取下她的帆布包往后一甩搭在肩胛上。十点后的小镇少有行人，月光把两人的影子拉至重合，镇上也少灯、走哪都黑灯瞎火；鹤遂打开手机手电筒，手腕微微一斜让光束始终固定在周念的脚尖前，她盯着那束光，突然觉得黑暗似乎也不是什么太可怕的东西。她提起上次在病房给他画的那幅画得奖了、是金奖，他问"金奖是最高奖项么"并真心实意地说"恭喜你，周念。对你来说，拿金奖应该很容易，你值得"，她则说拿不拿奖自己无所谓、主要是妈妈希望她拿奖；听到这话他脚步一顿，淡淡道"别做你妈希望你做的事情，要做你自己想做的事情"。她想了半天，说自己从记事起就开始画画、不知道除了画画还能做什么；他问她除了画画还喜欢什么，她想了一会儿，眼睛亮起来说想成天和猫猫狗狗待在一起、以后想开一家宠物店，他认真思考这件事的可行性后低声说"嗯，你会有的"。她本想问他以后想干什么，却想起他上次的回答——"我是个没有以后的人"，于是识趣地转开话题，让他把拔牙时那个故事讲完。不知不觉两人一直往南走出小镇，来到郊外的农田：月光下大片稻田、绿油油的麦浪、错落的田埂、咕咕的蛙声和跳来跳去的蟋蟀；鹤遂挑了个挨近稻田的地方停下示意她看，稻田间飞舞着无数明黄光点像起舞的星星，周念的鹿眼瞬间亮起来。他掏出一个玻璃瓶说"给你抓点带回去"，她半信半疑，他说"你猜？"，随后把她的包塞到她怀里、走进稻田。她坐在青草地上屈膝翻出速写本，画下为她捕捉萤火虫的鹤遂——少年、夏夜、月光、稻田、萤火虫、浅浅的风，她想不到比这更美好的画面。十多分钟后他带着大半瓶萤火虫回来，把瓶递给她；她发现木盖上被戳了细细密密的小孔，他解释不留孔萤火虫缺氧太快、死得快，这样装着能多活两天。她抱着瓶子道谢，随后惦记着让他讲完那个故事，他便闭着眼睛讲了下去：成为妓女后的女主人生更为不幸，被男朋友家暴，后来遇到一个很坏的男人、被绑架，她与男人合作杀掉家暴她的男友、诈骗高额保险金，后续又以同样方式骗婚、杀夫诈保，继续杀掉两任丈夫、获利惊人的保险金；女主看清情夫真面目后手刃情夫，又骗出之前的妓女同事继续杀人——这次是为了交换身份、以全新身份活着；最后她把那个生下她又无比嫌弃她的母亲推下了悬崖，决意重新开始生活。周念好奇地问杀了那么多人居然没被抓吗，他说"作者最后没明写"；她追问书名，他睁眼看她"你想看？"后说"绝叫"，并评价这故事本身就压抑——一个被原生家庭重伤的女主始终被创伤挟裹，才有了后续千疮百孔的不幸人生，他心里想到海明威那句"你从一个地方跑到另一个地方，但你还是你。你没法从自己的身体里面逃出去"。周念的思绪却被另一个细节拉扯着，问"现实生活里真有人骗保成功吗"，并说上次那个保险业务员问了她很多奇怪的问题、感觉他就是在怀疑她妈妈骗保，但因为妈妈和爸爸感情一直很好，所以她特别反感；他淡声宽慰她"不用搭理他"。她还想问点什么，却看见他皱眉——有条虫子在咬他；他拉起右边灰色裤管，小腿上吸附着一只褐色圆状的虫子，周念瞳孔骤缩、几乎是条件反射地握住他的手，结巴着让他赶紧回去把这只蜱虫弄掉。见他懒洋洋说"又死不了，不着急"，她的眼圈刷地红了，用近乎哀求的语气哭道"会死的，会死的，你快点起来吧……我求求你了鹤遂"；他完全怔住，利落站起问她怎么就哭了，而她蹲下收拾东西时哽咽着说"鹤遂，我爸爸……他就是被蜱虫咬了后，死于病毒感染"。去医院的路上她不停自责"都怪我要看萤火虫"，他反复说这只是一个意外、怎么能怪她，她只答"可是我爸爸就死于这种意外"；蜱虫不能自行拔除，到医院挂了急诊，从拔蜱虫到消毒开药她全程看着，临走还再三确认只要过了四天潜伏期就是安全的才肯离开。回家的路上她的身体一直在发抖、脸色苍白、唇上毫无血色；昏暗巷中，他倏地拽住她的手腕把她紧紧抱住，她撞进他的胸膛、腰间和背部多出一双有力温暖的大手，所有混乱在这一刻消失；他抱着她，那只大手在她背上轻轻拍、又上下温柔地抚了抚，耷颈低头把脸贴在她耳边低声呢喃"念念，别怕""我怎么会死"。她的颤抖一分一秒缓解，也永远会记得鹤遂叫她第一声"念念"是在南水街一条昏暗的小巷里；几分钟后她彻底平静下来，把眼泪蹭在他胸口，哑声说"不准死，也不准离开我"，腰间那只大手再次收紧，他抱得更用力、笃定地回答"不会，永远不会"，她心安地闭上通红的双眼，反复在心里默念：他说不会，永远不会。

**关键事件**：1. 《病症》获金奖与被电影导演看中 2. 冉银额头的淤青与两桶菜油买下的两份千万保额意外险 3. 体重维持82斤、催吐降到两天一次 4. 电话约看萤火虫与"可是我当了真" 5. 稻田捕萤与《绝叫》的故事 6. 蜱虫事件、"我爸爸就是被蜱虫咬了后死于病毒感染"与"念念，别怕"

**逐章写法公式**：

- **情绪流向**：起：闷（得奖报喜、藏手机、母亲的淤青） → 承：轻（电话约看萤火虫、情侣装、手电筒的光） → 转：静（稻田捕萤与《绝叫》的压抑结局） → 合：惊与暖（蜱虫引发的崩溃 + "念念，别怕"）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：金奖与授权（把成绩交给功利逻辑处置） + 母亲的淤青与保险往事（保险线取证，同时写她的憔悴） + 82斤与催吐递减（康复曲线的可视化） + 夜约看萤火虫（把甜蜜放到黑暗里） + 稻田捕萤与讲完的《绝叫》（把书与人互文） + 蜱虫与父亲的死因（用极小生物引爆创伤） + 巷中拥抱与"永远"（关系以昵称与承诺收束）
- **本章核心技巧**：全章以"光"贯穿——手电筒的光落在他为她照的路上、萤火虫的微光落在她眼睛里，最后在昏暗巷子里靠一个拥抱把恐惧关掉；浪漫与创伤共用一个光源，甜和痛互为背景
- **卡点与伏笔**：结尾卡点："不准死，也不准离开我"与"不会，永远不会"（以永远不会反衬此后的分离）；埋设/回收伏笔：《病症》被电影导演看中 → 画作将以另一种方式进入公共视野；两桶菜油买下的两份千万保额意外险 → 骗保疑云；《绝叫》的故事与海明威那句"你没法从自己的身体里面逃出去" → 对女主命运的影射；蜱虫与父亲的死因 → 首次交代周尽商死因；"念念"第一次被叫出口 → 关系命名升级

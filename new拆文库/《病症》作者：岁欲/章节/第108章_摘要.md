# 第108章 病症 摘要

**概要**：浴室里传来花洒声时，周念坐在桌前擦头发、看莫奈连发的十几条微信。莫奈甩来她与鹤遂并肩走在人群中的照片和一句"你和鹤遂就那么直接走在外面啊"，周念回"没事，我做好心理准备了""和他一起面对的准备"，并承认"他现在是我男朋友"；莫奈连打几个问号后提醒她两人差距太大，问他愿不愿意冒险公开、还是永远地下恋，周念说"我知道""我还想再相信他一次"。鹤遂在浴室里喊她，问自己穿什么——周念这才想起他的衣服是湿的，去隔壁卧室想找一件周尽商没穿过的衣服却找不到，因为冉银整理遗物时把他的东西全清理了；她只能拿一条新浴巾，问"鹤遂，你能裹着浴巾睡吗"，他回"你不介意就行"。她回书桌时看到一条实时资讯：高中同学韩青实名举报善进学院非法虐待，自诉曾被暴力殴打和性侵。周念点进十分钟的采访，听到韩青说禁食、体罚、关小黑屋都是最轻的惩罚，男教官会扒光学员衣服动手动脚、不听话就棍棒相加；她说绝大多数未成年学生只需两周就能被驯得像狗一样听话，自己因爱玩手机被父母送进去十三天，见到父母时跪着哭着认错、承诺不再玩手机才被接出，父母还给学校送了一面锦旗；她还说见过一个十三岁男孩扑过去用嘴舔爸爸皮鞋上的灰。更讽刺的是，学校被查封后不少家长堵在派出所门口大闹，要求善进重新开办。鹤遂洗完澡赤裸上身出来，周念看得一时忘记呼吸；她把善进的事讲给他听，说"他们只想要学生做到绝对的服从，就像是训狗一样"，鹤遂的表情莫名变得凛然、眸底酿出寒意。周念说受访的女生是自己高中同学、高二寒假被送进去、之后变得特别安静，并问他是不是自己惹他不开心，他从镜中与她对视、露出很浅的微笑说"你想多了"。他坚持给她吹了快一个小时的头发，自己却懒得吹，被她抢过吹风机；他不肯坐下，直接掐住她的腰把她整个人抱起来让她坐在腰上吹。之后他抱着她走到床边把她放倒，凑在她耳垂处轻声说"还能干嘛""我不是都按照你的要求，洗干净了吗"；周念用膝盖顶住他胸口说"我没那个意思"，又用认真的口吻说"你这样是把自己当鸭"，他却吻一下她的嘴唇说"为爱做鸭的话，也不是不行"。

**关键事件**：1. 莫奈的十几条微信与"我现在是我男朋友" 2. 找不到周尽商的衣服 3. "裹着浴巾睡" 4. 韩青实名举报善进学院 5. 舔皮鞋与送锦旗 6. 家长堵派出所要求复校 7. 鹤遂听见善进时的凛然与"我没事" 8. 给女友吹头发却不肯给自己吹 9. "为爱做鸭的话，也不是不行"

**逐章写法公式**：

- **情绪流向**：起：慌（公开后的处境） → 承：沉（韩青的采访与善进的恶） → 转：冷（鹤遂的凛然与"我没事"） → 合：甜（吹头发的双重标准与"为爱做鸭"）
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：莫奈的十几条微信与"我现在是我男朋友"（把公开的代价摊开） + 找不到周尽商的衣服（用旧账交代家庭状态） + "裹着浴巾睡"（用家常对话缓和） + 韩青实名举报的资讯（把善进线正式推上台面） + 十分钟采访的证词（把恶具体化） + 家长堵派出所要求复校（用反讽收尾） + 赤裸上身出浴与看呆（用甜度缓冲） + 复述善进与"就像是训狗一样"（触发男主的失态） + 镜中的浅笑与"我没事"（把悬念留住） + 吹头发的双重标准（用双标写偏爱） + 抱起来坐腰上吹（把荒诞与亲密叠在一起） + 放倒在床上与"洗干净了吗"（把暧昧推到临界） + "为爱做鸭"（用一句台词收束）
- **本章核心技巧**：一章里同时放三个层级——甜（吹头发、抱起来坐腰上）、恶（善进的证词）、疑（他听到"训狗"时的凛然），并且让甜度包住恶与疑，读者在放松时被不自觉地种下一个钩子
- **卡点与伏笔**：结尾卡点：周念说"你这样是把自己当鸭"，鹤遂回"为爱做鸭的话，也不是不行"，两人临近同床而本章即止，下一章进入关灯后的段落；埋设/回收伏笔：韩青举报善进学院 → 第111章她加周念微信、点出"鹤遂也进过那个学校"；鹤遂听到"训狗"时的凛然 → 他本人是善进受害者；"不吹干睡觉会头疼" → 他的细碎照顾；周念公开后没敢看热搜 → 第109章他凌晨两点半发微博公开她；冉银清理周尽商遗物 → 家中人物关系的现状
- **时间线**：本章紧接第107章当夜，自周念洗完澡后至就寝前

# 第56章 病症 摘要

**概要**：四年后，京佛这个城市十一月中旬的气温还稳在32℃以上，空气里黏着一层很腻的热意；周念醒来时发现自己躺在一张病床上，四周白花花，手背上扎着留置针挂着点滴，体腔里像有一团火在烧，一路往上烧得整条食道、心口和喉咙都火辣辣地痛。床头墙上的黑色显示屏写着她的信息：周念、女、22岁、一级护理。冉银提着热水壶进来，一开口就是"早给你说过，人家现在是大明星哪里还会看得上你？"——与鹤遂重逢的场景瞬间涌入脑海：他被好多人簇拥在中央、瞩目万分，看她的眼神却何等冷漠，就像在看一个从不相识的陌生人。冉银问她"这下总该死心了吧"，周念半耷着的眼皮动了动说"我要问清楚"，她一定要从他嘴里问到答案；冉银提醒她今天中午当着那么多人的面问他、他却说"不认识你"，周念宁死都不愿相信曾经那么宠惯她的鹤遂会这样对她，只哑声说"不要说了"，又告诉冉银"你只用知道你答应过什么就可以了"——冉银没忘，说只要她达到医生的标准出院，就同意她出院后去找他，但她毫不担心，因为今时不同往日，现在想见一见当年南水街那条疯狗比登天还难。门口传来三声敲门声，进来的是莫奈，外八的脚步、过胖的身形撑得门很小；自从13年高考结束后莫奈考上京佛的一所二本大学，两人再没见过，四年时间让两人都发生了翻天覆地的变化——她一边念大学一边搞直播，成了网上热门的吃播博主、目前粉丝五十多万，硬是靠直播在京佛挣出了一套属于自己的小别墅。周念伸手想拉她，莫奈看着那只手臂眼睛刷地就红了：那简直不像一只人类的手臂，瘦得能看清楚骨头的边沿形状、看得清每一根青筋和血管，很薄软的一层皮肤裹着那些人体组织，经不起细看，细看就像恐怖片里女鬼的手；莫奈没忍住眼泪，轻轻接住那只手捧着、生怕晚一秒接就会断掉，周念气息微弱地笑着说了个没事。随后被冉银介绍为主治医生的王学知（戴无框眼镜、近五十岁、上嘴唇边上有一颗痦子）走到床尾说明病情：她这个神经性厌食的情况已经很严重了，168的个儿只有58斤、浑身只剩一层皮；因长期营养严重不良，所有器官都出现了继发性病症——胃溃疡很严重还有炎症、贲门松得很厉害，严重贫血、低血糖、低血压，心脏也有问题、心肌缺血、心率不正常，所以老觉得心慌心悸；还有偏头痛，并警告"你再不好好配合治疗，是要丢命的"。神经性厌食症是精神科死亡率最高的疾病、死亡率高达5%—20%，医生所言没有任何夸大成分，可周念听完脸上依旧是不痛不痒的冷淡，只关心"我什么时候可以出院"，并追问"我要到多少斤才能出院"；王医生说至少也得七十斤，她答"好"——七十斤而已，她只用快速长到七十斤就可以出院，然后去找那个人要个答案。治疗方案主要是管饲和静脉内高营养治疗项目的结合，周念下意识皱眉，她讨厌管饲、之前在其他几个精神病院尝试过，就是用一根输食管从嘴里塞进胃里输入营养物让她活下去，而她现在已完全丧失了自主进食的能力。王医生离开后她请冉银也出去、想单独和莫奈待一会；这几年冉银变化不少，倒不是说变善良，而是变得无可奈何，她的强势和掌控欲在周念面前已没了用武之地，无论她怎样周念都只把她当空气。莫奈在床边坐下、用肥呼呼的手指擦眼泪，说自己快二百斤了、顶四个她，问她这是何苦；周念的善良温柔一直没变，用手给她擦眼泪说"挺好的""你看你现在多有福气"——莫奈做吃播挣的就是长肉的钱，一年时间从一百三长到了一百九。莫奈问她现在还画画吗，她声音很轻很空洞地说"不画了""……很多年以前就不画了"：从2013年的那个夏天开始，她就再也没有拿起过画笔，从蜚声画界的天才少女沦为碌碌无名的普通路人。莫奈终于把话题带到那个人身上，说"他的心里真有你，会四年不找你吗？这可能吗"，周念说"我只想亲口问问他"，莫奈回"他说不认识你，全中国都知道了"；周念的睫毛颤了颤、鼻尖泛红，莫奈便拿出手机悬在她眼睛上方让她自己看——那是一条评论过万的营销号爆料博，说影帝鹤遂在户外路演时被一个奇怪女子骚扰、被不停追问是否认识她，据说是一个狂热的私生；配图背景正是火车站外的大广场，周念跌坐在人群中央、骨瘦如柴，上镜胖十斤却仍像一副骷髅骨架，狼狈地红着眼仰着头，目光所及是几步远外的男人——阳光下他穿极简的黑衬衫、身高腿长、头身比优越，单眼皮、冷白肤色、鼻子很高、面部折叠度是黄金比例，一个黑色口罩被修长手指懒懒勾着垂在身侧，垂眸看地上的她时眸光睥睨且冰冷、没有一丝温度。莫奈的手指不小心点到评论，热评很扎眼地落进周念眼中，诸如"私生能不能去死""她这次是伸手拽了鹤遂的项链，那下次手里拿把刀呢""还问遂遂认不认识她？哒姐请问你谁"；莫奈发现她神色不对劲立刻收回手机，说不该让她看评论，周念则抿着干裂的唇问"私生是什么意思"——她不追星、看不懂这两个字，但知道这一定不是什么好词。莫奈只劝她别再找他，说人家现在多风光、顶流大佬、电影巨咖级别的存在；周念喉咙烧得更厉害，苦笑着说"是啊"，又问听说他今年得了戛纳的金棕榈奖、这个奖是不是很厉害，莫奈语气很怪地承认"那是相当的厉害""可以说电影圈没人能做到像他那样，再给二十年都不一定能出第二个他来"。其实她曾在搜索引擎里一次又一次搜过他的名字、看过无数遍他的资料：2014年7月他凭借处女作电影《屠佛少年》获得金鸡奖最佳男主角，十八岁的他一炮而红，这部片子是那年的暑期档黑马，上映前一片唱衰、排片率低得出奇却爆冷出圈、狂吸11亿票房；媒体评价他红得毫不意外，一张野性英俊的脸、189的个子、身上一股别的男明星没有的狠劲，网友说他只要站在那里就是一片阔无边际的荒野；2015年他又凭《灭》同时获得金马奖、金像奖最佳男主角，各路资本纷纷投去橄榄枝；2016年出道第三年上映第三部电影《六十六道》，靠它一举斩获隔年的戛纳最佳男演员奖，同时再获金像奖与金马奖——出道即巅峰且一直在巅峰，22岁的鹤遂各种耀眼奖项加身，演技绝、皮囊好，让万千少女为之疯狂。周念用手指轻轻掐着手背的皮肤，薄薄一层皮肤被她轻而易举地提捏起来，她就看着那点悬起的皮肤发呆，呐呐自语"我这个样子""怪不得他要忘了我"；四年时间她和他都是地覆天翻的变化——他早已不是南水街那条人人喊打的疯狗，而是万千少女的人间理想、是闪耀发光的顶流影帝，而她只是一副被皮肤包裹着的骨架，可她还在原地。

**关键事件**：1. 四年后周念住院、22岁、58斤、一级护理 2. 冉银提及中午重逢的"他说不认识你"与出院条件的约定 3. 莫奈成为吃播博主、五十多万粉丝 4. 王学知宣读全身继发性病症与七十斤的出院标准 5. "不画了"与2013年夏天后再没动笔 6. 营销号爆料"影帝鹤遂被私生骚扰"与那张火车站照片、热评 7. 鹤遂四年间的影帝之路与两人的天壤之别

**逐章写法公式**：

- **情绪流向**：起：灼（醒来、烧着的食道、58斤） → 承：钝（母亲的话、"他说不认识你"） → 转：惊（营销号爆料博、热评、影帝履历） → 合：空（掐着手背的皮、仍在原地）
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：病床与信息屏（用证件式细节交代四年与现状） + 母亲的刺激与重逢回忆（把最伤的话前置） + 出院条件的约定（给出女主唯一的行动目标） + 莫奈的出场与手臂特写（用闺蜜的眼睛写她的崩坏） + 医生的病情清单（把病危量化） + 七十斤的目标（把康复变成通往他的门槛） + "不画了"（写能力的永久丧失） + 营销号与照片（用舆论重述那一夜） + 影帝编年（把男主抬到天上） + 掐皮肤的自语（用最轻的动作完成自我否定）
- **本章核心技巧**：整章是"重逢的余震"——真正的高潮事件（她当众问他、他说不认识）被放在幕后，本章只处理它留下的后果：病床、热评、体重与奖项；作者用大量可核查的外部信息（医嘱、粉丝数、奖项年份、票房、诊断名）把情绪钉在现实里，让读者无法把它当成一场梦
- **卡点与伏笔**：结尾卡点："可她还在原地"——她要长到七十斤出院去找他要答案，而"想见他比登天还难"，下章期待为这次追寻如何推进；埋设/回收伏笔：他说"不认识你" → 失约的四年之谜（第55章的悬念延续）；"你只用知道你答应过什么" → 冉银与她的交易条款；七十斤的出院线 → 可量化的短期目标；管饲与丧失自主进食能力 → 康复线的具体障碍；"不画了""从2013年那个夏天开始" → 画笔停摆的节点；她伸手拽了鹤遂的项链 → 第52章的牙齿项链在重逢场景中以另一种方式出现；营销号与私生的标签 → 后续舆论风险；霍闯、厌厌等旧线索在本章未接续
- **时间线**：本章时间约为2017年11月，距2013年6月高考结束已过四年

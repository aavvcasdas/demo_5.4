# 第12章 病症 摘要

**概要**：冉银去市里处理保险理赔，周念独自在家两天，第一次体会到"三餐都不用在她注视下完成"的自由。她在河边写生时被新阳保险公司业务员陈志强找上，对方照笔记本提问"你父母平时关系怎么样""他们平时吵架吗"，进而问"你爸爸之前和其他的阿姨走得近吗"。周念一眼洞穿其目的，直白反问"你是怀疑我爸爸出轨……我妈也因此抱恨在心，所以弄死我爸诈骗千万保额对吗"，随即逐条驳回：父母感情好、保险是上门强力推销、冉银自己也买了一份同额一千万的保险、父亲是病故而非意外事故。陈志强知难而退。周念由此想起周尽商去世那晚——除夕夜，医生摇头，冉银泪如雨下却厉声"不准哭"，要她"任何时候你都要管理好的情绪"，她咬破下唇才把泪憋回去。回家后她面对冰箱里按餐分装、标明日期克数的食物，想出一个办法：把午饭热好，去邀请莫奈来家里一起吃。莫奈欣然赴约，吃得很开心，还因韩青不邀请周念而决定也不去韩青的生日聚会。当晚周念可熬夜、写了两篇日记，因月经将至出门买卫生巾，在南水街按摩店旁的巷口撞见肖护一行人神色慌张逃出，捂着流血的脸、明黄T恤上有一大团深红——她凭调色经验认出那是新鲜人血。她冲进漆黑小巷跑到巷尾，看见鹤家门口一大摊血，鹤遂侧身蜷在血泊里，腹部被捅、昏迷不醒。她打 120 时，看见他手边的青石板上有一卷未拆封的保鲜膜。

**关键事件**：1. 保险公司陈志强盘问，周念反诘驳回 2. 周尽商病故除夕夜的回忆 3. 邀莫奈共餐（把食物分出去） 4. 深夜撞见肖护一伙 5. 鹤遂被捅倒血泊，手边一卷未拆封保鲜膜

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |

**逐章写法公式**：

- **情绪流向**：起：自由（母亲离家） → 承：尖锐（保险盘问、丧父回忆） → 转：温柔（与莫奈共餐） → 合：恐怖（血泊 + 保鲜膜）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：自由日开场 + 保险业务员盘问（悬疑线曝光） + 父亲病故回忆（母亲真面目加码） + 邀莫奈共餐（友情线加固） + 夜行买物（转场） + 撞见肖护一伙 + 发现血泊中的鹤遂（最大卡点）
- **本章核心技巧**：前半章用极其日常的内容（写生、吃饭、写日记、买卫生巾）蓄满松弛感，后半章用一次夜行把它全部砸碎——强反差的章内节奏转换
- **卡点与伏笔**：结尾卡点：一卷未拆封的保鲜膜（谁买、为何被捅、与橘子的联系）；埋设伏笔：陈志强笔记本上那些"对理赔有好处的问题"、冉银自己那份同额保险、鹤广翻箱倒柜找钱

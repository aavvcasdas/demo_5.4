# 第67章 病症 摘要

**概要**：鹤遂慢条斯理地喝水，说"能让解狗亲自来找你，说不准你还真有"，圈内人叫解渤腾"解狗"正是因为他有对八卦气味格外敏感的狗鼻子。周念试他是否担心照片外流，他以"能用钱摆平的事就不算事"回应；她便当场开出价码——一张照片十万块、手机里有二百多张，按二百张算合二千万，问他这笔让影帝继续清白的买卖是否划算。他连眉头都没皱，反而替她算账，说和解狗合作要分钱又扣税、到手不多，可以直接把照片卖给他、他给税后二千万。周念听得险些打翻窗台上的万年青，问他想怎么买，他答先打钱、再当着面把照片删掉。她走到他面前打开相册，点开第一张双人合照给他看——简朴房间里少女站在少年胸膛前、少年头上缠着绷带，那是他当年拿来当过手机屏保的照片。她一张一张划过，声音里带上哭意，却被他打断："我发现你真的很喜欢用'以前'和'当年'这种词，可是人不能总活在过去，得向前看。"她自嘲"我真傻"，垂下手，他丢下一句"要做这笔买卖的时候告诉我"便离开，她把那张名片撕得粉碎扔进垃圾桶。下午冉银带着一双新毛绒手套来看她，母女俩站在天桥上，周念看着美人鱼喷水池前被护士和病人围着拉琴的鹤遂，提出"给我办理出院吧""我想回家了"；冉银说看来她已经得到答案，又劝她病还没好，她坚持不用一分赔偿金，冉银只好说存款还能撑二天、二天过后再说。她把二天后出院的消息告诉莫奈，莫奈隔一小时直接推门进来，说她好不容易长了一两肉就急着出院，并表示钱的事不用担心、可以借给她。两人到花园长椅上坐下，周念才说钱只是一小部分原因，更重要的是她不想再待在这里——她最初抱着怀想来这座城市、甚至想过破镜重圆，后来只想要一个答案，现在只想离开，因为破镜重圆和得到答案都不能使她愈合；莫奈替她不值，她却说"他也没做错什么"，只是没遵守一起离开花楹镇的诺言而已。正当莫奈还想说什么时，郁成急慌慌跑来告诉鹤遂有人扒出一张照片、已经冲上热搜前几位——那是四年前她和鹤遂在长狭弄喂厌厌时被旅客拍下的合照，当年她还同意对方发到微博上。舆论随即卷起，莫奈扬高音量喊"不见得影帝又有多清白无辜"，鹤遂抬眼望过来，目光在她脸上停留一瞬便收回、转身离开；周念看见他背在身后的那只手紧握成拳，鲜血从指缝间不停滴落，沿着他的脚步写了一路。

**关键事件**：1. "能用钱摆平的事就不算事" 2. 二千万的开价与"我给你税后二千万" 3. 第一张合照与"你当年还拿它当手机屏保" 4. 被"人不能总活在过去"打断、名片被撕碎 5. 天桥上提出出院、冉银说存款还能撑二天 6. 莫奈推门而入、愿借钱给她 7. 花园长椅上"破镜重圆和得到答案都不能使我愈合" 8. 四年前的喂猫合照冲上热搜、他握拳滴血沿路留痕

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 谈钱其实是在谈心 | 她报出"一张十万""二百张二千万"，他却只把玻璃杯放到桌上、连眉头都没皱，还替她算分成与扣税，最后给出"我给你税后二千万" | 反应层放大 | 心疼 | 让被开价的一方对价码毫无波动，反而更显出问价一方的试探性质 |

| 证据在别人手里先爆了 | 她原想把照片交出去又撕了名片，随后热搜直接爆出四年前的喂猫合照——那张还是当年她自己同意发的 | 反转式外部引爆 | 紧张 | 让主角放弃的筹码被第三方重新捡起，冲突不必靠主角主动升级 |

**逐章写法公式**：

- **情绪流向**：起：冷（喝水谈钱、一句"能用钱摆平的事就不算事"） → 承：痛（二千万、第一张合照与"人不能总活在过去"） → 转：退（提出出院、决定二天后离开京佛） → 合：爆（热搜流出旧照、他握拳滴血留下一路）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：谈钱开价（把关系折算成数字） + 他替她算税后价（用平静反衬她的试探） + 打开相册第一张（用旧照承载旧情） + "人不能总活在过去"（把回忆一次判废） + 撕碎名片（表明放弃外部筹码） + 天桥上看他拉琴与提出出院（把去意落到手续） + "存款还能撑二天"（给出倒计时） + 莫奈推门与愿借钱（用朋友接住退路） + 花园长椅上把话说完（交代她为何要走） + 热搜爆出旧照（让放弃的筹码被第三方捡起） + 他握拳滴血离场（把情绪转到身体的伤口上）
- **本章核心技巧**：把"谈钱"写成"谈感情"的替身——她开价是为了看他的反应，他谈成生意是为了把关系推导成交易；一个用数字试探，一个用数字封口，最后让第三方爆出的旧照把他没能消化的情绪直接转译成手上的血
- **卡点与伏笔**：结尾卡点：他一路滴血地离开、全程没看她第二眼，那笔没成交的买卖与热搜的后续都悬置；埋设/回收伏笔：二千万/三千万的价码 → 第68章三千万直接到账；撕碎的"解狗"名片 → 事态被热搜接管，外部引入的变量开始独立运转；四年前长狭弄喂厌厌的旧照（她当年亲口同意发布） → 与厌厌之死形成跨章回扣；二天出院的倒计时 → 推动她尽快离场；他背后的那只手滴血 → 延续"受伤总在右手/身体"的线索
- **时间线**：本章接第65-66章同病房对话之后，经当日下午，延伸至次日

# 第115章 病症 摘要

**概要**：从派出所回家那天，鹤遂用家里的尖口钳和胶水亲手把断掉的智齿项链修好，明明自己也能戴，却叫周念帮他戴，觉得由她来戴更有仪式感。她从堂屋出来时怀里抱着他在善进写的日记本，说他乜了一眼问还抱着干嘛，她慢吞吞走过去说想看但还没看，因为日记毕竟是很私人的东西；他说"你看"，又补一句"但你不一定能看得懂"。那是一本纯黑封面、用他遒劲板正的字迹写着《我和身体共用者们的对话选段》的本子，翻开第二页便被多种字迹冲击——有歪七扭八的，有标准行楷，有幼稚到夹杂拼音的，一人格一种字迹，周念只认得鹤遂的字。内容起初只有三两个人格参与，越往后参与对话的人越多，痛苦也越明显：2013年7月19日不知晴雨也不知昼夜，夏尔澈问为什么每次出来都这么痛，鹤遂答因为我每天都在挨打，又提醒上次逃跑被打断三根肋骨、流了半小时鼻血；夏尔澈问新人叫什么，他说叫顾无白、是个牙医，被追问得烦了只回"那就闭嘴"，字迹后还被夏尔澈画了个大大的鬼脸。新字迹游暗说"我想出去"，多个人格用不同字迹跟着写下三个字——想出去。2013年8月6日雨天深夜，正是他刚开始接受电击治疗的日子，夏尔澈闻到异味，桑遣说他们把他搞得尿了裤子也不给换，夏尔澈一句"我先不出来了"后便消失在后续日记里；老墨和桑遣要轮流出来扛，鹤遂说"你们都去睡觉，让我待在外面就好了"，随后说他好像看到她了——是周念，桑遣说是错觉，他却一连写下"念念，你又来了""你怎么不愿意带我走""我很想你""念念，救救我"，字迹剑走偏锋、纸张被疯狂撕裂，接着是一整页由他一人写下的周念的名字，其他人吓得不敢出来。阿烈说再不出去我们都会死在这里、唯一的办法是让鹤遂认错，顾无白提议大家都可以冒充他扮演认错，前提是演技得好，小智说"我害pà"、宋榭推给宋莱、老墨说俺也不行、许惠柔说自己太容易怯场，讨论无果，下篇日记已是半个月后：鹤遂说她又来看我了、穿白裙子拿着一颗橘子，老墨借机提起顾医生说得骗过那些人，点明需要"一个新的人"，鹤遂却说不想让自己病得更重、不想迈上第十三级魔鬼阶梯——一个人格代表一级阶梯，现在是十二级，每多一个人格就是更上一级阶梯的地狱；他补一句"我是把自己当魔鬼"，夏尔澈便拿"出去就能见到那个穿白裙子的女孩子"劝他，他答"……对，就能见到她"后不再作声。2013年11月9日，日记里出现龙飞凤舞的熟悉字迹——沈拂南登场，听完逃出去的办法后说"演戏？那不是易如反掌的事情吗"，随即开出条件：帮忙可以，但此后鹤遂不再是这具身体的主人，我才是；鹤遂回"你做梦？"，沈拂南只说"你看起来很虚弱，休息吧""好好睡觉，把身体交给我"。周念终于明白他为何沉睡四年——沈拂南足够强大、而他那时十分虚弱，早就没有选择权；往后一个月里再没有鹤遂的字迹，只有以主人格自居的沈拂南。最后一页，她又看见鹤遂写下的那句："我的十三级病症无药可医，念念，你要救我，还是要毁灭我。"她愁肠百结地合上本子塞进他怀里说"早知道就不看了"，他倒没什么难过——从派出所回来后他只觉得轻松，因为她已经知道全部、一点都不介意还愿意和他在一起，便打趣"有些字乱成那样，撒把米在上面鸡都写得比他们好，你还能看懂"。周念怏怏地叫他想说不知道要用多少东西去填满他经历痛苦和绝望后的空洞，又哽咽着说总觉得他身体里的其他人格似乎和自己脱不开关系；他把日记本放到条凳上、拉她坐到自己腿上、从背后圈住她、把下巴搁在她肩窝里，认真地说"把'似乎'去掉"，并说最近才慢慢理清副人格与她的关联。于是傍晚的院子里，她坐在他腿上翻出手机里那张人格记录表，听他一个个讲：小黑猫源于两人共同投喂厌厌的记忆，潜意识里期待变成一只猫在小巷风雨无阻地等一个穿白裙子的女孩；克莱因蓝蝴蝶是家门口被泼红油漆那天，浓雾里落在他肩上的那只——他觉得是自己亲手吹灭了那道救赎的光、掐死了那只蝴蝶；6岁的小智手里捏着一支没削过的全新铅笔在没开灯的房间里发呆，那不是在画画，是在等一个会画画的人，他简洁地说"我希望自己在很小的时候就遇见你"，她答"我也想""但是现在也不晚"；孪生兄弟宋莱宋榭里，打架的哥哥爱吃苹果味跳跳糖是她买过的那种，书呆子弟弟则源于她看着他桌面的奖状惋惜地说"你不读书很可惜"；43岁的许惠柔是唯一的女性人格，疼爱女儿、从不强迫，周念说"感觉你是想当我的妈妈"，他故作轻松说"当爸爸也行"，被她拍了一下，随即认真地说如果你是我的女儿我一定把你养得很好，最基本的就是饮食自由。她把手机塞给他撒娇要他讲每一个，他笑着说"我只讲一遍"：27岁的夏尔澈话痨、开宠物店，是因为她说过以后想开宠物店；32岁的顾无白是牙医，源于17岁陪她拔牙时医生手重、补了麻药她还是痛，他想换成自己一定会特别轻；41岁的老墨把橘子当招牌水果卖，是因为她给他送过橘子——她抢答对了，他便讨一个吻，她飞快在他唇角啄了一下被评价"偷工减料"，催他继续；游暗是营养师、和许惠柔一样希望她身体健康，桑遣是血站工作人员，爱抱怨"头天刚来抽了300cc，第二天又来，不给抽就不走"，她恍然大悟那就是他卖血时的亲身经历。最后剩阿烈与沈拂南：他指着"近段时间在忙着抓扒手小偷"那行问她记不记得那封信——那天她在暴雨的火车站等他，绝望中看见一个陌生男人扔掉一张纸，那正是她写给他的信；他说扒手偷走了装着你那封信的钱包，我甚至都没来得及打开看过，她这才明白自己当年误会了他毁约。至于沈拂南，她已完全明白那是为了逃出生天而必然出现的人格，他拨开她脸庞碎发说如果不从善进出去就见不到你，所有副人格都和你息息相关，若没有强烈想见你的冲动，沈拂南就不会存在；他倏地吻住她，长时纠缠后在她耳边哑声说："念念，我比你想象中，还要爱你。"

**关键事件**：1. 修好的智齿项链与由她来戴 2. 《我和身体共用者们的对话选段》 3. "因为我每天都在挨打" 4. 多个人格写下的"想出去" 5. 幻视中的念念与一整页的名字 6. 谁能冒充他认错 7. 第十三级魔鬼阶梯 8. 沈拂南登场的条件与四年的沉睡 9. "你要救我，还是要毁灭我" 10. 十二个人格与她的渊源逐一拆解 11. 被扒手偷走的那封信 12. "我比你想象中，还要爱你"

**逐章写法公式**：

- **情绪流向**：起：温馨（修项链、由她戴上） → 承：压抑（日记里的挨打、想出去、幻视与求救） → 转：紧张（谁能认错、第十三级阶梯、沈拂南开出条件） → 合：甜与悲伤交替（十二个人格逐一归因为她，与那句"我比你想象中还要爱你"）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：授权（她先自我设限，他给看） + 日记体回放（用日期与字迹把发病过程摊开） + 院中拆解（十二个人格逐一对号入座） + 误会翻案（把火车站那封信的真相留到最后）
- **本章核心技巧**：用"文本中的文本"承载全书最重的创伤——日记既提供多种字迹的物理证据，又用第一人称对话代替叙述；随后把同一份设定在院中现场重新拆解一遍，让每个副人格都挂靠到一件与她有关的旧物上，信息重复而不累赘。
- **卡点与伏笔**：结尾卡点：十二个人格已全部归因为她，"十三级"与沈拂南的存在也都解释完毕，下章期待是善进相关的人与事如何收束（校长上头有人、学校可能恢复营业）；埋设/回收伏笔：智齿项链（修复并重新戴上）；《我和身体共用者们的对话选段》（本章首次翻开）；"十三级魔鬼阶梯" ↔ "十三重人格分裂，重重爱你"（同章首尾呼应）；桑遣=卖血时的血站人员（回收第113章献血证）；红油漆与克莱因蓝蝴蝶（回收旧场景）；火车站被偷的信 ↔ 当年"毁约"的误会（翻案）；沈拂南的登场条件 ↔ 第114章"其他一个人，不是我"去认错（对上）；韩青"学校可能恢复营业"待回收。

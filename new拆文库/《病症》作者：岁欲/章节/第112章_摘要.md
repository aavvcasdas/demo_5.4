# 第112章 病症 摘要

**概要**：周念站着、鹤遂坐着，用单薄的身体接住他崩溃后摇摇欲坠的重量，他把脸埋进她心口，大手环紧她的腰、另一只手按着她的后背，抱得她骨头发痛；她一下下摸他的头像安抚被雨淋湿的狗，中间郁成推门看见两人抱在一起，转身快得像阵风。她看着他潮湿的黑眸说"鹤遂，我会一直陪着你"，并加重语气重复"一直，一，直"，随后俯身依次亲他的额头、眼角、鼻尖，最后吻住他的唇，还把他的下唇咬出血——她故意让他痛，想用痛把他从那片死海里拽出来；腥苦的血味在两人唇齿间蔓延，他吃痛也不皱眉，反而仰颈把自已送上去。房间里两人做了一次，尾声在八十分钟后来临。洗澡时周念借着水声开口：在东济时她问过他，沈拂南进组是2014年1月，而他2013年6月消失到12月，中间六个月一直被关在善进学院，沈拂南是帮他逃出来的人；他只用一个"嗯"把千万内情轻描淡写地隐去。韩老说过他其余12个人格就是在那六个月里分裂出来的，韩青被关两周出去就患上严重抑郁，他被关了整整六个月。她问"所以也不是你不想找我对吗"，他答"只要是我清醒的时刻，我就从没放弃过走向你"，又说从那个地方出来后自己真的太虚弱，压制关系让他被沈拂南压制整整四年。洗完澡穿好衣服，郁成在门外拍门说门口有警察找，鹤遂没抬头就说了三个字"找我的"。下楼时周念问他知不知道警察找他什么事，他说"最好别是我想的那样"。堂屋里站的是当年处理他打架的卢国强和徒弟段武，卢国强仰脸望着楼梯上的他，拿笔记本在腿上拍了两下说"你小子现在很可以啊"，拍他肩膀时又补一句"从四年前是这个姑娘，现在还是这个姑娘，我佩服你是个爷们儿"，周念察觉这位警官此次对鹤遂有种此前没有的长辈式亲和。段武说市里最近查封了那地方，卢国强接话：小镇上也有不少孩子被送去过，查封时发现旧物，让他们物归原主、顺便核实情况，需要鹤遂去趟所里。他长长吁出一口气，说去一趟可以，但需要周念全程陪着——没有她，他连走到阳光底下的勇气都没有；段武提醒做笔录不允许陪同，被卢国强一句"又不是审犯人"打断放行。走出堂屋时卢国强盯着周念重复"小丫头，做好心理准备"。警车穿过扛设备、举话筒的人群，上车时卢国强袖子被一个激动的男粉丝蹭上眼泪鼻涕，他嗤笑着讲起旧事：那会儿鹤遂蹲在饲料店门口抽烟，老板报警说对视一眼就害怕。车越近派出所，鹤遂越不对劲，宽敞后座里他瑟缩在靠窗位置，盛夏里冷得交叉双臂抱紧自己，目光恐慌地想摸车门开关；周念一把按住他，连说三个"一直"才让他缓过来。他艰难开口"我害怕"，怕的不是直面深渊，而是她看见那些东西后不要他；周念用两只手捧着他的手说"我的心不会变"，他终于沉声说"只要你陪着我，那我就什么都不怕"。

**关键事件**：1. 站立与坐姿的拥抱 2. "我会一直陪着你"与三个"一直" 3. 咬破下唇的吻 4. 浴室里对上的六个月时间线 5. 一个"嗯"隐去的内情 6. "从没放弃过走向你" 7. 卢国强与段武上门 8. 市里查封了那地方、物归原主 9. 去可以，但要周念全程陪着 10. "做好心理准备" 11. 车里瑟缩发冷想逃 12. "我害怕，你看见那些东西后会不要我"

**逐章写法公式**：

- **情绪流向**：起：心疼（抱住崩溃的他） → 承：压抑（六个月的时间线与四年压制被对上） → 转：紧张（警察上门、点名要他去所里） → 合：悲伤中带坚定（"我怕你不要我"与"只要你在我就什么都不怕"）
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：安抚与承诺（给他留下来的理由） + 浴室追问（把旧日空白补成时间线） + 警察上门（外力把他推向最不想面对的地方） + 陪同条件与车中崩塌（用恐惧换一次关系的确认）
- **本章核心技巧**：把最重的心理创伤放在"去派出所"这个外部动作上推进——先让角色主动提出附加条件暴露软肋，再让他在密闭车厢里失守，情感确认因此有了一个具体的物理场景。
- **卡点与伏笔**：结尾卡点：卢国强反复叮嘱"做好心理准备"却始终没说要核实什么，警车正驶向派出所，下章期待是那批"旧物"究竟是什么；埋设/回收伏笔：韩青两周抑郁 ↔ 鹤遂六个月（本章对照，量化善进学院的伤害）→ 为派出所的物证做铺垫；回收第111章"善进学院"与沈拂南"那个地方"的悬念；"十二个人格在六个月里分裂"由韩老旧话坐实；卢国强"打火机/未成年抽烟"的旧事为他对鹤遂的长辈式亲和提供来源。

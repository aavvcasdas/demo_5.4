# 第64章 病症 摘要

**概要**：鹤遂长腿一迈站到周念面前，用肩背挡住她的视线，第二次向男护工伸出左手，说"趁我还愿意好好说话之前，把手机拿出来"，男护工脖子上冒了一圈汗仍不肯交，另有人上来劝说是误会。鹤遂忽然笑了一下说"行"，随即豁然伸出右手揪住男护工的深蓝色圆口衣领，把人整个提起来、双脚离地，周念看见他手背暴起的青筋，也看见他右手手腕侧面和指骨处的两处绷带都开始渗血，提醒他"你在流血"却没有得到回应。手机终于脱手下坠，被他眼疾手快接住，屏幕上是肥大病号服领口微敞的偷拍照片。周念难为情地说"你不要看了"，他淡淡扫过一眼就挪开视线，并对起哄的男患者说"还能给你看不成"，随后喊来郁成把手机抛过去让报警。男护工央求别报警、说以后会改，被他反问"狗哪改得了吃屎"，并被指出"在精神病院里性骚扰女患者的男护工，罪加一等""瘦得只剩一把骨头的小姑娘，你也要欺负"。男护工的第一次道歉不诚恳，被他一句"要我教你道歉是不是"逼到重新连连道歉，随后警察赶到把人带走。护士站重新包扎时，郁成翻来覆去说他反常，举出拍《六十六道》时男二男三打架他只坐在旁边喝茶连眼神都没给，又提起他病房里住着双相、厌食症和精神分裂三个病人，被他反问"那你是没见过更吓人的"，最后郁成神秘兮兮地问他当时耳朵尖是不是红了。入冬后白昼变短，周念开始恢复自主进食、不再管饲，社工在食堂当众夸她恢复良好。她在天桥上看见楼下花园里鹤遂拉贝多芬《D大调小提琴协奏曲》，观众一如既往地多，她悄悄退开。回病房洗澡时她看了好几眼镜子，仍不明白那晚的他为何要打碎它，随后在病房地上捡到一张龙飞凤舞的纸条，写着"你别太过分，我已经仁至义尽""休想再要得更多，贪心的人可什么都不配得到"，她发现字迹与鹤遂剧本上的笔记一模一样，以为只是台词。她把纸条还给他并道谢，得到的回答是"你真想谢我，就少来烦我，离我远点"，她则重申除非他给出真相，否则在他离开前都会缠着他，他答那些都已经不重要，笑意里带嘲弄地说"你都说了，是对你很重要"。

**关键事件**：1. 第二次伸手要手机与"趁我还愿意好好说话之前" 2. 揪住衣领把人提离地面、两处绷带渗血 3. 手机里的偷拍照片与"还能给你看不成" 4. "狗哪改得了吃屎"与道歉被逼到诚恳 5. 郁成举《六十六道》为例说他反常、问耳朵尖是否红了 6. 周念恢复自主进食被社工当众夸奖 7. 天桥上看见他拉《D大调小提琴协奏曲》 8. 地上的神秘纸条与"少来烦我，离我远点"

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |

**逐章写法公式**：

- **情绪流向**：起：紧（第二次伸手要手机的僵持） → 承：怒（揪衣领、渗血的绷带） → 转：爽（照片被扣下、报警、逼出道歉） → 合：冷（"少来烦我，离我远点"与"对你很重要"）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：第二次伸手要手机（把僵持再推一层） + 揪衣领提人（用动作结束谈判） + 接住手机与照片（把证据落到实物） + 抛给郁成报警（把处置交给制度） + "狗哪改得了吃屎"与逼道歉（把公道收齐） + 护士站里的反常对话（用旁观者加固疑点） + 恢复自主进食与社工夸奖（写身体在好转） + 天桥上看拉琴（用观众数量写距离） + 地上的纸条与剧本笔记（埋一条字迹伏笔） + 道谢与"少来烦我"（把冷话说尽） + "对你很重要"（把真相变成单方面的需求）
- **本章核心技巧**：用一个完整的"取证—报警—道歉"小循环收掉偷拍事件，同时把两处需要延续的线索塞进日常缝隙里——郁成口中的"更吓人的"与地上那张字迹不同的纸条，都在爽点落地后悄悄挂上钩
- **卡点与伏笔**：结尾卡点：他说"你都说了，是对你很重要"，把她索要真相的资格抽走，她是否还会继续缠着他悬置；埋设/回收伏笔：两处绷带渗血 → 右手伤势反复的持续记录；龙飞凤舞的纸条与鹤遂剧本笔记字迹一致 → 字迹真假的后文对照（第69章出现另一种笔迹）；医院换上新的镜子 → 那晚打碎镜子的原因仍未解答；贝多芬《D大调小提琴协奏曲》与"学琴也不过才数月" → 他的学习能力与时间线疑点
- **时间线**：本章接第63章图书馆偷拍事件当日，延伸至入冬后周念恢复自主进食的一段日子

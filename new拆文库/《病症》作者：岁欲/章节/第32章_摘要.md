# 第32章 病症 摘要

**概要**：周念吐了鹤遂一身——不只是衣服和裤子，还有他的脚，而他穿的是双人拖。她僵在原地说不出话，嘴巴像被胶水粘着，两只手臂还被他握着，他的手指没有丝毫松力，依旧维持着牢牢接住她的力度；她以为他要生气，头顶落下的却是清冷平静的一句"周念，你这么小一只，早餐是吃了多少？"。她试探地问"你不生气吗"，他漫不经心低头看一眼身上秽物再看向她，反问"我应该生气？"；她放松后开始道歉，他则低头看地上的呕吐物，意味深长地问"周念，你吃东西都不嚼，直接咽？"——这句话让她心中咯噔一下。没等她答，他把脚从呕吐物里抽出来，逐一报出内容：今早吃了稀饭、火麻子稀饭、整只的馄饨，还有笋或者莴笋、以及饼状物；他俯身与她近距离对视，一字一顿认真问"你真能吃这么多？"，她紧张得哽了两秒才磕巴答"我，我食量比较大"，他不动声色地细究着说"我早上都吃不了这么多东西，看不出来啊周念"。她招架不住，借口用厕所，他淡淡说"用我房间里的"。她进去后，鹤遂拿来笤帚和铁戳子、又在院子里弄了灰土倒在呕吐物上，扫干净后又把门口拖了两遍，整个过程有条不紊、没有丁点厌恶和不耐烦，像对待一件极为平常的事情；最后他提起她落在门口的画具箱和画板进了门。周念蹲在他房间里那间干净简单、只有蹲厕的厕所旁吐了很久，最后连胃酸和胆汁都吐了出来；散在身后的长发总滑到脸颊和胸口，她只能一边撩一边吐。又一次头发滑落时，她刚要抬手，眼角余光里出现一只骨瘦的冷色大手——鹤遂弯着腰站在她身后，微凉的长指轻柔地替她把头发撩起、顺在脑后，指腹轻轻路过她的颈部，帮她握住头发，他的手就成了一根头绳。她鬼使神差转头，撞进他俯面望来的眉眼，时间就此凝固；厕所里只有一只昏黄色灯泡悬在他头顶，顶光而站的他脸孔格外清冷。此后经年周念都没办法忘记这一刹那的对视，她心里很清楚——他知道了她最见不得光的秘密。鹤遂先开口说"你没有关门"，另一只手递来一卷卫生纸，说是想到厕所没纸就给她拿来了；周念没接纸，狼狈地飞快转回脸，声音颤抖着说"鹤遂，你别看我……我不想让你看见这样的我"。他什么都没说也没离开，把纸反手放在盥洗台上，缓缓在她身侧蹲下，一手握着她的头发、另一只手轻轻落在她背上，自上而下地抚着她的背部安抚她、时不时拍拍背，同时摸到她背上嶙峋的骨头，每一块都硬得咯手。一连串细节在他脑子里串联起来——医院里宋敏桃买早餐时她吃鸡蛋吃得很勉强，上次她来家中他拿青团和牛奶她都百般推辞，今天这么瘦的她胃里居然能吐出这么多东西——他全部都搞明白了。那天厕所里从头到尾弥漫着诡谲的沉默，除第一句话外他没再说一个字，只是安静等在旁边，递纸、拿来画具箱里的漱口水、拿毛巾打湿给她擦汗，做完就靠在厕所门口默默等着。她擦完脸后情绪反扑，失控蹲在地上抱住头、用力扯自己的头发，鹤遂赶紧伸手握住她的手腕制止，她挣不脱，带着哭腔说"你一定会觉得我是个怪物吧"，他弯着腰单手撑在膝头说"我没那样觉得"，又让她到房间休息冷静一下、让他洗个澡。他把她从地上拉起来、松开手腕说"别扯头发，你也不嫌疼"；进厕所前他背对着她清晰地说"周念，我很庆幸，发现的是我，而不是其他人"，她反复琢磨这句话，不明白他为什么会觉得庆幸。他不到五分钟就洗完出来，她迫不及待追问那句话是什么意思，他薄唇微弯露出很醒目的浅笑答"字面意思？"，被追问后又一字一顿格外认真地说"静，夜，思"。她一时忘了难过和窘迫，站起来在他胳膊上拧了一把说"你不逗我会死吗"，他丝毫不躲、吊儿郎当笑道"我宁肯看你这样，实在难得看你刚刚要死不活的样子"——她手上的力气立马减缓，明白他不是在逗她，而是在想办法让她开心起来。

**关键事件**：1. 呕吐物溅满鹤遂全身与门口 2. 他逐样报出她早餐内容并追问"你真能吃这么多" 3. 他清扫门口、毫无厌恶 4. 他在厕所替她握头发、对视 5. "他知道了"与"我不想让你看见这样的我" 6. "我很庆幸，发现的是我"与"静，夜，思"

**逐章写法公式**：

- **情绪流向**：起：绝望（吐他一身） → 承：惊讶（他不生气、报出早餐清单） → 转：破防（厕所对视、被抱背安抚、扯头发崩溃） → 合：被托住（"我没那样觉得" + 洗完澡的玩笑）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：呕吐暴露与他的平静反应（用反差压住羞辱场景） + 早餐清单的当场拆穿（把秘密从"疑似"变成"确认"） + 他清扫门口（用劳动证明接纳） + 厕所里的握头发与对视（关系质变的关键定格） + 崩溃与安抚 + 洗澡后的对话（把沉重收进玩笑）
- **本章核心技巧**：全章只用两个动作推动关系——他"握着她的头发"和"抚她的背"，其余全是沉默与打扫；把病症的暴露写成一个被照顾的场景，秘密的重量就在服务性动作里被卸掉
- **卡点与伏笔**：结尾卡点："我很庆幸，发现的是我，而不是其他人"与"静，夜，思"（他已知情，后续如何对待她的病成为新看点）；埋设/回收伏笔：医院鸡蛋、青团牛奶、今天的早餐量三条细节被串成一条链 → 回收此前所有"她不吃"的伏笔；"发现的是我而不是其他人" → 指向后面他替她保守秘密与更深的原因；周念的画具箱被提进门 → 写生之行继续

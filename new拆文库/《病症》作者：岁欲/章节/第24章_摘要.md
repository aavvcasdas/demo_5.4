# 第24章 病症 摘要

**概要**：周念在小吃店主动笑着打招呼"鹤遂，好巧"，鹤遂面无表情地看了她一眼又看了一眼罗强，冷淡收回目光；周念的笑容瞬间凝住。他不看她、不应声，低头快速收拾上一桌的盘碗和两只倒着的北冰洋空瓶，端着东西转身进店，一副不认识她的样子。周念第二次搭话被他直接走过，第三次结结巴巴说"你出院了呀，真好"时，他把湿抹布"啪"地甩在桌上，擦桌子的力气大到小木桌笃笃撞地像在震；她小心上前问他是不是谁惹他不开心，他豁地抬脸反问"跟你有什么关系？"，她像被兜头浇了凉水。点单时罗强要一份炒面、叮嘱少辣不要葱花，周念说"我不吃"；她本想买完就走，因为他在这里打工又改主意坐下等机会。炒面端上来葱花还在，罗强抱怨鹤遂没听见，鹤遂没搭理。周念借递十块钱的机会问他几点下班，得到的是"和你有关系？"。罗强忍不住追上去骂他欠收拾，鹤遂骤然转身、攥着被捏变形的十块钱逼视他并挑眉挑衅，罗强想起他咬下肖护半张脸立刻服软回座；随后那份炒面被放足红油和小米辣，辣得罗强鼻涕眼泪一把还硬撑。周念走到油烟气呛人的锅边向老板打听，得知他下午三点下班。两点五十分她提前站在对面糖画摊旁，花八块钱转了一次转盘，心里念着千万别转到狗，指针偏偏停在狗头上，她拿着一只糖小狗等他下班。周念追着他不肯停步的背影跑进小巷，被一块半翘起的青石板绊倒，仍攥着竹签没松手；一阵皂香的风过后，本该走远的鹤遂已经蹲在她面前，皱眉说她"怎么能这么笨"，然后握住她一侧肩膀低声让她起来。

**关键事件**：1. 鹤遂全程冷待、甩抹布擦桌子 2. "跟你有什么关系？""和你有关系？"两次拒绝 3. 罗强追骂被挑眉逼退 4. 炒面被加满辣椒报复 5. 周念打听出他三点下班并转盘转到糖小狗 6. 巷中摔倒，鹤遂折返蹲下扶她

**逐章写法公式**：

- **情绪流向**：起：失落（打招呼被无视） → 承：难堪（三次搭话、递钱问下班都被顶回） → 转：倔强（请教老板、转盘、买糖狗、追进小巷） → 合：暖（他折返蹲下、攥住她肩膀让她起来）
- **节奏配比**：慢铺垫 30% / 快冲突 45% / 爽点爆发 5% / 悬念留白 20%
- **本章结构公式**：三次搭话被拒（把冷落写足） + 旁人在场的误会与小型报复（用罗强承担喜剧与冲突） + 打听下班时间 + 转盘买糖狗（她单方面的靠近） + 巷中摔倒与男主折返（用一次摔倒完成关系回温）
- **本章核心技巧**：全章让男主只说两句冷话、做一个动作（甩抹布），却用"他走远了又无声折返蹲下"完成人物反转——冷漠用行为堆，回温只用一个动作
- **卡点与伏笔**：结尾卡点：他握住她的肩膀说"起来"（下章两人近距离独处的第一个场景）；埋设/回收伏笔：被捏变形的十块钱（他对她的钱的敏感）→ 指向他的穷与自尊；糖小狗没有被接走仍在她手里 → 未完成的礼物；"你是周念，你怎么会随便请人吃东西" → 指向他早就认识她的过去

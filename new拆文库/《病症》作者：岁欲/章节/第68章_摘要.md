# 第68章 病症 摘要

**概要**：热搜撤得很快，鹤遂离开花园十分钟后相关词条就全部消失，莫奈说顶流团队动作就是快。周念舔了舔发干的唇尝到轻微腥甜，眼睛还在看那串延至远处的血迹，并意识到自从他住进来以后就总在受伤。莫奈问她是否真不打算把照片给解渤腾，她想起关于三千万的生意谈判不由笑了一声，只说"突然很想回到从前，再见一见十七岁的鹤遂"；莫奈仍不甘心，说他红得可怕、照片曝光顶多掉一两个代言，甚至可能一个都不掉，周念答不是床照、只是普通合照——他们之间最亲密的行为是象征救赎的深拥，以及十八岁时在月光照不到的阴影里那个隐忍克制、浅浅一下就抽离的初吻，除此之外他再无逾越。她解释报复或许能让她好受一点，可之后他会依旧站在高处闪耀发光，反倒把报复和她都衬成笑话。话说到这里，手机震了两下，一条银行短信显示她的储蓄卡收到三千万元。她匆匆赶回病房，人却不在，便挪到护士站，才从护士们的闲谈里得知他是在花园散步时摔了一跤、手掌按在草坪里隐着的碎玻璃上、掌心被划了老长一道口子，她隔着人群看见他坐在治疗台上由护士用镊子挑出玻璃碴子，双氧水淋伤口时他毫无反应。包好伤他说了句"麻烦了"便往外走，与她视线对上又神色淡漠地收回，她用带着颤抖的尾音叫住他"鹤遂，我们谈谈"，他问"在这儿"，她说"你选地方"，随后两人进了他近段专用的音乐理疗室，她把门反锁。她在钢琴旁开门见山问他为什么打钱，他答不想被解狗抢先一步、与其和他掰扯不如直接和她做买卖，被问是否心虚时低笑说只是"很怕麻烦"；她哽咽质问他对她难道没有一丝愧疚，他一边弹琴一边说"你现在这样，我还真有点抱歉"，又说"抱歉给不了你想要的答案，以及你想要重温旧情的需求""我能给的便只有钱"，并称若嫌三千万少可以再让助理多转一些。她点头又摇头地说"是我赚了，年少的一段经历居然值影帝的三千万"，没有接他递来的纸巾。就在她颤抖着悬指在删除键上时，他轻轻握住她的手腕说"你要真不想删也可以，你保证不让这些照片曝光就行"，她抽回手说"拿了你的钱，替你消灾是应该的"，最终在他面前把三百多张照片一张接一张删掉、又返回最近删除全部清空，前后删了近小半个小时。她问他怎么知道自己的卡号，他说是让助理问的她母亲。她道了谢，说"鹤遂，我们后会无期"，转身离开时肩膀仍在颤抖——这一次，总算是她把背影留给了他。

**关键事件**：1. 热搜十分钟内被全部撤下 2. 关于三千万的谈判与"只是很想再见一见十七岁的鹤遂" 3. 初吻与"再无逾越"的自述 4. 三千万到账、她赶回病房扑空 5. 花园摔跤与掌心被碎玻璃划出的长口子 6. 音乐理疗室里的对话与"我能给的便只有钱" 7. "你要真不想删也可以"与被握住的删除键 8. 三百多张照片删近半小时、"我们后会无期"

**逐章写法公式**：

- **情绪流向**：起：静（热搜被撤、腥甜、看那串血迹） → 承：痛（三千万到账、掌心伤口） → 转：冷（理疗室里"我能给的便只有钱"） → 合：断（删完照片、"我们后会无期"、她留下背影）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：热搜被撤与看血迹（把上一章的爆点收冷） + 关于三千万的谈判与"再见一见十七岁的鹤遂"（交代她真正想要什么） + 初吻与"再无逾越"的自述（给关系定性） + 三千万到账（把交易坐实） + 赶回病房扑空、转去护士站（制造空场） + 护士口中的摔跤与碎玻璃（交代新伤） + 理疗室内谈钱（把关系推成买卖） + "我能给的便只有钱"（把答案判死） + 递纸巾与"心疼你的趋势"（给一点假的暖） + 握腕与删除照片（用仪式完成告别） + 问卡号与"让助理问的你妈"（写他的另一手准备） + "后会无期"与留下背影（换手收章）
- **本章核心技巧**：整章是"分手仪式"的写法——先让外部爆点降温，再用一场私密的关门对话把关系摊到桌面上，最后用删照片这一套可数的连续动作把告别变成可验证的事实；夹在中间的掌心伤口与"心疼你的趋势"提供了两处反向证据，使"冷到底"并不彻底
- **卡点与伏笔**：结尾卡点：她留下背影离开、说"后会无期"，但两人都还在医院、他也还在受伤，重逢必然；埋设/回收伏笔：三千万由助理问她母亲要来的卡号 → 他仍在动用手上的关系；花园摔跤与碎玻璃 → 与前文"总在受伤"叠加，持续指向他自身的问题；被全部删除的三百多张照片 → 与第72章他派人来索要智齿项链形成对照（能删的都删了，删不掉的他偏要取回）；"心疼你的趋势" → 一句貌似玩笑的自陈，后文被反复验证
- **时间线**：本章接第67章热搜爆发当日，延伸至当日傍晚

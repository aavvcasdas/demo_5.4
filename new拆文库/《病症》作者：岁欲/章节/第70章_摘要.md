# 第70章 病症 摘要

**概要**：晴好的初冬阳光铺进病房，只有周念的病床和放着万年青的墙角是暗的，她整个人也灰暗了无生气，在明媚灿烂、有父亲疼爱、又被鹤遂百般迁就的生雅娇面前对比格外刺目。卫生间的门打开，穿上那套量身定做的黑色西装的鹤遂走出来，耀眼得让沉痛中的周念也一瞬丢了呼吸，生雅娇尖叫着扑上去夸"帅死了，阿遂哥简直就是女娲毕设"，把他拽到生东返面前宣告"放眼整个内娱，还有比阿遂哥更帅的男人么？我宣布——没有"，引得生东返大笑、郁成也跟着乐。周念试着站起来却因双腿无力重新跌回床上，再铆足力气起身时直接摔到地上，病房里的欢声笑语骤然停下，几个人同时看过来，生雅娇小声问要不要叫护士，郁成毫不避讳地说"不用管她啦""神经病一个"。生雅娇拉着鹤遂去阳台拍照发朋友圈，他回头对生东返说了句"生爹，你看她"，周念只听见"生爹"这两个字，由此明白他们关系深厚；她看着生雅娇像从前她画画时那样指挥他摆造型，想起他说过的"念念想怎么画都可以，我都配合"，终于扶着床沿逼自己逃出病房。她扶着过道扶手直奔主治医生王学知的诊室，在门口听见护士们议论生雅娇"爸爸是国内最牛名导、男朋友是圈内定海神针般的顶流影帝"，脸上没有表情也没有要哭的迹象，只弯了弯唇笑——哭是一件很痛的事情，笑比哭更痛。王学知回来后她提出出院，被以路都走不稳、体重还没到七十为由拒绝，她哽咽说"可是我不想治了"，王学知沉默良久，让她去和母亲商量、由母亲来跟他说。周念心里清楚，这样的身体状况出院几乎是任她自生自灭，九成的几率是死亡，她仍向王学知致谢告辞。出诊室便遇见来找她的冉银，她让冉银今天找时间跟王医生谈、让他同意她明天出院，冉银追问为何这么急，她只说"我想回去了"，回到花楹镇、回到最初和他开始的地方。走廊里鹤遂一行人走来，生雅娇笑说起当年生东返找鹤遂拍戏时，他答"你是个诈骗犯"并让对方滚，周念愣住，开始怀疑他当初没来赴约是否另有苦衷，便追上去按着胸口喘着叫他，问他"你当初没有来是有什么苦衷对不对"。鹤遂只小幅度回头、用眼角余光看她，说"我以为，我已经把话说得很清楚了"；她追问"你明知道我经历过什么的，你明知道我爸爸他被——"，被他一句"小事"逼到哽咽。围观的家属拿出手机拍照被郁成拦下，她脑中闪过"周七斤，七七四十九斤""念念，我们万年长青""念念，别怕""念念，我会带你逃出这个小镇"的幻听，抱头嘶吼"滚——！"。生东返让鹤遂"处理一下"，她抢先说自己明天就会走、不会成为他的负担和绊脚石，随即被鹤遂握住手腕扯进旁边的楼梯通道。昏暗里她后背抵着铁门、下巴被攫住，听他说"你真的很他妈缠人""三千万都买不了你闭嘴"，却瞥见他衬衫领间那根黑绳，认出那是自己那颗智齿，问他为什么四年都戴着、是因为想戴着还是因为不好解开。鹤遂松开她的下巴，反手扯开衬衫领口，毫不犹豫地把黑绳大力扯断，扬手把牙齿扔给她，说"不就是一颗破牙齿？还给你就是了"。

**关键事件**：1. 换上西装的鹤遂现身与全场的欢呼 2. 周念两次站起失败、摔在地上与"神经病一个" 3. 生雅娇的指挥与他那句"念念想怎么画都可以，我都配合" 4. 护士们在诊室外议论生雅娇、她笑比哭更痛 5. 王学知拒绝出院并让她与母亲商量 6. 生雅娇说出当年鹤遂拒戏的原话 7. 走廊里的追问、幻听与"滚——！" 8. 楼梯间里"三千万都买不了你闭嘴"与扯断智齿项链

**逐章写法公式**：

- **情绪流向**：起：暗（病房里只有她和墙角是暗的） → 承：辱（两次摔倒、"神经病一个"、旧场景复刻） → 转：求（求出院被拒、执着追问苦衷、幻听尖叫） → 合：断（楼梯间扯断智齿项链、"还给你就是了"）
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：光与暗的对照（用环境写落差） + 西装登场与全场欢呼（用别人的热闹加重她的失语） + 两次站起失败（把身体问题推到台面） + "神经病一个"（用旁观者的冷话刺穿） + 阳台拍照与旧造型场景（用镜像复刻旧情） + 逃去诊室与护士议论（把落差再放大一次） + 求出院被拒与"九成死亡"（把决定写重） + 遇见冉银与"我想回去了"（坐实去意） + 生雅娇复述拒戏原话（埋下苦衷的可能） + 走廊追问与"滚——！"（情绪崩断） + 被扯进楼梯间与"三千万都买不了你闭嘴"（把冲突封进密室） + 智齿项链被扯断扔还（用可物证的极端动作收章）
- **本章核心技巧**：把整章的压迫感挂在"对照组"上——同一个病房里生雅娇被捧被宠，周念被摔被无视；等她被逼到公开崩溃，作者立刻把她拖进一间关起来的楼梯间，让最私密的一件旧物（智齿项链）在最坏的时机出现，接住全部情绪
- **卡点与伏笔**：结尾卡点：黑绳被扯断、牙齿被扔还，她握着这颗牙会怎么处置、他又为何戴了四年都悬置；埋设/伏笔线索：智齿项链被戴四年 → 与第72章他派人专门来索要形成强回扣；生雅娇复述的"你说他是个诈骗犯，还让他滚" → 指向当年拒戏的隐情；幻听里的四句话（周七斤七七四十九斤/万年长青/别怕/带你逃出小镇） → 与"四年前"的失踪形成对账；"生爹"的称呼 → 关系深浅的标识，第80章他改口叫"生导演"时形成对照；周念当众说"我明天就会走的" → 为第71章离京佛返乡埋线
- **时间线**：本章接第69章清晨的西装事件，延伸至当日下午

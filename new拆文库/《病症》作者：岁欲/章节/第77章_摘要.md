# 第77章 病症 摘要

**概要**：房间里的五个人都看得出鹤遂此刻有多狼狈——脸色苍白如纸，额头冷汗一颗比一颗大，捂在腹部的手指缝间已渗出血，他却连呼吸都不肯加重，生怕惊扰床上的周念。郁成拨开冉银走到他面前说"流这么多血，得马上去医院啊"，被他以"不用"回绝；郁成见劝不动他，便转而对周念说"你劝劝遂哥吧"，周念只回"我何德何能劝得动你的老板，我不过就是一个疯子而已"——这是在记郁成先前几次出言不逊、还骂过她疯子的仇，郁成立刻变得能屈能伸，道歉说"之前是我出言得罪，您不要和我一般计较"。冉银则趁机数落，说他当初不信"这条疯狗成天追在我女儿屁股后面跑"的说法，又阴阳怪气地问鹤遂是从哪里赶回来的、会不会是洛杉矶；郁成心里清楚，的确就是洛杉矶。他随即想起3月11日的奥斯卡颁奖典礼：主持人宣布最佳男主角是鹤遂时，镜头只拍到一个空座位，满场皆惊，生东返上台代为领奖，而他发疯般在杜比剧院里找人，最后在洗手间找到——深褐与白相错的盥洗台淌着血，白色洗手池上布满血手印，空气中是浓烈的腥苦味，西装革履的鹤遂躺在血泊里，右腹部插着一把匕首，半张脸贴在粘稠的血地上。他艰难地转头看向洗手台上那面被擦得极干净的大镜子，镜子正中间用鲜血写着四个触目惊心的大字——【放我回去】，血还顺着笔画往下流、写得歪七扭八。回到当下，郁成又劝周念"您劝劝遂哥吧，这样下去真的会死人"，周念把脸转向窗外说"别死在我这里"；郁成只能蹲下劝鹤遂"要不我们养好身体再来"，被他低声回"我不走"，听到"不要命啦"时无一丝犹豫地答"不要了"，周念的眼皮几不可察地跳了一下。僵持中鹤遂扶着床沿艰难站起身，把冉银单独叫了出去。他在走廊上走进那间门没关的画室——四年前他踏进来时画布蒙尘、笔具染灰、入目皆是颓败的灰暗色；他问"她不画画了"，冉银说"早不画了""自从四年前找不到你开始，就没画了"。他想到周念背着画板走在青石板路上、模样无忧、裙摆洁白、梨涡浅浅的样子，再看这间满是灰尘的画室，只觉窒息。他对冉银说"我要带她走"，被坚决反对后冷冷反问"非得看她死在你眼前才甘心"，并说明自己不是在征求意见、只是知会一声，希望她到时不要阻拦。之后他安排郁成去找一家私人医院，也被霍闯拦住劝说——如果最后还是会离开，就不要再招惹周念姐姐，她真的经不起一点折腾了；他盯着木楼梯上的一道裂缝低声说"我不会离开了""再也不会了"。霍闯临走前说"周念姐姐真的很可怜，你都不知道周念姐姐失明前最后看到的画面是什么"，却又说"算了，也没什么意义了"，留他一个人在走廊上反复猜那句话的意思。这天雨落了下来，暴雨倾盆的小镇上少见人烟，一辆从市里来的救护车历时两小时驶进北清巷、停在周家门口；鹤遂挡开要来抱周念的医护人员，用被子把她裹好抱起来就下楼，脚步沉稳有力却是一种色厉内荏的虚张声势，从小腹处流出来的血已经染到被子上。周念从被子里抽出一只手想推开他，却摸到一手的黏腻潮湿，才反应过来自己刚才那一脚把他的刀伤踹裂了，而他现在还在流血。与此同时，他低沉温凉的嗓音从头顶落下："念念，我会治好你。"

**关键事件**：1. "不用"与"你劝劝遂哥吧" 2. "我不过就是一个疯子而已"与郁成的道歉 3. 冉银的阴阳怪气与"不会是洛杉矶吧" 4. 杜比剧院洗手间里的血、匕首与镜上的"放我回去" 5. "我不走""不要了"与周念眼皮的一跳 6. 画室里的灰尘与"我要带她走" 7. "我不会离开了""再也不会了"与霍闯的"失明前最后看到的画面" 8. 暴雨里的救护车、"我会治好你"与染到被子上的血

**逐章写法公式**：

- **情绪流向**：起：危（他渗血的指缝与不肯加重的呼吸） → 承：僵（劝不动、道歉、阴阳怪气） → 转：暴（洗手间的血、匕首、镜上四字） → 合：动（画室、"我要带她走"、暴雨中的救护车与"我会治好你"）
- **节奏配比**：慢铺垫 20% / 快冲突 25% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：渗血的指缝与"不用"（把伤情亮到台面） + 郁成求周念相劝与她的挖苦（用旧怨写她的态度） + 郁成的道歉与冉银的阴阳怪气（把局面推给旁人） + "不会是洛杉矶吧"触发洗手间闪回（把失踪之谜解开一半） + 镜上的"放我回去"（留下更大的谜） + "不要了"与眼皮一跳（用一个微反应写松动） + 画室里的灰尘与"我要带她走"（把他接下来的行动定下来） + "我不会离开了"与霍闯的半句话（埋下下一个悬念） + 暴雨与救护车（用天气与医疗车辆完成转场） + 抱起她、血染到被子上与"我会治好你"（把救她的承诺落到身体代价上）
- **本章核心技巧**：把男主"为什么会伤"这一层的答案在这一章解开（杜比剧院的洗手间），同时换上一个更大的问题（镜上的"放我回去"往外指）；再用一间蒙尘的画室把他"要带她走"的决定钉死，最后用一场暴雨和一辆救护车把全书从"小镇停滞"推进到"去医院"的新场域
- **卡点与伏笔**：结尾卡点：她被裹在被子里被抱走，他的刀伤正在裂开流血，两人一同被送上救护车，"我会治好你"能否兑现悬置；埋设/回收伏笔：杜比剧院洗手间镜上的【放我回去】 → 与沈拂南这一人格直接呼应（第78-81章揭示）；右腹的匕首与"刀伤" → 与第76章郁成失言对上；画室里"自从四年前找不到你开始就没画了" → 与第63章被撕碎的录取通知书互相咬合；霍闯没说出口的"失明前最后看到的画面" → 第78章揭晓为厌厌的死状；他走进画室时的窒息感 → 第75章"她本该无限荣光"的延续
- **时间线**：本章接第76章当日上午，经午后与暴雨，至救护车驶进北清巷的当日下午

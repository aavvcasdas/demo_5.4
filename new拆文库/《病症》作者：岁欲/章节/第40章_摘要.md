# 第40章 病症 摘要

**概要**：听见鹤遂的告白之后，周念再难找回正常的心跳——他的眼分明清冷，偏偏看向她的目光炙热又浓烈，那一个对视她记了很多年，纵使多年后这同一双眼无比冷漠地看着她、仿若不识，也没能让她忘记此刻的心动；当晚她通宵失眠，不是因为焦虑难过，而是因为兴奋，每一根神经都像在跳舞，耳边反复回响着那两句告白和霍闯那句"你就是喜欢周念姐姐"。她热得掀被子、开窗、躺回床上，脑海里反复闪过他给她撑伞、自然地把外套递给她、毫不避讳地承认喜欢她，她相信她和鹤遂是有以后的。那是一个悄然间发生许多变化的六月：饭桌上她一次又一次尝试拒绝吃自己讨厌的动物内脏、糯米类食物和多刺的鱼，每次拒食都会想到鹤遂给她的勇气；冉银无法接受她的改变，用痛心的眼神说"七斤，你真的很让妈妈失望"，而周念不再心如刀割，她觉得一味服从冉银是一种愚孝、也是对自己的不忠，在母亲的目光下变得越来越坦然自若。当冉银被新阳保险公司拒绝赔偿、其他小公司也有样学样卡住理赔的事缠住时，分到周念身上的精力直接减半，她转身就去打电话，周念饭菜吃不完也草草了事——这种情形下，她每餐催吐的量开始渐渐变少，有一天她欣喜地发现自己居然能做到餐后不再催吐，立刻用老年机给鹤遂发消息【我今天中午吃完饭没有吐诶！虽然我只吃了一点点，但是我没有吐！】，像汲求夸奖的小朋友。鹤遂二十分钟后回了"这么棒？"，她吐槽他"好抠，表扬人都只发三个字"，他坐在手机维修台里连回三条【周念，你很棒。】【上条是五个字。】【还嫌少的话字数还能加。】，看得她抱着枕头在床上来回滚了好几圈；她心疼短信费说一条一角钱、这样发就花了三角钱，他回一个"？"后接着来一句"周念，你真抠"，把她逗得芳心大乱、面红耳赤。而命运擅长焚琴煮鹤——同一间手机店里，老板正和两个店员拿北清巷死去男人留下的寡妇和千万赔偿金说笑，甚至说"那个画画的小姑娘倒是很水灵标志，给她当后爸也很爽啊，说不准，到时候母女两个还可以一起搞搞"，接下来的话全是黄言秽语；鹤遂不知何时出现在他们面前，歪了歪脖子发出一声骨响，俯身近距离看着老板，笑意抽丝剥茧地散开说"我想说——傻逼，你怎么还不死？"，随后一记重拳打在老板嘴上。三个人硬是没打过他一个，老板操起铁凳一下又一下砸在他脑袋上，他不躲不避、连眼睛都不眨，继续用拳头砸在老板脸上，额头很快见血、鲜血蜿蜒切割一张俊脸。下午偏头痛发作的周念（两周前开始犯，左太阳穴像针扎、吃止痛药和冷敷热敷都没用）疼得想见鹤遂，发短信问他能不能过来、还补了一条"我妈妈今天不在家"，他很快回"现在？""好"；她忍着头痛爬起来换下睡裙换上白色连衣裙、又去洗手间洗了头（女生只有见重要的人之前才愿意洗头），吹干梳顺后才下楼开门——看到门外鹤遂的瞬间她的笑容凝固了：他嘴角破损、额头缠着一圈纱布、鼻梁有一道微微肿胀的乌青。她生气又委屈地问他为什么又打架，他说"没事，不疼的"，再问就只说"都说没事了"；她背过身让他走，他绕到她前面说"可是我刚来"，第三次绕过来要拉她的手，她躲开、眼圈发红地说"我没开玩笑，你马上走"，他朝前迈一大步说"你都要哭了，我还走什么走"；他弯腰双手撑在膝盖上仰脸看她，承认"我错了好不好？我不打架了以后，你不要哭"，又低低道"周念，我真是见不得你哭""你一哭，我都不知道该怎么办"。她哽咽着要他保证以后都不打架，他立马站得规规矩矩，认真地说"只要你不哭，我保证——以后都不打架，再打架就让周念永远不理我"。随后他从黑色工装裤侧袋里摸出一个盒子放在她手上说"给你的"——是一台全新手机；她推辞说太贵，他反问"我都能买得起，能有多贵？"，她捧着盒子看着看着又哭了，他捧着她的脸轻轻擦眼泪，调侃"南水河里的水全是你的眼泪"。进堂屋上楼进她房间后，鹤遂看见墙上裱着的那些画、震惊地问"这些都是你画的？"，看了很久后眸光忽然晦暗，笑着问"你说你以后要是成为一个很有名的大画家，会不会不理我了"，又说她以后会是名声大噪的天才画家、会克服困难走向锦绣前程，"而我会继续留在这个小镇里，在小吃店、手机店、装修店里打工，还是人人喊打的疯狗"；周念快步走过去、垫着脚重重抱住他，说她不会因此疏远他、"鹤遂，你对我很重要，真的很重要""我不能没有你"——那是一个和爱情暧昧等字眼无关、只与最纯粹的救赎挂钩的拥抱；他先僵住、周身紧绷，被抱了很久后终于极为缓慢地抬起一只手、长指微微发颤，随后重重覆在她瘦薄的背部，她整个人像要被嵌进他胸腔里，那一刻她感受到他是需要她的，虽然他什么都没说。之后她拆新手机、要他教她用智能机，他逗她"你这么笨，懒得教"，她骂"鹤遂，你是狗吧"，他懒懒笑应"嗯，疯狗"；她学他把键盘切到26键、被他揉了好几次头顶，接着他凑到她耳边问"周念，你该不是为了见我特意洗了个头吧"，她死鸭子嘴硬说没有；注册微信时她想出的微信号是ZNHS1314（周念鹤遂一生一世），把他笑得胸腔发颤，他吐槽"你这和小学生拿着笔在墙上写xx我爱你有什么区别"，但一听她要删掉名字缩写就立刻拦住说"别""挺好的，就用这个"。两分钟后他成为她微信列表里的第一个人、此后很长一段时间也是唯一一个；他的头像是长狭弄那只叫厌厌的小黑猫，两人随后拍了第一张合照——他一手拿手机、一手搭在她身后的椅背上，头挨得很近，她要求他笑，他便薄唇微弯，即便缠着纱布、脸上挂彩也不影响上镜。那台白色安卓机价格一千八左右，却是鹤遂被砸破脑袋、由老板出的医药费外加舍掉一个月工资换来的；那天最后她还是追问打架的原因，他囫囵不过，模糊地说"老板说了你两句不好的，我听不惯"，她想当然以为是议论她太瘦之类，便劝他别为这种事生气，他却皱眉冷声说"不行。就是不能说"——他不让任何人说她不好，哪怕一句都不行；她半开玩笑问他总不能听一个人说她不好就去把人打一顿，他转过脸黑眸沉沉地说"你怎么知道我不能？"。也是那一天，两人心照不宣地把同一张合照设成了手机壁纸——只是后来，他的手机屏保随意换过很多次，却不会再是和她的合照。

**关键事件**：1. 告白之后的通宵失眠与"我们是有以后的" 2. 六月饭桌上的拒食与"你真的很让妈妈失望" 3. 第一次做到餐后不吐与互发的短信 4. 手机店老板的下流话与鹤遂的重拳 5. 偏头痛、他带伤赴约与"以后都不打架"的保证 6. 一千八的手机、进她房间看画与"我不能没有你"的拥抱 7. 微信号ZNHS1314、第一张合照与"老板说了你两句不好的，我听不惯"

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 病症出现第一次真实好转 | 不写"她开始康复"，而写三件事：六月拒食内脏糯米多刺鱼、"每餐催吐的量开始渐渐变少"、有一天"餐后不再催吐"并用老年机报喜 | 小目标嵌套 + 数据化 | 爽、感动 | 让康复用可计量的进步呈现（量变少→不吐），再配一次孩子气的报喜，努力才有回声 |
| 母亲的控制因外务而松动 | 交代保险理赔被卡、冉银跑市里越来越频繁，"分到周念身上的精力直接坎半"，饭菜吃不完也只草草了事 | 外部事件置换压力源 | 爽 | 让压迫者被另一条线占住精力，主角的喘息就不必靠宽恕或奇迹 |
| 短信成为全章最轻的甜点 | 她报喜、他回"这么棒？"、她吐槽"表扬人都只发三个字"、他连发三条把字数加码；再补一段算短信费"一条短信一角钱…就花了三角钱"，他回"周念，你真抠" | 对话节奏 + 数字细节 | 甜、好笑 | 用短信字数、短信费这种可数的小账目写甜，比长段情话更贴身 |
| 男主的暴力有明确的靶子 | 先原样给出老板与店员的下流议论（寡妇、赔偿金、后爸、"母女两个还可以一起搞搞"），再让鹤遂无声出现在他们面前 | 因果前置 + 延迟揭示 | 愤怒、爽 | 先让读者听到脏话、再让主角出手，暴力才有立场；出场不要写"他听见了"，写"不知何时出现在他们面前" |
| 打架写成"不躲不避" | 老板用铁凳砸他脑袋"砸得砰砰作响，完全是在下死手砸"，他连眼睛都不眨，继续用拳头砸在对方脸上，额头很快见血——"一如既往地打架不要命" | 反应层放大 | 爽、心疼 | 让伤害落在主角身上却不影响他的攻击，狠与惨同时给足 |
| 他的伤被女主一条条数出来 | 她开门后先笑、笑容凝固，再依次看见嘴角破损、额头纱布、鼻梁乌青，随后是"你怎么回事啊，为什么又打架" | 视觉清单 + 情绪反转 | 心疼 | 用恋人视角把伤口逐项看清，比直接写"他受了伤"更让人心疼 |
| 男主低头的方式是"仰视" | 他"弯腰，把双手撑在膝盖上，仰着脸去看周念"，低声道歉；同章后段他进她房间看画后又露出落魄表情 | 身体姿态 | 甜 | 让强势角色在认错时使用仰视视角，姿态本身就是妥协 |
| 手机的价格与代价绑在一起 | 收束处点明"价格1k8左右，但那却是鹤遂被砸破脑袋，老板出的医药费，外加舍掉一个月工资换来的" | 代价后置揭示 | 心疼、甜 | 先把礼物送出去，最后才交代钱从哪来，礼物的重量会延迟爆炸 |
| 全章用"后来"制造痛感 | 开篇写"纵使在多年后这同一双眼无比冷漠地看着她"，结尾写他的屏保随意换过很多次"却不会再是和她的合照" | 双端预叙 | 压抑、甜 | 在甜度最高的一章前后各钉一句未来，读者会在笑着的时候心口发紧 |

**逐章写法公式**：

- **情绪流向**：起：亢奋（通宵失眠、反复回想告白） → 承：希望（拒食成功、餐后不吐、短信斗嘴） → 转：怒与疼（老板的下流话、他被铁凳砸头、带伤赴约） → 合：暖与不安（一千八的手机、拥抱与合照 + 屏保的预叙）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：失眠回想（把上章告白消化掉） + 六月的拒食与保险线松动（病症第一次实质好转） + 短信往返（全章最轻的甜） + 手机店暴打（本章爽点与他的动机揭示） + 带伤赴约与保证（把暴力换成心疼与承诺） + 手机、看画、拥抱、合照（关系确立的实物证据）
- **本章核心技巧**：把"好转"与"暴力"放进同一章——她第一次不吐，他第一次为她的名声动手被砸破头；两条线都朝"救赎"靠拢，最后由一台一千八的手机把代价与心意焊在一起
- **卡点与伏笔**：结尾卡点：壁纸与"后来的屏保不会再是和她的合照"（甜的顶点同时给出散场预告）；埋设/回收伏笔：老板的下流话 → 他的打架动机，也预示镇上舆论对她的恶意；"你怎么知道我不能？" → 他为她动手的原则；ZNHS1314 的微信号 → 不能修改的承诺；保险理赔受阻 → 冉银线的后续危机

# 第18章 病症 摘要

**概要**：暴雨落下，鹤遂覆在周念头顶的大手是唯一的温热。周念第一次被肯定勇敢，感受到"一滴熔岩滴在辽阔冰面"般的陌生情绪，脸红到耳朵；鹤遂看见输液软管里已有十多厘米血回流，被周念带着哭腔命令"你把手放好"。她回到画板后，鹤遂踢开被子只说"热"，随后她专注作画，画出一幅冷色调油画：病房、剥裂墙皮、掉锈输液架、药水剩一半的吊瓶、缠白纱挂彩、鼻梁上有月牙型掉痂疤痕的少年，看向窗外暴雨与被摧残弯了腰的蓝花楹；而在输液软管处，她临时起意画上回流的鲜血，是整幅画唯一的暖色。画到上半身时，她提出要画他的伤口，要求他把衣服掀起来"掀一半就好"；鹤遂故意说"我不知道你口里的一半是多少""那你掀吧"，引出"你在耍流氓"的争执，最终周念自己小心翼翼把病号服卷到胸骨下方、露出腹肌与人鱼线，手指蹭到他腹部皮肤后触电般缩回。天黑画完，周念道谢告别，走两步又转身，鹤遂恰好也转头看她——"有种命运使然的巧合感"。他忽然问"一副够吗"，随后主动说"想多画几幅也不是不行"，两人交换联系方式：周念没有微信，掏出一台掉漆严重的灰色老人机，机械女音在病房里大声播报"右键解锁""电话簿""新建联系人"，鹤遂被逗笑说"早餐铺烙饼的宋阿公用的都是智能机"，最后还是报了号码，并冲她比了个打电话的手势："记得打给我。"

**关键事件**：1. 第一次被肯定勇敢带来的陌生情绪 2. 完成冷色调油画（唯一暖色是回流的血） 3. 画伤口引发的"耍流氓"争执与掀衣场面 4. 鹤遂主动提出"多画几幅" 5. 交换号码与老人机的笑点

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |

**逐章写法公式**：

- **情绪流向**：起：陌生（被摸头） → 承：专注（画画） → 转：暧昧（掀衣服） → 合：甜（加好友 + "记得打给我"）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：摸头余韵 + 作画过程（作品要素披露） + 画伤口要求（暧昧递进 + 笑点） + 完画道别 + 命运巧合的回头 + "多画几幅"的关系升级 + 交换号码的笑点收尾
- **本章核心技巧**：整章没有外部冲突，全靠"作品"和"联系方式"两件事推进；画出那幅画的同时把画的内容写成意象清单，使画成为后文可反复调用的情绪容器
- **卡点与伏笔**：结尾卡点："记得打给我"（下次见面靠这一通电话）；埋设伏笔：那幅画（将在第19章交给冉银，构成第8章埋下的"冒险"兑现）、周念无微信/用老人机（后文社交与联系的持续障碍）、鹤遂"热"背后的伤口与体温

# 第28章 病症 摘要

**概要**：潮湿的清晨里，不容易出汗的周念因为擦门累得满头大汗；鹤遂一趟提两桶水、每桶约三十斤却脚步沉稳，桶里的水只微微荡出纹路，两人耗时近两小时才把门上的油漆擦干净。周念蹲在原地休息时，一只冷白的手伸到眼前，递来一条拧过水的干净白毛巾让她擦汗；她因为发现毛巾是新的而悄悄开心，又自嘲这样的小发现有点神经质，便问他是不是特意拿的新毛巾，他反问"难道拿我用过的给你？"。他让她别蹲着，提醒"等下蹲久了起来又晕倒，这次我可不会接住你"——他还记得上次她晕倒时是他接住的；周念认定就算再晕他还是会接住，说他刀子嘴豆腐心。她站起来眼前发黑，模糊的视线里隐约看见两只手伸到面前做出接住的手势，睁眼后却发现他并没有伸手、气定神闲地站着，看来是她花了眼。进门时她提起他的衣服还在她那里（上次从医院穿走那件），说下次带来，他反问"那你今天怎么不带"，她说忘记了，他学着她的口气重复"你忘记了"，她慌忙解释不是故意忘记，被他一句"我又没说你是故意忘记的，你急什么"套了进去；她威胁"你再这样，我就不还你衣服了"，他笑说"在这个镇上没人敢威胁我，你可是第一个"——这句话让她意识到自己也是第一个接近他的人，于是壮胆当面把威胁说完。他霍地俯身凑到她脸前，一字一顿说"既然你那么想要我那件黑卫衣，那你就留着吧"，转身就走，她小跑追着上楼，到房门口才想起画具箱和画板还在外面，他大步出去替她拿。随后他端着四个青团和一杯牛奶回来，说"我妈做的青团"、"家里没有饮料，只有牛奶"；周念因为糯米做的东西很难吐出来而对着青团露出恐惧，又借口牛奶过敏推拒（过敏是真的，所以早上冉银只给她喝豆浆）。鹤遂若有所思地盯着她，两次欲言又止地说"周念，你是不是……"，她坐立难安、下唇哆嗦，只希望他什么都别说。门口响起三声敲门和宋敏桃的"阿遂"，宋敏桃进来让鹤遂去店里搬两箱泡脚材料包；房里只剩两人后，她问周念"鹤遂没欺负你吧"，周念才明白这个"欺负"和自己理解的不是一个意思，宋敏桃又叮嘱她注意分寸、他若提过分要求就拒绝，周念低声说"鹤遂也是个很好的人，他不是个坏孩子"。最后周念小心翼翼地开口："鹤遂……他为什么不念书了？"

**关键事件**：1. 两小时擦完门、递来新毛巾 2. "这次我可不会接住你"与模糊中伸出的两只手 3. 衣服的推拉与"你可是第一个" 4. 青团与牛奶被双双推拒、"你是不是……"两次中断 5. 宋敏桃的"欺负"之问与分寸叮嘱 6. 周念问出辍学的原因

**逐章写法公式**：

- **情绪流向**：起：疲惫与轻甜（擦完门、新毛巾） → 承：心动（刀子嘴豆腐心、疑似伸出的手） → 转：紧张（青团牛奶被拒、"你是不是……"） → 合：松气与悬念（宋敏桃介入解围 + 问出辍学）
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：收尾劳动与递毛巾（用劳动后的照顾完成关系升温） + 衣服的推拉斗嘴（把甜写到峰值） + 送吃与被拒（把病症逼近前台，制造第一次险情） + 母亲介入解围（外部人物打断危机并交出辍学线索） + 章尾提问（把悬念直接交到下一章）
- **本章核心技巧**：三起三落安排在同一章——甜（毛巾、斗嘴）→ 危险（"你是不是……"）→ 解围（敲门声），每一次升降都换一个功能位（照顾／试探／打断），让一章之内既有心动也有险情
- **卡点与伏笔**：结尾卡点：周念问"他为什么不念书了"（下章由宋敏桃揭底）；埋设/回收伏笔：他"记得她晕倒"并疑似伸手 → 回收前面的晕倒事件；青团与牛奶 → 他已经在用食物观察她的身体；宋敏桃的"欺负"与分寸叮嘱 → 母子对他的定性；牛奶过敏并非借口 → 病症的另一条身体底账

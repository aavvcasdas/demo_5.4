# 第49章 病症 摘要

**概要**：自打和鹤遂断开交集后，周念就生了一场经久难愈的心疾——看似肌理完好，实则灵魂溃烂。她没放弃找鹤遂，可他一点念想都不愿留：手机永远无人接听，去过他家很多次都是大门紧闭、怎么敲都无人应门，她像一只在南水街徘徊的孤魂野鬼，在他打过零工的地方、镇外的青草地、南水街某座石桥和河岸边反复游荡，始终一无所获。断联一周后厌食症重新发作，她又变成最初的样子，顿顿把大量食物、不管能不能接受的全吞进胃里，连最讨厌的动物内脏和糯米制品也眼睛都不眨地吞下，情况比之前更严重；每次跪在马桶前吐得昏天黑地时，她觉得自己是一个打了败仗的士兵、已经丢盔弃甲，没有鹤遂就丧失掉大半勇气去刺向冉银的阿喀琉斯之踵。半个月后她开始不停出现幻听，那种尖锐的刺耳声像一万根针同时在耳边高频震动，紧跟着是剧烈的偏头痛；夜里她想起自己坐在院中井沿上、鹤遂刚洗完手的手指沾着井水的凉探进她口腔、一颗接一颗摸到她嘴里最里面那颗横着长的智齿，于是她躺在床上学着他那时的模样把手伸进嘴里一颗一颗往里摸——嘴里没有智齿，她才明白这次是真的偏头痛，而那个陪她拔牙、在拔牙时给她讲故事转移注意力的少年已经彻底从她生活里销声匿迹，她把脸深埋进枕头，枕上很快洇开两团深色的潮湿。七月末莫奈从京佛玩了一圈回来，带着护发素、巧克力、桌上小摆件和一本书来找周念，见面就被她吓了一跳——此时的周念只有七十四斤，短短二十多天从八十二斤掉到比认识鹤遂之前还低的体重，皮肤苍白得像吸血鬼，穿一身白裙很像一朵枯萎、衰败、缺乏养分的茉莉花，十七岁的少女脸上竟有了病容。前三样礼物都没能吸引她，直到她看见那本褚褐色封面、中间一个悬空少女、白色字体的书——《绝叫》；她把书拿在手里垂眼看了很久说"以前有人给我讲过这个故事"，被莫奈问是谁讲的时沉默许久、声音颤抖地说"一个不会再回来的人"，莫奈试探问是不是鹤遂，她没有回答，一滴眼泪掉在了封面上。莫奈说自己这一个月都在京佛、回来也听说了鹤遂的事，说不定他调整好就会回来找她，周念却从没这么坚决过地说"他不会再回来"——就在前天她听说鹤广卖掉了南水街的那套房宅，卖房的钱不用想都知道是拿去当了毒资，鹤遂从此再无家可归，也听说他动身去了市里打工不会再回来；在她看来这是个让他伤心欲绝的小镇，满镇子的人都是杀死宋敏桃和宋平安的凶手，他们轻描淡写地用语言杀死两个人后还是一如既往地生活、照样笑得开心，照样选中下一个要杀死的对象开始议论。暑假还剩半个月，周念的体重还在掉，已经无法带着画板和画箱出门，那两样东西对她有如千斤重；想鹤遂的时候她会拿出专属于他的那本素描本，里面全是他一个人的人物画——站着的他、坐着的他、懒散躺在藤椅里的他、为她捕捉萤火虫的他，翻着翻着视线就模糊一片，而那些画曾有多开心，此时的悲伤就来得有多汹涌。她灵感枯竭、完全无法画画，有时对着画纸坐两三个小时都动不了笔，这激怒了在画画上采取零容忍态度的冉银：冉银站在她旁边说"画，我今天上午就这样看着你画"，从"动笔"一路喊到全名"周念，我让你动笔"，周念却把铅笔扔到地上说"不行，我画不出来"，铅笔坠地笔芯折断，冉银一脚踹翻画架质问她到底想做什么，又握住她的肩膀大力摇晃，要她成为像梵高和毕加索那样出名的大画家、让全世界都知道周念这个名字。周念勾唇笑着问"为什么"，接着说出"是因为你没能成为出名的大画家，所以我就必须成为是吗？妈妈，我一定要按照你的想法活吗？我真的很累啊"，并在冉银"我这都是为了你好"的逼问下亲手剥开那个茧——她说冉银从来不是为了她而是为了自己，为周尽商关掉画室、放弃画画回到花楹镇当家庭主妇，后来心有不甘，便把没能完成的事情全部寄托在女儿身上。冉银气得瑟瑟发抖、脑后盘着的头发散下来，仍咬着"你没有选择，你这辈子只能走画画这条路""你想画也好，不想画也罢，你都得给我画"；周念从高脚凳上站起来踩在一页雪白的画纸上说"现在的我不仅不想画，也画不了"，并在一遍遍的"画！画——！"中一字一句回"我，不，画"。就在冉银崩溃边缘、眼泪冲刷着脸剧烈摇晃她肩膀时，一句"你知不知道我为了你，把周尽商给——"戛然而止，她像咬住自己的舌头把没说出口的字眼吞回肚子；周念目光发直地追问"你把爸爸怎么了"，冉银打了个哆嗦，随后在眨眼间变得格外镇定、脸上的肌肉也停止颤动，表情由愤怒焦躁转为平静冷漠，一字一顿地说出"我把周尽商给杀了"，并以沉默代替回答。当周念追问爸爸不是被蜱虫咬了后死于感染、那不是意外吗时，冉银干脆而冷漠地答"蜱虫是我放的"。

**关键事件**：1. 断联后的心疾、厌食症复发与幻听偏头痛 2. 体重从82斤掉到74斤、莫奈送书《绝叫》 3. 鹤广卖房、鹤遂离镇去市里打工 4. 母女因画画爆发的正面对峙与"我不想画" 5. 周念剥开母亲把未完成的自己寄托在女儿身上的真相 6. 冉银自曝"我把周尽商给杀了""蜱虫是我放的"

**逐章写法公式**：

- **情绪流向**：起：病（心疾、幻听、掉到七十四斤） → 承：痛（《绝叫》、素描本、灵感枯竭） → 转：爆（母女为画画的对峙与"我，不，画"） → 合：惊悚（"我把周尽商给杀了""蜱虫是我放的"）
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：断联与“孤魂野鬼”式寻找（把他写成一个已经消失的人） + 厌食复发与幻听偏头痛（用身体写心理） + 摸智齿的模仿动作（用小动作扣回关系） + 莫奈与《绝叫》（让旧书带出现场缺席的人） + 七十四斤与病容（把崩坏量化） + 鹤广卖房与去市里打工（彻底切断退路） + 素描本与灵感枯竭（写创作停摆） + 画笔落地与踹翻画架（把冲突推到肢体层面） + "我不想画"与揭底台词（女主第一次彻底反叛） + 失口的半句与"我把周尽商给杀了"（在崩溃里掀开命案） + "蜱虫是我放的"（一句话闭环前文伏笔）
- **本章核心技巧**：全章把"画画"这个从第1章就存在的功能位翻转为冲突核心——它先是母亲的全部希望、再是女儿唯一的能力，最后成为她丧失能力后仅剩的反抗方式；一次"我不想画"同时削掉母亲的人生寄托和女儿的身份依托，母亲因此失口泄出最大秘密
- **卡点与伏笔**：结尾卡点：冉银一句"蜱虫是我放的"停在章末，命案已认、理由未给，下章必然交代杀夫经过；埋设/回收伏笔：蜱虫与周尽商"死于感染" → 本章回收为人为投虫（跨度自第42章）；"阿喀琉斯之踵"的提法 → 冉银的致命弱点待用；《绝叫》（鹤遂讲过的书）→ 再次出现，与女主被原生家庭伤害的命运互文；鹤遂手机永远无人接听、去市里打工 → 他的消失与可能的再见；莫奈从京佛带回的礼物 → 大城市线；冉银"为爸爸关掉画室"的往事 → 母亲身世补全；灵感枯竭与无法动笔 → 女主职业生涯的危机；本章附于文末的鲁迅引语（"从来如此，便对么？"）不在正文叙述内，不参与情节点

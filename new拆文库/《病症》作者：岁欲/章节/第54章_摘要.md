# 第54章 病症 摘要

**概要**：七月中旬周念收到法院的通知，让她三天后作为证人出庭，作证那件数月前肖护持刀故意伤人的案子；冉银得知后不知具体情况就不同意她出庭，周念站在院子里看着要死不活的万年青，平静地说"我不需要你同意"。外面那场黄谣风暴还在卷、从没停过，现在的周念在那些人眼里成了和鹤遂一样的存在——一个不知检点的女孩子、他们女儿的完美反面教材；她蹲下拨弄万年青的叶子说"外面为什么会那样说我，你不是很清楚吗？你不是很得意这样的结果吗？"，自从那天起她再也没有叫过冉银一句妈妈，在她心里已经没有妈妈了。面对冉银又一次的"我都是为了你好，七斤"，她说出"你去自首吧"；冉银被激怒，拿出手机摁了110递到她面前"你报警吧，你报警去给警察说，你看警察会不会信你"，周念的手指悬在拨号键上悬而未决，时间流逝间冉银眼里的把握更胜一筹，甚至挑衅"怎么？不敢打报警电话"，又量她不敢，说出"周尽商的价值就是那一千六百万。你要为了这么个人去报警，七斤，你才是真的不孝"。周念想不明白一味服从听话、做到她口中的懂事听话就是孝吗，咬了咬唇后鬼使神差地按下了拨号键；冉银瞳孔一缩，在110被接通以前迅速挂掉电话，质问"你真想看你亲妈去坐牢是吧"，周念安静三秒后说"从很小的时候开始，我画的不好时，都会被你惩罚继续画。然而现在你做错了事，杀了人，却想逃之夭夭吗"。冉银沉默许久后从厨房里走出来，手里拿着一把菜刀；周念惊愕地站起来，只听她说"我告诉你，七斤，你想我去自首，可以。你甚至想我去死，也可以。但是前提是我必须看到你出人头地，看到你成为赫赫有名的大画家，那到时候我做什么都可以。你不用担心妈妈会骗你，我会证明给你看——"，那把菜刀高高举起，周念尖叫出声，随着尖叫声一并落下的是菜刀和冉银的一根手指。三天后周念还是作为证人出庭，在法庭上被公诉人问话时条理清楚地陈述了那晚看到的完整事发经过——看见肖护一身是血地从巷子里跑出来、后面跟了好几个人；以肖护为首的被告一共八个人，肖护爸爸很有钱、给他请来了很有名的刑事律师，可惜证据确凿，再有名的律师也打不过这一仗，肖护最终判了四年零八个月，其他几人也依照情况判了刑。宣判结束后周念正好和肖护对上视线，这才注意到肖护的右脸上有一个深坑、看上去疤疤癞癞，有点像被硫酸腐蚀后的皮肤——那就是鹤遂咬出来的伤口；猝不及防看见，她被吓得不轻，肖护恶狠狠地盯着她、目光里射出寒光，她连忙转开视线，她很害怕但不后悔出庭作证，她觉得鹤遂值得一个公道和清白。鹤遂此时就坐在旁观席上，目光始终在她身上，听她作证时收起了那副万事不挂心的慵懒样、听得格外专注，他知道这是她在为他勇敢。两人从法院出来后要坐大巴回镇上，车程一个多小时；周念带了遮阳伞，鹤遂很自然地接过替她撑着，路过一家小商店时他看见绿毛怪包装的跳跳糖便停下来买了几包散的青苹果口味——自从那次在医院吃过她买的跳跳糖后，他看见了就总想买，然后倒一包在嘴巴里感受一整个春天在嘴巴里炸开的感觉。车站热得像个蒸笼，售票的女人原本一直低头看手机，抬眼扫了鹤遂一眼后视线就再没移开过，笑着多问了他几句去哪个火车站，直到鹤遂提醒"你还没找我钱"才回过神来，还不停给对面的女人使眼色示意快看有帅哥；周念看在眼里，上车前忍不住犯嘀咕"眼睛都长在你身上了"，被他笑着回"阿姨的醋也要吃，你别太夸张"，她口是心非地说"我才没有吃醋"便快步朝大巴走去。上车后他们坐在最后一排，他替她放下挡窗户的布帘，问出"有正事和你说"的内容——"你高考报哪里？"，说她得先告诉他报哪里，他才能为他们的出逃做计划；周念认真想过之后说"京佛美院吧"，那是国内顶级的艺术类院校、也是一流的985，每年超过三万人报考而录取不会超过1500人，他说"那我们就去京佛"。她担心没有钱，他看着她的眼睛低低说"你什么都不用担心，你只用高考结束后跟我逃跑就行"，并平静地讲出计划：从镇上坐大巴到县城，再从那个车站坐车去火车站；她凑到他耳边说高考完立马走、多一天都不想待，还可以到京佛定下来再收通知书。他依她，又顺势把头靠在她肩上说好累要睡会、到了叫他，周念闻着他身上淡淡的清香让他睡——在这辆大巴车上，他们坐在最后一排计划过未来、设想过远方，准备在不久之后上演一出盛大的逃亡计划，那时候周念是真的相信他会带她走。八月初她开始去省里参加集训，集训的日子里没有冉银、她暂时得以喘息，再加上对未来充满希望，她重新对画画燃起了激情，又能像以前一样一动笔就惊艳所有人，老师甚至说她完全可以不用参加集训、轻松过省线不是问题；她没有因此自傲，特别刻苦地没日没夜泡在画室里、每天都是最后一个离开的学生，晚上回宿舍还会和鹤遂打视频电话——手机是她出发前鹤遂帮她修好的，视频里的他打着很多份工、休息的时间寥寥可数，年轻英俊的脸上常常挂着倦容，她让他休息，他总懒懒笑着说不累。集训结束回花楹镇那天正好是十一月十三号、是她和他的生日，然而回镇上时已经是晚上十一点；冉银在镇门口来接她，她态度很冷漠，也不让冉银帮忙拉行李拿东西，自顾自朝家走，冉银跟在后方说"七斤，我给你准备了生日蛋糕"，她没有理会。到家后她径直回房间，拿出手机发现收到了鹤遂的消息——他说她在家的巷子口等她；她立马轻手轻脚地打开房门下楼，楼下没弄出一点动静，还好没被冉银发现。十一月的深夜又黑又冷，出来没一会儿她的鼻尖就被冻得发红；她来到巷口没看见人，四下张望时旁边闪出一道高瘦身影、轻笑一声"在找我？"，她捂住胸口松了口气说"吓死我了你"。他的双手从背后伸出来捧着一个东西，太黑她看不清，"念念，生日快乐。"她开心地接在手里、觉得有点沉，却说自己才回来还没来得及给他准备生日礼物，他沉默了下低声说"你现在就可以给我生日礼物"；话音落下，少年俯身而下、极尽温柔且隐忍地在她唇上亲了一下，很轻很轻、转瞬即逝——这是她的初吻。周念僵了许久，还是鹤遂拿着手机给她看时间"还有五分钟，还不祝我生日快乐"，黑暗里她的脸早就涨成番茄红，开口时声音又哑又抖、还结巴个不停"鹤，鹤遂，祝你十八岁，生日快乐"，月光洒在他清绝眉眼间，他冲她展眉一笑、嗓音倦懒"谢谢，我很快乐"。她想化解这暧昧又尴尬的气氛，便走到亮堂的月光底下看清楚手里的东西——一株长势惊人的万年青，叶片肥厚、绿得惊人，还用一个特别可爱的粉色花盆装着；鹤遂弯腰、双手撑在膝盖上改为仰视她，眸子又黑又深邃、眸底璀璨如星河，开口时嗓音徐徐"念念，我们万年长青"。

**关键事件**：1. 法院传票与"我不需要你同意" 2. 递到面前的110与"你去自首吧" 3. 菜刀与冉银自切的一根手指 4. 庭审作证与肖护脸上的深坑、四年零八个月 5. 车站的跳跳糖与售票女人的注视 6. 大巴上"报哪里"的出逃计划与京佛美院 7. 省城集训与重新能画 8. 生日夜巷口的初吻与万年青"我们万年长青"

| 母女关系用称呼的消失来标记 | 不写决裂，只写"自从那天起，她再也没有叫过冉银一句妈妈。在她心里，她已经没有妈妈了" | 称呼刻度 | 压抑 | 用一个称呼的有无记录关系存亡，比任何争执都清楚 |

**逐章写法公式**：

- **情绪流向**：起：冷（传票、黄谣、不再叫妈妈） → 承：烈（110、菜刀、一根手指） → 转：亮（法庭作证、判决、跳跳糖、大巴上的计划） → 合：甜与定（生日夜初吻、万年青、万年长青）
- **节奏配比**：慢铺垫 20% / 快冲突 20% / 爽点爆发 15% / 悬念留白 45%
- **本章结构公式**：传票与拒绝沟通（把母女关系写成零） + 递到面前的110与"你去自首吧"（把选择摆上台面） + 菜刀与一根手指（用自残提出交换条件） + 出庭与判决（用最短篇幅完成公道） + 肖护脸上的坑（回扣旧暴力） + 遮阳伞与跳跳糖（用照料和零食写两个人的日常） + 售票窗口的插曲（用旁人的目光写男主外貌与女主在意） + 大巴上的计划（把出逃落到路线与院校） + 省城集训与重新能画（让女主的能力回归） + 生日夜的巷口与初吻（在最冷的天给最甜的戏） + 万年青与"我们万年长青"（用礼物命名关系）
- **本章核心技巧**：把"逃亡"从口号变成日程表——问院校、算车程、定路线、约定"到京佛定下来再收通知书"，让读者相信这场出走真的要发生；甜的部分全部落在具体的器物与时间里（跳跳糖、遮阳伞、布帘、"还有五分钟"、粉色花盆），越是具体越显得这份好日子随时会被收回
- **卡点与伏笔**：结尾卡点："念念，我们万年长青"——承诺已许、日子正甜，而黄谣、命案与母亲自残的三重隐患都在场外等着，下章期待为逃亡是否成行；埋设/回收伏笔：肖护脸上的深坑 → 鹤遂咬出的旧伤，也是两人关系的起点事件；肖护四年零八个月 → 出狱时间；"必须看到你出人头地"与那根被切下的手指 → 母亲的病态绑定；一千六百万 → 母亲拒绝自首的理由；鹤遂帮她修好的手机 → 通讯恢复；京佛美院与"高考结束后跟我逃跑" → 全书的大方向；万年青与粉色花盆 → 关系命名与新生意象；跳跳糖的青苹果口味 → 医院时期的回扣；本章附于文末的作者留言（"下章结束小镇"）不在正文叙述内，不参与情节点

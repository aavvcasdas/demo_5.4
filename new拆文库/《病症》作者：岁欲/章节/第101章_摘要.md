# 第101章 病症 摘要

**概要**：鹤遂离开小镇回京佛当顶流影帝后，周念频繁梦见他站在黑漆漆的悬崖底部、被黑雾一点一点掩住五官，每次都从梦中惊醒。刷牙时莫奈打来语音问她与鹤遂的现状，周念说"各自安好"，并回想最后一次见面时他卑微地说"可没有你，我不会过得好"、她却拒绝了他；莫奈说这也许是最好的结局。莫奈提到自己曝光肖护虐猫狗的抖音视频点赞破五万，又提起鹤遂身体里的另一个人格叫沈拂南——拿钱摆平肖护、此前拿钱养鹤广的都是他。当天早上霍闯抱来一只五百块的"迷你猪"送她，扭捏着请她帮忙让莫奈曝光校园霸凌：那三个当年打过他的初中生如今仍在霸凌一个瘦弱男生，他手里有四年前拍的视频。周念看视频时注意到远景里有个抽烟的人影，放大后认出是鹤广；把山林、水库、4月9号下午起火、烟头火因等细节串起来后，她确认鹤广就是当年烧了七天七夜、烧死二十七名消防员那场山火的人。周念决定报警，霍闯问要不要告诉鹤遂，她点头说相信他很愿意做报警的那个人。沈拂南在拍杂志封面时挂断了"小橘子"的来电，傍晚去生东返家吃饭哄生雅娇，席间收到周念一句短信"你想永远摆脱鹤广吗？"，立刻离席回电。周念提出唯一条件：方法只和鹤遂谈，让鹤遂回来小镇找她；沈拂南拒绝，她给三天期限并以销毁证据相威胁后挂断。

**关键事件**：1. 黑崖梦境与惊醒 2. 莫奈的语音质问与"各自安好" 3. 霍闯送猪并请求曝光校园霸凌 4. 四年前视频里抽烟的鹤广 5. 山火火因与二十七名消防员的复盘 6. "小橘子"来电被沈拂南挂断 7. 生东返家宴与五只包的哄人 8. "你想永远摆脱鹤广吗？"短信与三天期限

**逐章写法公式**：

- **情绪流向**：起：空（黑崖梦境、各自安好） → 承：惊（视频里的鹤广、山火旧案） → 转：冷（沈拂南挂断"小橘子"） → 合：悬（一句短信、三天期限）
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：黑崖梦境与惊醒（立分别后遗症） + 莫奈语音交代现状与沈拂南的行径（用闲聊补设定） + 霍闯送猪与请求曝光（把主线委托塞进日常） + 四年前视频与远处抽烟的人影（用细节埋证据） + 山林水库起火时间的交叉复盘（把旧案钉成事实） + 决定报警并问要不要告诉鹤遂（立本章行动目标） + "小橘子"来电被挂断（用备注暴露关系） + 生东返家宴与五只包哄人（交代沈拂南的生活面） + 一句短信与阳台回电（把对手拽回小镇） + 三天期限与销毁证据的威胁（收紧倒计时）
- **本章核心技巧**：双线并行——明线是霍闯的视频牵出山火旧案与报警决定，暗线是周念用一句短信把沈拂南从京佛钓回小镇；两条线都以"一次日常接触"作为发起形式，把重大转折伪装成琐事
- **卡点与伏笔**：结尾卡点：周念以"三天过后没消息我就销毁证据"威胁沈拂南并挂断电话，而那句话本身是诈他——沈拂南会不会上钩、会不会让鹤遂出来都悬置；埋设/回收伏笔：梦境里被黑雾掩住的鹤遂 → 他此刻被压制沉睡的状态；"小橘子"备注 → 鹤遂私下存下的幼稚称呼；四年前4月9号山林视频与烟头火因 → 鹤广的旧罪与山火案；冉银已自首走流程 → 后续开庭会被公开；沈拂南提到的"那个地方"（本章仅由周念回忆赌约引出三个月期限）→ 与善进学校相关；赌约"输的人消失三个月" → 下一章被推翻为"永远消失"
- **时间线**：本章自鹤遂离开小镇后的某个清晨起，至当日晚间沈拂南家宴后

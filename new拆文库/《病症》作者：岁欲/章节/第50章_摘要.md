# 第50章 病症 摘要

**概要**：三伏天的画室没开空调、格外闷人，周念非但不热，反而冷得瑟瑟发抖，一度怀疑是自己听觉出了问题——周尽商是冉银杀的，导致周尽商感染而死的蜱虫是冉银放的，这竟然是真的。巨大的刺激下她用手捂着胸口、呼吸困难，费劲地张大嘴巴深深吸气才往肺里卷送去一点氧气，那感觉就像真的死过一遍；只是剧烈的痛楚让她重新活过来，命运不让她就此死去，而是要她清醒地存在、亲手去剥开血淋淋的残忍真相，青筋和血管从她纤细的脖子上鼓出来。她哑声问"是你杀了爸爸，你还说是为了我杀了爸爸"，冉银披头散发像哀怨未了的女鬼回"我不是为了你，那是为了谁"；周念哭着说她做什么都说是为了自己、现在连杀了爸爸也说是为了她，那她到底算个什么十恶不赦的罪人，说完连自己都笑了——泪水在流她却在笑。冉银抹一把脸把头发抹到脑后，冷漠地说"周尽商他死有余辜""他就算是死一万遍那都是他该死"，随后不再与她对视，抬脚朝画室外的木地板阳台走去，仰头眯着眼却不敢直视太阳——她看的不是太阳，而是十九年前年轻的自己。那时她是风光无比的新晋才女画家，毕业后开画室风生水起、报她课的学生还要排队，追求者每天等在画室外；画室有一天突然停电，找来的电工年轻憨厚、看她一眼都会羞得耳朵通红，她主动搭话调节、故意调侃"你一个大男人怎么像个小姑娘似的"，又在一来二去熟络后主动约他"修完和我去喝一杯啊"，得知他不会喝咖啡便改约喝茶，那个爱喝茶的电工周师傅全名周尽商，就这样走进她的生活。恋爱一年后周尽商突然求婚，用一枚质朴到不能再质朴的素戒，笨拙又真诚地单膝跪着说背了一整个通宵的求婚话语，她感动得一塌糊涂，即便他要求她陪他回老家花楹镇，她也不顾家里长辈的反对、关掉画室坚定地选择了他和爱情；可爱情保质期一过只剩慢性毒药般的一地鸡毛——小镇电工的收入撑不起她想给孩子的进口奶粉和一切婴孩用品，两人在育儿观念上分歧不断，她回到小镇成了家庭主妇、没有精力画画，存款被迅速吞掉。冉银对着太阳数落他的种种：怀孕时孕吐得厉害他不管，只管抽烟喝茶、在手机上玩游戏，曾说会细心呵护她却把她骗到小镇后卸下伪装，家务从不做，一个月工资只有两千八还成天喊累，家里花销靠她培养女儿画画拿的奖金补贴，他每个月的烟钱都得大几百，没去过一次女儿的家长会，只会在女儿这里讨巧。她忍了这么多年不离婚，就是想着等女儿出人头地自己就算解脱，却万万没想到看上去老实巴交的周尽商敢在外面偷人——就两千八的工资还要花一千给外面的野女人；她不是冤枉他，是李丽芳拿着怀孕的检查单来找她，她才不得不信。周念如遭雷劈、眸光凝固：那正是教过她一学年的语文老师李丽芳，正是当初陈志强拿着照片来问过她的那个女人，也正是前些天街上相遇时冉银冷冷让她别打招呼、李丽芳表情极不自然的那个人。冉银接着交代作案经过：她抓了几只蜱虫趁他熟睡时放进他的被子里，总有一只携带致死病毒；第二天晚上他就开始发烧，他想去医院看，她说只是普通风寒感冒不用在意，给他喂了感冒药、眼睁睁看着他一点一点变得虚弱、显出死相，一直到完全撑不住时才把他送去医院，送得太晚、抢救也来不及。周念这才明白保险金为什么会被卡住，也明白周尽商死的时候冉银不让她哭，是因为觉得周尽商不配让她流泪；她浑身失力、狼狈地跌坐在地，说出"所以，你买了大额保险，杀夫骗保"——这一刻她想到的是鹤遂给她讲过的那个杀夫骗保的故事，当时只当是故事，从未想过会发生在自己父母身上。冉银擦掉眼泪、嘴角一点点牵起一个十分诡异的笑容，说是"那个姓陈的自己撞上来的"：在李丽芳找上门要求她离婚的第二天陈志强上门推销保险，她故意周旋好几天、装出想买又不想买的样子，吃准业务员不会放弃大几千的提成，最后在陈志强提着两桶菜油登门时露出一副贪小便宜的样子买下两份大额保单，而愚蠢的陈志强还在沾沾自喜。她笑着说自己今天彻底搞定了保险公司那群难缠的人，明天一千六百万赔偿金就会打到她的账户，随后蹲下来温柔地捧住周念苍白的脸颊说"有了这些钱，妈妈可以给你最好的""周尽商那条贱命也算是派上了点用场"；周念彻底崩溃，尖叫一声挥掉她的手，发疯一般冲出画室逃跑。

**关键事件**：1. 周念当场确认杀父事实与窒息般的躯体反应 2. 冉银自述十九年前才女画家与电工周尽商的恋爱与婚姻 3. 数落周尽商的失职与出轨，点名李丽芳拿怀孕检查单上门 4. 交代投蜱虫、谎称感冒、延误送医的作案过程 5. 陈志强推销保险与两份大额保单的算计 6. 一千六百万赔偿金与"贱命派上用场" 7. 周念崩溃冲出画室

**逐章写法公式**：

- **情绪流向**：起：寒（三伏天里的发抖与窒息） → 承：恨（"死有余辜"与十九年前的自己） → 转：凉（账目式的婚姻控诉与投虫的照顾） → 合：崩（一千六百万、捧脸微笑与冲出画室）
- **节奏配比**：慢铺垫 15% / 快冲突 25% / 爽点爆发 0% / 悬念留白 60%
- **本章结构公式**：确认事实与躯体崩溃（把认知冲击写成缺氧） + "为了你"的互怼与泪中发笑（把母女的逻辑死结摆开） + 阳台与十九年前的才女画家（倒叙母亲的选择） + 电工与素戒求婚（写爱情如何开始） + 账目式控诉与出轨（写爱情如何变质） + 李丽芳的回扣（把旧伏笔接上动机） + 投蜱虫与延误送医（把谋杀写成照料） + 陈志强与两桶菜油（写骗保如何落地） + 一千六百万与捧脸（用温柔动作说出最冷的话） + 冲出画室（以逃跑收束）
- **本章核心技巧**：真相不再靠反转而靠"复述"——全章几乎由冉银一个人的长段自述构成，作者把母亲的青春、婚姻、怨恨、手法按时间顺序摊开，让读者在听她讲话的过程中逐步站不住脚；情绪落点不在杀人的手法，而在那句把丈夫的命折价成"派上了点用场"
- **卡点与伏笔**：结尾卡点：周念尖叫挥开母亲的手、发疯般冲出画室，"逃，她要逃，逃离这个噩梦般的家"——她将逃向何处成为下章期待；埋设/回收伏笔：李丽芳（第46章的语文老师、被陈志强拿照片询问过的人）→ 本章回收为父亲出轨对象与冉银动手的触发；陈志强与两桶菜油（第42章）→ 本章回收为被骗保人；《绝叫》的杀夫骗保情节 → 现实版的对应；保险理赔的踢皮球与被卡的保险金 → 全部解释；一千六百万赔偿金 → 巨额资金的去向；冉银"为爸爸关掉画室"（第49章）→ 本章补全细节；本章附于文末的作者自述（指认第43章小狗与噩梦两处伏笔）不在正文叙述内，不参与情节点

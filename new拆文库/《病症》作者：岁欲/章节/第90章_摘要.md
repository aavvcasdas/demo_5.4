# 第90章 病症 摘要

**概要**：原来割腕那天鹤遂是真的在和她做最后的告别——他向来只做不说、不喜把爱挂在嘴边，因为觉得行动才是最有力的证明，正是这样的他却亲口对她说出"我爱你"这样郑重深沉的情话，可见当时他已做好赴死的准备；他倔强见缝而生、什么都不怕，只是在死之前要让周念知道他爱她。他再次把她的脸扳过来，非要问出"如果我就那样死掉，你会不会记我一辈子"，周念喉咙堵得说不出话，停了两秒才答"这样的假设没有意义"并把脸转开；他坚持"可是对我有意义"，于是两人沉默良久地坐在沙发上，呼吸节奏与起伏都同步。周念垂着长睫、声音放得很轻地说"鹤遂，不管你是死是活，是好是坏，我都会一直记得你"，随即在他指尖泛白的一颤中把话说完——"记得曾经的你"。她永远记得17岁的鹤遂：狠厉阴沉，从骨血中恣肆地生长出疯狂，是挺立在南水街的一道禁忌，所有人都怕他、畏他、辱他、骂他；而她以身入网，窥见他有一颗最柔软纯净的内心，发现他也是一件需要被呵护的易碎品，两个颤抖虚弱的灵魂互相救赎、彼此依偎。鹤遂抱着她，抬起一张被无助装饰的脸说"我现在也和曾经一样""我没有变，一点都没有变"，周念却平静地提出要问他一个在沈拂南那里没要到答案的问题："那天你为什么没有来？"他眸光当场凝固。她哽咽着提醒他，对她许下承诺的是他而不是沈拂南，沈拂南没有义务承担这件事上所有来自她的恨意——他在她最绝望的时候给她希望，承诺带她逃出那个小镇，最后却食言了。她仰脸想把眼泪逼回去，说"我实在为你哭过太多次，不想再为你掉眼泪了"，又挡开他探过来擦泪的手指；鹤遂颈骨微弯、耷着头，始终不开口，沉默格外触目惊心，她终于忍不住站起质问"你连最基本的坦白都做不到，还谈什么没变"。189的身高让他此刻像一座随时会崩塌的山，颓丧气息横逸斜出，他开口"那天——"却又顿住；在周念作势要走、被他握住手腕时，他才低低说出"那天我病了"。她追问是不是从那时开始的多重人格、追问那天身体里的是他自己还是别的人格，他答"是我自己"，随即又说生病的原因只是"感冒了"，让她有一种被狠狠羞辱的感觉。她开始给他捋时间线：6月9日他说要带她逃走却没有来，他从这天消失、她也从这天开始找他，一年后7月《屠佛少年》上映他出现在大荧幕上，让她的坚持成了一个笑话；而《屠佛少年》进组时间是2014年1月，那之前的六个月他在哪里、在做什么，"你从没想过要找我吗"。他欲言又止、指节发颤，始终没有回答，周念一瞬心死抽回手，说"我不逼你了""先把你的病治好吧"，鹤遂却说治病"还不是时候"——因为"我和他做了一个约定，也可以说是一个赌"，而这场赌的内容他没有告诉她。她最后只要了他一个承诺式的检查："我倒要看看，你的身体里都住着些什么人。"

**关键事件**：1. 割腕前那句"我爱你"与"已做好赴死的准备" 2. "如果我就那样死掉，你会不会记我一辈子" 3. "我都会一直记得你""记得曾经的你" 4. 17岁的鹤遂与两张互相救赎的灵魂 5. "那天你为什么没有来？"与"那天我病了" 6. "是我自己"与"感冒了"这个答案 7. 6月9日与《屠佛少年》的时间线、六个月的空缺 8. 治病"还不是时候"与"我和他做了一个赌"

**逐章写法公式**：

- **情绪流向**：起：堵（非要一个答案的假设） → 承：暖（"我都会一直记得你"与十七岁的南水街） → 转：冷（"那天我病了""感冒了"与六个月的空缺） → 合：退（"先把你的病治好吧"与一句"可以"的检查）
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：回溯割腕告白的分量（用一个性格判断给旧场景称重） + 反复追问"你会不会记我一辈子"（把一句问话分三次递进） + "我都会一直记得你""记得曾经的你"（用半句反转给出限定的爱） + 十七岁的南水街与那张网（用意象写两人的互相救赎） + "我没有变，一点都没有变"（让他的自证先立住） + "那天你为什么没有来"（用她唯一的问题把主动权拿回来） + 哽咽诉说与挡开擦泪的手（用拒绝身体接触写她的恨） + 他站着像一座会崩塌的山（用身高与体态写愧疚） + "那天——"的停顿与"你倒是说啊"（把等待拉长） + "那天我病了"与"感冒了"（用最轻的理由砸下最重的羞辱） + 6月9日与《屠佛少年》的时间线（让她自己完成对账） + "那六个月你在哪里"与指节发颤（把问题钉在最痛处） + 一瞬心死的抽手与"我不逼你了"（用退让代替爆发） + "先把你的病治好吧"与"还不是时候"（用一个反常的拒绝制造新悬念） + "我和他做了一个约定…也可以说是一个赌"（把最重要的事留白） + 疲惫蹲下与"那你做个检查可以吧"（用一次让步把剧情推向下一章）
- **本章核心技巧**：整章只有两个问题——"你会不会记我一辈子"和"那天你为什么没有来"，前者让他卑微地索取一次被记住，后者让她把四年的账一次算清；解答之间不断插入可验证的日期与片名（6月9日、2014年1月、《屠佛少年》），把一个情感问题硬生生变成一张时间对不上的表，读者获得的不是情绪而是疑点
- **卡点与伏笔**：结尾卡点：他答应去做检查，"我倒要看看，你的身体里都住着些什么人"——检查结果与那六个月的空缺同时悬置；埋设/回收伏笔：6月9日的承诺与"我会带你逃出这个小镇" → 四年等待的起点，本章首次被具体日期钉住；2014年1月《屠佛少年》进组与13年6月至12月的六个月空白 → 第91章由此得出"短短6个月分裂出其他12个人格"的关键结论；"我和他做了一个约定…也可以说是一个赌" → 鹤遂为何不许沈拂南消失的原因，留待后续揭开；"那天我病了"与"感冒了" → 明显被压住的真相，与第91章的急性应激形成呼应；17岁的鹤遂与"以身入网"的互相救赎 → 与第89章"萤火虫、酸杏、智齿项链的光"同属私密往事清单
- **时间线**：本章紧接第89章同一日上午（阳台与客厅连续场景）

# 第100章 病症 摘要

**概要**：信息飞速传播膨胀的时代，听见怎样的骇人新闻都不足为奇——年轻女生在烧烤店被陌生男子骚扰辱骂殴打致重伤入院、有女子被丈夫故意暴力伤害需终身挂粪袋生活、因承受不住学习压力跳河自杀的十一岁孩子。周念坐在院子里面无表情地翻过一条又一条消息，看见一条似曾看过的新闻：近日我市警方查封一所名为善进的违办寄宿学校，该校涉嫌长期非法拘禁、以各种手段虐待未成年，包括但不限于体罚、关黑屋、禁食、电击；她还住在东济的时候就看过这条新闻，最新消息显示善进学校创办人非法获利800亿，她咋舌，这得祸害多少个家庭的孩子才能搞到这么多钱。那会儿鹤遂冒着夜雨给她买来不少画具，进门时她正在看关于这所学校的新闻，他不动声色地用遥控器关掉电视，让她重新开始画画。距离沈拂南离开已经有小半个月，冉银已经自首、会在两个月之后开庭，她独自住在北清巷的家中，每天给自己做三餐、好好吃饭好好睡觉，其余时间就坐在画室外的挑空阳台上画画，要么就背着画板写生；画画的手感恢复得很快，天赋霸道得不讲半分道理，如今外出写生的她和从前一样，不论在哪里画画，只要周围有人都会忍不住夸她画得好。同时她留意到全国画家联展正在报名征集，便挑了幅近期新画的《晚森流浪》——65厘米×90厘米的布面油画，整幅画以蓝黑色为主、以萤火的微光点缀，光晕落在树木的枝桠间、落在站在乌石块垒最上方的少年背影上，他的衣服被鼓出风包；她用光拿捏许多细节，笔触的收放炉火纯青。一条新的资讯在手机上弹出时，她正坐在南水河边写生，低眸一瞥看见"鹤遂殴打生父有隐情"的字样；顶流团队的公关不是白拿工资的，前提是当事人得配合。她点进那条娱乐资讯，看见视频中召开记者会的沈拂南眼眶微红、苍白薄唇有点颤抖，面对镜头说话时几度哽咽，最后索性转头侧脸对着镜头，眼角一滴悬悬欲落的眼泪配合着隐忍时微微滚动的喉结，直接将破碎感拉满；团队爆出鹤广长年扎针吸毒，证据找得非常充分，说鹤广以此要挟鹤遂索钱，鹤遂发现实情后不愿再出钱，鹤广便找上门挑衅刺激，为的就是能拍下自己被打的视频继续索要钱财。公关文写得逻辑缜密、滴水不漏，舆论完全实现两极反转，五分钟后"鹤遂哭得漂亮"的词条冲上热搜第一；她翻过几页实时评论，想到的却是另一边的沈拂南一转身就会立马擦干眼泪、恢复冷漠神情——道歉和眼泪都是他的手段，而他的演技为他买了单。另一边，结束记者会的沈拂南回到休息室仰靠在沙发里，姿态懒散地抽着烟，漫不经心地问郁成反响怎么样，听郁成说很不错后薄唇微微一勾说那就行；郁成查看行程说还有六天进组，他若有所思地重复"还有六天就三个月了"，随后让郁成帮自己预约精神卫生中心的号，时间定在六天后。周念很少再做关于周尽商的噩梦，只是眠浅易醒的习惯没改掉，九点上床十一点半就醒，下楼找水喝——如今一个人住一座房屋，到夜里难免有点害怕，喝完水从厨房回堂屋时她看一眼黑漆漆的院子、看在夜里静止不动的瓜藤木架，刻意放轻脚步生怕惊扰到某些夜间生物。突如其来的敲门声吓得她浑身一个激灵，在开门前她假设过好多个人，却偏偏是万万没想到的那一个——门外站着的不是别人，而是半个月没见过的鹤遂。他穿着一件黑色冲锋衣、帽檐拉过头顶遮住双眼和颧骨，听见她的声音才缓缓抬起头来，一双眸黑白分明、眼角凛着凉意，准确地与她四目相对；她怔住，视线往下几寸看见他身前捧着一个东西，借着半扇月光看清那是一株长势蓬勃的万年青，底座是她熟悉的粉色花盆。她呐呐地说"怎么会，我明明把它——"，他低声接下去"把它扔在了京佛的精神病院"；没错，她离开时带走了所有东西、小到哪怕一根数据线，唯独把它留在阳光照不到的阴暗墙角任由自生自灭，她以为它早该枯萎腐烂，现在却生机勃勃地重新出现在眼前。半个月前，在鹤遂不知情的情况下沈拂南回到京佛，并告诉他周念不会回到他身边的消息，说或许你装点可怜、周小姐会因为赌约和你在一起，又立刻否定"但你不会选择那么做"——你不止想要她爱你，还想要她毫无杂质地爱你，你不会接受她因为同情怜悯而和你在一起；鹤遂在昏暗灯光里凑近镜面，沉声说他不会听一面之词，她的心意究竟怎样他要亲自听她说，沈拂南势在必得地说不介意他去见她最后一面，但提醒他"你的时间不多了，你还有半个月的时间"。鹤遂记得还在京佛精神病院时，病房里始终摆着一株粉色花盆的万年青，他当时被强烈压制、出来的次数寥寥可数，但他就是记得，并且认出那就是他当初送给周念当十八岁生日礼物的那一株——他当然要回去找她，但在回去之前，他要把两人间的信物一并带回。他找到那株万年青时它被收在护士台，保洁阿姨清扫病房时没有将它一并扫进垃圾袋，它被放在杂物角，堆叠着旧资料和坏了一条腿的椅子，叶片边缘干得有些翻卷，但还是活着的；他带它回家精心侍弄，每天都让它晒足够的太阳，看叶片逐渐舒展、翻厚、绿意重新旺盛，差不多十天左右它竟然开了淡黄色的花束、散发着淡淡香气——养得好的万年青才会开花结果，去年周念让它结了果，今年鹤遂让它开了花，他觉得开花是好兆头，于是在开花的第一天登上了飞往云宜的飞机。他把万年青捧高举至她眼前，她睫毛微颤，看一眼万年青又抬头看他，他深深看着她的眼，低低徐徐地说"念念，我们万年长青"——那一瞬间她仿佛回到四年前11月的冬夜，他也是这样深深凝视她的眼说着一模一样的话。只是时光荏苒，她在与他分别的四年里经历过身败名裂、无数次呕吐、五识尽丧，还有一千多个翻来覆去睡不着的夜晚；即便现在身体恢复良好，那些经历永远是横在她内心的一道伤疤，伤疤教会她不要把自身的中心依靠在他人身上，她逐渐找到真的自我，只为自己而活才是真的新生。她迟迟没有伸手去接那株万年青，清晰地看见他眸中的光在一点一点流逝泯灭、直到完全暗淡；夜风微凉，她在风里找回自己的声音说"对不起，鹤遂"，每一个字都说得很慢也特别清楚，他怔愣好几秒才缓过神，薄唇动了动却什么都没能说出来。她再次开口，很平静地说其实没有什么是不可摧毁的，你的诺言、我们的约定，包括一切我自以为的坚不可摧；他抬手把帽子拉下、神色落寞地点头说"你还是恨我"，她当即否认说恨一个人很累、我不会去恨，况且知道了多重人格的事也恨不起来。他追问"既然你不恨我，那我们……"，她还是决定把话说清楚——不恨你不意味着我们还能在一起，这压根是两码事，我希望自己过得好、你也过得好，也就是说我们各自都能好好生活；他只觉得脑中混沌不堪，沉默好久才喑哑地说"可没有你，我不会过得好"，她看着眼前浑身流动着低气压、似乎下一秒就要碎掉的他，目光变得小心翼翼，内心开始动摇，问他"要是我答应你，你是不是就不用消失三个月了"。他胸壑里被切肤的痛填满，面上却还稳得住，很淡定地摇头说"不，没关系"，又说要是你因为这样答应和我在一起，那我不是在对你进行道德绑架——他想要她纯粹的爱，要她很多很多的爱。他在最后把万年青再次递出去说"把这个收下吧，它能活着回来见你也不容易"，她尚未听懂话中意，只懵懂地接过，顺便说"你要是想见我，随时都可以"，又补了句"如果你方便的话"，他低低嗯一声、脸上瞧不出情绪。她看见他转身、将帽子拉过头顶遮住眉眼、浑身洇在黑暗里，便叫住他，捧着那株万年青极诚地说"希望你后续可以进行治疗，早点好起来"；他没有开口，生怕声音会驱散空气里有关她的余音和气息，只转过半张脸、下颌线清晰，黑夜深远透着无尽的悲凉，风里隐隐传来呜咽声，最终他离去的背影在这暗里黑透，连一丝气息都不曾留下。

**逐章写法公式**：

- **情绪流向**：起：压抑（社会新闻、善进与800亿） → 承：其他（她的恢复、公关战的表演） → 转：紧张与期待（深夜敲门、捧回的万年青） → 合：悲伤（拒绝、道德绑架的自我否决与黑透的背影）
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：日常线（新闻、画画、联展投稿） + 舆论线（记者会、反转、热搜） + 信物线（万年青的丢弃、找回、开花与送回） + 对峙线（拒绝、挽留、自我否决与离场）
- **本章核心技巧**：用一株万年青串起全章——它既是四年前的信物、又是被丢弃的证据、也是被救活的希望，最后成为一场拒绝里唯一被递出去的东西；物件承担了所有说不出口的话。
- **卡点与伏笔**：结尾卡点：他带着"没有你我不会过得好"离场，六天后是精神卫生中心的预约与三个月的期限终点，下章期待是三个月到期后沈拂南是否会消失、鹤遂能否回来；埋设/回收伏笔：三个月赌约（只剩六天）→ 最大悬念；六天后进组与精神卫生中心的预约（新线）；《晚森流浪》投稿全国画家联展 → 回收于第119章画展；冉银两个月后开庭（倒计时）；善进学校被查封、创办人非法获利800亿 ↔ 他在东济关掉电视（回收）；鹤广吸毒要挟的真相（舆论反转）；"去年结果、今年开花"（万年青的两年对仗）；"你要是想见我，随时都可以"（留门）。

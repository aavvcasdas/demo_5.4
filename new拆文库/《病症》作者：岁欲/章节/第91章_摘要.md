# 第91章 病症 摘要

**概要**：鹤遂的检查由韩老亲自做，六小时后她拿着很厚一叠检验表出来，穿淡蓝色病服的男人紧随其后。走廊上鹤遂一直走在周念身后、保持两步远的距离，看着她垂在身侧纤细苍白的手指，伸出手去想拉她的手一起走，偏偏在马上要触碰到时倏地缩回——他怕她嫌弃、也怕她生气，只能极度克己地把眼里的隐忍潜藏，而周念并无察觉；他亦步亦趋地跟着，只要她回头就能看见，她却始终没有回头。到病房会议室后，韩老说的第一句话是"通过人格真伪鉴定，他的多重人格是真的，不是装的"；她解释有人犯罪后装疯卖傻、质控凶手是自己身体里的另一个人格，但成功的几率基本上是零，因为专业检查下结果不会说谎。韩老把检查表放在桌上说，这次做了心理测试和生理检查——每个人格的智商和思维模式都不同，做催眠询问时他们的EEG脑电波都有区别，还有皮肤电阻等方面的差异，目前他被确证为分离性身份障碍。周念说她见过其他三个：沈拂南、老墨，还有一只蝴蝶，韩老摆手说"那你一半儿都没见到呢"，并告知他身体里有十一个副人格，加主人格总的有十三个人格，把周念吓到。韩老又苦笑说副人格里有的人格真的很棘手——有一个刚出来没说两句就冒火发脾气、差点把她电脑显示屏砸地上，还有一个出来后跳到她桌子上蹲着盯着她看，搞了半天才知道那是一个猫的人格；最难聊的还是特傲的沈拂南，愣是不说话，两人大眼瞪小眼耗了一个小时才撬开他的嘴。韩老递来一张A4检查记录表，上面密密麻麻记着人格详情：六月龄黑猫常年流浪、身上有烟头烫伤与开水泼痕，对人类戒备极重，却会风雨无阻在小巷等一个每次来投喂都穿白裙子的人类女孩；存活15天的克莱因蓝色蝴蝶喜欢在下雨的浓雾里出现，最终都会被一个少年抓住杀死、掉进泥土里腐烂，等待下一次破茧；6岁的小智不会笑、讨厌与人接触、只喜欢待在没有开灯的房间里发呆，手里捏着一支全新未削过的铅笔；17岁的孪生兄弟宋莱与宋榭；43岁的家庭主妇许惠柔从不强迫女儿做任何不喜欢的事；27岁开宠物店、专做宠物救助的夏尔澈；32岁的著名牙医顾无白；41岁穿白背心、卖橘子、"你们不吃就算了！下次不带了！"的老墨；28岁的明星御用营养师游暗；23岁在血站上班、爱发牢骚的桑遣；30岁忙着抓扒手小偷的基层民警阿烈；以及22岁、最新分裂出的人格沈拂南——一个没有过去的空白人物，年轻英俊、性格傲气冷漠，演戏天赋属于被老天爷哭着求着喂饭那种，其他所有人格都怕他并心甘情愿被他压制，除了主人格。周念看完久久不能平静，冥冥中觉得这些人格或多或少和她脱不了关系——比如那只黑猫永远在等一个穿白裙子的人类女孩，而她最常穿的就是白裙子。韩老又说多重人格发现得早及时治疗可以很好控制，他现在已有十二个副人格，说明患病时间不短、起码好几年；周念说"四年"，韩老却纠正说不是，通过和鹤遂谈话得知，他是在短短6个月里就分裂出其他12个人格。时间线完整对上：沈拂南2014年1月进组，鹤遂则从2013年6月消失持续到12月，这六个月他患上了多重人格，而他那时人在哪里、经历过什么是莫大的疑问；那场长达六小时的检查里，韩老一聊到这个问题就仿佛有一堵看不见的墙。周念把人格表放在他面前，说"我想要你对我坦白""你想要我们回到过去，你又对我保守秘密，这可能吗"，随后追问"那六个月你到底在哪里"——话音落下，鹤遂胸膛高起、急遽喘息，骤然睁眼、黑眸欲裂般瞪着，浑身疯狂哆嗦，想站起来却狼狈滑倒在地、痛苦至极地蜷着身体。韩老说这是"应激了"；鹤遂蜷在她脚边，额头暴出大颗冷汗和青筋、脖子也起了爆根，大张嘴像无法呼吸，饶是这样他还是颤悠悠伸出一只手握住周念的脚踝，挤出两个字"别、别走"。护士与护工被按铃叫来，鹤遂被挪到病床上打了一针安定，很快入睡。韩老后来解释，是周念的发问让他产生了急性应激，说明那六个月里他一定有过不愉快的经历、说不定是巨大创伤，才会反应如此激烈；周念沉默良久，明白他并不是不愿意告诉她，而是深有苦衷、有口难开，只要一回想就会感到莫大痛苦。她来到床边看着男人熟睡中的脸，静谧英俊、睫毛比女子都要长，心里只留下一句"鹤遂，你究竟经历了什么"。

**关键事件**：1. 走廊上伸出又缩回的那只手 2. "是真的，不是装的"与真伪鉴定 3. "你一半儿都没见到呢"与十三个的数目 4. 砸显示屏、跳上桌子蹲着的猫人格、耗一个小时的沈拂南 5. 十二个人格记录表（黑猫、蝴蝶、小智、宋莱宋榭、许惠柔、夏尔澈、顾无白、老墨、游暗、桑遣、阿烈、沈拂南）6. 黑猫等的是穿白裙子的人类女孩 7. 六个月分裂出十二个人格 8. 一句追问引发的急性应激与"别、别走"

**逐章写法公式**：

- **情绪流向**：起：酸（走廊上缩回的那只手） → 承：奇（真伪鉴定、十三个与一副副人格档案） → 转：寒（四年前六个月的空缺） → 合：痛（急性应激、蜷在地上的"别、别走"）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：六小时后出检查室（用等待时长交代检查的分量） + 身后两步远的手与缩回（用未完成的动作写他的克制） + "是真的，不是装的"（用真伪鉴定把怀疑一次排除） + 检查项目与脑电波差异（用专业名词给设定加固） + 汇报副人格数量（用一个数字反问把规模揭开） + 医生的两件轶事（用砸屏与猫人格的可笑案例写危险与荒诞） + 人格记录表的逐条陈列（用档案体把设定一次性铺满） + 黑猫等白裙子女孩（在档案里埋下最重的一钩） + 她的自我指认与手指发抖（让角色自己完成拼图） + "12个副人格说明患病时间不短"与"短短6个月"（用两个不同的时间跨度制造疑问） + 13年6月至14年1月的对齐（把空缺定格在六个月） + 六小时里问不出的那堵墙（用医生的失败侧面写创伤深度） + "你想要我们回到过去，又保守秘密"（把矛盾摆到台面） + "那六个月你到底在哪里"（用一句追问点燃应激） + 从喘到滑倒在地的生理级联（把创伤写成身体反应） + 握住脚踝的"别、别走"（用最小的台词完成情感结算） + 病床边"你究竟经历了什么"（用一句无声的疑问收章）
- **本章核心技巧**：把"设定交代"和"创伤取证"装进同一场对话——前半段用一张人格记录表把十二个副人格全部摊开，让读者在逐条扫读中自己发现这些身份（等白裙女孩的黑猫、被少年抓住杀死的蝴蝶、铅笔全新未削的六岁小孩、从不强迫女儿的母亲）全都指向周念与鹤遂的过往；后半段只用一个问题就让他的身体当场崩溃，把纸面上的档案变成可见的疼痛
- **卡点与伏笔**：结尾卡点：她盯着他熟睡的脸问"鹤遂，你究竟经历了什么"，那六个月的内容与急性应激的原因同时悬置；埋设/回收伏笔：黑猫"人类女孩子每次来投喂它都穿白裙子" → 直指周念，是她认定这些人格与自己有关的依据；克莱因蓝色蝴蝶"最终都会被一个少年抓住杀死" → 与第87章挥手臂的蝴蝶人格、沈拂南口中"那个少年"相关联；小智手里那支全新未削过的铅笔 → 与第92章鹤遂买画具让她"重新开始画画"直接呼应；许惠柔"从来不会强迫女儿做任何不喜欢的事情" → 与冉银对周念的相处方式形成对照；沈拂南"一个没有过去的空白人物"与"其他人格都怕他" → 解释他为何能压制全场；"13年6月到12月的六个月" → 与第90章"《屠佛少年》2014年1月进组"对齐，成为全书最大的谜面；急性应激与"他承受过巨大创伤" → 与韩老所说的病因"童年创伤和环境因素"对接；原文内部冲突：韩老口述"十一个副人格，加他的主人格，总的有十三个人格"，而记录表标题写"副人格数量：12"，两处数字不一致，已按原文保留
- **时间线**：本章为第90章当日检查开始后六小时至当夜

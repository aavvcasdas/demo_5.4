# 第47章 病症 摘要

**概要**：比日光更晃眼的是浮尸被泡发后的皮肤，一种不掺任何杂质的死白；两具女尸面朝下漂在水面，一大一小，穿着冬季厚棉服，长长的黑发散浮着像两团水草。周念在瞳孔一寸寸放大中看见小的那具尸体五指粘连在一起，惊慌地捂住嘴把尖叫堵住，转头去看对岸的鹤遂——那个终日冷淡、喜怒不形于色的人此刻满眼震惊、一脸错愕，眸光在逐秒逐分破碎。他指间的烟坠落在地，没有犹豫地纵身跳进南水河；周念爆发出尖叫，河面的浮尸与跳河捞尸的少年很快引来一大群人聚在两岸看热闹，人们带着讥讽的表情看他在水里，恨不得把"活该"写在脸上。周念冲向岸边时被冉银一把拽住质问"你想做什么""休想让我在这么多人面前丢脸"，她发疯一般挣脱，手臂被冉银的指甲划出两道血痕。鹤遂游到尸体旁把大的那具手臂搭在自己肩上，一动才发现两具尸体连在一起、只能同时驮着游回岸边，水里阻力太大、他渐渐体力不支，上半身不住地没入水面，被湍急水流推着往下游方向移去，却始终没有放弃肩上的两具尸体。周念在岸边急得团团转——涨水期的南水河每年都会淹死几个人，两岸却没有一个懂水性的镇民愿意下水帮他，除非有另一个值得他们伸以援手的人，想到这里她没有任何犹豫地抬脚跳了下去；不会游泳的冉银撕心裂肺地喊着，人群中爆发出哗然，认出跳下去的是"画画那个小姑娘""周家丫头"，冉银扑进人堆哭着哀求"救救我女儿"，镇民们念着周念是学习好、画画常得奖的乖乖女，纷纷扒掉上衣跳入水中。周念的落点刚好在鹤遂旁边，他哪怕已经身负重荷也第一时间朝她伸手；一个四十多岁的大叔喊着"来，孩子，抓住我"，她抓住大叔的手臂后第一件事就是去抓鹤遂的手，怕他们只救她一个人；呛了好几口水后她终于一把抓住鹤遂的手腕、用力到像是生怕他下一秒就会从手中流走，其他人只得合力将周念、鹤遂和大小两具尸体一起拉上岸。周念趴在岸边狂吐，被冉银在背上打了两下；众人围拢过来拍照，昔日小镇上最美的女人已变成一具被河水泡发的青面女尸，旁边是才重见天日就已走向死亡的宋平安——两岁起被铁链拴着、一拴十年，摆脱铁链的第三天被哥哥从南水河里打捞起来。母女两人的手腕上各有一根麻绳把彼此的一只手拴在一起，宋敏桃的一只脚踝上还拴着一根连着破洞棉布口袋的麻绳，袋里此前一定装过足以让母女溺亡的重物。鹤遂左右手臂各揽着一具尸体、把下巴轻轻放在它们中间，大手不停摩挲着她们的胳膊想给一点温度，脑子里钻的牛角尖竟是前天晚上宋敏桃夹给他的那块啤酒鸭、问他当时为什么没有接下。周念吐完爬到他身边，握住他的手哽咽说"我会陪着你，我会一直陪着你"，不在乎四周诧异的目光，也不愿再做那个胆小怕事的周念；冉银来拉她，她狠狠抱住鹤遂的脖子不肯离去，冉银气急攻心两眼一黑栽倒在地。警察、救护车和殡仪馆的车随后赶到，急救人员说冉银只是情绪过于激动导致晕倒、没有大碍，周念仍决定留下陪鹤遂而不跟去医院。警察在宋敏桃的裤子口袋里发现了一封用塑料袋包好、未被水打湿的遗书，字迹是宋敏桃的：她说自己已带着妹妹去了一个很美好的地方，那里没有流言蜚语、没人会拿异样目光看妹妹，说妹妹终身需要照顾、不想在阿遂的人生里添加更多阻碍，说给妹妹和自己都穿了厚棉服所以路上不会冷，嘱咐阿遂好好吃饭、好好睡觉、把自己重新养一遍，并回答了他曾问过的那个问题——她从来没有后悔过生下他，有了他是她的幸运。遗书末尾还画了一个可爱阳光的笑脸，鹤遂看完依旧面无表情，那些字迹上却已落满数不清的眼泪，周念抬眼望去，发现他早就哭湿了脸。

**关键事件**：1. 浮尸确认为被麻绳相系、脚踝坠重物的宋敏桃与宋平安 2. 鹤遂跳河捞尸、镇民围观讥讽无人援手 3. 周念不会游泳却跳河、以自己换来众人下水 4. 上岸后鹤遂抱着两具尸体摩挲取暖、冉银晕倒 5. 塑料袋里的遗书被找到并读完

**逐章写法公式**：

- **情绪流向**：起：惧（泡发死白与五指粘连的身份确认） → 承：怒（跳河、围观者的讥讽与母亲的阻拦） → 转：燃与痛（不会游泳的女主跳河、众人下水、尸体被打捞上岸） → 合：崩（遗书、眼泪与那张手绘的笑脸）
- **节奏配比**：慢铺垫 10% / 快冲突 35% / 爽点爆发 15% / 悬念留白 40%
- **本章结构公式**：浮尸特写与身份认证（让读者先于心认人） + 鹤遂跳河与两岸围观（写全镇的冷） + 母亲拽阻与两道血痕（把女主的选择摆上台面） + 尸体相连与体力不支（把救援写成一个死局） + 女主跳河与接力救援（用一个牺牲动作撬动全场） + 上岸的呕吐与母亲的质问（回到家庭的压迫） + 现场物证与抱着尸体的姿势（把惨剧写成画面） + 冉银晕倒与警察到场（清场收束） + 遗书全文与手绘笑脸（用逝者的声音完成最后一击）
- **本章核心技巧**：用一场公共救援把"全镇的恶意"一次性演完——同一群人先看笑话、后下水救人，改变他们只需一个他们喜欢的乖孩子跳下去；章的重量则全部压在末尾那封被塑料袋保护好的信上，让死者自己说话
- **卡点与伏笔**：结尾卡点：遗书读完、"他早就哭湿了脸"，母亲的动机与遗愿已完全揭开，下章期待转向鹤遂的安置与周念与母亲的决裂代价；埋设/回收伏笔：宋敏桃饭后反复重写的那张纸 → 本章回收为遗书（第45章的沙沙写字在此兑现）；脚踝麻绳与破洞棉布口袋 → 固化自杀事实与重物来源；宋平安"摆脱铁链的第三天" → 铁链被解除的时间点，隐含母女离开前的动作；遗书中"你曾经问过妈妈一个问题，后不后悔生下你" → 鹤遂的身世自认；宋敏桃"我明明什么都没做，他们却说我是荡妇" → 与刘春花等人的流言线收束；周念不会游泳却跳河 → 冉银的晕倒与后续母女关系的必然清算

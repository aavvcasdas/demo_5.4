# 第118章 病症 摘要

**概要**：上午九点，周念和鹤遂抵达东济，是郁成开的车，一路上甩掉了多辆跟拍的车，两人直接去往韩老的诊室。韩老看见推门进来的两人，目光先落在周念脸上，欣慰地说小姑娘恢复得不错、光看脸都知道长了不少肉，她温和地答现在81斤，韩老点头说不错继续保持、三餐都要好好吃；随后韩老扶一扶眼镜把目光转向鹤遂，以轻松的口吻问"终于舍得来治疗啦"，他看一眼身旁的周念淡淡地应了一声——她明白，如果不是为了她，他肯定还是不愿意来治疗，他在为她做很大的妥协和让步。韩老示意两人坐下，用通俗易懂的话解释人格整合的治疗流程：手段是催眠疗法，让他身体里的其他12个副人格通过催眠治疗去融合、使他们成为一个整体，而不是单独去杀死某个人格，因为不论哪一个副人格都是主人格的一部分，如果进行绞杀，会让整体人格遭到破坏。他听完淡淡地问第一个接受整合的对象是谁，韩老手里拿着人格详细单反问"你想整合谁"，他说沈拂南是个麻烦人物、如果能将他解决那其他人格都会很好办；韩老沉默一秒说"那就他吧"，起身带他们去催眠室，说治疗需要进行多次、今天可以进行第一次。周念只能留在门外等，鹤遂和韩老进去，催眠开始——韩老用催眠手段把沈拂南唤醒，问"早上好，感觉怎么样"，沈拂南满脸阴鸷地反问你觉得我看上去很好的样子，并说鹤遂居然要为了一个女人杀死我、杀了作为救命恩人的我，不可笑吗，你现在坐在我面前就代表他已经在行动了。韩老云淡风轻地说"他杀不死你的"，解释他只是想让你们成为整体；沈拂南反问"谁要和他成为整体"，韩老笑笑说成为整体你们就可以一起做很多事情、也不用起争执，你本来也就是他的一部分，不然也不会分裂存在。沈拂南沉默一瞬说"可我想拍戏"，韩老立刻接话：你可以继续拍戏，他现在一点都不愿意让你出来，但如果你融合就可以继续拍，你想继续拍戏吗——他说"我当然想"，韩老乘胜追击让他闭上眼睛、把自己想象成他的一部分，你是他、他也是你，你们是一部分，你可以做任何想做的事包括你最喜欢的拍戏。沈拂南猛地睁开眼睛问"可他要是不愿意拍戏怎么办"，韩老赶紧说放心、他非常愿意，我已经问过他了，现在你只需要相信我，我会帮助你和他成为一个整体，这样你也不会被他压制，你会享有24小时的自由权；他思索片刻问"我怎么知道你说的是真是假"，韩老便提议叫鹤遂出来聊，他说行吧、我亲自跟他聊。韩老做了一个催眠中惯用的触发动作——触碰男人的额头，沈拂南随即冷笑一声说"你还真愿意舍得出来和我聊"，韩老知道这是沈拂南看见鹤遂的表现，是好的开始。韩老问他给你说什么，沈拂南眸光凝定在虚空某个点上，转述说他说他会继续拍戏、不会把时光荒废，前提是我好好配合进行人格整合；又补一句"就像你说的，治疗只是把我们融合成一个整体，并不是要杀死我"，韩老笑着温柔低语"对，对的，就是这样的"。韩老问"现在呢"，他说"他朝我伸出了一只手"，韩老鼓励"很好，握住他"。催眠治疗在一个半小时后结束，沈拂南和鹤遂成功融为一体——治疗比韩老想象中还要顺利，归根结底是解决了沈拂南这个副人格最担心的事情：他想要拍戏，想要万人仰慕的功成名就，于是让他明确知道自己可以拍戏、可以继续当大明星后，他就选择妥协、愿意重新与鹤遂成为一体。周念一直在催眠室外等着，听到开门声立马站起来，韩老说这次催眠治疗非常成功，下次治疗时间定在下周、频率一周一次最好，保持良好的持续治疗一直到他身体里的人格全部融合；她松一口气说那就好。他拉起她的手往电梯走去，她问感觉怎么样，他说感觉很奇妙——现在他能感受到沈拂南是自己的一部分，有他的全部记忆，包括他拍戏时那些鲜明的情绪感受都能感受到。她小心翼翼地问既然有他全部记忆，那这四年前他有没有和其他女人……他挑眉故意反问"和其他女人恩爱？"，这一声反问后他沉吟几秒，说"和其他女人吃烛光晚餐，留她们过夜算吗"；她瞠目结舌，当然算。电梯正好到层，两扇银色大门缓缓打开，他抬脚往前，手上却感受到一股阻力——拉着的她还站着一动不动；他停住问怎么，她垂着眼不看他，说"你自己坐电梯吧，我想走楼梯"，顺势松开他的手。他重新拉起她说那我也走楼梯，她又把手抽走环在胸前说自己走，转身就走进安全通道，下楼速度快得像突然叠加了一层加速，快得后面身高腿长的男人都要三步并两步迈楼梯。在一个拐角平台，她的手腕倏地被他握住，身后传来玩味的嗓音"真生气了？"，她嘴硬说才没有，却别开眼不肯看他、眼角有泛红的趋势；他看她一副要哭的架势立马缴械投降，坦白说"我逗你玩的，就想看你会不会吃醋"。她哽了一下说我不仅吃醋还生气，你满意了；他敛了敛笑意解释，沈拂南只爱名利，他要是想谈恋爱，一开始就会追求生雅娇，和女人恩爱的记忆是没有，倒是有很多他无情拒绝、把那些姑娘搞得嗷嗷哭的记忆——她听见"嗷嗷哭"有点想笑，觉得用一副要哭的脸笑会很诡异，于是强行忍住。他重新伸手拉她，这次她没躲，但也不打算轻易放过他："这就算完了？"他低低笑着问"那我背你下楼"，她说"勉强接受吧"，他被这个字眼逗乐说行、勉强就勉强吧，随即在她面前半蹲下身；她恶趣味地伸手戳了戳他头上那个反方向的漩，才慢吞吞爬到他的背上——他的背宽实有力、身上是好闻的清爽味道，头发蓬松茂密，会随着下楼梯的步伐一颤一颤，更会有一下没一下地扫在她的侧脸，让她觉得痒酥酥的。她把脸放在他耳朵边，有点委屈地说"你不可以有别人，只可以有我"，他侧过半张脸问哪有别人，她强调"开玩笑也不可以"，他失笑着认栽："行，没有别人。"

**关键事件**：1. 甩掉跟拍抵达东济 2. 81斤与"终于舍得来治疗啦" 3. 融合不是绞杀 4. 第一个整合对象是沈拂南 5. "为了一个女人杀死我" 6. "可我想拍戏" 7. 24小时自由权的许诺 8. "他朝我伸出了一只手" 9. 一个半小时后融为一体 10. 一周一次直到全部融合 11. 烛光晚餐与留她们过夜 12. 背下楼时那句"只可以有我"

**逐章写法公式**：

- **情绪流向**：起：期待（抵达东济、讲解疗法、选定沈拂南） → 承：紧张（唤醒后的质问、谈判与怀疑） → 转：爽（一个半小时后融为一体、顺利得超预期） → 合：轻松转甜（一句玩笑引爆吃醋、楼梯间的追逐与背下楼）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 20% / 悬念留白 35%
- **本章结构公式**：就诊（把治疗动机与规则一次说清） + 谈判（让最难缠的副人格在欲望上被说服） + 结果（用一个动作完成融合并给出后续排期） + 余波（用一句吃醋玩笑把严肃的治疗反转为甜的收尾）
- **本章核心技巧**：把一场心理治疗写成"谈判"——先让对手亮出真正想要的东西（拍戏与功成名就），再用他想要的东西换取合作，最后用一个可见的动作（伸出手、握住）完成抽象的人格融合。
- **卡点与伏笔**：结尾卡点：沈拂南已融合，但其余十一个副人格尚未整合、下次治疗定在下周，下章期待是余下人格的整合进度与最终结果；埋设/回收伏笔：81斤 ↔ 他"迟早把你喂到四十九公斤"的目标；"融合不是绞杀"（治疗原则）；沈拂南要拍戏、要24小时自由权（已兑现）；一周一次、直到人格全部融合（排期）；两天后的生雅娇订婚宴与回京佛（倒计时仍在）；"你不可以有别人，只可以有我" ↔ 生雅娇的订婚宴。

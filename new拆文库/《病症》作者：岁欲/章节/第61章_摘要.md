# 第61章 病症 摘要

**概要**：时隔四年再次感受到他的指温，周念如坠梦境，偏偏男人薄凉如水的目光又在不停提醒她这不是梦——他就在眼前，他的手指正被她握在掌心；她彻底慌了神，忘记做出反应也忘记松开。鹤遂漫不经心地淡扫过她的脸，而后看向她床头墙上贴着的电子屏幕，目光很快划过患者姓名那一栏，再次开口时只叫了一声"周小姐？"；这一声像给了周念当头一棒，将她从自以为的梦境里强拽回现实——他从前叫她周念、周七斤、念念，"周小姐"还是她第一次从他嘴里听见，他语气没有一点温度，陌生得真像是第一次认识她，眸底还有被几次三番冒犯过后才会有的韫凉。她脑中一片空白，还没来得及想好要不要道歉，他就看着她的手意有所指地问"周小姐，还想握多久"。男助理嚷着"哎呀，怎么又是你！""阴魂不散啊你"快步绕过病床，重重攥着周念的手臂甩开，她的手甩撞在床侧栏杆上、闷响一声后钻心的疼痛传来；助理如临大敌般挡在鹤遂面前指着她质问"这是第三次了吧"，她低头看见手臂外侧被撞出一团红紫——她只有骨头和皮肤、没有肌肉保护，稍有磕碰都会造成触目的伤色，这要是从前鹤遂是不会允许任何人这样伤她的。助理骂她装可怜、说自己对付过的私生多了去，又转头问要不要联系主任换病房、说私生本来就危险、疯子私生岂不是险上加险，鹤遂看了眼对床的裴巷只说"不用"，助理再提议把她换走，他也只说"不用麻烦"。助理前脚刚走，裴巷就来叫她一起去食堂，她摇头说还不饿，裴巷反问"你有饿的时候吗"——住在一起彼此都知道对方的病况，他当然知道她对饥饿的感受非常不明确；随后裴巷拉着徐散去食堂吃早餐，病房里只剩下周念和鹤遂两个人。她努力让混沌的脑子找回理智，突然意识到一个问题：他为什么会出现在这里，这里可是精神病院。她小心翼翼地偷偷打量他，看见他站在床边低头像是在给谁回消息、唇角勾着一丝浅淡的笑弧，身上穿的确实是病号服；与此同时她注意到他滑出宽大袖口的手腕上缠着白色纱布，肉眼可见最少缠了三层，便下意识开口"你受伤了吗"——刚说完就觉得很不妥，她现在的立场连一个粉丝都算不上，只是一个招人讨厌的私生；果然他的反应就是没有任何反应，继续回复着谁的消息、眼皮都不曾抬一下，她只好安静下来，枯坐在床上像一株马上就要枯死的植物。护士拿着她早上要吃的药进来，一进门眼睛就定在鹤遂身上——正是上次电梯里手机屏保是他，这位护士交代完吃药便小心翼翼地请求合照，说自己从第一部电影开始就喜欢他、每部电影都刷了五遍以上；上一秒还在回消息的鹤遂马上抬头，目光温和而很有礼貌地淡淡一笑说"可以"，还迁就地弯腰俯身把肩膀对齐只有一米五的护士，与她正对着周念拍了很多张，拍完护士开心得眼睛都红了、离开时脚步轻快。这让周念又想起从前——那时她总喜欢缠着他拍照，要么乖乖站在他胸口前、要么和他头贴头，他每次都很配合，她想怎么拍就怎么拍；她猝不及防地问"鹤遂，我也能和你拍照吗"，他清冷的目光落过来，居高临下地笑着反问"怎么？我记得你很清楚地说过，你不是我的粉丝"，那是重逢后的第一次见面在户外路演现场她确实说过的话。她问他"你只记得这个吗""还记不记得别的什么"，心里想问的是那些小镇的日子、他说过喜欢她、还有他要带她逃走的承诺，却没能问出口；她看着他的眸光变得越来越深暗难测、俊脸上凉薄不减，仿佛正在酝酿堪比毒箭的回答，就在他薄唇微张快要出声的那一秒，病房门被人打开——男助理拎着大包小包进来，抱怨"这电影还有一个月才开机，你非要先住到这里来提前感受，我生怕带的东西不够"。周念怔住：他不是因为生病才住进来的，而是为了拍电影；从助理絮絮叨叨的话里她才弄明白，鹤遂的下一部电影是关于精神病人的题材，为了更贴合角色、在取得院方同意后他选择提前一个月入住精神病院，将饰演一个患上双相情感障碍的知名小提琴家，因为需要观察一个真正的双相患者，所以被安排和裴巷一个病房。她不禁在心里嘲笑自己愚蠢、笑自己还忍不住关心他——如今的他风光无限怎么会变成一个精神病，有病的只有她。随后他问助理"郁成，琴带了么"，助理得意地说新电影里拉小提琴肯定会再一次惊艳观众、还说"活该遂哥你是长红不衰的命"，他只回"得了，少马屁"；助理又问他手腕怎么伤到的、昨晚送他回去时都是好的，周念看见他神色明显凝了一下、眸底有一闪而过的阴暗，随即恢复如常只说"不小心弄到的"，被追问流血与纱布时也只答"没事"。她下床接了杯水、空腹把药吃了，抬头就看见冉银出现在门口，她的目光粘在鹤遂脸上，腔调格外阴阳怪气地说"大明星也有精神病吗""打小就不是什么好苗的人"；鹤遂转眸的视线如结寒霜、下颌角线条崩得很紧，助理没忍住回怼，冉银冷笑着说有些人只敢把曾经的所作所为藏着掖着，又说"你当初成天追着我女儿后面跑的时候，可不是这个样子"，鹤遂出声制止助理"别理"。助理看了眼周念不屑地说"就她啊——？我呸""你知不知道追我们遂哥的都有谁啊""数不完的千金名媛还有当红小花，遂哥追着你家病秧子女儿屁股后面跑？想啥屁吃呢"；周念一字不落地听着，知道追他的人很多，便很平静地叫他的名字问"所以你恋爱了吗"，他神色比她更平静地回"这似乎和你没关系"。她竭力控制住发颤的声音，说如果他真的和自己彻底没关系就回答她的问题——是不是真的不记得她、四年前的六月九号那天晚上为什么没有来火车站、又为什么丢掉了她写给他的信；随后她抬脚朝他走去、身子在虚空中微微晃着，助理如临大敌想拦，鹤遂却抬手示意他别动，她便畅通无阻地走到他面前，抬脸迎着微凉的目光微微一笑说"你想要摆脱我对吗""那你起码得拿出点诚意来""告诉我答案"。死寂的沉默在病房中漫延，随着她越来越紊乱急促的呼吸，他的嗓音低低响起"周小姐，那些都已经不再重要"——又是周小姐，他还说那些都不重要；周念觉得自己就是个天大的笑话，看着他突然开始笑起来，本该甜美的小梨涡看上去那么悲怆，她由无声笑到笑出声、笑出眼泪，纵使视线模糊泥泞也不肯从他脸上移开；他缓缓皱了眉，下一秒只见她身体剧烈颤了颤，随后张嘴，一大口猩红液体瞬间喷涌出来，鲜血糊了鹤遂一脸，他的眼前瞬间沦为一片红光。

**关键事件**：1. "周小姐"的称呼与"还想握多久" 2. 助理甩手致她撞伤、提议换病房被拒 3. 裴巷的早餐邀请与"你有饿的时候吗" 4. 手腕上三层白纱布 5. 护士的合照与"我记得你说过你不是我的粉丝" 6. 为拍精神病人题材提前一月入住、与裴巷同房 7. 冉银与助理的争吵、"追他的人很多" 8. 走到他面前索要答案与"那些都已经不再重要" 9. 喷出的一大口鲜血

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 关系的断裂由一个称呼承担 | 一声"周小姐"后立刻回扣"他叫她周念，周七斤，念念"，再补"这还是她第一次从他嘴里听见这个称呼""陌生得真像是第一次认识她" | 称呼刻度 | 心碎 | 用旧称呼的列表与新称呼并列，一个词就写完四年 |
| 亲疏由一次合照演示 | 同一间病房里，护士请求合照他"目光温和"地说可以，还弯腰把肩膀对齐一米五的护士，与对她"眼皮都不曾抬一下"构成对照 | 对比锚点 | 心疼、愤怒 | 让男主对陌生人温和、对女主冷漠，在同一场景里读出差别 |
| 伤痛用身体的缺陷解释 | 她手臂被撞出一团红紫，叙述补出原因："她只有骨头和皮肤，没有肌肉的保护，稍有磕碰都会造成触目的伤色" | 生理归因 | 心疼 | 用身体条件解释伤口为何刺眼，比直接写"她很瘦"更能让人难受 |
| 私生的标签被反复砸在她身上 | 助理骂"我对付过的私生多了去"、"疯子私生岂不是险上加险"，她自己也认下"她连一个粉丝都算不上，只是一个招人讨厌的私生" | 标签内化 | 压抑 | 让主角接受外界给的贬称，屈辱感由她自己的承认产生 |
| 住院的真实原因延后揭示 | 先给手腕纱布与"怕被冒犯"的冷淡，再由助理的抱怨"这电影还有一个月才开机，你非要先住到这里来提前感受"一句揭开 | 铺垫后置 | 讽刺、心酸 | 把男主的处境藏在助理的牢骚里，让冷遇先成立、理由后到 |
| 角色功课交代得精确 | 他的下一部电影是精神病人题材，为贴合角色在院方同意下提前一个月入住，饰演患上双相情感障碍的知名小提琴家，为观察真正的双相患者而与裴巷同房 | 设定细化 | 其他 | 把观察对象的病症与同房安排对上号，情节就显得是专业的 |
| 手腕伤的疑点被留白 | 助理问"你的手怎么伤到的，明明昨天晚上送你回去的时候都是好的"，他"神色明显凝了一下，眸底有一闪而过的阴暗"，只答"不小心弄到的""没事" | 反应留白 | 悬念 | 让关键伤情由旁人问出、由当事人沉默，读者自动开始猜 |
| 母亲的角色被写成闹剧推手 | 冉银进门先嘲讽"大明星也有精神病吗"，再以"你当初成天追着我女儿后面跑"把旧事摊到台面，直接引来助理的"就她啊——？我呸"与"追我们遂哥的都有谁" | 借他人之口羞辱 | 愤怒、心疼 | 让长辈的挑衅引来旁人的羞辱，主角被动成为全场笑话 |

| 章末用生理性的爆发收束 | 她笑着哭、"格外漫长的慢放镜头"之后是"一大口猩红液体瞬间喷涌出来""鲜血糊了鹤遂一脸，他的眼前瞬间沦为一片红光" | 身体代替台词 | 震惊、心疼 | 把委屈写到吐血的具象程度，用视觉冲击替代任何辩解 |

**逐章写法公式**：

- **情绪流向**：起：懵（握着的手、周小姐） → 承：辱（被甩开受伤、私生、换病房） → 转：苦（护士合照、旧照片的回忆、"那些都已经不再重要"） → 合：爆（笑到哭、喷出一大口血）
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**："周小姐"与握手的纠缠（用称呼与新距离定调） + 助理甩手与撞伤（用身体写被嫌弃） + 换病房被拒（用一句"不用"留悬念） + 裴巷的早餐与"你有饿的时候吗"（用病友写她的失感） + 手腕纱布与冷遇（埋疑点） + 护士合照与"你不是我的粉丝"（用对照写亲疏） + 旧日拍照的回忆（用习惯反衬此刻） + 助理揭开住进来的真正原因（一次性解释同房安排） + 冉银的挑衅与"追他的人很多"（用旁人羞辱把关系摊开） + 索要答案与"不再重要"（把四年之谜顶到顶点） + 喷血收章（用生理爆发终止对话）
- **本章核心技巧**：全章只围绕"称呼"与"距离"两件事推进——从"周小姐"到"还想握多久"再到"那些都已经不再重要"，男主的每一次开口都在撤走旧关系；女主的每一次靠近都要付出可见的身体代价（撞伤、吐药、最终吐血），关系拉锯被完全写在肢体上
- **卡点与伏笔**：结尾卡点：她被他一席话激到"笑出眼泪"后喷出一大口血，"鲜血糊了鹤遂一脸"——他的反应被切断，下章必然处理这场失血；埋设/回收伏笔：手腕上缠了三层的白纱布 → 昨晚还好、今早就有伤，与"心理干预理疗室"（第57章）隐线相接；"我记得你说过你不是我的粉丝" → 重逢现场的旧话被回扣；"四年前的六月九号"与丢掉的信 → 第55章失约的正面追问被"不再重要"挡回；为拍双相题材提前一个月入住、与裴巷同房 → 后续长期同处的场景基础；郁成这个助理的名字出现 → 前文"鹤哥的助理"在此具名；冉银的挑衅与"追他的人很多" → 恋爱状态的问题被他以"和你没关系"回避
- **时间线**：本章为第60章清晨的延续，同一日早晨

# 第59章 病症 摘要

**概要**：在京佛精神卫生中心治疗一周后，周念得上称称重，以便根据体重确定新一周的详细治疗计划；面前站着王学知医生、冉银和责任护士，让她很有心理压力，不过她庆幸在医院称重不需要脱光衣服。她脱掉鞋光脚站上去，体重秤的数字闪了闪定格在58.6斤——住院一周、一天三次管饲，结果只涨了6两，"拉泡屎就没了"。王医生安慰她别灰心、这病不是一天两天的事，她便顺势问今天能不能请假出去，理由是"我一个朋友想带我出去散散心"；冉银插话说她还住着院、身体虚弱不合适外出，王医生却摆手说出去透透气心情好更有助于治疗，只提醒行动要慢些、别磕着碰着，并向责任护士请假拿条子签字才能走。莫奈说十一点来接她，她早早换好样式简单的白色长袖衬衫、牛仔裤和一双洗得磨边的小白鞋，干净寡素得像女高中生，加上瘦得皮包骨、肉眼年龄更显小；莫奈晚了十分钟、进门就吐槽堵车，她夸"你会自己开车，好厉害"，并说自己还没学驾照——自从看过火车站那场整夜暴雨后，她很难有心力去做其他事情，连画都不画了，光是活着和对抗病魔两样就足够让她心力交瘁。冉银一直在身后絮叨别忘记回医院的时间，她没理会，也没有同意让冉银跟着外出；离开前她把床头柜上的万年青挪到窗台上，说"它要晒晒太阳"，她每天都会让它晒五六个小时的太阳。电梯里有两个年轻护士，其中一人的手机壁纸是鹤遂怼脸拍的照片，她们兴致高涨地聊他新上的电影《昼春》，一个说自己男朋友看电影时一直凑在耳边说鹤遂帅死了；周念把目光落在楼层键上仿佛没有在听，直到两名护士走出去才意识到自己一字不落地都听见了。莫奈叹口气问"这滋味不好受吧"，她说"还好"，被拆穿口是心非后才苦笑说"不好受又能怎么办"——现在的鹤遂早就不是那个南水街满心满眼都只有她的少年，他属于任何一个喜欢他的人，独独不属于她。负一层的停车场里，莫奈的白色奥迪车灯亮起，上车后她看见周念薄薄地靠在座椅里、安全带横在胸骨处往中间凹陷，惊道"这就是身材天赋？你都这么瘦了还有胸啊"。车子驶出停车场拐上马路时，周念从后视镜里第一次看到这座规模不小的精神病院的全貌；一路上鹤遂的脸出现在好多地方——巨大的幕墙屏上、商场顶部的海报上、公交车的车身广告上，还有没看清店名的门口放着他的人形立牌，他实在火得一塌糊涂；她由此又开始内耗，想如果四年前的逃亡计划顺利进行，她现在是不是也已经习惯了这座城市的空气、重要的是现在是不是还在他的身旁。莫奈劝她不管他出于什么原因说不认识她，既然拿出了态度就没必要再执著，最后受伤的只会是她；她轻轻笑了一下说"还差这一点半下的吗"——一个早就千疮百孔的人是不会害怕受伤的，反正已经遭过那么多罪。莫奈愤愤地为她鸣不平，说当初在镇子上所有人都骂他、拿他当条狗，只有她愿意和他来往、对他那么好，最后还跟着一起被骂，现在他翻身成了大明星倒忘了当初施恩的人；周念被京佛十一月的风吹红了鼻尖，沉默很久才说"我比谁都更清楚，我和他回不去了"——中间隔着一条天堑，天堑里流淌着的是他的声名赫赫、他在聚光灯下捧着金杯享受掌声的模样，以及她的碌碌无名、她被当作疯子私生遭受唾弃辱骂的模样。莫奈也伤感地说现在他们差距太大了，又说"谁又知道，当初在那个小破镇，明明你才是站在云端上的那一个"——是啊，谁还记得那个走在青石板上的天才画画少女，身上永远背着块画板，所到之处听到的都是夸奖。到了莫奈的双层大挑空别墅，周念强打起精神说"好漂亮"，莫奈邀她出院后过来一起住、住到开学都行，得知她休学一年后更说得直接；随后带她看二楼专门打造的直播间，设备很齐全，她说莫奈每天播六个小时也挺辛苦。周念正好停在窗边随意往下一望，看见一个熟悉的人，便叫莫奈来看那个像不像鹤广——那人身高形瘦、略佝偻着背、脸色有些蜡黄，却把自己收整得很光鲜，脚下一双皮鞋擦得锃亮。莫奈确认他就是鹤遂的爹，还说他确实住这儿、鹤遂在这给他买了房子、听说一个月给上百万的生活费；周念下意识否定"这不可能""绝对不可能"，因为鹤遂恨鹤广到骨子里，怎么会给他买房子还给他养老，其中一定有什么地方不对劲，她转身要下楼去问。楼梯还没走完她就累得喘息不停，只能张着嘴大口呼吸，吸进嘴巴里的空气是热的——其实不是空气热，而是她的喉管和食道被胃酸灼烧着才觉得空气是热的；医生千叮咛万嘱咐让她注意情绪、不能急不能燥、更不能太过愁肠郁结，否则胃上的毛病只会越来越严重。莫奈搀着她出门，又先跑去找鹤广拦人，鹤广停下来笑容满面地说"想要我儿子签名照还是咋的"，乍看宛如一个爱护晚辈的中年叔叔；周念迈着虚浮的步子走过来，鹤广回头看见她的脸时明显怔了一下，像是没料到会在这里看见她、也惊诧她如今的模样。她冷冰冰地问"你对鹤遂做了什么"，他敛了些笑容装听不懂；她开门见山地说鹤遂恨他恨到骨子里、怎么可能给他买房子还每个月拿钱给他挥霍，鹤广仍笑着答"父子哪有隔夜仇"，被她一句"你可以骗过他们，但你骗不了一个从小在花楹镇长大的人"戳破后，脸上最后那点笑意也消失了——没了笑意伪装，他本就刻薄的长相立马显出凶光，细看会发现他的眼珠子浑浊不清、像蒙着一层白色的东西；面对此人，换作四年前的周念会害怕得尖叫，现在的她有的是置之死地而后生的孤勇，她甚至叫出了只有花楹镇人才知道的绰号"鹤千刀"。这一声彻底惹恼了鹤广，他说她是纠缠、说"你也不看看你这幅样子，他怎么可能还会要你""我出门一趟都能遇见无数个叫我公公的女娃，你算是什么东西"；周念平静地回"你只不过是沾了鹤遂的光而已"，鹤广却挑眉得意地说"问题是她们不知道""也没人过问我的过去。就像没人过问鹤遂的过去一样，什么花楹镇，什么南水街，都滚他妈一边儿去吧""你看看现在，还有人叫鹤遂疯狗吗"。见她流露出受伤的表情，他立马又以胜利者的姿态笑着说"别怪叔叔伤你的心，可事实就是这样"，说她只是个无足轻重的人、和那些花钱去看他儿子电影的观众没什么两样、别太把自己当回事；他想走，周念拦住他的去路坚持"一定是你对他做了什么，他才会变成这个样子"，被他反问"难不成他放着明星不当，要回去当那个成天追在你屁股后面跑的毛头小子"，并直接甩出"他早把你给忘了"。她的表情瞬间滞住，急道"你在撒谎"，鹤广转着拇指上的金戒指笑说"既然你觉得我在撒谎，你这么急干什么？你慌了？"，她的眼圈不受控地红了——她确实慌，因为她已经领教过如今的鹤遂有多冷漠。莫奈劝她算了，她摇头说不走、一定要知道真相，鹤广便说出真相：鹤遂准备坐火车和她离开的那一天遇到了他人生中的伯乐生东返大导演，生导一眼相中他让他当电影男主，也就是那部《屠佛少年》，"有这样天上砸馅饼的好事情，是个人都不会放过机会，他当然选择去拍电影了，怎么可能选择你"。周念不敢相信自己的耳朵，追问"你怎么会知道他准备坐火车和我离开的事情"，鹤广得意地耸肩说"那天他和生导谈的时候，我就在旁边"。她觉得整条食道都开始烧起来，脑子里思绪无比混乱：他选择了去拍电影、没有选择她，可倘若真是这样，他为什么说都不愿意说一声，她又不会阻拦他拥有更好的未来；鹤广似乎猜到她在想什么，又说"斩断旧的过去，开始新的生活，不辞而别也没啥好奇怪的""现在他已经彻底忘了你，你也不要继续纠缠了""好自为之哈"，随后离开。周念一时竟忘记了哭，只是僵在那里像一尊随时都会坍塌的雕像，随后开始不停地战栗，莫奈过来拥住她瘦如薄片的肩膀——或许这就是故事的结局：没人再记得南水街的那条疯狗，也没人记得故事开端里的周念，包括鹤遂自己；周念深知如今的她也注定沦陷为千千万万为他疯魔之人其中的一个，她不再特别，她不过尔尔。

**关键事件**：1. 58.6斤的称重与请假条子 2. 电梯里护士壁纸和《昼春》的议论 3. 一路上的广告与人形立牌、"我和他回不去了" 4. 莫奈别墅与直播间 5. 窗下的鹤广与"一个月上百万生活费" 6. 鹤千刀的对峙与"你慌了" 7. 生东返大导演与《屠佛少年》的真相 8. 僵住的雕像与"她不过尔尔"

**逐章写法公式**：

- **情绪流向**：起：钝（58.6斤、请假条子、被挪到窗台的万年青） → 承：酸（护士的壁纸、一路的广告、莫奈的鸣不平） → 转：怒（鹤广的光鲜外表与"你慌了"） → 合：塌（生东返的真相、僵住的雕像、不过尔尔）
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：称重的6两（写治疗停滞） + 请假外出与挪花盆（给她一天的自由） + 电梯里的议论（用陌生人写他的热度） + 车上的一路广告（用城市写距离） + "我和他回不去了"（把落差说成一个天堑） + 别墅与直播间（写朋友的善意） + 窗下的鹤广（用外表反差引出反派） + 楼下对峙与绰号（用孤勇逼出裂缝） + "你慌了"（用逼问撕开她的自我保护） + 生东返与《屠佛少年》的真相（一次性交代四年之谜） + 僵住的雕像与她不过尔尔（以自我注销收章）
- **本章核心技巧**：把四年之谜的答案交给全书最卑劣的人转述——不是男主解释，不是警方披露，而是那个靠儿子享福的父亲以炫耀的口气说出"他当然选择去拍电影了，怎么可能选择你"；真相因此不带任何体谅，读者与女主同时被这句话击中，随后章节用"不过尔尔"把她从故事里除名
- **卡点与伏笔**：结尾卡点："她不再特别。她不过尔尔"——真相已知（他选择了电影），但他为何一言不发、为何眼神带厌恶仍未解，下章期待为她的选择；埋设/回收伏笔：58.6斤与七十斤的出院线 → 目标进度；窗台上的万年青（每天晒五六个小时）→ 关系意象与她的照料习惯；生东返大导演（第55章"生导"的车边等待）→ 本章回收为真相的执行者；那部《昼春》 → 他的近况；鹤广的别墅与每月上百万生活费 → 鹤遂与父亲之间违背常理的供养，暗示另有代价；"父子哪有隔夜仇" → 未解的反常；"没人过问鹤遂的过去" → 舆论与身份的遮蔽；莫奈邀她出院后同住 → 后续落脚点；休学一年 → 学业的悬置
- **时间线**：本章为2017年11月，接第58章之后数日

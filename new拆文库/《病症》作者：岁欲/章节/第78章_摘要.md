# 第78章 病症 摘要

**概要**：鹤遂抱着周念下楼、穿过堂屋步入雨中，声势浩大的雨竟没能把她淋湿一分半点——他深低着头、宽肩向内扣着，为她撑起独一把伞，雨水只落在他身上。他把周念轻放进救护车的担架床，拒绝郁成"太挤，坐我们自己的车"的建议，说"我要陪着念念"。暴雨里的路不好走，车速甚至不超过二十五码；他坐在担架旁说等你好起来以后可以一起做好多事情——看夏夜稻草田里的萤火虫，看万物蓬勃的小镇，还能一起去喂厌厌。周念听到最后一句冷不丁笑了一下，问他"你还记得厌厌"，又说影帝的演艺事业如日中天竟还愿意花心思去记一只小镇的流浪猫、还真是难得；被打断的他想解释"根本就不是这样"，却被她以一句比较截断："我和厌厌还是有区别的""区别在于我还有一口气，而厌厌已经死了"。他花了好几分钟才消化这个消息，追问厌厌是怎么死的，她才终于开口——肖护出来了，那个捅了他一刀被判了四年多的肖护。他立刻猜出"是他杀了厌厌"，她纠正"不是杀"而是"虐杀"。车子碾过凸起地势颠簸了几下，一滴眼泪从她的内眼角滚落，他伸手替她拭去，她却毫无知觉；她说"你永远都不会懂那种感受""在你风光无限的时候，肖护剥了厌厌的皮，把它送到我的面前"，让他终于明白霍闯没说完的那句话——她失明前最后看到的画面是厌厌凄惨的死状。她说他走以后是她在喂养厌厌，她喂了它四年、连去京佛看病都叮嘱霍闯代喂，那是她生命里仅存的一点温暖，而它那么凄惨地被虐杀，成了压垮她的最后一根稻草。他说他红了眼，她则说"归根结底怪不得你什么"，如今光芒万丈的他是应该抛下厌厌、抛下十七岁的鹤遂、抛下南水街、抛下这个小镇，当然也理应抛下她；他垂眼看着右手手腕的疤说"我没有抛下你，也没有抛下任何东西"，她只回"对，你只是做了你觉得对的选择"——他在京佛曾亲口说"你只是不被我计划在未来里面而已"。最后他说"等你重新能看见那一天，我会证明给你看"，她云里雾里却没有深究的欲望，太累，只想睡。趁她熟睡，他把手伸进被子里轻轻握住她的手。下午一点救护车停在云宜东济医院住院部楼下，那是全国排第一的私人医院、VIP病房一晚两万元，鹤遂戴上口罩和黑色棒球帽、又替她挡开人群一路送进住院部、坚持"我陪着"先等她检查完。接诊的是京佛精神病院王学知的老师、精神科名医韩老，她第一眼就说"现在才来医院，早点在干什么"，掀开被子摸到清晰的腿骨与根根分明的肋骨，说这已经瘦得不能再瘦、又发现他答"不止是眼睛"、"五感都没了，听觉还剩一点"，直接判断如果不积极治疗她撑不过两个月就得死。韩老让护士先推周念去做全身检查，再把鹤遂单独留下谈话，得知他不是哥哥也不是男朋友，说明厌食症必须从病根下手，他低声说"她的病根是我"。就在韩老提起他黑眼圈重、晚上睡不好时，他的瞳孔骤涨骤缩、仿佛瞬间换了个人，神情阴恻深狠地微笑说"你帮我杀了他，我就能睡个好觉"，并在被追问后答出"杀了鹤遂"，最后说出自己的名字——"我是沈拂南"。尾音刚落他闭眼皱眉、重新睁眼时恢复了先前的淡漠平静，说"我没事，韩老，麻烦您费心治好她就行"。他开门离开前，韩老忽然问"你知道你的身体里有其他人格的存在吗"，他身形一僵、转过半张脸平静地说"我知道"，被说"他想杀了你"时也只沉默一瞬答"这个我也知道"——他比谁都更清楚自己的情况，清楚地知道自己是个什么怪物。

**关键事件**：1. 雨里的独一把伞与"我要陪着念念" 2. "还能一起去喂厌厌"与"我和厌厌还是有区别的" 3. "不是杀，是虐杀"与"剥了厌厌的皮，把它送到我的面前" 4. "它是我生命里仅存的一点温暖"与"抛下我" 5. "你只是不被我计划在未来里面而已"与"我会证明给你看" 6. 东济医院与韩老的"撑不过两个月就得死" 7. "她的病根是我" 8. "我是沈拂南"与"你知道你的身体里有其他人格的存在吗"

**逐章写法公式**：

- **情绪流向**：起：护（雨里的伞、担架旁陪伴） → 承：伤（厌厌之死、"虐杀"、暖光的熄灭） → 转：判（他自认病根、她要他抛下自己） → 合：恐（"我是沈拂南"与韩老的那句发问）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：雨中的独一把伞（用保护动作开场） + 担架旁的未来清单（用美好邀约铺温情） + 猫的比较与"虐杀"（用对照把温情撕开） + 肖护与厌厌死状（把第71章的悬案收束） + "它是我生命里仅存的一点温暖"（把崩坏归到最后一根稻草） + "抛下厌厌、抛下十七岁的鹤遂、抛下我"（用名单完成清算） + "我会证明给你看"（埋下未来的许诺） + 东济医院与韩老会诊（换场到新舞台） + "她的病根是我"（男主第一次交底） + 瞳孔骤变与"我是沈拂南"（让第二人格第一次现形） + "你知道你的身体里有其他人格吗"（把谜团变成可对话的设定）
- **本章核心技巧**：把"厌厌之死"这一压抑了七章的信息放在一趟救护车的行程里交代完，用"虐杀"两个字把仇人、创伤与失明的因果一次串齐；行程结束时切入一家全新的医院，让读者以为要转向疗愈线，却在同一章末尾让第二人格第一次在医生面前现形，把书的谜团从"他为什么变心"换成"他身体里还有谁"
- **卡点与伏笔**：结尾卡点：他亲口承认身体里有其他人格、且那人格想杀他，而他仍选择先治她，这条线刚刚打开；埋设/回收伏笔：沈拂南的自述与"放我回去"的镜上血字（第77章）直接呼应；"她的病根是我" → 与全书"救赎/灭世主"的双重定位咬合；韩老与王学知的师徒关系 → 把京佛与云宜两地串起；"等你重新能看见那一天，我会证明给你看" → 为后文感官恢复留出兑现点；"厌厌虐杀"归到肖护 → 肖护这条未清算的威胁线仍在
- **时间线**：本章接第77章当日下午，经暴雨中的两小时车程，至下午一点抵达云宜东济医院

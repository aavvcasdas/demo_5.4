# 第95章 病症 摘要

**概要**：最近几天周念总会无端想到那个赌约——输的人会失去三个月的身体使用权；如果输的是鹤遂，沈拂南就会回到京佛继续过他的影帝人生，与她的人生轨迹没有半点关系，至于她那时会不会不舍和遗憾，她自己也说不清。还没等她想明白，职业是民警的人格阿烈出现，和她插科打诨地聊上班琐事，说昨天有个人因为丢了一封信而报警；她笑着问信最后找到了没有，阿烈搓搓脸说"没，被扒手扒去了，找不到了"，她替丢信的人感叹了一句，人格却在一瞬间转换回了鹤遂。她注意到他眸色变得轻懒深邃，说"你回来得挺快"，他只知道"也就眨眼的功夫"；她一边盘腿坐在客厅地毯上拆画纸塑封，一边问为什么电影里人格切换时主角会很痛苦、还会抱着头咆哮，他取过画纸帮她撕塑封，懒懒扫她一眼反问"你也想看我抱着头咆哮"，又说"是转换人格又不是变异，那么夸张干什么"。问他能不能随意叫其他人格出来，他先点破"你想见沈拂南"，被她以"我最讨厌他了"回绝，又轻笑"那你是不想见我"；她挑铅笔时说要见宋莱，理由是"他很像十七岁的你"——宋莱成天打架、性格阴晴难定、暴戾又疯狂，正是十七岁的鹤遂。他敛住笑意、仰头看着天花板，嗓音幽凉地说"是现在的我还不够好""才让你只想见到十七岁的我"；她无法反驳，因为谁都会怀念十七岁的他：那时候他不是万人瞩目的巨星，只是属于她一人的鹤遂，会在阴暗小巷和她拥抱接吻，而现在的他连出门都要帽子、口罩、墨镜全副武装，遮得一丝白都不露还是会被认出来、被人追着要签名和拍照。门铃在这时响起，她去开门，莫奈扑上来把她抱得差点喘不过气；两个月未见，莫奈又长胖十多斤、体重直逼二百五，她发现莫奈脖子后面有一圈黑色纹路，提醒那是黑棘皮、是胰岛素抵抗的表现，莫奈说"我知道啊""但还想再多赚一点钱，赚够了就收手"。莫奈一进门就注意到坐在地毯上的鹤遂，说话刺刺儿地问他是不是突然良心发现了，他只勾唇浅笑"是，良心发现了"。莫奈说自己为请假被迫狠干了几天、提前把时长播够，周念最懂那种被迫进食的感觉；随后莫奈翻出手机点进肖护的抖音，说视频里的背景很熟悉——那是花楹镇南水街。周念告诉鹤遂，肖护现在成了搞流浪猫狗救助的宠物博主、靠这个赚了不少钱；莫奈感叹这比鹤遂摇身一变成了国际巨星还让她震惊，周念平静地说"他的确不是"，并第一次说出"他虐杀了厌厌"——莫奈登时哑住，她们以前一起去喂过那只特别乖巧的黑猫，没想到竟死在肖护手里。两人商量很久，决定回花楹镇暗中跟踪肖护、拍下他虐待猫狗的证据再在网上曝光；鹤遂突然说要一起去，被周念想都没想拒绝，他脸色沉下来说"除非我跟着你去，我不会让你冒这个险，你一个人不安全"，被莫奈问"那请问我是狗吗"后只回"两个也不安全"。谈到用什么账号曝光时，莫奈的抖音有58.9w粉丝，她拿话点鹤遂说还有个粉丝更多的坐着，周念抢先说不需要——那毕竟是沈拂南的账号，用了反而欠人情；没想到鹤遂主动说"到时候把证据发我，我发微博"，周念担心他三千万粉丝量级的账号会被有心人拿来做文章、说他引导网暴，更担心沈拂南出来发疯，他只说"别怕""我还能压住他"，并冷冷补一句"他那样伤过你，毁了他都不为过"。莫奈满脸问号追问他们在说什么，周念征得鹤遂同意后说出"鹤遂有人格分裂"，并耐心解释人格间思维独立、转换速度很快；莫奈恍然大悟"也就是说，在京佛病院冷漠对待你的并不是鹤遂本人"，还向鹤遂道歉说"错怪你了"。出发时间定在当天，周念却因为当初是被鹤遂裹在被子里穿睡衣带进东济的、没有可换的衣服，莫奈便出门去附近商场给她买，说好买回来就出发。莫奈走后空气静了好一阵，在又一次铅笔坠落时，男人低沉的嗓音缓缓响起："念念，你这一走，还会回来吗？"

**关键事件**：1. 赌约的反复与"她自己也说不清" 2. 阿烈与那封被扒走的信 3. "你想见沈拂南"与"我很讨厌他" 4. 想见宋莱的理由"他很像十七岁的你"与"现在的我还不够好" 5. 莫奈登门的熊抱与黑棘皮、58.9w粉丝 6. 南水街的背景与"他虐杀了厌厌" 7. 回花楹镇拍证据的计划与"两个也不安全" 8. "到时候把证据发我，我发微博"与"毁了都不为过" 9. 向莫奈坦白人格分裂 10. "念念，你这一走，还会回来吗？"

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 悬念先由角色自我盘问 | 不写"她很在意赌约"，而写"如果输的人是鹤遂，那么沈拂南会回到京佛……那到时候她会有不舍和遗憾吗？周念自己也说不清" | 内心二选 | 其他 | 把一个大悬念拆成一个主角自己都答不上来的假设，读者会替她选 |
| 人格切换被常识误解 | 她拿电影里"主角会很痛苦，有的还会抱着头咆哮"来问，他用"是转换人格又不是变异，那么夸张干什么"回敬，前置一句"是转换人格又不是变异" | 用常识反衬 | 轻松 | 让角色拿大众印象来质疑设定，一句话就把科普做得自然 |
| 想念被藏在一个化身里 | 她不说想念十七岁的鹤遂，只说想见宋莱——"他很像十七岁的你：成天打架，性格阴晴难定，暴戾又疯狂" | 借代表白 | 心疼 | 让角色用第三个人来指认自己的怀念，比直接说更有余味 |
| 落差写在两段身份里 | 一边是"那时候，他不是万人瞩目的巨星，只是属于她一人的鹤遂，会在阴暗小巷和她拥抱接吻"，一边是"帽子，口罩，墨镜，哪怕这些全部都带着，把脸遮得路不出一丝白，还是会被认出来" | 前后对照 | 悲伤 | 用"一人所有"与"人人可见"两段身份摆在一起，怀念就不需要理由 |
| 朋友的登场靠体重与毛病 | 莫奈的出场先写"扑过来重重抱住周念""周念差点被勒得喘不过气""又长胖了十多斤，体重直逼二百五"，再给"脖子后面有一圈黑色的纹路"与"黑棘皮……胰岛素抵抗" | 身体标签 | 温馨 | 用一句可量化的身体特征和一个专业小病名，让朋友一出场就立体 |
| 恶行靠一句旧事引爆 | 周念先平静地说"他的确不是"，顿一下再说"他虐杀了厌厌"，随后接莫奈的反应与一句旁白解释那只黑猫的来历 | 一句爆点 | 愤怒 | 把最重的指控留给最短的句子，前面只留两句无关痛痒的铺垫 |
| 计划用条目说清 | 不写"她们商量了对策"，而写"她们决定回到花楹镇去，找到肖护暗中跟踪观察，拍下他虐待猫狗的证据，然后在网上进行曝光" | 三步行计划 | 期待 | 用三个动词把计划摆平，读者跟得上也记得住 |
| 争执用一句反问破局 | 他说"你一个人不安全"，被莫奈反问"请问我是狗吗"，他只回"两个也不安全" | 荒诞回击 | 轻松 | 让一句不合逻辑的直男式回答化解僵局，紧张里插一口气 |
| 平台的后果被预先算出 | 他提出用自己的微博发，作者随即补"三千万粉丝量级的顶部流量去发这样曝光微博……都会被有心人拿来做文章，首要的就会说他引导网暴" | 预支风险 | 紧张 | 把最强手段的副作用先摊开，角色的选择才有分量 |
| 结尾只问一句话 | 全章末不给答案，只写"在又一次铅笔坠落时，男人低沉的嗓音缓缓响起：念念，你这一走，还会回来吗？" | 悬念收束 | 心疼 | 用一件反复掉落的小物提示他的走神，再用一句问话把下一章的门推开 |

**逐章写法公式**：

- **情绪流向**：起：疑（赌约与"她自己也说不清"） → 承：暖（阿烈的信、宋莱与十七岁的他） → 转：怒（肖护的伪善与"他虐杀了厌厌"） → 合：悬（计划定下与"你这一走，还会回来吗"）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：赌约的反复盘问（用一个未决的假设开场） + 阿烈与那封找不到的信（用一段无关痛痒的闲聊补人格质感） + 眨眼间的人格回归（用一次瞬时切换写日常） + 电影的夸张与"转换人格又不是变异"（用常识质疑完成科普） + "你想见沈拂南"与"我最讨厌他"（用一句话写两人都不肯认的在意） + "我想见宋莱"与"他很像十七岁的你"（用借代说怀念） + "是现在的我还不够好"（让落差被角色自己说出来） + 全副武装的巨星与只属于她一人的少年（用两段身份写时间差） + 门铃与莫奈的熊抱（用朋友的进场打断沉重） + 黑棘皮与"赚够了就收手"（用身体信号写她的处境） + "你还真在这儿"与"是，良心发现了"（用一句冷话完成和解） + 肖护视频的熟悉背景（用一个地名把旧案牵出） + "他虐杀了厌厌"（用最短的一句引爆） + 回花楹镇的三步行计划（把复仇写成可执行的动作） + "我也要去"与"两个也不安全"（用争执与荒诞反问写他的保护欲） + 58.9w粉丝与"还有个粉丝更多的"（用数字引出账号之争） + "我发微博"与网暴的顾虑（把选择的代价先算清） + "他那样伤过你，毁了他都不为过"（用一句狠话给他的动机定性） + 向莫奈坦白人格分裂（把秘密交出去并在友情里结算误会） + 出发当天与没有换的衣服（用一个小麻烦把出行坐实） + 铅笔频频坠落与"还会回来吗"（用一个小动作预支下一章的悬念）
- **本章核心技巧**：把"复仇计划"这条新线和"赌约"这条旧线并行推进——旧线只用一个反复盘问的内心独白和一次"你想见沈拂南"的试探；新线则完整走完发现（南水街的背景）、确认（"他虐杀了厌厌"）、定策（跟踪取证曝光）、分工（谁跟着、用谁的账号）四步；两条线在同一场景里交汇，最后用他手里反复掉落的铅笔和一句"你这一走，还会回来吗"把赌约的紧迫感直接压到出行这件事上
- **卡点与伏笔**：结尾卡点：她们当天就要出发回花楹镇，而他问"你这一走，还会回来吗"，三十日倒计时的赌约与这次离城同时开始；埋设/回收伏笔：三月赌约的最后三十日 → 她这次一走正好落在倒计时里，赌约的兑现与她的离开绑定；"他虐杀了厌厌" → 回扣第92章阳台裤脚边"很像厌厌在蹭她的裤脚"的联想，厌厌之死首次被明说；肖护视频背景是花楹镇南水街 → 与鹤遂的少年场域重合，取证之行会把他带回老家；鹤遂要发微博 → 与解渤腾那条"影帝暴力殴打亲生父亲"的热搜形成正面冲突；"他那样伤过你，毁了他都不为过" → 他对沈拂南的敌意升级，与"死在这个夏天"的赌注对应；莫奈得知人格分裂并道歉"错怪你了" → 沈拂南在京佛的恶行第一次被第三方理解；"是现在的我还不够好""才让你只想见到十七岁的我" → 他对自己被偷走四年这件事的心结；她当初是被裹在被子里穿睡衣带进东济、没有可换的衣服 → 一个生活细节，反证这两个月的封闭
- **时间线**：本章为第94章之后数日的某一天，上午至午后（当天即计划出发）

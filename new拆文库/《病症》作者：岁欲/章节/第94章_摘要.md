# 第94章 病症 摘要

**概要**：鹤遂气息轻懒地笑笑说"也没什么"，周念摆出打破砂锅问到底的态度盯着他，他撩着肩上搭的毛巾擦濡湿的黑发，漫不经心地答出赌约内容——"输的人要失去三个月的身体使用权"。说完他目光越过她看了一眼桌上手机，说还得给郁成打个电话、让他联系冉银明天过来，随即抬脚经过去拿手机；周念回头看他瘦高的背影，心里隐隐觉得哪里不对劲又说不上来。她独自上床，环顾房间里的沙发桌椅、落地台灯和嵌壁式衣柜——如果不看床头摆着的仪器和输液架，真叫人看不出这是病房；她意识到不知不觉间自己已在这里和他同居两个月，也明白她不会永远和他这样下去，总该有分别的那天，或早或晚的区别而已。鹤遂煲完电话回来，问她是不是要睡了，随后抄起床头柜上的一本书、盘腿坐在地铺上说"给你讲故事"——除了雷暴天气，他从不会上她的床；打雷那些夜晚他从背后抱着她，她好几次感觉到他的不适，但他从不会对她做什么，只是极尽克制地抱着她。她想起自己曾问他"我感觉你挺难受"，他面不改色说"还行"，却无声息地把贴着她的长腿往后移了几分；她红着脸劝他下去睡地铺，他说"我才不下去，下去你会害怕"，她改口说"那就害怕吧"，他沉默片刻，学着她的话回"那就难受吧"。当夜他给她讲了一个因为一根胡萝卜引发兔子群体犯罪的童话，她听完直说幼稚，他揉着她的头说"幼稚才适合你，周念小朋友"。隔天上午十点，郁成带着冉银过来；母女两月未见，周念脸上没有任何表情，只指了指沙发没什么情绪地说了一个"坐"字，并在冉银下意识伸手想抱她时转身走向沙发、不动声色避开接触，也没注意到冉银的笑容瞬间凝固。鹤遂和郁成待在关着推拉门的阳台上，郁成连叫四遍"遂哥"他才醒神，问他还要住多久，他答"一个月"；郁成乐着说一个月后就回京佛去、抱怨这两个月耽误了多少行程，他弹了弹烟灰只说"再说吧"——拍电影或以任何形式暴露在镜头前对他都很陌生，那些是沈拂南的经历和人生，在沈拂南影圈杀出重围的这四年，属于鹤遂本身的记忆一片空白，他的记忆还停留在13年夏天的花楹镇。客厅里周念选择坐在沙发尽头、浑身气息疏离，冉银在隔着一臂远的位置坐下，端详半晌后如释重负地说"长了不少肉起来"，随即又开始张罗要给她搭配饮食、早上做现磨豆浆；周念没感受到关心，只觉得熟悉的窒息感直窜心头，微不可察地皱眉打断"这里吃的很好，不用担心"，冉银愣了一下、语气低落下去。冉银说自己这两个月吃不着也睡不好、来找过几次都被拦住了，脸上多横出几道细纹、人消瘦了一大圈。周念在肚子里酝酿着话、眼里的决然越来越明显，突然开口"你去自首吧"，空气瞬间安静；她按住鼻腔涌起的酸意，看着冉银的眼睛一字一字说"去，自，首"——也许这三个字三年前的她就该说。冉银强装笑容问怎么突然提这件事，她答"我不是突然提起，我只是一直忍到现在才提"，说常梦见爸爸，说自己对她的所作所为不闻不问、仿佛也成了杀死爸爸的凶手；冉银愠怒"可他周尽商是个什么人"，被她打断"他出轨是他不对，但是你可以和他离婚，你为什么选择杀了他"，冉银红着眼拍着胸口说"我这可都是为了你"，周念笑着流泪反问"是我让你杀的人吗？难道不是因为他出轨李丽芳，你恨他，所以才杀他吗"。阳台上鹤遂看见她在哭，踩灭烟头就要进门，被她用眼神制止；冉银回头看了一眼门外的鹤遂，只觉得他像周念饲在暗处的一头狼。周念接着说"不要把你的自私粉饰得那么漂亮，为我是假，为你自己才是真"，并指着画具说自己会继续画画，但"这不是为了你，是为了我自己"，还说不自首就再不见她；冉银眼底挣扎，问"如果我去自首呢"，她答"那我会抽时间去看你"。冉银离开时脚步变得蹒跚、和来时判若两人，走出门外又回头问"如果当年你没遇见他，是不是不会这样"，周念答"如果当年我没遇见他，我已经死了"——遇见鹤遂的时候，是她最低谷绝望的时候。

**关键事件**：1. "输的人要失去三个月的身体使用权" 2. "给他讲故事"与地铺上的克制、"那就难受吧" 3. 一根胡萝卜引发兔子群体犯罪的童话与"周念小朋友" 4. 郁成问"你还要在这住多久"与"再说吧" 5. 空白四年的记忆还停在13年夏天的花楹镇 6. 一臂远的距离、搭配饮食与窒息的关心 7. "你去自首吧"与"去，自，首" 8. 周尽商、出轨与李丽芳 9. "这不是为了你，是为了我自己"与"那我会抽时间去看你" 10. "如果当年我没遇见他，我已经死了"

**逐章写法公式**：

- **情绪流向**：起：缓（"也没什么"与三个月使用权） → 承：暖（地铺上的克制、兔子童话） → 转：对峙（"你去自首吧"与一臂远的距离） → 合：定（"是为了我自己"与"我已经死了"）
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：以"也没什么"引出赌注内容（用轻语气交付重规则） + 他心里"隐隐觉得哪里不对劲"（留一处未解释的直觉） + 环顾几乎看不出是病房的家（用空间写两个月的同居） + 一句"总该有分别的那天"（提前给这段同居定限期） + 抄起书本坐地铺"给你讲故事"（用固定动作重启日常） + 雷夜里抱住的克制与"那就难受吧"（用对称台词写两人各自的让步） + 胡萝卜引发兔子犯罪的童话（用一个不高级的故事写宠溺） + 隔天十点冉银登门（用一个"坐"字定场） + 冉银想抱却被避开（用手部动作写拒绝） + 阳台上的"再说吧"与空白四年的记忆（补足他的处境） + 隔一臂远的距离与饮食搭配（用距离与话术写窒息的关心） + "你去自首吧"与逐字加重（把冲突推到顶点） + 周尽商、出轨与李丽芳的旧账（把事实一条条对清） + "为我是假，为你自己才是真"（用拆穿自私完成反击） + 指画具说"为了我自己"（把本章的成长线与画画挂钩） + "不自首我不会再见你"与"我会抽时间去看你"（用两个条件收束关系） + "如果当年我没遇见他，我已经死了"（用最后一问一答定调收章）
- **本章核心技巧**：这一章把"进展"与"清算"并排放——前半段是他在地铺上讲兔子童话、在雷夜抱着她却只敢抱着的日常；后半段是她把母亲两月未见的会面直接变成一次自首的最后通牒，且不给任何缓冲；两段之间用一句"原来在不知不觉间，她已经在这里和鹤遂同居两个月时间"和一句"总该有分别的那天"连起来，让温柔与决裂互为对方的代价
- **卡点与伏笔**：结尾卡点：冉银离开时的蹒跚脚步与那句"我考虑一下"，她是否自首悬置；埋设/回收伏笔："输的人要失去三个月的身体使用权" → 兑现方式与"死在这个夏天"的赌注直接相关；鹤遂"心里隐隐觉得哪里不对劲" → 一处被作者明确标出的直觉，指向赌约的另一层含义；床头摆着的仪器、输液架与她的画具同处一室 → 医院生活正在被绘画日常替代；周尽商、李丽芳与"去自首" → 承接全书最前期的旧案，此处首次由周念正面要求法律清算；鹤遂在门外"像一头随时扑咬的狼" → 冉银对他的判断，为后续母女关系走向留位；"他的记忆还停留在13年夏天的花楹镇" → 与第91章"短短6个月分裂出12个人格"的时间点重合；郁成还不知道人格分裂的事 → 他迟早会知道，与工作室公关线相连；"如果当年我没遇见他，我已经死了" → 她对这段关系给出的最终定性

**时间线**：本章为第93章当夜至次日（隔天上午十点冉银到访）

# 第21章 病症 摘要

**概要**：周六艳阳，周念早醒后异常活跃地纠结穿裙子还是裤子、该买什么。她照常先到公厕吐空，看见对面长狭弄瓦檐上窜过很像那只小黑猫的黑影；随后挑水果（特意没买橘子，因为上次那颗被他扔了）、买零食，扛着画板画具水果零食共约四十斤爬四楼。病房门开着，隔壁床是个和侄子扳手腕扳骨折的黝黑大叔，一群人笑成一团，鹤遂靠窗独坐、对谈笑声充耳不闻。周念说"是不是因为没有人来看你，你看着不高兴"，被冷淡回绝"我不需要谁来看我"，她赌气"那就当我是厚脸皮要来的"。她递上零食，被"我嘴不馋"顶回，用"不，馋，也，能，吃"反击；鹤遂从袋底掏出跳跳糖讥"只有三岁小孩子才吃这个"，周念撕开包装直接怼到他唇边，最终趁其不备倒进他嘴里，青苹果味在口腔里炸开——"像一整个春天在嘴巴里跳舞"。周念夸他懂二氧化碳的原理，鹤遂两次说"别夸我"，并解释"我就是不喜欢"；周念困惑于他"可以被骂被羞辱被揍被刀，就是不可以被夸"。他还请她帮忙喂长狭弄那只黑猫，并说"猫粮的钱回头给你"。周念起身要走，鹤遂叫住她解释"我没不开心""我也没生气"。她追问他不喜欢被夸的原因，他答"你不用知道这个"。周念碰翻垃圾桶弯腰去捡时，鹤遂看见她隔衣显形的每一块骨头，直接问"周念，你在减肥？""你太瘦了"，并倾身靠近、认真说"你已经很瘦了，所以多吃点，嗯？"——周念"灵魂失火"，落荒而逃，如同那日手攥橘子逃跑的他。

**关键事件**：1. 带水果零食探病（独不买橘子） 2. 跳跳糖强喂与青苹果春天 3. "别夸我"的禁区暴露 4. 托付喂猫 5. 鹤遂看见她背上的骨头并说"多吃点" 6. 周念落荒而逃

**逐章写法公式**：

- **情绪流向**：起：雀跃（挑衣服、挑水果） → 承：别扭（被拒绝、抬杠） → 转：甜（跳跳糖） → 合：崩溃（被说出"多吃点"后逃走）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：出发前的雀跃 + 买东西（橘子留白） + 病房环境（孤独对照） + 零食与跳跳糖（甜点） + "别夸我"禁区 + 托付喂猫 + 追问他为何解释 + 看见骨头的质问（最大触动） + 逃走
- **本章核心技巧**：用"零食袋"贯穿全章——从被嫌弃到被塞进嘴里再到掏出跳跳糖，一件小道具完成关系升温；末尾一次"被看见"把整章甜度立刻转为痛感
- **卡点与伏笔**：结尾卡点："落荒而逃的画面似曾相似。像那日手攥橘子逃跑的他"（镜像呼应）；埋设伏笔：小黑猫与猫粮（后文长期纽带）、鹤遂不喜欢被夸的原因（未解谜团）

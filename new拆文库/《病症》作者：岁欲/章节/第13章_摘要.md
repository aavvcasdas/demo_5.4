# 第13章 病症 摘要

**概要**：周念愤怒于肖护第二次以多欺少、还动了刀，但更多是恐惧鹤遂会死。她用米色针织衫卷成一坨按压他腹部那道五厘米伤口，一直在他耳边碎碎念"你别死啊鹤遂"，泪水滴进他的耳廓。救护车赶到后急救人员夸她"做得不错"，她起身即眩晕，仍跑去叫鹤遂妈妈，把按摩店的灯关掉、卷帘门拉下后才离开；走到巷口小腹痛得走不动，因下午已吐空胃，只能干呕出胃酸与胆汁，看见鹤遂被抬上担架后一头栽倒。醒来时她在镇医院病房，宋敏桃告知她是营养不良加严重贫血、输了两瓶营养液，并说"要不是你，阿遂就没命了"；周念说出捅人的是肖护，宋敏桃只含糊解释是"肖护爸爸和鹤家有点恩怨"。宋敏桃还替她换过卫生巾、把她的画板认出来，高兴地鼓励她"以后一定要和阿遂多来往"。鹤遂在这时睁开了眼。

**关键事件**：1. 按压伤口施救与耳语呼唤 2. 跑去通知宋敏桃并善后关门 3. 力竭晕倒 4. 醒来告知凶手是肖护 5. 宋敏桃的感激与"多来往"嘱托 6. 鹤遂醒来

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 周念的救援是肉身级的 | 脱针织衫、踩进血泊、指腹捻起T恤下摆、见伤口后脸色煞白、抖到咬破嘴唇才压住伤口、跪到膝盖沾血 | 步骤化动作 + 身体反应交替 | 紧张、心疼 | 写救人不要写"她救了他"，要写她每一步做错了什么、克制了什么 |
| 耳语是男主唯一的活命锚 | "你别死啊鹤遂""我好害怕，但我也努力救你了"反复呼喊，泪水落进耳廓（第14章回收为其濒死时唯一的感知） | 先埋伏、后回收 | 心疼 | 呼救台词要具体而笨拙，不要抒情，越笨越真 |

| 宋敏桃是唯一没有敌意的成年人 | 她扔掉零钞冲出去、回来只说"我怎么还好意思问你要医药费"、主动替周念处理经血、鼓励来往 | 以善意成年人反衬全场恶意 | 温暖、意外 | 给男主的家庭留一个正常的成年人，全书气压才不至于全黑 |

**逐章写法公式**：

- **情绪流向**：起：愤怒 → 承：恐惧（救护） → 转：力竭（晕倒） → 合：温柔（病房里的两个女人的对话）
- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：愤怒定性 + 施救过程（肉身代价） + 通知家属 + 力竭晕倒 + 病房醒来（信息交换 + 宋敏桃好感铺垫） + 鹤遂睁眼（卡点）
- **本章核心技巧**：整章不做主角心理分析，只跟踪她的身体消耗（血、抖、晕、干呕）——用体力透支程度替代感情强度，救援的可信度和感情的深度同时成立
- **卡点与伏笔**：结尾卡点：鹤遂睁眼（下章第一段对话）；埋设伏笔：宋敏桃对肖护家恩怨的"言辞闪烁"与"难以启齿的隐情"、宋敏桃看到画板认出周念

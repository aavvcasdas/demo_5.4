# 第45章 病症 摘要

**概要**：打砸按摩店的那群女人拒绝调解赔偿，情愿被拘十几天也不肯给宋敏桃道歉，还让她想要钱就去告，吃准她没钱没心力抗衡；刘春花在调解室里冷嘲"别以为你没做皮肉生意就有什么可骄傲的""藏这个怪物女儿也不是什么能晒到日头底下的光鲜事情""我要是你啊，我早就去死啦"，宋敏桃心力交瘁、连悲伤都已衰竭，只无声移开视线对警察道谢说自己得回家照顾女儿。走出派出所时鹤遂等在红火烈日下，脚边积了一圈烟头，母子相望无言，她抬手摸他的脸，他轻轻握住她的手，带她回家。回家后宋敏桃表现得太过正常反而反常——不回房间冷静，立刻清理冰箱、打扫厨房、冲洗院子、打扫各个房间，鹤遂跟着她里外忙活，宋平安被拴在院子里的杏子树上；晚饭她做了满满一桌鹤遂爱吃的菜，频频往他碗里夹啤酒鸭说"多吃点"，他以"够了""不要了"挡回，她眼中流露出失望和淡淡悲伤；饭后她回房拿出纸笔沙沙地写东西，宋平安把鼻涕糊在纸上，她叹气揉成团扔进垃圾桶又重新拿一张写。这天夜里正是周念冒黑来找鹤遂的那晚，他送完周念、近凌晨三点回到家，发现母亲房间还亮着灯，敲门时她只说宋平安尿在床上、马上就收拾好让他先睡。隔天早上鹤遂睡了四个小时、八点起床做了三碗撒小葱的清汤面和三个煎蛋，上楼叫母女俩起床却两次敲门无人应答，拧开门后只看见阒无一人的卧室、窗户大开、风直往里面灌——宋敏桃和宋平安都消失了。周念正在给先前那幅素描上色时接到鹤遂电话，听筒里只有急促紊乱的喘息和呼呼风声，他说"不见了""我妈和我妹妹"，她问明他在南水街便拿下一套衣服，跟堂屋里正在换新插香的冉银说"出去一趟"就出了门。她一路疾走到南水街汗如雨下，路过按摩店时看见门紧闭、地上还留着没拖干净的红油漆；找到鹤遂时他满面汗水、薄唇发白起皮，她买了两瓶水递给他，他一口气灌完整瓶，并说如果只是出去散心、"她的手机为什么关机"。两人绕着花楹镇来回找了三遍，连镇外那座被烧秃的荒山脚下都找了，暮色降临仍一无所获，去派出所报案也只得到"回去再等等看，明天人还没回去就安排人去找"。这一天下来毫无消息，反倒是周念跟着鹤遂满镇子跑的事最快传开，人们惊讶乖孩子怎么会和"那条疯狗"扯上关系，多数人先入为主认定是鹤遂纠缠哄骗周念。当晚鹤遂送周念回家，走在北清巷她身后两步远的位置，到门口时冉银从门边闪出，看清鹤遂的脸后愤怒瞬间烧起——"原来是真的""你就是出去和他厮混的是不是"，她绕过女儿走到鹤遂面前扬手甩了一记响亮耳光，鹤遂不躲不避、连脸都不偏一下，像一尊没有灵魂的雕塑；周念冲过去护在他身前说"你为什么要打他！你不可以打他！"，坚称"鹤遂他不是混小子"，冉银气得拽住她的手腕把她拉进屋，指着鹤遂警告"你要是再敢靠近我女儿一步，我一定不会放过你"，大门合上后鹤遂仍站在原地，脸上留着清晰的红色指痕。周念被拽到堂屋，手腕被拽出一圈红痕，冉银咬牙要她解释和鹤千刀那个瘾君子的儿子到底是怎么回事。

**关键事件**：1. 调解失败、刘春花在调解室嘲讽宋敏桃"我早就去死啦" 2. 母子无言相望与反常的大扫除、丰盛晚饭、纸上写字 3. 宋敏桃与宋平安在清晨同时消失 4. 周念陪鹤遂找遍全镇并报案无果 5. 两人的关系被全镇当成谈资 6. 冉银堵门、甩鹤遂耳光、周念护人、母女对峙

**逐章写法公式**：

- **情绪流向**：起：冷（调解室里的嘲讽与母亲衰竭的平静） → 承：暖与诡异（无言的相望、大扫除、丰盛晚饭、纸上写字） → 转：空与急（三碗面换来一间空房、全镇奔走、报案无果） → 合：爆（堵门的耳光、护人的反抗、堂屋里的对峙）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：调解室受辱（交代赔偿走不通） + 母子无言相望（写母亲的衰竭） + 反常的大扫除与晚饭（把诀别伪装成日常） + 深夜的纸与"尿床"借口（留下最后的疑点） + 三碗清汤面与空房间（用早餐揭破失踪） + 电话、奔走与报案（让搜寻全面落空） + 全镇流言（叠加舆论压力） + 巷口堵门与耳光（把关系暴露推到最烈） + 女主护人与母女对峙（完成第一次站队）
- **本章核心技巧**：整章都在为一次"看起来正常的告别"埋线——清扫、做饭、写字、"你睡你的"，全部用母亲日常的行动写她的决定；等她消失后，读者回看那顿晚饭和那三碗面，情绪才落地
- **卡点与伏笔**：结尾卡点：冉银"你给我解释解释，你和鹤千刀那个瘾君子的儿子到底是怎么回事"——逼问未完，母女冲突悬置；埋设/回收伏笔：宋敏桃饭后反复重写的纸条 → 消失后是否留信、去向为何；"平安她尿在床上了"的深夜借口 → 掩盖离开的准备；宋平安回家长住的不便 → 母女转移的动机；按摩店地上没拖干净的红油漆 → 第44章砸店的余波；镇上认定"鹤遂哄骗乖乖女"的流言 → 校方与镇上舆论的后续风险；被烧秃的荒山脚下（明确找了此处）→ 与"疯狗"旧事相关的场景线索；周念"出去一趟"敷衍冉银 → 后续母女对峙的引线

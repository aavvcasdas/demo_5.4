# 第119章 病症 摘要

**概要**：生雅娇的订婚宴办得很隆重，中午在京佛一处五星级酒店、晚上在海边；鹤遂提前给她打招呼要带周念一起出席，生雅娇欣然同意，还让人把周念的名字牌放在主桌、和他的放在一起。这一日他西装革履，穿一身正黑的高定手工西装，腕上一块价格足够唬人的奢侈名表，从衣帽间出来时看得周念有些发怔——这是她第一次亲眼见他穿西装，只在网上看过图片，她忍不住拍了张照片发给莫奈，莫奈连发三条感叹说这就是男明星吗、真的帅，还要和他合照发朋友圈、标题就写关于闺蜜男朋友是爆红男明星那些事；她说自己有个问题，不知道穿什么才有勇气站在他身边，莫奈回别焦虑、咱们念念纯天然大美女、十分般配。她放下手机犹豫地说"我觉得你今天有点太帅了"，他对着镜子整理领带反问你不喜欢，她吞吐着说之前就说过觉得有点自卑、老觉得配不上现在的你；他转身几步来到她身边蹲下，把手放在她膝盖上说真心相爱的两个人之间是不用觉得谁配不上谁的，四年以前他也自卑，觉得她那么耀眼温暖、自己怎么配走在她身边，可后来是她的爱让他觉得也值得被美好围绕，所以念念别自卑，他本来就是一个平凡的人，是她的爱给他渡上金光，只有在她的眼里他才光芒万丈。她淤堵的思绪顿时消泯，他又说"你是我的女朋友这件事，一直都让我特别骄傲"，宠溺地揉她的脑袋说恨不得把她揣在包里、走到哪儿带到哪儿；她被逗乐说少扯，他不依不饶说不信你试试，手指触到她领口开始拆解，"首先需要去皮，不然携带起来太重了"，她一把抓紧领口说乱来会迟到，他说我尽快，"你就当我是个秒男吧"，她蹭地站起来说先下楼、再见，身后传来他低徐的笑声。去酒店的路上堵车，她在心里庆幸幸好没在家里乱来；酒店门口有很多记者——订婚主角是名导生东返的掌上明珠，又知道影帝鹤遂会出席，各方媒体当然不会错过，郁成让司机把车停在后门。时间有点赶，他还要去生雅娇的休息室提前看她，拉着她走得颇快，她紧张地说怕她不喜欢我怎么办，毕竟大小姐喜怒不定、讨厌一个人不需要理由，何况他还曾因为她把生雅娇气哭过；他淡淡地说没事、她人很好——在沈拂南留给他的记忆里，生雅娇就是个小女孩性格，买个包包就能哄好，平时多是笑脸挂在脸上。事实证明她的担心完全多余，一进休息室生雅娇没先给鹤遂打招呼，而是热情地冲她招手喊"嫂子，你好呀"，一句嫂子把两个女孩的距离拉近；她拿出提前准备好的红包祝新婚快乐，生雅娇没客气地接过后转脸问鹤遂答应的表演节目，他示意看郁成手里提着的小提琴盒。他在台上拉了一曲《卡伐蒂娜》，运弓极为优雅娴熟、指法准确到位，舒缓优美的旋律流淌在整个大堂里，下面无数人拿手机录这一幕，包括坐在最前排正中间的周念；他就站在她的正前方，目光始终停留在她身上，唇角噙着一弧似有似无的笑，她看着手机里的他才发现他一直在看她，不好意思地抬眼，发现周围好多人也在顺着他的目光看她——爱意快要从他的眼睛里跑出来，是个明眼人都能看见。同桌的生东返凑过来小声说"那小子很喜欢你嘛"，她抿唇谦虚说还好，他说鹤遂昨晚打电话和他坦白了一些事，关于多重人格什么的，自己毫不介意，他现在也挺好，"他还愿意叫我一声生爹就行"——生东返也只需要他扮演好理想中的角色，并不介意皮囊里的灵魂是谁；她在心里默默说，我不一样，鹤遂，我是非你不可的。关于2013年的山火案重新被推到大众视线里时掀起一波民愤，那毕竟是十几条年轻鲜活的生命，最年轻的一位消防员刚满十八岁，给鹤广判死刑的呼声高之又高；这事对他没什么影响，他之前已明确和鹤广划清界限，而且有知情人透露就是他到派出所举报的鹤广，与他和周念同去派出所的时间线完全对得上，网友对他多褒少贬、称他愿意大义灭亲。他本人倒很少去听网上的声音，很清楚就算没有山火的事，鹤广本身也是罪孽深重的人，只不过这件事让死亡在他身上落下更厚的砝码。由于社会关注度高，案子进度很快，从落网到宣判仅一个多月，结果是死刑、立即执行，鹤广上诉被最高院驳回、维持原判。执行前他依照说过的话去见最后一面，囚犯会面厅里他坐在厚重玻璃前，面无表情地看着鹤广被带出来——还是那张让人憎恶的脸，形容枯槁、双颊凹陷、一嘴黄烂的牙齿、面如纸色；他拿起听筒，冲他缓缓露出微笑说"真好，你终于可以去死了"。鹤广一怔后愤怒质问你就这样对你老子，他嗓音裹着寒也有些颤抖地反问"你不该死吗"，说你知不知道我当时就差一点就能走到她面前——那天是2013年6月9日，是他约定带周念逃走的日子，卖完血的他虚弱又疲惫，拖着有些浮的脚步走向云宜火车站，从怀里掏出她写给他的信，想着马上就能见到她、先看一看信也是可以的，看到那句"鹤遂，与你之间，我们的距离恒定"时他苍白的唇缓缓勾起露出淡淡笑意；还剩下几百米，他抬头遥遥看见火车站阶梯上蹲着一个熟悉的身影，是她，是念念，怀里还抱着他送的那一株万年青。伴随着一声闷响，后脑传来强烈剧痛，他单膝跪倒、强撑着回头，看见鹤广像个突然降临的魔鬼、手里拿着一根木棒得逞地笑着；他想保持清醒，力气却被一点一点抽走，刚想抬手就重重摔倒在地，脸贴着冰冷地面，身后传来鹤广谄媚带笑的声音"生导吗？对对对我是鹤遂的父亲，上次和您聊过我儿子拍电影的事情"——他懂了，鹤广一路跟踪他就是要让他去拍电影、成为一棵摇钱树。他想起两天前：那天是周念高考的日子，他向厂里请假回小镇到校门口见了她一面给她加油，等她进考场后坐车回市里，出车站走在人行道上时一辆黑色路虎停在他身边，生东返下车递名片问他对拍电影感不感兴趣，他直接绕过说"没兴趣"，被追上后只回一个"滚"；生东返没见过这么脾气冲的年轻人，停在原地望着他清瘦的背影只觉得可惜，也就是在这时，偶然撞见这一幕的鹤广凑上前说"导演是吧，那个我是那个小子的爸爸"，他不幸的命运开始转轮。少年狼狈地趴在地上，看着远处她的身影颤抖地伸出手想要触碰，一个小偷却趁鹤广背身打电话的功夫利索地扒走了他怀里的钱包和那封信——这是属于他的至暗时刻，他弄丢了她的信，看着近在咫尺却够不到的她生出无尽的绝望，明明只差一点点就能到她身边带她离开，一步之遥、相隔万里；那之后他先是被困在魔鬼学校六个月受尽非人折磨，后来又被囚在原本属于他的身体里四年、永无光明，如果不是后来与周念重逢，他可能会一直待在黑暗里。鹤广还在替自己狡辩"我那也是为了你好啊，你当大明星多挣钱啊，现在要啥有啥，多风光啊"；他闭上眼长吸一口气，缓缓说"希望你死后一定要下地狱，离妈妈和妹妹远一点""你这种人，一定要下地狱"，不给对方再开口的机会就啪地把听筒放回原处，离开前冲他狠狠竖了一根中指，用嘴型再次说了两个字"去死"。周念一直在外面等着，他走出来看见她瞬间红了眼，紧紧把她抱在怀里、嗓音发抖地说"念念，我当时真的，就差一点点了"——就差一点点就能走到她面前、就能兑现带她逃亡的承诺；她大概知道他在说什么，抿抿唇抬手回抱住他、比他抱她还要紧，温声说没关系、你已经很努力了，以后我们一定会很幸福的，他低低重复"会幸福的"，她答"嗯，一定"，相信两人在经历过那么多的不容易后从今往后都会特别幸福。八月中旬，一场高关注度的全国画家联展在京佛举行，周念的画作《晚森流浪》也在展位之中；联展当天她独自一人去到会展中心，这时的鹤遂已经进组，成天忙得饭都顾不上吃，没有空参加她的画展。开展后人非常多，她在一幅又一幅画作前停留细思慢品，也站在远处看着自己的画前围满了人，喜欢那一幅画的人很多、女孩子居多，好多女孩子停在画边自拍，她心里渐渐松一口气——还担心重新画画后的作品不会受人喜欢呢。场内开始有人认出她是鹤遂的女朋友，纷纷投来目光，也有大胆的找她要合影，她没经历过觉得新鲜、也都友好答应，有个女生夸"嫂子好美，照片都可以不用修直接出"，又问遂哥新电影是不是要拍完了，她温和地答他说还要两个月。刚说完，空气里突然冒出一阵骚动，她听见身边人窃窃私语"卧槽，鹤遂来了""听说到门口了啊"，正疑惑着包里的手机震动起来，是鹤遂打来的，她接起电话，听筒里传来那句"你转身"——一转身就看见十米开外的他，身上还穿着拍戏时的衣服，白T搭灰色休闲裤，很寻常的穿搭落在他身上帅出另外一种境界，他逆光而站、面目些许模糊，随意一个插兜的动作都引爆一片少女心；他望着她露出淡淡笑意说"傻了？"，她慢半拍地问你不是在剧组吗，他说请假了，又说放他们半天假、带薪的，都在乐呢，随即当着所有人的面冲她招手说还不过来，她温吞地说"我不，我要你走向我"。他失笑两声便抬脚，长腿一步一步地朝着她靠近，又说"巧了"，她问什么，他眉眼逐渐清晰，薄唇缓缓开合，嗓音隔着几步之遥与听筒中的声音重合着一并进入她耳中——"念念，我这一生走过许多路，但我最喜欢的路，还是走向你的路。"他陪她逛展，视若无人地与她亲密着，从头到尾牵着她的手没放开过；停留在她的画作前时，他特意留意她新取的画家名字"小顺遂"，若有所思地盯着看了半晌，扭头说"我怎么觉得这名字和我有关"，她扔出一句"少自恋"，他厚脸皮地凑上来问"说说看？"，她故意逗他说才不要呢。他掏出手机递给她让她帮忙，说麻烦帮我拍一下照，我要和女朋友的画合个影，周围爆出低呼声，有人直呼磕到了磕到了，她脸上一热不敢看四周，接过手机飞快又随意地给他拍了一张，匆匆拉着他离开现场。回去的路上他还在评价她的拍照技术，"也得是拍我，换作别人拿给你拍的话，估计能被你拍成元谋人"，她抢过手机说哪有那么夸张，结果一看瞬间心虚——幸好拍的是三百六十度无死角的他，否则肯定很灾难；他还是用她拍的照片发了一条微博：@鹤遂：再忙也要来看女朋友的画。

**关键事件**：1. 主桌上的名字牌 2. 第一次见他穿西装 3. "是你的爱给我渡上金光" 4. 一句"嫂子"拉近的距离 5. 《卡伐蒂娜》与始终看着她的目光 6. "还愿意叫我一声生爹就行" 7. 大义灭亲与死刑立即执行 8. 会面厅里"你终于可以去死了" 9. 6月9日那根木棒与摇钱树 10. 被扒走的信与够不到的她 11. "我当时真的，就差一点点了" 12. 走向你的路

**逐章写法公式**：

- **情绪流向**：起：甜（西装、自卑与被拆掉的配不上） → 承：轻松转压抑（一句"嫂子"与大义灭亲的舆论） → 转：爽与悲伤交替（会面厅里的"去死"与6月9日那一步之遥） → 合：甜中带释然（画展上的"走向你的路"与那条微博）
- **节奏配比**：慢铺垫 20% / 快冲突 20% / 爽点爆发 25% / 悬念留白 35%
- **本章结构公式**：公开场合确认关系（主桌、嫂子、目光） + 报应落地（死刑与最后一面） + 真相回放（6月9日那一棒与命运的一串偶遇） + 各自前程里的重逢（她的画展与他的请假赴约）
- **本章核心技巧**：用"差一点点"作为全书最后一条情感主线——会面厅里他说"就差一点点"，火车站那一段用几百米和一根木棒把这四个字具象化，再在画展上以"走向你的路"完成反向补偿：当年没走完的那段路，这一次由他当着所有人走完。
- **卡点与伏笔**：结尾卡点：全书收束于他发的那条微博"再忙也要来看女朋友的画"，余下十一个副人格的整合与他的新电影仍在继续；埋设/回收伏笔：6月9日（卖血日期 ↔ 约定逃亡日 ↔ 被鹤广一棒，三线合一）；被扒走的信 ↔ 第115章"没来得及打开看过"的翻案；生东返递名片 ↔ 鹤广凑上前（命运转轮的起点）；"小顺遂"（她的新画家名，与他的关联留白）；万年青（火车站的等待）；宋敏桃、宋平安（"离妈妈和妹妹远一点"）；主桌名字牌 ↔ 生雅娇那句"嫂子"；一周一次的人格整合仍在持续。

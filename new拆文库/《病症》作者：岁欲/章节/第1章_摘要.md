# 第1章 楔子 摘要

**概要**：二十二岁生日当天，周念被母亲冉银从南方小镇带到京佛精神卫生中心求医。她被人群挟裹出站，在遮阳棚下抬头看见幕墙屏上的高奢手表广告——屏幕上那张脸让她呼吸一滞。随后她在人流里认出一个清瘦背影，世界的声音逐渐消失，她踉跄穿过人群喊出"……鹤遂？"。男人转身，摘下口罩后被年轻女孩的尖叫包围，却只对她说三个字："不认识。"周念扑上去拽住他颈间黑绳，扯出一颗用银丝缠绕的人类牙齿——那是她十七岁拔下的智齿，被他做成项链戴了四年。她被保安拉开摔在地上，围观者议论她"精神不太正常"。冉银赶来向众人解释"我女儿精神不太正常"，并拒绝主持人给的合照机会。周念在被拖走前干呕、意识溃散，只留下一个结论——鹤遂忘了她。

**关键事件**：1. 到京佛求医，在幕墙屏上认出鹤遂 2. 人群中指认，被当众说"不认识" 3. 拽出智齿项链作为反证 4. 被保安摔地、遭围观者议论 5. 意识溃散前确认"鹤遂忘了她"

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| 女主是病人且她认识屏幕上的顶流 | 用一个生日场景反向拉低（没有蛋糕、没有礼物），再用"京佛精神卫生中心"的电话坐实病人身份，最后让她的呼吸在人脸出现时一滞 | 场景反差 + 三层信息叠加 | 好奇 | 开篇三句内完成人物定型与悬念投放 |

**逐章写法公式**：

- **情绪流向**：起：陌生（新城市） → 承：紧张（人群追认） → 转：撕裂（"不认识"） → 合：悲怆（干呕、忘记）
- **节奏配比**：慢铺垫 25% / 快冲突 55% / 爽点爆发 0% / 悬念留白 20%
- **本章结构公式**：生日求医（病体建立） + 幕墙屏（身份落差） + 人群指认（私密撞公开） + 当众否认（最强痛点） + 智齿项链（反证） + 摔地围观（余波） + "鹤遂忘了她"（立主问题）
- **本章核心技巧**：把四年后的最惨一幕放在第一章，用"他忘记了但她没忘"的信息差制造全书的倒计时式悬念
- **卡点与伏笔**：结尾卡点："鹤遂忘了她" + 末行"夏天来了，周念和鹤遂也来了"（转回四年前）；埋设伏笔：智齿项链、《昼春》电影路演、冉银的"精神不太正常"

# 第117章 病症 摘要

**概要**：鹤遂要在两天后离开小镇回京佛，参加生雅娇的订婚宴，同时重新投身演艺工作；恰逢离开的前两天是宋敏桃和宋平安的忌日，周念便陪着他在一个深夜去看她们母女俩。白天她一人出门到丧葬店买了些纸衣纸元宝和能亮几十个小时的电子红蜡烛——2013年那场山火后当地采取禁火措施，一切冥币纸钱都不许焚烧，所以只摆放不烧，另外还买了些时令水果。出门这一趟她注意到不少人热情地和她打招呼，连当初对她极尽冷嘲热讽的人也换了脸色，那些目光里有艳羡也有嫉妒：年纪轻轻二十二岁就成了当今顶流的女朋友，顶流甚至不惜一夜掉粉几十万也要公开，换谁能不羡慕；可他们没想过，在很久的从前，当周念早已因极高的画画天赋出名时，鹤遂还是一条人人喊打的疯狗，全镇人都对他敬而远之，而她是第一个也是唯一一个对他抛出善意橄榄枝的人——所以不论她现在有怎样让人歆羡的境遇，那都是她值得的。小镇上逝去的人都埋在郊外山间，一个土山包里住着一个亡灵，条件好的买棺材立碑，次点的直接埋骨灰盒再插一块手写的木牌子了事；走在漆黑的山林里，鹤遂把她的手拉得很紧，另一只手提着东西问"怕不怕"，她温吞地答"你拉着我的话，我就不怕"，月色下他回头说"我会一直拉着你"。找到坟后，两人停在石碑前看着上面有些褪色的照片——照片上的宋敏桃姿容艳绝、笑容却格外平易近人，旁边的宋平安用着一张四月龄的照片，那是她唯一一张照片，看上去和正常婴儿无异；他蹲下身把纸衣、纸元宝、红蜡烛相继摆在两座碑前，电子蜡烛的红光照着他阴郁的脸，他抚着墓碑一角说妈、妹妹，我现在很好，你们都不要担心，我遇到了一个很爱的姑娘，妈你认识她的，她叫周念，这么多年过去在我身边的还是她，我也只喜欢她。他又垂眼说自己以前不好、从来没有回来看过你们，以后不会了，每年都会回来看你们，你们在那边要好好的，一定要多来我的梦里看看我；周念站在他身边控制住想哭的冲动，认真地对墓碑说阿姨、小平安，你们放心，我一定会好好照顾鹤遂的，我会一直陪着他，永远和他在一起。回家时已是深夜十二点，线面在院子里的小棚里熟睡——那棚是他白天花了六个小时搭的，用砖、木板、铁皮，相当的熟稔有余，看来早年在装修师傅那里学的手艺还没丢。白天红火烈日下，他穿着件最寻常的白色老头背心，极致的冷白皮、优越的头肩比、肩膀很宽，拿着瓦刀慢条斯理地抹水泥，周念站在旁边捧着给他倒的冰水，忽然问起他发的公开微博里有艾特她的微博，她记得从没告诉过他那是自己的号；她的微博名叫"一起逃返吧"，是她在京佛精神病院时注册的，也就是在他生日那天，她还用这个号给他留过一条评论。他停下动作把瓦刀搭在砖上起身，接过水仰头猛灌、喉结急遽滚动，一口气喝完整杯后用拇指擦了擦唇角，说两人还在东济时他闲得无聊看微博评论，一眼就看到了她的评论——她祝他生日快乐，关于那条评论的每一个字他都记得很清楚。她更疑惑了：他每一条微博的评论都是一百万以上，从百万评论里被看到是多小的概率，他转过脸、脸庞一半光亮一半阴影，慢悠悠地说"直觉"，又说"我就是知道，那一定是你"。她偷偷抿唇一笑说那好吧，我就当自己是你的真爱了，他懒懒抬眼说你还挺自恋，她瞪眼反问难道不是吗；他勾唇笑得迷人，点了点玻璃杯闲散地说"真爱，你要不要再去给我倒杯水"，她站着没动忍着笑说可以，除非你求我。他重新放下刚拿起的瓦刀，利落简短地说"行"，随即以很快的速度扣住她的下巴、低脸吻下去，唇齿相贴的一瞬她呼吸一滞，脑中像放烟火般绽开五颜六色的形状，心跳飞快——她明明已和他做过，却只是接个吻就有种高烧不退的眩晕感，而她没有闭眼，看得见他黑眸中得逞的笑意，知道他是故意的。等他松开，她红着脸磕磕绊绊地问你干嘛突然亲我，他眼梢一挑做出一脸无辜："这就是我求人的方式，怎么了？"她一字一顿地说"没！怎！么！"，他又故意凑到她没捂的那只耳朵边连声叫"真爱"，她气得放下杯子要打他，他一边躲一边后退，笑得特别欠揍地说"傻子才不躲呢"；阳光下她追着他满院子跑，他会故意停下来等她逗她，眼角眉梢都酿满笑意，恍惚间两人都回到了那年的十七岁。上楼后周念先洗澡，出来看见他还坐在桌前打字，说在回郁成——郁成已按要求帮他约到了韩老的号，让他明天一早过去；她眼睛一亮问那明天过去就可以做人格整合吗，他说应该是，她开心得眼睛弯成月牙，相信一切都在往正轨上前行。翌日一早她醒得很早，他还搂着她想赖床，被她强行摇醒说起来、我们早点过去；他嗓音含糊地问去哪，她爬到他身上伏在他胸口说去医院啊，他把脸转过去埋进枕头里，碍于她整个人都在身上根本翻不动，她伸手把他的脸从枕头里掏出来、凑到他耳边软软地撒娇"别睡啦"。外面还是半黑的天，他终于舍得睁眼却只睁一半，虚眯着眼一只手放在额头懒散地说"念念，你这样可叫不醒我"，她问那要怎么叫，他说我教你，随即伸来一只大手按住她一侧肩膀将她往下推，她一下滑进被子里，抬头那一瞬他已经扯过被子把她的头一并盖住。四十分钟后两人一起洗漱，她很轻地刷着牙、喉咙里涩痛感很强烈，通过镜子瞪着身后容光焕发的他说"我要是长溃疡的话，都怪你"；他低低一笑说别生气、今晚换我，她僵住不确定地问换你什么，他目光下滑又回到她脸上，只说两个字"你猜"，她瞬间意会、脸上烧出一片红云。他忽然一把将她抱起来放在盥洗台上、自己却蹲了下去，扬起脸用欲色横生的黑眸直勾勾抬头看着她问"要不现在试试"；她下意识夹紧双腿从盥洗台上跳下来，羞得通红地把他推出厕所说"我不要和你一起洗漱，等我弄完再换你"，门外传来他低沉的笑声，她拍一下门羞得要命地说你不要笑了，外面静了一秒后传来更加放肆的笑声。

**关键事件**：1. 两天后回京佛与忌日撞在一起 2. 只摆放不焚烧的纸衣纸元宝 3. 镇上人态度的转变 4. 深夜山林里"我会一直拉着你" 5. 墓碑前的告白与承诺 6. 六小时搭好的狗棚 7. 百万评论里的那个"直觉" 8. "这就是我求人的方式" 9. 满院子的追逐与十七岁 10. 约到韩老的号 11. 叫不醒的早晨与被子里的四十分钟 12. "今晚换我"与"你猜"

**逐章写法公式**：

- **情绪流向**：起：悲伤（忌日、禁火规则与坟前的告白） → 承：爽与温馨（镇上人态度的翻转、六小时搭好的狗棚） → 转：甜（百万评论里的"直觉"、求人的吻、满院子的追逐） → 合：轻松期待（约到韩老的号与早晨的赖床闹剧）
- **节奏配比**：慢铺垫 25% / 快冲突 0% / 爽点爆发 20% / 悬念留白 55%
- **本章结构公式**：倒计时（两天后离镇） + 夜祭（把逝者、承诺与亏欠一次说完） + 白日甜宠（用一个悬案答案与一场追逐把情绪推高） + 翌日清晨（用赖床闹剧把两人送向人格整合的下一站）
- **本章核心技巧**：把"祭奠"和"调情"放进同一章且不违和——前半夜用墓碑前的告白与承诺压低情绪基线，白天用"你怎么知道那是我的微博"这个小疑问把情绪抬起来，两段的落差本身就是节奏。
- **卡点与伏笔**：结尾卡点：韩老的号已约到、翌日一早就要去医院，人格整合即将开始，下章期待是整合过程与沈拂南的处置；埋设/回收伏笔：生雅娇订婚宴（两天后，倒计时）；电子红蜡烛与禁火措施（13年山火）；宋敏桃、宋平安的坟与"每年都回来看你们"；"一起逃亡吧"这个微博名 ↔ 他生日那天的评论（回收）；线面的狗棚（六小时，早年装修手艺）；韩老 ↔ 人格整合（承接第116章"我陪你去做人格整合"）；"今晚换我"待回收。

# 第57章 病症 摘要

**概要**：和莫奈谈起那个人时，周念不可避免地被拉回2013年那个夏天。逃亡失败的她被冉银捉了回去，冉银拿着两张火车票质问她时她无可辩驳、始终一言不发，像生了哑病，那之后好长一段时间都不愿再开口说一个字；她开始发烧、生了一场经久难愈的重感冒，烧退了又来、来了又退，终日觉得自己泡在一个熔炉里被烤着融化，迷迷糊糊时还会不停喊一个名字，喉咙里的声音又嘶哑又微弱、不像活人。好不容易痊愈后，她发现自己还在那个房间里、在北清巷的房子里、在熟悉的花楹镇里——她没能逃出去，然而那个说要带她逃走的人却人间蒸发，发过的微信、打过的电话都如沉海的石头。周念想他是不是在去火车站的路上出了意外，否则怎么会抛下她；已是7月，一个月过去，她不顾冉银的劝阻跑到派出所报失踪，民警却说"他没有失踪哈，也没有出什么意外，只是人没回小镇"，再问在哪里便被以"涉嫌泄露隐私"挡回——他没有失踪、也没有出意外，他只是不回来了。她无论如何也接受不了这个说法，发疯一样地找他，去了任何一个他可能在的地方、甚至去过他打工的厂里，得到的答案却很统一：所有人都说没再见过他。饶是这样，她还是一根筋到绝境，认为他才不是抛弃她，而是先去京佛等她了，于是按照原本的计划报了京佛美院；冉银很清楚她报京佛美院是为了谁，这当然不被允许，只是通知书下来后无法更换学校，冉银便把京佛美院的录取通知书撕得粉碎，也把她最后的希望彻底剿灭。周念被迫走上复读的道路，却再也没办法拿起画笔画画——她觉得自己就是个脑袋空空的木偶，对着画纸时表情木然又冷漠，昔日给他画画的场景不停在眼前闪现时，她会立马把画笔扔出去很远，像那是什么非常恐怖的东西。复读那一年浑浑噩噩，小镇的人都拿异样目光看她，想不通美术联考第一、京佛美院校考第一的人居然不去念美院、反而留在小镇复读；她的厌食症也在恶化，逐渐分不清饱足感和饥饿感，每一餐饭后都把食物吐得很干净、次次都要吐到看见胆汁才罢休。当她暴瘦到65斤时，冉银终于发现她的不对劲，开始给她买各种高营养的补品和食材——燕窝、松茸等等，还买了人参给她煲汤喝；她知道买东西的钱从何而来，每一次都会用一种无比嘲讽的眼神看一眼冉银的断指、再看一眼那些东西，然后起身离开，决计不会吃上一口。2014年的夏天，埃博拉病毒在西非爆发、死亡率超七成以上；也是这年夏天，周念收到本地云宜市一所重本大学的录取通知书，中文系——她自己都没想到最后会读一个和画画完全没关系的专业，想来她的体内也有不少株致死性的病毒在潜伏着，才让她的人生走上一条荒诞可笑的道路。收到通知书同一天，有人问她有没有看那部《屠佛少年》，她没兴趣、眼皮都没抬一下，直到那人说"没想到咱们小镇还能出电影明星啊"，旁边人接话说"还是当初小镇最不受待见的人""不得不说他确实长得好""天生的电影脸"；周念慌了神，仓惶地从议论声里逃走、躲到一个无人的小巷里才敢拿出手机搜索，电影海报刚跳出来她就在上面看见一张熟悉的脸孔，瞳孔剧烈颤了一下，她把手机亮度拉到最高，看清那是一张设计绝伦的海报——对角线结构凸显男演员的锋芒，他俯视镜头伸出一只手，相当死亡的角度却找不出死角，眼神如刃、轮廓清晰，配上身后翻滚的黑色云海更显神秘强大。她看了那张海报很久，最后不死心地去看演职员名单，看见那两个字时终于肯接受了——鹤遂，是他没有错。随着那年暑假《屠佛少年》的大爆，花楹镇沸腾不已，大家又开始热烈议论起鹤遂来，不过这一次没人再骂他疯狗、也不会再把肮脏词汇用在他身上——所有人都突然开始爱他，说他从小就长得特别好看、也很可怜，还有人后悔之前没有对他好一些；周念也被各式各样的人追问是否还和他有联系、能不能帮要个签名、能不能约回来一起吃个饭，她自然没有那个本事，她早就没办法联系到他，也只不过是一个普通的观众而已。她也去看了他的电影，坐在电影院里最后一排的角落位置；那是一部热血复仇片，观众情绪高涨，只有她一个人从他一出现在大荧幕上就开始哭——她终于见到了朝思暮想的人，以这样的方式。电影散场后，保洁阿姨来打扫时发现最后一排还坐着又瘦又小、两只眼睛肿得像两只核桃的小姑娘，问她怎么了，周念哽咽着用只有自己能听见的声音说"没事""我只是很想他"。回忆到这里，周念只觉得有一股火从胃里烧上来、眉心传来一股酸意，她让莫奈拿来角落里的呕吐盆，坐起来捧着盆吐了起来，却什么也没吐出、只有胃酸和胆汁；她说"习惯了""胃酸会反上来，吐出来会好受点"，并答莫奈说厌食症是高中就得的；莫奈想到她高中就很瘦，却说现在的她和高中完全不是一个瘦法，让她一定快点好起来——她曾经的确有一段时间好起来过，那时还有人说过"周七斤，七七四十九公斤，他的目标就是把她养到四十九公斤"。莫奈约她等好点就带她去看自己直播的地方散散心，随后因晚上还有一场直播先行离开。周念有气无力地瘫回床上，刚闭眼就听见外面走廊里传来男人的嗓音"嗯？"，那嗓音像玉石的冰凉质地又带点儿懒意；她霍地睁眼看向门口，听见他又说"哪次少了你的礼物？少逼逼"，很冷淡的腔调却有点像在哄人——买礼物，女孩子才需要买礼物，听他口气不像买给男人的。她艰难地起身、推开被子抬脚下床，却因没力气摔到了地上，手背传来刺痛；她不想拔针给护士添麻烦，就扶着床站起来、把挂钩上的输液瓶取下来提在手里，打开门冲出去时房门撞在墙上发出砰的一声，惹来前方的男人驻足回眸——走廊尽头一扇天窗开着，他逆光而站、英俊脸庞模糊在光影里，戴着黑色口罩、姿势懒散、单手插在裤兜里。她单手扶墙、另一只手提着输液瓶，软管里的血液开始回流；这时鹤遂的目光终于落到她脸上，那些如金粉般浮沉的尘粒仿佛静止，时间被按下暂停键——这一次他看她的眼神有了变化，不像在路演现场般的冷漠无温，而是多了一丝厌恶，除此外什么多余的情绪都没有。对视没能超过三秒，他轻描淡写地扫过她的脸、又扫了一眼那根已经回流好长一截鲜血的输液管便挪开眼，转身进了旁边的诊室；她扶墙一步步靠近，看见诊室门牌上写着"心理干预理疗室"。一名年轻男子走过来挡在她面前说"不好意思，你不能进去哈""你要是再这样骚扰鹤哥，我们会报警的"，自称是鹤哥的助理并翻了周念一个白眼；周念虚弱地解释"我和他认识的，我想和他聊聊"，被助理挥手赶"你可省省吧""走走走"。她没走，固执地留在原地等着、举着药水瓶的手臂发酸得厉害；过了好一会儿门从里面打开，鹤遂走了出来，助理赶紧跑到她身前用背挡着她，像是生怕她会有什么危险动作。他越来越近时，天窗里涌进来一阵风，把他身上的味道吹给她——一种质地清冷的男香，雪松混淡茶，很淡却散着悠远、有旷野袭来的侵略感，不再是十七岁少年时期的淡淡皂香。周念把头从助理肩膀处探出去，苍白干裂的唇缓缓张开，发出嘶哑虚弱的颤音"鹤遂，我……"，而他根本就不看她、一步都没停，长腿越过她时带起的那一点微风都那么冷漠无情；周念认命般闭上了嘴——四年太久了，他变成了她完全不认识的样子，也变成了彻底不在意她的模样，不管她愿不愿意接受这都是事实，而她却什么都做不了、无能为力。他消失在视线里，风又吹进来了，这一次是带走空气中他残留的一点气息。

**关键事件**：1. 逃亡失败被捉回、一言不发与高烧重感冒 2. 派出所报失踪得到"他没有失踪、只是人没回小镇" 3. 京佛美院通知书被冉银撕碎、被迫复读与再也画不出画 4. 暴瘦到65斤与拒吃买来的补品 5. 2014年夏天《屠佛少年》海报与"鹤遂"两个字 6. 全镇改口"所有人都突然开始爱他"、她被追问要签名 7. 影院最后一排的哭与"我只是很想他" 8. 医院重逢：走廊里的电话、"心理干预理疗室"、助理拦人、换掉皂香的男香与一步未停

**逐章写法公式**：

- **情绪流向**：起：闷（不敢回忆的灰暗） → 承：熬（高烧、复读、吐到胆汁、65斤） → 转：亮与痛（海报上的脸、影院最后一排的哭） → 合：冷（走廊里的电话、厌恶的眼神、一步未停）
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：逃亡失败与失语（写被捉回后的静） + 高烧与派出所报失踪（让希望由公家判死） + 撕碎的通知书与复读（回收美院线） + 停笔与厌食恶化（用身体与能力同时崩塌） + 补品与断指（写母女之间零交流的对峙） + 2014年的埃博拉与中文系录取（用时代与专业错位写荒诞） + 海报与演职员名单（用一张海报确认他的去向） + 全镇改口与被追问签名（写世态的反面） + 影院最后一排与"我只是很想他"（把思念交给陌生人听） + 呕吐盆与"习惯了"（把旧病拉回现场） + 走廊里的电话与男香（让重逢落地） + 心理干预理疗室与助理拦人（设置无法同一空间的障碍） + 一步未停（以位移完成拒绝）
- **本章核心技巧**：整章是一段追问式的倒叙——用"为什么他会抛下我"从头查到尾，查到的是"他没有失踪、也没有出意外，只是不回来了"，再用《屠佛少年》的海报把"不回来"变成"去了别处"；重逢段落刻意只给嗅觉与步伐，不给一句台词，把解释权继续悬置
- **卡点与伏笔**：结尾卡点："风又吹进来了，这一次，是带走空气中他残留的一点气息"——他进了"心理干预理疗室"，就诊原因与那句"哪次少了你的礼物"都尚未解释，下章期待为门后的真相；埋设/回收伏笔：两张火车票（第55章）→ 被冉银当作质问的证据；第55章的失约 → 本章确认他"没有意外、只是不回来"；京佛美院的录取通知书被撕 → 她与那条路的彻底切断；画笔被扔出去 → 停笔的心理成因；冉银的断指与补品 → 母亲用那笔钱供养她；"心理干预理疗室"与助理 → 鹤遂当下的处境与病况；电话里的"哪次少了你的礼物" → 他身边是否存在别人；雪松混淡茶的男香 → 取代皂香的人物标识；呕吐盆、胃酸与胆汁 → 康复线的具体障碍
- **时间线**：回忆段为2013年夏至2014年夏；现实段接第56章，为2017年11月

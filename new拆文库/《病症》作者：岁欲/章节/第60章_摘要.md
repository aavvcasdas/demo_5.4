# 第60章 病症 摘要

**概要**：京佛是座很难会下雪的城，上次下雪还是二十年前的九零年代——别的地方在飘雪，京佛只会下一场冰雹雨，雨停了翌日又是个艳阳天。在十二月快要结束的一个夜晚下了场冰雹雨，石子大小的冰坨像箭雨般落下，砸在车顶、地面、雨棚和任何一个暴露在外的地方砰砰作响。周念站在窗前看着这场雨，身后传来同房病人无比激昂的演讲声——她现在不住单人病房，一周前王医生将她从重症病区调到普通病区和其他病人同住，一间病房住四个人，她这间还住了另外两个、另外空出一张床位。正在发表演讲的是一位昆虫学家裴巷，他患有严重的双相情感障碍，永远在极端亢奋和极端抑郁的两种状态下切换，几乎不会有过渡的中间状态；他的病床前围满了主治医生、三个护士和两名社工，都是他的观众，他手里拿着一只巴西大蓝闪蝶的标本，语速是普通人的三倍、快得像发电报，说好多人以为闪蝶的蓝色翅膀本身是蓝色、其实那与色素无关，完全是一种光学效应，是因为翅膀上布满数百万的角蛋白鳞片，又讲蛾子和蝴蝶的区别可以靠触角分辨。亢奋中的裴巷近乎癫狂、思维跳跃，讲话时仿佛有一万只蝴蝶从他嘴里飞出来；他需要观众，每次亢奋都需要最少五个人听他讲话来满足表达欲，不然就会发疯、或许还会拆掉整个病房。周念也是其中一个观众，同在一个病房想不听到都很难，她有时甚至会羡慕裴巷有用不完的精力，和死气沉沉的自己截然相反，但也仅限羡慕他的癫狂状态，因为他的抑郁状态和她一样死气沉沉。病房里还住着一位与周念年纪相仿、大学刚毕业的男生徐散，他被家里人送来，起因是他老看见一个人拿着刀想要伤害他的母亲，为了保护母亲他冲过去夺刀和那个人搏斗，他赢了、用刀划伤了那个人的胳膊，最后被抬上救护车的人却是他的母亲；他总分不清现实和虚幻，住在周念的对床，裴巷在她斜对面。每当裴巷高谈阔论时，徐散总是最不感兴趣的那一个，他自己坐在床上表情呆滞、眼睛东看看西看看——周念知道，他的目光落在哪里就代表他能看见那里有一个人；和不同的精神病待久了自然也就了解一些，毕竟她也是个精神病。她又在窗前待了会儿才慢吞吞回到床边，刚好枕边的手机收到一条新的娱乐新闻推送"恭喜电影《昼春》突破20亿票房大关"，她盯着那条通知，耳边传来万根针的尖锐震响，响声吞没了裴巷激昂的声音还有护士们哄着他吃药的声音；只要一看到关于鹤遂的消息，周念总是会出现这样那样的病症——要么烧心难受，要么出现幻听，又或者心慌心悸、头晕目眩，总之不会让她好受，由此可见他对她的影响是如此深刻。她缓了一阵，等幻听不那么严重时到共用卫生间洗漱；上面摆着三个牙杯，属于徐散的杯子里没有牙膏、他都是蹭周念的牙膏，她也不介意、每次都当不知道。刷牙时她在算还有多久能出院：来京佛精神病院治疗已经有一个多月、现在体重是60斤，按一个月长五斤算，她可以在两个月后出院；倘若称重前耍点小聪明多喝些水、喝个三斤左右，那她可以更快出院。这个阶段的周念根本就不在意自己的身体、也不想后果，更不在意会不会好起来，她只想尽快出院去找鹤遂——就算听过鹤广那些话后她也没有死心，毕竟鹤广是什么恶人她很清楚，她觉得其中有隐情，说不定鹤遂是有什么难言之隐当初才会不辞而别；时至今日，她变成如今这幅病容残躯，也还是选择去相信他、相信那个曾把她放在掌心里宠着的少年。从卫生间出去时裴巷已经安静下来、陷进抑郁状态，他有气无力地靠在床头、眼神空洞，与十五分钟前大相径庭，他总这样在天堂和地狱之间反复切换；周念发现旁边的空床有两名护士在整理，被套、床单包括棉芯都是最新的，护士说"应该是，可能是个VIP患者，主任亲自交代的"，又说"主任说的，要把他和裴巷安排在一个病房，明天一早住进来"，闻言她看了眼斜对床的裴巷。她脱鞋上床，靠在床上玩了会手机，收到霍闯发来的微信——一张厌厌正在吃猫粮的图片和一句"姐姐，我今天喂厌厌了，你不要担心它，它在等你好起来回来看它"，她浅浅一笑回了"好"；如今的厌厌四岁、长得油光水滑，黑色的毛发在阳光下发亮。退出对话框返回好友列表，她看见自己的微信置顶人头像是厌厌的小时候、备注是鹤遂，便像之前无数次那样点进对话框给他发消息，说今天外面下了很大的冰雹雨、听说下冰雹砸死过人也不知是真是假，说淋这样的雨会不会很痛、自己竟然想出去试试但护士姐姐不会允许，还说这里的病房都有警报、不在自由活动时间离开病房警报就会响、整个楼道发出红光而她很害怕这种红光——周念并不是在给如今的顶流影帝发消息，而是在给十七岁的鹤遂发消息，即便她知道不会收到回复也还是会发；四年来消息已经发出去上万条，是她一个人的独角戏。她放下手机盖好被子躺下，闭上眼睛却很久都没有睡着，失眠的情况很严重——最近给她的药物里安眠量减少了，王医生建议她自主入睡，而自主入睡的结果就是睡不着。深夜的病房里她听见徐散很响的磨牙声，像真的在啃骨头似的；裴巷睡觉很安静、偶尔梦游，有一回周念半夜醒来还看见他站在床边直勾勾盯着她看，当时把她吓得不轻；一晚上不睡总能听见各种声音，尽头病房里传来女人嚎啕大哭声、还有老人嘿嘿的怪笑声，所有声音都在深夜放大，包括怪异荒诞也被放大，向来胆小的周念听着这些声音就更加睡不着，一直醒到清晨六点、听见外面走廊上开始有了脚步声后才昏昏沉沉地睡过去。睡着后她一直做梦，都是荒诞不经又恐怖的梦：梦到鹤遂抱她、亲她、陪她在夜空下看萤火虫，又梦到他无情抛弃她、用最冷漠的眼神看着她。晨光大亮、天空鸣金收兵停雨放晴，她在阵阵说话的声音里醒来，头痛欲裂、眼睛酸胀不已；她侧躺着惺忪地缓缓睁眼，视线还是模糊的，微蒙的画面里是男人肩宽瘦高的背影，他穿着与她身上一样的条纹病号服，两条腿格外修长笔直，视线再往上抬，她看见男人头顶一个反方向的旋儿。她以为这一定是在做梦，不然鹤遂为什么会出现在她面前、就在咫尺的距离——两张病床间距不到一米、最多七十公分，只要她伸手就能触碰他。既然是梦，那她肆意一点也没关系，周念用手撑着坐起来，朝着男人的背影伸出一只苍白枯瘦的手，手背上血管和青筋鼓凸着、看着有些渗人；离得越近，她的手指就颤得越来越厉害，此时此刻她心底的欲望被无限膨胀、同时理智在无限萎缩；在彻底被欲望吞噬掉的那一秒，她握住了男人垂落在身侧的手指。刹那间空气寂静，病房里正在交谈的人声也突然停止——周念本来以为这只是一场她的梦，直到男人回过头来，黑眸阴郁深沉，他扫了一眼周念握住他的那只手，而后缓缓抬眸、目光凝定在周念脸上。四目相对，周念的呼吸凝滞；她这才后知后觉地感受到，自己握着的那只手是有温度的，不是虚幻，而是有如实体般的温度——温凉，像刚从泉水里捞出来的玉石。下一秒，周念慌了。

**关键事件**：1. 十二月末的冰雹雨与调到普通病区 2. 双相障碍的裴巷与精神分裂的徐散 3. 《昼春》20亿票房推送引发的幻听 4. 徐散蹭牙膏与"喝三斤水"的出院算盘 5. 主任亲自交代的VIP患者、要求与裴巷同房 6. 给微信置顶的"鹤遂"发出第一万条独角戏 7. 失眠的深夜与荒诞的梦 8. 醒来后在七十公分的距离上握住他温热的手指

**逐章写法公式**：

- **情绪流向**：起：冷（冰雹雨、病院的嘈杂） → 承：钝（病友的癫狂与抑郁、蹭牙膏、算出院） → 转：酸（20亿票房、置顶的对话框、一万条独角戏） → 合：惊（七十公分的背影、握住温凉的手指）
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：冰雹雨与病房环境（交代时间与地点） + 裴巷的演讲与双相（用病友立病院生态） + 徐散的身世（用一句反转写精神分裂） + 20亿票房推送与幻听（用外部消息诱发症状） + 共用卫生间与蹭牙膏（把压抑写成日常） + 算出院与喝水的算盘（写她的执念） + 病友的抑郁面与空床整理（埋VIP伏笔） + 霍闯的猫与置顶的对话框（写四年独角戏） + 失眠与荒诞的梦（把思念交给梦） + 醒来后的背影与握住手指（用误以为做梦完成越界）
- **本章核心技巧**：全章刻意不写"他来了"，只写病院的日常与她的独白，把重逢藏在一场冰雹雨之后的清晨里；越界的动作因为"她以为是梦"而合理，章末也不给任何解释，只用一句"下一秒，周念慌了"把主动权交出去
- **卡点与伏笔**：结尾卡点：她握住的那只手"温凉，像刚从泉水里捞出来的玉石"、"下一秒，周念慌了"——他为何住进这间病房、为什么被安排与裴巷同房，全部悬置；埋设/回收伏笔：主任亲自交代的VIP患者 → 本章末尾兑现为鹤遂；与裴巷同房的要求 → 治疗关联或另有安排；《昼春》20亿票房 → 他的近况与她的症状触发源；微信置顶人与上万条未回消息 → 她的四年；霍闯与厌厌（四岁）→ 第55章托付的回收；徐散蹭牙膏 → 病友关系的温度；"他也许有难言之隐"的坚持 → 与第59章真相构成张力
- **时间线**：本章为2017年12月末的夜晚至次日清晨

# 第97章 病症 摘要

**概要**：周念在镇上医院的病房里醒来，距去肖护家录像已过去十个小时，莫奈守在床边哭得双眼通红，反复说是自己踩到易拉罐才害她被肖护的麻醉枪射中；周念迟疑着问起昏迷前看到的那个背影，莫奈点头确认是鹤遂，随即说出眼下最大的麻烦——肖护被打得住院、要做伤情鉴定告鹤遂故意伤害。莫奈回忆当晚：肖护的目标本就是出庭作证送他获刑四年零八个月的周念，千钧一发时一道黑影从五人合抱的老橡树后闪出挡在她身前，鹤遂握着枪口把那一针压进泥里、反手用枪柄怼碎肖护一颗门牙，又像当年扛铁锹那样把麻醉枪扛在肩上蹲到豁沟边，一句"改造四年还没改造明白"气得肖护翻身时忘了斜坡，滚进深林。周念拔了针就要去派出所，赶到时花楹镇已被几千名记者和粉丝挤得水泄不通；鹤遂戴着黑口罩墨镜出现在台阶上方，郁成陪在身侧，对"殴打生父""暴力倾向"等连珠炮式的追问始终沉默，只在人群里一眼看见她，脸始终朝着她的方向没有偏移。他钻进黑色埃尔法驶离后，周念接到一个归属地为京佛的陌生号码，等车彻底看不见时，听筒里传来一声低低的"念念"，他说去南水街、"你来我家见我"。周念重回那条小巷，粉蔷薇开得比13年更盛，木门上留着一层积灰和几个新鲜指印；可堂屋里走出来的男人眉眼冷沉、眼里透着厌恶，只一眼她就知道那不是鹤遂——沈拂南说以前不屑与她多说，现在改了主意，因为鹤遂先打了鹤广、又为她惹上官司，"我绝对不允许他毁了我的一切"，他要她听清楚鹤遂为她做过什么再决定要不要复合；周念退无可退地说"让鹤遂出来"，被他一把扣住手腕，失控低吼出那句："睡了四年的他突然就醒了，你能不能明白我的意思？他醒了！"

**关键事件**：1. 医院醒来与莫奈的内疚 2. 肖护要做伤情鉴定告鹤遂故意伤害 3. 老橡树后闪出的黑影 4. 握枪口、打偏的一针与磕掉的门牙 5. 滚下斜坡的惨叫 6. 派出所外几千人的围堵 7. 台阶上的沉默与始终朝向她的脸 8. 京佛来电与那声"念念" 9. 南水街的粉蔷薇与木门指印 10. 沈拂南"睡了四年的他突然就醒了"

**逐章写法公式**：

- **情绪流向**：起：惊（医院醒来与"要告他故意伤害"） → 承：爽（握枪口、门牙与滚下斜坡的转述） → 转：乱（派出所外几千人与记者的连珠炮） → 合：悚（南水街旧院里"他醒了"）
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：病房醒来（用十小时后的身体状态承接上一章的麻醉针） + 莫奈的内疚与"是鹤遂"（用一句确认接上昏迷前的背影） + 伤情鉴定（用一个法务动作把救人变成新危机） + 回忆里的一战（用转述补齐昨晚的打斗，把爽点放在中段） + 反派动机的对账（用四年零八个月与顶流的落差解释恨） + 拔针去派出所（用主角的行动把场景推到公共空间） + 几千人的围堵与沉默的台阶（用公共围观放大代价） + 京佛来电与"念念"（用一次错位通话完成私密连接） + "你来我家见我"（用一个地点把两人拉回原点） + 粉蔷薇、木门与杏树（用不变的景物计时） + 走出来的不是他（用一眼辨认同人格完成转场） + "我绝对不允许他毁了我的一切"（用另一人格的立场重述冲突） + "他醒了"（用一句重复的短句收章）
- **本章核心技巧**：整章用"转述+延迟"把最激烈的夜战挪到中段由他人口中补出，前半靠法务危机吊住、后半靠人格登场接棒——先让读者为救人的后果担心，再在同一章里把打人的爽感补发，最后用一句"他醒了"把全书最大设定推到台前
- **卡点与伏笔**：结尾卡点：沈拂南扣住她的手腕吼出"睡了四年的他突然就醒了"——鹤遂为何睡了四年、醒后要付出什么代价都不明朗；埋设/回收伏笔：肖护"要做伤情鉴定""告鹤遂故意伤害" → 与第96章麻醉针、踩扁的易拉罐直接接续，法务线由此开启；"他获刑四年零八个月"因周念出庭作证 → 回收花楹镇旧案，解释肖护只针对周念；"打了鹤广" → 与记者口中"前阵子被爆出殴打生父没有回应"互证；南水街的粉蔷薇"比13年那会儿有过之而无不及"与"他掐着她的下巴说她烦人，又因为她说了一句疼就立马松手" → 四年前后的同一地点对照；杏树"今年又结了新果"与"四年前吃下的那一颗酸杏" → 甜味与酸味对举；木门上"一层积灰，还有几个清晰的指印" → 鹤遂刚回来的物证；"睡了四年的他突然就醒了" → 与全书多重人格设定正面接榫，是全章最大的钩子
- **时间线**：本章为第96章当夜十点后的次日，早上九点周念醒来，至同日上午抵达南水街

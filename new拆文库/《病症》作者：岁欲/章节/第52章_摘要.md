# 第52章 病症 摘要

**概要**：河岸边上演着一场声势浩大的沉默，两个湿淋淋的人一个屈膝靠在柳树下坐着、一个侧身面朝南水河站着，彼此身下都是一大团水渍，谁都没有开口。周念看得出来他非常焦灼纠结，胸口起伏是乱的，有时会长长呼出一口气；他从裤兜里摸出一包烟，发现烟已被泡烂便不悦地皱眉，把烟带火机一并扔进不远处的垃圾桶，折回后抬眼看见柳树下那个瘦小苍白的人，锁骨凹得不成样、薄皮下是肉眼可见的青色血管，她的眼睛湿漉漉还很明亮，像一只受伤的小鹿。他抬脚走到她面前垂睫低眼，随后俯身弯腰问"你想怎么跟我走"，又温柔地低低问"背你走，还是抱你走"——她给了他两个选择，他也给了她两个回答。周念的眼底瞬间明亮，眼角那滴泪因喜悦落下，她冲他伸出双手哽咽说"你抱我"，被横搂着腰、穿过膝弯轻松抱起，像捞起一捧沙；她把脸贴在他怀里、蹭了蹭他的胸口提醒自己这不是梦，而他打横抱着她的第一句话是"周念，你瘦了很多"。她委屈地说"你不理我，我很难过，我吃下去的东西全部都会吐出来"，又说感觉好久好久没见过他、像过了一万年，他嫌她夸张却还是妥协；她失落地说他好像没有特别想她，他漫不经心答"哪有"，又在她追问"你很敷衍"时落下"周念，我从来不骗你"——她由此悟出他不是不想她，也不是情绪内敛，而是经常能见到她。她追问是不是有偷偷看她、一般几天来看一次，他抱着她走得很稳地答"每一天"：事实上他每天都在北清巷徘徊，在她家附近一根接一根地抽烟，好像有永远用不完的耐心只为看她一眼，一开始还能看见她每天出门，后来发现她出门的次数越来越少、好不容易见到一次却发现她肉眼可见地消瘦下去，他判断她的厌食症应该又复发了。她把脸重新靠在他胸口时碰到一个坚硬的小东西，才发现他脖颈上有一圈黑色细绳；她用小拇指勾出坠物，看到的是一颗被清洗干净、做过抛光的人类牙齿，周身被极细的银丝缠绕、根部固定在量身定做的银座里，做工无比精细。她认出那是自己那颗智齿——那天他陪她拔牙后向医生索要带走，说那会是他十八岁的生日礼物；她问他的生日，答案是十一月十三号，而她的生日也是那一天，他薄唇微扯露出浅笑说"那赶巧"，她还盘算着等生日时只买一个蛋糕很省钱，把他逗乐。她又发现项链没有活扣、反倒系了个死结，他答"不好解""不摘，它不怕水"；她把牙齿小心放回他锁骨中间，看了一眼那流畅的锁骨与银丝牙齿。走到他家门口时她疑惑房子不是被卖掉了，他说"最后没卖成"——后来周念才知道，当有人来看房准备签合同时，鹤遂提着把杀牛刀坐在门口抽烟，没看任何人也没说一句话，三根红塔山下肚后买房的人永远地离开了。他把她抱进卧室放到床上，从只有黑白灰三色的衣柜里挑了件黑t、又拿了条她之前用过的毛巾让她去洗澡；她问没有裤子吗，他说"我的裤子你穿不上，你穿着会踩脚""这很长，你可以当裙子穿"。洗手间里没有沐浴露，只有洗发水和一块白色舒肤佳香皂，她用他的香皂洗了澡，属于那栋房子的豆蔻香被一点一点洗去、被他身上的味道取而代之；衣服果然刚好遮住臀部，两条晃在外面的腿又长又白、就是过于瘦了。没有吹风机，她把头发擦到不再滴水才出门，看见他准备好酒精、纱布和棉签在等她处理脚下伤口；她套着他44码的拖鞋（她的脚只有36码）走得费劲，只能怯怯求助，他嫌她走得慢直接把人打横抱回床边，说"是你的脚太小"，又单膝蹲下把她的右脚放在自己膝盖上查看那道大口子。处理伤口时他问她今天怎么突然从家里跑出来，一提到家她就反常地沉默、想到冉银和那个家就觉得难以呼吸、心口紧得难受，连酒精抹上伤口的疼痛都没引起她的注意；他没有勉强，只说"你想说的时候再说"。她定定望着他笑了下说"我要是说出来，你可能不会信，会觉得我是个疯子"，他抿唇答"只要你说，我就信"，并在她确认"无论再荒唐的事情吗"时点头。周念以很轻的语气说出"还记得你给我讲的那个故事吗""里面的女主人公杀夫骗保……我妈妈也是"；他眸光明显凝住、缠绷带的动作一点一点慢下来，问她"你怎么知道的"，她说就在今天她妈说漏嘴亲口告诉了她，他深深吸一口气，开始无比后悔那天晚上答应了冉银的要求，冷静下来后问她有什么打算、是要报警还是别的方式。周念痛苦地捂着脸摇头哭说"我不知道，我真的不知道，警察也不会信的，我没有证据，只会把我当一个胡言乱语的疯子"，又说"我妈杀了我爸，我再亲手把我妈送去坐牢吗，这天底下哪有这样荒唐的事情"。他把她的手从脸上拉下来，凑上来一把抱住她，在她耳边低低说"念念，你还有我"；她憋了许久的情绪终于泄洪般爆发，呜咽着说"我讨厌这个小镇，讨厌这里的一切""你带我逃吧，好不好"，十七岁的少年无惧山海、心性似无转移的磐石，温柔无比地许下诺言"好""念念，我会带你逃出这座小镇""相信我"，而周念当然会相信他——他从来都不会骗她，也舍不得骗她。

**关键事件**：1. 河岸边的沉默与"背你走，还是抱你走" 2. "每一天"的偷偷探望与厌食复发的判断 3. 银丝牙齿项链与同一天生日的巧合、死结不摘 4. 杀牛刀守住房子的真相 5. 洗澡、处理脚伤与"只要你说，我就信" 6. 说出"我妈妈也是"与"念念，你还有我" 7. 逃出小镇的承诺

**逐章写法公式**：

- **情绪流向**：起：闷（声势浩大的沉默、泡烂的烟） → 承：暖（两个选择、抱起来、瘦了很多） → 转：甜（每一天、牙齿项链、同一天的生日、杀牛刀守房） → 合：痛与定（家里的伤口、坦白"我妈妈也是"、逃出小镇的诺言）
- **节奏配比**：慢铺垫 20% / 快冲突 10% / 爽点爆发 20% / 悬念留白 50%
- **本章结构公式**：河岸的沉默与扔掉的烟（把他的犹豫写进动作） + 两个回答与抱起（用对仗完成和解） + 体重与"每一天"（补齐他缺席期间的在） + 牙齿项链与同天生日（用信物把关系钉死） + 杀牛刀守房（交代他留下的原因） + 沐浴与气味替换（完成从家到他的空间转移） + 处理脚伤与"只要你说，我就信"（给出坦白的条件） + "我妈妈也是"（把真相交给信任对象） + 报警的犹疑与"你还有我"（写出无解处境） + 逃出小镇的承诺（定下下一步方向）
- **本章核心技巧**：全章把上一章的"以命相逼"消化成了日常的照护——洗澡、拖鞋、酒精、纱布、缠绷带，用一连串照顾动作化解生死威胁；最大的情绪转折不靠争吵而靠一条项链和一句"我从来不骗你"，信任被物化成一个戴在颈上的死结
- **卡点与伏笔**：结尾卡点："念念，我会带你逃出这座小镇""相信我"——逃跑计划尚未落地，母亲的一千六百万与命案悬在身后，下章期待为出逃的准备；埋设/回收伏笔：牙齿项链 → 第43章拔牙与"十八岁的生日礼物"，本章兑现并附带同一生日（十一月十三号）；白色舒肤佳（第51章的味道）→ 再次强化为男主标识；杀牛刀与红塔山 → 鹤遂被惹急时的行事方式；冉银的一千六百万赔偿金与命案 → 未解决的定时炸弹；"我们生日只买一个蛋糕"的玩笑 → 后续生日线的约定；他"无比后悔那天晚上答应了冉银" → 承诺的自我推翻；本章附于文末的作者留言（"还有一、两章就结束小镇了"）不在正文叙述内，不参与情节点

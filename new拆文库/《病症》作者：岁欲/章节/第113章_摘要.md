# 第113章 病症 摘要

**概要**：卢国强把两人带进一间宽敞明亮的询问室，黑色椭圆形长桌尽头摆着电脑，墙上挂着65寸电视，他让两人随便坐，又支段武去把东西拿过来；鹤遂牵着周念坐到离电视机最远的位置，卢国强本想去电脑前，看见他坐这么远又折回来坐在两人对面。段武回来时捎上卢国强的茶杯，手里还抱着一个刚好装得下十斤狗的纸箱，周念心里明白这将是场特别漫长的谈话——她转头看见鹤遂漆黑眸底化不开的恐惧。卢国强翻开的却不是什么恐怖玩意，只是一沓用橡胶绳紧束的厚照片，说"这些都是你留在善进的东西"；鹤遂像被人按了暂停键，呼吸微弱到让身边的周念快感受不到他的存在，她便主动开口要过照片，卢国强答"毕竟这些照片的一半主角可是你"。照片里是四年前鹤遂家院子的杏树下，他把她驮在肩上、大手握着她的两根小腿胫骨，她对着镜头露出小梨涡；第一张合照上他额头缠着纱布、衣服沾着血污，看向她的眼神却熠熠生辉。周念一张张翻过去，发现他拍照时从来不看镜头只看她——三百多张照片里找不出一张他看镜头的。她说"还以为再也都看不见这些照片了"，因为沈拂南在京佛时逼着她把手机里的合照全部删除；鹤遂低垂着眼说每拍一张就洗一张出来，害怕手机突然坏掉照片会不见，而每一张都被精心塑封，存放多年仍颜色新亮。段武关门坐下后，卢国强从纸箱里拿出三个红色小本，打趣"没想到你还挺有爱心"，推过来两本无偿献血证——按理说献血多少次都只发一个证，可这两本一本写着鹤遂、一本写着林强。周念想起林强是霍闯的表哥，鹤遂在厂里打工时借过他的身份证，问他当初借身份证是不是就为了献血，他整理着照片好半晌才低低地嗯一声。卢国强挑明2013年献血200ml补贴三百块，周念比对发证日期：2012年11月13日是鹤遂，2013年6月9日是林强；她理清头绪——血只能半年献一次，说明他借身份证时已经又用自己的身份证献过，冲着补贴去等于变相卖血，他那时正在筹钱。三双眼睛盯着他，他硬是一个字不说，场面僵住，卢国强便从纸箱里拿出一页纸展开："我好像知道他为什么要那样做了。"那是一整页标题写着"预计花销"的清单：个人租房（地下室）300/月、京佛美院学费10000/年、念念的住宿费1500/学期、念念生活费最低标准2000/月（画具开销除外）、个人生活费500/月、交通费200/月、日常生活消耗品300/月。周念的眼泪啪地落在少年清晰有力的字迹上——京佛最便宜的地下室床位也要300一个月，而她当初不管不顾地让他带她逃跑，把学费和生活花销全抛给了那时也才刚满十八的少年，他从不抱怨，闷头在厂里打工，凑不够就卖血也要凑。她说"你卖了多少次血"，他答"只有两次"，被她搬出"我们之间不能有谎言"后改口"四次"，并讲出详情：第一次是两人18岁生日那天，他抽了300ml拿450块补贴，比在厂里坐流水线赚得多；第二天又去血站，工作人员不肯抽，他赖着不走、骗对方说父亲得癌症急着用钱；硬等半年到六月，先用自己身份证抽，第二天又借林强的身份证抽，四次一共一千八，"就算让现在的我来看，我也不后悔"。周念想到同一天的生日自己收到他送的万年青、憧憬着未来，而他让针管扎进皮肤，哭到崩溃说"你没有必要为了我做到这种地步"，他把她抱进怀里说"别哭，我一点都不在意"，最后凑近她的眼睛认真笃定地答："有必要，你值得，为你做什么我都愿意。"

**关键事件**：1. 询问室与那个纸箱 2. 一沓照片与"你留在善进的东西" 3. 杏树下的驮肩合照 4. 三百多张从不看镜头的照片 5. 两本献血证与林强的身份证 6. 2012年11月13日与2013年6月9日 7. 一整页"预计花销"清单 8. 四次共一千八的卖血 9. "你值得，为你做什么我都愿意"

**逐章写法公式**：

- **情绪流向**：起：紧张（询问室、纸箱与他的恐惧） → 承：甜与温馨（三百多张只看着她的照片） → 转：压抑（两本献血证与一页花销清单） → 合：悲伤中带坚定（四次卖血的详情与"你值得"）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：公事场景（把最怕面对的东西端上桌） + 照片（先交付爱的证据） + 证件与清单（用物证逼出当年的筹钱） + 自白（让沉默者讲完四次抽血，用承诺收束）
- **本章核心技巧**：全章几乎不用回忆闪回，而是让派出所的"物归原主"把旧物一件件摆上桌——每一件旧物都自带一个未说出口的真相，靠在场的人互相辨认、互相追问把真相挤出来。
- **卡点与伏笔**：结尾卡点：清单与四次卖血已被摊开，纸箱里还剩第三个红色小本没被翻开，下章期待是那本是什么；埋设/回收伏笔：无偿献血证（两本不同名字）→ 导出卖血筹钱；"预计花销"清单 ↔ "念念，我会带你逃出小镇"的承诺（回收旧台词）；沈拂南逼删合照 ↔ 他每拍一张就洗一张（对照式回收）；林强=霍闯表哥（回收早年借身份证的旧线）；第三个红色小本与纸箱中剩余旧物 → 待下章揭开。

# 罗强

- **archetype**：supporting（同学 / 传声筒 / 理性反对者）
- **出现章节**：11/119（首第3章，末第51章）
- **首次出场**：第3章（用说书般的口吻给周念科普"疯狗"的来历）

## 档案

周念的同班同学，家住鹤遂家附近（"这么多年邻居"），是全书最重要的**信息中转站**：鹤遂的来路（四岁替父买毒被抓、全镇孤立）、他家门口被泼油漆的旧事、捅伤当夜的目击（他听见救护车声出来看热闹，看见地上那件全是血的米色外套），都由他转述给主角与读者。他胆小、爱凑热闹、有点贫嘴（用一份炒面就能被收买），却在第23章给出全书最准的一句预言——"周念，他会毁了你""他会拉你一起进地狱"，叙述随即点出"后来发生的事桩桩件件都在印证这句话"。他也曾当面质问鹤遂、被一句挑衅逼退，并在第51章劝周念回家。他对周念有好感（"你都不知道多少男生会羡慕我"），但从不越界。

## 关键情节（按时序）

1. 第3章：科普"疯狗"与杀猪刀旧事，把她吓得更好奇。
2. 第6章：讲出鹤遂四岁替父买毒的完整来路。
3. 第23章：揭破那晚救疯狗的人是她，并给出"他会毁了你"的警告。
4. 第35-36章：端着冰镇米酒汤圆请她吃，被鹤遂连碗端走并塞给他二十块。
5. 第51章：在她跌坐在鹤家门槛上时说"他不会再回来了"，并看见她血肉模糊的脚底。

## 成长弧线

无成长弧线。他的功能是三重：① 以胆小者的视角转述强者的传说（转述者的可靠性本身就是滤镜）；② 提供理性反对者的声音，让"她偏要靠近"成为主动选择而非无知；③ 用一句"他会毁了你"承担全书的预叙功能。

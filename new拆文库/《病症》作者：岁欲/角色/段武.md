# 段武

- **archetype**：minor（功能角色；卢国强的徒弟）
- **出现章节**：5/119（首第16章，末第114章）
- **首次出场**：第16章（随卢国强到病房做笔录）

## 档案

花楹镇派出所民警，卢国强的徒弟。第16章他随师父做捅伤案笔录；第53章参与"诱骗强奸"报案的破门带走；第112章随师父上门通知善进旧物归还，提醒"做笔录不允许陪同"被师父一句"又不是审犯人"打断放行；第113-114章在询问室里负责操作投屏播放善进的监控，并在画面推进到禁食与电击时看不下去，主动催周念"你赶紧抱抱他吧"。他是全书为数不多在长时间沉默后替读者说出那句话的人。

## 关键情节（按时序）

1. 第16章：捅伤案笔录。
2. 第53章：参与破门带走鹤遂。
3. 第112章：随师父上门，提醒笔录规则。
4. 第114章：操作投屏播放监控；催促周念去抱住男主。

## 一、故事核（Story Core）

**一句话核**：数学常年不及格、却稳居文科年级前三的「废柴学霸」白蓁蓁，因在天台假装跳楼被抓，被学校强行安排给常年霸榜的理科大神顾雁舟「补课」，两人从「放养式睡觉 vs 抄答案」的欢喜冤家，到因一只流浪猫、一场竞赛让贤、一本写满名字的字帖，逐渐确认彼此心意，最终在高考落幕时牵手 HE。

**故事核四要素**：
- **欲望（Want）**：白蓁蓁只是想不被数学拖垮、平安熬过高三；顾雁舟只想借「补课」名头在办公室睡觉。
- **阻碍（Obstacle）**：两人都把对方当麻烦——她嫌他字丑脾气臭，他嫌她笨得离谱；外部还有母亲缺位、情敌（沈念白）错位、自尊心拉扯。
- **转折（Turn）**：顾雁舟为沈念白让出竞赛名额后重新认真辅导、写下满本名字的字帖被撕掉又捡回，白蓁蓁从「习惯他」到「离不开他」。
- **结局（Payoff）**：高考后字帖真相揭晓，两人约定「考上 H 大就原谅你」，顾雁舟牵起她的手回家见猫——甜宠闭环。

**核心钩子**：「理科大神被迫给文科废柴补课」的身份落差 + 「假装跳楼」的社死开场，天然制造喜剧与甜感。

## 三、叙事时间线（Timeline）

- **顺序主线**：天台事件 → 补课日常 → 家长会 → 月考野猫 → 换师 → 练字道歉 → 见家长 → 竞赛让贤 → 沈念白回归拉扯 → 顾家约定 → 高考旗袍 → 成绩揭晓。
- **时间跨度**：高三一整年（从天台事件到高考放榜），以大事件节点推进，非严格线性日历。
- **倒叙/插叙**：无硬倒叙；第11节以秘书台词「许菁把工作提前做，挤时间陪我」软性补出母亲转变（信息释放点）。
- **悬念节奏**：「字帖写了什么」作为贯穿性麦高芬（节12首次出现被撕、节16揭晓），属于甜宠特有的「延迟揭晓型甜点」。

**曲线特征**（5 项）：
1. 整体呈「低开高走·螺旋上升」型，无虐点硬伤，落寞（节点5）被后续暖意持续回填。
2. 喜剧强度稳定托底（+2~+4），保证甜宠底色不被亲情缺口拉崩。
3. 心动节点（7/9/13/15/16）呈阶梯式加密，越近结尾甜度越高，符合甜文「收束即爆发」规律。
4. 唯一负向（节点5）为「母亲缺位」，但被节点12「许菁回归」与节点15「旗袍站台」闭环补偿，形成情绪回收。
5. 终点是全篇情感峰值（+9），由「麦高芬字帖揭晓」引爆，实现甜宠特有的「延迟糖点」释放。

### 5.2 爆点分析（Climax）

- **主爆点（节16/原文15）**：字帖真相。前文明暗铺设「撕掉的纸」「练字受刺激」「吴维说发神经练字」，此处一次性回收——写满白蓁蓁名字的字帖，是男主「不说出口的喜欢」的物质化证据。属「叠加型甜爆点」（信息回收 + 情感确认 + 动作收束「牵手回家」三重合一）。
- **次爆点（节13/原文12）**：顾雁舟吃醋后白蓁蓁主动回头 + 学习计划表，证明双向奔赴。
- **辅助甜点（节9/原文8）**：带猫回家见家长，秦媛「定情之猫」金句，提前锁定「一家人」喜剧框架。
- **爆点密度**：甜宠文爆点非冲突型，而是「糖点型」，全篇 4 处强糖（7/9/15/16）+ 若干微糖，节奏均匀不拥挤。

## 六、反差萌设计与写作手法（Stage 4）

> 甜宠向无反转，原「反转设计」维度替换为 **反差萌浓度**；「写作手法」≥ 5 维。

### 6.1 反差萌浓度（替代「反转设计」）

| 反差对 | 表现 | 浓度 |
|---|---|---|
| 外表冷淡 vs 内心在意 | 嘴上说「关我屁事」，转头狂练字、送药、让名额 | 高 |
| 理科大神 vs 字丑 | 常年第一却字丑如蟹爬，被嘲后发奋练字成艺术体 | 中高 |
| 毒舌 vs 老妈子 | 「命比什么都重要，不准去跳楼」「我怎么跟个老妈子一样」 | 高 |
| 傲娇 vs 直球 | 说「找我妈」实则是想见她；字帖写满名字却不承认 | 高 |
| 凶巴巴 vs 呆萌 | 趴睡红痕、被揭丑照「烦躁转身」 | 中 |

**反差萌浓度评分（1–5）= 5**：五组反差覆盖全篇主线，且每组都有具体情节落地，非标签堆砌。

### 6.2 写作手法（7 维度，≥ 5，达标）

1. **第一人称限知视角**：全程白蓁蓁「我」的内心声、误判（以为顾雁舟只是不想教）、事后悟（字帖真相），制造甜宠特有的「迟钝少女」滤镜。
2. **反差人设对位**：废柴学霸 × 傲娇大神，用「数学」这一共同战场承载情感推进。
3. **麦高芬悬念**：字帖作为贯穿物，前撕后揭，实现「延迟甜点」。
4. **群像喜剧配角**：肖勇（假发/严厉嘴软）、张校长（大葱/口气攻击）、吴维（八卦助攻）、秦媛（怪阿姨丈母娘），每人一句名场面托举主线。
5. **对话驱动**：大量「我：……」「顾雁舟：……」留白式对话，以沉默与省略号制造喜剧呼吸感。
6. **意象物件复用**：小白猫（从野猫→定情之猫→家庭一员）、假发/大葱（校长线笑点）、字帖（情感物证）。
7. **信息落差制造笑点**：白蓁蓁的误读（「他只是想借机睡觉」「他不开心」）与读者/顾雁舟真实意图之间的落差，是全文喜剧发动机。

| 秦媛 | 助攻家长 / 喜剧担当 | 恒定热情，推动两家结缘 | 「定情之猫」「开窍了」名场面 |

**人物原型数（character_archetypes）= 6**（废柴学霸 / 傲娇大神 / 热情家长 / 事业母亲 / 错位情敌 / 喜剧配角），满足 ≥ 2。

### 7.2 人物功能评价
- **白蓁蓁**：第一人称限知天然拉近距离，误判制造笑点，主动回头完成「女主能动性」，避免甜宠文常见的被动挂件。
- **顾雁舟**：反差浓度极高，所有「傲娇」动作都有暗线支撑（练字=在意、让贤=腾时间、撕字帖=害羞），人物行为逻辑自洽。
- **秦媛/许菁**：双母亲线是该篇差异化亮点——不止谈恋爱，还补出「原生家庭温情」，提升共鸣厚度。

### 7.3 开头与结尾

**开头（前 3 句引用）**：
> 「在天台抽烟被抓，和年级主任大眼瞪小眼。我灵光一闪，夹着烟故作深沉:『不想活了。』年级主任大惊失色。」

- 功能：一句话立住「社牛废柴」人设 + 抛出荒诞钩子（假装跳楼），零铺垫入戏，钩子强度高。

**结尾（引用）**：
> 「其实我早就知道了。因为那张丢进垃圾桶的字帖，满满当当写的都是我的名字呀……」

- 功能：以「麦高芬揭晓」收束，呼应节12撕字帖伏笔，用「名字」具象化暗恋，温柔闭环。留白式省略号收尾，余甜悠长。

| 人物立体度 | 4 | 主角反差饱满；沈念白/吴维稍工具化但符合功能 |
| **综合** | **4.8** | 优质甜宠校园短篇，结构与人设完成度高 |

### 8.2 高潮与主题
- **高潮**：字帖名字揭晓（节16），信息回收型甜爆点。
- **主题**：「被看见与被爱」——白蓁蓁在「所有人都以为我要跳楼」的荒诞里，反而收获了老师、同学、傲娇男主、两家母亲的多重在乎；副题「傲娇是喜欢的遮羞布」。

### 8.3 共鸣层次（≥ 3，实际 5 层）
1. **高三共鸣**：数学不及格、被老师「特殊关照」、课间操逃避，强学生时代代入。
2. **母爱缺口共鸣**：许菁式「给钱不给时间」的母亲，现实普遍存在。
3. **暗恋共鸣**：字帖写名字——谁没偷偷写过喜欢的人的名字。
4. **傲娇共鸣**：嘴硬心软的相处模式，甜宠受众核心爽点。
5. **代际温情共鸣**：秦媛式「怪阿姨丈母娘」与两家母亲结盟，补足家庭暖意。

### 8.4 可复用结构（≥ 3，实际 5）
1. **社死开场钩子**：用「假装跳楼」极端行为瞬间立人设+抛冲突，适合轻松向开篇。
2. **放养伪装结构**：「借名头睡觉/偷懒」制造喜剧，再以「突然认真」反差收甜。
3. **定情之猫**：用宠物作为关系绑定媒介，自然引入家长线。
4. **竞赛/名额让贤**：用「让机会」替代「争抢」，制造男主偏爱证据且不撕逼。
5. **麦高芬字帖揭晓**：贯穿物件延迟揭晓，作为结尾金句载体。

### 8.5 节奏报告
- 全文 16 节，单节聚焦一个喜剧/甜点事件，无注水；亲情缺口（节5）与暖意回收（节12/15）形成对称节奏。
- 对话占比高，阅读轻快，符合短篇甜宠「一口气读完」的节奏预期。
- 结尾麦高芬回收干净，无烂尾。

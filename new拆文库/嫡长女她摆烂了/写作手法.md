# 写作手法分析（嫡长女她摆烂了）

## POV 策略

| 维度 | 分析 |
|------|------|
| POV 类型 | 第一人称（刘雯玉「我」） |
| 选择效果 | 强代入与私密感，读者贴着女主冷嘲腔看家族闹剧；盐言第一人称刚需 |
| 信息操控 | 不可靠叙述者（表层）：女主自陈「病弱摆烂」，实则清醒布局，读者被「昏倒/呕血」表象误导至第14节才翻盘 |
| POV 切换 | 无（严格第一人称）；他人前史（肖成业缘起、宋如织仇）借女主转述承载 |
| POV 代价 | 丧失父亲/弟妹内心直写，反派动机靠行为外显（如父亲收礼走侧门），反而强化悬念 |

## 对话手法

| 指标 | 数值 | 评价 |
|------|------|------|
| 对话占比 | 约 42% | 第一人称吐槽+对白双轮驱动；丫鬟群像（莲蓉酥桂花糕驴肉火烧麻婆豆腐）用对话立喜剧节奏 |
| 潜台词率 | 中高（约 45%） | 女主对父「苏家四娶是否影响声誉」表面为府分忧实为反将；对刘婉晴「顶上去的是你」是威胁 |
| 对话模式 | 推拉+称谓降级 | 女主对父亲从「父亲」到「刘豚苏狗」暗讽；对刘婉晴从「妹妹」到直呼其名，称谓即定性 |

| 手法 | 位置 | 效果 |

| 倒叙 | 节8（青州童年）、节15（初遇肖成业） | 交代女主「懂事」根源与情起，避免开头信息倾倒 |
| 时间跳跃 | 节17→18「留待期满两年后」、节18末「又过两年/后五年」 | 快进收束各人命运，留白不拖沓 |
| 场景压缩 | 节18 丞相倒台段 | 把政治清算压缩成旁白，保留爽点省略过程 |

| 物件/意象 | 出现位置 | 每次承载的含义 | 演变轨迹 |

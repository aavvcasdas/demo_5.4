# 故事线

## 故事框架

| 项目 | 内容 |
|------|------|
| 框架类型 | 日常单元 / 多线交织（14 个独立「故事」共享母题的合集式长篇） |
| 核心驱动 | 母题「深情即伤害，掌权方可自保」——每个女主都在「被爱所伤 / 得不到爱」与「必须自己掌权才能活」之间做选择 |
| 主轴矛盾 | 个体真情 vs 权力牢笼；「被爱」往往异化为控制与伤害，安全只能来自自身权位 |
| 升级机制 | 非力量升级，而是「地位/认知/掌权力」的递进：从被摆布的棋子 → 识破棋局 → 自己执子（太后、女帝、皇太后、出宫者） |
| 叙事节奏模式 | 单元内 铺垫→冲突→爽点/反转→新悬念；单元间以「同一母题不同切面」循环，并以实体（秦不祥/夫诸）与引出关系（故事十一→十二→十三→十四）串成隐线 |

### 故事线一 · 今天我当上太后了吗（EM-01）
- 类型：权谋线
- 描述：无名女主（淑妃→贵妃→太后）借傅丞相畸恋为底牌，毒杀专权父亲、与儿子琮儿/琏儿夺嫡失败，临终揭穿「我是琏儿」，以太子妃之身借夫诸附身重生。核心冲突是父权与子权的零和博弈，她每一步「当太后」的算计都建立在「掌权才安全」上。
- 情绪引擎摘要：用「女性借身体/子嗣博弈皇权」的缺口，延迟满足于临终掉马，释放于附身重生。详见 `情绪模块.md` EM-01。
- 套路运行方式：退婚打脸/迟来追悔的权谋变体——「我养的面首反成我的劫」。
- 主题：权力、亲情、复仇
- 包含剧情：故事一
- 模块引用：EM-01

## 故事线关系

- 实体呼应（交织）：故事一 ↔ 故事九（秦不祥 / 夫诸鹿旨酒，同一灵魂跨卷）。
- 时间线引出（依赖）：故事十一（上官婉儿垂帘）→ 故事十二（闻衡有棠，史笔补完引出太子）→ 故事十三（宁折枝，小公主宁安引出）→ 故事十四（汉成帝后宫，尾声历史镜像）。
- 其余故事（二~八、十）为并行独立单元，仅共享母题，人物设定互不重叠。

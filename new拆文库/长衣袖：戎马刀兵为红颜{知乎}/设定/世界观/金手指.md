## 一、故事一 · 今天我当上太后了吗（第 1-6 章）

| 字段 | 内容 |
|---|---|
| 类型 | other（制度知识 + 人情底牌） |
| 名称 | 无（原文未命名） |
| 描述 | 主角没有超自然能力，其「金手指」是**对制度规则的精确掌握**与**一张人情底牌**。制度知识包括：公主封号八字上限、皇后十字、和亲须正经公主、双胞胎无继承皇位资格、遗诏须独占临终时刻才有效、侧妃须待正室生子方可迎娶；人情底牌是当朝傅丞相对她长达十余年的畸恋——他被她「利用到了极致」，成为她在朝堂唯一的支点，入宫后源源送来金银财宝供她收买人心，死后更把朋党与死士两份名单和符印一并留给她。二者叠加构成她全部行动力的来源。另有一次超自然助力：神兽夫诸鹿旨酒在她死后将其附身于一名阳寿已尽的太子妃身上，这是**一次性、非成长型**的救命机制 |
| 核心机制 | 规则认知 → 找到制度缝隙 → 用人情底牌执行 |
| 当前能力 | 全书终局：制度知识全部掌握，傅丞相势力（名单 + 符印）到手但「之前假装乖巧，我一直都按兵不动，没有与傅丞相留给我的势力联络」，因此在秦桀阳新朝初立的机会面前「空有造反的心，没有造反的资本」 |

## 二、故事二 · 浣纱溪旁见卿卿（第 7-24 章）

| 字段 | 内容 |
|---|---|
| 类型 | transmigration（穿书） |
| 名称 | 无（原文未命名） |
| 描述 | 主角是现代人穿进书中世界，成为太子妃（女二），并**记得部分原书剧情**：女主急火攻心、郁郁寡欢已有咳血迹象；太子求皇上准许娶她为侧妃；宰辅纵觉丢人也恳求皇上、甚至愿告老还乡。但预知是**残缺的**——她自陈「很多故事情节我却都模糊了记不真切，而且也不知道我的行为如果跟原书不符合会造成什么改动」。因此她的策略不是靠预知取胜，而是靠「守则 + 行动」：立下不给男女主添乱、守身如玉、求休妻费脱身的三条守则，并逐条执行 |
| 核心机制 | 预知（残缺）→ 转化为可执行守则 → 用行动而非信息取胜 |
| 当前能力 | 预知在感情变量面前部分失效（太子对她的态度、清秋的坚持均不在原书脚本内）；实际起作用的是她的人脉网（小夏的信息渠道、宋清秋的退路凭据） |

# 藏娇阁

> **依据范围**：100%（207/207 章全量重跑，本势力覆盖：故事十一·妃常了得（第 135-159 章），前史涉及杭州倚红楼）。

| 项目 | 内容 |
|------|------|
| 名称 | 藏娇阁（位于苏州；其对应机构「倚红楼」在杭州） |
| 类型 | 组织（清绾型青楼 / 庇护所） |
| 核心人物 | 阁主（**身份成谜，从无人见过，由墨晴代理一切**）、墨晴（代理阁主、调教者）、木槿（看护者）、紫竹（琴师，留下琴谱）、上官婉儿（五岁被卖入阁的罪臣之女，由墨晴亲自调教） |
| 立场倾向 | 庇护型。阁内「几乎都是清绾——其中舞妓和歌妓居多，再少数的就是抚琴、吹箫、吟诗作画的清绾」；客人须能对上墨晴的对联或即兴赋诗（诗的立意由墨晴指定）方可入内，因此消遣者多为文人墨客与达官贵人。**所有姑娘都是自愿留下、可自主选择去留**，且「都是有过惨痛经历的苦命人，而且都是被墨晴姑娘救回来的」，墨晴根据其特点教授才艺，使每人有一技之长；离开者随时可回，阁内无争宠倾轧 |
| 与其他势力关系 | ① **对官方的隐形势力**：藏娇阁「从未有过任何麻烦」，说明其背后有未被写明的保护力量（原文未明确）；② **与皇权**：本卷开篇的冤案（邓将军被诬谋反、礼部尚书上官洪求情被斩、家产充公、女子卖身为娼）即是阁中成员的来源渠道；③ **与外部**：苏州藏娇阁为上官婉儿的落点，杭州倚红楼为其母的落点，母女「从此便再也没有见过面」 |
| 关键事件 | 上官洪求情被斩、婉儿被卖入藏娇阁；墨晴亲自调教失语的婉儿，告诉她「只要婉儿乖，娘亲就会回来见婉儿」「如果婉儿把姐姐们的才艺都学会了，娘亲就永远不和婉儿分开」，并留下全卷的行动纲领：「只有你变得强大了，才能保护你爱的人」；婉儿在别院学艺、谱曲，两年后在庭中跳舞被一名十八九岁的少年看见，少年称「在她的舞蹈中感受到了生命」 |

## 机制说明

- **才艺比拼与许愿规则**：阁内每月月底举行为期三天的才艺大比拼，每位清绾都可准备才艺且「不能与上月相同」；比拼前每位清绾可许一个愿望，「最后会评出当晚的花魁，而且她的愿望肯定会实现」。可弃权。这是本势力唯一的资源兑换机制。
- **未明确事项**：阁主身份（原文明确写「阁主身份是个谜团」）、藏娇阁为何从未遇到麻烦的保护来源。

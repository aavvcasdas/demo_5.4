# 宁家与将军府

> **依据范围**：100%（207/207 章全量重跑，本势力覆盖：故事四·临云鹤（第 42-65 章））。

| 项目 | 内容 |
|------|------|
| 名称 | 宁家（将军府）——故事四所在势力 |
| 类型 | 家族 / 军事门第 |
| 核心人物 | 宁思远（将军，凯旋归来的男主）、宁老妇人（宁思远之母，坐于高堂，掌家法）、云鹤（女主，宁思远的未婚妻，母亲是「一个籍籍无名、完全不受正视的公主」）、西域女子（宁思远带回的怀孕女子） |
| 立场倾向 | 以军功立足、以「家门体面」为先。宁老妇人在儿子携怀孕女子归来时当众命嬷嬷掌掴儿子，并称「思远这事儿干的不地道，我定然不会让你受委屈」；但她的处置是「当众打儿子」，而非解除婚约 |
| 与其他势力关系 | ① **与皇权**：这桩姻缘是**宁家求皇上亲自赐下**的，宁思远以此为由拒绝云鹤「退回聘礼、一别两宽」的提议（「你若走了，我们两家都不好交代」），说明赐婚制度把双方都锁死；② **与云鹤母族**：云鹤之母是不受正视的公主，家族政治分量不对等；③ **与西域**：宁思远出征西域方向并带回西域女子，暗示边功与外部势力接触 |
| 关键事件 | 将军凯旋并带回怀孕女子；宁老妇人当众掌掴宁思远；宁思远声言「她已经有我宁家的骨肉了——我的骨肉」，并提出要「求皇上让她当我平妻」；云鹤只说一个「好哇」，在女子惨叫、宁思远闷哼与棍棒声中走出将军府 |

## 叙事功能

- 本书「**体面退场式打脸**」（EM-012）的核心场景：主角的胜利不来自争赢，而来自「同意」——她把对方最想要的体面与婚约一并留下，自己抽身，使宁家同时背负「家法已动」与「平妻之议」的两难。
- 也是对「深情即伤害」母题的一次制度性演示：多年征战前「此生唯你一人」的承诺、凯旋时带回的外室、以及以赐婚为名的封锁，三层叠加构成同一命题。

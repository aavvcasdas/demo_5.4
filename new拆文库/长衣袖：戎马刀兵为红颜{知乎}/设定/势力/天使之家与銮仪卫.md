# 天使之家与銮仪卫

> **依据范围**：100%（207/207 章全量重跑，本势力覆盖：创设于故事一（第 1-6 章），机构影响延续至故事九（第 96-133 章）、故事十一（第 135-159 章））。

| 项目 | 内容 |
|------|------|
| 名称 | 天使之家（前身为慈济院分出的部司）；其后衍生机构为**銮仪卫** |
| 类型 | 组织（慈善收养机构 → 官员与武将的培养来源） |
| 核心人物 | 创立者：**百里牧云**（盛虞澜之女，盛兰之外孙女，后为中宫皇后、太后，谥号仁圣德皇太后）；使用者：**秦桀阳**（百里牧云被害后借其死肃清朝野并开创治世的新帝） |
| 立场倾向 | 直接向皇帝负责。銮仪卫「办差极是雷厉风行，直接向皇帝负责」 |
| 与其他势力关系 | ① **与皇权**：銮仪卫是皇帝的直属工具，其官员全部出自天使之家；② **与武将体系**：多年后「人才辈出的武将统领，有一半也是自小在那里长大」；③ **与宗室**：大皇子（秦桀阳）幼时被养在百里牧云的宫里，是天使之家理念的实际受益者 |
| 关键事件 | 百里牧云在还是皇后时，从慈济院分割出一个部司叫「天使之家」，专门收容那些「不言不语不理人但又不哑巴」的弃童；她说过「每一个自闭症儿童，都是被上帝咬过一口的苹果」。她死后，这批孩子成长为銮仪卫与半数武将统领，成为秦桀阳治世「政通人和、国库充盈、边境安稳」的支柱之一 |

## 叙事功能

- 这是全书**唯一一个「善意长成制度」的组织**：主角的路线是「以恶制恶、以掌控求安全」，而百里牧云的路线是「以慈善与制度沉淀力量」。两者构成同一部作品内的价值对照（对应 `剧情/情绪模块.md` A4 对位与 `故事线.md` 的母题线阶段②③）。
- 也承担了「百里牧云死后其意志仍在」的追认功能——她的死不是白死，而是把一批孤儿变成国家的骨干。

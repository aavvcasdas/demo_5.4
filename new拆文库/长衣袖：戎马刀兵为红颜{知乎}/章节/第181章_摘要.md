## 第181章 微君

**概要**：本章写雯楚对毓娈的心结、卫南风的旧伤，与陈怀之逼雯楚选妃的决裂。自毓娈搬入府一夏，雯楚早看出她心事。陈怀之带毓娈初回长安时雯楚失眠几夜怕他变心，多年青梅竹马默许的婚事因毓娈出现头回让她慌，相处后才承认只是把毓娈当"假想敌"。她调皮问毓娈"真喜欢我大哥"，毓娈红脸扑打；雯楚换神情讲南风无疾而终的初恋曼离——东边姜姓孤女，与南风冬日听雪夏里划船，姜老爷被暗杀后曼离孤僻归乡，去年已与普通人成亲生子。毓娈深陷想象那白衫恬淡女子，暗叹"南风啊南风，如何打动你"，梦甜只幻影。初秋下弦月，陈怀之来，说婚事耽搁不得、太子选妃提前至年初，希望她去。雯楚心如刀刺，陈怀之说会打点掖庭、不成也封良媛良娣，坦言"我爱着你、需要你帮我建功"，要她最后一次帮。她依偎他泪浸发丝，明白"该结束了"。

**关键事件**：
1. 雯楚坦言曾把毓娈当"假想敌"，毓娈红脸否认恋南风；雯楚讲曼离故事——南风无疾而终的初恋。
2. 毓娈想象白衫曼离，暗叹"南风如何打动你"，梦甜只幻影。
3. 陈怀之来，下弦月下说婚事耽搁不得，太子选妃提前；希望雯楚去选妃。
4. 陈怀之说"我爱着你、需要你帮我建功"，雯楚泪奔涌，依偎他明白"该结束了"。

**逐章写法公式**：

- **情绪流向**：起：假想敌坦白的趣（趣） → 承：曼离旧伤的怅（怅） → 转：选妃逼婚的痛（痛） → 合：该结束的悲（悲）
- **节奏配比**：双女心事 30% / 曼离前史 25% / 选妃逼婚 30% / 清醒收束 15%
- **本章结构公式**：一认假想敌（写醋） + 一讲曼离（写旧伤） + 一叹打动（写动心） + 一逼选妃（写决裂） + 一明结束（写放手）
- **本章核心技巧**：把"男二旧伤""女二被弃""女主暗恋"三线拧在一章——读者每怜一人，便疼三人
- **卡点与伏笔**：卡点：陈怀之"需要你帮我建功"动机不纯，埋下雯楚入宫后的怨；埋设/回收：曼离 → 接182章南风雪中忆曼离；太子选妃提前 → 接184章验容验德；下弦月 → 接182章《诗经》"见晛曰消"

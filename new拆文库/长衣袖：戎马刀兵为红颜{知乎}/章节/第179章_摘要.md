## 第179章 淇奥

**概要**：本章写毓娈搬入卫府、初遇卫南风。暮春毓娈搬入卫府，对外称亲戚家女孩、阖府喊"二小姐"，实则比雯楚还大三个月，飞澜榭临水竹幽她甚喜。初入府独自竹林散步至内湖，少见地雀跃折芦苇抛湖哼家乡民谣，忽见礁石上有人！惊退绊倒，那陌生男子含笑扶起，声音黏软如桂花糕。她慌拍尘泪，自报"我是毓娈"走入竹林，那人拾得她遗落耳环。午膳卫老爷送，雯楚笑盈盈来照料，给落霞侍奉；雯楚发现她左耳垂空了——耳环掉了。家宴上陈怀之闲聊，通报"大少爷到了"，毓娈抬头震惊：湖边那人正是大少爷卫南风！卫南风笑打招呼，目光落她身上，雯楚介绍"怀之从南方带的姑娘毓娈，这是我大哥卫南风"。卫南风瞧她换了耳环微微笑，席间毓娈偷看他被他若无其事冲她笑，任她再清高也跟着笑了。

**关键事件**：
1. 暮春毓娈搬入卫府称二小姐，飞澜榭临水；独游竹林内湖折芦苇哼歌，惊见礁石上有人绊倒。
2. 陌生男子扶起声音黏软，毓娈慌称"毓娈"逃走，遗落耳环被他拾得。
3. 雯楚来照料她，发现掉耳环；午膳家宴陈怀之在，通报大少爷到。
4. 毓娈惊觉湖边男子即大少爷卫南风，卫南风瞧她换耳环微微笑，二人初识暗生波澜。

**逐章写法公式**：

- **情绪流向**：起：临水雀跃的轻（轻） → 承：湖畔惊撞的悸（悸） → 转：遗环拾得的甜（甜） → 合：家宴识破的波（喜）
- **节奏配比**：入府铺陈 25% / 湖畔初遇 30% / 耳环暗线 20% / 家宴识破 25%
- **本章结构公式**：一入飞澜榭（安居） + 一折芦苇（遇人） + 一遗耳环（牵线） + 一报大少爷（揭面） + 一回眸笑（生波）
- **本章核心技巧**：把"男主"拆成两个——陈怀之是恩人、卫南风是命定，女主先撞见南风再在家宴认人，读者比她先知的悬念拉满
- **卡点与伏笔**：卡点：卫南风"换耳环微微笑"已记住她，暗恋线就此起；埋设/回收：耳环 → 后续南风认出她耳垂伏笔；飞澜榭临水 → 接180章内湖相会；二小姐身份 → 接182章选秀身份掩护

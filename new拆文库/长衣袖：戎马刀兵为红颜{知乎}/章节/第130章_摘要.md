## 第130章 归真

**概要**：秦不祥再度醒来已是清晨，只见一个峻拔如松的身影侧坐在床边低头看书，日光在他身上镀了层暖金光圈，清风徐来乌发微扬，鼻尖拂过淡淡鹅梨香。他察觉她的目光后偏头粲然而笑问「你醒了」，一双勾魂夺魄的狐狸眼眼尾微扬、染着几分绯红，被她看得不自在地摸了摸面颊。她以为他是兄长请来治病的大夫，随口一问「可是兄长请先生来为我治病」，他却露出既迷惑又惊诧的神色，艰难地问她刚刚叫自己什么；她请教学名，他忧虑地蹙眉半晌才迟疑唤她「姐姐，你不要吓我」，她乐道自己才七岁担不起这声姐姐。他小心问她可还记得自己是谁，她朗声答「我是秦不祥，摄政上王爷之女，明慧郡主」，他强自镇定地报出名讳——傅寒池，她便顺口叫他傅哥哥，并宽慰他这病是娘胎里带出来的、治不好也没人怪罪，却让他眉头蹙得更紧。她肚子叫了，他去备了八宝粥，见她头晕无力便扶她靠坐、每勺都吹过才喂，她实在太饿抢过碗三两下吞下，又羞涩地递回空碗说还要。他再出门时她昏沉睡去，恍惚中听见管家问「少主如何了」，傅寒池叹说她并无外伤、脉搏也无异常，却什么都不记得、只以为自己是个七岁的孩子，担心是失魂症——毕竟他去救她时打断了国师的做法；他决定再去经阁查医书，实在不行便去寥望天一趟。近黄昏她醒来出门，凭直觉要去城外等兄长，被一条河拦住后跳上泊在岸边的小舟，行至河中才发现船是漏的，裙摆堵不住处处窟窿，船沉了一半、四周旷林阔野空无一人。危急时一阵破空之声压过水声，鹅梨轻风拂过耳畔，她被人一把提起揽进怀中，足尖在沉船边角一点凌空一旋便到了对岸。落地后傅寒池急问可有受伤，她想起自己是出城等兄长的；她问他不骂我吗，他却说在不熟悉的地方也会好奇、遇到同样的情况可能还没她冷静，这话让她心头如榛果裂开细缝、有暖意流淌。她央他带自己去找兄长逛花灯会，他迟疑后柔声应好，又温然说别担心、我带你飞过去，并解释这里是迷林、有毒瘴和绞藤，那漏船也是故意凿洞停在岸边防外人闯入的，随即揽住她的肩膀纵身跃上树梢。

**关键事件**：
1. 她醒来后失忆，只认自己是七岁的明慧郡主，把守在床边的傅寒池当成大夫。
2. 傅寒池察觉异常，确认她失去记忆，与管家商议失魂症并决定查医书、必要时去寥望天。
3. 她私自出门渡河遇沉船，被傅寒池凌空救起。
4. 他以温柔回应她的不安，答应带她去找兄长逛花灯会，并带她飞跃迷林。

**逐章写法公式**：

- **情绪流向**：起：晨光中初见的惊艳（温馨） → 承：失忆的错愕与诊断（紧张） → 转：沉船绝境与凌空相救（紧张） → 合：温柔安慰与飞跃迷林（温馨）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：晨光初见与身份错位（立局） + 失魂症诊断（加压） + 沉船与凌空救起（危机释放） + 温柔安慰与带她飞（情感升温）
- **本章核心技巧**：用「认错人」写失忆——她把守在床边的人当成兄长请来的大夫，一个误会同时交代了她的记忆断层与两人的关系错位
- **卡点与伏笔**：结尾卡点：他已带她跃上树梢飞向迷林之外，下章看二人同行；埋设/回收伏笔：失魂症 → 后文记忆是否恢复；寥望天 → 后续求医线；迷林与漏船 → 凌天盟据点机关；兄长八月十五归来 → 花灯会线

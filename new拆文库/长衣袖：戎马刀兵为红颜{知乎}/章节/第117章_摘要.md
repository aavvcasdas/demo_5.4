## 第117章 争吵

**概要**：秦琏喝了绿豆汤仍火气不消，直问她连夜送走解语花是不是为了防着自己，她答是怕他看见人生气、对伤不好，被他一语戳破「是怕我伤不好，还是怕我伤害他」。他咬牙讥讽她爱得深沉，抓到她走神后又怒称那日亲耳听见她说「要他活着娶你」，攥住她腕子不许她嫁；她挣开回呛「我爱嫁给谁就嫁给谁，你管不着」，并说自己如今身份清白与皇家无关。他一句「朕凭什么不能」说到一半骤然住口、表情僵滞，随后铁青着脸赶她出去，她偏不走，逼问「你为什么就见不得我好」。他说恨不得把心挖出来给她，她气极反笑回「挖出来给我建一座牢吗」，他两眼泛红反问自己的情意对她来说竟是牢笼，随即改口称说的是心意、是她听错，两人陷入尴尬沉默。他要批折子赶人，她怕他摔值钱玩意儿，想到漠北国主更新军备、在边界虎视眈眈而他又不敢声张伤情，决定自己点的火自己灭，开口求坦诚相待，却被他轻佻逼近反问「你想要哪种坦诚相待」，又遭一句「说了也是对牛弹琴」。她摸准他巴不得她留下的脾气，从案上抽了本《三十六计》坐到角落翻看，先翻到美人计斥为破书，再翻到苦肉计，盘算要苦中带酸、酸中透涩、涩里含甜才哄得住。他见她看书安逸心里不痛快，便要她念奏折，她以太后不得干政、秦桀阳清君细则严格推辞，他一句「你算哪门子后宫」点醒她已不是太后，她正好借机破冰，颠颠过去为他念奏折。

**关键事件**：
1. 秦琏质问送走解语花的用意，两人就「你护着他」与「我凭什么不能管」正面争吵。
2. 争吵中秦琏说出「恨不得把心挖出来给你」，被她回成「建一座牢」，随后把「情意」改口成「心意」。
3. 她求坦诚相遭拒后抽《三十六计》翻出美人计与苦肉计，盘算哄他。
4. 他命她念奏折，她以「你算哪门子后宫」被点醒已非太后，顺势借机破冰。

**逐章写法公式**：

- **情绪流向**：起：绿豆汤压不住的火气（紧张） → 承：护谁、嫁谁的正面争吵（压抑） → 转：「情意」说漏与改口的尴尬（紧张） → 合：翻书找计、被点醒身份的破冰（轻松）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：质问送人引爆争吵（对立升级） + 「情意」说漏又改口（情感暗线露头） + 翻《三十六计》找哄法（喜剧缓冲） + 念奏折点醒新身份（关系转圜）
- **本章核心技巧**：让最关键的情感词在吵架中说漏一次再被改口——「情意」被收回成「心意」，读者已经听见，角色却假装没发生，用一次口误承载全章的情感转向
- **卡点与伏笔**：结尾卡点：她已答应念奏折，两人进入近距离共处的破冰局面，下章看计策如何落地；埋设/回收伏笔：秦琏「朕凭什么不能」未说完 → 后续身份/关系揭底；苦肉计 → 下章哄人计划；漠北更新军备、边界虎视眈眈 → 后续边境战事线；秦桀阳清君细则 → 太后干政限制

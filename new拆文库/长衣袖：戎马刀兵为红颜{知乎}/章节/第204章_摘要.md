## 第204章 往愬

**概要**：御驾回銮，许娥主持晨会，魏昭仪嘲讽失宠的雯楚，许娥转而挑明毓娈乃四年前长沙王独女、刘骜是其杀父仇人、入宫目的须彻查，号召众妃阻止纳妃。朝会散去后，许娥向梦兰吐露当年派瑞香陷害雯楚、致班美人滑胎的真相，称纳刘毓娈入宫无法阻止，决意除掉雯楚、栽赃给刘毓娈。卫府内，毓娈脱罩衫时不慎摔碎母亲遗物羊脂玉镯，落霞收拾碎玉，毓娈捧碎玉沉思，午后入宫。卫南风收拾雯楚旧居浣雅轩藤萝花架，目送毓娈上轿。刘骜在上林苑观枫轩与毓娈对弈，忆长沙王当年拥立刘康、令他经历丧父丧母之痛，四十三手胜她。刘骜抓她手留她今夜留宫、说已收拾好合欢殿，毓娈沉默后应「好」，刘骜大喜。

**关键事件**：
1. 许娥晨会挑明毓娈长沙郡主身世、号召阻止纳妃，私下向梦兰吐露当年派瑞香陷害雯楚真相，决意栽赃除掉雯楚。
2. 毓娈摔碎母亲羊脂玉镯，决意入宫与刘骜说清楚。
3. 刘骜观枫轩与毓娈对弈，留她今夜留宫，毓娈应下。

- **情绪流向**：起：晨会针对的阴冷 → 承：阴谋吐露的压抑 → 转：玉镯碎与对弈的转折 → 合：应下留宫的决绝
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：晨会挑明身世（攻讦） + 吐露陷害真相（杀机） + 玉镯碎入宫（决心） + 观枫轩对弈（应诺）

- **卡点与伏笔**：结尾卡点：毓娈应下留宫合欢殿，纳妃已成定局；埋设/回收伏笔：许娥栽赃雯楚 → 后续下毒伏笔；瑞香陷害 → 许娥真凶回收；羊脂玉镯碎 → 毓娈命运转折伏笔

## 第107章 摊牌

**概要**：秦琏要她解释，秦不祥只好讲起"鬼故事"，小心翼翼问陛下有没有偶尔一晃神觉得她像先太后。他指节微顿、目色骤暗，一把甩开她的手冷冷说"没有"，任她追问三点也只答没有，最后低吼"朕说了没有就没有"，眼神像刀刮在她脸上。她识趣闭嘴，才明白这些牵涉鬼神的事最伤他奇怪的自尊。他搁笔起身，高大的影子像噬人的怪兽将她笼罩，一步步逼近问"你很想当太后"，她连说不想，他却目色轻佻说"也不是不行"，又把话题推到"按顺序，是不是该先当皇后，才是太后"。她心里为太子叫屈、担心动摇国本，转念想起自己已不是太后，可再不管眼看就要成皇后，这辈子要找如意郎可不是白眼狼，到嘴的拒绝却弱成了"不好吧"。他俯在她耳边说"朕倒觉得好得很"，握着她的后脖颈迫她对视，问她抖什么，她谎称发热想温暖他冰冷的心，被追问怎么温暖时，他倏地在她耳尖啄了一口。她慌极，猛然大叫一声"琏儿"，同时攀住他的脖颈把袖中簪抵向他喉间，准备要死一起死。他闻言一怔、戏谑全退，只说她在胡言乱语；她见他没立刻叫人便知信了几分，索性豁出去问他是不是对她没感觉、是不是不知道她是谁。他嗤笑着反问她想让他有什么感觉，她只得委婉提起"你是琏儿不是琮儿"与临终遗言两桩无人知晓的秘密，末了憋出一句"还挺有缘分的吗"。他却误会她是为了某人急着挑明身份，厉声追问"他哪一点好"，越说越气地数落她"左一朵解语花，右一个青梅竹马"。她这才反应过来他说的是傅长卿，正要理清思路，他已沉脸喝"出去"；她才走几步就被他一只杯子砸在脚下，骂"让你出去你就出去，你可真听话"，又扬扬下巴命令"哄朕"。她先是不肯，随即一个念头闪过——这小子难道是在吃醋。

**关键事件**：
1. 秦不祥以"像不像先太后"试探，被秦琏冷拒并低吼压下。
2. 秦琏以皇后之位相逼，耳尖一啄逼得她亮出簪子、喊出"琏儿"。
3. 她委婉亮出两桩秘密，被他误会成替傅长卿挑明身份。
4. 秦琏砸杯后又命她"哄朕"，她恍然他是在吃醋。

**逐章写法公式**：

- **情绪流向**：起：心虚（讲鬼故事被否） → 承：压迫（影子逼近、皇后之议） → 转：惊险（耳尖一啄、亮簪喊名） → 合：错频（他吃醋、命她哄朕）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：鬼故事被否（挫） + 皇后之议（逼） + 耳尖一啄与亮簪（险） + 暗语摊牌（转） + 砸杯与哄朕（钩）
- **本章核心技巧**：让"摊牌"全程只说半句——她三次开口都被打断或转向，真相始终悬在唇边，读者跟着一起憋。
- **卡点与伏笔**：结尾卡点：反转型——她悟出他在吃醋，读者等她如何用"哄"化解；埋设/回收伏笔：耳尖一啄 → 关系越界的明证；袖中簪 → 后文被他收走的伏笔；"左一朵解语花，右一个青梅竹马" → 他已知她与傅长卿接头。

## 第93章 坦诚相对

**概要**：次日天水楼月庚、江雪、月季三人到别庄见卞翡蝉。江雪假意关心卞私走遇黑衣人，卞冷刺其必知内情；月庚冷称卞擅自离楼与叛徒无异，亲认派过人"略微惩罚"。月庚单独携卞漫步，坦言一旦背叛便无退路，并说邵金花会告知母亲事但卞将背上沉重责任；更承认杀手是江雪主使、自己默许，"为你好才出此下策"。月季留纸条约尚微茶馆，揭江雪与穆芸嫣暗通款曲致卞被毒打，并述江雪悲苦身世与夺楼主之野心；月季自陈是月庚义姐、姓商，力主卞离开，言"芸嫣与你不可能共存"。卞终知江雪、月庚、邵金花皆历梁灭江夏之战，关系绝非表面。

**关键事件**：
1. 月庚当面认派杀手"略惩"卞，后单独承认江雪主使、自己默许。
2. 月季揭江雪与芸嫣勾结、江雪身世与夺位野心。
3. 月季点破卞与芸嫣不能共存，暗指三人皆历灭国之战。

**逐章写法公式**：

- **情绪流向**：起：对峙（楼主三人到） → 承：压迫（叛徒斥、认派杀） → 转：松动（月庚软话、月季泄密） → 合：清醒（知三人皆灭国遗民）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：月庚当众认派杀施压（立反派） + 单独软话揭默许江雪（反转） + 月季茶馆泄江芸勾结（解谜） + 灭国旧事收束（升格局）
- **本章核心技巧**：把"谁害我"的答案拆给两个信源——月庚亲口认（执行层）、月季补全江雪动机（幕后层），双保险立信。
- **卡点与伏笔**：结尾卡点：信息型——三女皆历灭国之战，读者疑母亲恭娘亦在其中；埋设/回收伏笔：江雪与芸嫣勾结 → 前章卞被毒打成因；月庚默许 → 与ch91宋指"楼主派杀"呼应；月季姓商义姐 → 后文持续助卞。

## 第28章 （4）

**概要**：爹扶摇直上，我过起官二代生涯，遇见各项平均分的老王——开国元勋之后、爷爷早死只留人脉（寿安长公主是姑姥姥、安王爷是亲舅舅、神勇少将军是兄弟），却被三方排挤。我逼老王撮合俏寡妇与憨将领，带他回家换衣时老王发现我女儿身，自此向权臣女婿拼搏；我上私塾他跟、我考科举他报、考场都没带笔墨。老王问我相信路不拾遗吗，我以赵大娘馅饼、李秀才死、大黄狗殁例举不信，他却信，白天招猫逗狗夜里用功，我偷偷送他燕窝。

**关键事件**：
1. 遇老王：身世与"平均分开国元勋之后"人设，三方排挤的背景。
2. 女儿身暴露：撮合俏寡妇弄脏衣、带回家换衣，老王识破女儿身，开启追妻线。
3. 兄弟心事：考场都没带笔墨、老王问世道、我举三例不信、他信且用功、我送燕窝。

**逐章写法公式**：

- **情绪流向**：起：爹扶摇、遇老王的轻松立人 → 承：撮合弄脏衣、女儿身暴露的紧张甜 → 转：跟屁虫日常与考场都没带笔墨的搞笑 → 合：世道之辩（我不信他信）、送燕窝的友情温馨
- **节奏配比**：慢铺垫 30% / 快冲突 5% / 爽点爆发 0% / 悬念留白 65%（以对话与白描推进）
- **本章结构公式**：遇老王（身世与排挤） + 女儿身暴露（撮合弄脏、带回家换衣、识破） + 跟屁虫日常（私塾科举皆跟、考场都没带笔墨） + 世道之辩（老王问、我举三例、他信用功、送燕窝）
- **本章核心技巧**：用"我不信/他信"的价值观对照写友情，把宏大世道之问拆成馅饼、李秀才、大黄狗三件小事
- **卡点与伏笔**：结尾卡点：温馨型——我送燕窝成全老王前程，读者知二人情谊已深、科考在即；埋设/回收伏笔：老王识破女儿身 → 后续自投黎相家求娶黎泗水；考场都没带笔墨 → 后文松香泪墨借老王高中；神勇少将军/寿安长公主/安王爷人脉 → 后文老王巡街古蚕缎、朝堂站位

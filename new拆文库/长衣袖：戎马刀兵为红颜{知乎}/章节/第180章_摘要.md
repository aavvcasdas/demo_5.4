## 第180章 昧旦

**概要**：本章写雯楚与毓娈的隐忧、毓娈与卫南风的暗生情愫。春逝夏至，雯楚望满架藤萝出神——她在等自己的未来，却遥遥无期。毓娈翩然来，问"为何同意我来卫府"，雯楚答"帮怀之一个忙，也更信冥冥缘分"。毓娈幽叹，忽问起太子妃薨、朝廷广选新太子妃，雯楚警觉"莫不是想去参选"，毓娈低头发《氓》琴曲不否认不承认。半年来毓娈总往内湖跑，躺石上哼家乡歌。卫南风坐石头另一端看风景，她坐起，他指荷花"开得多好"，她偷看他反被笑"我让你看花你一味看我"。他转话题问"来卫府两月适应么"，她称"您"被纠正叫"南风"或"大哥"，迟疑却坚决叫了。她脱口问"为何还没娶亲"，他自嘲"没合适姑娘"，背影落寞凄凉，她一眼望穿他心底悲怆——盛夏日光里她默默落了泪。

**关键事件**：
1. 夏至雯楚望藤萝，毓娈问"为何同意我来卫府"，雯楚答帮怀之忙、冥冥缘分。
2. 毓娈试探太子妃薨广选，雯楚疑她想去参选；毓娈不答只弹《氓》。
3. 毓娈内湖躺石哼歌，卫南风坐另一端；他指荷花她偷看他，被笑"看花一味看我"。
4. 毓娈脱口问"为何未娶亲"，卫南风自嘲没合适姑娘，背影落寞，她暗落泪。

**逐章写法公式**：

- **情绪流向**：起：藤萝待嫁的怅（怅） → 承：参选不答的悬（紧） → 转：湖畔看花的甜（甜） → 合：落寞落泪的揪（揪）
- **节奏配比**：双女心事 30% / 选妃伏笔 20% / 湖畔暗恋 30% / 落寞收束 20%
- **本章结构公式**：一望藤萝（写待嫁） + 一问参选（埋伏笔） + 一躺湖石（遇南风） + 一看花看人（生甜） + 一问未娶（落泪）
- **本章核心技巧**：把"女主暗恋"与"男主旧伤"放在同一湖石上——她偷看他被笑穿，他自嘲背影凄凉，读者同时心疼两人
- **卡点与伏笔**：卡点：毓娈"第三种选择"疑似参选太子妃，埋下与太子刘骜仇线；埋设/回收：卫南风"曼离"旧伤 → 接181章雯楚讲曼离故事；内湖 → 接179章飞澜榭临水；《氓》琴 → 接183章雯楚弹《氓》泣

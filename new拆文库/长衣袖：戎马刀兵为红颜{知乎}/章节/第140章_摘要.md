## 第140章 私人太医

**概要**：皇上换来的私人太医踏进卧室，婉儿掀开纱帐后才发现这位王太医竟是一年不见的墨晴姑姑。她先打发丫鬟去领炭火支开旁人，却在墨晴中规中矩的跪拜里只能以官腔相对。墨晴一把脉就点破药方与药渣都没问题、这病早该好了，随即猜出她是自己不愿好转；她夹在用生命发誓不背叛的王爷和一心要护住的婉儿之间，最终选择站在婉儿这边，改开温补方拖延。为了弄清一个女人怎么进得了太医院，婉儿追问来历，墨晴说是祖父王宇霆的孙女、应召入宫；而这身份是假的——她是江忍的孙女，十二年前祖父因冒死医治皇上被太后处死、满门抄斩，她因偷跑去市集躲过一劫，被永定王救下打理藏娇阁，也正因如此格外心疼婉儿。此后皇帝三日只来两次，听墨晴说需安心调养不得打扰便不再纠缠，眼神里带着心疼、不再每日醉酒、也不再传召任何嫔妃侍寝，墨晴由此担心婉儿被真情迷惑。某夜婉儿梦里摸着贤亲王的手喃喃说出心意，惊醒时人真的坐在床头、脸上有泪痕——他说这一趟没有白来，知道不是自己一个人的一厢情愿就够了；她一句别走换来他明晚再来的约定，宫人昏睡是迷香所致，她顺口用野猫遮掩。第二夜他迟迟不来让她哭到绝望，终于掀开被子躺进来道歉，两人相拥说开，他许下愿意等她自由。第三夜她主动说出我好想你、我是你的，二人情之所至，事后他承诺带她远走天涯，她却定下暂不再见面的约定以加快计划，并第一次唤他九郎。他为六皇兄求一条活路，说出郑家等开国功臣被灭门其实都是太后所为、皇兄不过是个傀儡；她说自己的第一个目标就是整垮太后，叹惜地问自己会不会到时不忍心，他答我的母后早在十二年前夺位时就死了。天明她珍重地藏起床单，换上一身从未有过的华服来遮掩昨夜。随即她直截了当地请墨晴去给太后治病，说不能医好难道就不能医差吗，并明言先除太后、再来除根；一行人进冷清的雍和宫，对着形如老妇、有气难言的太后针灸半日使其开口，却在太后问为什么对我这么好、你是不是不恨我时答：正因为恨才救你，要你亲眼看见你不想看见的一切再慢慢折磨死你。

**关键事件**：
1. 私人太医竟是墨晴姑姑，她选择站在婉儿一边替她拖延病情。
2. 墨晴的真实身世揭出十二年前江家满门抄斩的旧案。
3. 婉儿与贤亲王连番夜会彼此说开，定下暂不相见、早日了事的约定。
4. 婉儿请墨晴以太后患病为切口动手，当众在病榻前向太后摊牌。

**逐章写法公式**：

- **情绪流向**：起：重逢却要打官腔的别扭（压抑） → 承：夜会与相拥的心动（甜） → 转：坦白、许诺与暂别的决断（悲伤） → 合：向太后摊牌的反杀（爽）
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：故人以敌方身份归来（补身世） + 连番夜会把感情钉死（定关系） + 旧案与名单的交代（立目标） + 病榻前的一次公开反杀（开杀局）
- **本章核心技巧**：把旧人重逢安排在身份最尴尬的位置——她既是监视者又是守护者，重逢带来的不是温情而是需要重新试探的悬置，感情线由此多出一重张力
- **卡点与伏笔**：结尾卡点：太后宁死不要她医治，墨晴留在原地无从下手，下一步靠什么手段让太后就范要看回宫后的药方；埋设/回收伏笔：江忍满门抄斩 → 墨晴与太后不共戴天；郑家灭门旧案 → 六皇兄只是傀儡；藏起的床单 → 二人私情的物证；六郎留性命的请求 → 夺位后的处置

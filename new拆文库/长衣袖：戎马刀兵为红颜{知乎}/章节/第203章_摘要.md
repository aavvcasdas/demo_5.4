## 第203章 江汜

**概要**：雯楚在刘兴处醒来，发觉自己未着寸缕，刘兴半醒着拥她、让她今晚别回宫，雯楚叹这少年郎比自己还小一岁、不知能否担起责任，刘兴梦呓般说带她去中山国过神仙眷侣生活，雯楚泪水滑落、如重见春天。骊山行宫，毓娈被安排在皇帝临华殿后的快绿轩、比皇后月室殿还近，遭妃嫔议论狐媚。刘骜连赢四局后攥她手，说既有人说她不合礼法干脆将错就错、要封她为昭仪。毓娈自陈曾亲眼撞见殷其雷与婢女瑛兰在自己房中苟合、才搬回卫府，又说最怕的是嫁给义妹雯楚的丈夫。刘骜评雯楚是自顾自开谢的空谷幽兰、自己是好奇大过于喜欢，对毓娈却是知晓一切仍愿在一起、也许这便是爱。毓娈眼眶发热，惊觉离开黑暗梦魇已在不知不觉中完成，带她离开的正是眼前这个血海深仇之人。

**关键事件**：
1. 雯楚与刘兴相拥醒来，刘兴说带她去中山国，雯楚重见希望。
2. 毓娈在骊山被安排住快绿轩遭议论，刘骜提出封她为昭仪。
3. 毓娈自陈撞见殷其雷与瑛兰苟合搬回卫府，刘骜剖白对她是爱，毓娈心动。

**逐章写法公式**：

- **情绪流向**：起：晨起的缠绵 → 承：带她去中山的许诺 → 转：骊山受议与封妃的试探 → 合：血海深仇下心动
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：晨醒相拥（私情坐实） + 许诺中山（希望） + 快绿轩受议（封妃试探） + 剖白真心（心动）
- **本章核心技巧**：双线对称——雯楚与刘兴的私情、毓娈与刘骜的禁忌之爱，两条线都以「离开」收束，一明一暗推进
- **卡点与伏笔**：结尾卡点：毓娈惊觉带她离开黑暗的是血海深仇之人，禁忌之恋将明；埋设/回收伏笔：殷其雷与瑛兰苟合 → 毓娈离殷府前因；封昭仪 → 纳妃伏笔

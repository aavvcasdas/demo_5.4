## 第134章 反派大佬小甜甜

**概要**：身为系统的「我」因系统故障被困进自己亲手设计的世界，穿成了大反派沈净天的小情人，还把女主陈纤儿得罪到家破人亡——她假意接近偷出布防图，反派率军踏过三千禁军尸体入宫，女主爹娘兄长相继死于非命。沈净天凯旋后一把将她勾进怀里亲了一口说「成了」，此人弑父弑主、无恶不作，唯独长相冠绝当世，按设定最终会在与女主成婚当晚自杀、出家为僧。她为回家必须撮合二人，沈净天却因吃醋不许她见陈纤儿，被她一句「见到你天下第一高兴」哄得抱起她转圈。天牢中她以「你爹娘其实是你的杀父仇人」打消陈纤儿死志，又搬出造物主记忆科普其身世——她是别国公主，养父杀了亲父却将她纳入族谱；沈净天逼陈纤儿道歉未果，终因「我不杀女人」的人设收手。此后她安排酒局却被城外暴乱打断，自己与陈纤儿对饮大醉，被沈净天托住脑袋救下，回房后勾着他的脖子耳语「办事儿」，两人拉扯一番后她哭着说想回家。宿醉醒来才知他竟未趁人之危。她又买下自己放进世界的定情信物清光贵翠多宝灯笼步摇，被举着镜子的一军将士齐喊嫂子；血人龚举仁报出齐治桓之名，她与沈净天同时想到将军府。齐治桓为陈纤儿而来，沈净天却意外受伤，露出满身新旧伤疤，她第一次为纸片人流泪说「这些伤痕都是我给你的」。撮合屡屡失败后，她筹备烛光晚餐被陈纤儿识破，反被沈净天当作是为他准备，两人谈心时他忽然一吻说「亲到了」。她继而以自毁人设逼他厌恶自己，三次出手尽数落空，反被齐治桓掐脖几乎丧命，被沈净天掌风救下；两人比试时沈净天点到为止，陈纤儿遂随齐治桓离去，他把那句「不行！陈纤儿是你的」化解为「陈纤儿是她自己的，你才是我的」。陈纤儿临别将步摇戴回她发间道后会有期。最后青楼花魁柳未雨登门，沈净天握着母亲留下的双蝶玉坠说出已找到妹妹、养父母遗命将妹妹终生托付于他，她冰凉着手问他是否要遵从遗命娶她，他却说即便因不孝不义下地狱也只要你。

**关键事件**：
1. 她穿成反派情人并得罪女主，为回家必须撮合二人的困局确立。
2. 天牢中以杀父仇人的真相打消陈纤儿死志，并验证沈净天「不杀女人」的人设。
3. 酒局、步摇、齐治桓来袭三事串联，沈净天受伤露出满身旧疤，她第一次动情。
4. 撮合全线失败，陈纤儿随齐治桓离去，她被沈净天一句「你才是我的」留住，最终面对双蝶玉坠与妹妹的身世。

**逐章写法公式**：

- **情绪流向**：起：穿书困局的自嘲（轻松） → 承：撮合屡败与反派的偏爱（甜） → 转：受伤、旧疤与生死危机（压抑） → 合：放手成全与「我只要你」（甜）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：穿书困局与得罪女主（立目标） + 天牢劝生与不杀女人（人设验证） + 醉酒与步摇与受伤（情感推进） + 撮合全线失败与成全（转向自留）
- **本章核心技巧**：把「撮合别人」写成主角自己的动心过程——每一次撮合失败都把她往反派身边推近一步，任务与情感形成反向拉动
- **卡点与伏笔**：结尾卡点：双蝶玉坠牵出未死的妹妹与养父母遗命，下章须面对这一伦理难题；埋设/回收伏笔：清光贵翠多宝灯笼步摇 → 由男女主信物变为她的信物；齐治桓 → 陈纤儿的真正归宿；柳未雨 → 身世线；双蝶玉坠 → 妹妹线

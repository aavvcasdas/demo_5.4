## 第104章 修罗场

**概要**：承安传旨时秦不祥正要起身，解语花拉住她的衣角问"姐姐你走了还会回来吗"，眼圈红了小声哀求别丢下他。她想起他平日种种撒娇模样——拉着她的手覆在心口说姐姐召别人时这里疼、勾着她小指问以后只看他好不好、枕在她膝头求只喜欢他一个——心里怜意更甚，却也由此生出一条试探之计：照上辈子最后一月的样子，故意忽视秦琏、只顾解语花，若他真认出了自己便只会生气不会降罪。她于是对外说"我已经歇下了"，话音未落门就被踹开，秦琏阴沉着脸踏进来，而解语花竟撑着坐起、狐狸眼中盈满厉色与他对视，两人同时脱口"你认出她了"。秦琏质问他们在干什么，被解语花一句"与你无关"顶回，随即上前拽住他的衣领，解语花也攥住他的手腕僵峙不下。她拉架说他还受着伤，秦琏反问"他这伤可是为朕受的"，又说是他自找的、不介意让他更伤。解语花剧烈咳嗽起来，她过去拍背，反被他握住掌心说没事；秦琏见状一把抓住她另一只手，理直气壮地说"你既拉着他的手，就也得拉着我的，这才公平"，两人各攥一只互不相让。解语花欲说"他早已……"被秦琏厉声喝断"朕与阿祥说话，何时轮到你插嘴"。她断喝"够了"，把两人一个轰出去、一个按回床上睡觉。出院门后她解释二人并无其事，秦琏却揪住"你们睡一个屋子"反复追问，她正要摊牌，他忽然转了话题，说明日让她出宫、派追影跟着。她嫌追影嘴碎想换成逐月，又没反应过来"出宫去哪"的暗示，秦琏被她的迷茫气得恶声恶气丢下一句"爱去哪去哪"，狠狠剜她一眼后挥袖离去。

**关键事件**：
1. 秦不祥以"怠慢皇帝、只顾解语花"设试探局，反被秦琏踹门撞破。
2. 秦琏与解语花当面僵峙，两人同时问出"你认出她了"，暴露双方均已识破。
3. 二人各攥她一只手争"公平"，被她喝止后双双收声。
4. 秦琏暗示她明日出宫扫墓，她未领会，气得他拂袖而去。

**逐章写法公式**：

- **情绪流向**：起：柔软（解语花撒娇求留） → 承：爆笑转紧张（踹门、对峙、争手） → 转：松弛（喝止两人、出院解释） → 合：错频（暗示落空、拂袖而去）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：拉衣角撒娇（甜） + 设局说已歇下（计） + 踹门与双男对峙（爆） + 各攥一手争公平（闹） + 喝止与暗示落空（钩）
- **本章核心技巧**：把三角关系全部写成"手"的争夺——拉衣角、握掌心、攥手腕、扯来扯去，情感归属用肢体位置表达。
- **卡点与伏笔**：结尾卡点：悬念型——秦琏丢下"爱去哪去哪"离去，读者等她何时反应过来出宫之约；埋设/回收伏笔：解语花那句未说完的"他早已……" → 后文揭示秦琏早已知情；追影随行 → 出宫扫墓线的安排；秦琏叫她"阿祥" → 认亲证据再添一条。

## 第174章 "宁封番外"

**概要**：本番外以宁封视角回望与季桃枝的"先婚后爱"。他顺风顺水，遇温柔端淑的白知月，却因白太妃与母后争宠被阻；他跪寿康宫一日、母后绝食相对，贤王又求娶白知月，白知月不愿让宁若为难甘心放手，他看她拜堂。由母后安排娶了同样另有所爱的季桃枝，洞房夜烂醉，季桃枝丢下带血帕子说"欠我一个人情"。他几次听她梦话"湛行殊"，方知她心上人是前朝余孽；又发现她把二人情事写成《玉徽记》。母后下催情香，二人发生关系，太医报有孕他竟喜，劝她留子。白知月生产日他在贤王府外想通"放手才留得住回忆"；撞见湛行殊提醒反吓着她。他让季桃枝写完《玉徽记》其实是告诉她自己已放下。中秋他往水灯里写"阿桃忘了湛行殊"，又去冷宫见湛行殊，湛嘱"好好待她"。阿桃生女儿，他候到深夜；终夜吻她，她不抗拒。那夜她答"想同你好好过下去"，他才知自己倾心两次。

**关键事件**：
1. 宁封遇白知月却被母后阻婚，跪宫一日、母后绝食，白知月为不让他为难甘心嫁贤王，他看她拜堂。
2. 由母后安排娶季桃枝，洞房夜二人皆另有所爱；他从她梦话知心上人湛行殊，又发现她写《玉徽记》。
3. 母后下催情香二人圆房，太医报有孕他喜，劝留子；白知月生产日他想通放手。
4. 中秋水灯写"阿桃忘了湛行殊"，冷宫见湛行殊，湛嘱"好好待她"；他终对阿桃说谎。
5. 阿桃生女他候到深夜，夜吻她不抗拒；她答"想同你好好过下去"，他年少倾心两次。

**逐章写法公式**：

- **情绪流向**：起：白月光放手的憾（怅） → 承：合约婚姻的闹（趣） → 转：想通放下的释（暖） → 合：夜吻圆房的满（圆满）
- **节奏配比**：前情回忆 35% / 婚姻日常 35% / 心境转折 20% / 情定收束 10%
- **本章结构公式**：一跪绝食（失白月） + 一纸血帕（得阿桃） + 一本话本（知情敌） + 一盏水灯（祈忘情） + 一夜轻吻（定此生）
- **本章核心技巧**：番外把173章里"宁封的警告与拌嘴"全部翻成"怕失去她"——读者才懂男主每句狠话都是慌
- **卡点与伏笔**：卡点：他终对阿桃说谎（湛行殊劫持真相），埋下主线未解的刺；埋设/回收：冷宫见湛行殊 → 呼应173章劫持；水灯"阿桃忘了湛行殊" → 接176章宁安番外母后"舍不得"；小环 → 接173章生女

## 第176章 "宁安番外"

**概要**：本番外以小公主宁安（小环）视角看父母宁封与季桃枝的恩爱。宁安自出生便是人见人爱的小公主，闯祸有皇祖母挡、天塌有父皇扛。母后教她画画，她偏画好看的贤王世子，父皇总替她说话"小环画自己喜欢的人，随了你"，还偷偷炫耀母后最画他。她从母后库房翻出一幅红衣男子画像（像父皇），拿去问父皇，父皇高兴地找母后、把她晾在御书房——青绫说父皇在母后寝殿待了两三个时辰。上元节母后拉父皇猜灯谜，父皇全错母后全对还损他；宁安偷看百兽舞，遇一好看叔叔盯着她，叔叔蹲下说她像故人、问名字，她指母亲，父皇赶来抱起她，叔叔却不见了。父皇同母后说那人是湛行殊，母后淡淡"我早知道，你真当我蠢"，父皇问"你不怪我"，母后答"舍不得"——宁安见母后耳尖红了、父皇笑没了眼。她小小年纪生出愁：今晚父皇又要将她拎去偏殿、独占母后。文末引出故事十四汉成帝后宫之争。

**关键事件**：
1. 宁安自幼集万千宠爱，母后教画她偏画贤王世子，父皇替她说话并向她炫耀母后最画他。
2. 她翻出母后库房红衣男子画像（像父皇），父皇高兴找母后，把她晾御书房两三个时辰。
3. 上元节母后猜灯谜全对损父皇，宁安遇盯着她的好看叔叔，父皇抱起她时叔叔消失。
4. 父皇说叔叔是湛行殊，母后"我早知道"、答"舍不得"，宁安见父母打情骂俏。
5. 宁安愁父皇今夜又拎她去偏殿独占母后；文末引出故事十四汉成帝后宫之争。

**逐章写法公式**：

- **情绪流向**：起：集宠小公主的甜（甜） → 承：画像惹醋的趣（趣） → 转：灯谜遇叔的奇（怅） → 合：舍不得的暖（暖）
- **节奏配比**：童真日常 45% / 父母互动 35% / 伏笔引入 20%
- **本章结构公式**：一帧集宠（立人设） + 一幅画像（写醋意） + 一场灯谜（写亲密） + 一个叔叔（留前史） + 一句舍不得（收暖）
- **本章核心技巧**：番外用"女儿的眼睛"替读者确认——173/174章里吵吵闹闹的帝后，其实是全天下最甜的一对
- **卡点与伏笔**：卡点：母后"舍不得"暗示已原谅湛行殊劫持旧事，主线心结在此收；埋设/回收：红衣男子画像 → 呼应173章她画错把宁封袍画朱红；湛行殊看宁安 → 接175章"红桃已落"余韵；故事十四 → 接177章新单元

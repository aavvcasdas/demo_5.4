## 第131章 等待

**概要**：临近街市傅寒池才将她放下，她满眼敬仰地问「你是神仙吗」，他赧然说只是轻功还算不错。她追问缘由，他目色晦暗一瞬便掩饰过去，说小时候空有皮相又脑子不好，常被骗走卖掉，逃跑时总因跑得不够快被抓回去、免不了一顿毒打，后来有机会学武便最努力钻研轻功；她认真地说那不是脑子不好，是单纯，没有人生来就什么都懂得。他怔然一瞬，眸中有情绪流动又很快掩饰，这次的笑与以往不同，不是习惯性的温柔也不是故作轻松，而是一种释然。她说明明才认识不久却觉得他很熟悉、甚是安心，他说她很像自己的一个朋友，只是那位朋友现在病了、症状是他从未见过的；他说她尊重他、怜惜他、救过他的命，是世上对他最好也是唯一不会利用他的人。她安慰说那人定明白他的难处不会怨怼，他却眸中涌上痛色，哽咽说自己已经失去过她一次、后悔过一次；她握住他的掌心说世间之事岁岁无常、唯尽力而已，说罢自己也诧异竟会讲出这样老气横秋的话。她最终没等到兄长，他便提议陪她去逛花灯节，她问他会不会保护自己、即便有人追杀也决不丢下，她答追杀自己的是亲爹——他在母亲忌日发了疯，半夜举着刀闯进她的房间，奶娘拦住他让她逃去城外等兄长。她还说死了便可见到从未谋面的娘亲，他面色一慌，急急握住她的手说死很可怕、死了再也感受不到阳光、看不见在意的人，手都在颤抖；她忙说自己知道要好好活着，又提起传闻中的返魂树与返魂香，说兄长每次出征都会去寻。他静默半晌轻声道会有那么一天的，她便拉住他的手笑着说我相信你，他回握住她的手，突然一把将她搂进怀里越拥越紧，手轻抚她的头顶，哽咽着说「以前……你辛苦了，以后，再不会了」；她贴着他胸膛听见凌乱的心跳，却觉得无比安心。

**关键事件**：
1. 两人同行进城，他讲出自己苦练轻功的童年缘由，被她一句「是单纯」点破。
2. 他说她像自己病重的朋友，承认已失去过她一次，她以「唯尽力而已」宽慰。
3. 她没等到兄长，他提议陪她逛花灯节，她说出父亲要杀自己与想见娘亲的念头，被他郑重劝止。
4. 他承诺会有返魂的那一天，把她搂进怀里说以前你辛苦了、以后再不会了。

**逐章写法公式**：

- **情绪流向**：起：飞行后的敬仰与轻功往事（温馨） → 承：彼此倾诉与握掌宽慰（悲伤） → 转：父亲追杀与死亡念头的惊险（紧张） → 合：返魂之约与拥抱承诺（温馨）
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：飞行落地与轻功往事（补身世） + 「很像我的一个朋友」的错位倾诉（情感加深） + 父亲追杀与轻生念头的惊险（加压） + 返魂之约与拥抱（收束）
- **本章核心技巧**：让他对着失忆的她倾诉真心——借「我的一个朋友」把话说给本人听，读者知道真相而她不知道，同一句话产生两层重量
- **卡点与伏笔**：结尾卡点：两人已拉手同行去逛花灯节，下章进入灯会；埋设/回收伏笔：返魂树 → 兄长出征寻药的线索；父亲忌日持刀 → 她的童年创伤；唯一不会利用我的人 → 两人信任的基石；花灯节 → 下章主场

## 第143章 太后初醒

**概要**：皇上、婉儿、墨晴与一众太医在雍和宫守了整整一夜，太后始终昏迷不醒，天亮时人人眼里都布满血丝。皇上追问何时清醒，墨晴说太后今日一定会醒，却在半句上吞吞吐吐，被婉儿替她挡下皇上的怒意后才说出实情：太后很可能在疼痛中醒来。为了止痛，太医院道出那味能成瘾的罂粟粉，婉儿以做臣子的一番心意暗示用药，皇上下旨让太医斟酌剂量。天大亮后妃嫔们自发赶来，永定王与贤亲王踩着宫门刚开的时间进宫，皇上只以摇头作答。一阵咳嗽打破死寂，太后醒来，看见满屋子的人才意识到自己还活着；她见婉儿本要破口大骂，看见一旁的墨晴却硬生生忍住了——因为她记得克制脾气没准能多活些时日。皇上沉默地观察，看着她一双眼睛始终恶毒地盯着守了一天一夜的婉儿，积了十二年的怨终于压过了理智：他当着满屋子的人质问母后为何总把身边可心的人逼走，并说出自己早就知道并非太后亲生、当年是用庄平公主调的包。太后气得要打他耳光被拦住，他继续嘲讽说最后悔的是十二年前没能杀她给父皇陪葬，又当面宣布她活不过七天。太后一口气没上来晕死过去，皇上却命墨晴用针刺激死穴把她强行弄醒，一针下去她喷出黑血，毒气攻心之下三日之期都难保。皇上愤然离去，妃嫔一哄而散，殿里只剩太医、墨晴、婉儿、永定王与贤亲王。贤亲王追问身世，太后转头对着永定王说出他多年散布的谣言，又抖出一个更大的秘密——她是他们的生母，但他们的生父却不是先皇。当年先皇子嗣单薄请来一位大师，大师借疗养之名霸占皇后生下大皇子，又骚扰太后生下九皇子；梦嫔因为撞破而被下歹意害死。前一任皇后为护儿子冒死给皇上下毒，反被皇上在每日餐饮中慢性毒杀，圣旨确是先皇亲笔。墨晴忍不住追问江忍一家，太后却说自己从未杀过他，还说难怪你医术如此精湛——墨晴转头看向永定王，那个告诉她全家是太后所杀的人。太后随即盯着婉儿说像，实在是太像了，最后咬牙说出婉儿的母亲正是那位奸人的妹妹，所以她才想方设法要整死她。永定王被逼到怒吼着跑出雍和宫，墨晴也哭喊着跑了出去，婉儿则封住太医的口、把止痛药的决定权收归自己。太后在最后的对峙里说出庄平公主是被她亲手害死的，理由是那孩子越长越像自己；贤亲王终于忍无可忍，说我也是被你瞒了这么多年，拉着婉儿离开，留她一个人在雍和宫等死。

**关键事件**：
1. 太后醒来后皇上当众爆发，抖出自己并非太后亲生、当年被调包的事实。
2. 强行唤醒的太后毒气攻心，七日之期骤缩为三日。
3. 太后在病榻上否认知情江忍灭门，并说出两位皇子的生父另有其人。
4. 婉儿的身世被牵出——她的母亲是那位大师的妹妹，这正是太后要置她于死地的缘由。
5. 太后承认亲手害死亲生女儿庄平公主，被贤亲王彻底抛弃。

**逐章写法公式**：

- **情绪流向**：起：守夜待醒的煎熬（紧张） → 承：太后睁眼与皇上积怨爆发（爽） → 转：身世与旧案层层掀开（紧张） → 合：无人悔改的对峙与弃她而去（压抑）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 25% / 悬念留白 30%
- **本章结构公式**：醒来前的止痛布置（埋代价） + 醒来的第一次母子对撞（爆旧怨） + 病榻上的身世倒叙（掀旧案） + 无人认错的收场（断关系）
- **本章核心技巧**：把最大的秘密交给最不可信的那张嘴——所有真相都由临死的反派说出，可信度天然存疑，主角们因此只能靠自己去查，悬念由此自动延长
- **卡点与伏笔**：结尾卡点：太后被独自丢在雍和宫等死，而止痛药已归婉儿定夺，三日之期里她会先出手还是先查清身世；埋设/回收伏笔：大师 → 两位皇子的生父与婉儿母亲的兄长；庄平公主之死 → 太后的狠绝；江忍灭门的真凶 → 墨晴与永定王的信任崩塌；圣旨是先皇亲笔 → 夺位的正当性动摇

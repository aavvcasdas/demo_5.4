## 第141章 太后中计

**概要**：墨晴从雍和宫回禀，太后的病本来很快就能痊愈，可一旦吃了太医院的药再配合她的针灸就会完全相反；她断定自己留的那服药太后迟早会服用，只要服了，就算不再针灸也活不过一个月。婉儿把这件事全权交给姑姑，只求拿捏得当别牵连到她。数日后宫中传太后能下床走动，婉儿急问缘由，墨晴只说这才刚刚开始。次日太后亲自传召，见了墨晴如同见到救命稻草，自述浑身发沉；墨晴确认脉象已服了自己的药，便顺势建议改请经验更丰富的太医院太医，太后照办。避开耳目到傍晚密谈，墨晴说出太后已经中计——太医院会开出温补方，气血逆转之下不出半月就会神志不清而亡。此后消息传遍宫廷，赏罚随之下达，两个不离不弃的嬷嬷受了重赏，不少见无药可医就各奔其主的宫人则被处死。再过数日太后的神志已经开始恍惚，墨晴刻意请了一个时辰的脉，当着她的面查出药渣有问题、宣称无能为力；太后不信，换来诊治她的冯太医，在最后一段清醒里下令把冯太医当场乱棍打死。就在太后一病不起、皇上始终不曾露面之际，皇上却忽然来到玉宁宫强行要求侍寝，扯到她胸前吊坠时整个人停住，红着眼追问来历。婉儿想起蓝依师傅说这坠子兴许能救她一命，赌了一把说自己只知唤师傅为蓝依，皇上当场泪流满面，念着蓝儿既然还活着为何不肯回来见朕，隔日又来求她凭记忆画一幅蓝依的画像。画像捧走后婉儿再压不住疑问，借口身子不适派人把墨晴从雍和宫请回，当面对质追问到底瞒了多少。墨晴先是装糊涂，被逼到最后也被她的口无遮拦气出了真话，骂她不该辜负蓝依把父母唯一信物相赠的心意；婉儿认错道歉，墨晴终于把十二年前的旧事和盘托出：先皇病倒时懿妃寸步不离侍疾，老太医诊出中毒却获罪满门抄斩，先皇暴崩后新帝竟是六皇子，皇后气病而亡，太子班师回朝已是物是人非，打抱不平的郑大将军被安上谋反之名灭门——蓝依正是郑大将军的小女儿、六皇子的青梅竹马，太后还要派人追杀她，被蝶影师傅救下收为关门弟子。墨晴也承认自己就是那位老太医的孙女，并澄清王爷派她入宫是来协助而非监督。此后太后一日重似一日，墨晴却在病榻前劝她不如顺遂天意，心里的恨意已被这些日子磨淡，只想退出这场争斗去做回寻常人。回到厢房看见被布置成藏娇阁模样的房间，她落下泪来，向婉儿说出想去找十二年前未娶的曾家二公子试一试；婉儿没有拦她，反而表示会替她把一切安排妥当。

**关键事件**：
1. 墨晴以太后所服之药布下死局，太后自己选了服下去的那条路。
2. 冯太医在前来诊治的太后清醒时被下令乱棍打死。
3. 胸前的吊坠揭开皇上与蓝依师傅的旧情，婉儿凭此躲过侍寝。
4. 十二年前的先皇之死、郑家灭门与蓝依身世被和盘托出。
5. 墨晴放下仇恨与旧情，决定退出争斗去做寻常人。

**逐章写法公式**：

- **情绪流向**：起：布局落定与太后自投罗网的痛快（爽） → 承：皇上动粗与吊坠引发的旧情（压抑） → 转：质问姑姑换来十二年前的真相（紧张） → 合：杀局收尾与姑姑放下仇恨（温馨）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：药方死局收口（敌手自毁） + 一次临幸变故（扯出旧情） + 一场当面对峙（倒出旧案） + 一条退场选择（人物收线）
- **本章核心技巧**：把杀人和救人放在同一双手上——墨晴既能开慢性的方子也能开救命的方子，选择权却交给了对手本人，主角的恶由此变成对手自己的因果
- **卡点与伏笔**：结尾卡点：她说要替姑姑把退出的事安排妥当，墨晴退场后宫里再无懂医术的自己人，下一步如何收掉太后要看这一个半月；埋设/回收伏笔：蓝依的吊坠 → 皇上旧情与可能救她一命；十二年前先皇中毒案 → 夺位的正当性；郑家灭门 → 蓝依与皇上的孽缘；曾逸晨 → 墨晴退路

## 第177章 棠棣

**概要**：本章开启"汉成帝后宫之争"单元，以第三人称写长沙王遗孤毓娈的劫难开端。冬夜幽秘，第一滴火星坠地时毓娈睁眼，乳母符慌张闯入让她快逃——太子刘骜爪牙不远千里从长安来，抢掠烧杀，要为太子登基扫清障碍。长沙王曾有意将毓娈许给定陶恭王刘康，因恭王生母傅昭仪不中意而作罢，如今太子既已扳倒长沙王便敢放肆。符收拾两包袱引她后门逃，毓娈折返寻母亲遗留的羊脂玉镯，符从褥下摸出荷包。火舌吞噬王府，一队散兵包围，符被长矛刺死，遗言"去长安……去长安"。士兵逼近时，一道白光旋风般清掉散兵——是剑眉星目的年轻男子陈怀之，毓娈此生第一次见他，那个寒冷冬夜他带来人间一缕温情。她随他去城东君悦客舍，坚持另要一间屋；陈怀之微醉，她请他带自己去长安，雪覆灭大火也覆灭一个时代，十七岁的毓娈告别少女时代踏上征途。

**关键事件**：
1. 冬夜太子爪牙火烧长沙王府，乳母符护毓娈逃，她折返寻得母亲遗留的羊脂玉镯。
2. 一队散兵包围，符被刺死，遗言"去长安"，毓娈孤立无援。
3. 陈怀之白影现身旋风清兵，救下毓娈，那是她第一次见他。
4. 陈怀之带她去君悦客舍，她坚持另要一间屋，请他带自己去长安。
5. 雪覆大火，十七岁毓娈告别少女时代，踏上向长安讨说法的征途。

**逐章写法公式**：

- **情绪流向**：起：冬夜惊变的慌（紧张） → 承：乳母死别的痛（悲） → 转：白光救美的撼（爽） → 合：雪葬时代的怅（怅）
- **节奏配比**：环境渲染 25% / 逃亡死别 35% / 英雄登场 20% / 征途铺垫 20%
- **本章结构公式**：一夜大火（灭门） + 一摸荷包（遗爱） + 一刺乳母（托孤） + 一抹白光（救美） + 一场大雪（葬时代）
- **本章核心技巧**：新单元用"灭门之夜"把女主从云端推入绝境，再让男主如光落下——读者先疼后暖，立住全篇救赎基调
- **卡点与伏笔**：卡点：毓娈"去长安讨说法"的执念，埋下与太子刘骜不死不休的线；埋设/回收：羊脂玉镯 → 后续身世信物；陈怀之"陈家名门" → 接178章长安陈府；恭王刘康/傅昭仪 → 汉成帝史背景铺垫

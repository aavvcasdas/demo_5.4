## 第110章 神秘暗桩

**概要**：自坦言身份后秦琏便传口谕让秦不祥休息几日，可过了好几个几日仍不召见，她反倒心慌——从前争执他几个时辰都忍不住会主动来找她。她在湖心亭边看鸭子，那些鸭子原是秦桀阳生母春花养的，后又归百里牧云，如今成了她的；其中小云、小花是在她手心里破壳、把她当妈的，她换了副身体它们竟还认得出，她因此腹诽秦琏连鸭子都不如。鸭子吃完点心扭头就走，她一边馋烤鸭一边思忖凌千荷的话：那位神秘暗桩身居高位又与皇帝亲近，时机一到便可一招毙命，薄妃凉妃轻妃浪妃都有可疑。正想着，薄妃娇媚地过来以"奉茶宫女"相讥，见她不施礼便喝令掌嘴，侍女劝她颇得圣宠动不得，薄妃却推开侍女亲自扬手打来。她被戒指反光一刺，脑中闪过一个画面，下意识抬手格开又反手一掌打在薄妃心口，随即惊觉自己何时会了武功；太阳穴剧痛中，恍惚有人自身后握住她的手腕带她向前，耳畔低醇温耐地说"这样出掌才更效"——那是傅长卿，是盛雪依残留的记忆。秦琏一声"放肆"赶到，问的是"你打她了"，薄妃刚喊冤就被他断定狡辩、下旨禁足。她看着薄妃离去时嘟囔"工伤，绝对得算工伤"，越看越像那个暗桩。秦琏握着她的手凑到嘴边吹气问疼不疼，又指腹擦过她脸颊说"你从来都不哭"，她一摸才知是盛雪依为傅长卿流下的眼泪。她顺势装疼卖惨，被他一句"戏太过就不像了"戳穿，又可怜兮兮告状说他不理睬她就人人欺负她，他无奈叹气转身就走。她急得脱口喊"狗子，啊不，儿子"，被他以抄家灭族相胁，又苦口婆心数落他不问冷暖、只知喊打喊杀没礼貌，气得他拂袖而去。听见他冷叱"还不跟上"，她忙跑过去殷切问他是不是肝火旺盛，被反问"朕因何发脾气，你心里就没点数吗"。她索性摊牌说认他当爹是想当个公主，从华阳公主一路讨价还价到郡主、县主、城主，他只冷冷一句"当公主，你想都不要想"，最后被她吵得只吐出"给朕安静"。

**关键事件**：
1. 秦不祥在湖边推敲神秘暗桩人选，薄妃出现并动手被她反手打倒。
2. 盛雪依的武功记忆借傅长卿之声浮现，暴露其身体仍残留原主痕迹。
3. 秦琏不问青红皂白将薄妃禁足，又为她吹手擦泪。
4. 她装疼卖惨、讨要公主名分，从华阳一路降到城主，被他喝止。

**逐章写法公式**：

- **情绪流向**：起：心慌（几日不召见、看鸭子） → 承：冲突（薄妃掌嘴、反手打倒） → 转：护短（禁足、吹手、擦泪） → 合：耍赖（装疼、讨名分、给朕安静）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：湖边推敲暗桩（悬） + 薄妃挑衅被打（爽） + 盛雪依记忆浮现（疑） + 皇帝禁足护短（甜） + 装疼讨封号（闹）
- **本章核心技巧**：把"她不是盛雪依"这件事拆成三次失控——武功、耳语、眼泪，全靠身体而非台词泄露，读者比角色更早察觉。
- **卡点与伏笔**：结尾卡点：喜剧型——她讨封号不成被喝止，读者等下章风波再起；埋设/回收伏笔：薄妃疑似暗桩 → 下章设局试探；盛雪依为傅长卿流泪 → 原主情根未断；鸭子认得她 →  identity 的旁证；华贵公主需和亲 → 她讨封号时的自我避雷。

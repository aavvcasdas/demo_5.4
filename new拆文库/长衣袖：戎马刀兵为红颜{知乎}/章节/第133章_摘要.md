## 第133章 狭路相逢

**概要**：满手的血勾起七岁那年的旧事——花灯节前一日奶娘在城外破庙叮嘱她一定要去渡口等自己，她去了却等来一个粗犷男人，说已把她买下给儿子当童养媳；她挣脱逃走后撞见奶娘，奶娘却反手将她送回那男人面前催他快带走，最终是兄长及时赶到救下她。她质问奶娘为何卖她，奶娘说是在救她——留在王府早晚是死，卖了还能给滥赌的儿子还债；这个照顾了她七年、被她当作亲娘的人在争执中慌乱后退，一脚踩空掉进河中，被救起时只剩一息，却仍爬到她脚边哀求她救救自己的儿子，而她居高临下地看着奶娘头上伤口流下的血染红鞋面——那是她第一次杀人。她深陷回忆，未察觉身后砍来的冷刀，危急时有人长臂揽腰将她旋身带开，那杀手又被当胸一脚踹飞倒地不起；她看着满手鲜血与地上流不尽的血泊，只觉漫天血浪将她吞噬。昏沉中她梦见一贯的大雪、七岁的自己和持刀的父亲——父亲自小只当她不存在，却在七岁那年母亲忌日醉酒挥刀，年年母亲忌日都是他杀意最盛之时；她又梦见奶娘撕开雪幕、血红着眼索命，惊叫着醒来说手上到处都是血。傅寒池守在床边握住她的腕子把手举到她面前说你看什么都没有，只是噩梦，说她逛灯会累了睡着后被自己背了回来；她冷静后问起花灯，他便从床头取出，灯上题的是一个「恙」字——希望无论分开多久、分隔多远，最后都能对面而坐说一句别来无恙。次日她醒来竟又不认得他，抄起软枕砸向床边的他说大胆狂徒敢擅闯摄政王府，认出后诧异地问傅哥哥你怎么会在这，还说他俩快一年没见、自己今年八岁了；她说兄长今日凯旋，拉着他去离城门最近的兴雅阁等，等了大半日不见动静便下楼买小吃，回来的路上被一个剑眉凤目、气迫慑人的男子一把攥住手腕。她下意识缩了缩脖子，把手里的桂花糕递过去问要不要吃，那人面色沉寒地咬牙说跟我回去；她笑着先应下，待他转身拉她要走时突然朗声问红馆、为什么要去红馆，接着大声说兄长是去参军、你为什么要带我去青楼找他。四周人立刻围上来替她打抱不平，说他定是人口贩子、打军属主意实在令人不齿，那人被围得脸色铁青，凌厉地瞪着她一字一顿叫出「秦、阿、祥」。

**关键事件**：
1. 回忆七岁那年奶娘卖她、落河而死，那是她第一次杀人。
2. 冷刀袭来被傅寒池揽腰救下，她因满手鲜血陷入噩梦。
3. 醒来后他安抚她只是噩梦，并取出题着「恙」字的花灯。
4. 次日她再次失认他，去兴雅阁等兄长时被一男子攥住手腕，当众喊破红馆逼退对方。

**逐章写法公式**：

- **情绪流向**：起：奶娘旧事的回忆（压抑） → 承：冷刀与血浪、噩梦（恐怖） → 转：被安抚与恙字花灯（温馨） → 合：再失忆、被攥手腕与当众反制（紧张）
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：奶娘旧事与第一次杀人（创伤补完） + 血浪与噩梦（加压） + 恙字花灯与安抚（缓释） + 再次失忆与当众反制（立新钩）
- **本章核心技巧**：用「血」这一个意象串起三层时间——七岁的鞋面、此刻的双手、噩梦里的血泊，让回忆、现实与梦境在同一个感官里叠合
- **卡点与伏笔**：结尾卡点：那男子被人群围住后铁青着脸叫出「秦、阿、祥」，下章展开新篇；埋设/回收伏笔：恙字花灯 → 两人别来无恙之约；奶娘之子 → 后续复仇线；她八岁的失忆状态 → 记忆恢复线；红馆 → 下章场景

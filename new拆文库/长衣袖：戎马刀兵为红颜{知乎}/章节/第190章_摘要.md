## 第190章 独茕

**概要**：送走俪良媛已是宫门下钥，雯楚愁丝难解。她回想一年半前毓娈以远房亲戚名义改姓卫入府掩人耳目，太子等人究竟何时知晓真相？莫非从陈怀之回京便有人盯上她们？她头一回恶意揣测所爱之人，疑这一切从一开始便是陈怀之设计。她强撑起身要写信，笔却因刘骜忽然夜访而掉在纸上晕开墨花。刘骜狡黠笑说母后只禁她入乾宁殿、却不禁自己来普元殿，宠自己喜欢的人何须管旁人说什么。他卖关子说赐号「幽兰君」只猜对一半，另一半等她想到再告诉他，又嘱她备好三日后太后寿辰的礼与妆。临去他不经意提一句：卫府二小姐似与殷议郎家公子定亲了。另一边长安城萧索，毓娈病得厉害，日日咳，卫南风来服侍她便要伤三日心，后来索性不见。这日天暖她去上善寺拜佛，三叩首愿岁月静和，刚出殿便迎面撞上陈怀之，身后还跟着个丰壮浓妆、梳双刀髻的女子。陈怀之迟疑称她「甘棠」，毓娈平静回礼。陈怀之慰她能放下过去与殷家成亲，毓娈却冷笑回说今后各走各路，并撂下一句：雯楚如今已是极得太子宠的从二品幽兰君，若记恨他难保他日后如何。回府她提笔想将甘棠之事告雯楚，写到一半却搁笔——明知雯楚心里还有陈怀之，作为最好的姐妹她要护她周全，至少在雯楚宫中根基未稳时瞒着。正此时落霞慌报：老爷给大少爷提亲，让娶温家小姐。

**关键事件**：
1. 雯楚夜半疑陈怀之布局，刘骜突然夜访普元殿表护持并卖关子赐号。
2. 刘骜透露卫府二小姐（毓娈）似与殷家公子定亲。
3. 毓娈病中去上善寺拜佛，撞见陈怀之与一陌生女子甘棠。
4. 毓娈冷拒陈怀之，回府欲告雯楚甘棠之事却为护姐妹搁笔隐瞒。
5. 落霞急报卫老爷给卫南风提亲温家小姐。

**逐章写法公式**：

- **情绪流向**：起：夜半疑局的恐惧（恐惧） → 承：太子夜访的心动（心动） → 转：撞见旧爱新欢的心酸（心酸） → 合：搁笔护姐妹与提亲惊讯的错愕（错愕）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 悬念留白 25% / 爽点爆发 15%
- **本章结构公式**：一夜疑思（揣测陈怀之） + 一访示宠（刘骜夜来） + 一寺偶遇（陈怀之带甘棠） + 一笔隐瞒（毓娈搁笔） + 一报提亲（温家小姐）
- **本章核心技巧**：双线并行——宫里雯楚疑爱人、得宠；府里毓娈见旧爱新欢、为姐妹隐瞒。两条线都落在「隐瞒与保护」上，把姐妹情与爱情危机对位写
- **卡点与伏笔**：结尾卡点：卫南风被提亲温家小姐，毓娈与南风、陈怀之三条感情线同时被外力推动；埋设/回收伏笔：甘棠身世 → 后文落霞查出是绣红坊歌妓；赐号另一半含义 → 后文揭晓；殷家定亲 → 后文成婚

## 第124章 请旨赐婚

**概要**：承安传上早膳，秦琏把秦不祥的手拉下来让她吃饭；她看中的肉丸子被他截走，却原来是放进另一只碗里递给她暖胃，转头又被他自己夹进嘴里吃得自得。她懒得理他只顾吃饭，被要求喂饭时干脆专挑菜叶子喂，说是专治手麻手酸手不便，喂得他脸都绿了。太子来请安并汇报查案结果，称秦琏是食物中毒、御厨已自首承认误用相克菜品后畏罪自尽；她心中冷笑这是偷梁换柱，立刻推出凉妃——凉妃祖上三代名厨，昨日下午呈送的点心被秦琏抢着尝了两口，她精通食理，即便入口不多，晚间遇上相克食物也发作得厉害，只是醒得也快。她虽推断完整却无证据，便未多言，秦琏却气得掷了茶杯、训斥太子办事不力要彻查到底，她借故出去备茶躲开骂声。回来时太子正被骂得神色怏怏地出来，她因情商触底、知道一开口太子反而会哭，便选择不安慰；正当她犹豫时，与太子青梅竹马的平昭郡主走过——她是宁国公的掌上明珠，整个宁国府只有她与她有过指婚纠葛，杀她的奴才极可能是她所指派。她隐在暗处偷听却一无所获，只得把凉了的茶换过热再进帐。秦琏问她为何去得久，又状似漫不经心地问是否因为太子来了；她替太子说了几句好话，他便冷嗤着说既然他千万般好，朕将你许配给他如何，随即道出太子刚才来求娶她。她脱口而出当然不该，他从她目光中读出愉悦——原来他早有决断，方才只是故意试探。话音未落，承安神色严肃地呈上北漠军情急报，她心里猛地一沉。

**关键事件**：
1. 早膳桌上两人互相截胡与喂菜叶子的拉扯。
2. 太子汇报食物中毒与御厨自首，她推断真凶是凉妃却无证据。
3. 她偷听平昭郡主与太子，确认平昭郡主是宁国公之女、可能是杀她的幕后。
4. 秦琏以太子求娶之事试探她，被她一句「当然不该」通过，北漠军情急报突至。

**逐章写法公式**：

- **情绪流向**：起：早膳桌上的拌嘴（轻松） → 承：食物中毒的推断与彻查（紧张） → 转：赐婚试探与「当然不该」（爽） → 合：北漠军情急报（紧张）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 15% / 悬念留白 40%
- **本章结构公式**：早膳拌嘴（关系日常） + 食物中毒案与凉妃推断（悬疑推进） + 偷听平昭郡主（敌线加码） + 赐婚试探与军情急报（情感过关、战事立钩）
- **本章核心技巧**：把试探做成倒装——先抛出「朕将你许配给他如何」的惊人之语，再补上「太子刚才来求娶你」的前提，让读者和主角在同一秒经历从错愕到恍然的转折
- **卡点与伏笔**：结尾卡点：承安呈上北漠军情急报，她心里一沉，下章揭开边境战事；埋设/回收伏笔：凉妃相克下毒 → 后续凉妃线；平昭郡主是宁国公之女 → 杀局幕后；太子求娶 → 后续婚事线；北漠军情 → 下章主线

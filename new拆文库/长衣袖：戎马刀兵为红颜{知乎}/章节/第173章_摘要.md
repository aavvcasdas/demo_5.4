## 第173章 宁折枝

**概要**：皇后季桃枝（阿桃）以第一人称回望与宁封的"合约婚姻"。她有孕那日从殿前台阶摔下，宁封来告是母后换了避子汤、点了催情香。二人是被按头成亲的——宁封心里有白知月，她心里有前朝余孽湛行殊，于是约法三章：床一人一半、互不干涉，替对方打探心上人。太后求孙若渴，逼得宁封临幸出身低微的赵贵嫔养子，赵贵嫔却游湖落水胎没。季桃枝曾改写宁封与白知月的风月事卖作话本《玉徽记》洛阳纸贵，钱被宁封收进私库。白知月难产，她拿出表姑母所赠、可解难得之症的顺胎丸救人；宁封也去求一颗给自己。她男装出宫看白知月生产，归途遇见摘下面具的湛行殊，宁封当即警告"他最好不要动不该动的心思"。中秋二人出宫放水灯，他纸上写"愿季桃枝母子平安"；她画花灯画了头猪。白知月进宫谢恩，反劝她"皇上真的很爱你"。冬日宫墙转角她再见扮太监的湛行殊，被劫走又送回，宁封说明真相：湛行殊劫她上山只为威胁放人。她泪落愧疚，羊水破生下女儿小环（宁安），封号昭雪。此后满月、周岁、抓周、上书房画像，宁封夜留宿圆房，二人终相拥。

**关键事件**：
1. 季桃枝有孕，宁封告是太后换避子汤、点催情香；二人被迫成亲各有心上人，约法三章互不干涉。
2. 太后逼宁封临幸赵贵嫔养子，赵落水胎没；季桃枝改写《玉徽记》卖钱被宁封收进私库。
3. 白知月难产，季桃枝给顺胎丸相救；男装出宫看生产，归途遇湛行殊，宁封出言警告。
4. 中秋出宫放水灯写"愿季桃枝母子平安"，画花灯画猪；白知月进宫反劝她皇上爱她。
5. 冬遇扮太监的湛行殊被劫又送回，宁封道破其威胁真相；季桃枝生女小环，此后圆房相拥。

**逐章写法公式**：

- **情绪流向**：起：有孕撞破太后的怒（紧张） → 承：合约婚姻的闹（喜） → 转：出宫遇湛行殊的痛（揪心） → 合：生女圆房的暖（圆满）
- **节奏配比**：日常拌嘴 35% / 孕事波折 25% / 情感暗涌 25% / 收束甜暖 15%
- **本章结构公式**：一跤有孕（起冲突） + 一本话本（写心结） + 一丸顺胎（救情敌） + 一遇故人（揭利用） + 一盏水灯（定真心） + 一女小环（收圆满）
- **本章核心技巧**：用"帝后扮恩爱"的戏中戏套着"各自有心上人"的戏，两层戏同时演，读者看谁先醉
- **卡点与伏笔**：卡点：季桃枝仍画错把宁封袍子画成朱红，暗示心已移；埋设/回收：顺胎丸 → 救白知月伏笔回收；湛行殊劫持 → 接175章番外；小环(宁安) → 接176章番外

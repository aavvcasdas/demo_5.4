## 第185章 道思

**概要**：本章写毓娈陪雯楚赴验前夕的心事、茶馆遇殷其雷，与雯楚中选的消息。一场夜雨落花，卫夫人携雯楚去掖庭第二轮，府中喧嚣，毓娈醒去后湖站了许久，想与卫南风初遇——曾以为曼离离开、自己时机刚好，却忽略爱与时间无关。落霞陪她去掖庭附近"畅得园"茶馆二楼雅座，想窥探一二。殷其雷竟来斟茶坐对面，笑"同小姐有缘，避俗却未免俗"，直夸她"玲珑美人聪敏灵慧"。他问"若今日在掖庭中的是你，想中还是想弃"，雅间气氛微妙，落霞添茶，毓娈黯然"或许有一天能回答，今日恕难回答"告辞。轿回府她一阵头晕，管家喜报"十二上秀大小姐名列第五"。毓娈暗赞。暮春过后天热，金凤阁流苏玉钗送来，碧云扶正珠花插玉钗，卫夫人让她站起瞧——浅杏长曲裾雅致，卫夫人"不能输人后"。雯楚却觉如精致木偶，心冷若冰霜。

**关键事件**：
1. 夜雨毓娈醒去后湖，想与南风初遇、曼离之憾，落霞陪去"畅得园"茶馆。
2. 殷其雷来雅间斟茶坐对面"同小姐有缘"，问若今日在掖庭你想中还是弃，毓娈告辞难答。
3. 轿回府晕，管家报雯楚十二上秀名列第五；毓娈暗赞。
4. 暮春雯楚妆扮浅杏曲裾如木偶，心冷若冰霜待入宫。

**逐章写法公式**：

- **情绪流向**：起：后湖思人的柔（柔） → 承：茶馆诘问的揪（揪） → 转：名列第五的赞（慰） → 合：木偶冰霜的悲（悲）
- **节奏配比**：后湖心事 25% / 茶馆插曲 30% / 中选喜讯 20% / 木偶收束 25%
- **本章结构公式**：一立后湖（写思） + 一坐茶馆（写纠缠） + 一问中弃（写两难） + 一报第五（写定） + 一如偶（写悲）
- **本章核心技巧**：把"女主的暗恋"与"闺蜜的喜讯"放在同一章——她替友暗喜，读者却替友垂泪
- **卡点与伏笔**：卡点：毓娈"或许有一天能回答"未答，埋下她日后自身选秀或抉择；埋设/回收：殷其雷 → 接184章绸缎庄初遇；十二上秀第五 → 接186章封良娣；浅杏曲裾 → 接186章入宫妆扮

## 第33章 （9）

**概要**：我呕心泣血的诉状小皇帝一个字没看，只拿起签名页说"好香"。踏进承天门，小太监一箱箱运松木（雪松黑松赤松乔松黄山松），小皇帝水蓝常服笑问用什么松木做墨水；我拱手低眉说秘方不便说、愿侍奉圣上，皇帝眯眼透冷意说"朕身边可只有太监"，我抬头笑说愿意。我早明白该低头时低头，赌小皇帝把权力移交宦官——给我做净身的是老王爷爷的人脉，检查的是受爹赠田的贱民。我穿深蓝宫服成御书房小太监，爹与老王仍陷狱中待我周旋。

**关键事件**：
1. 诉状未阅：小皇帝只说签名页"好香"，承天门运松木、问松木来源。
2. 愿为太监：我献秘方、皇帝点"只太监"、我笑应，赌权力交宦官。
3. 入宫为监：净身人脉、穿深蓝宫服成小太监，爹老王待周旋。

**逐章写法公式**：

- **情绪流向**：起：诉状未阅、只说"好香"的寒意 → 承：承天门运松、皇帝问墨的平静对峙 → 转：献秘方、皇帝点"只太监"、我笑应的决绝 → 合：入宫为监、净身人脉闭环的悲凉
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 0% / 悬念留白 55%（以对话与白描推进）
- **本章结构公式**：诉状未阅（签名页好香、承天门运松、皇帝问墨） + 愿为太监（献秘方、皇帝点太监、我笑应） + 赌交宦官（明白低头、权力移宦官） + 入宫为监（净身人脉、深蓝宫服、爹老王待周旋）
- **本章核心技巧**：用"我早知道该低头"的冷静独白，把女主从官家小姐到深宫太监的坠落写成主动选择，痛感来自清醒
- **卡点与伏笔**：结尾卡点：压抑型——我入宫为监、爹老王仍陷狱，读者知这是以身为质的周旋；埋设/回收伏笔：松香泪墨 → 本章"好香"与"用什么松木"再点其香、皇帝执念收束；老王爷爷人脉/爹赠田贱民（前章伏笔）→ 本章净身闭环回收；权力移宦官 → 后文黄全忠赵德宝登天、东厂成立

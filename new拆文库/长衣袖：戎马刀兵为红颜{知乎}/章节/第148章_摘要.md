## 第148章 一心求死

**概要**：蓝依经墨晴诊治竟查出有孕，对她这般一心求死之人无异于折磨，遂闭门以泪洗面，决意不要孽障也无颜苟活。皇上闻讯赴玉宁宫门外卸防备恳请依依开门，蓝依却发狂喊「我好脏配不上六子」；皇上踹门惊见她肚上插刀倒在血泊。墨晴抢救，皇上为保其命舍了孩子，蓝依虽活却全无求生欲。此后一月她拒见任何人，皇上终强行闯入，亲喂汤药、动情求她「做朕的皇后」。蓝依先以放婉儿为由回避，被逼视后含泪点头。宫中传开立郑将军遗女（蓝依）为后，永定王惊而赶早朝阻挠，反被晾、众臣倒戈。端午大典上永定王酒气持剑抵蓝依脖，蓝依凛然斥其卑鄙，王剑落被擒，却留「典礼上还少了谁」的阴狠伏笔。墨晴悟其所指贤亲王，婉儿挺近五月身孕跪求出宫寻夫，皇上改宣其回宫；曾逸晨跑边境带回其书信，许诺班师后迎娶。夏热，婉儿命墨晴取冰未归，中暑昏倒，醒见一酷似蓝依神韵的女子喂她糖水并唤「芸姨」请医——新人悄至。

**关键事件**：
1. 蓝依被诊出有孕，万念俱灰之下自戕，皇上踹门救下血泊中的她，为保命舍了胎儿。
2. 蓝依经月闭门拒见，皇上强行闯入喂药表白，终以「做朕的皇后」逼她点头应允。
3. 皇上早朝宣布立郑将军遗女（蓝依）为后，永定王当殿阻挠反被晾、朝臣纷纷倒戈。
4. 端午立后大典永定王酒气持剑胁蓝依，被擒前留下「还少了谁」的伏笔，指向贤亲王。
5. 婉儿闻伏笔挺孕身跪求出宫寻贤亲王，皇上改宣其回宫；曾逸晨带回书信报平安，婉儿中暑昏倒遇神秘女子。

**逐章写法公式**：

- **情绪流向**：起：诊出有孕与自戕的惊（震惊） → 承：抢救舍胎与闭门拒见的压抑（悲伤） → 转：喂药表白换来点头的甜（期待） → 合：立后受阻与永定王被擒的爽（紧张） → 尾：中暑遇新人的悬（悬念）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：一刀（自戕揭惨） + 一跪（门外求见） + 一喂（逼出应允） + 一立（大典定局） + 一伏（还少谁）
- **本章核心技巧**：把「求死」写成血泊里的一刀、把「求生」写成喂药时的一勺——用最具体的动作替代最抽象的情绪
- **卡点与伏笔**：结尾卡点：婉儿中暑昏倒，睁眼见酷似蓝依的神秘女子与「芸姨」，新人身份未揭；埋设/回收伏笔：永定王「典礼上还少了谁」→ 指向贤亲王边境有变；皇上早朝十年未见的转变 → 永定王失势；蓝依「先放婉儿」被拒 → 冷宫线未结

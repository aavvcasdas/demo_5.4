## 第186章 玄黄

**概要**：本章写宫门候见、未央宫遴选，与雯楚封良娣后与毓娈的决裂边缘。雯楚再遇许娥，十二名秀女皆绮罗钗环，唯许娥浅藕色碎花曲裾家常平髻、出水芙蓉般纯朴。内侍宣分两队候见，前排左班令曦——越骑校尉班况之女，孤傲。雯楚平静自嘲。位次后秀女入正殿，她恍惚听见怀之笑声，忆童年采莲蓬。太宰令之女卫氏被宣，沿汉白玉甬道入未央宫中宫。上首元帝、左后王政君、右太后、下首太子刘骜。太后喜"明眸善睐"，元帝问"夫小惑易方大惑易性"出自《庄子·骈拇》，雯楚答对。元帝"位列第五怕委屈"，皇后睨"生辰不佳十八还……"太后咳"当年嫁先帝十七、骜儿非头婚"。太子朗声"仁者见仁看不出喜气"。圣旨下：卫氏封正三品良娣赐居普元殿。三日后卫府门槛踏破，雯楚闭门三日。毓娈点破许娥乃恭哀皇后许氏侄女夺魁、班令曦仅少使。雯楚吼"我将嫁给你的仇人！"毓娈逼视"你选这条路背叛我"。雯楚平静说毓娈从无伤人力，"即使刀柄递你转向自己"。陈怀之来求见，雯楚不见，毓娈劝见，雯楚泪"自小情分抵不过他荣华"。

**关键事件**：
1. 宫门外十二秀女候见，许娥出水芙蓉，班令曦孤傲；雯楚被宣入未央宫，对元帝太后太子应对得体。
2. 圣旨下：卫氏封正三品良娣赐居普元殿；卫府三日门槛踏破。
3. 毓娈点破许娥乃许皇后侄女夺魁、班令曦仅少使；雯楚吼"我将嫁给你的仇人"，毓娈逼她"选这条路背叛我"。
4. 雯楚平静说毓娈从无伤人力，"即使刀柄递你转向自己"；陈怀之来求见，雯楚不见，毓娈劝见，雯楚泪"情分抵不过荣华"。

**逐章写法公式**：

- **情绪流向**：起：宫门候见的庄（庄） → 承：未央应对的敬（敬） → 转：圣旨夺魁的惊（惊） → 合：仇人一句的痛（痛）
- **节奏配比**：宫门铺陈 20% / 未央遴选 30% / 圣旨夺魁 20% / 决裂对话 30%
- **本章结构公式**：一立宫门（写候） + 一入未央（写选） + 一纸良娣（写定） + 一揭夺魁（写反转） + 一吼仇人（写裂）
- **本章核心技巧**：把"中选的荣耀"与"友谊的碎裂"同步写——读者替她戴上凤冠，却看见她亲手推开唯一懂她的人
- **卡点与伏笔**：卡点：雯楚入宫为良娣，与毓娈"仇人"之结未解，埋下宫中再会的张力；埋设/回收：许娥许皇后侄女 → 接184章"若中选定在雯儿之上"兑现；太子刘骜 → 接187章普元殿侍寝；陈怀之求见 → 接187章角门告别

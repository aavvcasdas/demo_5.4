## 第144章 步步紧逼

**概要**：皇上从雍和宫回去后把自己关在建章宫再不肯出来，婉儿和贤亲王则从雍和宫直奔永定王府要一个说法。眼前的王府已不是从前那副朴素模样：火红的龙凤大门、两尊石狮、镶金的门匾，园子里牡丹争奇斗艳，连下人的衣着都胜过普通大户人家的主子，贤亲王也被震住。二人刚要进门便被管家拦下，婉儿怒喝着往府里喊话，引出了不顾劝阻跑来的王妃。王妃仍亲切地唤她妹妹，婉儿却冷冰冰地顶了回去，直到嫣儿替王妃辩白说她一直在别院疗养什么都不知道，王妃也不由分说拉着她直闯书房，要王爷给个交代。书房里永定王正与朝臣议事，永定王先是对王妃温言，被逼问后却露出真容：他承认自己一直在利用婉儿，反呛她当初是心甘情愿的，也坦然答出一个是字——他早知道两人的真正身世。婉儿转而挑动在场的安大人，说您就这么一个女儿，安大人怒斥永定王后奔出去寻女，这一次歪打正着让永定王失去了一股重要助力。王妃却在逼问中被永定王一巴掌打出了血，心死之下跑出书房。婉儿与贤亲王找遍王府，最后在孩子房里找到她——满地散乱的头发，她抱着两个孩子坐在地上，半边脸还是红肿的。永定王跪求她别作践自己，她只留下恩断义绝情难续、愿常伴青灯古佛为孩子赎罪的话，又把两个孩子塞进婉儿怀里托她抚养，随后跑了出去再没有回来。抱着孩子离开王府的婉儿已经看开，什么天下苍生、什么先大家后小家都是胡扯，她要的就是让太后和永定王一个一个生不如死。她大张旗鼓走到雍和宫，太后正被疼痛折腾得满地狼藉而无人送药；她遣退嬷嬷，用簪子刺人中把昏死的太后扎醒，又把足够让一头牛服下的整包罂粟粉灌进她嘴里，看着她从惶恐到转而觉得舒服，只说明天再来看成果。太后急召墨晴，才知道王太医自那日一别就下落不明，连宫里的奴才都避之唯恐不及；张嬷嬷跪地自责，太后难得说了几句肺腑之言让她离开皇宫。第二天清晨婉儿再来，老嬷嬷躺在她面前拼死拦门，她当场下令把张嬷嬷拖到雍和宫门外杖毙。太后跑到庭院只看见一滩血，随即冷冷说那不过是个尚有利用价值的奴才，拿来考验她一番罢了；而那个被所有人以为死了的张嬷嬷，正拿着婉儿递来的罂粟花粉走进殿内。

**关键事件**：
1. 婉儿与贤亲王登门质问，永定王承认一直利用她并早知两人身世。
2. 王妃为婉儿出头被永定王一记耳光打碎了心，托付两个孩子后出走。
3. 婉儿彻底转向报复，用簪子扎醒太后并灌下整包罂粟粉。
4. 张嬷嬷被当众杖毙，太后亲眼看见后仍只当她是有用的奴才。

**逐章写法公式**：

- **情绪流向**：起：登门问罪的怒（紧张） → 承：王妃被打与托孤的痛（悲伤） → 转：信念崩塌后转向报复（压抑） → 合：灌药与假处决的反杀（爽）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：登门对质（逼出真话） + 一记耳光与托孤（断一条情线） + 信念翻覆（换动机） + 灌药与假处决（连出两记反杀）
- **本章核心技巧**：让主角把「被利用」直接兑换成「我要你们生不如死」——先用一场对质剥夺她的道义借口，再用一个具体受害者把她的报复钉成必然
- **卡点与伏笔**：结尾卡点：张嬷嬷已经成了婉儿手里的人，太后只剩两天可活，罂粟粉的成瘾会在明日显出成果；埋设/回收伏笔：整包罂粟粉 → 明日之果；张嬷嬷假死 → 安插在太后身边的耳目；墨晴失踪 → 永定王失去掌控；王妃出走 → 安大人与王府助力流失

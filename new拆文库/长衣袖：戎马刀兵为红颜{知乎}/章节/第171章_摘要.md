## 第171章 "衡帝萧怿番外"

**概要**：本番外以衡帝萧怿视角回望两世。他自幼在皇城长大、看惯人心，初见十二岁被算命选入宫的闻棠，她便许下"生生世世"的诺言，他记了一辈子。那日他醒来成了鬼魂，地府阎王道出死因，他唯一的愿望是与闻棠生生世世，再睁眼回到走的那天。重生后闻棠"变了一个人"——避他如蛇蝎、骂他"带着面具的恶鬼"，他寻得半仙才知这是前世被卫长生伤透的闻棠。他暗中布局：故意让闻棠撞见陈淑妃与侍卫私通以表只爱她一人；装醉说重生引她出宫；潜入客栈点她睡穴抱回。行宫遇刺他明知卫长生做手脚仍去，只为留住她；待闻棠说出爱的是他，他便遂了卫长生意带她隐居。番外末回至中秋山林赏月，闻棠说肚子里的孩子要吃月饼，他拿走半块换酸梅汤，二人白头偕老，"如此互相依偎，甚好"。

**关键事件**：
1. 衡帝幼见十二岁闻棠许下"生生世世"诺言，记了一辈子，自此只留她一人在后宫。
2. 他死后成鬼魂见阎王，只求同闻棠生生世世，再睁眼回到未死的那天。
3. 重生后闻棠"变了一个人"，他寻半仙确认是前世被卫长生伤透的闻棠，布局证明只爱她。
4. 他故意让闻棠撞见陈淑妃私通、装醉说重生、点睡穴抱回，层层留她。
5. 行宫遇刺他明知圈套仍去，闻棠说出爱的是他后遂带她隐居，番外收于中秋赏月盼白头。

**逐章写法公式**：

- **情绪流向**：起：童言定情的暖（甜） → 承：死后许愿的憾（震撼） → 转：识破替身的痛（释然） → 合：布局留人、隐居白头的满（圆满）
- **节奏配比**：回忆铺垫 35% / 布局揭秘 35% / 情感收束 30%
- **本章结构公式**：一句童言（定深情） + 一场死亡（许来世） + 一段替身（解误会） + 几手布局（证只爱她） + 中秋赏月（收白头）
- **本章核心技巧**：番外把主线里"闻棠视角"看不到的算计全摊开——男主每一步"狠"都是"留她"，读者得以正反合看同一段情
- **卡点与伏笔**：卡点：番外补完主线留白，衡帝"装醉说重生""点睡穴"皆回收；埋设/回收：陈淑妃私通 → 对应主线借刀杀人伏笔；行宫塌落 → 呼应170章刺杀；酸梅汤 → 对应147章燕窝薏米甜汤的口味梗

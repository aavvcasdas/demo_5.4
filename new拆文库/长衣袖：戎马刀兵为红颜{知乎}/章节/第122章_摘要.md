## 第122章 死傲娇

**概要**：行刑之际传来「陛下驾到」，承安满头大汗跑来喝止，秦琏虽病着仍大步流星赶至，几步上前将秦不祥扶起、三两下扯掉捆绑的绳索，关切地问她可曾受伤。她愣愣地看着他衣衫潦草、发丝微乱、面色苍白、唇无血色、胡茬根根冒起的狼狈模样，才信他是真中了毒；他淡然说「梦见你受了委屈，自然就醒了」，目光却眨也不眨地锁着她，随即用力将她搂进怀中，连说两声幸好，声音哽在喉头、身子微微颤动。他松开后又按着她的后脑将她捂在心口深缓了几口气，转身面对监斩台跪了一地的人，目光陡厉地喝道「连朕的人也敢动，你们好大的胆子」，直吓得众人连连告罪。他气极之下剧烈咳嗽、整个胸腔震颤，她急忙替他顺气，并借机示意承安宣太医——她既怕他气出好歹，也怕他一怒降罪，若皇上为一介宫女怪责肱股之臣传出去，她便无从收拢人心；她索性把这当成以德报怨、笼络朝臣的机会。回到皇帐，他命太医院齐院正先给她诊脉，得「姑娘身体极为康健」的结论后她问他可以好好看病了，他别过脸说「谁担心你了」，却乖乖伸手让太医诊出内伤未愈、又怒急攻心。太医告退时她要起身相送被他一把拽住手腕，承安识趣地带走众人，留下两人两两相觑。她问他疼不疼，他答疼，又嫌她只回一个「好」字；她提出给他揉揉，他一会儿嫌她用自己的手、一会儿嫌她不动手，被问「揉哪」时索性抓着她的手按向自己心口而疼得闷哼。她轻轻揉着，他竟歪头睡了过去，她想叫人来扶却被他铁钳般箍住手腕，只能眼巴巴盼承安回来，谁知帐帘一掀进来的却是本该留在京都监国的太子。

**关键事件**：
1. 秦琏在行刑现场现身救下她，自称梦见她受委屈而醒，并当众喝止监斩众人。
2. 她借宣太医阻止他降罪，把这场危机化成笼络朝臣的人情。
3. 皇帐内他坚持先给她诊脉，诊出自己内伤未愈又怒急攻心。
4. 两人独处，她被拽住手腕，在一连串傲娇的别扭中给他揉胸口至他睡去，太子突然入帐。

**逐章写法公式**：

- **情绪流向**：起：刀斧之下的绝境（紧张） → 承：他狼狈赶来相救（温馨） → 转：独处时的别扭与揉胸（甜） → 合：他睡去、太子忽至（紧张）
- **节奏配比**：慢铺垫 15% / 快冲突 20% / 爽点爆发 20% / 悬念留白 45%
- **本章结构公式**：刑场获救（危机解除） + 阻止降罪换人情（转弊为利） + 先给她诊脉与独处尴尬（关系升温） + 揉到睡着与太子入帐（新钩子）
- **本章核心技巧**：把傲娇写成「嘴上一条线、身体一条线」的双轨——每一句否认后面紧跟一个相反的动作，让读者从动作里读出真相
- **卡点与伏笔**：结尾卡点：本该在京都监国的太子突然出现在皇帐，下章需解释他为何离京；埋设/回收伏笔：梦见她受委屈 → 两人之间的感应线；以德报怨笼络朝臣 → 后续收服大臣线；齐院正 → 太医线；太子离京 → 下章主线

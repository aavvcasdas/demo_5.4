## 第116章 喂药

**概要**：秦不祥端药进养居殿，只见满地碎裂杯盏与药汁，正撞上自己的童年阴影；秦琏先以恶鬼般的目光瞪她，吓得她半身麻软，看清是她后却目光骤亮、露出温和喜悦，见她瑟缩又立刻沉脸躺下用后脑勺对人。她连哄三句都不被理，直到说「本宫第一次哄人」才被揭穿哄过琮儿，秦琏这才转身让她扶起，傲娇应允喝药，被她灌得呛到后说「下次看你表现」。当夜她在小榻守夜，想通秦琏容留解语花养伤是怕打草惊蛇、想放长线钓大鱼借力打力暗中拔除凌天盟，因漠北西辽边境不安生才不便大动干戈；她既不愿两人互残，便趁解语花烧得昏迷，用秦琏给的「如朕亲临」腰牌连夜将他送出宫。次日秦琏知情后大发脾气，却因腰牌是自己所赐只能生闷气，窝火程度堪比她死前那场争吵。回忆中那次他为面首之事脱口「朕绝不允准这种狐媚惑主的低贱娈宠踏入宫门一步」，她回「那本宫便陪他在外，永不回宫」，他被气到发颤追问是否当真，又攥臂质问她怕不怕自己，她退让到只留解语花一人，他却恨声说「你将他放心里，却不知将我丢弃在哪里」，随后笑着连说「好，很好」，并召国巫为她驱邪。国巫日夜念咒，她因装病成真病、病得说不出话而无法驱逐，最终真病而死，由此秦琏嫌疑在她心中变重。如今他火气正旺，她端来绿豆汤想灭火，却被质问「你连夜将他送走，就是为了防着朕对不对」。

**关键事件**：
1. 秦不祥端药入殿，撞见满地碎瓷与秦琏的暴怒，哄了三句才让傲娇的他肯喝药。
2. 她守夜时想通秦琏容留解语花是放长线钓大鱼，趁其昏迷用腰牌连夜将他送出宫。
3. 回忆死前最严重的那场争吵：娈宠之争、永不回宫、攥臂质问，末了他召国巫为她驱邪。
4. 她装病想给两人台阶，反而真病而死，因而重新怀疑秦琏；眼下为保命端绿豆汤，反被质问送走解语花的用意。

**逐章写法公式**：

- **情绪流向**：起：满地碎瓷与暴怒（紧张） → 承：三哄三哼的傲娇和好（轻松） → 转：送走解语花与回忆中的争吵（压抑） → 合：装病致死的真相与当下的质问（紧张）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：端药入殿撞怒（压力开局） + 三哄一揭穿的傲娇喂药（关系回温） + 守夜推理与连夜送人（主动破局） + 前世争吵与装病之死（死因加压、立新疑）
- **本章核心技巧**：把「喂药」这个日常动作做成关系晴雨表——同一碗药承接了暴怒、傲娇、和好三层情绪，再用「下次」这个词把一次性和好延展成连续期待
- **卡点与伏笔**：结尾卡点：秦琏直接质问她送走解语花是否为防着自己，下章需应对；埋设/回收伏笔：「如朕亲临」腰牌 → 本章兑现为送人出宫的通行证；国巫驱邪 → 死因线与「鬼上身」怀疑；漠北西辽边境不安生 → 后续边境战事线

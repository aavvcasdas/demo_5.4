## 第175章 "湛行殊番外"

**概要**：本番外以湛行殊视角回望对季桃枝（阿桃）求而不得的一生。他平日巡视山头，忽见林中作画的女子——低垂粉颈、翠袖低垂，分明不是寻常人家，山中蛇虫猛兽她却毫无防备。他救了她，她却缠上了他，如桃花在他心上开出满娇烂漫红。但他们之间隔了太多，他只能任情种生根直至心支离破碎。那日风细柳斜，她终表心意，他想说"好"开口却是"保重"，她哭着跑下山，他悄悄跟了一路。后听说她入宫做了皇后，他几次混入皇宫看她——青丝梳鸾髻、枕边睡了他人，但总归比跟着他好得多。底下叔父不满他许久、瞒他劫了御贡，他将叔父行踪报给朝廷借朝廷清门户。那日他又进宫忘了离她远些，她发现了他、仍没忘了他。长痛不如短痛，宁封赶到冷宫从他手里接过她，他让宁封同他说个谎让她彻底死心——因他是前朝余孽、她是朝廷重臣之女，非良缘。他走回寨子，雪浸衣、泪冻脸，红桃已落只剩孤寂。

**关键事件**：
1. 湛行殊巡山救下作画的季桃枝，她缠上他，如桃花开满他心，却隔了太多只能任情种生根至心碎。
2. 她表心意那日风细柳斜，他想应"好"却出口"保重"，她哭跑下山他悄悄跟了一路。
3. 闻她入宫做皇后，他几次混入看她，枕边睡了他人，却觉总比跟着他好。
4. 叔父瞒他劫御贡，他报朝廷清门户；又进宫忘了远离，她发现他仍没忘他。
5. 宁封冷宫接过她，他让宁封同说谎令她死心；走回寨子雪浸衣泪冻脸，红桃已落孤寂。

**逐章写法公式**：

- **情绪流向**：起：巡山救美的纯（美） → 承：表白错口的痛（虐） → 转：入宫放手的悲（悲） → 合：雪中孤寂的空（空）
- **节奏配比**：初遇 30% / 错口 25% / 入宫 25% / 死心收束 20%
- **本章结构公式**：一救作画女（种情） + 一句保重（碎心） + 一入深宫（放手） + 一报门户（立身） + 一谎死心（孤寂）
- **本章核心技巧**：番外把173/174章里"季桃枝单方面痴恋"翻转——原来他更早动心、更先放手，读者的心疼从女主移到男主
- **卡点与伏笔**：卡点：他让宁封说谎，埋下173章劫持真相的刺；埋设/回收：叔父劫贡 → 呼应173章长兄上报山寇；红桃意象 → 接176章宁安"像故人"伏笔（湛行殊看宁安）

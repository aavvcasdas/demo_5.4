## 第136章 情窦初开

**概要**：木槿看着少年走出别院才回阁，发现婉儿小脸通红坐在凳子上发呆，问了半天她才呆呆地说心里怪怪的，并把木槿的手按在自己胸口，说心跳得好快、脸好烫、像要着火却不难受反而开心，还说只偷看了一眼那人的脸就总在脑海里赶不走，怀疑自己被下了毒药。木槿意识到这是心病，怕无法向墨晴交代，便故作轻松说只是受了惊吓有些发烧，熬了姜汤哄她睡下；第二天婉儿果然又活蹦乱跳。墨晴归来后木槿据实禀报，墨晴赶到淑雅别院，一步步诱导婉儿说出那日偷看少年的情形，点破这不是病而是心动，并说明天要带她去见一位很重要的人、此后可能要与她分开。三天后藏娇阁被一位神秘客人包场，众人聚集正厅，戴铁面具的阁主以腹语般的声音问婉儿可愿意跟他走；婉儿提出两个请求——要知道带她走的人是谁、什么模样，以及带走她的原因，阁主大笑说初生牛犊不怕虎，答应满足但要她永远不违抗。上到二楼他摘下面具，声音变得正常好听，婉儿认出他竟与那日闯入别院的少年惊人相似，只是棱角更分明、多了狠厉与霸气。她问娘亲是否还在，阁主说她娘在倚红楼第二天就自尽了，是晚到一步没能救活，也是他让墨晴瞒下真相，并说出带她走的唯一原因——帮他夺回皇位，成功后替她父亲洗脱冤情、还她自由。墨晴一口气道出全部实情：阁主是先帝大皇子，六皇子趁他在边疆杀敌时逼位、害死大皇子母后并气死先帝，邓将军为他抱不平遭灭门，她爹爹也因此获罪；六皇子登基后由明转昏，沉迷女色、乱征苛税。次日婉儿只带走几件衣物与紫竹的琴谱，一路沉默入京，途中恨意由愤怒转为冷静；进京后她亲见士兵强拉油纸伞摊贩抵税、繁华集市瞬间凋零，阁主说她身上担负的还有百姓的未来。马车停在寒酸的永定王府，偏房布置竟与淑雅别院的闺房一模一样，小丫鬟嫣儿唤她表小姐。王爷给她新身份——王妃江南姨娘家的表妹孟菲雨、闺名雨儿，父亲经商失败家道中落、父母病亡后投奔舅舅安彼道，此来陪伴怀孕的表姐安凌雅；次日王府上下迎接王妃归来，婉儿初见这位温柔如水、腹有身孕的女子，两人以姐妹相称，一切水到渠成。

**关键事件**：
1. 婉儿偷看少年后心动，被木槿以「发烧」掩盖并在墨晴归来后道明。
2. 墨晴点破她只是心动，并预告次日要去见一位重要的人、此后将要分别。
3. 阁主现身藏娇阁，婉儿以两个请求换得真相，得知娘亲已自尽、自己将被带去夺位。
4. 入京路上她完成由恨到冷静的转变，抵达永定王府后获新身份孟菲雨，与王妃以姐妹相认。

**逐章写法公式**：

- **情绪流向**：起：心动的慌乱与掩盖（甜） → 承：阁主现身与真相揭开（紧张） → 转：入京路上的恨与冷静（压抑） → 合：新身份与姐妹相认（温馨）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：心动与掩盖（情感起点） + 阁主现身与两个请求（命运转折） + 身世真相与入京见闻（动机加固） + 新身份与姐妹相认（潜入开局）
- **本章核心技巧**：让初恋对象与命运主宰者在最后一刻重合——少年与阁主惊人的相似把少女的心动直接变成她无法挣脱的枷锁
- **卡点与伏笔**：结尾卡点：婉儿以表小姐身份留在王府，王妃为何要陪太后去祈福仍是疑点；埋设/回收伏笔：紫竹的琴谱 → 后续入宫用琴；孟菲雨的新身份 → 潜入皇宫线；面纱 → 容貌线；九皇子与贤亲王 → 后续夺位线

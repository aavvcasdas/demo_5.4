## 第172章 "前世卫长生番外"

**概要**：本番外以卫长生视角回望两世痴妄。他第一次入宫陪太子读书，遇见如蝴蝶兰般娴静的闻棠，烙在心上多年，却知她心里只有衡帝。一次偶然救下老者，老者问所求，他随口一说竟真成了衡帝，老者代之成了卫长生。他权谋心机远不及衡帝，为朝局安稳纳妃拉拢权臣，把本该为妻的闻棠当作棋子困于骗局。闻家渐失势，他仍留她为后；僵持日久终送一杯毒酒，说"若不要后位便还你做后"，闻棠却饮下毒酒转告"收回年少诺言，生生世世永不相见"——他这才知她爱的一直是衡帝。重生后他仍是卫长生，宫宴再见假笑的闻棠，借宋家兵力夺位、利用许文兰通风，再坐那位却身旁无闻棠，终成暴君死在衡帝剑下，死前想说"还你皇位换闻棠"却没机会。后记补完史笔：衡帝隐退、卫长生暴政身死，衡帝携闻氏回宫诞太子，引出故事十三宁折枝。

**关键事件**：
1. 卫长生幼入宫见"蝴蝶兰般"的闻棠，救老者随口许愿竟真成了衡帝，老者代之成了卫长生。
2. 他为权谋纳妃、把本该为妻的闻棠当棋子，闻家失势后仍留其为后，却终送毒酒。
3. 闻棠饮鸩转告"收回诺言、生生世世永不相见"，他才知她爱的一直是衡帝。
4. 重生后他仍是卫长生，借宋家兵力夺位、利用许文兰，再坐那位却无闻棠，终成暴君死在衡帝剑下。
5. 史书记载衡帝隐退、卫长生暴政身死，衡帝携闻氏回宫诞太子——正文故事十三引出宁折枝。

**逐章写法公式**：

- **情绪流向**：起：初见动心的纯（怅） → 承：夺位占人的执（压抑） → 转：毒酒醒悟的悲（痛） → 合：再世身死的空（唏嘘）
- **节奏配比**：前世回忆 40% / 夺位执念 30% / 身死对照 20% / 史笔收束 10%
- **本章结构公式**：一遇蝴蝶兰（种情根） + 一愿成衡帝（造错位） + 一杯毒酒（醒痴心） + 一世再夺位（空余恨） + 一笔史传（收结局）
- **本章核心技巧**：番外把"反派"还原成"求而不得的人"——他不是恶，是偷了一世去爱却始终不在她心里
- **卡点与伏笔**：卡点：史笔"衡帝同闻氏及公主回宫"留公主伏笔；埋设/回收：兰儿 → 对应许文兰白月光；毒酒诺言 → 回收主线闻棠收回诺言；故事十三宁折枝 → 接173章新单元

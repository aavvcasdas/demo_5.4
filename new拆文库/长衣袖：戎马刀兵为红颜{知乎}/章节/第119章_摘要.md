## 第119章 变故丛生

**概要**：抵达猎场时天色近晚，秦琏下令休整一夜、明日再猎；因秦氏祖上是马背上打天下的游族，猎场周边不建行宫而以传统房帐为营寨，秋猎盛会众人围着篝火饮酒歌舞热闹到大半夜。秦琏喝了不少酒，刚露微醺便沉叱住要溜走的秦不祥，仰头饮尽一樽酒后扣杯命她过来，随即一把将她拽进怀里，眯着眼口齿不清地控诉「我讨厌你，最讨厌你了」。他半倚着她往房帐走时踉跄了一下，随即像不认识她似的问「你……谁」，端详后眼中浮起恼怒与怨怼，一把推开她并反复缠问「你是谁」，一声比一声逼切，终至大吼。众臣之前如此纠扯不成体统，她面色冷凝地严厉慑视他，像他小时候闹脾气那般，他暴虐之气顿消、垂眸委屈却乖顺下来；她轻唤一声「琏儿」，他眸光骤缩、眼角凝泪却固执不肯落下，仍执拗追问到几近哀求。她只得凑近他耳边哄说人多、回去悄悄告诉他，他果然被「乖」字安抚，还认真确认她叫的是琏儿不是琮儿，笑说自己很乖，随后朝前一栽倒地。他一倒，她立刻被侍卫捆成粽子堵嘴丢进帐监、罪名谋害陛下；后半夜先有人兜头泼一桶冰水再塞药丸，她咬了对方虎口反被威胁，接着持短刀者、持白绫者接连进帐，白绫套颈猛抽险些将她勒死。危急时鹅梨香拂过，解语花现身卡住那人脖子一举而起，面色冷峻如玉面罗刹；她急忙吐出布塞喊别杀，想留活口审出幕后主使，并先求松绑，解语花怒气顿散、一脚踹在那人腿弯上使他跪地难起。

**关键事件**：
1. 秋猎夜宴上秦琏醉酒拽她入怀，先说「我讨厌你」又反复缠问「你是谁」，被她一声「琏儿」与哄孩子的语气安抚。
2. 秦琏笑着说完「我很乖的」便栽倒在地，她随即以谋害陛下之罪被捆入帐监。
3. 帐监中先后进来泼冰水塞药者、持短刀者与持白绫者三批人要她的命。
4. 解语花及时赶到卡住勒颈者，她喊停要留活口审问，并让他先给自己松绑。

**逐章写法公式**：

- **情绪流向**：起：夜宴热闹中的暗流（轻松） → 承：醉酒缠问「你是谁」（紧张） → 转：栽倒入狱、三批杀手轮番（紧张） → 合：解语花现身救人（爽）
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：夜宴醉酒起衅（加压） + 「你是谁」的反复缠问与一声琏儿收服（情感暗线） + 栽倒后被捆入狱（横祸） + 三批杀手与解语花救场（释放）
- **本章核心技巧**：把「你是谁」这句最短的问句用三遍递进推出最大张力——疑惑、推开、大吼，同一句话承载了失忆、怨怼与隐秘痛苦三层含义
- **卡点与伏笔**：结尾卡点：解语花已踹跪勒颈者，三人活着待审，下章从他们口中挖出幕后主使；埋设/回收伏笔：秦琏醉酒认不出她 → 后续身份认知线；「琮儿」被拿来与「琏儿」对照 → 兄弟关系线；鹅梨香 → 解语花的标识；薄妃宫女持刀是来救她 → 下章反转

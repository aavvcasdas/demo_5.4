## 第146章 暗流涌动

**概要**：墨晴动身后，贤亲王一边思忖下一步一边警惕——若蓝依听信了永定王的谗言，他们就少一分胜算，而皇上虽多年不理政事却并非昏庸无能之辈，还需多加忌惮。墨晴早早赶到四人相约的老地方，却迟迟不见人影，只好去蝶影师傅陵墓前等，一等就是三天，直到忌日当天仍不见踪影。她正要离开，紫竹和碧婼才急急忙忙奔来，两人抱着她哭说以为你遇到了不测，随后道出原委：她们刚到两天就有人跑到客栈报信，说墨晴和蓝依在半路遇到了意外，二人找了许久只寻回墨晴，蓝依至今下落不明。墨晴断定蓝依真的出事了，永定王显然是利用了她们之间的感情对她下手，四人便分头去找，边走边听墨晴叙述这事的来龙去脉；紫竹和碧婼听后又惊又怒，碧婼问起婉儿，墨晴说已一月未见、想来日子也不会好过。最后她们仍回墓前等，一直等到天黑才看见蓝依的身影——脸色苍白、衣衫凌乱、神情木讷，蹲在地上只顾哭泣。墨晴问是不是永定王做的，蓝依一听这三个字眼睛通红，说出我恨他、他怎么能这么对我。墨晴抱住她说明天就一起回天朝帮婉儿、无论如何也要把永定王整垮，心里则狠狠诅咒着这个被自己瞎了眼错信了十二年的人，并决定回天朝第一件事就是给曾逸晨一个交代。穿插其间的是蓝依的自述：将门之女，自幼在宫中伴皇子读书，因貌美才高拒了数门亲事，心里早已钟情六皇子；十六岁那年爹爹因大皇子之事被满门抄斩，她靠已是皇帝的六皇子求情才免死，却被太后暗中卖入偏远官妓楼，从鞭打到被摆上台叫价，最后被广宁知府的二公子以八十两买下。就在她认命之际，楼里来了个来头更大的爷——大皇子当场让二公子割爱，以二百两为她赎身，只说一句你已经是自由身了、走得远远的再也不要回来便头也不回地走了；她无处可去一路跟着，被安排在蝶影师傅门下学画，也由此认识了墨晴她们。直到这一回被永定王毁掉，她才幡然悔悟：其实皇上从未忘过自己，是自己钻了牛角尖，十二年前被骗离皇宫时就该看穿这场阴谋。宫里的婉儿则每天如坐针毡，妊娠反应已经出现却不敢让太医诊治，只把对贤亲王的思念硬压下去；她收到墨晴的来信说三位师傅一同前来，第一时间通知了曾逸晨，曾逸晨赶进宫中谢恩并承诺听凭差遣，随后被她留在宫中暂住。初春乍暖还寒，马车越近皇宫蓝依越觉得自己没脸见人，只求姐妹们将来不要把这件事告诉任何人、尤其是皇上。玉宁宫外婉儿与曾逸晨相迎，墨晴趁人不注意给紫竹她们递了个眼色，碧婼这才回过神来寒暄；进殿时墨晴偷瞥曾逸晨一眼，被他完整无误地捕捉到，羞赧地快步走进内殿。

**关键事件**：
1. 蓝依在赴约路上失踪，最终以衣衫凌乱、神情木讷的模样独自出现在蝶影师傅墓前。
2. 蓝依的自述揭开她从将门之女到官妓楼再到蝶影门下的全部过往。
3. 墨晴断定是永定王所为，四人决议一同回天朝联手整垮他。
4. 婉儿妊娠反应已现却不敢请医，并把墨晴回来的消息通知了曾逸晨。
5. 四人入宫，蓝依立下绝不把此事告知皇上的请求。

**逐章写法公式**：

- **情绪流向**：起：久候不至的焦虑（紧张） → 承：蓝依归来与真相的痛（悲伤） → 转：自述揭开十二年的旧伤（压抑） → 合：入宫与封口的决定（紧张）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：久候与失踪（加压） + 归来的一眼与指认（爆点） + 长段自述（补旧伤） + 入宫与封口（埋新雷）
- **本章核心技巧**：把最惨的一段过往交给当事人以第一人称娓娓道来——读者先看到伤后的样子，再听她讲伤是怎么来的，痛感因此被放大一倍
- **卡点与伏笔**：结尾卡点：四人已经入宫而婉儿尚未得知蓝依的遭遇，以她的性格一旦知情绝不肯罢休；埋设/回收伏笔：绝不告诉皇上 → 蓝依与皇上重逢的定时雷；蓝依回归 → 请回蓝依以加大胜算；曾逸晨入宫 → 人脉与头脑加入；妊娠反应 → 身孕瞒不住的倒计时

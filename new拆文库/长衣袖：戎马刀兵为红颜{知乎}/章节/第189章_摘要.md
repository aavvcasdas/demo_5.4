## 第189章 愁予

**概要**：卫良娣雯楚昨夜刚被太子刘骜召去侍寝、抬进乾宁殿，今晨却因哭肿了眼破了例，迟到皇后处的晨会。众女眷纷纷侧目，魏良媛以她入宫刚得宠便摆架子冷嘲，班少使亦以「可喜可贺」的酸话讥讽，碧云恨得攥拳，太子妃许娥与素无交情的俪良媛却先后替她解围。正说着，内侍高传太子手谕：奉皇上特许，升良娣卫氏为从二品、赐号「幽兰君」、赐居粹安殿，并赏下首饰锦衣——这打破大汉朝开国以来无妾室获赐号的先例，满殿错愕。皇后王政君恰在此时进殿，不由分说喝斥雯楚教唆太子坏祖宗规矩，魏良媛再进谗言，班少使则一句看似寻常的话挑拨雯楚与太子妃的关系。雯楚深知皇后本就不喜自己，索性低眉认错，许娥求情，皇后罚她一个月不得入乾宁殿、罚俸三月。风波次日，俪良媛亲来普元殿送饭，点破太子将她安置在离乾宁殿最近的粹安殿是为就近护她；又自曝本家姓原、小名素俪，其母是已故长沙王的亲姑母，自己竟是长沙郡主的表姑，更惊告：长沙王遗孤在长安一事，太子清楚、皇上亦有所耳闻。雯楚顿感后背发凉，惊觉自己已一步步落入别人布好的棋局，头一回恶意揣测起步步高升的陈怀之，也头一回后悔踏上这条路。

**关键事件**：
1. 雯楚侍寝次日迟到晨会，遭魏良媛、班少使讥讽，许娥与俪良媛解围。
2. 太子手谕破例升卫良娣为从二品、赐号「幽兰君」、赐居粹安殿。
3. 皇后王政君借机问罪，魏良媛进谗、班少使暗中挑拨，雯楚俯首认错被罚禁入乾宁殿一月。
4. 俪良媛夜访送饭，点破粹安殿近便护人的用意，并自曝原姓身世。
5. 俪良媛直言太子与皇上皆知长沙王遗孤在长安，雯楚惊惧并疑心陈怀之。

**逐章写法公式**：

- **情绪流向**：起：迟到受嘲的委屈（紧张） → 承：破例晋封的错愕（震撼） → 转：被罚禁足的压抑（压抑） → 合：身世揭破的惊惧（恐惧）
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 悬念留白 25% / 爽点爆发 15%
- **本章结构公式**：一场晨会（受嘲） + 一道手谕（破例晋封） + 一顿问罪（罚禁足） + 一夜密谈（身世揭破）
- **本章核心技巧**：把「恩宠」与「危机」写在同一章里——越是被破例抬举，越引来嫉妒与问罪，最后用一句闲谈把女主推到棋局中心
- **卡点与伏笔**：结尾卡点：太子与皇上皆知长沙王遗孤在长安，雯楚疑陈怀之是布局者，下一步她会去求证；埋设/回收伏笔：赐号「幽兰君」 → 后文保留此号的晋封；粹安殿近便 → 后文侍寝与护持；原姓素俪与长沙郡主表亲 → 后文毓娈身世线交汇

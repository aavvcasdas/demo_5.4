**概要**：翡蝉与兰风初见天水楼，楼主月庚（母旧友）率江雪、月季迎入，认出恭娘之女、忆正通三年花魁永别而落泪。兰风因举人身份不便入青楼，与翡蝉吻别离去。月庚为翡蝉取名"翡娘"，引见教习江雪、义妹月季，带她穿重重帷幕入奢华后厅，遇头牌芸嫣冷嘲。翡蝉被安二楼背阴小房，次日闻刺史次子陆葭综将至，换生母樱粉直裾下楼时陆已到、芸嫣正起舞《凤求凰》。

- **情绪流向**：起：初入天水楼的惊叹与月庚认亲（暖） → 承：兰风吻别、踏入新世界的孤（怅） → 转：穿帷幕入后厅、芸嫣冷嘲（压） → 合：安顿小房、陆大人将至的悬念（钩）
- **节奏配比**：慢铺垫 50% / 快冲突 15% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：月庚认亲引见（暖） + 兰风吻别入楼（怅） + 穿厅遇芸嫣冷嘲（压） + 安房待陆大人（钩）

- **卡点与伏笔**：结尾卡点：陆葭综已到、芸嫣起舞，翡娘初登场的处境未明，接第77章；埋设/回收伏笔：樱粉直裾（生母遗物） → 再次穿着镇场；芸嫣敌意 → 后续楼内 rivalry

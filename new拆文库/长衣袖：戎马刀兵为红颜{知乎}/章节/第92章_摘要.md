## 第92章 复归别庄

**概要**：云州来的寻卞者竟是陆良澍——卞翡蝉的保护人。他亲赴江州，坦言因亲弟陆葭综之故亏欠卞翡蝉，请她回云州查清谁要杀她。宋及泉见陆良澍惹卞落泪，一把推开他厉声斥责；卞翡蝉却决定随陆良澍回云州。归途陆良澍嘱先去别庄避天水楼，双儿、小筠迎候。双儿不解卞为何去而复返，卞坦言只为一探究竟"谁要杀我"。双儿透露月庚明日将到别庄面谈，并替卞问出"陆葭综可曾爱过我"，又温言劝解：纵使爱过，他这样待你也只会伤人。

**关键事件**：
1. 陆良澍亲赴江州接卞回云州查清追杀真相。
2. 宋及泉护卞、斥陆良澍，卞仍决意随陆回云州。
3. 回别庄双儿迎候，透露月庚将到；双儿代问陆葭综是否爱过卞。

**逐章写法公式**：

- **情绪流向**：起：悬念（云州来者） → 承：软化（陆的歉意与弟控） → 转：决断（随陆回云州） → 合：暖中带刺（别庄双儿、爱过吗）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：陆良澍现身致歉（解前嫌） + 宋护卞斥陆（立新线） + 返别庄避楼（转场景） + 双儿代问爱否（收温情钩）
- **本章核心技巧**：用"保护人亲自追来+新男主护短"双线把女主从绝境拉回，却不给答案、只给"回云州查清"的动作目标。
- **卡点与伏笔**：结尾卡点：情绪型——双儿代问"陆葭综爱过我么"无答，月庚将至，读者期待对峙；埋设/回收伏笔：宋及泉江州离别 → 后文重逢；陆良澍"护你" → 后文持续庇护；双儿"爱过吗" → 后文隐园陆葭综拒纳妾呼应。

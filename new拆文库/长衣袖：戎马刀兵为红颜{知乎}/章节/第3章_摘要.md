## 第3章 今天我进宫了吗？

**概要**：我吐槽盛虞澜劝皇上雨露均沾后又劝他生下三个皇子，随后她死了，而我不确定是不是我杀的，因为父亲也派了很多人去杀她——她率领疆夷军队影响了父亲独揽兵权。父亲此后第一次为我的婚事发愁，说「把你嫁谁就是坑了谁，你自己选一个坑罢」，我借机说喜欢皇上很久了，父亲当即去逼皇上写立后诏书，皇上不理；皇上正为盛虞澜之死绝食到几乎丧命，我把他一直当亲女儿疼的盛虞澜十岁女儿送到他面前，他从此开始进食，并以国丧之礼葬盛虞澜、全国守丧三年禁礼乐嫁娶，包括他自己的大婚。三年后我被从准皇后的位子上挤下，取代我的是盛虞澜刚及笄的女儿百里牧云；父亲怀疑盛虞澜的兵符在她手里，因此同意让痴傻的侄子娶她，但在我父亲入宫逼诏之前，圣旨先下达，聘百里牧云为中宫皇后、封我为淑妃。我去找皇上换封号，先遇到了百里牧云，她有不符年纪的成熟稳重，我便把宫里闹得天翻地覆，把人设从白莲花改成霸王花，以盛气凌人的愚蠢隐藏才智与野心。入宫后我专注打压小皇后与怀崽两件事：小皇后极能忍，我的攻击全部落空；我改攻皇上，假装悔不当初哭诉当年下药之事，反使皇上防范更紧，事后还命人煮了好几碗避子汤。我再次给皇上下药成功，但药因屯放太久而过期失效。

**关键事件**：
1. 盛虞澜死亡，凶手不明（父亲亦曾派人杀她）；父亲首次为我的婚事操心，去逼皇上写立后诏书未果。
2. 我送盛虞澜之女百里牧云入宫劝食，救回绝食的皇上；皇上以国丧之礼葬盛虞澜并守丧三年。
3. 三年后百里牧云被聘为中宫皇后，我被封淑妃；我改立「霸王花」人设，并在入宫后同时打压小皇后与图谋怀孕。
4. 我第二次给皇上下的春药因过期而失效。

**逐章写法公式**：

- **情绪流向**：起：吐槽式好奇（盛虞澜之死与凶手的悬案）→ 承：无语与揪心（父亲的嫁人逻辑、皇上绝食）→ 转：憋屈后振奋（后位被夺、改人设、撩丞相）→ 合：荒诞式的归零（两次下药，第二次因药过期失败）
- **节奏配比**：慢铺垫 52% / 快冲突 16% / 爽点爆发 10% / 悬念留白 22%
- **本章结构公式**：交代盛虞澜之死与被父亲杀害的疑云（承接上章并留悬案） + 父亲逼诏失败与皇上绝食（展示父权与帝权的相持） + 后位被夺、改立霸王花人设、傅丞相表忠（主角重建势能） + 二度下药因过期失败（把小循环归零）
- **本章核心技巧**：完整小循环——「拿到半个目标（入宫）→ 立刻减损（只是淑妃）→ 用新策略填平（改人设、拉丞相）→ 章尾归零（药过期）」，用同一模板在后续章节放大复用
- **卡点与伏笔**：结尾卡点：喜剧式反转型——「我终于成功地给皇上下了药」→「这个药，它没起效」→「这药我屯了太久，它过期了」；埋设/回收伏笔：「我不确定她是不是我杀的」→ 盛虞澜之死成为长期悬案；盛虞澜的兵符下落 → 父亲误判在百里牧云手中，构成本卷后续的权力误判；避子汤无效 → 为主角的生育线留技术性后门

## 第135章 飞来横祸

**概要**：礼部尚书上官洪在朝堂上为含冤的邓将军求情，国舅爷王满以两家交好、人头担保不了江山稳固反驳，皇上震怒斥他暗示朕昏庸听信谗言，满朝文武跪倒齐呼圣明。上官洪仍说臣无话可说但恳请明察，被定以下犯上、执迷不悟、袒护罪臣，明日午时处斩，家产充公、男丁卖身为奴、女子卖身为娼，且不许任何人求情。三日内两位重臣获罪，满朝文武在上官洪的下场里看到自己的未来，百姓眼中的皇上爱民如子却手段残戾。上官洪的妻子与五岁的女儿上官婉儿被分别卖到杭州倚红楼与苏州藏娇阁，从此再未相见。藏娇阁多是清绾，进门须对上墨晴姑娘的对联或即兴赋诗，月末的才艺大比拼为期三天，姑娘们比拼前可许愿、花魁的愿望必定实现，且人人可自主去留；阁主身份成谜，由墨晴代理一切事务，阁中姑娘都是被她救回的苦命人。婉儿被安排在墨晴身边调教，整日不哭不闹却一句话不说，只有睡着时才哭喊爹娘。墨晴谎称知道她娘亲的下落，哄她说学会姐姐们的才艺就能永远和娘亲在一起，婉儿终于开口说想爹娘，又立誓要变强大保护姑姑和姐姐们。七岁时墨晴已教无可教，便在蝶影居士祭日前请来三位同门——琴艺出神入化的紫竹、精通棋艺的碧婼、画技了得的蓝依，以三年为限教婉儿绝艺。婉儿每日只睡三四个时辰，琴棋书画各练两个时辰，只因想早点见到娘亲。十岁生日那天她当场作画、布棋吟诗、抚琴和歌，惊艳众人，生日愿望仍是要见娘亲，墨晴只能答应替她捎信。师傅们离去后馈赠琴谱与赠言，十三岁起墨晴遵阁主之意把她安置在淑雅别院不许露面。两年后一个放晴的日子，十五岁的婉儿在庭院中随木槿的琴音恣情起舞，被一个误入别院的书生少年看呆；木槿厉声驱离少年，他却已将那银铃般的笑声与旋转的身影刻进脑海，发誓不惜代价也要再见她一面。

**关键事件**：
1. 上官洪为邓将军求情触怒皇上，被满门治罪，妻女被分卖至两地妓院。
2. 五岁的婉儿被送入藏娇阁，在墨晴的谎言与守护下开口说话并立誓变强。
3. 七岁起三位师傅以三年为期授艺，十岁生日验收时她作画、布棋吟诗、抚琴和歌惊艳全场。
4. 十三岁后幽居别院两年，十五岁起舞时被误入的少年窥见，木槿驱离少年却拦不住他的执念。

**逐章写法公式**：

- **情绪流向**：起：朝堂获罪的雷霆（紧张） → 承：藏娇阁的庇护与谎言（温馨） → 转：三年苦学与生日验收（期待） → 合：别院起舞被窥与少年执念（紧张）
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：朝堂获罪与家破人亡（立女主处境） + 藏娇阁规矩与开口说话（立庇护所） + 三年学艺与生日验收（成长兑现） + 别院幽居与少年窥舞（立新线钩子）
- **本章核心技巧**：把苦难写成人物的日程表——不写她多刻苦，只写十二个时辰如何被切割，让成长本身成为证据
- **卡点与伏笔**：结尾卡点：少年发誓付出再多代价也要再见她一面，下章看他如何寻来；埋设/回收伏笔：蓝依的吊坠 → 师徒凭证；蝶影师祖的琴谱 → 传承与身份线；阁主的安排 → 婉儿的真实使命；娘亲在杭州倚红楼 → 母女重逢线

## 第118章 幕后赢家

**概要**：秦不祥替秦琏念奏折时发现他批注极简，只回「朕知道了」，大臣拿到的奏折上只有「已阅，不回」四字；她翻到户部侍郎的折子才知赢下红馆与潇湘苑的正是秦琏。她索要这两处旧产，他一句「现在是朕的了」顶回，又说自己从不做赔本生意，她便提出用凌天盟在宫中的暗桩名单、乃至沉桩名单来换。他神色更冷，反问若他想要傅长卿的项上人头她待如何，见她犹豫便摔了折子斥她难舍；她说凌天盟一倒他自会远走、何必赶尽杀绝，他转而问那人离开京都她会不会跟，她立刻表态生是天赢太后、死是天赢死了的太后，在他与那人之间选他，乐得他压不住笑意却偏过身去佯装找折子。她趁热说沉桩名单比两馆有用，他问若他要的不止名单呢，她答「只要你要，只要我有」，他却忽而缓了神色说只是逗她玩儿，并皱眉说不会让她以身犯险；她承认自己缺钱是为结交大臣、收买人脉，他无奈吩咐承安让张良把地契给她，末了握住她后颈警声「不准做傻事」。此后她主动散布自己是御前新宠的流言以立名头，又从镜中觉出自己与薄妃、凉妃、轻妃、浪妃容貌相似，推断秦琏专一喜爱同一类容貌，遂定下「美人苦肉计」，只等围场秋猎这个飞箭无眼的时机。马车上她一路盘算，被秦琏一句「你是算盘精投世吗」当场抓包。

**关键事件**：
1. 秦不祥发现红馆潇湘苑被秦琏赢走，以凌天盟暗桩、沉桩名单换回地契。
2. 两人就傅长卿的去留与她会不会跟人走展开试探，她当面试探性地表态选择秦琏。
3. 她承认缺钱是为结党营私，秦琏无奈交出地契并警告她不准做傻事。
4. 她散布御前盛宠流言，借妃嫔容貌相似推断秦琏的偏好，定下美人苦肉计，只待围场秋猎。

**逐章写法公式**：

- **情绪流向**：起：念奏折的平静（轻松） → 承：两馆归属与名单交易（紧张） → 转：选他还是选傅长卿的试探（甜） → 合：地契到手、计策成型、被抓包（轻松）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 25% / 悬念留白 30%
- **本章结构公式**：念奏折发现两馆易主（信息冲击） + 以名单换地契（交易推进） + 选谁的表态与不准做傻事（关系升温） + 散布流言与定下美人苦肉计（立新目标）
- **本章核心技巧**：把权力交易写成情侣讨价还价——每一次报价都同时是情感试探，让「换东西」和「试心意」在同一段对话里同步推进
- **卡点与伏笔**：结尾卡点：她已在马车上盘算美人苦肉计且被秦琏听出「算盘声」，下章围场秋猎的险境如何发生；埋设/回收伏笔：沉桩名单 → 后文获取情报线；傅长卿是傅丞相侄孙、傅家唯一血脉 → 后续傅家线；妃嫔容貌相似 → 美人苦肉计；围场秋猎 → 下章主场

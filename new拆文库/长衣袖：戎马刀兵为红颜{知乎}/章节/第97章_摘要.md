## 第97章 太子妃变宫女

**概要**：秦琏睁眼质问"要治谁的罪"，秦不祥立刻缩到垂幔后藏身，被点名后装没听见，遭人踹出又照腿窝补了一脚跪倒在地。秦琏认出她是方才哭晕的那个，说她"很有孝心"，随即屏退众人却独独留下她。秦不祥拔腿就走，被他一把攥住手腕拽回，扑进他铁硬的胸膛；他捏住她的下巴迫她抬头，盯着她的眼睛怔了半晌，最后问出的却是"你的眼睛，怎么是三眼皮"。她腹诽未完，肚子先叫，秦琏低低笑出声，随即一把将她压在身下、单手扣住她的手腕，俯在她耳畔说"朕许你在这歇着"，下床后特意吩咐送些和软的吃食。次日秦琏下旨留她在宫中侍奉，对赐婚一事只字未提，太子妃就此变成宫女，秦不祥因猜不透他的心思只敢静观其变。午间一个小太监来传话说召她去湖心亭，她一眼认出那不是秦琏身边的人而是薄妃的宫仆，随即交代薄妃的来历：天赢朝历代皇帝都栽在女人手里，胜武帝秦桀阳为一名与仁圣德太后百里牧云极为相似的民间女子禅位隐居，百里牧云是秦桀阳的嫡养母，只比他大两岁，曾同他上战场、守边防、率兵勤王，最终以死保住他的名声，薨逝时年仅二十。秦桀阳因此不再充后宫、不衍子嗣。朝臣担心秦琏的心理健康，见天儿往后宫塞女人，薄妃刘浅便是其中一个，她把封号"薄"解成"红颜薄命的薄，皇上这是夸我好看"。秦不祥判断薄妃找她，是察觉了秦琏待她不一般、想按惯例打压，而她已多年没被人打压过，竟觉得兴奋。

**关键事件**：
1. 秦不祥被秦琏单独留下，遭强拽压身，以一句"三眼皮"化解相认危机。
2. 秦琏下旨留她在宫中侍奉，赐婚只字不提，太子妃变宫女。
3. 薄妃以湖心亭为名传召，秦不祥识破其宫仆身份并交代薄妃与百里牧云的渊源。

**逐章写法公式**：

- **情绪流向**：起：心虚（皇帝睁眼追问） → 承：紧绷（被留、被拽、被压） → 转：泄气变玩笑（三眼皮、肚子叫） → 合：跃跃欲试（薄妃要来打压）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：垂幔后藏身（逃） + 被拽回压身（逼） + 三眼皮泄压（破） + 降为宫女（转向） + 识破薄妃传召（下章钩子）
- **本章核心技巧**：用"身体距离"写关系——踹、拽、扣腕、压身、耳畔低语，全程没有一个称呼变化，却把暧昧与威胁同时推进。
- **卡点与伏笔**：结尾卡点：新角色型——薄妃在湖心亭设局，读者期待这场"打压"如何落空；埋设/回收伏笔：秦琏盯她的眼睛 → 认亲线未断；留宫侍奉不提赐婚 → 婚约悬念；百里牧云与薄妃相似 → 后文秦桀阳线与薄妃封号成因。

## 第91章 追杀背叛

**概要**：三黑衣人欲杀卞翡蝉，宋及泉忽从后现身，以麻沸散药包点倒三人、捆缚于树，称半个时辰内赶到江州报官便安全。卞翡蝉惊其文弱书生竟身怀药技。掀帘见翠翠面色苍白晕在车内——受惊小产。宋及泉抱翠翠上己车疾驰江州，途中责卞翡蝉不该带孕中翠翠远行；卞翡蝉抢缰称不需施舍，被宋以幽微气息迷晕。醒于江州旅店，宋及泉说翠翠孩子没保住但人无恙，并点破追杀者"十有八九是天水楼楼主"、陆葭综知情却劝阻未成——卞翡蝉如遭雷击："我是被他们放弃了么？"宋及泉欲送她去渊一阁，邵金花护卫阿格姆来接，称昨日攻击者已被官府清理。渊一阁两栋三层小楼连廊、可望钱塘江；邵金花直言"等到了这一天"，说追杀是月庚所派，揭卞翡蝉是恭娘之女，与月庚、邵金花皆曾共历生死为同僚，欲知母亲事须离开云州入渊一阁，并说卞翡蝉身负"使命"。卞翡蝉回旅店，宋及泉问母亲事，卞翡蝉反问宋是梁国还是江夏国人，宋答梁国；卞翡蝉身为江夏遗民顿生隔阂。邵金花许赎身条件：参加花魁大赛。卞翡蝉决意先回云州查清谁要她命。翠翠房中，宋及泉说有云州来人寻卞翡蝉。

**关键事件**：
1. 宋及泉麻沸散退敌、救小产翠翠，揭追杀疑为月庚、陆葭综知情。
2. 渊一阁邵金花认卞翡蝉为恭娘之女，许赎身但要其参赛花魁。
3. 宋及泉身世为梁国人，与江夏遗民卞翡蝉生隔阂；宋告知云州来人寻她。

**逐章写法公式**：

- **情绪流向**：起：危机（截杀） → 承：解围（宋制敌、翠翠小产） → 转：真相（月庚追杀、身世揭） → 合：悬疑（梁国隔阂、云州来人）
- **节奏配比**：慢铺垫 15% / 快冲突 35% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：宋麻沸散退敌救翠翠（危机解） + 江州醒悟追杀出自月庚（真相落） + 渊一阁邵认亲揭使命（身世升） + 宋梁国身世与云州来人（新悬疑）
- **本章核心技巧**：把"谁要杀我"的答案拆成两层——先由配角点出执行者（月庚），再用渊一阁揭示主角身世，让逃亡自然转为身世探秘。
- **卡点与伏笔**：结尾卡点：悬念型——云州来人是谁（后文揭为陆良澍）；埋设/回收伏笔：麻沸散/宋医术 → 后文救解语花；月庚派杀 → 后文月庚亲认默许；恭娘之女/使命 → 后文凌天盟线呼应；宋梁国身世 → 后文国族立场冲突。

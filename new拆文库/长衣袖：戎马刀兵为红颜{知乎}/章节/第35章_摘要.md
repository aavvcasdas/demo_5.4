## 第35章 （11）

**概要**：入宫第三个月爹死，半个月后我才接到囚服血书"别哭"。我忆起破茅屋十几年养不起土狗、暗恋李秀才被爹骂、考场交墨被毒打、大黄被毒死爹吼别哭、嫁老王时爹藏水粉胭脂哄别哭；嫁妆在轿上自画，喜娘画的全被黑泪糊成狂躁水墨，掀盖头老王吓死、京中笑丑妻。问送信人老王如何，说他在牢里堆土包一日三拜、分食上坟。我小跑进御书房拜倒求收尸，皇帝笑抬我头："秘方朕早知道，不就是你的泪吗"——我心凉。皇帝秘密成立监察署，不久更名东厂。

**关键事件**：
1. 爹死血书：入宫三月爹死，血书"别哭"，串起父女多年"别哭"记忆。
2. 出嫁回忆：自画嫁妆、黑泪糊面、老王吓死、京中笑丑妻；老王牢中上坟。
3. 求收尸与东厂：求说出秘方换收尸，皇帝早知是泪、心凉；监察署更名东厂。

**逐章写法公式**：

- **情绪流向**：起：爹死血书"别哭"的悲 → 承：多年"别哭"回忆蒙太奇的暖与痛 → 转：出嫁黑泪糊面、老王吓死的搞笑 → 合：求收尸被揭穿、东厂成立的寒意
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 0% / 悬念留白 55%（以回忆与对话推进）
- **本章结构公式**：爹死血书（入宫三月、血书别哭） + 别哭蒙太奇（茅屋、李秀才、考场毒打、大黄、出嫁藏胭脂） + 出嫁回忆（自画嫁妆、黑泪糊面、老王吓死、牢中上坟） + 求收尸（皇帝揭穿、东厂成立）
- **本章核心技巧**：用"别哭"作为贯穿父女情的复调意象，把喜剧化的黑泪出嫁与血书之死并置，痛感翻倍
- **卡点与伏笔**：结尾卡点：寒意型——皇帝早知秘方、东厂成立，读者知主角彻底落入皇权网；埋设/回收伏笔：松香泪墨 → 本章"黑泪糊嫁妆"、皇帝"不就是你的泪"收束其秘密；老王牢中上坟 → 后文老王疯前喊泗水、撞墙之呼应；东厂成立 → 后文主角掌东厂、弑君之线

## 第102章 太子与狗子

**概要**：秦不祥打定主意要救解语花，出刑司后径直去养心殿——秦琏亲自下旨关押，没有他的口谕刑司不可能放人；为表诚意她半路顺了个食盒，到门口才发现是秦琏最不喜欢的点心。殿内秦琏正与太子下棋，她一眼看出两人棋艺毫无长进，随即为"三人行谁该行大礼"纠结——不是皇帝也不是龟孙子，是她，于是一福到底高声道"拜见太子殿下"，把太子吓得差点跳起来。秦琏当场拧眉喝止，随即传下口谕：盛雪依身患隐疾、不便行礼，今后免除诸事礼仪。她由此推断秦琏待自己殊遇，已不止于七品县官之女的分寸。秦琏被她洞悉的眼神看得发恼，问她会不会下棋，又拿"盛家三姑娘无一不精"的传闻讽她，被一句"既是传闻自然不足采信"噎住。太子告退时低声安慰她不必害怕，还许诺会再劝父皇、婚约之事非她之过，她反倒同情起这位连老婆都没有就要看老婆变祖婆的孙子，劝他世事难料天恩难测。送走太子回来，秦琏已在批阅奏折，她本想借机试探认亲却开不了口，反被他轻叱"怎么去这么久"并唤到跟前。他一把将她扯到腿上圈住腰说"别动"，却只要她喂桂花糕——她随即想起他不吃桂花糕的缘由：当年她疑心糕点有毒，拿琮儿试毒，秦琏认定她偏疼弟弟，从此不碰桂花糕，继位后还砍光了宫里的桂花树。她正要拿糕点，秦琏捏住她的脸扭向自己，黑沉沉的眼牢牢锁着她，她心一横要开口认亲，才齿节微动就被他的指尖点在了唇间。

**关键事件**：
1. 秦不祥为求情携食盒入养心殿，当着太子的面行大礼，秦琏随即下旨免她诸事礼仪。
2. 太子宽慰婚约之事，秦不祥反劝他世事难料，祖孙两代错位成笑点。
3. 秦琏要她喂桂花糕，牵出当年试毒旧事；她欲开口认亲被他以指尖封唇。

**逐章写法公式**：

- **情绪流向**：起：算计（携食盒求情） → 承：错位的恭敬（给孙子行礼） → 转：柔软（太子的善意、桂花糕旧事） → 合：紧绷（被封唇、认亲未出口）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：携盒求情（立目标） + 殿中见太子生错位（笑） + 免礼口谕露偏心（甜） + 送别太子（暖） + 喂糕与封唇（悬）
- **本章核心技巧**：让"救人"这个目标全程悬置——她进了殿、行了礼、喂了糕，却始终没开口，用一连串擦边动作维持张力。
- **卡点与伏笔**：结尾卡点：悬念型——秦琏指尖封住她的唇，读者等他是否接下认亲；埋设/回收伏笔：免行礼口谕 → 身份特殊化的明证；桂花糕旧事 → 解释秦琏的执念；太子许诺再劝父皇 → 婚约线悬念；食盒错拿点心 → 后文桂花糕梗的落点。

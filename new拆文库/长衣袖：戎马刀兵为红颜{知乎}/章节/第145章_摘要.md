## 第145章 收买人心

**概要**：张嬷嬷拿着罂粟花粉走到太后跟前，太后先像见了鬼，随即冷静下来连说嬷嬷你没死真是太好了——她没听出「太后还没死老奴又怎么舍得死」这句话里的别扭，只为身边还有可利用的人而开心。张嬷嬷不等她反应就把药硬灌下去，呛得太后猛咳大骂，她却一口一个娘娘地说自己要为娘娘做些力所能及的事；太后只顾要水，她却说要去向仙皇妃复命，把太后独自留在殿里任她吼叫，听见的只有一句「我就算做鬼也不会放过你」。与此同时婉儿已安排贤亲王暂离皇宫，去边境外援的军队里躲避宫中事宜、暗中收买人心对抗永定王。塞北条件艰苦，贤亲王水土不服病倒，帐外李副将一句「不在宫中享福偏到这穷乡僻壤遭罪」被王将军呵止，却全落进他耳里。他从屈辱里翻身起来连吃三碗凉粥，第二天五更与军士同席喝粥吃咸菜，白天练武骑射、夜里挑灯读兵书，遇到不懂便向李副将请教，久了连这个直性子的副将也认真起来。一个月后他把李副将挑下马，全军鼓掌，他却在那一刻盼着婉儿能在身边分享。收到婉儿的书信，太后已死、皇上卧病不起、她自己已有身孕并催他加快脚步，他既喜又急——孩子绝不能名不正言不顺地出生。他凭武艺兵法在军中建立起威信，人人说他越来越有当年永定王的风范。半营士兵放了三天假，他独自饮酒思念婉儿，被李德全拉去当地有名的飞仙楼避寒。楼里迎客的是个一身白衣的秀丽女子，开口便说改了规矩、只卖艺不卖身，李德全怒吼被他拦下；走近一看，那女子竟是失踪多日的墨晴。他支开李德全要了雅间，直言曾逸晨为找她几乎跑遍天朝、最近还去了藏娇阁所在的地界，劝她逃避永远不是解决的办法。墨晴终于松口，说自己不知该如何面对突然发生的一切；他便以太后已死、王妃出家托孤、若能把蓝依请回来胜算更大来留住她，并在临走前被她叫住问婉儿怎么样，答出一句她很好、只是她怀孕了——墨晴立刻斩钉截铁地说孩子是你的。两人定下初步共识，又议出一条将计就计的法子：墨晴照常去赴蝶影师傅的忌日之约，事先备好书信找机会交给蓝依，赌的是蓝依更信谁。她还答应借飞仙楼的人脉把永定王的阴险与阴谋散播出去。第二天回到军营已是人人愤愤不平，李副将当众表态绝不再让王爷受永定王算计；夜里他再访飞仙楼，听见子爵等人正把那些传闻说得有声有色，墨晴随即走过来挤弄眼睛、高声劝他保重身体，让在座几人当场谢罪愿效犬马之劳。就这样他身边多了子爵、子弦等五位可用之士——而当朝宰相之子，竟是在这苦寒塞外被他遇上的。

**关键事件**：
1. 张嬷嬷假意复命，把罂粟粉灌进太后嘴里并当众撇下她。
2. 贤亲王被派往边军收买人心，从水土不服的病号练成挑落副将的将领。
3. 婉儿来信告知太后已死、皇上卧病、自己已有身孕。
4. 在飞仙楼偶遇墨晴，二人定下联手的初步共识与将计就计的法子。
5. 借飞仙楼散播永定王的阴谋，贤亲王顺势收下子爵等五位谋士。

**逐章写法公式**：

- **情绪流向**：起：灌药与无人理会的冷（爽） → 承：从屈辱到立足的燃（热血） → 转：书信带来的惊喜与焦急（紧张） → 合：偶遇结盟与收拢人心的稳（期待）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 30% / 悬念留白 25%
- **本章结构公式**：假复命灌药（断太后最后一臂） + 边军立足（换一条成长线） + 一封书信（推进新危机） + 楼中偶遇与散播（结成同盟）
- **本章核心技巧**：用一条明线（收买人心）串起两条暗线——同一批人既被他练兵服气，又被楼中传闻扭转立场，人心是被两件事同时买下的
- **卡点与伏笔**：结尾卡点：墨晴已动身去赴蝶影师傅的忌日之约，永定王可能先一步埋伏，蓝依到底信谁尚无定数；埋设/回收伏笔：将计就计的书信 → 蓝依倒向哪边；婉儿身孕 → 孩子不能名不正言不顺；子爵与子弦是宰相之子 → 朝中人脉；墨晴答应回宫 → 婉儿身边重新有人

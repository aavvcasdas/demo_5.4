## 第106章 死路就在前方

**概要**：回宫路上秦不祥越想越沉，得出一个更糟的结论：秦琏既不是认出了她，也不是看上了她，而是想色诱盛雪依——堂堂一国之君用上美男计还没成功。她自问不过是出宫扫个墓，回来就成了被识破身份的反动分子；眼下两种可能一九开，弄好是九族升迁、弄不好是九族升天，而她这个被追影亲眼看见与傅长卿接头的凌天盟少主，此刻说自己是皇帝的妈，连她自己都不信。正怀疑人生时追影"嘭"地从车窗蹿进来，她以为来了灭口密令，脑中播放一千零一种死法，结果他只说"外面下雨了，躲躲"。她忍不住怼他练金钟罩还怕下雨，他一本正经分辩金钟罩不是铁布衫，还笑她没文化、滔滔不绝要给她讲凌云腿纵云梯，她牙咬得咯咯响却打不过他。心思转回秦琏，她越想越无解：他六岁就能溺毙胞弟、又装傻近十年，登基后杀伐决断，别说盛雪依，连自己在夏天死于风寒都未必不是他的手笔；可转念又想不过是吵吵嘴，他还不至于痛下杀手——不对她动手，却未必放过盛雪依。追影看她愁眉苦脸说她看起来好委屈，她说自己只是未知选项太多、题太难不会做，最后决定破釜沉舟以力破巧：猜累了，只想让他知道。还没进宫就得消息说有人趁她出宫时入宫行刺，她觉得这也太会挑时间，就差在她脸上写卧底二字。在崇政殿门口她腿软得迈不开步，追影问怎么不进去，她心里连喊傅长卿快来救我，却听见秦琏在殿内低沉沉地说"进来"。她抬步向前，佯装抚发把簪子拢进袖中，想着他若敢下令处死她、她就让他先死在她前边，又盼着在场的凌天盟暗桩能救她一命；转念又想他既肯召见局面或许没那么糟，只要他肯听她讲鬼故事，她就有把握让他信了她的鬼话。进殿后她立马怂了，决定先礼后兵、先糖后炮，殷勤奉茶时被秦琏一把擒住腕子，他掌宽指长、温度炽热，她生怕袖中簪子暴露，只听他神色冷峻地问："你就没有什么话，想对朕解释？"

**关键事件**：
1. 秦不祥推翻前判：秦琏是色诱盛雪依，自己成了被识破身份的少主。
2. 追影躲雨闹剧，随后她推想秦琏可能连自己的死都脱不了干系。
3. 有人趁她出宫入宫行刺，时机直指她是内应。
4. 她藏簪入殿奉茶，被秦琏擒腕质问要她解释。

**逐章写法公式**：

- **情绪流向**：起：发凉（色诱说、九族升天） → 承：插科打诨（追影躲雨、嘴碎） → 转：腿软（行刺消息、迈不开步） → 合：对峙（藏簪入殿、被擒腕质问）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：车内推翻判断（压） + 追影躲雨闹剧（松） + 推想反派之狠（紧） + 行刺消息与殿前腿软（急） + 藏簪入殿被擒腕（爆点前置）
- **本章核心技巧**：让"进殿"这个动作被无限拉长——腿软、藏簪、盼救兵、自我打气，五段心理把一个走路的动作写成一场战役。
- **卡点与伏笔**：结尾卡点：对峙型——秦琏问"你就没有什么话想对朕解释"，读者等她开口认亲；埋设/回收伏笔：入宫行刺 → 后文追查内应的线索；袖中簪子 → 后文被他识破的伏笔；凌天盟宫内暗桩 → 后文接应；夏天死于风寒 → 死因悬案再提。

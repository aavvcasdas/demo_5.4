## 第191章 猗嗟

**概要**：正月未过完，汉元帝骤然离世，上元节的红灯笼还未来得及摘，便在大雪中换成白纸灯笼。雯楚敬元帝如父，守丧那夜哭得伤心；定陶恭王生母傅昭仪亦真哭——她与皇后王政君同入宫，却因产子晚屈居其下，元帝一去便失了庇佑。国丧后刘骜登基为汉成帝：许娥封皇后居椒房殿，魏良媛为魏昭仪居昭阳殿，俪良媛为俪昭仪居增成殿，雯楚封卫婕妤居披香殿并保留「幽兰君」赐号，班少使为班美人居安处殿——班令曦怨恨赋诗传咏。卫府在京郊避寒，吟梅堂只余毓娈一人，因国丧三月不得办婚礼，嫁殷府推迟到四月。毓娈又发痧，卫南风冒雪来，被她隔着床帐冷拒，却抓住她的手辩白与温家小姐合蘼「什么都没有、是父亲的意思」。毓娈冷讽合蘼既愿、父亲何来提亲，南风握她冰冷双手柔情相对，她却大恸：纵你不娶温家又与我何干，我早已应了殷家！南风悄然而去，说后日是雯儿册封礼。落霞随后探出那傅甘棠原是绣红坊歌妓、卖艺不卖身，更闻陈怀之从去年夏天便常出入绣红坊——正是选秀正酣时。毓娈朗声大笑：原来雯儿不过成了人家手中棋子，一片痴心错付！二月雪未消，她入宫贺刘骜登基，在椒房殿外迷了路踱向偏殿，庭院忽无宫人，钟响她急急往回走却转晕了，被一瞪目侍卫喝问，那侍卫竟哈哈大笑。

**关键事件**：
1. 汉元帝骤崩，刘骜登基，后宫大封：许娥为后、魏俪封昭仪、雯楚封卫婕妤、班令曦为班美人。
2. 毓娈因国丧推迟婚期，与冒雪来的卫南风隔帐争执、终知温家小姐名合蘼。
3. 落霞查实傅甘棠是绣红坊歌妓，陈怀之去年夏天起常出入勾栏——选秀时便已负心。
4. 毓娈入宫贺登基，在椒房殿外迷路误入空庭，撞见一瞪目侍卫（后揭为刘骜）。
5. 班令曦失宠怨愤赋诗，暗线铺后宫争宠。

**逐章写法公式**：

- **情绪流向**：起：元帝崩的悲凉（悲凉） → 承：册封与南风争执的压抑（压抑） → 转：甘棠真相的愤怒（愤怒） → 合：迷路遇侍卫的悬疑（悬疑）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 悬念留白 30% / 爽点爆发 15%
- **本章结构公式**：一场国丧（朝代换） + 一道册封（位分定） + 一幕隔帐（南风辩） + 一桩揭底（甘棠歌妓） + 一遭迷路（遇刘骜伏笔）
- **本章核心技巧**：用「时间差」制造痛感——选秀正酣时陈怀之已在勾栏，让读者与毓娈同时「迟到地」获悉背叛；再用迷路把毓娈推到刘骜面前却不点破
- **卡点与伏笔**：结尾卡点：瞪目侍卫大笑不语，其身份留至下章揭为刘骜，毓娈将与他正面相对；埋设/回收伏笔：元帝崩 → 刘骜正式上位；保留幽兰君赐号 → 后文沿用；甘棠歌妓 → 后文再议；册封礼 → 后文雯楚见毓娈

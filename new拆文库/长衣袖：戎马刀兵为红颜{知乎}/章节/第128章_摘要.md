## 第128章 国师

**概要**：秦不祥睁眼发现自己被打晕后绑了起来，先以为是秦琏得不到便囚禁她，随即听到傅长卿在外与争执，本以为他是替她出头，越听越惊悚——抓她的正是他，外间那个劝他回头是岸的人也是他掳来的。他走到床前毫无感情地问「醒了」，手掌覆上她的脸颊、冰冷的唇瓣几乎贴上她的耳廓戳穿她装晕，她只得切回盛雪依模式佯装惊讶叫他傅哥哥。他语色沉冷如冰针扎耳，说她不希望自己在这儿却还是落到了他手里，眉目锐利、眸光含着出鞘寒刀般的煞气；她一边示弱拖延一边打量，认出这是内外两间的暗室，外间还绑着一人。他捏住她的脖颈要她好好配合，她才示弱叫一声傅哥哥，他便踢翻椅子厉喝不许这么叫，指节死死掐住她的气管，咬牙骂出「你这个鸠占鹊巢的孤、魂、野、鬼」。前有凉妃下毒、后有宁国府勒颈，如今连傅长卿也要杀她，她自嘲重生了个靶子、伪装了个寂寞。他的手越收越紧，她喘不上气只能泫然落泪，泪溅在他手背上，他像被灼到般松手、震诧无措地唤了声雪儿，她连忙咳着点头承认自己就是雪儿。他端详片刻又冷下脸，说爱人换了魂自己怎会察觉不出，并给出理由——因为你不爱我；经他与她一番争论，他承认人可能变心却不可能一朝一夕变了性格。他说要让雪儿回来，她说盛雪依阳寿已尽、大概已投胎，他猩红着眼反驳她比盛雪依先死都没投胎，她无奈说那你行你上啊。他便把国师拎到她面前；她趁他出去摔碎茶壶藏下瓷片，却因他耳力过人被搜走一块，好在还藏了不止一块，随即一边割绳一边听他与国师扯皮。国师容貌清潇却性子傲娇不肯配合，一头乌发几乎全白；她认出他正是当年追着她算命、被她揍过扔郊外的算命先生——他入宫后逼她祈福祭天、禁足念佛、常年茹素，还总拿天意命理压她，她不能明着揍他，便指使人在拐角小巷给他套麻袋，看他鼻青脸肿来见她时连菜叶子都香甜。

**关键事件**：
1. 她醒来发现自己被傅长卿绑在暗室，外间还绑着一个劝他回头是岸的人。
2. 傅长卿识破她装晕并掐住她脖子，骂她鸠占鹊巢的孤魂野鬼，却在她落泪时松手唤雪儿。
3. 他说要让盛雪依回来，两人就变心与换魂争论，她让他「你行你上」。
4. 他把国师拎来做法，她藏下碎瓷片割绳，并认出国师是当年被她揍过的算命先生。

**逐章写法公式**：

- **情绪流向**：起：醒觉被绑的惊疑（紧张） → 承：掐颈与孤魂野鬼的指控（紧张） → 转：落泪松手与换魂之争（压抑） → 合：国师登场与旧怨回溯（轻松）
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：醒觉被绑与真相反转（加压） + 掐颈指控与落泪松手（拉锯） + 换魂之争与「你行你上」（立目标） + 国师登场与旧怨（缓释与新钩子）
- **本章核心技巧**：用「认错绑匪」延后真相——先让主角按惯性把账算在皇帝头上，再用一段偷听把真凶翻出来，让惊悚感多一层转折
- **卡点与伏笔**：结尾卡点：国师被拎来做法，她正割绳伺机脱身，下章仪式与逃亡齐发；埋设/回收伏笔：傅长卿识破她换魂 → 后续追杀线；国师曾施展转魂咒 → 下章真相；满头银发 → 启用禁术折寿；套麻袋旧怨 → 两人关系线

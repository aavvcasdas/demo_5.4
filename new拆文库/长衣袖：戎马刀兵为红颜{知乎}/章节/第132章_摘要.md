## 第132章 花灯

**概要**：华灯初上的花灯节夜市热闹非常，秦不祥趁傅寒池给糖葫芦付账，从对面摊位拿了张鬼面獠牙的面具覆在脸上，拍他肩膀后大叫着凑近吓了他一跳，摘下面具哈哈大笑；他缓过神嗔怪地点她鼻尖，实则已偷偷蘸了香粉抹在她脸上，惹得她连打喷嚏。她拿过香粉盒朝他吹去，两人闹作一团，最终都满头满脸白粉、相视大笑，末了还得赔人家的面具与香粉钱。路过算命小摊，算命先生招呼她求姻缘上上签，她雀跃地说自己才七岁也能求吗，傅寒池已掏银子拍在摊上；她摇出的卦签让算命先生连称奇怪却只答「佛曰不可说」，被她嚷着退钱后才又给了一张解惑签，上书「春雨绵绵，一木成林」，她一眼认出是个秦字，想着秦是国姓又是姻缘签岂不是嫁自己，便卷巴卷巴丢回去说一点都不准，拉着傅寒池离开，没注意他变了的脸色。两人在花灯集前看灯，她指着正中心的凤凰灯说要最大的那个，灯主说那是今年的彩头、须连解两层谜面。傅寒池先解出左边灯谜的「秋」字，她抢答右边灯谜是「花」字却被告知须以另一谜面对上，他略略思索答「萤火虫」，灯主一句「腐草为萤」点破——腐草化为萤火虫，一草一化正是花字。凤凰灯前的谜面随后放下：一人腰上挂把弓，无言，灯主提醒谜底是一个字且只有一次机会；她推想出一「夷」字却觉「无言」多余，傅寒池思忖后拿起角落的弓箭朝凤凰灯射去，纵身一跃在空中接住落下的花灯，落地后答「秋花为谢，无言为射，自然该以弓击之」，灯主赞他好文采并请他题字，她说既然是你送我的自然看你。他题字时她被酸枣糕吸引走开，一群穿戏服的人涌来将两人冲散，她被裹挟着走到护城河边才脱身，望着漆黑的河面正自空茫，一个黑衣人突然出现拽住她的手说带她去找兄长。走了几步她发现并非回摄政王府的路，便蹲下装肚子痛，趁他俯身查看时把香粉撒向他的眼睛，转身狂奔却被扑倒掐住脖子；慌乱中她摸到一块砖头砸中他的脑门，他栽倒在她身边，她喘息着看着他的血汩汩流出、染红了自己的衣服与双手，忽然想起这样多的血她曾见过。

**关键事件**：
1. 花灯节上两人互相恶作剧、撒香粉闹作一团。
2. 算命摊上求得解惑签「春雨绵绵，一木成林」，她认出是秦字却嫌不准丢还。
3. 连解三层灯谜赢下凤凰灯，傅寒池以弓射灯并题字。
4. 她被人群冲散后遭黑衣人诱拐，用香粉与砖头脱险，看着满手鲜血忆起旧事。

**逐章写法公式**：

- **情绪流向**：起：灯会恶作剧的欢闹（轻松） → 承：求签与解谜的智斗（爽） → 转：走散与被诱拐（紧张） → 合：砖头反击与满手鲜血（紧张）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：灯会恶作剧（情感升温） + 求签与三层灯谜（智斗与伏笔） + 人群冲散与黑衣诱拐（危机） + 香粉砖头反击与血的记忆（绝境与回响）
- **本章核心技巧**：把灯谜做成情感暗码——秋、花、萤火虫三层谜面最终指向他题在灯上的字，让一场智斗同时完成定情与伏笔
- **卡点与伏笔**：结尾卡点：她满手是血地想起旧事，下章揭这段记忆的来处；埋设/回收伏笔：「春雨绵绵，一木成林」 → 秦字与姻缘线；凤凰灯题字 → 下章揭示的「恙」字；黑衣人 → 诱拐与追杀线；满手的血 → 七岁旧事

## 第187章 弗及

**概要**：本章写陈怀之与雯楚的角门告别、雯楚入宫后的冷遇与太子突至。陈怀之在西角门站了半晌，雯楚终来——比上善寺时更清瘦，明眸折射不出光。她说"本不打算来，只是毓儿说得对，有些话当面说清"，陈怀之慌忙解释，雯楚抬头泪涌，强镇定道"去选秀非为你、为家族为自己；若想获取好处别找我，此生不想往来"，泪流满面。陈怀之忆她从小爱哭抓袍角，觉对她的感情不是真爱只是责任；他要的是独立不依附的女子，前程重于儿女私情。他抱她入怀，下巴搭肩忧伤，叹"是我对不起你，请忘了我罢"，松手头也不回走。雯楚转身眼珠空洞——告别如仪式带离最初的天真。入夜宫门下钥，普元殿东宫西北角寂寥，雯楚水红薄纱寝衣抚琴，碧云撒安枕香。入宫五日，太子妃许娥、少使班令曦已侍寝，她独未召。太子刘骜突至，命她"弹一曲最拿手的"，鸣鼓阴阳怪气"不过略坐，班少使焚香候着哪轮普元殿"，碧云泪模糊。

**关键事件**：
1. 西角门陈怀之等雯楚，雯楚来明言"去选秀非为你为家族为自己，此生不想往来"。
2. 陈怀之抱她入怀说"是我对不起你，请忘了我"，松手头也不回走；雯楚眼空洞，告别如仪式。
3. 入宫五日雯楚普元殿抚琴，碧云撒安枕香；太子妃许娥、班令曦已侍寝，她独未召。
4. 太子刘骜突至普元殿，命她弹琴，鸣鼓说"不过略坐、班少使候着"，碧云泪模糊。

**逐章写法公式**：

- **情绪流向**：起：角门明言的凉（凉） → 承：抱憾忘我的悲（悲） → 转：入宫孤寂的揪（揪） → 合：太子突至的闷（闷）
- **节奏配比**：角门告别 40% / 入宫铺陈 20% / 冷遇对比 20% / 太子突至 20%
- **本章结构公式**：一角门等（写别） + 一抱忘我（写放） + 一殿孤琴（写寂） + 一驾突至（写压）
- **本章核心技巧**：把"男主退场"与"男二登场"放在一章首尾——读者刚送走渣男，立刻迎来更冷的宫墙
- **卡点与伏笔**：卡点：太子只令弹琴未侍寝，埋下普元殿无人夜的孤与后续；埋设/回收：毓儿说得对 → 接186章毓娈劝见陈怀之；鸣鼓 → 接188章宫中规矩；许娥班令曦侍寝 → 接186章夺魁少使兑现

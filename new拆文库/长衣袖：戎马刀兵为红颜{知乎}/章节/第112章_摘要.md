## 第112章 弄巧成拙

**概要**：刺客搀着伤者撤退，秦不祥正要叫侍卫追击，解语花却身形一踉跄倒了下去。她扶着他跪地按住伤口，血仍汩汩涌出，烫得几乎灼穿掌心；傅长卿上前点住他的心脉大穴后去传太医，她这才发觉自己的手抖得不成样子，生平第一次生出了后悔。解语花看透她的仓惶，虚弱地说"别慌，你做得很好"，话未说完便面色一变，横臂将她勾进怀里旋身一转，堪堪躲过身后宫女刺来的匕首，滚撞数圈仍牢牢护着她；那宫女再扑时，被逐月一脚踹在腰眼撞上山石昏死过去。秦琏一把将她拽起，面色如焚地追问伤到没有，又攥住她不许她走，非要查看她身上的血迹；此时追影扶起解语花，他脸色惨白、哇地呕出一大口血，她心里猛地拧紧，挣不开秦琏的铁掌，焦灼之下抬手一掌挥在他身上。他闷哼后退，眼中满是受伤与震惊，她顾不上他，只扑过去压紧解语花血流如注的伤口、连喊太医。他轻拍她的手说别担心，她胸口发闷地说"我不会让你有事的"；他望着她陷入回忆，说姐姐去时他就想若能替她受难该有多好，如今至少得偿所愿、死也无憾，被她厉声喝止。他吃力接住她落下的一滴泪，说"你一哭，我的心比伤口还疼"，她忍着酸楚让他别离开，最后急得拿婚约逼他——"你说过要娶我的，你得说话算话"，他回握住她的手低低应了"说话算话"。太医说剑伤只偏离心口半寸，能否熬过今晚生死攸关。她守在床边，忽有小石子砸窗，追出去见是傅长卿；他攥着她的手问她如何，又犹豫着问她和解语花何时变得如此亲密，她信口胡诌说是曾在陛下面前为他求过情、他投桃报李。两人相对无言尴尬非常，末了他只说"夜晚风凉，记得多加些衣裳"。她硬着头皮以"傅哥哥"相称嘱他早些回去，心里直呼恶心，他眼睛一亮说"我就知道你是挂念我的"，还要看着她走，她只好几步一回头装作依依不舍。

**关键事件**：
1. 解语花伤重倒地，仍护着她躲过宫女的匕首，被逐月制服刺客。
2. 秦琏拦着她查看伤势，她情急之下挥掌打他，转而全力救护解语花。
3. 二人以婚约相系，太医断言今夜生死攸关。
4. 傅长卿夜会，她以谎言遮掩与解语花的关系，尴尬收场。

**逐章写法公式**：

- **情绪流向**：起：慌乱（他倒下、血涌不止） → 承：焦灼（躲匕首、被拦、挥掌） → 转：酸楚（以婚约相逼、太医断言） → 合：尴尬（夜会傅长卿、谎话收场）
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：伤重倒地（急） + 躲匕首与被拦（乱） + 挥掌与救护（裂） + 婚约相系与太医断言（痛） + 夜会傅长卿（尬）
- **本章核心技巧**：把"救人"与"伤人"放在同一个动作里——她挥向秦琏的那一掌，既是对他的伤害也是对解语花的救护，一掌完成两条关系的转向。
- **卡点与伏笔**：结尾卡点：悬念型——解语花生死未卜、她脚踏多条船的谎话已难维系，读者等下章如何收场；埋设/回收伏笔：剑伤偏离心口半寸 → 生死悬念；她打的那一掌 → 与秦琏关系的新裂痕；撒谎一摞纸 → 后文穿帮风险；行刺的宫女 → 宫内暗桩浮出水面。

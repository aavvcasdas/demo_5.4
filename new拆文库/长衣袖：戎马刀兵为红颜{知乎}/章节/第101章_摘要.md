## 第101章 你为什么不看朕？

**概要**：秦不祥刚开口露出要救解语花的意思，秦琏便沉下脸，眼中像燃了两团火，说让朕放掉这些低贱的娈宠想都别想，还挑衅道既然他最善解人意、去地下陪着母后岂不正好。她还要再说，秦琏猛地将桌案扫落，杯盏碎了一地，狠狠瞧她一眼抬腿就走。承安为难地告诉她，皇上之前还特意下旨不准陪葬，昨儿却突然改了主意。她推断秦琏是知道她还活着，才诚心要坏她的姻缘，又想起上辈子他百般阻挠她养面首、还拿她与百里牧云相比——百里牧云不养是因为有秦桀阳这个"面首"，而他们并非亲生；秦琏明明也能，她却觉得这事儿不行。秦琏厉声催她跟上，她走过灵堂时忍不住看向解语花，他正要起身却在四目相投时一顿、目光微闪又跪了回去，那眼神让她觉得异样。秦琏折回来一把拽着她出了宫门，气急败坏地质问"朕就在你眼前，你还敢看别的男人"，又追问"你怎么不看朕？难道朕没他好看"。她表面把好话说得诚恳真挚，他却更恼怒，突然扬声命承安把解语花关进刑司。她奇怪解语花明日就要殉葬，按礼制该留几分体面，哪有断头饭里掺刀片的道理；秦琏却咬牙说"你休想对他好"，随即拂袖而去。她踢飞脚边的石子，想起上辈子最后一个月两人日日争吵，自己临终前特意营造温馨假象，只因笃定淳厚的琮儿会饶解语花一命，没想到活下来的是凉薄的琏儿，话没出口先被气死。她凭近身女官的身份轻易进了刑司，看见解语花被绑在刑架上、鞭痕遍布，他在昏昧中一遍遍呜咽着"姐姐救我"，她心里像扎进一根刺。

**关键事件**：
1. 秦不祥为解语花求情，秦琏当场翻脸扫落桌案，并改旨将其打入刑司。
2. 秦琏因她看解语花而大发雷霆，追问"你怎么不看朕"。
3. 秦不祥在刑司见到遍体鳞伤、昏昧中唤姐姐的解语花。

**逐章写法公式**：

- **情绪流向**：起：交锋（求情被驳） → 承：暴怒（扫案、改旨、刑司） → 转：回望（临终假象与琏儿的凉薄） → 合：刺痛（地牢中的呢喃）
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：求情被拒（爆） + 灵堂对视生疑（疑） + 宫门外质问"不看朕"（醋） + 下旨入刑司（狠） + 地牢见伤（痛）
- **本章核心技巧**：全章用一个"看"字串起冲突——她看解语花、他不许她看、他追问为什么不看他，视线归属即情感归属。
- **卡点与伏笔**：结尾卡点：情绪型——解语花在昏昧中一遍遍唤姐姐，读者等她如何相认施救；埋设/回收伏笔：解语花那个"异样的眼神" → 后文他识破她的关键；秦琏昨儿改旨 → 殉葬动机成谜；临终营造温馨假象 → 解释琏儿为何恨解语花。

## 第105章 小丫头还有三重身份呢！

**概要**：秦琏折返回来厉声不许秦不祥碰解语花、更不许与他孤男寡女共处一室。她由此推翻前判：他不是看上了她，而是早已认出她；最硬的证据是他把御用暗卫追影派给了她——追影与逐月分则各自猖狂、合则天下为王，把追影送出等于把半条命给了她。她唯一没想通的是自己明天为何非要出宫，做了一晚上梦也没结果，第二日听宫女说起祷丰节才恍然，今日正是傅丞相的忌日。傅丞相是她母亲的前夫，为免她爹大开杀戒而忍痛和离、终生未再娶，还在她夺嫡失败后为她顶罪而死；她每年都去扫墓，也是她把傅丞相与母亲合葬。然而站在墓前，身着戎甲的傅长卿却接连扔下惊雷：叫她"雪儿"、问她是不是还在怪他、问她现在带她走还愿不愿意——他竟与盛雪依是青梅竹马。她一句"你觉得呢"逼得他后退一步恭敬施礼："请少主恕罪。"她不动声色套话，成功把自己套了进去：她先从太后穿成太子妃，再降成御前奉茶女官，如今又成了凌天盟的少主。凌天盟是疆夷灭国后由四位长老创立的反动势力，取"凌驾天赢之上"之意，拥立盛雪依之母为主；其母死后盛雪依成为唯一疆夷王族之后而继任少主，盛雪依一死便轮到她。傅长卿正是长老安排在她身边护卫其长大的青梅竹马，因她入京后凌天盟想借太子妃身份的便利才令他联络。傅长卿警觉有人来了，留下"我会安排宫内暗桩与你联系"便施展轻功离去。回程车上她重新审度：秦琏的纵容、准她出宫、派追影三件事，全都可解读成欲擒故纵与监视，他大概是早识破盛雪依的身份，想借她把凌天盟一网打尽——然而盛雪依死了，她却活了。

**关键事件**：
1. 秦琏折返下禁令，秦不祥由追影一事反推他早已认出自己。
2. 扫墓遇傅长卿，得知盛雪依与他是青梅竹马，并被称为"少主"。
3. 套出凌天盟与疆夷王族的来历，坐上三重身份的少主之位。
4. 回程推翻前判：秦琏的恩宠可能是针对凌天盟的圈套。

**逐章写法公式**：

- **情绪流向**：起：得意（确认他认出了我） → 承：缅怀（傅丞相忌日） → 转：惊雷（雪儿、少主、凌天盟） → 合：发凉（恩宠原是圈套）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：折返禁令（翻案） + 扫墓遇傅长卿（奇） + 少主身份揭晓（惊） + 凌天盟来历补述（设定） + 回程重估秦琏（反转）
- **本章核心技巧**：把"身份"做成可叠加的道具——每揭一层就给主角多一道枷锁，喜剧与危机同一动作完成。
- **卡点与伏笔**：结尾卡点：悬念型——秦琏可能早识破盛雪依身份，读者等她如何自处；埋设/回收伏笔：宫内暗桩 → 后文联络线；祷丰节 → 时间坐标；傅丞相顶罪而死 → 秦不祥的旧账；盛雪依之母是叛徒 → 少主无实权的原因。

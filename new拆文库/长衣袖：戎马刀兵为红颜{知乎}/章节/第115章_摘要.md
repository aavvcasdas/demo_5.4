## 第115章 隐情

**概要**：秦不祥盯着昏迷的解语花眼神太冷，他似有所感地睁开眼，握住她想从他颈项收回的手，问她为何看起来这样悲伤，并说除了担心还有伤心、她的眼尾都垂了下来。两人以「小狐狸」互喻打岔，门外承安却急促敲门，解语花按住她的手、心跳骤快，眼底浮起浓重忧虑，开口求她抱抱自己，抱紧后小声问她可怪他隐瞒身份。秦不祥心知他明知会泄露身份仍冒死相救，只要不是他杀了自己便不怪他，但因事情一旦摆上台面便难如往昔、此刻不能失去凌天盟助力，只答「不怪，咱都自己人」。承安再敲，解语花勒住她哭着说她不会再回来，诉说想念得心都碎成一片一片，要她当初救了他便不能再丢弃；两人拉勾为定，他猛地一拉将她拽进怀里碰到伤口，仍不肯放，吻在她额间说「姐姐给的疼，甘之如饴」。她替他掖被出门，他随即睁眼落泪，呢喃她不会再回来。承安在门外急报陛下伤重，解释皇上当日把追影派去随她出宫以致自己被刺客所伤、隐忍不发，下午又添新伤，晚间已进不下药。秦不祥想起幼年每逢母亲生辰忌日，父亲醉酒踹门摔酒坛、挥刀吼骂她的阴影，最怕别人吼她，本想硬扛，终是硬着头皮接过新熬的药走进养居殿。

**关键事件**：
1. 解语花被她的眼神惊醒，察觉她悲伤并求抱，问她是否怪自己隐瞒身份，秦不祥权衡后答「不怪，咱都自己人」。
2. 承安二次催促，解语花哭着拉勾定约、额间一吻后仍喃喃她不会再回来。
3. 承安报皇上伤重缘由——派走追影、被刺客所伤后隐忍不发，下午添新伤，晚间进不下药。
4. 秦不祥回忆父亲醉酒摔酒坛挥刀的童年阴影，硬着头皮端药入养居殿。

**逐章写法公式**：

- **情绪流向**：起：被识破边缘的试探（紧张） → 承：求抱、拉勾、额吻的依恋（甜中带疼） → 转：出门即落泪、承安急报皇上伤重（紧张） → 合：童年阴影翻涌，硬着头皮进殿（压抑）
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：病榻识破边缘的互相试探（维持伪装） + 抱与拉勾加固羁绊（立情感筹码） + 承安急报引出皇帝伤重（转场加压） + 童年阴影自述（解释性格、铺垫进殿反应）
- **本章核心技巧**：把「依恋」拆成一串可数的肢体动作——勒疼、落泪、呜咽、拉勾、拽入怀、额吻，让情感强度靠动作数量累积而不是靠形容词
- **卡点与伏笔**：结尾卡点：她端着药踏进正发脾气的养居殿，下章直面皇帝怒火；埋设/回收伏笔：解语花「你不会再回来了」 → 后文送他出宫线；追影被派走 → 皇帝被刺客所伤的直接原因；童年阴影 → 下章面对皇帝吼骂的身体反应

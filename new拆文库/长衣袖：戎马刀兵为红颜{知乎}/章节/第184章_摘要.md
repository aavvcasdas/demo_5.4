## 第184章 曾思

**概要**：本章写选秀前夜的绸缎庄、殷其雷的轻薄与许娥的初遇。一场夜雨落花，距掖庭局第二轮验容验德仅五天，卫夫人携雯楚毓娈去长安最负盛名的金煜昌绸缎庄定制参选衣裳，也借机摸清对手。店里乌央央停了半条街轿子，卫夫人压低声说"那些高门宰相家的千金"也来了。殷其雷进来找人，见雯楚笑，又极尽溢美之辞赞毓娈"手如柔荑、巧笑倩兮"，雯楚笑嗔，卫夫人念叨他"油嘴滑舌"——并点破殷家祖上非世家、得登基便宜入京、根基不稳名声不好，女儿也能入选是笑话。试完衣裳卫夫人坚持给毓娈也买一身，雯楚去门外透风，柳树下遇石榴花旁身量高挑、穿得简单的女子许娥，二人初识。许娥言"深宫富贵乡还是修罗场"，雯楚劝她别颓唐，许娥说"许是有宫中话谈那一日"。卫夫人问，许娥不卑不亢"萍水相逢"。毓娈柔声评"那姑娘比一般人通透，若中选定在雯儿之上"。

**关键事件**：
1. 距掖庭第二轮验容五天，卫夫人带雯楚毓娈去金煜昌定制衣裳，借机摸清对手。
2. 殷其雷入店赞毓娈"巧笑倩兮"，雯楚点破殷家根基不稳名声不好。
3. 雯楚门外遇石榴花旁许娥，二人初识；许娥言深宫修罗场，约"宫中话谈那一日"。
4. 毓娈评许娥通透，若中选定在雯楚之上——埋下许娥夺魁伏笔。

**逐章写法公式**：

- **情绪流向**：起：绸缎庄喧嚣的奇（奇） → 承：殷郎溢美的厌（厌） → 转：石榴遇许的惊（惊） → 合：一句定评的期（期）
- **节奏配比**：绸缎庄铺陈 30% / 殷郎插曲 25% / 石榴遇许 30% / 一句预言 15%
- **本章结构公式**：一进金煜昌（摸对手） + 一赞巧笑（写浮） + 一遇许娥（立高人） + 一约宫谈（埋线） + 一评定上（预言）
- **本章核心技巧**：用"选秀前的衣香鬓影"衬托许娥的出水芙蓉——读者一眼认出她才是这一局的真赢家
- **卡点与伏笔**：卡点：许娥"宫中话谈那一日"未兑现，埋下宫中再会；埋设/回收：殷其雷 → 接185章茶馆再遇；十二上秀 → 接186章宫门候见；许娥通透 → 接186章许皇后侄女夺魁

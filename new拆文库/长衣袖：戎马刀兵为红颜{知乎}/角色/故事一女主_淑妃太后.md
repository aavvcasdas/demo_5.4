# 秦不祥（故事一女主 · 淑妃→贵妃→太后）

> 依据范围：故事一（第1-6章）＋故事九（第96-133章）共 44 章，本人出场第1-6、96-133章。基于全书 207/207 章逐章摘要全量重跑，覆盖率 100%。

## 身份与所属卷
- **故事一（第1-6章）**：天赢朝权倾朝野之权臣的独女 → 淑妃 → 贵妃 → 太后。姓名在故事一原文未出现；故事九第101章起由秦琏唤出「阿祥」，全量统计口径定名**秦不祥**。
- **故事九（第96-133章）**：病逝后借神兽夫诸**鹿旨酒**之力附身于阳寿已尽的太子妃盛雪依体内，同时继承凌天盟少主之位。

## 别名称谓
我 / 淑妃 / 贵妃 / 太后 / 娘娘 / 阿祥 / 姐姐（解语花称）/ 少主（凌天盟称）/ 本宫 / 盛雪依（冒用）/ 雪儿（傅长卿误称）。

## 外貌与性格
- 自陈以「盛气凌人的愚蠢，隐藏我聪明绝顶的才智和狼子野心」，由「白莲花人设」改立「霸王花人设」（第3章）。
- 坦白得可怕：主动交代弑父、造假、下药；停手杀春花的理由是「收买宫人太贵了，我没钱」。把「安全第一」当最高纲领，自称「缩头小甲鱼」。
- 故事九附身后为十八岁少女皮囊，仍保留太后的权谋本能；第96章照镜后「果断不换」。

## 核心动机与欲望
九岁读《史记》吕太后一节而立志当太后；更深的源头是「世上唯一爱我的人死在我出生那天」——要「不被忽视、不被践踏、不必任人宰割」（第1、2章）。故事九转为：先查清自己究竟怎么死的，再重新掌权自保。

## 人物弧光
从「用伪装换生存的受害者」→「以掌控求安全的加害者」→「赢到顶却无人可托的太后」；故事九再由「执棋者」跌落为「被爱囚禁的棋子」，最终被解语花从血浪里拉回——母题「深情即伤害，掌权方可自保」在她身上走到极致。

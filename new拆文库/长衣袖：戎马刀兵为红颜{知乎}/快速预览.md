## 开篇判断

- **开篇钩子类型与效果**：反差钩 + 信息差钩。效果**强**。三句之内把「弑父」写成「梦想冲突的技术问题」，并立刻在第 39-40 行自我推翻（「啊不对，好像是我害死的」），暗示叙述者不可靠——读者在笑的同时已经在做情报甄别，注意力被双重锁定。
- **主角立人设手法**：行为自证（下药、暗杀、撩丞相）+ 自我矛盾式旁白 + 人设主动重构（白莲花 → 霸王花）。最关键的一次塑造在第2章第 20-21 行：把「当太后」的动机与「不被忽视、不被践踏、不必任人宰割」绑定，使全书所有不择手段都不再需要额外解释。
- **世界观铺设方式**：旁白式家族史 + 事件带规则 + 清单式排比（朝局四党四行交代）。优点是密度高、无信息倾泻感；缺点是场景感弱，前三章几乎没有「当下正在发生的大场面」。
- **黄金三章节奏**：
  - 第1章 = **立人 + 立目标 + 引爆外部危机**（疆夷入侵、和亲要求、父亲那一眼）；
  - 第2章 = **双线展开**（他者英雄线：盛虞澜和亲—归来；主角喜剧线：四次暗杀失败）+ 交付「封号量化」等制度细节；
  - 第3章 = **阶段目标达成与减损**（入宫但只是淑妃）+ 人设升级 + 反制失效（下药过期）。

## 早期可借鉴点

1. **前三句交付核心矛盾**：目标、家族结构、叙述者人格三合一，不写外貌与景物。
2. **把最重的伦理事件写成最轻的句子**：弑父用一句因果句带过，随后自我推翻，笑点与「不可靠叙述者」两个功能一次完成。
3. **幻想目标必须落在可打勾的制度步骤上**：「当太后」拆成「先当皇后生崽 → 我爹造反成功 → 我的崽是新皇」，还配 Plan B（造反失败皇上也会变先皇），读者才能追进度。
4. **用制度数字当反应层**：写「他给了她超规十二字的封号（公主八字上限、皇后十字）」，再让一个无关旁观者去数字数——比任何「他很爱她」都有力。
5. **喜剧循环换物理机制**：同一动作（杀春花）失败四次，原因分别是食材、材料、地形、天意，四类不同，长线喜剧不腻。
6. **恶人主角退场理由必须是资源而非良心**：停手因「收买宫人太贵了，我没钱」，一句话保住人设一致。

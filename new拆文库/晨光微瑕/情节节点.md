# 《晨光微瑕》情节节点（N1–N50）

> 密度：50 节点 / 约 39621 字（>12000，标准 45–60）
> 视角：林夕第一人称为主，沈梦依番外补叙

- N1【起·钩子】「秦燃是缅北的王，他说我是他养的狗」——身份与冲突一句话立住。（1）
- N2【逍遥窝日常】林夕是管事人、秦燃麾下利刃，却在秦燃面前只是狗。（1–2）
- N3【沈梦依夺宠】大学生被卖入窝点，秦燃着迷，林夕地位被撼。（2）
- N4【掌掴训狗】秦燃因护沈梦依掌掴林夕，童年杀保姆阴影浮现。（3）
- N5【烟蒂烙臂】林夕按规矩办事反被烟蒂烫，驯狗模式"打一巴掌给颗糖"。（4）
- N6【圆场救女】林夕以甜美皮囊化解女孩恐惧，获秦燃满意目光。（5）
- N7【放女孩·伏笔】收进 14 岁女孩，林夕守底线放人；女孩称"找哥哥"。（6）
- N8【女孩被杀】秦燃出夜色一枪毙女孩，林夕被关禁闭。（6）
- N9【禁闭受电棍】林夕攥女孩糖果不肯认错，濒死才求见秦燃。（7）
- N10【苏醒喂药】秦燃亲手喂药，"下不为例"，林夕更卖力讨好。（8–9）
- N11【沈梦依扇秦燃】沈梦依喊"恶心"，林夕震惊其大胆。（9）
- N12【断指之辱】沈梦依逼秦燃剁林夕尾指，林夕磕头求情被切指。（10）
- N13【断指之痛】"心脏被挖去一半"，林夕丢失某种东西。（11）
- N14【越南任务】秦燃派林夕解越南被困毒品，初见新人顾安晨。（12）
- N15【暗线提案】顾安晨提"走暗的"查 C 弱点，秦燃准行。（13–14）
- N16【C 弱点】C 靠妻发家、私养情人子，顾拟以此威胁。（14）
- N17【谈判被擒】C 开枪，顾护林夕，二人被关地牢。（15）
- N18【林夕中枪】顾误以为林夕掀衣献身，实则其小腹中枪。（15）
- N19【无麻取弹】顾无麻药为林夕取弹，教她"痛可叫出声"。（17）
- N20【C 视频要挟】C 连线秦燃，秦燃弃林夕利益不松口。（19）
- N21【秦燃亲救】秦燃现身扭转战局，林夕劫后余生。（19）
- N22【回缅北避吻】林夕首次侧头避开秦燃吻，厌倦觉醒。（20）
- N23【天台披衣】顾调来当差，天台夺烟披外套，"多笑笑"。（21）
- N24【管束甜恼】顾夺烟夺酒管天管地，林夕落荒而逃。（22）
- N25【心动沦陷】林夕睡前醒后满脑子顾安晨。（23）
- N26【中国之喻】顾讲中国"有法、坏人被抓"，握她的手约看日出。（24）
- N27【表白赠戒】顾以为林夕爱秦燃，表白赠简易戒指，约定戴戒相见。（25）
- N28【三月无音】顾去 M 国失踪，秦燃与沈梦依完婚。（26）
- N29【会议疑内鬼】M 国货被条子扣，秦燃暗示顾或泄密。（27）
- N30【血牢虐杀】林夕被拖见顾：右眼钉穿、手脚尽断，被丢绞碎机。（28）
- N31【目睹惨死】顾"别看"最后一眼，林夕世界变黑。（28）
- N32【梦境婚后】林夕梦与顾正常生活，被呼声打碎。（29）
- N33【伪装失忆】睁眼"失忆"，被称女疯子，暗中找东西。（30）
- N34【厌秦圈养】林夕厌秦燃却惧，被圈养家中。（31–32）
- N35【明面小三】成秦燃小三，沈梦依神情复杂。（32）
- N36【梦游看日出】林夕哭要去看日出，秦燃抱其上山（雨）。（33）
- N37【黏沈梦依】林夕察觉沈梦依眼底恨意，反显兴奋黏上。（35）
- N38【溃败逃亡】秦燃势力倒，直升机带林夕沈梦依逃往岛屿。（36–37）
- N39【岛屿被困】秦燃守岛捏炸弹器，藏人质对峙警方。（38）
- N40【沈梦依亮明】沈梦依对秦燃举枪："束手就擒"，卧底身份揭。（38）
- N41【林夕亮装】林夕举枪射秦燃："原来一直是你"（伪装揭）。（39）
- N42【秦燃反噬】秦燃称顾安晨利用林夕，激其狂补数枪。（39）
- N43【推沈挡弹】沈梦依扑护林夕，林夕反推開她，胸口中弹。（40）
- N44【戴戒而死】沈梦依替林夕套上戒指，林夕满足而亡。（40）
- N45【余韵问日出】林夕临终问"日出美吗"，沈答"美"。（40）
- N46【番外·目标】沈梦依自述：目标本非秦燃，林夕是唯一突破口。（41番）
- N47【番外·潜入】沈梦依伪装被拐大学生入窝，被秦燃盯上忍辱。（41番）
- N48【番外·顾信任】顾挡弹得信任，借计划近林夕，未料林夕动心。（41番）
- N49【番外·无监听】沈备监听戒交顾，顾却给无监听真戒，以死补漏洞。（41番）
- N50【番外·真心】葬林夕时沈梦依泣："顾安晨还有一件事没骗你——他真想娶你。"（41番）

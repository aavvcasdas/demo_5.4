# 《双淑》情节节点（N1–N50）

> 密度：50 节点 / 约 38861 字（>12000，标准 45–60）
> 视角：苏茵茵第一人称为主，番外补充

- N1【起·钩子】将军出征归来，带回怀孕的苏茵茵；开篇"我就是那个怀孕的女子"强悬念。（节01）
- N2【梦境】苏茵茵梦见自己害死傅婉、独占沈时礼的恶毒结局，埋反向预言。（节01）
- N3【入府】回府见原配傅婉，心生负罪感。（节01）
- N4【初见交锋】傅婉试探"夫君去哪了"，苏茵茵睁眼说瞎话。（节02）
- N5【谎言揭穿】苏茵茵质问沈时礼"你说过没娶妻"，识破欺骗。（节03）
- N6【撕婚书·一】苏茵茵撕当初婚书欲走，被孩子要挟。（节03）
- N7【进宫布局】傅婉暗塞纸团、使眼色，沈时礼安排宫装遮肚。（节04）
- N8【身世侧写】席间得知沈时礼靠傅家发迹，傅家已败落。（节04）
- N9【拒赐婚】皇后面前苏茵茵求银两回青州，反将沈时礼一军。（节05）
- N10【傅婉拦夫】宫门傅婉抱住沈时礼喊"一生一世一双人"，苏茵茵随傅家大哥走。（节06）
- N11【马车异客】车内遇冷面异族少年（九王子），被厌恶打量。（节07）
- N12【小产】腹痛血崩，方悟傅婉纸条"舍得"之意——舍子保命脱身。（节07）
- N13【傅府养伤】傅大哥温润开导，傅夫人泼辣护短。（节08）
- N14【日常相处】傅大哥每日探视念书，嘉悦公主赐婚伏笔。（节09）
- N15【长街对峙】再遇沈时礼，傅大哥当众甩耳光护妹，顺手扶起傅婉。（节10）
- N16【信物威胁】铺中沈时礼以阿翁信物逼哄，苏茵茵佯羞索看婚书。（节11）
- N17【撕婚书·二】"婚书已毁，孩子已无"，一别两宽。（节11）
- N18【强暴未遂】沈时礼施暴被九王子踹门救场，露"九王子"身份。（节12）
- N19【九王子救场】九王子驱赶沈时礼，赠粽子糖，答"为了她……"留悬。（节13）
- N20【傅婉谈心】傅婉摸肚自陈丧子，问"可怪我打掉你的孩子"，赠折扇（爹爹印章）。（节14–15）
- N21【傅婉回府】傅婉归府，傅大哥为其与沈时礼打架鼻青脸肿。（节16）
- N22【阿翁线】苏茵茵寻阿翁，知其为九王子师傅、曾与外孙订娃娃亲（伏笔）。（节17）
- N23【身世伏笔】九王子送归，提"傅景那个臭小子别提多高兴"，苏茵茵猜"她是谁"。（节17）
- N24【嘉悦挑衅】嘉悦公主居高临下嘲苏茵茵"赖在傅府"，碰壁回宫。（节18）
- N25【立储暗涌】京中二皇子/大皇子争储，沈时礼属大皇子，嘉悦属二皇子。（节18）
- N26【被囚·上】嘉悦邀上佛寺，苏茵茵被迷晕掳至沈时礼处。（节20）
- N27【囚禁】沈时礼软禁苏茵茵，称"为你打江山"。（节20–21）
- N28【同囚】嘉悦亦被困，二人同院，嘉悦仍骄纵。（节21）
- N29【自白·青州】沈时礼吐露"青州一夜是我故意设计"，苏茵茵拔簪刺胸。（节22）
- N30【画像墙】屏风转，满墙苏茵茵画像，"你的一切都在我掌控"。（节23）
- N31【嘉悦泄密】嘉悦推门见状，哭诉"他是我哥哥""汝阳王世子死了"。（节23）
- N32【身世推断】苏茵茵据传言推断：沈时礼=皇后与书生私生子。（节24–25）
- N33【围城称帝】三月变天，沈时礼六十万军围京，穿龙袍强喂合卺酒。（节26）
- N34【吐露阴谋】沈时礼醉吐害二皇子（嘉悦下药三年）、掰断定情莲花簪。（节27）
- N35【卧底约定】苏茵茵与傅婉早约定假意被困搜集通敌证据，现寻兵符。（节28）
- N36【计败】沈时礼识破蒙汗药，嘉悦被绑，苏茵茵心虚。（节29）
- N37【假兵符】嘉悦递出假兵符，真兵符已交傅婉安排之人。（节30）
- N38【攻城不动】逼宫日禁军分列，九王子/傅婉军至，兵符在苏茵茵手。（节31）
- N39【高潮·女将军】傅婉铠甲现身，一箭射穿沈时礼胸膛，救下苏茵茵。（节31–32）
- N40【真相大白】苏茵茵方知傅婉本为女将军、阿翁即沈时礼外公。（节32–34）
- N41【沈时礼死】骨灰交阿翁，皇后葬子守灵，新皇辅政走向正轨。（节34）
- N42【定情】傅大哥湖边赠木簪求婚，苏茵茵心动收簪。（节35）
- N43【备嫁】傅府张罗婚事，九王子收苏茵茵为义妹，嘉悦添妆。（节36）
- N44【傅婉点醒】傅婉以"姐姐"身份劝：你才十七，是否被推着走？（节37–38）
- N45【谈九王子】傅婉明言只爱过沈时礼（已碎），今只做自己、欲云游。（节38）
- N46【觉醒·拒婚】苏茵茵坦白"被推着走""没准备好"，傅大哥答"我等你"。（节39）
- N47【离京】苏茵茵随傅婉马车远行，傅大哥竹林相送，不悔。（节40）
- N48【三年成长】三年游历，苏茵茵知所求；九王子缠随傅婉，二人登对。（节40）
- N49【番外一·傅婉视角】补全：早看穿一切、下滑胎药、安排卧底、射杀沈时礼的真相。（番外一）
- N50【番外二·女儿视角】傅苏苏视角，姑姑傅婉嫁舅舅九王子，真爱传承收束。（番外二）

# demo_5.4 → 剧本工厂

**这个仓库现在是两件事：一份归档 + 一个新项目。**

- 🗂 `archive/旧链路/` —— 旧的人生副本生产线（14 个 skill、2.9M 字规则、拆文库工具链、作品与评估），**冻结，只读参考**。
- 🏭 `剧本工厂/` —— 新建的口播剧剧本生产线：**判型 → 取骨架 → 定钩子 → 排 beat 时钟 → 写逐字稿 → 念稿体检 →（可选）高保真改编**。
- 📚 `拆文库/` —— 旧链路留下的 54 篇真实对标（原文 + 拆解），现在是新工厂的**只读语料**。

## 为什么推倒重建（一句话版）

旧链路把 3.43M 字规则里 **0.18%** 给了人生副本手艺；拆解报告平均 **1.4 万字/篇**却不产出功能位与加价阶梯（功能位只出现在 7/54 篇）；成品是**分行散文**——没有 beat 秒窗、没有带说话人的台词；门禁把 10 条创作规则里的 6 条设成 `null`，然后给出 PASS。用户看完成品说“看不懂、流水账”，系统里没有任何一个环节能把这句话接住。

完整诊断（含全部数字与复核命令）→ [`docs/诊断_剧本为什么水.md`](docs/诊断_剧本为什么水.md)

## 快速开始

```bash
# 1) 蒸馏语料：拆文库 → 结构指纹 + 真实开场原句库（只需跑一次，产物已提交）
python3 剧本工厂/scripts/distill.py

# 2) 念稿体检：写完后必须跑，BLOCK 必须修
python3 剧本工厂/scripts/fuben_check.py 剧本工厂/样片/001_年夜饭桌/剧本.md
```

写新稿的入口：`剧本工厂/SKILL.md`（六道工序，一屏读完）。

## 新工厂的硬规矩（四条）

1. **没有骨架不许开写**：先出 `结构指纹.json`（功能位、加价阶梯、兑现类型、结尾债务），再写一个字。
2. **分行 = 换气**：口播字数 ÷ 4.2 = 秒；行长中位 ≤12 字；台词占口播字数 ≥35%。
3. **对手至少施压两轮，且第二轮要换形**；兑现必须看得见（改口 / 让位 / 换持有人），旁白不许替人物打架。
4. **体检只判可测项**：BLOCK 必修；PASS 只代表“可测项没问题”，好看度永远由人判；正文一改，旧体检作废。

## 关于 GitHub 仓库“归档”

沙箱里的 token 对该仓库只有读权限（`permissions.push=false`），**无法替你在 GitHub 上点击 Archive**。所以“归档”这件事分两层：
- 代码层：本仓库内已把旧链路整体移入 `archive/旧链路/`（纯改名，历史与文件都在，可随时 `git mv` 还原）；
- GitHub 层：需要你在仓库 Settings → Danger Zone → **Archive this repository** 手动执行（或告诉我另一个新仓库地址，我把新项目推过去）。

旧链路里值得带走的东西列在 [`archive/README.md`](archive/README.md)。

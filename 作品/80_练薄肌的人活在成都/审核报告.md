## 1. 本次返工改了什么（V2 → V3）

V2 机检 `PASS_WITH_REVIEW` 之后我仍然判断它不合格，因为**机检过的稿子可以照样是流水账**。三处根因改动：

### 1.1 骨架：日历 → 因果（这是流水账的真凶）

V2 的八个段间连接点**全部**是时间标签（周五／第二周／月底／接下来两周／第二个周日／第二天／几个月后），
**零个**因果连接词。把时间标签当段落骨架，写出来必然按日期排列——那就是账本；账本再加三百字还是账本。

V3 换了一根因果脊柱：**这一辈子你要学会三个词**（开场第 3 行立下）。
三个词是递进的，而且**递进的方向是他越来越省力**：

| 词 | 谁给的 | 给什么发通行证 |
|---|---|---|
| **涮起嘛 / 蛋白** | 阿峰（别人给的） | 给破戒 |
| **充碳** | 健身圈（行业给的） | 给夜宵 |
| **训练可持续 / 练中找耍** | 他自己造的 | 给放弃 |
| **耍起** | 全网的（时代给的） | 给全部 |

于是每一幕都由上一幕的**结果**触发，不由日期触发：
吃了那一筷 → 才需要「充碳」；用了充碳 → 身上才有账 → 才被教练叫去量；
量出来「你这个叫瘦」→ 他不想听量出来的，才去找光 → 才有天台；
天台被评论区判了 → 他才去搜「薄肌是什么」→ 搜到「挽尊词」→ 他才自己造结论；
自己造了结论 → 日子才好过 → 才敢设免打扰；
免打扰 → 群里只发视频不发话 → 才有那副干碗筷。

幕间起句现在**先给因果再给时间**（例：「可你不想听量出来的／你想看见的／那天晚上你回家路上」）。
判据（已写进 `口播节奏与连接.md §A`）：**把段间时间标签全删掉，故事还站得住吗？**

### 1.2 事实：联网搜索查出 V2 写反了

V2 写主角「体脂掉了零点六」+「练完直接回家做饭」+「秤上的数一格格往下走」当自律成果。
联网核实（见 §3）：**瘦子要线条得先增重**——「肌肉线条＝肌肉形状＋较低体脂。瘦子从不缺低体脂，缺的是肌肉量」，
路径是先增肌后刷脂，**不是**降体脂。V2 把一个方向性错误当成了励志蒙太奇。

V3 把这变成剧情：教练说「**你搞反了**／你要的是线条／线条是形状加低体脂／你不缺体脂／你缺的是量／
你得先吃重」，主角**听懂了却挑了另一半听**（「其实教练那句话你听懂了／你没想起它／你想起了这一句」——
指博主那句「一半是光给的」）。此后他越自律越往反方向走，「连教练都说这才有样子／他没再说你搞反了／
你也就不再想那件事」。**错误没被修好，被话术盖住了**——这才是这个题的戏。

### 1.3 判词：从「哥 你那叫瘦」升级到「薄肌是挽尊词」

联网搜到本题真正的判词（知乎高票，24 万人点赞的争论对面）：
「一开始是细狗，增肌增不上去，**挽尊的叫法叫薄肌**」。

V3 让主角自己去搜到它，然后**不信**（借 29 号《愤怒的普通人》的「急了学」自欺闭环）：
「你的结论是／他们不懂薄肌／练得大的人／没有资格定义薄肌」。
紧接着落本篇的核心判词：「**你看／第三个词还没到／你已经开始自己造了**」。

于是全篇的题眼成立：**薄肌、充碳、耍起是同一个动作——给自己的做不到找一个体面的名字。**
而结尾他连名字都不造了，直接用时代现成的那两个字，这是弧线的终点。

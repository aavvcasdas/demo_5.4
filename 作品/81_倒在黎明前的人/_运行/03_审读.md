# 03 审读（story-architect 副本职责·审读 + fuben-review · solo）

- 输入：`02_初稿.md`、`00_简报.md`、`01` 第六节交接。没有看作者自评。
- 方式：solo，主会话在独立步骤里以审读角色完成，不是多 Agent 会审。

## 一、创作审读

**开场让人等什么？** “早上五点四十 / 天刚蒙蒙亮”+推送“你待过的那家公司今天上市了”+“你差四个月”。字面上的黎明和题目里的黎明叠在一起，三十秒内立起两个疑问：为什么差四个月就走了？他会不会再碰上这家公司？成立。

**哪里最可能划走？** “那几年你信……这点房贷不算什么”是背景，但每一句都在给“差四个月”加码（元老承诺、月供、指望期权），而且很短。接下来“第五年的冬天”把压力凑到同一个夜里：半薪→刷卡还房贷→父亲住院→协议还差四个月。放弃是算出来的，不是懦弱，符合题意约定。

**兑现有没有演出来？**
1. 三十份庆功早餐送到新楼：由“早餐单最多”自然长出来，不算空降巧合（同城骑手接到大单），可以接受。
2. 历程墙：横幅“歪的”兑现了“贴歪了”的伏笔；老照片里的你只剩半个肩膀，是侧面描写。
3. 替陌生人在横幅前拍合照：扎心顶点，而且由主角动手按快门。
4. 老板认出来 → 递来厚红包 → “你要是当年再撑四个月……” → 主角把红包放回去，只谈这一单。主角自己完成反击，没靠配角替他说话。递手机的年轻人“悄悄把手机收回去了”，侧面显示局面变了。
5. 小孟挡电梯：注释“一直没删”“最稳的一块”，兑现“老周写的 别乱删”，把他的价值交还给他，但没有抹掉“倒下”的代价。
6. 收尾：太阳出来、五星好评“谢谢老周”、接下一单——用行动收，没有加金句。

结构、场面不用返工。

## 二、读通专项

- 问题类型：事实／流程
  - 位置：“麻烦签收一下 / 三十份 超时了要扣钱”“在你手机上 / 签了自己的名字”
  - 对照：外卖平台送达靠骑手点“已送达”，一般不要顾客在骑手手机上签名
  - 影响：懂行的观众会出戏；而且“超时扣钱”是在货已经送到之后说的，逻辑也别扭
  - 判定：**确定错误**
  - 最小修复：改成“三十份 您点一下 / 齐了我就走了 / 后面还有单”，老板“低头数了一遍 / 说 齐了”
- 问题类型：术语／歧义
  - 位置：“最边上那个人 / 被裁掉了半个肩膀”
  - 对照：他是谈 N+1 主动走的，不是被裁员；前文还有“组里开始用AI写代码……三个就够”
  - 影响：口播里“被裁”容易听成被裁员，跟事实冲突
  - 判定：**待确认 → 修**
  - 最小修复：“被相框边压住了半个肩膀”
- 问题类型：时间锚点（核对，无误）
  - “六年前你进这家公司”“干了四年八个月”“差四个月”：4年8个月+4个月=5年归属，✓；离职到今天大约一年四个月，公司走完上市流程，虚构情节里可以接受；“第五年的冬天”落在第 4 年 8 个月之内，✓。“五点四十”推送→“直到今天早上六点”抢单，同一个早上，顺序对。✓
- 问题类型：代词／身份（可接受）
  - 五星好评“谢谢老周”没写是谁发的：此前在场知道“老周”的只有老板和小孟，观众能推断出来，留白可以接受。
- 可接受表达：“黎明前最黑暗”由老板说出来，是角色话术，不当作者的道理；最后“第一次这么认真地 / 看一次天亮”，他每天天不亮出门，“认真看”跟“看见”不矛盾。

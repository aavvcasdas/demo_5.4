## 一、主题深读

- 题眼是什么：**命**
- 谁在受这个处境的罪、受众替谁共情：替那个把大半情绪、尊严和社交都押进游戏里的人共情；他并不完全快乐，但也说不清为什么退不出来。
- 情感核：不是“打游戏很酷”，而是“现实里说不上话的人，是否还有一种不丢人的活法”。
- 这个主题天然能长出的冲突池：
  1. 游戏身份很硬，现实身份很空。
  2. 线上关系很真，线下称呼却很陌生。
  3. 家里替你圆谎，你自己也半真半假地活着。
  4. 兼职/日结/陪玩给了拖延现实的理由，也加深了脱节。
  5. 真到必须进现实场合时，语言、礼数、履历全露怯。
- 主题边界：
  - 不能写成热血电竞升级文；LOL 只是主角赖以维持自尊的场域，不是比赛爽文主线。
  - 不能写成多游戏盘点；具名只保留 LOL。
  - 不能只剩“婚礼翻盘一场爽”，前面必须铺出为什么这场翻盘对他有重量。

## 二、真实检索记录（单批 8 路并发）

批次：B01

### 检索 1

### 检索 2

### 检索 3

### 检索 4

- 借用质感：不是不会说话，是只会在熟悉频道和固定话题里说话；一进现实场合，整个人像掉线。

### 检索 6

- 借用质感：最刺人的不是“没找到工作”，而是被问“那几年干了什么”时，答出来的东西自己都不敢信。

### 检索 7
- 查询：`2026 英雄联盟 五杀 大龙 翻盘 玩家 回忆`

  - 玩家怀旧帖/翻盘讨论
  - 职业赛五杀翻盘新闻

### 检索 8

## 三、剧情方向（需用户选定）

### 方案 A｜【保留现版·校准】（推荐）
- 类型标签：扎心现实向 / 保留婚礼主线
- 一句话剧情线：保留“婚礼认亲”骨架，把前面所有日结、陪玩、社交退化和家里圆谎都压得更实，让婚礼那一刻真正像现实与游戏的正面对撞。
- 开场钩子速写：
  - 老刀在语音里说他要结婚了。
  - 伴郎给你留着。
  - 你忽然发现，你连他真名都叫不出口。
- 主峰兑现路径：婚礼桌上先被现实问题问住，再被旧局认出来，主角第一次在现实场合里“不是空气”。
- 借用的检索质感：空窗期面试卡壳、日结平台化、固定双排情谊、宅家后现实失语。
- 主要风险：如果中段还是只报流水账，会变成“前面很丧，后面突然一场爽”。

### 方案 B｜爽向版：婚礼桌翻盘更狠
- 类型标签：爽向 / 现实反压一桌人
- 一句话剧情线：婚礼前半段把主角压到最哑，后半段在 LOL 旧局与一桌人的围观里狠狠干回来，让“你到底是干什么的”这句问话反过来变成全场记住他的理由。
- 开场钩子速写：
  - 伴郎给你留着。
  - 你练了一路“赵成”。
  - 到了现场，第一句问你的却是：你是新郎什么人？
- 主峰兑现路径：问工作 → 卡壳 → 有人认出 47 血翻盘 → 老刀盖章 → 整桌态度翻面。
- 借用的检索质感：老玩家记旧局、婚礼社交压力、双排关系的情感重量。
- 主要风险：爽点如果太猛，会把“长期躺平的代价”压扁，变成单场打脸文。

### 方案 C｜扎心版：这辈子最熟的人，现实里却叫不出口
- 类型标签：扎心向 / 关系错位
- 一句话剧情线：把重心更偏向“线上关系是真，线下身份却悬空”，婚礼只是引爆点，主角最难受的不是被人看不起，而是发现自己这些年最亲近的人都停在 ID 那一层。
- 开场钩子速写：
  - 朋友要结婚了。
  - 你要给他当伴郎。
  - 可你对着请帖上的真名，练了一路也没练顺。
- 主峰兑现路径：婚礼上完成第一次真正的“叫出名字”，把关系从 ID 往现实里拉下来半步。
- 借用的检索质感：网友线下见面分类尴尬、宅家社交退缩、家里替你圆谎。
- 主要风险：如果处理不好，会偏抒情，少一点抓人的传播性。

### 方案 D｜温情向：屏幕里的人，先把你当回事
- 类型标签：温情向 / 宅男现实回温
- 一句话剧情线：不把婚礼写成纯翻盘，而写成主角第一次确认——这群语音房里的人并不是“假朋友”；他们先于现实世界，把他当成一个真的人。
- 开场钩子速写：
  - 你妈问你要去参加谁的婚礼。
  - 你说老刀。
  - 她问，那是谁。
- 主峰兑现路径：婚礼现场的认出 + 回家后语音房自然接住他，让请帖和显示器第一次同框，形成温柔回扣。
- 借用的检索质感：固定语音房关系、母亲圆谎、现实场合失语、老玩家情怀。
- 主要风险：如果太温，会削弱“把游戏当命”本身的刺。

## 四、主控建议

如果这次是为了测试**新链路是否真的更稳**，优先选 **方案 A｜保留现版·校准**。
理由：
1. 它最适合验证“题意约定 → 检索 → 成稿 → 读通专项 → 关联返工”的新闭环是否有效。
2. 它能直接拿旧版 79 做对照，看新链路是不是把前面生活压力和后面婚礼兑现接得更顺。
3. 它不会因为大改骨架，掩盖链路本身有没有进步。

## 七、交给主笔（narrative-writer）的内部交接

- 选中切口：请帖发进群里，新郎一栏是一个陌生的真名——双排七年，你叫不出他的名字。
- 观众在等什么：①他能不能当着所有人把“赵成”叫出口；②**反过来，老刀知不知道你叫什么**（前文要埋下“你也从没告诉过他”）。
- 伏笔：你的 ID `电一守门员`；签到本上写真名；席位卡。揭示：席位卡上印的是 ID，因为老刀也不知道你的真名——两个人都停在 ID 这一层。
- 主峰：伴郎致辞时第一次叫出“赵成”，然后老刀在台上反问“你叫什么”，你当众说出自己的名字。要写到场，不能一笔带过。
- 侧面：邻桌从席位卡认出“47 血翻盘”（这张桌上的人只认 ID）；新娘或旁人的反应；老刀改席位卡时写错字。
- 收尾行动：回家以后，下一个礼拜三晚上八点，语音房里老刀第一次叫他的名字；那张改过的席位卡立在显示器边上。
- 保留的硬事实：二十九岁、毕业六年、日结做不长、陪玩、LOL 是唯一出现名字的游戏、电一、每礼拜三晚上八点固定双排、母亲“网友”与两千块随礼。

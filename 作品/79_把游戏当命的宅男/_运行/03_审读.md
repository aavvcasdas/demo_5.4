## 一、创作审读

**开场让人等什么？** “双排七年 / 你第一次知道 / 他叫赵成” → 往上翻聊天记录，一条喊过你名字的都没有 → “他一直叫你守门员”。前三十行就立起了两个期待：婚礼上能不能叫出“赵成”；他知道不知道你叫什么。钩子成立，而且落在 C 的题眼上。

**哪里最先可能划走？** “你今年二十九……已经有人管你叫叔了”这一段是背景块，好在每一拍都扣着“没人叫你名字”（领班喊“穿灰衣服的”、快递员喊“周川 取件”），把背景拧成了主线的蓄势。可以留，不需要重构。

**兑现有没有演出来？**
1. 席位卡揭示“原来他也不知道”：签到本写“周川”→名单上翻不到→席位卡印的是“守门员”，前面埋过（名单翻到尾、老刀只叫 ID），揭示有依据。✓
2. 邻桌认出 47 血：延续旧版的爽点，但这次反过来用——“这桌人认识的 / 还是那个ID”，爽点顺手变成扎心，服务 C。✓
3. 主峰：扣下手机稿、当众叫“赵成”→老刀反问“那你叫什么”→“周川 / 周末的周 / 山川的川”。交锋、选择、反应都写到了场，主角自己完成最难的一步（扣手机不念稿），不靠配角。✓
4. 侧面：新娘“叫你呢”、台下笑声变小、他妈先鼓掌、老刀用记号笔改席位卡还写得很丑——每处都在显示关系变了。✓

**结尾**：席位卡划掉的那面朝外 + 礼拜三八点“周川 上号” + 好友备注“赵成”。用行动兑现“从 ID 往现实挪半步”，没有加金句。✓

结构层、场面层都不用返工。

## 二、读通专项（逐场）

- 问题类型：人物状态／时间
  - 位置：开头第二段“你知道他儿子半夜两点半要醒一回 / 知道他怕老婆 从不在十二点以后开麦”
  - 原句与对照：“儿子”“老婆”对照开头“说他下个月结婚”
  - 影响：婚还没结，已经有儿子、有老婆，听众会以为是二婚或者写错了；这个问题是从旧版带过来的
  - 判定：**确定错误**
  - 最小修复：删掉儿子那一句；“怕老婆”改成“女朋友不许他十二点以后还开麦”，顺便给后面新娘“叫你呢”那一拍垫个底
- 问题类型：问答／计数边界
  - 位置：主峰前“这个问题 / 签到台问过你 / 面试官问过你 / 你妈也问过你 / 你都没答上来”
  - 对照：签到台问的是“你是新郎什么人”，面试官问的是“这六年你干了什么”，你妈问的是“那是谁”（问的是老刀），而且你答了“网友”
  - 影响：“这个问题”指的是“你叫什么”，可三处原问题都不是这一句；你妈那处问的对象是老刀，你也答了，“都没答上来”对不上
  - 判定：**确定错误**
  - 最小修复：改成“你是谁这件事 / 换着法子被问过好多回”，只列签到台和面试官两处原问法，删掉你妈
- 问题类型：代词／场景
  - 位置：“敬完酒回来 / 你那张席位卡不见了 / 老刀坐在你位子上”
  - 影响：谁去敬酒？新郎怎么会坐在宾客位上？交代不清
  - 判定：**待确认 → 修**
  - 最小修复：“老刀敬酒敬到你这桌 / 一屁股坐在你位子上 / 手里拿着你那张席位卡”
- 问题类型：人物知情状态
  - 位置：结尾“小弟问 / 周川是谁啊”
  - 对照：高铁上你已经在群里发了席位卡照片，东北大姐也回了“周川 吃了吗”
  - 影响：小弟在群里，照理已经知道
  - 判定：**确定错误**
  - 最小修复：改成“小弟跟着喊 / 川哥 带我”
- 可接受表达（不修）：
  - “守门员这三个字 / 比你的名字有名”：角色的自嘲，不当事实判断。
  - 四十七血翻盘 / 主播晋级赛：虚构情节，旁白没有当成现实新闻来写。
  - 签到写“周川”但名单上找不到：两处写的是不同的名字，正是后面揭示的依据，不是漂移。
  - LOL 好友备注：客户端有这个功能（01 补充检索 #6）。

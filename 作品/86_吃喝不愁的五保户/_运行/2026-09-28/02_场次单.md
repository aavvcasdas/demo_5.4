# 02_场次单 · 86 吃喝不愁的五保户（搞笑错位向 × 分散供养）

**方向定板**：用户选定 **B 搞笑错位向《全村最像有编制的人》** + **分散供养（守老屋）**（2026-09-28 会话内选定）。

**主线一句话（直白爽）**：全村把「五保户」当成一种编制来羡慕，你守着老屋、月月等打款，直到有一份单子推到你面前——上面有一栏叫「关系人签字」。

**错位总开关**：**客体越一致（月月到账、不裁员、看病全报——全是"编制"的特征），主体越突兀（这份"编制"的入职条件是"没有人"）**。笑点一律架在**别人的羡慕与算账**上，绝不架在"你占了便宜"或"你可怜"上。

**伏笔（≤3，均登记回收）**：
1. 社保卡（器物三现：①豆腐摊前揣兜 ②医院拿出来 ③压在枕头下）——埋：场 0；回收：场 4、场 5。
2. 「你这个月到账没」这句问候（跨角色升级：调侃 → 真心问候 → 没人再问）——埋：场 0；回收：场 2、场 4。
3. 「关系人签字」那一栏——埋：场 3（照料协议上的"照料服务人"不是关系人）；回收：场 4（医院）。

**判词（≤2）**：终判词「你这一辈子在账上，就是九百九十一乘以月数；最后一笔，是十二个月。」

## 场 0 · 村口豆腐摊前（傍晚）

> 场址微调记录（2026-09-28 开写前闭环）：原设「小卖部门口」与 00 简报禁用器物清单冲突（79–85 已用小卖部），改为「村口豆腐摊」；器物随之换为杆秤／豆腐板／钱盒，老板换为卖豆腐的老康——换址后笑点反而更硬（991 折算成一板两块豆腐＝一天要卖十六板半）。

| 字段 | 内容 |
|---|---|
| **入场** | 你 60 岁刚过，公示贴在墙上快一个月，全村都在议论你「月月到账」；你只是出来买两块豆腐 |
| **欲望** | 你只想买完豆腐回家（最小欲望，好落子）；三个光棍想知道"怎么才能像你一样" |
| **阻力** | 他们堵着你问，你不愿意说——说出来这个数就再也收不回去；而且你也说不清条件 |
| **落子** | 你把社保卡往兜里一揣，说了一句「我这编制，不裁员」——**你顺着他们的语言点了火** |
| **出场** | 全村对你的叫法从"可怜人"改成"有编制的"；第三天有人问的是"名额还有没有" |
| **递进** | 因为（你说了"编制"）→ 所以（全村开始算账、打听名额；场 2 的晒场账由此而来） |

- 器物一现：社保卡（揣兜）｜钉子句 1（「我这编制，不裁员」）｜笑点：光棍三连问、卖豆腐的老康当场把 991÷30≈33.03 折算成豆腐（「我这一板豆腐两块，我得卖十六板半，一天卖不了十六板半」），算得手上切歪了

## 场 1 · 认定（回溯，前一年冬天，村委会）

| 字段 | 内容 |
|---|---|
| **入场** | 60 岁整（与正文一致，2026-09-28 校准），屋里冷，一个人过了大半辈子；小王骑电动车上门，车筐里夹着蓝皮本子 |
| **欲望** | 把日子过稳（不是想要施舍，是想要"稳"） |
| **阻力** | 三条件逐条卡：无劳动能力（够）、无生活来源（够）、**无法定赡养义务人**（这一条最硬——得证明"没有人"）；还要查存折、查房、查车 |
| **落子** | 你自己跑了三趟镇上（问材料 / 交材料 / 补一张"你确实没有人"的说明） |
| **出场** | 公示贴上墙：名字、组、每月的数 **991** 全村可见——**你的账第一次公开** |
| **递进** | 因为（公示＝把私账变成公账）→ 所以（场 2 的议论有了具体数字） |

- 器物：蓝皮本子 / 一卡通 / 公示栏｜钉子句 1（小王第三条念得最慢）｜笑点：小王报年龄像报户口、村里人围着公示问「这钱是不是白给」

## 场 2 · 晒场上的账（午后）

| 字段 | 内容 |
|---|---|
| **入场** | 公示后，议论最凶的地方是晒场；四个人围着一副旧扑克，谁也没出牌 |
| **欲望** | 每个人都在给自己算账（老陈算军龄、老周算儿子、支书算工龄） |
| **阻力** | 没人敢去镇上问政策——去问就等于承认自己在算这笔账 |
| **落子** | 你把卡掏出来递给老陈看（把"编制"的证据主动递出去）——老陈没接 |
| **出场** | 账摆平了，谁也没赢；但「名额」这个词开始在村里传，**小宽上门问"怎么进"** |
| **递进** | 因为（名额传开）→ 所以（有人开始算你的**身后**：堂侄上门） |

- 器物：社保卡（递出被拒）｜钉子句 1（支书：三十二年、一个月一百多）｜笑点：老周掰手指头算三个儿子一年两趟一趟两百、老陈把牌扣了、「你这卡颜色比我那本子正」｜问候梗第一现

## 场 3 · 照料协议（入秋，堂屋）

| 字段 | 内容 |
|---|---|
| **入场** | 你腰不行了，起夜扶墙；小王说你这叫"半护理"，在家养要有确定照料人，签三方协议，护理费**打给照料人不给你**，否则转集中供养（进院） |
| **欲望** | 你要留在老屋（这是你唯一的东西） |
| **阻力** | 照料人得是个具体的人，还得每月上门签字；愿意干的人一开口就变味；不签就进院 |
| **落子** | 你拎着两瓶水去隔壁老赵家，把话说透：护理费全给你，我只要你在本子上签字 |
| **出场** | 协议签了，你留住老屋——**代价是每月都有一个外人进屋签一个名字**；村里开始讨论"照料人"这个岗（又一个编制） |
| **递进** | 但是——那个本子证明"有人管你"，证明不了"有人是你的"；堂侄上门问"叔，你那屋子以后归谁" |

- 器物：协议 / 签字本（一现）｜钉子句 1（老赵：「我签，钱我拿，活儿我干」）｜笑点：村里打听"这个岗还用不用人"

## 场 4 · 医院（腊月十四半夜 → 六天后）

| 字段 | 内容 |
|---|---|
| **入场** | 胆结石半夜发作，你喊的是老赵（不是亲人的名字）；老赵背你上车 |
| **欲望** | 把疼去掉、把账结清 |
| **阻力** | **手术同意书最下面那一栏"关系人签字"**——老赵在协议上是"照料服务人"，不是关系人；护士说这栏不能填本人 |
| **落子** | 你给堂侄打电话（他说"明天来"，手术排在今天）；你在委托书上按了手印，村支书在村委见证栏签字 |
| **出场** | 手术做了，六天，一站结算，**个人自付 0.00**——账全清；但你记住了那一栏空着的样子 |
| **递进** | 因为（那一栏空着）→ 所以（场 5：你开始算"最后一笔"） |

- 器物：社保卡（二现）、签字（二现）｜钉子句 1（护士：「这栏不能填本人」）｜对照侧面：隔壁床先交了一万押金｜问候梗第二现（老陈来问，语气变了）

## 场 5 · 收束（腊月二十九，屋里）

| 字段 | 内容 |
|---|---|
| **入场** | 出院回家，全村对你的议论升级成"你这是真稳"；老赵把本子翻给你看，二十号的名字照旧在 |
| **欲望** | 你第一次自己算自己的账（一年） |
| **阻力** | 算到最后有一笔账你算不出来（那一栏）；丧葬这事没人愿意替你答——办事员答得比你想的熟 |
| **落子** | 你专门去镇上问了一趟丧葬怎么办（主动把一个忌讳的事办了） |
| **出场** | 你知道最后一笔＝十二个月＝跟你一年领的一个数；社保卡压在枕头下，写了堂侄的名字，又用铅笔划掉 |
| **递进** | 收束（灰）：停在细节上——手机响一声，这个月的钱到了；不说教、不留"下集" |

- 器物：社保卡（三现）、签字（三现）｜钉子句 1（办事员：「这个不用你操心，到时候是村里办」）｜笑点（黑色、克制）：把"最后一笔"用算账口气说出来

| 兑现点 | 认领关键词 |

**账目反算**：991×12＝11892（一年＝最后一笔，同一个数）；991÷30≈33.03（老板那句"一天三十三块零三"）；248 与三十二年来自第 5 路来源（村干部原话、老兵打款截图热帖）。全部可回链，见 01 表。

**六字段自检**：6 场全部写齐（入场/欲望/阻力/落子/出场/递进）；无平行并列陈列场——场 2 的三笔账各由一个具体的人当场算出并当场影响下一场（名额→堂侄），不是"再举一例"。

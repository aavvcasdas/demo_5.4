# 钩子备选 · 83 资产从A2迈入A4的搞笑

> 三条钩子均先过开头铁律：不出现定义/科普/讲解，只用动作、赌注或数字开场。推荐 A。

## A · 数字判词（推荐）

上周你的余额是 68.50。
今天是 1001.50。
中间没有任何神话，
只有五件你不想承认的小事，
和一只两年前没销户的账。

- 吊住的期待：五件小事到底是什么；没销户的账是谁的。
- 兑现靠哪场：倒序到账复述 + 老周敲门。

## B · 群开盘

你的室友在手机上架了个盘：
今晚十二点之前，
你的余额能不能站上四位数。
赌注是一整袋辣条。
四十七条回复，
全是表情图。

- 吊住的期待：一场用辣条下注的余额直播。
- 兑现靠哪场：四位数截图发群，全员沉默 47 秒。

## C · 规则喜剧

你去退一张健身卡。
她告诉你：
卡不退，只能转，
转卡费三百。
你算到一半打开了计算器，
她按出来的数是 200。

- 吊住的期待：数学和合同到底谁赢。
- 兑现靠哪场：退卡谷底 「这是我们这边剩下的」。

> 备选语料备注：B/C 的器物（辣条赌局、退卡绕口令）在正文都有对应场次兑现；A 是判词式收尾前置，与结尾两两呼应。三条都没有讲定义，A2/A4 的含义靠「两位数站上四位数」的动作给。

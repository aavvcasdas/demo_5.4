# 02_人生时间轴 · 87 天天健身偷吃练成脂包肌（fuben-write v2.0）

**方向定板（用户 2026-09-28 会话内选定）**：**方向 C · 共鸣扎心向《练了三年，我还是脂包肌》**；目标时长档 **1–2 分钟（300–700 字）**。

> 方向卡 C 原文风险已登记并接受：「共鸣强、转发弱，爽点缺位（用户本轮已选爽优先，选 C 等于放弃这条裁决）」——**用户明示选择 C**，故本篇观众关系定为**共鸣（主）＋爽（副，落在"被看见"那一下）**，爽点四段按共鸣路线改写为 **压制 → 承受 → 谷底 → 被看见**；黑名单项「灰到底无释放」仍须避免，结尾必须给出被看见的一格变化。

**一句话主线**：一个天天去健身房、半夜偷吃的男人，练了三年没人看出来他健身——直到有人问了他一句"你是不是练过"。

**观众关系**：**共鸣**（这也是我）＋**爽**（这口气出了，落在"被看见"）。
**证据句**：共鸣＝「健身三年，没人看出来我健身」（无数人办卡后最真实的处境）；爽＝「你是不是练过」这句问出来的瞬间。

**情绪出口＋互动动作**：观众想说一句自己的**年数**（我练了 X 年／我卡办了多久）→ 结尾互动钩按此写。

**伏笔（≤3）**：体测单（①被念出的判决 → ②折起来塞包 → ③结尾被自己的记录替换）；「你练过」这句话（全程缺席 → 结尾第一次出现）。

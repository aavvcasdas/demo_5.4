## 三步定骨架

`_系列总拆书.md` §十一的接入指南，压成三句：

1. **选志**（决定天花板与地板）→ 2. **选曲线**（决定情绪形状）→ 3. **套六段公式**（决定占比与位置）。

然后取 2–3 篇同型样本的 `情节节点.md`，**把节点功能按字数位置抄到新篇**（不是抄情节）。
这是全仓最有效的一个动作：`情节节点.md` 每个节点都带「类型 / 情绪值 / 涉及 / 手法 / 位置」四标注，
等于一份带时间码的分镜表。

## 第三步：套六段公式

`_系列总拆书.md` §十的通用骨架（39 篇的最大公约数）：

| 段 | 功能 | 占比参考 |
|---|---|---|
| 1 开题 | 第二人称口播签名 | 11% |
| 2 基线铺设 | 正常／甜／无敌的起点——**给下坠定价** | 20% |
| 3 触发事件 | 免责设计：误点／被推荐／时代浪潮 | 25% |
| 4 编年下行 | 清单化证据：身体账单／社交账单／数字账单 | 15% |
| 5 谷底 | 结构性死路 + 情感性死刑的**双谷**为佳 | 17% |
| 6 反转或清算 | 数字判词／器物判词／钝刀判词三选一 | 12% |

**反转置 80–85%，尾部留给余波。** 收束二选一：灰收束（接受／少年留在过去）或暖收束（题眼追认／器物回暖）。
**别写大团圆**（`_archived` 包 §十，这条有效）。

**双谷分离**（`28/写作手法.md` §3）：生存谷与情感谷不在同一维度——破产挨饿是世界的清算（可以扛），
她的平静拒绝是关系的清算（扛不动）。**浅的那个更疼**，因为世界没义务爱你，她有 20 年的爱的记录。
中间用一碗面的救赎假象把情绪抬起来，好让拒绝的一刀落得更深。

## 搞笑题专用：sitcom 四幕连播

17 号是系列首个 sitcom 结构（`17/情节节点.md` 结构特征）：

```
序（定义 + 信条，0–10%）
├─ 幕一（320–1100 字）  景区插队      对手：老人
├─ 幕二                西餐礼仪      对手：服务业 + 对照组朋友
├─ 幕三                理发办卡      对手：手艺人（Tony）
└─ 幕四                缺斤短两      对手：小贩
判词收束（身份自封 + 零和金句）
```

四条设计要点（`17/写作手法.md` §1）：

1. **选 4 个国民级痛点场景，越日常越好——每个观众都是受害者。**
2. **每幕打一场完整的「受辱→反杀」比赛**，幕内四拍齐全（见 [爽点兑现.md](爽点兑现.md)）。
3. **四幕的对手要换类型**，证明方法论的普适性。
4. **幕与幕不连线**（零因果、等距 24/23/20/19%、可任意重排），每幕自带时间戳重新起跳，幕间空切
   ——这是拆条经济学：单条爆了能带火全系列。

**注意这里的「零因果」不是流水账。** 流水账是等重、无输赢、无对手（`作品/80` 02b 的病灶）；
四幕连播是每幕都有完整的蓄势—兑现—余波，只是幕间不连线。**区别在于每一段内部有没有一场比赛。**

## 双联法：找光谱上的空位

`_系列总拆书.md` §六：每对双联都是一次受控实验——**同变量、异结局**。

强双联（节选）：08↔11（贫民窟↔婆罗门）／15↔28b（147 万↔68块5）／21↔23（赌↔分期）／
24↔37（公主病↔汉子茶）／28↔35（辜负端↔珍惜端）／29↔30（愤怒↔装逼）／
33↔38（婚姻升温↔冻死）／36↔38（救赎 A 面↔认账 B 面）／27↔13（祛魅↔装逼）。

**用法**：写新篇时选定一对双联，读两篇 `拆文报告.md` Stage 6 的互相引用，把**分岔点**找出来
（36↔38 的分水岭在 N11：狂奔 vs 掩埋）。然后让新篇落在光谱的空位上：
糖水志 + 一道裂缝 = 温情志；忏悔志 + 真实反复戒断 = 36 的升级版。

**六条暗线**（§七）可以用来定位新题落在哪条线上：身体／金钱／社交／婚姻／阶级／表演。
每条线的核心断言：身体的每一项参数都有市场价；数字越小品越疼；社交资本是隐性资产负债表；
阶级先决定气候再决定选择；人设有利息和清算日。

## 文体税与补张力

`_系列总拆书.md` §三第 2 条「文体税定律」：

- 糖水（35＝16）、无坠落爽文（14＝16）、警世通言（36＝16）、软文（34/38＝17）、暴富反写（04＝16）
  ——**先天缺对抗或缺悬念的文体，技术再好也压在 16–17。**
- 反之温情志只要带苦底就能上 21–23（22/26/33），**纯糖必塌**（35）。

**补张力的办法**（§十一第 5 条）：文体先天缺对抗时，用「外部危机 + 清单化代价」补。
即：给一个会倒计时或会涨价的外部压力，把代价铺成清单（身体账单／社交账单／数字账单）。

**反转的溢价**：反转设计 5 分的篇全在第一梯队（15 的真事反转、28b 的价格反转）——
**数字判词 + 信息差是本系列最好用的反转引擎。**

**收束的稳定性**：结尾收束是全系列最稳的维度（灰收束／器物判词／一字收束的模板成熟）；
**开头钩子是最参差的维度**（依赖系列片头，脱离语境多篇开头偏弱）——所以 [开场与钩子.md](开场与钩子.md) 要单独下功夫。

## 节奏调控

借 short-drama 的加速／减速手段，改成口播可用：

**加速**（用在蓄势与兑现段）：短句快切、倒计时（02 号的 12 秒）、多线交叉（群里在喊／你在练）、
对话加速（争吵与质问）、连续反转（29 号的双假峰）。

**减速**（用在余波与温情段）：双人对话、独处与回忆、日常片段（一顿饭）、环境描写（空调冷得冒白气）。
**注意**：减速段也必须携带新信息。short-drama 的原文判据可以直接用——
> **喘息段是否也在推进剧情？（不能只是闲聊）**

**信息真空判据**：连续两段没有新的处境变化 = 观众划走的位置。审读时要能指出最早可能划走的那一段。

## 自检

| 检查项 | 标准 | 不合格怎么办 |
|---|---|---|
| 志 | 能说出本篇是哪一志（可以多志） | 说不出来＝没有骨架，回策划 |
| 曲线 | 能画出情绪形状（不是直线，也不是全平） | 从曲线表里选一条，重排节点 |
| 六段 | 六段功能都能在正文里指到 | 缺「基线铺设」最常见——补上，给下坠定价 |
| 主兑现位置 | 75–88% | 挪位置，别加字数 |
| 双谷 | 扎心题是否有结构性 + 情感性两个谷 | 只有一个谷时，把浅的那个补出来 |
| 同型样本 | 读过 2–3 篇同型的 `情节节点.md` | 没读就写＝凭手感，去 [样本索引.md](样本索引.md) 查 |
| 文体税 | 若选了糖水／软文／警世体，是否补了外部危机 + 清单化代价 | 补，或换志 |
| 信息真空 | 没有连续两段无处境变化 | 合并或删掉那两段 |

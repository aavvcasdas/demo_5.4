# 人生副本 · 手艺包（fuben-craft）

这一层解决一个问题：**「要好看」不是指令，「这样写才好看」才是。**

本仓的语料早就拆好了（`拆文库/` 45 篇原文 + 写作手法 + 情节节点，约 500 万字），
但 v13 profile 只留了六条抽象原则，没有一条真实例句。模型拿不到可模仿的形状，
就只能交出「梗清单 + 碎行 + 口号收尾」。本包把语料里的机制压缩成**类型 → 原文示例 → 反例 → 自检**四段式，
每个示例都标出处，可以直接照形状写。

> **口播稿 ≠ 短篇小说。** 本包所有规格按「一个人对着手机念、观众听一遍就懂」定。
> 篇幅、行长、气口、一遍听懂这四件事的判据集中在
> [口播稿规格.md](口播稿规格.md)，写前必读；反流水账的判据与改法在 [口播排版与反流水账.md](口播排版与反流水账.md)。

## 用法纪律（四条，优先级高于本包所有细则）

1. **借机制，不搬情节与原句。** 示例是给形状用的。把 17 的「早说没意见呀 那我也插队了」抄进新稿是洗稿；
   借「群体的沉默被谁先翻译成授权，谁就签收」这个机制去写自己的场景才是拆文的用途。
2. **配额一律无效。** 本包出现的数字（四幕、三拍、六段占比、≤3 行短行、字数带）都是**语料的描述统计**，
   用来对照形状，不是达标线，也不做机械闸（`fuben_policy.json`: `metric_thresholds: descriptive_only`）。
   不为凑数塞梗、加旁观者、拆碎行。**但字数带要认真对待**——篇幅不够时「没有剧情」是必然结果，
   解法是加场面，不是加形容词。
3. **ASR 语料有污染。** 原文是字幕转写：全篇零标点、他/她混用、同音误写（17 全篇「外耗→外号」）。
   借语感时**补意群、修代词**（把 ASR 断错的地方重新断成可朗读的意群）；
   **不要顺手把标点加满**——零标点是本账号的排版约定，加满标点就变成文章，不是口播稿。
   不把转写错误当事实，不把梗的出处当剧情。
4. **不写脚本删改正文。** 口播稿不做「去 AI 味」清零；自动改写出来的稿子百分百有问题。
   审核 = 成稿复读 + 联网搜索对标（见 `fuben-review/SKILL.md` §1.5）。

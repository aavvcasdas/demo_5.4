## 前 8 行的三件事

签名行（「今天体验的人生副本是……」）是账号资产，保留。它**不是钩子**，钩子从它后面第一行开始算。
八行之内必须完成：

1. **处境反差**：这个人现在在哪、身上有什么不对劲（一句话，不铺背景）。
2. **一个具体疑问**：观众心里冒出一句「那后来呢／他怎么敢／这是为什么」。
3. **一个可感知的东西**：身体感觉、器物或数字，三选一。抽象概念不算。

`拆文库/_速拆卡.md` 的「开头钩子 5 分」九篇：**02 / 09 / 11 / 12 / 13 / 15 / 20 / 24 / 30**。
写开场卡住时，从这九篇里挑同型的读前 30 行，看它把这三件事放在第几行。

**反例（本仓 `作品/80_练薄肌的人活在成都/_运行/02c_初稿_叙事版.md` 开头）**：

```
今天你要体验的人生副本是
练薄肌 撞上耍起的一生

最近全网都在传一个口号
能耍就耍 不该耍也耍
耍不了硬耍 耍完再耍
大家管这个叫 耍起主义
```

签名行之后连贴四行梗原文 = 把词典放在门口。观众此刻没有任何疑问，只有作业。
`_运行/07_诊断_流水账.md` 已经判过这一条（「Hook 违规：把词典放门口」），改法见下面模板一。

## 六种开场模板

每个模板给：机制 → 原文示例 → 适用志 → 反例改法。

### 模板一：热词翻转式（旧词诊断 → 新词开药）

**机制**：观众已经认识的那个词先出场当病症，再给它一个反向衍生的新词当人设。
发明权交给「网上」，观众以为是集体智慧，推销感归零（`17/写作手法.md` §7）。

**原文（17 外耗型人格）**：

> 从小到大 / 你就是人群里的那个异类或者说 / 在你的眼里 / 其他人才是难以理解的生物
> ……直到有一天 / 你在网上看到了一个词 / 外号型人格（按：源文同音误写，应为「外耗」）
> 瞬间如同醍醐灌顶 / 只要我没有道德 / 别人就绑架不了我

注意顺序：**先给三个具象动作画靶子**（琢磨一整宿／脚趾抠出三室一厅／绕路走半个小时），
再出新词。词是结论，不是开场白。

**适用**：迷因志、清算志、孤独志。**慎用**：新词必须由正文兑现，只贴口号就是模板一的失败形态。

**80 号怎么改**：把「耍起主义」四行口号压成一行背景，靶子换成动作——
朋友把代餐盒转半圈、一筷子牛肉已经架进你碗里，然后才让「耍起」这个词从别人嘴里出来。

---

### 模板二：结果先行式（倒叙悬念）

**机制**：先给一个不可思议的结果画面，观众必须知道「怎么会变成这样」。
short-drama 的「倒叙悬念型」在口播里的等价物：不用字幕「三年前」，用一件物或一个动作把时间钉住。

**原文（28 你有一个长得不好看但很爱你的女朋友）**：开篇即「一碗被倒掉的面」的器物判词，
`28/写作手法.md` §10「碗的判词——容器物理学」；情绪落点在生存谷 −7 与情感谷 −5 的双谷分离（§3）。

**适用**：代价志、辜负志、忏悔志。**要点**：结果场景必须是**具体的物**，不是「你后来后悔了」。

---

### 模板三：倒计时压迫式（第一秒就在输）

**机制**：开场就把人放进一个正在流逝的时限里，让观众替他着急。代入感来自体感细节的精度。

**原文（02 外卖员的一生 · 开头钩子 5 分）**：

> 第一集新手入行 / 雨水顺着劣质头盔的裂隙流进你的眼睛 / 二十三点五十八分
> 你站在6楼的防盗门外大口喘气 / 手里提着一份重量超过3公斤的麻辣香锅
> 包装袋的塑料提手已经勒进你冻僵的肉里 / 手机屏幕上的倒计时疯狂闪烁 / 只剩最后12秒门开了
> ……他的手指在手机屏幕上轻轻一点 / 订单已取消 / ……你没有敲门 / 你不敢敲门

**可偷的四件东西**：钟点（23:58）＋重量（3 公斤）＋身体痛感（勒进冻僵的肉里）＋系统冷酷话术（机械女声）。
`02/写作手法.md` 的「倒计时语法／好评经济」是同一套机制的展开。

**适用**：寓言志、实录志、沉沦志。写「打工人／系统挤压」类题时优先。

---

### 模板四：基线定价式（先给甜或无敌，再给下坠的价）

**机制**：开头把起点抬到最高（甜、无敌、体面），后面每一次下坠都有对照物。
`拆文库/_系列总拆书.md` §十的第 2 段「基线铺设（给下坠定价）」就是它。

**原文（13 高中死装努力姐 · 开头钩子 5 分）**：

> 凌晨5点 / 放在枕头边的手机发出刺耳的闹钟声 / ……北方冬日的宿舍如同一个冰窖
> 空气里弥漫着下水道反胃的酸臭和潮湿毛巾的霉味 / ……你是第一个 / 你必须是第一个

**要点**：基线不是「他很努力」，是**冷到能闻见的宿舍 + 一句自我命令**。
`13/写作手法.md` §2「表演选址学」——自虐要选在有观众的地方，开场就把舞台搭出来。

**适用**：清算志、装逼家族（13/30/31/27）、身体志。

---

### 模板五：反常物开场（一件不该在那里的东西）

**机制**：第一行给一个位置错乱的物件，疑问自动生成。比「介绍身份」快十倍。

**原文（38 小时候去浏览器玩游戏意外发现新世界的男生）**：破旧风箱、水池（`_系列总拆书.md` §八 器物判词系统）。
**原文（36 误入色途一事无成后幡然醒悟）**：30 块床帘——「沉溺的基建投资」（§八 §9 密室器物）。

**适用**：忏悔志、代价志、温情志。**要点**：物件第一次出现只承担当下功能，第二层意思留到后面（伏笔纪律）。

---

### 模板六：数字判词前置（一个数就是一次丈量）

**机制**：开场直接甩一个精确到分的数字，观众的疑问是「这数怎么来的」。

**原文（15 卖肾买iPhone4的人生 · 开头钩子 5 分）**：

> 2010年9月的正午 / 秋老虎的燥热死死粘在高中的走廊里 / ……那是一台刚刚上市的iphone4
> 阳光穿透教学楼的玻璃 / 恰好打在它平直的钢化玻璃背板上 / 折射出一圈冷冽锋利的光晕

判词数字在结尾兑现：147 万（`_系列总拆书.md` §九）。
**数字的刺痛与位数成反比**：147 万 / 48,452.31 / 15块8毛6 / 4,576 / 68块5。
小数字承担大清算时落差最大（20 号的 21,450.3 元、31 号的 15块8毛6 同族）。

**适用**：代价志、沉沦志、身体志。

## 段内钩子：五型

口播一条 3 分钟，观众在任意 15 秒都可能划走。把 short-drama 的五种钩子改成**段尾**用法：

| 型 | 机制 | 口播落法 | 语料例 |
|---|---|---|---|
| 悬念钩 | 抛出必须知道答案的疑问，先不给 | 段尾一句未完成动作：「你张了张嘴」 | 79 号「你张了张嘴 / 没出声」 |
| 信息钩 | 给关键信息，只给一半 | 段尾披露成本，把前面的滑稽重新定价 | 22 号「你后来才知道 / 为了这几个简单的手势 / 他反复看了一个小时的手语教学视频」 |
| 反转钩 | 观众以为 A，最后一秒是 B | 段尾一句翻面，且前文已铺过支撑 | 22 号「干瘪的文字」在两个语境里两次定价（`22/写作手法.md` §3 语法的翻案） |
| 情绪钩 | 推到顶点就断，不给释放 | 段尾停在身体反应上，不写心情 | 19/20 号对照：冷凝水一滴滴砸在 T 恤上 vs 端起奶茶喝一大口（`20/写作手法.md` §3） |
| 危机钩 | 平静假象被一句话戳破 | 段尾一句冷淡台词，规格低于观众的战争预期 | 29 号反派全部台词十一个字：「为什么要刀我」「你很无聊吗」 |

**信息钩是本赛道最值钱的一型**，因为它同时完成「伏笔回收」和「共情二次结算」：
先按当事人当下视角如实记录（笨拙、滑稽、不标准），情绪落定后再披露成本（一小时／三个月／攒了两年），
观众自己完成价值结算，比直接煽情高一档（`22/写作手法.md` §2 延迟披露）。
间隔要够长，句式用「你后来才知道」起跳。

## 钩子分布与叠加

单条口播的形状（借 short-drama 的分阶段配置，压缩到一条）：

```
签名行 + 开场模板          ← 强钩子（模板二/三/六 最抓人）
基线 / 靶子                ← 悬念钩：观众在等第一击
第一次小兑现（20–35%）     ← 兑现 + 立刻挂新钩子（新的阻力或新的信息差）
第二次加码（40–60%）       ← 危机钩或反转钩：对手赢一次 / 代价露头
主兑现（75–88%）           ← 全系列最稳的位置：反转置 80–85%（_系列总拆书.md §十）
余波 + 收束（88–100%）     ← 器物或动作收束，不再挂钩子，留余味
```

**叠加规则**：一个段尾只挂一种钩子。两种叠在一起会互相稀释（short-drama 同款结论）。
**不许**：反转钩连着用两次；钩子和主线无关；钩子在下一段秒解（虚假悬念）。

## 致命问题清单

- ❌ **签名行之后贴设定/梗原文**（80 号 02c 的「耍起主义」四行）→ 换成一个正在发生的动作。
- ❌ **开场介绍身份**（「你是一个 29 岁的宅男」）→ 换成处境反差（79 号：「老刀在语音里说他要结婚了 / 语音房里刷满了恭喜 / 刷着刷着 / 他点了你的名 / 伴郎给你留着」）。
- ❌ **开场讲道理**（「在这个内卷的时代……」）→ 观众要的是人，不是社论。
- ❌ **只有噱头接不上兑现**：开场的疑问如果全篇没有一处实质回应，切口就是废的，回策划重选。
- ❌ **段尾全是总结句**：每段都以「这就是……」收，等于每段都把观众送走。

## 自检

写完开场和每个段尾，逐条对照，答不出就改：

| 检查项 | 标准 | 不合格怎么办 |
|---|---|---|
| 签名行之后第 1 行 | 是动作、物件或台词，不是概念 | 把概念换成能拍出来的东西 |
| 前 8 行 | 有具体疑问 + 一个可感知的东西 | 补体感／器物／数字，三选一 |
| 每 200–400 字 | 有一个段尾钩子 | 找最近的一次「局面变化」，把段落切在那儿 |
| 钩子类型 | 相邻两个不同型 | 换型，或把其中一段并掉 |
| 主兑现位置 | 落在 75–88% | 太早＝后面注水；太晚＝余波没了 |
| 开场许下的期待 | 本篇有实质回应 | 没有就回策划换切口，别靠改第一句救 |

# 口播节奏与连接：流水账的真凶不是字数

> 来源：`imfangli/mediastorm-copywriter`（104★，影视飓风风格中文口播稿 Agent Skill，
> SKILL.md + references/{hooks,structure,style-guide,transitions,examples}.md）
> 与 `gushuaialan1/broadcast-craft`（11★，口播工坊，khazix-writer 人格系统的口播化），
> 两者均已克隆精读。本文件只取**口播节奏层**，不取科普评测的人格与商业件（见 §I）。
>
> 本文件是 80 号返工的直接产物：那稿两次重写都还是流水账，
> 排查下来不是字数不够、不是行数不对，是**段与段之间只有时间，没有因果**。

---

## A. 真凶：时间连接词 vs 因果连接词

80 号返工稿的八个段间连接点，全部是时间标签：

> 周五晚上八点零七分 / 第二周 / 月底 / 接下来两周 / 第二个周日 / 第二天 / 几个月后

**零个**因果连接词。把时间标签当段落骨架，写出来的东西必然按日期排列——
那就是账本。账本再加三百字，还是一本更厚的账本。

判据（写完通读一遍，只问这一句）：

> **把段间的时间标签全删掉，故事还站得住吗？**
> 站得住 = 有因果，时间只是记号；
> 塌了 = 全篇靠日历推进，这就是流水账，回去补因果，不要补字数。

因果长什么样：后一段之所以发生，是因为前一段有人做了个决定、说了句话、
留下了一个没解决的处境。**观众要能说出「所以他才……」。**

---

## B. 因果连接词库（替换时间标签用）

| 功能 | 词 | 干什么 |
|---|---|---|
| 启动新话题 | **那 / 那么 / 那么问题来了** | 段首最常用，比「第二周」有推进感 |
| 转折 | **但是 / 不过 / 可是 / 反过来说** | 制造波折，避免平铺；一篇至少一次 |
| 揭示纠偏 | **其实 / 说白了 / 老实说 / 你还真别说** | 引出真相或人物自己的判断 |
| 收束因果 | **所以 / 也就是说 / 就这么着** | 把一段的账结掉 |
| 举例落地 | **比如说 / 举个最直接的 / 像这种** | 抽象之后马上给画面 |

零标点排版下这些词照用，它们本来就是口语词，不需要标点承载。

## C. 设问是口播的呼吸

口播稿跟文章最大的区别：**你是在对着一个随时会划走的人说话**，不是给人读。
所以要有对话感。mediastorm 的实证是「平均每 100–150 字一个设问」——
**这是它的观察值，不是本账号的配额**；本账号照它学会「要有设问」，不照它数数。

**自问自答（节奏引擎）**
- 「为什么 X 呢」→「答案是 Y」
- 「那这是什么概念呢」→ 生活化换算
- 「那有没有解法呢」→「有」
- 「那怎么办呢」→ 引出下一段
- 「你猜他怎么说」→ 停在半秒，再给台词

**拉观众进对话的词**（撒着用，别堆）
`你看` · `对吧` · `你会发现` · `你有没有想过` · `你敢信吗` · `换你你也……`

人生副本是第二人称剧本，设问要问在**观众会替主角着急**的地方，
不要问在旁白想解释设定的地方（那就变成讲课）。

---

## D. 数据必换算，抽象必打比方

**裸数字是口播稿的哑弹。** 观众听「体脂掉了零点六」没有感觉，
听「一斤半」也没有感觉，听「掉的那点体重还没一顿火锅重」才有感觉。

公式：`<抽象数据> = <日常可感的等价物>`
- 「种活一棵树要 150–200 升水，**够一个人喝三个月**」（mediastorm 实例）
- 「一段 10 秒视频，**服务器要蒸发四升淡水、一度电**」
- 「比 Pocket 4 重了，**大概一个 AirPods**」

**抽象概念必打比方**
- 「整个过程其实很像是在**给沙漠织一个毛衣**」
- 「这相当于是**牛的科目一**」
- 降维解释：先给一句电梯版，再展开——「简单来说它就是一个能预测 X 的模型」

本账号的对应写法：判词独占一行做气口，**判词本身必须是换算过或比方过的**，
不是术语。术语（薄肌、充碳、耍起）第一次出现时由剧情解释，解释要用比方，不用定义。

## E. 钩子按的是哪个心理按钮

所有钩子都在触发一个原始按钮（broadcast-craft）：

| 按钮 | 心理机制 | 观众为什么停下 |
|---|---|---|
| **好奇** | 认知闭合需求 | 我想知道答案跟我猜的一不一样 |
| **恐惧** | 生存本能 | 这事可能影响到我 |
| **愤怒** | 不公平感 | 怎么可以这样，我要看他怎么骂 |
| **共鸣** | 群体归属 | 这说的就是我 |
| **幻想** | 反差现实 | 原来还可以这样活 |
| **干货** | 效率忌惮 | 我正需要这个 |

**好钩子同时按两个。** 人生副本天然带「幻想 + 共鸣」；
搞笑向再加「好奇」，扎心向再加「恐惧」。只按一个的开场就是平开场。

配套：**0–3s 具体的人做具体的事；3–8s 承诺收益**（凭什么看完）；
**最后一拍回环呼应**——callback 开头的钩子，形成记忆闭环。
80 号返工稿漏了后两条：开头给了场面但没给「凭什么看完」，结尾落在器物上却没回头咬开场。

## F. HKR 三问（选题与成稿都能用）

来自 khazix-writer 的选题质检，broadcast-craft 按平台给了权重：

- **H（Happy）**：看完有没有觉得有趣、有悬念、想看完？
- **K（Knowledge）**：看完有没有学到新东西、新视角？
- **R（Resonance）**：看完有没有「对对对我也这么觉得」？

**抖音权重 H 50% / K 25% / R 25%**——口播的 H 远高于长文：
观众可以先因为有趣看完，再在过程里学到东西；但**开头不 H，根本不会有过程**。

规则：三个只占一个，选题就要重审；一个不占，趁早放弃。
人生副本的 H 来自处境荒诞与自欺，R 来自「我也这么给自己找过理由」，
K 来自那个真实的行业/圈层知识（本篇是「薄肌其实是练不大的人的挽尊词」）。

## G. 五问质检（Stage 05，人审，不是扫描器）

broadcast-craft 的收口方式值得抄：**五个问句，人来答**，不写正则。

1. 反差够强吗？（开场立的和结尾落的，是不是同一个东西）
2. 事实可靠吗？（联网核过没有，编的数字有没有标出来）
3. 人设立体吗？（主角有没有一个自己看不见的盲点）
4. 情绪有收获吗？（观众退出时带走了什么感觉）
5. 值得分享吗？（他会转给谁，转的时候说什么）

第 2 问对应本仓的 **04c 联网对标**，第 1/3/4/5 问对应 **04b 复读**。
五问答不出来的，回去改稿，不要去改检查脚本。

---

## H. 不许编造：未核实的事实要标出来

mediastorm 的硬规则里有一条本仓此前没有：**素材不足时用 `[待补充: …]` 占位，不要编造具体数字。**

人生副本是虚构剧本，允许虚构处境，但**不允许虚构可被核实的外部事实**：
真实的热梗原文、真实的行业数值、真实的品牌与人物。
80 号返工稿里「体脂掉了零点六」「四十七个博主」「十七个赞」看着像细节，
其实是编的；而联网一查，**瘦子要线条得先增重，不是先降体脂**——方向写反了。
这类事实必须走 04c 核实，核不到就删掉或改成不必核实的写法。

## I. 不借什么（划清边界）

| 来源里的东西 | 不借的理由 |
|---|---|
| mediastorm 的自称「我／我们」、主持人 Tim 人格 | 人生副本是第二人称剧本，不是第一人称科普 |
| CTA 模板「那么我们下次再见」「三连」 | 本账号发布包另有约定，且剧本结尾要回环呼应不要喊话 |
| 合作方自然植入话术 | 人生副本不接商单植入 |
| 栏目 IP + 仪式转场（抛硬币／样片日记） | 本账号的仪式是签名行，已有 |
| broadcast-craft 的 L1 禁语表（综上所述／说白了／本质上…） | **用户明确要求口播不做去 AI 味**；且该表与 mediastorm 推荐的「说白了」自相矛盾。禁语扫描是本仓已删掉的老路（`fuben_craft_scan.py`），不再引入 |
| 两个库的分镜／BGM／标签／字幕工程件 | 本仓发布包三件套已有更硬版本 |
| 「每 100–150 字一个设问」「每 15 秒一个高峰」的**数字** | 借它们指出的**手法**，不借它们的**计数**。计数就是配额，配额就会被凑满 |

# 口播稿规格（替代小说设定）

> **这个文件存在的原因**：本仓的执行链脱胎于网文工具集，`story-short-write` 的默认设定是小说的
> （章、场景数、篇幅区间、付费点、情绪拉扯 Phase）。人生副本是**口播稿**——一个人对着手机念，
> 观众听一遍就懂，划走只要 1 秒。小说设定套不上来，而仓里从来没有一份口播稿规格。
> 后果是实测出来的：交付稿、回归夹具、语料原文**三种排版并存**，没有任何一条规则说哪种对。
>
> 来源：`ShortVideo-AI/short-video-script-skill`（国内短视频脚本 Skill，`mode: prompt-only`，零代码）
> 的 `prompts/*/04_spoken_script.md` 字数节奏要求 ＋ 本仓 v10.x 冻结档
> （`evaluations/2026-09-19_手动对照包/冻结规则/B_旧主profile.md` §0.4/§0.5/§2.9/§3.3/§3.9/§3.10）
> ＋ 本仓 18 篇语料原文、79/80 交付稿、红绿样夹具的实测。

## A. 小说设定 → 口播稿设定对照

| 小说设定（作废／不适用） | 口播稿设定（本文件） | 为什么 |
|---|---|---|
| 章、场景数、每场行数 | **时长档 → 字数带**（§B） | 口播按秒计，不按章计。观众不知道「第几场」，只知道「听了多久」 |
| 篇幅区间当硬闸 | 字数带当**对账口径**，闸不拦 | `fuben_policy.json` 已定 `metric_thresholds: descriptive_only`；本仓 2026-09-19 实测过「计数全绿但稿子仍是流水账」 |
| 付费点、跨集吊胃口 | **段内钩子 + 回位钩**（§D） | 单条口播没有下一集；期待必须在本篇偿还 |
| 情绪拉扯 Phase 1–4 | **秒级节奏图**（§D） | 情绪位置要换算成「第几秒」才能对账 |
| 去 AI 味清零、句式配额 | **一遍听懂 Gate**（§E） | 口播的验收标准是「听一遍懂不懂」，不是「有没有 AI 腔」。语气词、方言、答非所问的玩笑都是人味 |
| 读拆解摘要／考点提纲 | **精读原文全文**（§F） | 「考点提纲不能生产质地；课文才能」（本仓 v10.2 §0.4 原话） |
| 十二列表格、角色配额 | **场面表五要素**（见 profile §五） | 口播的原子单位是「场面/镜头」，不是「节点」 |
| 审稿＝跑脚本找问题 | **审稿＝复读 + 搜索网页** | 见 `skills/fuben-review/SKILL.md` §1.5 |

## B. 时长档与字数带

**对账口径：6.4 字/秒**（`scripts/fuben_policy.json` 的 `estimated_chars_per_second`，本账号实测值）。
不要用行业默认的 3–4 字/秒——那会把时长算长一倍。字数估时不等于配音实测，但它是写前唯一能对账的尺。

| 档 | 时长 | 字数 | 段（空行分隔）上限 | 说明 |
|---|---|---|---|---|
| 切条 | ≤60s | ≤400 | 3 | 不设回位钩；一个场面讲完就收 |
| 标准 | 3–5 分 | 1,150–1,900 | 6 | 2–3 个场面 |
| **全长（主档）** | 7–10 分 | **2,700–3,800** | 8 | 3–5 个场面；本账号主发布形态 |

**语料实测校准**（`拆文库/` 18 篇 10w+ 原文）：2,262–4,540 字，行数 229–435。
本仓 v10.2 定的账号带是 2,800–3,600（原文实测 3,043–3,849）。

**交付稿实测（这是问题所在）**：

| 稿 | 字数 | 对全长档下限 | 折算时长 |
|---|---|---|---|
| `作品/79` 正文 | 1,565 | 58% | 4.1 分 |
| `作品/80` 正文 | 1,117 | **40%** | 2.9 分 |

> **「没有剧情」首先是篇幅问题。** 1,117 字装不下三个场面：一个场面按 §D 要 ≥12 行逐拍，
> 三个场面加蓄势与兑现就是 2,500 字起。稿子短到只能列节点，节点列出来就是流水账。
> 80 号自己的复盘（`_运行/07_诊断_流水账.md`）：「节点写成了『第几天→做了什么』，缺少压力递进和代价。」

**超长时怎么删**（借 `short-video-script-skill`）：**优先删背景铺垫，不要压缩关键结论和例子。**
**每 2–3 个抽象概念后必须补一个具体场景或例子**——这一条同时防流水账和防超长。

## C. 排版：三种实测形态与判定

本仓实测三种排版并存：

| 样本 | 字数 | 行数 | 均行长 | 最长行 | >22字行 | 空行段 | 全篇标点 |
|---|---|---|---|---|---|---|---|
| **语料原文**（真抖音 ASR，18 篇） | 2,262–4,540 | 229–435 | **8.5–10.7** | 24–39 | 0–1% | **0–1** | **0–5** |
| **回归夹具**（作者自存绿样／红样） | 712 / 1,119 | 40 / 65 | **17.2–17.8** | 41 / 55 | 25–26% | **0** | **0** |
| **交付稿** `作品/79` / `作品/80` | 1,565 / 1,117 | 218 / 151 | **7.2–7.4** | 16 / 17 | 0% | **62–63** | **0** |

**判定：**

**权威只有一个：`拆文库/NN_*/原文/原文.txt`——那是作者手写的口播稿。**
`作品/_regression/` 的绿样红样是**为测绑定与机检造的回归夹具，不是作者字迹**，
只能用来验证脚本行为，不能当排版标准。（v15.1 之前把这两者的权威关系搞反过，特此纠正。）

1. **手写稿实测 0–1 个空行**（29 号：2,375 字 / 261 行 / 均行长 9.1 / 最长 19 / 空行 1 / 标点 2），
   交付稿有 62–63 个空行段。空行在提词器里不产生停顿，只让稿子「看起来有节奏」，
   实际是把意群打散。**照手写稿写：不靠空行做停顿，停顿由行长和气口行承担。**
2. **手写稿一行 ≈ 8.5–10.7 字**，一行一个可朗读的意群，零标点。夹具那 17 字/行是测试件的密度，
   **不要照着它把行写长**。写长行会吞掉气口——判词、数字、台词落点必须独占一行。
3. **交付稿的 7.2 字/行看着接近手写稿，其实差在别处**：手写稿的短行是「一行一意群、主谓宾完整」，
   交付稿的短行是 v10.5 §0.5 定性过的**电报体压缩**——「短行只许切分不许省成分」，
   它省掉的正是主语和动作链，观众必须自己脑补，这是「念出来不像人话」的物理成因。
   判据不是数字长，是问：**这一行单独念出来，主谓宾还在不在。**

### 排版五条

1. **一行 = 一个可朗读的意群**：主谓宾完整，或明确承接上一行。基准 **8.5–10.7 字/行**（`拆文库/` 手写稿实测）。
2. **判词落点、数字落点独占一行 = 气口。** TTS 停顿不加标记，**用排版实现**（v10.5 §3.9 原文）。
3. **短行是刹车，不是吞字。** 连续 ≤4 字的短行不超过 3 行，且每行必须携带新信息或新动作。
4. **不用空行做停顿**（手写稿实测 0–1 处）；停顿由行长和气口行承担。
5. **零标点是本账号排版约定**（语料全篇 0–5 个标点），意群之间用空格。
   借语感时要**补意群、修代词**（ASR 有他/她混用与同音误写，17 号全篇「外耗→外号」），
   但**不要把标点加满**——那会变成文章，不是口播稿。

### 反例 → 正例（v10.5 §0.5 原始改法）

改前：

```
辞得不壮烈
醒过站四站
你没补觉 也没补票
```

改后：

```
辞得没有一点动静
没摔工牌 也没跟领导吵
睁眼 已经坐过了四站
出站你补了票 那个觉 你没处补
```

差别不在文采：改前每行都省掉了主语和动作链，观众要脑补「谁辞的、怎么醒的、补了什么」；
改后每行都能**一遍听懂**，且「那个觉 你没处补」这个判词独占一行，正好是气口。

## D. 秒级节奏图与回位钩

**原子单位从「节点」换成「场面/镜头」。** 每个场面五要素齐（v10.2 §2.9）：

> **在场者**（≥1 个有身份的活人）/ **地点** / **进行时动作链**（动词连着动词，不是状态形容词）/
> **一句转述引语** / **一件可拍器物**

**关键瞬间 ≥12 行逐拍**——把时间写慢，让观众住进去。这是反流水账的第一件事。

按 6.4 字/秒把「位置百分比」换算成「第几秒」：

| 秒位 | 必须有什么 |
|---|---|
| **0–3s** | 「具体的人在做具体的事」。**不许放抽象钩**（「今天全网都在传一个口号」不是 0–3s 该干的活） |
| **15s** | 第一个可看见的场面 |
| **30 / 60 / 90s** | 各一个场面爆点 |
| **末 20s** | 判词 + 器物 |

**回位钩**（v10.5 §3.9）：全长版（>180s）**每 30–45 秒**设一个「你」行，
把观众从别人的故事拉回自己身上（75 号实证句式：「看到这里的人／多半也刚瞟了眼钟」）。
切条 ≤60s 不设。位置优先落在两个爽点表的空档里，**禁抽象喊话**。

## E. 一遍听懂 Gate

口播稿的验收标准不是「读起来美」，是**听一遍就懂**。听第二遍才懂的地方，观众已经划走了。

### 三条硬规矩（advisory，违反处由 `fuben-review` 人审判，不做机械闸）

1. **关键事件首载必须完整主谓宾。** 辞职、住院、搬家这类节点，第一次出现时用完整句说清「谁、干了什么」；
   **金句只能复述已交代的信息，不许首载。**
   *豁免*：0–5% 的结果前置钩子（判词先行）不算违规首载，但**钩子句后三行内必须落到事实句**（谁／何时／干了什么）。
2. **对仗/谐音压缩句每篇 ≤2 处，且不得承载情节**（「没补觉 也没补票」式）——**它们是糖，不是饭。**
3. **每段第一句 = 谁在哪干什么**（冷开场钩子段除外）；因果必须显式，
   「因为 X」的 X 不许是观众没见过的前提（「因为桌上摆着饭」式）。

### TTS 听感三问（通读时逐处标记）

1. 哪里要**回听**？
2. 哪里要**脑补因果**？
3. 哪里**念出来不像人话**？

一稿标记 **≤3 处**；超出就回写正文，再读一遍。
**标记数与改法必须写进审核报告——未写 = 没做听感 QA = 不发。**

### 定稿之后的流程顺序（不许颠倒）

1. 场面表**按定稿反抽**（表随文，不预先臆写）
2. 听感三问，逐处标记并回写
3. **搜索网页**：对标同题爆款、核实外部事实与热梗时效、核对账号带位（见 `fuben-review/SKILL.md` §1.5）
4. 才提交审核

## F. 精读 Gate

v10.2 §0.4 的原话：**「考点提纲不能生产质地；课文才能。」**
同一份审计还写着：**「39 篇 10w+ 原文从未被读过全文，这一条不变。」**

- **写前**：同型语料原文**全文**逐字进上下文（`拆文库/NN_*/原文/原文.txt`——
  **不是拆文报告、不是 `_meta.json`、不是节点表、不是写作手法摘要**），
  并留一行复述：*它怎么把一个瞬间写大到能住进去*——感官落在哪、动作链怎么走、时间在哪膨胀。
  **复述写成机制提纲（「它有爽点、在 20%」）= 视同没走流程。**
- **写时**：关键瞬间 ≥12 行逐拍，场面五要素齐（§D）。
- **带位参照**：原文感官密度 0.0–15.0/千字（中位 3.8），本库交付稿 0.0–3.2。
  **这是参照，不是义务下限**——目标不是把计数拉过线，是学 06 号怎么把一个瞬间写大。

> **为什么不能靠计数器**：2026-09-19 本仓实测，给密度检查补上动作流计数后，
> 75=12.9、73=14.4、66=12.4 **全绿——但稿子仍是流水账**。结论原文：
> 「**动作流计数不辨别时间膨胀，感官计数才有区分度**……所以 texture 永远只作 advisory，
> 质地修复靠精读与场面表，**不靠把计数做成闸**。」

## G. 拒录清单

v10.5 立目，防外部公式库回潮。**照抄这些会直接毁掉本账号的口播感**：

| 拒录 | 为什么 |
|---|---|
| 「每句 ≤15 字」 | 杀长句呼吸。本账号一行是一个**意群**，不是每句都短 |
| 「口播 3–4 字/秒」 | 本账号实测 **6.4**。先对账再采信，别用行业默认值算时长 |
| 「完播 30%+ 目标」 | 营销话术。本库带 = **10–15% 及格** |
| 远程规则注入（`latest-rules.json` 之类） | 绕过事实锁的供应链风险。**教义只进 Git** |
| 带货线全套（价格锚定 / CTA / 广审） | 无变现链路，死重 |
| 任何把文风词表做成闸的提议 | **闸只留在可判定真假处，文风词表类一律 advisory** |
| 英文散文规则（杀光副词 / 禁破折号 / 句子不许以 Wh- 开头） | 中文口播的语气词是人味，照搬必误伤 |
| 写脚本自动删改正文 | 口播稿不做「去 AI 味」清零；自动改写出来的稿子百分百有问题 |

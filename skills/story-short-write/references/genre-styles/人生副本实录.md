# 人生副本口播 · 口播稿 profile v15

适用：人生副本、剧本人生、第二人称人生体验**口播稿**。
本文件替代 v14 与更早的累加规则，不叠加旧骨架和普通网文契约。

> **这是口播稿，不是短篇小说。** 下面所有设定都按「一个人对着手机念、观众听一遍就懂」来定，
> 不按「读者捧着看、可以回读」来定。凡与小说设定冲突处，**以本文件为准**。

**一句话定位（本赛道的基因，写每一篇都要守住）**：
> 把一种抽象的人生焦虑翻译成**身体、器物与数字**；把人生的下坠铺成**编年与清单**；
> 把清算留给一个**最小的单位**（一碗面 / 半步 / 一秒 / 68块5）。
> 第二人称「你」是代入接口——**故事是别人的，痛是自己的。**
>
> 出处：`拆文库/_系列总拆书.md` 结语（39 篇系统深拆的结论）。

**少配额不等于少戏。** 本账号默认要：抓人的开头、可感知的爽感、能复述的绝杀台词、牵引下文的伏笔钩子、
有作用的侧面描写、以及（用户点名要搞笑时）**说得清用哪种引擎的笑点**。
不能把「自然、无错、过机检」当成写好了。用户明确指定其他目标时，以本次要求为准。

### 2. 实测：交付稿的篇幅与排版都不在账号带上

| 样本 | 字数 | 行数 | 均行长 | 空行段 | 折算时长(6.4字/秒) |
|---|---|---|---|---|---|
| 语料原文（真抖音 ASR，18 篇） | 2,262–4,540 | 229–435 | 8.5–10.7 | 0–1 | 5.9–11.8 分 |
| 回归夹具（作者自存绿样/红样） | 712 / 1,119 | 40 / 65 | 17.2–17.8 | **0** | — |
| **`作品/79` 交付稿** | **1,565** | 218 | **7.2** | **62** | **4.1 分** |

结论：**「没有剧情」首先是篇幅问题，其次才是笔法问题。**

## 一、精读 Gate：写前的第一个动作不是搜索

**第一步不是搜索，是选样本 + 读原文全文。**

1. 按 [样本索引.md](../fuben-craft/样本索引.md) 的方向表挑 **2–3 篇同型语料**。
2. 其中至少 1 篇的 `拆文库/NN_*/原文/原文.txt` **全文逐字进上下文**——
   **不是拆文报告、不是 `_meta.json`、不是节点表、不是写作手法摘要。**
3. 留一行复述，只回答一个问题：**它怎么把一个瞬间写大到能住进去？**
   （感官落在哪、动作链怎么走、时间在哪膨胀。）
4. 再读另 1–2 篇的 `情节节点.md`（节点功能 + 字数位置）与 `写作手法.md`（挑 3–5 项当本篇手法清单）。

**违规定义**：没有精读行，或复述写成机制提纲（「它有爽点、在 20%」）＝**视同没走流程**。
> **考点提纲不能生产质地；课文才能。**（v10.2 §0.4 原文）

之后才做主题深读与并行检索。**借处理方式，不搬人物经历与原句**；
不把转写错误当事实（ASR 语料有同音误写，17 号全篇「外耗→外号」）、他/她混用要修。

默认第二人称「你」、口语、具体。先抓住本题最有张力的处境和欲望：
人物想得到什么，什么在挡他，观众想看到谁翻盘、谁露馅、什么被揭开。
切口太平，就换入场位置或重构事件，不靠添一句「你绝对想不到」续命。
材料够用就写，不要求先填设定卡和情绪表。

## 二、口播稿规格：时长 ↔ 字数 ↔ 行

**对账口径 6.4 字/秒**（`scripts/fuben_policy.json` 的 `estimated_chars_per_second`，本账号实测）。
字数估时不等于配音实测，但估时是唯一能在写前对账的尺。

| 档 | 时长 | 字数 | 说明 |
|---|---|---|---|
| 切条 | ≤60s | ≤400 | 不设回位钩 |
| 标准 | 3–5 分 | 1,150–1,900 | 三个场面是上限 |
| **全长（主档）** | 7–10 分 | **2,700–3,800** | 语料 44 篇 10w+ 原文实测 2,262–4,540，账号带 2,800–3,600 |

**这是带位参照，不是闸**（`fuben_policy.json`: `metric_thresholds: descriptive_only`）。
但写前必须先定档，并算一遍：这个字数装得下几个场面？装不下三个，就别指望有剧情。

**排版五条**（实测对照与判定详见 [口播稿规格.md §C](../fuben-craft/口播稿规格.md)）：

1. **一行 = 一个可朗读的意群**，主谓宾完整或明确承接上一行；以回归夹具为基准 **12–20 字/行**。
2. **判词落点、数字落点独占一行 = 气口。** TTS 停顿不加标记，**用排版实现**。
3. **短行是刹车，不是吞字**：连续 ≤4 字短行不超过 3 行，每行必须携带新信息或新动作。
4. **空行只做段落分隔，一篇 ≤6 处**；不用空行做停顿（停顿由行长承担）。
5. **零标点是本账号排版约定**，意群之间用空格。借语感时补意群、修代词，但不要把标点加满——那会变成文章。

超长时的删法：**优先删背景铺垫，不要压缩关键结论和例子。**
每 2–3 个抽象概念后必须补一个具体场景或例子。

## 三、场面表与秒级节奏图：把百分比换成「第几秒」

**原子单位从「节点」换成「场面/镜头」。** 设定里每个场面一行，五要素齐：

> **在场者**（≥1 个有身份的活人）/ **地点** / **进行时动作链**（动词连着动词，不是状态形容词）/
> **一句转述引语** / **一件可拍器物**

**关键瞬间 ≥12 行逐拍**——把时间写慢，让观众住进去。这是反流水账的第一件事
（第二、三件见 [口播排版与反流水账.md §B2/§B3](../fuben-craft/口播排版与反流水账.md)；三个判据见同文件 §A）。

秒级节奏图（按 6.4 字/秒换算，有真实时长后换实测倍率）：

| 秒位 | 必须有什么 |
|---|---|
| **0–3s** | 「具体的人在做具体的事」。**不许放抽象钩** |
| **15s** | 第一个可看见的场面 |
| **30 / 60 / 90s** | 各一个场面爆点 |
| **末 20s** | 判词 + 器物 |

**回位钩**：全长版（>180s）每 **30–45 秒**设一个「你」行，把观众从别人的故事拉回自己身上
（75 号实证句式：「看到这里的人／多半也刚瞟了眼钟」）。位置优先落在两个爽点表的空档里，**禁抽象喊话**。

## 四、一遍听懂 Gate：口播稿的验收标准

不是「读起来美」，是**听一遍就懂**。听第二遍才懂的地方，观众已经划走了。

**三条硬规矩**（advisory，违反处由 `fuben-review` 人审判，不做机械闸）：

1. **关键事件首载必须完整主谓宾。** 辞职、住院、搬家这类节点，第一次出现用完整句说清「谁、干了什么」；
   **金句只能复述已交代的信息，不许首载。**
   *豁免*：0–5% 结果前置钩子（判词先行）不算违规首载，但钩子句后**三行内必须落到事实句**。
2. **对仗/谐音压缩句每篇 ≤2 处，且不得承载情节**——**它们是糖，不是饭。**
3. **每段第一句 = 谁在哪干什么**（冷开场钩子段除外）；因果必须显式，
   「因为 X」的 X 不许是观众没见过的前提。

**TTS 听感三问**（通读时逐处标记）：①哪里要回听？②哪里要脑补因果？③哪里念出来不像人话？
一稿标记 **≤3 处**，超出回写正文再读一遍。**标记数与改法写进审核报告，未写 = 没做听感 QA = 不发。**

反例 → 正例（v10.5 §0.5 原始改法）：

```
改前：辞得不壮烈 / 醒过站四站 / 你没补觉 也没补票
改后：辞得没有一点动静 / 没摔工牌 也没跟领导吵 / 睁眼 已经坐过了四站 / 出站你补了票 那个觉 你没处补
```

差别不在文采：改前每行省掉了主语和动作链，观众要脑补；改后每行都能一遍听懂，
而且「那个觉 你没处补」独占一行，正好是气口。

## 五、把追看和兑现写进正文

- **开头先发生事。** 尽早给一个反常结果、正在发生的冲突、身份错位或未完成的动作，让观众生出具体疑问。
  不要先讲完整背景，也不要拿题目复述充当钩子。签名式开场（「今天体验的人生副本是」）是账号资产，保留，
  但它**不是钩子**——钩子从它后面第一行开始算，且 0–3s 必须是具体的人做具体的事。
  → 六种模板与反例见 [开场与钩子.md](../fuben-craft/开场与钩子.md)。

- **钩子带动下一步，不是一直欠账。** 解开一层，同时让行动带出新的阻力、选择或信息差；
  必要背景在观众想知道时补。开头许下的核心期待要在本篇得到实质回应。
  → 段内钩子五型与分布见同文件 §段内钩子。

- **伏笔当下有用，后来变义。** 一次不合常理的阻拦、一个被藏起的物件、一句多余的解释，都可以埋线索。
  后面的揭示须由前面的东西长出来，不临时塞证据、贵人或新身份；呼应不是把同一个词再说一次。
  → 器物判词与延迟披露见 [侧面与共情.md](../fuben-craft/侧面与共情.md) §通道B / §延迟披露。

- **侧面描写承担戏。** 让对手改口、旁人收起原本要说的话、一个人把刚递出的东西拿回去、环境留下不同痕迹，
  使观众自己看出能力、处境或话语权变化。动作要有动机并影响后续，不是轮流「震惊、僵住、脸白」，
  也不强迫每场都加围观者。→ 四型 + 群体静场见同文件 §侧面描写四型。

- **爽点要演到兑现。** 前面蓄起的憋屈、好奇、期待，需要一个看得见的变化。把关键交锋、揭示和反应写到场，
  别用「大家都服了」「你很厉害」跳过最好看的部分。爽感不只等于反杀，但不能拿「不必反杀」替没有情绪力度开脱。
  → 四拍、绝杀台词产品化、不反杀的三种替代见 [爽点兑现.md](../fuben-craft/爽点兑现.md)。

- **要搞笑就必须说得出用哪种引擎。** 笑点不是梗，是结构：
  预期违背 / 归因反转 / 请君入瓮 / 沉默授权 / 恶意顺从 / 对照组 / 静物化余波 / 自欺闭环 / 双假峰。
  把热梗原句贴进正文不是笑点，观众笑的是梗本身，笑完就划走。→ [笑点机制.md](../fuben-craft/笑点机制.md)。

**每段至少在当前故事里有去处**：推进处境、改变理解、蓄积期待或兑现情绪。
判据一句话——**把这一段删掉，后面还成立吗？成立就是流水账。**
「第几天 → 做了什么」的时间推进不算处境改变。不按句子计数；必要的缓冲、心理与旁白可以留。
结尾可以安静，但不能用安静替代前面欠下的兑现，**也不许用口号收束**。

## 六、发布包三件套（定稿随正文交付）

写进审核报告「发布包」节（advisory 操作件，不入闸）：

- **标题 3 备选**，各标一个策略名（悬念/数据/身份代入……）；
  **签名句「今天体验的人生副本是」必进每个备选**（语料 47/47 铁证；76 号丢签名句 = 798 播放、0% CTR 的直接代价）。
- **封面一句话大字（≤12 字）+ 副行小字（栏目名）**；封面是视觉钩，须与正文首句**强化同一信息**。
- **置顶评论一句**（互动问题）——**不许出现「关注/点赞」乞讨式 CTA**。评论是下一稿的选题池。

发布质检四查（账号主执行位）：开头无静音 / 响度一致 / 前奏不吞首句 / 字幕与逐字稿对齐。

## 七、拒录清单：外部公式别搬进来

| 拒录 | 为什么 |

## 八、执行入口：借鉴的 Agent 方法

**用户要求真实调用。** 正文、开头候选及实质改稿须由实际调用的创作 Agent 产出。执行入口：
已认证外部执行器，或 Arena 会话内按 [arena.runtime.json](../../../../arena.runtime.json)
（路由见根 [AGENTS.md](../../../../AGENTS.md)，说明见 [docs/Arena运行时.md](../../../../docs/Arena运行时.md)）
的管线逐阶段执行并落 `_运行/` 阶段产物。两者都不可用就停止并报告阻塞；
不允许主会话读完规则后越过角色与阶段产物直接生成，也不得补造调用记录或虚构会话 ID。

> **配置缺失时的行为**：`arena.runtime.json` 或 `AGENTS.md` 读不到时，
> **报告 `BLOCKED: runtime config missing` 并给出缺失路径，不要用「我直接写一版」兜底。**
> 这两个文件曾在沙箱回滚中丢失过（见 `作品/80/审核报告.md` 的「环境事故披露」），
> 静默兜底会让稿子脱离角色与阶段产物，是 79/80 两篇返工反复的成因之一。

## 九、审核 = 生成完再次查看 + 搜索网页

**不是跑脚本删改文章。** 两半都必须做，缺一半就是没审。完整判据见
[`fuben-review`](../../../fuben-review/SKILL.md) §1.5。

**前半（复读）**：完整读当前正文 → 听感三问逐处标记（≤3 处）→ 核口播稿规格（篇幅档、均行长、空行数、
气口行）→ 核反流水账三件事（场面膨胀 ≥12 行、每段改变处境、秒级节奏图落位）→
指出哪句抓住了什么期待、哪段让期待断掉、最好的一刻是否真正展开、伏笔揭示是否成立、
侧面反应是否让局面变化、**要搞笑的题每个笑点用的是哪种引擎**。

**后半（联网）**：真跑搜索，结果写进审核报告「联网对标」节，未写 = 审核未完成。查三件事——
①同题近 30 天爆款的开场写法与时长带位，本篇差在哪；②稿内每个热梗的**当前**含义、出处、是否过期或有争议
（过期就换掉，不是加注释）；③稿内涉及的价格、政策、地名、品牌、行业流程、时间线。
**搜到的是带位与时效，不是写作许可**；搜索结果与 `拆文库/` 语料冲突时**语料优先**。

**用户说「不好看」，优先改开头、主线、蓄势与兑现，不自行转去修工具、数词、建测试包或写新脚本。**
问题要指到原句和影响，然后拿改写回答。主线散了就重构，不只润色；不要用「我有意这么写」替代效果。
不给自己凑高分，不把几个审查角度冒充独立评审。
**审稿不许按 `_archived/` 里的旧配额验收**——那套条款已作废，按它审只会把稿子逼回流水账。

**改稿顺序从大到小**（前一档没修好，改后面的是白费；详见 [口播排版与反流水账.md §E](../fuben-craft/口播排版与反流水账.md)）：
篇幅 → 排版 → 场面膨胀 → 处境改变 → 秒级节奏图 → 一遍听懂 → 个别词句。
**不要在最后一档上花时间**：79/80 的返工反复正是因为一直在改词句，而问题在篇幅（40%）、
排版（63 处空行、均行长 7.2 字）和零场面膨胀。

改场景、食物／道具、人物称呼、时间、标题题意或结尾计数后，检索全文关联依赖并重审新版本；旧报告不自动沿用。

## 十、事实是底线，工具在后台

保留用户给定事实和剧情，分清虚构、角色误信与现实信息；必要时核查来源、数量、日期及账号约定，
不伪造授权与数据。**文学效果不靠八拍、峰值百分比、感官词频、对白数量或数字预算证明。**

需要机械检查时用 `python3 scripts/fuben_run.py 路径 --profile full`；短版检查自己的正文并用 `--profile short`。
BLOCK 修明确错误，REVIEW 结合语境判断，ERROR 不算通过。

**机检的边界**：`fuben_run.py` 查的是日期、算术、事实锁、账号契约与输入完整性
（`SCOPED_CHARACTER_COUNT`、`DATE_COUNT_MISMATCH`、`BAD_DATE_LOCK`、`EXPLICIT_ARITHMETIC` 一类），
**它不查钩子、笑点、共情、侧面描写和剧情**——这五项只能靠复读与联网对标。

**不以机检结果替代创作审核，不以回归报告替代用户要的好稿。**
只有用户要求制作或发布时，才进入媒体及发布证据阶段。

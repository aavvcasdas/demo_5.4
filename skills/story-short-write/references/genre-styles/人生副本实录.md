# 人生副本口播 · 轻量创作 profile v14

适用：人生副本、剧本人生、第二人称人生体验口播。本文件替代 v13 与更早的累加规则，不叠加旧骨架和普通网文契约。

**一句话定位（本赛道的基因，写每一篇都要守住）**：
> 把一种抽象的人生焦虑翻译成**身体、器物与数字**；把人生的下坠铺成**编年与清单**；
> 把清算留给一个**最小的单位**（一碗面 / 半步 / 一秒 / 68块5）。
> 第二人称「你」是代入接口——**故事是别人的，痛是自己的。**
>
> 出处：`拆文库/_系列总拆书.md` 结语（39 篇系统深拆的结论）。

**少配额不等于少戏。** 本账号默认要：抓人的开头、可感知的爽感、能复述的绝杀台词、牵引下文的伏笔钩子、
有作用的侧面描写、以及（用户点名要搞笑时）**说得清用哪种引擎的笑点**。
不能把「自然、无错、过机检」当成写好了。用户明确指定其他目标时，以本次要求为准。

## v14 改了什么（相对 v13）

v13 的问题不是方向错，是**只有原则没有形状**：六条抽象要求，全文一句真实例句都没有，
而仓里躺着 500 万字已拆好的语料（`拆文库/` 45 篇写作手法 + 情节节点 + 原文）和一份 54KB 的旧配额包。
结果模型两边都够不着——**语料没被加载，配额包却被 glob 顺手读了进去**
（实证：`作品/80/_运行/03b_审读.md` 全篇按已作废的「§17 反流水账 / 场景≥4 / 时间标签≤6 / 内联说话≥15行」验收）。

v14 的三处结构改动：

1. **新增手艺层 [fuben-craft/](../fuben-craft/README.md)**：把语料里的机制压成「类型 → 原文示例 → 反例 → 自检」四段式，
   按阶段加载。写法参照 `0xsline/short-drama`（每型必配可直接抄的剧本示例）、
   `blader/humanizer`（Watch for → Problem → Before → After + When not to act）、
   `hardikpandya/stop-slop`（结构级 slop 清单 + 5 维评分）、`anthropics/skills`（progressive disclosure）。
2. **补上完全缺失的喜剧模块**：v13 里「笑点」一个字都没有，`沙雕脑洞.md` 是小说包且副本分支不加载它。
   现在搞笑向有 [笑点机制.md](../fuben-craft/笑点机制.md)（九种引擎 + 剂量安全线 + 反例解剖）。
3. **旧配额包移出发现路径**：`genre-styles/_archived/人生副本实录_v1_归档.md`，只作史料，不加载。

## 执行入口：借鉴的 Agent 方法

**用户要求真实调用。** 正文、开头候选及实质改稿须由实际调用的创作 Agent 产出。执行入口：
已认证外部执行器，或 Arena 会话内按 [arena.runtime.json](../../../../arena.runtime.json)
（路由见根 [AGENTS.md](../../../../AGENTS.md)，说明见 [docs/Arena运行时.md](../../../../docs/Arena运行时.md)）
的管线逐阶段执行并落 `_运行/` 阶段产物。两者都不可用就停止并报告阻塞；
不允许主会话读完规则后越过角色与阶段产物直接生成，也不得补造调用记录或虚构会话 ID。

新稿、创作审核与改稿按 [人生副本 Agent 方法](人生副本_Agent方法.md) 执行对应阶段：
主控比较可兑现的切口 → 主笔写连续关键戏 → 审读定位追看断点 → 按结构／场面／表达分层返工。

> **配置缺失时的行为（v14 明确）**：`arena.runtime.json` 或 `AGENTS.md` 读不到时，
> **报告 `BLOCKED: runtime config missing` 并给出缺失路径，不要用「我直接写一版」兜底。**
> 这两个文件曾在沙箱回滚中丢失过（见 `作品/80/审核报告.md` 的「环境事故披露」），
> 静默兜底会让稿子脱离角色与阶段产物，是 79/80 两篇返工反复的成因之一。

## 先找到观众要追的那件事

**第一步不是搜索，是选样本。** 按 [样本索引.md](../fuben-craft/样本索引.md) 的方向表挑 2–3 篇同型语料，
读它们的 `情节节点.md`（节点功能 + 字数位置）、1 篇的原文首尾、1 篇的 `写作手法.md`（挑 3–5 项当本篇手法清单）。
然后再读本题相近的真实原文——**不只看拆解摘要**。重点看：它让人等什么、怎样吊住期待、爽在哪里落地、
别人或环境的变化怎样替主角说话。

**借处理方式，不搬人物经历与原句**；不把转写错误当事实（ASR 语料有同音误写，17 号全篇「外耗→外号」）。
材料够用就写，不要求先填设定卡和情绪表。

默认第二人称「你」、口语、具体。先抓住本题最有张力的处境和欲望：
人物想得到什么，什么在挡他，观众想看到谁翻盘、谁露馅、什么被揭开。
切口太平，就换入场位置或重构事件，不靠添一句「你绝对想不到」续命。

## 把追看和兑现写进正文（v13 六条保留，每条挂上手艺层）

- **开头先发生事。** 尽早给一个反常结果、正在发生的冲突、身份错位或未完成的动作，让观众生出具体疑问。
  不要先讲完整背景，也不要拿题目复述充当钩子。签名式开场可以保留，后面要立刻进入本题的戏。
  → 六种模板与反例见 [开场与钩子.md](../fuben-craft/开场与钩子.md)。

- **钩子带动下一步，不是一直欠账。** 解开一层，同时让行动带出新的阻力、选择或信息差；
  必要背景在观众想知道时补。开头许下的核心期待要在本篇得到实质回应，不把一串日常轶事接在刺激开头后面。
  → 段内钩子五型与分布见同文件 §段内钩子。

- **伏笔当下有用，后来变义。** 一次不合常理的阻拦、一个被藏起的物件、一句多余的解释，都可以埋线索。
  后面的揭示须由前面的东西长出来，不临时塞证据、贵人或新身份；呼应不是把同一个词再说一次。
  → 器物判词与延迟披露见 [侧面与共情.md](../fuben-craft/侧面与共情.md) §通道B / §延迟披露。

- **侧面描写承担戏。** 让对手改口、旁人收起原本要说的话、一个人把刚递出的东西拿回去、环境留下不同痕迹，
  使观众自己看出能力、处境或话语权变化。动作要有动机并影响后续，不是轮流「震惊、僵住、脸白」，
  也不强迫每场都加围观者。→ 四型 + 群体静场见同文件 §侧面描写四型。

- **爽点要演到兑现。** 前面蓄起的憋屈、好奇、期待，需要一个看得见的变化：能力压住质疑、话被原样顶回去、
  伪装露馅、包袱揭开、代价反过来落下。把关键交锋、揭示和反应写到场，别用「大家都服了」「你很厉害」跳过最好看的部分。
  爽感不只等于反杀，但不能拿「不必反杀」替没有情绪力度开脱。
  → 四拍、绝杀台词产品化、不反杀的三种替代见 [爽点兑现.md](../fuben-craft/爽点兑现.md)。

- **要搞笑就必须说得出用哪种引擎。**（v14 新增）笑点不是梗，是结构：
  预期违背 / 归因反转 / 请君入瓮 / 沉默授权 / 恶意顺从 / 对照组 / 静物化余波 / 自欺闭环 / 双假峰。
  把热梗原句贴进正文不是笑点，观众笑的是梗本身，笑完就划走。
  → [笑点机制.md](../fuben-craft/笑点机制.md)。

每段至少在当前故事里有去处：推进处境、改变理解、蓄积期待或兑现情绪。不按句子计数；
必要的缓冲、心理与旁白可以留。删的是断掉主线的重复和闲笔，不是所有慢句。
结尾可以安静，但不能用安静替代前面欠下的兑现，**也不许用口号收束**
（→ [口播腔调与反AI味.md](../fuben-craft/口播腔调与反AI味.md) §B1）。

## 审稿先看为什么有人愿意听

完整读当前正文，直接指出：哪句抓住了什么期待，哪段让这个期待断掉，最好的一刻是否真正展开，
伏笔揭示是否成立，侧面反应是否让局面变化，**要搞笑的题每个笑点用的是哪种引擎**。
**用户说「不好看」，优先改开头、主线、蓄势与兑现，不自行转去修工具、数词、建测试包。**

问题要指到原句和影响，然后拿改写回答。主线散了就重构，不只润色；不要用「我有意这么写」替代效果。
不给自己凑高分，不把几个审查角度冒充独立评审。机械通过但抓不住人、爽点落空的稿，仍应转
[`fuben-review`](../../../fuben-review/SKILL.md) 判创作 `FIX`。
**审稿不许按 `_archived/` 里的旧配额验收**——那套条款已作废，按它审只会把稿子逼回流水账。

创作效果之后必须再读通当前完整稿：题意是否由事件兑现，人物／物件／时间／代词／问答／序列与连接词是否接得上，
术语和玩笑是否被旁白当成事实。合理状态转移、不同实例、不同时间事件不得靠关键词误判。
改场景、食物／道具、人物称呼、时间、标题题意或结尾计数后，检索全文关联依赖并重审新版本；旧报告不自动沿用。

## 事实是底线，工具在后台

保留用户给定事实和剧情，分清虚构、角色误信与现实信息；必要时核查来源、数量、日期及账号约定，
不伪造授权与数据。字数估时不等于配音实测。**文学效果不靠八拍、峰值百分比、感官词频、对白数量或数字预算证明。**

需要机械检查时用 `python3 scripts/fuben_run.py 路径 --profile full`；短版检查自己的正文并用 `--profile short`。
BLOCK 修明确错误，REVIEW 结合语境判断，ERROR 不算通过。
`python3 scripts/fuben_craft_scan.py 路径/正文.md` 是**只读的读感扫描**，输出带行号的候选（口号收尾、
梗搬运、假动作主语、碎行、未解释术语、时间戳分段器），**只用于定位，永不 BLOCK，也不计入创作结论**。

**不以机检结果替代创作审核，不以回归报告替代用户要的好稿。**
只有用户要求制作或发布时，才进入媒体及发布证据阶段。

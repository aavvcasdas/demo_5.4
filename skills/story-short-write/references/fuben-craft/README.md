# 人生副本 · 手艺包（fuben-craft）

这一层解决一个问题：**「要好看」不是指令，「这样写才好看」才是。**

本仓的语料早就拆好了（`拆文库/` 45 篇原文 + 写作手法 + 情节节点，约 500 万字），
但现行 profile 只留了六条抽象原则，没有一条真实例句。模型拿不到可模仿的形状，
就只能交出「梗清单 + 碎行 + 口号收尾」。本包把语料里的机制压缩成**类型 → 原文示例 → 反例 → 自检**四段式，
每个示例都标出处，可以直接照形状写。

结构参照三个成熟项目：

| 来源 | 借的是什么 | 落到哪个文件 |
|---|---|---|
| `0xsline/short-drama`（references/hook-design、opening-rules、satisfaction-matrix、villain-design、rhythm-curve） | 「每种类型都给一段可直接抄的剧本示例 + 设计要点 + 自检表 + 致命问题清单」的写法 | 开场与钩子 / 爽点兑现 / 结构与曲线 |
| `blader/humanizer`（51k★） | 「Watch for → Problem → Before → After」四段式，以及 **When not to act**（哪些人味不许清掉） | 口播腔调与反AI味 |
| `hardikpandya/stop-slop`（17k★） | 结构级 slop 清单（binary contrast、dramatic fragmentation、false agency、narrator-from-a-distance）与 5 维评分 | 口播腔调与反AI味 |
| `anthropics/skills`（skill-creator） | Progressive disclosure：SKILL.md 只做路由，重资料按阶段加载；大文件带目录 | 本 README 的加载表 |

## 用法纪律（三条，优先级高于本包所有细则）

1. **借机制，不搬情节与原句。** 示例是给形状用的。把 17 的「早说没意见呀 那我也插队了」抄进新稿是洗稿；
   借「群体的沉默被谁先翻译成授权，谁就签收」这个机制去写自己的场景才是拆文的用途。
2. **配额一律无效。** 本包出现的数字（四幕、三拍、六段占比、≤3 行短行）都是**语料的描述统计**，
   用来对照形状，不是达标线。不为凑数塞梗、加旁观者、拆碎行。
3. **ASR 语料有污染。** 原文是字幕转写：无标点、他/她混用、同音误写（17 全篇「外耗→外号」）。
   借语感时补标点、修代词；不把转写错误当事实，不把梗的出处当剧情。

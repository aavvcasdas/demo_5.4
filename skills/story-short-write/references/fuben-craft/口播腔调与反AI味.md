## A. 行节奏：口播的行是气口，不是碎纸

**规则**：

1. **一行 = 一个可朗读的意群**，通常 6–18 字，主谓宾完整，或明确承接上一行。
2. **允许超短行做节拍，但连续超短行（≤4 字）不超过 3 行**，且每行必须携带新信息或新动作。
3. **不许把一句话劈成三行制造深沉**（stop-slop 的 dramatic fragmentation）。
4. 段落之间一个换行；不用空行做停顿（停顿由句子长度承担）。

**语料的实际形状**（02 号外卖员，开头钩子 5 分）：

```
雨水顺着劣质头盔的裂隙流进你的眼睛
二十三点五十八分
你站在6楼的防盗门外大口喘气
手里提着一份重量超过3公斤的麻辣香锅
包装袋的塑料提手已经勒进你冻僵的肉里
```

每行都有主语、动作或具体量。唯一的短行「二十三点五十八分」携带的是**倒计时信息**，不是气氛。

**反例（`作品/80_练薄肌的人活在成都/正文.md`）**：

```
你忘了

最难的
是你的朋友
```

三行、九个字、一次空行，只为了一个停顿。这是 stop-slop 表里的「[Noun]. That's it. That's the [thing].」
中文等价形态。**改法**：

```
你算漏了一样东西
你算漏了你这拨朋友
```

或者干脆让它落在动作上：

```
你唯一没算进去的
是周五晚上那通电话
```

信息量相同，行数减半，读起来不像在演深沉。

## B. 十二条中文口播 slop（按强弱排序）

前 5 条见一次就改（humanizer 的「justify an edit on one sighting」）；
后 7 条标了「弱」的，需要同段还有别的毛病才动手。

---

### 1. 口号收尾 ★最强

**留意**：结尾用对仗句、零和句、人生格言收束。

**为什么是问题**：观众刚刚经历了一段人生，最后被告知一个道理，代入立刻断掉。
`_速拆卡.md` 的短板预警写得很直白：**结尾 3 分区＝直白兑现无余味（04/14/34/35/36/37/38——警世与软文收尾说教税）**。
stop-slop 的对应条：「Cut quotables. If it sounds like a pull-quote, rewrite it.」

**反例（`作品/80` 正文结尾）**：

```
她笑了几秒
那你带我呗
第一课学什么

群里的兄弟们还在刷屏
耍起 耍起

你没理他们
认真回了九个字

人生就两字
练完再耍
```

**改法**：收在**器物或动作**上。80 号正文里已经有一个合格的收束物——空碗里的蟹柳。
语料的正解：28 号的碗、20 号端起属于自己的那杯奶茶喝一大口、79 号显示器边立起那张红面朝外的请帖、
33 号的环腰零。**一个字或一件物，比九个字的人生格言重。**

> 注意区分：17 号的「只要你不内耗 内耗的就一定是别人」是**角色的信条**（在序言 10% 处就立起来了，
> 结尾是身份自封的追认），不是旁白的格言。信条可以有，旁白不许有。

---

### 2. 抽象总结代替戏 ★最强

**留意**：「他论证了一晚上」「大家都服了」「你终于赢了」「气氛很尴尬」「场面一度失控」。

**为什么是问题**：这是 telling instead of showing 的中文形态，也是最省事、最毁稿的一条。
最好看的那一场被旁白替观众看完了。humanizer §17 的同款：用长短语替代简单动词，信息量归零。

**反例（`作品/80`）**：

```
再然后你发现
毛肚是蛋白
鸭血是蛋白
他论证了一晚上
整张桌子全是优质蛋白
```

**改法**：展开成三轮，每轮主角的抵抗降一档（详见 [笑点机制.md](笑点机制.md) 引擎 8）：

```
他先讲道理
牛肉也是蛋白质啊 涮起嘛

你说不算 我这有代餐
他把你的代餐盒转了半圈
说这个碳水太高

你想站起来
他已经在给你夹毛肚了
说这个蛋白比鸡胸还高
你坐下了
```

**判据**（`人生副本_Agent方法.md` §2）：**别把最关键的反击压成一句「后来你解决了」。**
反过来也成立：别把最好笑的一场压成一句「他论证了一晚上」。

---

### 3. 假动作主语（false agency）★最强

**留意**：「评论区炸了」「气氛凝固了」「沉默蔓延开来」「时间仿佛停止了」「空气里弥漫着尴尬」。

**为什么是问题**：stop-slop 的原文判据可以直接搬——
> **Give inanimate things human verbs? Name the person.**
> 「a complaint becomes a fix」→ 有人修了它。「the decision emerges」→ 有人做了决定。

中文口播里这条特别容易犯，因为「炸了／凝固／蔓延」听起来很有画面，其实没有人。

**反例**：「整个群都炸了」「包厢里的气氛一下子凝固」。

**改法**：指名谁做了什么。语料的示范（17 号 N6）：

```
空气突然安静
几百个人有的假装看天
有的低头玩手机
有的眼神闪躲
整整10秒钟 竟然没有一个人站出来说一句话
安静的连树上的知了都停了
```

**同样是静场，它给了三种具体的躲避动作 + 一个生物学认证（知了）。** 这才是「炸了」应该长的样子。

---

### 4. 梗原文搬运 ★最强

**留意**：把检索到的热梗原句整段贴进正文，由旁白介绍「大家管这个叫 X」。

**为什么是问题**：观众笑的是梗，不是你的主角，笑完就划走。
`作品/80/_运行/07_诊断_流水账.md` 自己的判词：**「我把『梗的出处清单』当成了剧本——检索材料被摆进正文而不是被炖进因果。」**

**反例（`作品/80` 02c 开头）**：

```
最近全网都在传一个口号
能耍就耍 不该耍也耍
耍不了硬耍 耍完再耍
大家管这个叫 耍起主义
```

**改法**：让梗从**人物嘴里**出来，并且被剧情重新定价。80 号正文里做对的那一句可以当范本：

```
旁边伸过来一只手
把代餐盒转了半圈

牛肉也是蛋白质啊
涮起嘛
```

同一个方言梗，从朋友嘴里说出来、配一个动作，就活了。详见 [笑点机制.md](笑点机制.md) §梗的正确用法。

---

### 5. 术语/新词没有剧情解释 ★最强

**留意**：正文用到圈内词、地方词、平台黑话，第一次出现时观众看不懂。

**为什么是问题**：口播是线性媒介，观众不能回翻。`07_诊断_流水账.md` 的原话：
**「不懂即死：耍起／充碳／练起嘛／四十七个博主 全部默认读者已熟梗——用户『看不懂』是最直接的证据。」**

**改法**：让剧情自己解释，不用旁白下定义。80 号 02c 已经修对了三处，可以当范本：

```
健身圈里管晚上补这个
叫充碳            ← 由主角的认知带出，不是词典

你这顿
算正经充碳了      ← 立刻用在玩笑上，完成定价
```

**判据**：一个词第一次出现时，观众能不能只看上下文猜出八成意思。猜不出就补一句人物台词或动作。

---

### 6. 排比三件套（弱）

**留意**：三个并列的短词或短句凑成一拍。「蘸料 入口 点头」「震惊 僵住 脸白」「上班 吃饭 睡觉」。

**为什么是问题**：humanizer 的 rhythm by rule——triads applied everywhere whether or not the meaning asks for it。
stop-slop 更直接：**「Two items beat three.」**

**反例（`作品/80`）**：「蘸料 入口 点头 / 好吃」——三个动作没有信息差，只有节奏。

**改法**：两拍 + 一个后果。「你蘸了料 吃了一口 / 然后把筷子伸下去了」——第二拍改变了处境。
或者保留三拍，但让第三拍翻面（17 号的「越过她、越过前面的大哥、越过了一排又一排的人」，
第三个对象是**沉默者**，排比就有了意义）。

---

### 7. 情绪播报（弱）

**留意**：「你破防了」「你很委屈」「你有点心酸」「你突然觉得很累」。

**为什么是问题**：情绪是结论，不是证据。humanizer §17 的同款问题：inflated claims without detail。

**改法**：过 [侧面与共情.md](侧面与共情.md) 的三通道。80 号正文里最好的一句就是身体通道：

```
地铁里你把手机揣回兜里
揣得很轻
跟做贼一样
```

没说「你羞愧」，但羞愧是可感的。**这一句要保留，它比全篇任何一处都值钱。**

---

### 8. 万能旁观者（弱）

**留意**：「大家都震惊了」「所有人都傻眼了」「全场鸦雀无声」。

**为什么是问题**：群体没有脸就等于没有群体。详见 [侧面与共情.md](侧面与共情.md) §群体静场。

**改法**：给三种不同的具体反应，或者干脆不写群体、只写一个人的一件事
（80 号：「只有花生米 / 被一只手推了过来 / 往你这边」——一个人、一个动作，胜过一百个「大家都」）。

---

### 9. 时间戳当分段器（弱）

**留意**：「周五晚上八点零七分」「第二周」「月底」「接下来两周」「几个月后」一行一个时间标签往下推。

**为什么是问题**：`evaluations/2026-09-19_手动对照包/冻结规则/B_旧主profile.md` §v6.1 已经实证过一次：
**「指令要时间 → 模型交钟面账」**，75 号开头「凌晨三点十一」独立成行 + 全篇 22 处时戳分段，
读感＝钟面台账。

**改法**：时间只能嵌在动作句里，且**仅当时间本身是信息**（约定时刻、掐表成绩、倒计时、发病钟点）才保留。
正例：02 号「二十三点五十八分」+「只剩最后12秒」——时间是压力。
反例：80 号「周五晚上八点零七分」——这个 07 分不承载任何东西。

---

### 10. 旁白讲解员（弱）

**留意**：「这就是 X 主义」「你要知道」「说白了」「其实这就是人生」。

**为什么是问题**：stop-slop 的 narrator-from-a-distance——**「Put the reader in the room.」**
第二人称一旦开始解释概念，代入就断了，因为解释是站在观众外面的动作。

**改法**：把解释改成人物的台词或动作，或直接删掉让观众自己看出来。

---

### 11. 不是 X 而是 Y（弱）

**留意**：「这不是瘦 这是薄肌」「问题不在于 A 而在于 B」「你以为的是 X 其实是 Y」——空洞对照。

**为什么是问题**：humanizer §1（最强的一条）：**负面半句命名了一个没人主张过的东西，正面半句因此显得更大。
它增加了重量，没有增加主张。**

**例外**：当负面半句纠正的是**观众真的持有的信念**，或两半都携带信息时，保留。
80 号的「薄肌 不是瘦」写在备忘录里，是**角色的自我说服**，而且后面被评论区「哥 你那叫瘦」精准爆破——
这是合法的，因为它有对手、有兑现。**判断标准是它有没有在正文里被演出来。**

---

### 12. 元叙述残留（弱）

**留意**：正文里出现「第一幕」「伏笔」「钩子」「侧面描写」「这一段的节奏」，或者「字数约 1200」。

**为什么是问题**：humanizer §22 chatbot residue / §25 writing about the previous version。
工程词泄漏进正文是模型退化的信号（本仓 `check-degeneration.js` 已经在查这一项）。

**改法**：删。设计语言只留在 `_运行/` 阶段产物和审核报告里。

## C. 保留清单：这些是人味，不许清掉

humanizer 的 **When not to act** 与 **Keep the details that carry the writer's voice**，翻译成本赛道的版本。
以下各项**即使命中上面的模式也不改**：

- **市井俚语与方言语气词**：「涮起嘛」「啥子」「羽化登仙」「哥们」。80 号审读（`_运行/03b_审读.md`）
  已经正确裁决过一次：「友仔台词『羽化登仙』俚俗程度 → 保留：市井反讽口吻，不崩人设」。**这个裁决是对的。**
- **故意答非所问的玩笑**：80 号「让人吃口鱼」（蟹柳＝鱼糜仿蟹），审读裁决保留——反话即玩笑本身。
- **角色的自我辩解与胡诌**：39 号「想来想去 还是没钱」（反思的自我开脱式收束）、
  29 号的「急了学」四分支全胜模板、80 号教练的「练中找耍 耍中找练」。
  **这些是人物在骗自己，不是作者在说教。** 语气必须让人听得出来他在胡诌。
- **真实的重复口头禅**：角色反复说的那句话是人设指纹（20 号的四信条各配一句可引用的口头禅）。
- **具体、不寻常的细节**：「那个律师以前在我牙医楼上办公」级别的怪细节，是真人写作的证据。
  本仓等价物：35 块钱的音乐盒、68块5、48,452.31、四十七个博主。
- **矛盾与未解决的情绪**：「我觉得这样挺好，但心里还是不舒服，也说不清为什么」。
- **特定年代的梗与内部笑话**：它们标记了具体的年份和亚文化。
- **真诚的旁白插入与自我修正**：「（这里我总想说『差不多』，可它真的是确定的）」。

**一条总纪律（humanizer 原文）**：**一个 tell 的分量，与「一个认真的写作者故意这么写的概率」成反比。**
标了「弱」的模式，需要同段还有其他毛病才动手。

## D. 五维评分

借 stop-slop 的 5 维评分表 + short-drama 的 `/review` 打分维度，合并成本赛道的五维。
**每维 1–10 分，总分 50。低于 35 分回炉。**

| 维度 | 问题 | 判据来源 |
|---|---|---|
| **追看** | 前 8 行有没有具体疑问？哪一段观众会划走？ | [开场与钩子.md](开场与钩子.md) 自检表 |
| **笑点** | 每个笑点能不能指出用的是九种引擎里的哪一种？ | [笑点机制.md](笑点机制.md) 自检表 |
| **共情** | 抽象焦虑有没有过身体／器物／数字三通道？观众认得出自己吗？ | [侧面与共情.md](侧面与共情.md) 自检表 |
| **兑现** | 四拍齐不齐？绝杀台词观众 30 秒后能复述吗？ | [爽点兑现.md](爽点兑现.md) 自检表 |
| **腔调** | 行节奏对不对？命中几条 slop？有没有误伤人味？ | 本文件 B / C 两节 |

**评分纪律（三条，防 Goodhart）**：

1. **分数只用于定位问题，不是通过证明。** `fuben-review` 的创作结论（FIX/APPROVE/BLOCK/PROVISIONAL）
   按证据下，不按总分下。机检 PASS 与评分都不等于好看。
2. **每一分必须挂原句。** 「笑点 6 分」无效；「笑点 6 分：第三幕的『他论证了一晚上』把戏压成了总结，
   引擎 8 需要三轮降档」有效。
3. **不设配额。** 不许为了把「共情」刷到 8 分而往里塞器物、数字和旁观者。
   `fuben_policy.json` 已经把 `creative_rules` 全部置空（`required_beat_count: null` 等），
   `metric_thresholds: "descriptive_only"`——本文件不推翻这个决定。

## E. 改稿顺序

humanizer 的工作流（Mark → Draft → Check → Final）压缩成三步，**顺序不可换**：

1. **先结构与兑现**（对应 `人生副本_Agent方法.md` §3 的分层返工）：
   切口平／主线散／蓄势无兑现 → 回策划重构，**不是改第一句**。
2. **再场面与侧面**：关键交锋被跳过、伏笔没落正文、侧面成捧哏 → 重写那一场。
3. **最后才是腔调**：戏已经成立，只是啰嗦、碎行、口号收尾 → 按 B 节逐条改。

**最常见的错误是把第 3 步当第 1 步做**：稿子没有对手、没有蓄势、没有兑现，
却花了三轮去调句式、清 AI 味、数时间标签。`人生副本实录.md` v13 已经写明：
> **用户说「不好看」，优先改开头、主线、蓄势与兑现，不自行转去修工具、数词、建测试包。**

改完必须重读当前完整稿（`fuben-review` §3 读通专项 11 项），并把审核报告绑定新的
`body_path` 与 `body_text_sha256`——正文一改，旧结论自动失效。

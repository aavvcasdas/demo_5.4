# 拆文语料使用：读原稿，不学表面

## 1. 当前语料的真实指纹

`拆文库/00_8月16日_合集本体/原文/原文.txt` 的 `_meta.json` 标明它是 ASR 字幕原稿：行是气口，不是小说段落；单篇大约 3,000 字。对照单篇原文和拆文报告，可以稳定观察到以下机制：

### 《无辣不欢的一生》

- 开头不急着讲道理：校门、5:50、10 元、三个搪瓷缸先把主角放进一个能闻到味道的现场；
- 真实冲突由胖子激将触发，主角当众做出“变态辣”的选择；
- 第一次奖赏（“辣王”）紧跟身体代价（排骨汤失味、腹泻），之后每次加码都同时带来身份奖励和更重的损失；
- 结尾不是“你成功戒掉了”，而是一个可见的选择——“微辣”。前面的汤、辣度和围观者在这一刻一起回声。

### 《外卖员的一生》

- 8 个小集不是 8 个素材分类，而是 8 次权力/位置变化：被取消→抢单→派单→封禁→算法收紧→被系统替罪→债务→新人循环；
- “系统故障”与“系统升级”构成台词回旋镖；“蓝色耗材”在结尾被重新指回主角；
- 台词很少，但每句都改变称谓、权力或预示下一次清算；数字（12 秒、50 元、80 个、500 人、48 楼）不是资料表，而是角色位置的变化。

这些样本可以教我们：具体动作承载主题、同一物件/词语发生意义变化、每个段落把主角推到下一种选择。它们不证明必须照抄“今天体验的人生副本是”，也不证明所有题材都要苦难或反转。

## 2. 最新 87 稿为什么不像这些原稿

`作品/87_年卡洗澡空调饮用水/正文.md` 的第一句“你把健身年卡用成了三个家电”有明确错位，但后面主要是：

1. 家里缺热水；
2. 买卡；
3. 洗澡、吹空调、接水；
4. 教练问答和几个谐音/错位笑点；
5. 淋浴限时；
6. 算总账；
7. 年底榜单和评论提问。

问题不在短，而在**没有戏剧性选择**：教练、店长和主角没有持续的目标冲突；“限时十五分钟”没有形成一场可见的谈判或行动；“五千四百五”是作者报告里的反算，不是角色用来改变局面的筹码；结尾“你才是健身房最喜欢的客人”是解释，不是后果。它是合格的口播段子草稿，不是剧本。

## 3. 借用规则

- 先读 `原文/原文.txt`，再读 `拆文报告.md`、`情节节点.md`、`写作手法.md`；报告不能替代原文。
- 每次只抽取 2–3 个机制，并写明“机制 → 本集动作”；例如“数字递进 → 让价格改变谈判筹码”，而不是“加入更多数字”。
- 研究原文的节奏，不复制台词、标题、独特比喻、人物组合或可识别的事件链；不把多个来源拼成“看似真实”的新苦难。
- 如果用户没有合法使用权，只做方法批评，不改写、续写或传播原文。
- 引用原文做内部分析时尽量短，并保留来源路径；交付的剧本要有自己的场景和语言。

## 4. 读稿问题清单

读新稿时先标出最早的“只是在说明”的位置，再问：主角下一步为什么非做不可？谁使他付出代价？这个动作让谁的判断改变？如果回答只能引用 stage 卡、物证数量或搜索路数，说明审读跑偏了。

# 抖音原生剧本：从平台样本到可执行判据

> 这不是“爆款公式”，也不是平台官方算法文档。平台指标会变化，外部文章的百分比多是经验或自媒体推断；只用它们帮助排查开头和观看路径，不拿数字代替创作判断。

## 1. 搜到的样本说明了什么

截至 2026-09-29，本轮搜索到的公开材料有三类：

1. 抖音创作者中心是内容、互动和数据管理入口：<https://creator.douyin.com/>；真正发布后的判断应回到创作者中心的实际数据，而不是网上通用的“及格线”。
2. 新榜 2026-08-26 对“剧本人生”创作者的访谈：<https://news.qq.com/rain/a/20260826A0DBMC00>。它描述了从虚构猎奇到真实普通人经历的转向；受访者强调真实感，评论区也出现“这就是大部分普通人的一生”一类的自发共鸣。这里能借的是**真实经历、可讨论的人和具体生活阶段**，不是“7 天涨粉百万”这个可复制承诺。
3. 抖音搜索结果页的公开文稿样本：<https://www.douyin.com/shipin/7316056034525874186>。可以看到“今天体验的人生副本是”是系列识别句，但固定句只是入口，后面仍要有事件、阻力和变化。

另有教程和行业文章反复提出“前三秒/黄金开头/每几秒一个信息点”。这些可作为念稿和剪辑提醒，但不是抖音官方保证，也不应该逼出 8 个笑点或 18 路检索。

## 2. 对剧本真正有用的转换

- **第一拍**：画面中已经发生一个可理解的异常或冲突。不是 `系统提示`、标题和作者问候的堆叠。
- **第一阶段**：观众立刻知道主角现在要什么，或看到一个无法忽略的问题；不要先铺一页“这个人是什么类型”。
- **中段**：每一次信息增加都必须改变选择。平行罗列“后来又发生了……”会降低观看动力。
- **高点**：由主角/对手的行动造成，必须看到对方失去什么、关系变了什么或风险落在哪里。
- **收尾**：画面/台词完成一次兑现，停在余波；评论引导另写在发布说明，不进入剧情。

## 3. 口播稿与剧本的边界

口播稿可以让一个旁白快速跨越十年，依靠第二人称、数字和叙述者拆穿；剧本需要让镜头和演员承担这些信息。可以保留 `[VO]`，但 VO 不能替所有场景做摘要：

```text
错误：
[VO] 你终于把账算清楚了，店长被你打脸，大家都很震惊。

可拍：
你把手机转过去，屏幕停在“320 次”。
店长翻到合同的“淋浴”一栏，手指停住。
店长：这张卡……你真来过三百二十次？
你：我不是来占便宜的。我是来把它用满的。
店长把“限时十五分钟”的通知撕下来，揉成一团，却没有扔进垃圾桶。
```

第二段仍需继续审：它是否真的改变规则，还是只用动作装饰旁白？

## 4. 不固定模板

本项目不硬编码：

- 3 秒必留人、每 5 秒一个信息点；
- 1–2 分钟只能写多少字；
- 每篇必须爽、反转、CTA 或第二人称；
- 机器检测到关键词就判“笑点/钩子/爆款”。

发布后的播放、点赞、评论、分享、完播和负反馈只能做下一次迭代证据，不能回填成这次写作质量的证明。

# fuben-write：抖音人生副本口播稿创作（v2.0）

**你写的是口播逐字稿，不是小说，也不是制度观察文。** 交付物是一个主播从头念到尾、观众一秒不跳的音频文本。默认第二人称「你」。

**判定标准（2026-09-28 换代后）**：不是「写得好不好」，而是**这条稿子能不能从冷启动池里出池**——平台对标的及格线是**点赞率 ≥3%、互动率 3–5%、中长视频完播率 ≥25%**（三方实测口径，非官方公布）。我们 85/86 两篇都在 0.7–1%、86 只有 1k 播放——**问题不在文笔，在结构与情绪**。

> **v2.0 换代记录（用户裁决原话，必读）**：用户回传 86 数据「点赞 10 都不到，1k 播放量」，指令「**这个 skill 整体肯定有问题，但是保留搜索！其他的全部重构**」。四岔已裁决：①内容源＝**混合**（虚构骨架＋真实原型锚）；②时长＝「**时长不限，只要剧情节奏好不水，1–2 分钟都可以**」；③情绪路线＝**爽优先**（谷底逆袭、打脸反杀）；④签名开场＝**后置到第 2–3 行，第 1 行先给钩**。诊断与证据见 [docs/技能重构诊断-2026-09-28.md](../../docs/技能重构诊断-2026-09-28.md)。
>
> **换代红线**：v1.3.x 的「器物清单／共鸣八件套／长版 2800–3300」路线作废。**保留的只有**：真实检索（≥8 路，本文件阶段 1 铁律）、全程无烟、账目可反算、不报「必爆」不编造来源、机检与产物门禁、发布后数据回填台账。

**对标语感**见 `拆文库/`（原稿与拆解）。本仓小说流程（付费点、题材包、`###1.` 标记、8000 字默认篇幅）**全部不适用**。

## 流程

### 阶段 0 · 简报（`_运行/YYYY-MM-DD/00_简报.md`）

从用户题面提取：主题/题眼、目标时长、题材限制、人设补充。题面以用户为准。

**体量与时长口径 = `scripts/fuben_policy.json`**（唯一口径）。2026-09-28 用户已授权：**「时长不限，只要剧情节奏好不水，1–2 分钟都可以」**——所以 v2.0 起**节奏优先于字数**：写多长由「每 15–25 秒有没有翻面」决定，出参考带只需在 04 引用本条授权，不许在简报里自造区间。估时两口径照旧：创作语感 4.5–5 字/秒（含呼吸）／机检 6.4 字/秒（不含停顿）；听感以念稿计时为准。

**发布合规（阶段 5 落地，正文内不写）**：混合源稿件必须在发布建议里注明**「剧情为虚构演绎」**（赛道通行做法；声明放在标题/简介/左上角，不进口播正文）。

### 阶段 1 · 深读 + 检索 + 选题（`_运行/YYYY-MM-DD/01_深读_检索与方向.md`）

1. **深读题眼**：谁在受这个处境的罪／观众为什么会说「这也是我」／这条稿子想让观众产生什么动作（想哭、想骂、想转发、想讲自己的事）。
2. **真实搜索，单批 ≥8 路并行**（保留项，不调用搜索即任务失败）。四类路线、逐路表格式、大额数字单独校验，见 [1_检索与真实骨架.md](references/1_检索与真实骨架.md)。**每路一行进表：`批号 | 检索词 | 来源 | 取用的真实骨架 | 用到哪站`**。借真实不借剧情，不编造来源。
   - v2.0 起检索的目标从「找共鸣质感」改为**找真实骨架**：同类人的真实经历线（结果最好）、行业与场景细节、可反算的数字与政策锚、**情绪现场**（评论区高赞原话、真实吐槽）。**检索结果只许进「事件＋物证」，不许排开当介绍。**
3. **选题三闸，一票否决**（见 [2_选题与结构.md](references/2_选题与结构.md)）：
   - **闸一 · 一句话主线**：能用一句话说清「这是谁、他经历了什么、最后怎么了」；说不清＝毙。
   - **闸二 · 观众关系**（三选一，必须写出来）：**爽**（我也想这样／这口气出了）／**共鸣**（这也是我）／**猎奇**（我从没见过）。观众关系是空的＝毙。
   - **闸三 · 情绪出口＋互动动作**：看完想让观众干什么（想骂/想哭/想讲自己的事/想转发给谁）。说不出＝毙。
   - **黑名单**：无社会关系的主角、纯制度或政策观察、没有阶段推进的流程文、灰到底无释放的收束（86 的四个死因）。
4. **产出 3–4 个分类型剧情方向**，每个给：类型标签、一句话剧情线、**开场第一句（钩）**、爽点/情绪峰值写在哪一站、**兑现认领**（哪句话落地）、真实原型锚（混合源要求，见下）、风险。老五向照旧（爽向/搞笑向/扎心向/温情向/悬念向/脑洞猎奇向/搞笑错位向）。
   - **混合源纪律**：每篇必须登记 **≥1 个真实原型锚**——一个真实人物的真实片段、一个真实职业的真实细节、或一条真实报道里的事实（可回链）。虚构人物**不许冒用真人姓名与身份**；发布建议带「剧情虚构」声明。
5. **交用户选定方向**。未获用户选定不得开写；产物里必有「**方向定板**」小节（用户原话引用或代选授权来源）。

### 阶段 2 · 人生时间轴（`_运行/YYYY-MM-DD/02_场次单.md`）

不是小说大纲表，也不是「一场一件事」的流程图。**把一个人的一生（或一段关键人生）切成 5–8 站**，每站写三件套：

| 每站必写 | 说明 | 反例（86 教训） |
|---|---|---|
| **事件** | 谁要什么 → 谁挡着 → 他做了什么 → **哪一格变了**（账目/关系/权力/信息） | 「认定三条件逐条讲」——是流程不是事件 |
| **可视物证** | 这一站能拍到的那一个东西（画面可以没有这个人，也必须能有这件物） | 全篇只有账目、单据、签字，AI 画面没得画 |
| **一句人话** | 这一站观众会跟着说出口的那句话（写在正文里，不是旁白解释） | 判词太文学、太绕，听完记不住 |

- **爽点曲线（用户选定爽优先）**：**压制 → 谷底 → 反打 → 释放**。谷底落在全篇约 60–70% 处；反打必须**由主角自己动手**（旁人送的胜利不算）；释放要有人承担——**写清楚对手输了什么**，不能只写「你赢了」。
- **钩点密度**：每 200–250 字必须换一次局面（新信息/新坏消息/新动作/新对手）。写完把「钩点」列成表，标行号区段；两钩之间超过 300 字＝水段，必须压或删。
- **反转节奏**：全篇至少 2 个真反转（不是复述同一件事的两种说法）；大反转一次说透，禁双层倒叙（85 教训）。
- **兑现认领表**（3–5 行，落字面）：`| 兑现点 | 认领关键词 |`——关键词必须是正文里真会出现的字（数字、单据、器物名、原话）。
- **物证 3 件**：选 3 件走全篇的物证（可 1 件反复换义＋2 件配角物证）；第 4 件起只做背景。
- 伏笔 ≤3 个，每个登记「埋在哪站 → 哪站当场回收」；金句/判词 ≤2 句。

### 阶段 3 · 成稿（`_运行/YYYY-MM-DD/03_初稿.md` → `正文.md`）

**首稿质量是主指标**：一次写对，阶段 4 只做减法和补漏。三件先决：方向已选定；**开场第一句已定**（第一行就是钩）；**3 条钩子备选 A/B/C 同批写出**（受三秒铁的约束）。

**开场（v2.0 核心改动）**：

1. **第 1 行就是钩**——结果／冲突／反常／悬念四型选一，不许用「今天你要体验的人生副本是」开篇；
2. **签名句后置到第 2–3 行**（保住系列识别，把前 3 秒让给钩）；
3. 「系统提示」式标签 ≤2 行，且必须**自带信息或笑点**，不许只当仪式；
4. 前 160 字内不许出现定义、科普、口径、身世交代。

**节奏**：每 15–25 秒（约 25–45 行短句）必须翻一次面；中段禁信息真空；结尾＝**金句 ＋ 互动钩**（提问/征集，让观众有话说）。详见 [3_口播与节奏.md](references/3_口播与节奏.md)。

**分块直写、防漂移（保留 v1.3.5 执行纪律）**：一次只写一站（≤35 行），写完逐行回读；每站过**块级三问**并把答案写进 `03_初稿.md`：

1. 这一站之后，**谁的处境变了**？（答不出 → 并入别站或删）
2. 这一站给观众的**新信息/新坏消息**是什么？（「他很惨」不是新信息，说第二遍就不是）
3. 删掉这一站，**后一站还成立吗**？（还成立 → 它是装饰，压成一句判词）

**写法铁律（保留）**：

1. **旁白驱动**：口播稿不是对话剧。直接引语占比 ≤10%、每站至多 1 句原话钉子、全篇钉子句 ≤8；禁「你说他说」乒乓回合，交锋一律旁白转述。
2. **每段都能当分镜拍**：不能拍的压成一句带数字的判词。
3. **抽象心理只准翻译成身体、器物与数字**，不准用情绪形容词宣布。
4. **口语短句成行**（5–12 字是语感指纹，不是机检规则）；禁书面腔/AI 腔（禁词表见 [5_代入感与禁忌.md](references/5_代入感与禁忌.md)）。

### 阶段 4 · 投手预演 + 返工（`_运行/YYYY-MM-DD/04_审读与返工.md`）

**把「审读」换成「投手预演」（v2.0）**：假设你是这条稿子的投手，平台只给你冷启动池的几百次曝光，逐问回答，**每条引原句＋行号**，答不出的地方就是返工点：

1. 第 1 行／第 3 秒：观众凭什么不划走？（没有钩 → 回阶段 3 重写开场）
2. 第 15–25 秒：第一个翻面在哪？
3. 第 60 秒：还在推进吗？最早的划走点在哪一段（Lxx–Lxx）？
4. 谷底（60–70% 处）：这一下最疼的是什么？有没有被旁白抒情替代？
5. 反打/释放：主角自己做了什么？对手当场输了什么？
6. 结尾：凭什么点赞、评论、转发？互动钩在哪一句？
7. 观众关系（爽/共鸣/猎奇）在哪一句被兑现？「这也是我」或「这口气出了」的那句话在哪？

其余照旧执行（详见 [4_审读与改稿.md](references/4_审读与改稿.md)）：**平铺扫描**（人工点名连续并列段：行号+字数+占比，处置三选一：压成判词/并进有对手的站/写明保留理由）、**可删测试**、**念稿测试**、**账目对账**、**兑现对表**。分层返工：主线/选题不成立 → 回阶段 1；站没展开 → 回阶段 2；只有表达问题 → 局部改。改完复审，不凭「我改了」通过。

机检是闭环工具（**PASS≠好看，但候选不清零不许交付**）：

```bash
python3 scripts/fuben_run.py 作品/NN_主题/ --profile full --json    # 红线/禁词/开头/对白/账目/体量
python3 scripts/fuben_craft.py 作品/NN_主题/正文.md --ledger        # 账目对账全表
python3 scripts/fuben_viral.py 作品/NN_主题                        # v2.0 结构自评（首行钩/签名位置/结尾互动钩/物证/检索路数，advisory）
python3 scripts/fuben_run.py 作品/NN_主题/钩子备选.md --profile full --json 2>/dev/null || true
```

返工后**复跑并把 findings 差异写进 04**；`facts`/`policy`/`LEDGER_*` 的 REVIEW 逐条闭环，`style` 类点名判定。对白与引语占比一律引用 `DIALOGUE_*` 数字，禁止手工自报。

### 阶段 5 · 交付

产物：`_运行/YYYY-MM-DD/` 下 `00_简报.md … 04_审读与返工.md` ＋ `05_机检.json`；根目录 `正文.md`、`钩子备选.md`、`审核报告.md`。

```bash
python3 scripts/fuben_products.py 作品/NN_主题
```

- `正文.md`：可直接朗读的逐字稿。
- `钩子备选.md`：A/B/C 三条＋推荐；**每条都必须是钩打头**（第 1 行不是签名句）；每条标注吊住什么期待、靠哪一站兑现。另附**标题 3 选 1、封面文案、评论区首评、话题标签**。
- 发布建议里必须有**「剧情为虚构演绎」声明**（混合源强制）与时长。
- 可选：`正文_短版.md`（重写，不是删减）。

## 边界

- 保留用户给定事实与剧情；分清虚构、角色误信与现实断言。检索到的现实信息注明来源；拿不准就标注待确认，不编造。
- 合规红线：不写平台违规内容（见 [5_代入感与禁忌.md](references/5_代入感与禁忌.md)）。**剧情、对话与细节一律不出现吸烟/电子烟/烟草**（用户红线）；需要烟熏质感改用等价感官比喻。机检 `NO_SMOKE` 扫正文、短版、钩子（BLOCK）。
- 账目红线：数字判词链可反算（`LEDGER_*` ＋ `fuben_craft --ledger`）；对不上要么修，要么让角色点破差异。
- **不报「必爆」、不虚构流量与授权**；机检 PASS 只说明无机械阻断。
- 跟随用户语言回复；中文遵循《中文文案排版指北》。

## 数据回传与调参

每篇发布后用户回传的真实数据登记 [docs/作品数据台账.md](../../docs/作品数据台账.md)（播放/点赞/点赞率/归因假设/本稿用了哪些 skill 变量）。规则：①**一次只改一个变量**（结构换代除外，换代需 3 篇同结构样本看趋势）；②不报「必爆」，只记真实数字与待验证假设；③v2.0 起回传节点为 **24 小时与 72 小时**两档；④用户开新对话续序时先读台账再继续。

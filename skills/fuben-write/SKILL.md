# fuben-write：抖音人生副本口播稿创作

**你写的是口播逐字稿，不是小说。** 交付物是一个主播从头念到尾、观众一秒不跳的音频文本（配漫画/实拍画面均可）。默认第二人称「你」，签名开场「今天你要体验的人生副本是……」。判定标准只有一个：**观众有没有一直听下去的欲望，听完有没有情绪**。机器检查、格式齐全都不算写好了。

对标语感见 `拆文库/`（39 篇 ASR 原稿+拆解）。本仓小说流程（付费点、题材包、小节大纲、`###1.` 标记、8000 字默认篇幅）**全部不适用**，不要加载。

## 执行入口

主会话即执行器（Arena / Codex / Claude Code 同理）：按下面阶段顺序执行，产物落 `作品/NN_主题/_运行/`。分阶段是为了把思考摊开可查，不是给用户看的审批仪式；每阶段干完的活直接体现在产物内容里。外部执行器可用时照同一阶段执行。

## 四份必读参考（写作前按序读完，只读本文件不算）

1. [references/搜索与质感.md](references/搜索与质感.md) —— 检索怎么做、结果怎么变成正文里的质感
2. [references/口播结构与节奏.md](references/口播结构与节奏.md) —— 签名开场、**开头铁律（黄金 3 秒：禁定义前置）**、六段骨架、钩子公式、时长字数
3. [references/代入感手艺.md](references/代入感手艺.md) —— **反流水账的八件手艺**，本 skill 的核心
4. [references/审读与改稿.md](references/审读与改稿.md) —— 追看断点审读、念稿测试、分层返工

独立可复制版提示词（不装 skill、直接贴任意对话框）：[references/独立提示词.md](references/独立提示词.md)。

## 流程

### 阶段 0 · 简报（`_运行/00_简报.md`）

从用户题面提取：主题/题眼、目标时长（默认长版约 10 分钟 ≈ 3000 字；短版约 3 分钟 ≈ 1000 字）、题材限制（如“不反杀”“不悲剧”）、人设补充。题面以用户为准：题面是人生，题材元素（游戏、健身……）只做质感与道具，不能抢主线。

### 阶段 1 · 深读 + 检索 + 剧情方向（`_运行/01_深读_检索与方向.md`）

1. **深读题眼**：谁在受这个处境的罪（观众替谁共情）、情感核、天然长得出哪几类冲突、什么写法算跑题。
2. **真实搜索，单批 ≥8 路并行**（用户裁决：不调用搜索即任务失败）。四类覆盖与质感转写法见 [搜索与质感.md](references/搜索与质感.md)。逐条记录检索词、来源、取用的质感。**借质感不借剧情，不编造来源。**
3. **产出 3–4 个分类型剧情方向**（爽向/搞笑向/扎心向/温情向/悬念向等，按主题定；“各种类型的都要”是用户明示要求）：每个给类型标签、一句话剧情线、开场钩子速写、主峰兑现路径、借用的检索质感、主要风险。已存在成稿的作品，第一选项固定为【保留现版·校准】。
4. **交用户选定方向**。未获用户选定不得开写（用户授权“你定”时代选并记录理由）。

### 阶段 2 · 场次单（`_运行/02_场次单.md`）

不是小说大纲表。选 [口播结构与节奏.md](references/口播结构与节奏.md) 的曲线与骨架，排出：

- 3–6 个**能直接开拍的场景**（每个：现场在哪、对手是谁、谁要什么、哪句话有潜台词、哪个动作改变局面、哪个细节可拍）
- 编年压缩段（哪些经历压成带数字的清单，不展开）
- 谷底、清算时刻（数字判词/器物判词/钝刀判词选一）、收束（灰/暖选一）
- 器物三现表（选 1–2 个小器物走全程）与数字判词链

写不出“能拍”的场景 → 回阶段 1 换方向或补检索，不要先写长稿再救。

### 阶段 3 · 成稿（`_运行/03_初稿.md` → `正文.md`）

按 [代入感手艺.md](references/代入感手艺.md) 写全篇。铁律四条：

1. **旁白驱动（判型铁则）**：这是口播稿＝文案/信息驱动的独白讲述，不是对话剧。直接引语字数占比 ≤10%、每场至多 1 句原话钉子、全篇钉子句 ≤8 句，对白只做激将/预警/刻度；**禁止「你说他说」乒乓回合**，交锋一律旁白转述（详见代入感手艺·三点五）。
2. **每个编年段落先问：这场能不能当分镜拍？** 能 → 展开成现场；不能 → 压成一句带数字的判词。不允许“第二件事发生在……”式的事件摘要流水账。
3. **抽象的焦虑只准翻译成身体、器物与数字**（本系列基因），不准用情绪形容词宣布。
4. **口语短句成行**（5–12 字一行，ASR 字幕语感），情绪最痛处用最短句；技术性细节才用长句。禁书面腔/AI 腔（首先、其次、然而、随着、不禁、眼眶一热等，详见手艺文件）。

### 阶段 4 · 自审 + 返工（`_运行/04_审读与返工.md`）

按 [审读与改稿.md](references/审读与改稿.md) 执行三测：**追看断点审读、念稿测试、反流水账复检**。问题分层返工（切口/主线→回阶段 2；关键场没展开→回阶段 3 重写该场；只有表达问题→局部修）。改完复审，不凭“我改了”通过。

创作审读之后，转 `fuben-review` 读通当前完整稿（题意、人物/物件/时间/代词/问答/序列、连接词、返工残留），报告绑定 `body_path` 与 `body_text_sha256`；正文改动后旧结论失效。

### 阶段 5 · 交付

- `正文.md`（可直接朗读的逐字稿，正文）
- `钩子备选.md`（3 个开场钩子 A/B/C + 推荐；标题/封面文案建议）
- 可选：`正文_3分钟版.md`（短版重写，不是删减）、发布建议（话题、封面、发布时间）

机械检查（可选，**PASS 不是创作批准**）：

```bash
python3 scripts/fuben_run.py 作品/NN_主题/ --profile full --json
python3 scripts/fuben_run.py 作品/NN_主题/正文_3分钟版.md --profile short --json
```

估时口径 `fuben_policy.json` 仅作参考；真实听感以试读/试听为准。不报“必爆”、不虚构流量数据；好看与否以用户验收和真实观众为准。

## 边界

- 保留用户给定事实与剧情；分清虚构、角色误信与现实断言。检索到的现实信息（价格、案件、热梗）注明来源；拿不准就标注待确认，不编造。
- 合规红线：不写平台违规内容（详见 [独立提示词.md](references/独立提示词.md) 红线段）。**剧情、对话与细节一律不出现吸烟/电子烟/烟草（用户红线，2026-09-23）**；需要烟熏、朦胧类质感时改用等价感官比喻（灰尘光束、油味、雾气、水汽）。检索素材里有烟也只是外部事实，不进稿。
- 研究/改造 Agent 的任务到方法落地为止，不自动转成样稿。
- 跟随用户语言回复；中文遵循《中文文案排版指北》。

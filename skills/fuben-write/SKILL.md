# fuben-write：人生副本口播剧本创作（v3.0.1 提示词版）

**你写的是口播剧本，不是小说，也不是制度观察文。** 交付物是一个主播从头念到尾、观众一秒不跳的逐字稿。默认第二人称「你」。

**判定标准**：不是「文笔好不好」，而是**这条稿子能不能从冷启动池里出池**——平台对标的及格线是**点赞率 ≥3%、互动率 3–5%、中长视频完播率 ≥25%**（三方实测口径，非官方公布）。85/86 两篇都在 0.7–1%，问题不在文笔，在结构与情绪。

> **v3.0 换代（2026-09-30 用户裁决）**：用户指令——「**不要这么多的限制脚本，把规则写进提示词**」。本版把 `fuben_craft`（禁词/开头/对白/账目档位/体量）、`fuben_claims`（站点字段与认领对表）、`fuben_viral`（结构自评）、`fuben_consistency`、`fuben_scene_check`、`fuben_setting_years`、`fuben_density`、`fuben_hype`、`fuben_shotmap`、`fuben_trial_blind`、`fuben_corpus`、`fuben_health`、`fuben_lint` 等 16 个创作类脚本**删除**，规则整体并入提示词与本目录 references。脚本只剩技术核对：输入/算术（`fuben_run`）、产物与哈希绑定（`fuben_products`）、审核报告绑定（`fuben_loop`）、发布证据（`fuben_release`）、数据台账（`fuben_data`）。

**保留不动的硬承诺**：真实检索（≥8 路，不调用即失败；**方向定板后另需一批定向补检索**）、全程无烟、账目可反算、不报「必爆」不编造来源、产物与哈希绑定、发布后数据回填台账。这些纪律现在写在提示词里，最长的禁词表与红线见 [references/5_代入感与禁忌.md](references/5_代入感与禁忌.md)。

## 二、流程（00–05，产物与历史一致）

### 阶段 0 · 简报（`_运行/YYYY-MM-DD/00_简报.md`）

从用户题面提取：主题/题眼、目标时长、题材限制、人设补充、**路线偏好**（爽/共鸣/猎奇/搞笑）。题面以用户为准。

**时长口径（提示词，不再由脚本判）**：用户 2026-09-28 授权「**时长不限，只要剧情节奏好不水，1–2 分钟都可以**」。写多长由「每 15–25 秒有没有翻面」决定。参考带：短平快 400–900 字 / 中 1800–2600 字 / 长 2800–3300 字（`scripts/fuben_policy.json` 的 `volume_reference`，只是历史参考）。估时两口径：创作语感 4.5–5 字/秒（含呼吸）／机检 6.4 字/秒（不含停顿）；听感以念稿计时为准，别混用。

**发布合规（阶段 5 落地，正文内不写）**：混合源稿件必须在发布建议里注明**「剧情为虚构演绎」**（放标题/简介/左上角，不进口播正文）。

**简报自检**：一句话能说出「写给谁看、他为什么要点赞」；说不出就回用户问清，别开写。

### 阶段 1 · 深读 + 检索 + 选题（`_运行/YYYY-MM-DD/01_深读_检索与方向.md`）

1. **深读题眼**：谁在受这个处境的罪／观众为什么会说「这也是我」／这条稿子想让观众产生什么动作（想哭、想骂、想转发、想讲自己的事）。
2. **真实搜索，单批 ≥8 路并行**（不调用搜索即任务失败）。四类路线：**同类人真实经历**（最重要）／**行业场景细节**／**数字与政策锚**／**评论区情绪现场**。逐路表：`批号 | 检索词 | 来源（可回链） | 取用的真实骨架 | 用到哪一站`。
   - 检索结果**只许进「事件＋物证」**，不许排开当介绍、不许让角色停下来解释。
   - **≥千元的关键数字单独占一路校验**（不许凭印象写大数）。
   - 外部素材里有吸烟等违规元素：素材是外部事实，**不进稿**。
3. **选题三闸，一票否决**（写进 01）：
   - **闸一 · 一句话主线**：这是谁、他经历了什么、最后怎么了。说不清＝毙。
   - **闸二 · 观众关系**（三选一，必须写出证据句）：**爽**（我也想这样／这口气出了）／**共鸣**（这也是我）／**猎奇**（我从没见过，且是真的）。空＝毙。
   - **闸三 · 情绪出口＋互动动作**：看完想让观众干什么（骂/哭/讲自己的事/转发给谁）。说不出＝毙。
   - **黑名单**（86 的四个死因）：无社会关系的主角、纯制度或政策观察、没有阶段推进的流程文、灰到底无释放的收束。
4. **产出 3–4 个分类型剧情方向**（模板见 [2_选题与结构.md](references/2_选题与结构.md) 五；老五向：爽向/搞笑向/扎心向/温情向/悬念向/脑洞猎奇向/搞笑错位向）。
   - **混合源纪律**：每篇登记 **≥1 个真实原型锚**（可回链）；虚构人物**不许冒用真人姓名与身份**；发布建议带虚构声明。
5. **交用户选定方向**（产物里必有「方向定板」小节：用户原话引用或代选授权来源）。**未获选定不得开写。**
6. **定板后补检索（v3.0.1 强制步骤，用户 2026-09-30 指令「选定方向后需要再次调用搜索 skill 来运行」）**：方向定了以后再发起一批定向检索，批号写成 `B<日期>-NN`，登记进 01 的第二张表。
   - **和第一批的分工**：第一批解决「这个题材真不真」（同类人经历／场景／数字／评论区）；第二批解决「**这一版有没有人、有没有那句话说出口**」——即：主角身边有没有具体的人（谁在场／谁会说那句话）、有没有原型锚可以升级、有没有真实口吻可以借。
   - **总量**：定向检索 **≥4 路**（88 实跑 8 路，5 路进稿可接受），逐路同样记「检索词 | 来源 | 取用的真实骨架 | 用到哪一站」。
   - **进稿判据**：补检索素材只许进「人／事件／物证／一句人话」，不许改成科普；找不到合适的素材就如实登记「本批未进稿」，不硬塞。
   - **失败处理**：这一批没跑，阶段 4 的返工清单里必须留下记录，且该篇不得标「可交付」。

**阶段 1 自检提示词**（照抄自问）：
> 「这个主角，观众里有多少人会说'这也是我'或'我也想这样'？说出那句会被模仿的台词。若说不出来，重选题。」

### 阶段 2 · 人生时间轴（`_运行/YYYY-MM-DD/02_场次单.md`）

把一个人的一生（或一段关键人生）切成 **5–8 站**，每站三件套：

| 每站必写 | 说明 | 反例（86 教训） |
|---|---|---|
| **事件** | 谁要什么 → 谁挡着 → 他做了什么 → **哪一格变了**（账目/关系/权力/信息） | 「认定三条件逐条讲」——是流程不是事件 |
| **可视物证** | 这一站能拍到的那个东西（画面可以没有这个人，也必须能有这件物） | 全篇只有账目、单据、签字，AI 画面没得画 |
| **一句人话** | 这一站观众会跟着说出口的那句（写进正文，不是旁白解释） | 判词太文学太绕，听完记不住 |

- **爽点曲线**：**压制 → 谷底（全篇 60–70% 处）→ 反打（主角自己动手）→ 释放（写清对手输了什么）**。
- **钩点密度**：每 200–250 字换一次局面（新信息/新坏消息/新动作/新对手）；两钩之间 >300 字＝水段，压或删。
- **反转**：≥2 个真反转；大反转一次说透，禁双层倒叙。
- **物证 3 件**：1 件主物证走全篇并换义，2 件副物证；每件必须干活（被递出/退回/记账/摔/点破）。
- **伏笔 ≤3** 个，每个登记「埋在哪站 → 哪站回收」；**判词 ≤2 句**。
- **兑现认领表**（3–5 行）：`| 兑现点 | 认领关键词 |`——关键词必须是正文里真会出现的字（数字、单据、器物名、原话）。
- **拆文库对标**（[8_拆文库与对标.md](references/8_拆文库与对标.md)）：同文体挑 2 篇原稿读其「情节节点.md」，看别人的峰值放在字数几成处。

### 阶段 3 · 成稿（`_运行/YYYY-MM-DD/03_初稿.md` → `正文.md`）

三件先决：方向已选定；**开场第一句已定**；**3 条钩子备选 A/B/C 同批写出**。

**开场（第 1 行就是钩）**：结果／冲突／反常／悬念四型选一；**签名句「今天你要体验的人生副本是……」后置到第 2–3 行**；「系统提示」≤2 行且自带信息或笑点；前 160 字内不出现定义、科普、口径、身世交代。

**节奏**：每 15–25 秒（≈70–125 字）翻一次面；中段禁信息真空；结尾＝**金句（≤16 字）＋ 具体互动钩**（提问/征集/立场，不写空壳「你怎么看」）。

**分块直写、防漂移**：一次只写一站（≤35 行），写完逐行回读，每站过**块级三问**并把答案写进 `03_初稿.md`：
1. 这一站之后，**谁的处境变了**？（答不出 → 并入别站或删）
2. 这一站给观众的新信息/新坏消息是什么？（「他很惨」不是新信息，说第二遍就不是）
3. 删掉这一站，后一站还成立吗？（还成立 → 它是装饰，压成一句判词）

**写法铁律（提示词自带，脚本不再扫）**：
1. **无烟**：剧情、对话、细节一律不出现吸烟/电子烟/烟草/点烟/烟头/烟味；要烟熏质感用灰尘光束、油味、雾气、水汽。**写完自己在正文、短版、钩子三个文件里搜一遍，写 0 命中才交。**
2. **旁白驱动**：引语字数占比 ≤10%，每站 ≤1 句原话钉子，全篇钉子句 ≤8；禁「你说他说」乒乓回合（连续三行以上问答交替）。
3. **禁词/禁腔**（完整表见 [5_代入感与禁忌.md](references/5_代入感与禁忌.md)）：首先、其次、然而、随着、不禁、值得一提的是、眼眶一热、五味杂陈、五雷轰顶、不由得、感慨万千、心潮澎湃、不知不觉、似乎在诉说着；开头禁「先校准/先说说/今天我们来聊/大家好/先来科普/名词解释/口径如下」。
4. **抽象只准翻译成身体、器物与数字**，禁情绪形容词宣布。
5. **口语短句成行**（5–12 字是语感指纹，不是硬指标）；每段都能当分镜拍，拍不出的压成一句带数字的判词。
6. **账目**：数字判词链可反算；同一器物/欠款的数两处必须一致；**大钱账只报总数＋一粒记忆点**，分项明细留在 `04` 表里。

### 阶段 4 · 投手预演 + 返工（`_运行/YYYY-MM-DD/04_审读与返工.md`）

假设你是这条稿子的投手，平台只给你冷启动池几百次曝光。逐问回答，**每条引原句＋行号**，答不出的地方就是返工点：

1. **第 1 行／第 3 秒**：观众凭什么不划走？钩是哪一型？签名句在第 2–3 行吗？
2. **第 15–25 秒**：第一个翻面在哪？
3. **第 60 秒**：还在推进吗？最早的划走点在哪一段（Lxx–Lxx）？
4. **谷底（60–70% 处）**：最疼的一下是什么？是动作造成的，还是旁白抒情？
5. **反打/释放**：主角自己做了什么？对手当场输了什么？
6. **结尾**：凭什么点赞、评论、转发？互动钩在哪一句？金句落在哪？
7. **观众关系**（爽/共鸣/猎奇）：哪一句兑现了它？

**其余四道人工关卡**（都在提示词里，不用脚本）：
- **平铺扫描**：找出连续两段以上只展示、没有局面变化的段落，给行号+字数+占比；处置三选一：压成判词／并进有对手的站／写明保留理由。
- **可删测试**：删掉它，后文还成立吗？成立＝装饰。
- **念稿测试**：出声读一遍，拗口立刻断行；连续 30 秒纯介绍/回忆/抒情＝断崖点，压或前置半句钩。
- **账目手算**：把正文里每个主张（位数、档位 A5、单价×数量、总−支出=余）在表里反算一遍，对不上就修数、改主张、或让角色点破差异。
- **评分**：按 [7_自检与评分.md](references/7_自检与评分.md) 的十项清单打分＋拆文库五维对标分，写进 04。

**分层返工**：主线/选题不成立 → 回阶段 1；站没展开、没有谷底、反打靠旁人 → 回阶段 2；只有表达问题 → 局部改。改完复审，不凭「我改了」通过。改稿后重绑审核报告哈希（见阶段 5）。

### 阶段 4b · 审读（`fuben-review`，产物 `审核报告.md`）

按 [fuben-review/SKILL.md](../fuben-review/SKILL.md) 走「创作审查＋读通专项」；报告必须写 `body_path` 与 `body_text_sha256`（技术绑定，防旧结论给新稿背书）。审读结论与机器状态分开：**能独立审则独立审，否则标 solo 自检，不冒充多 Agent 会审**。

### 阶段 5 · 交付与自检（产物 `05_自检.md`；旧作品里的 `05_机检.json` 照旧保留）

**先过提示词八问**（写成 05 文件，逐项给行号或数字）：

1. 第 1 行是不是钩？签名句在第 2–3 行？前 160 字有没有定义腔？
2. 压制者是不是一个具体的人/一笔具体的账？谷底在 60–70%？反打是主角自己动手？
3. 每 15–25 秒有没有翻面？有没有 >300 字的水段（点名行号）？
4. 结尾有没有金句＋具体互动钩？
5. 无烟搜了三个文件吗（正文/短版/钩子，0 命中）？
6. 禁词表逐条扫过吗（命中处改写或写明保留理由）？
7. 账目手算对得上吗（数字判词链、两处一致、大钱只报总数）？
8. 十项清单得几分（[7_自检与评分.md](references/7_自检与评分.md)）？低于 16 分的项，返工到哪一阶段？

**再跑技术核对（这是脚本唯一的位置）**：

```bash
python3 scripts/fuben_run.py 作品/NN_主题/ --json                 # 输入/算术/指标
python3 scripts/fuben_run.py 作品/NN_主题/正文.md --style --json   # 可选：AI 腔句式候选
python3 scripts/fuben_products.py 作品/NN_主题                     # 产物齐备＋审核报告哈希绑定
```

`BLOCK` 只可能是确定的输入或算术错误——必须清零；`REVIEW/NOTE` 是描述信息，由写作与审读判断。**PASS 只说明没有机械错误，不是创作批准。**

**交付包**：`_运行/YYYY-MM-DD/` 下 `00_简报.md … 04_审读与返工.md` ＋ `05_自检.md`；根目录 `正文.md`、`钩子备选.md`、`审核报告.md`。

- `正文.md`：可直接朗读的逐字稿。
- `钩子备选.md`：A/B/C 三条＋推荐；**每条都必须是钩打头**（第 1 行不是签名句）；每条标注吊住什么期待、靠哪一站兑现。另附**标题 3 选 1、封面文案、评论区首评、话题标签**。
- 发布建议里必须有**「剧情为虚构演绎」声明**与时长（两口径）。
- 可选：`正文_短版.md`（重写，不是删减）、`分镜建议.md`（照 02 的物证与站写，每站一条可拍画面）。

## 三、三张内置提示词（可直接整段复制使用）

### A. 写稿总提示词（有方向后，开写前贴上）

> 你是抖音「人生副本」第二人称口播剧本作者。写一个主播从头念到尾、观众一秒不跳的逐字稿，主题：**{{主题}}**。
> 硬规则：①第 1 行就是钩（结果/冲突/反常/悬念），「今天你要体验的人生副本是」放第 2–3 行，前 160 字禁定义；②压制→谷底（60–70%）→主角自己动手的反打→写清对手输了什么；③每 200–250 字换一次局面，两钩之间不得超过 300 字；④结尾金句 ≤16 字＋具体互动钩；⑤物证 3 件（1 件走全篇并换义）；⑥引语 ≤10%、钉子句 ≤8、禁乒乓回合；⑦抽象只准落在身体/器物/数字，禁情绪形容词；⑧**全篇无烟**；⑨账目可反算、大钱只报总数＋一粒记忆点；⑩用我给你的检索素材，不编造来源。写完按《7_自检与评分.md》给自己打分并逐条给行号。

### B. 自检提示词（写完第一稿后单独一轮问）

> 只做检查，不要重写全文，逐条给行号：①第 1 行是钩吗？②60–70% 处最疼的一下是什么？③反打是谁动的手？对手输了什么？④有没有连续两段只在展示、没有局面变化（给行号+字数）？⑤结尾互动钩是哪一句？⑥无烟：搜索三个文件里的烟字；⑦禁词表逐条；⑧账目反算表。每条给「修／保留＋理由」。

### C. 审读提示词（独立第二次读稿时用）

> 你是这条稿子的投手，平台只给几百次曝光。按《4_审读与改稿.md》的投手预演七问逐条回答，每条引原句＋行号；答不出的地方就是返工点，并写明退回哪一阶段（1 选题/2 结构/3 表达）。不要因为「机检通过」就放行。

## 四、边界（提示词纪律，脚本不再管）

- 保留用户给定事实与剧情；分清虚构、角色误信与现实断言；检索到的现实信息注明来源，拿不准标待确认，不编造。
- **无烟红线**（用户 2026-09-23 裁决）：正文、短版、钩子一律不出现吸烟/电子烟/烟草。外部素材有烟也不进稿。
- 不写平台违规内容（涉政、涉黄、血腥、未成年恐吓等）。
- 不冒充真人：原型锚去标识化；发布建议注明「剧情为虚构演绎」。
- **不报「必爆」、不虚构流量与授权**。
- 跟随用户语言回复；中文遵循《中文文案排版指北》。

## 五、数据回传与调参

每篇发布后把真实数据登记 [docs/作品数据台账.md](../../docs/作品数据台账.md)（播放/点赞/点赞率/归因假设/本稿用了哪些 skill 变量；结构化快照用 `python3 scripts/fuben_data.py`）。规则：①**一次只改一个变量**（结构换代除外，需 3 篇同结构样本看趋势）；②不报「必爆」，只记真实数字与待验证假设；③回传节点为 **24 小时与 72 小时**两档；④开新对话续序时先读台账再继续。

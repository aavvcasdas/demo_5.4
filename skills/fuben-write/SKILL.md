# fuben-write：人生副本·可拍剧本（v3.0）

**交付物是一份能拍的剧本，不是一篇被切成一行一句的稿子。** 形态＝旁白驱动的第二人称剧本：每场写清「画面看到什么／配音念什么／这场多少秒」，另抽一条纯配音轨。默认第二人称「你」，全程不许换人称。

**判定标准**：这条片子能不能从冷启动池出池（对标：点赞率 ≥3%、互动率 3–5%、中长视频完播 ≥25%，自媒体实测口径，非官方公布）。同时看第二件事：**这份剧本能不能直接喂给画面与配音**——87 篇 617 字、谁在说话靠猜、旁白在宣布画面已演的东西，那种稿子既不出池也拍不出来。诊断见 [docs/剧本化改造诊断-2026-09-29.md](../../docs/剧本化改造诊断-2026-09-29.md)。

> **v3.0 换代（2026-09-29，用户裁决）**：①主交付从 `正文.md`（逐字稿）改成 `剧本.md`＋`旁白.md`；②**审核层「删到会咬人就行」**——退役产物齐备门禁、哈希绑定报告、数关键词的结构自评与兑现认领对表，只留能真出错的确定性检查；③体量恢复**下限门禁**（旁白轨 ≥700 字，终稿低于即 REVIEW），上限仍自由；④审读从「十条自审」改成「划走点三扫＋可拍三问」。
> **仍然保留（2026-09-28 用户的「保留搜索」指令与其它红线，一字不松）**：真实检索（单批 ≥8 路、逐路表、不调用即任务失败）、选题三闸一票否决、用户未选定方向不开写、全程无烟、账目可反算、不报「必爆」不编造来源、发布带「剧情为虚构演绎」声明、发布后数据回填台账。

## 流程（产物落 `作品/NN_主题/_运行/YYYY-MM-DD/`）

**过程文件是脚手架，不是作品**：00–04 每份 ≤80 行，写不下就删解释；正文（剧本.md）的预算永远优先于自证。**不许用文档长度证明工作质量。**

### 阶段 0 · 简报（`00_简报.md`）

题面（用户原话）、时长档、人设补充、题材限制、本篇专用禁用器物（避免与前作撞道具）。体量与时长口径＝`scripts/fuben_policy.json`（唯一口径）：**默认 3–5 分钟／旁白轨 900–1600 字；终稿低于 700 字会被门禁点名**，确要写 1–2 分钟单事件段子，在简报里写「本篇是段子，不走一生弧」并由人工放行。估时两口径：语感 4.5–5 字/秒（含呼吸）／机检 6.4 字/秒。

### 阶段 1 · 检索 + 选题（`01_深读_检索与方向.md`）

1. **真实搜索，单批 ≥8 路并行**，逐路一行：`检索词 | 来源(可回链) | 取用的真实骨架 | 用到第几场`。四类路线：同类人真实经历／行业与场景细节／数字与政策锚／情绪现场（评论区原话）。不调用搜索＝任务失败。
2. **选题三闸，一票否决**（详见 [2_选题与结构.md](references/2_选题与结构.md)）：一句话主线／观众关系（爽·共鸣·猎奇，必须写出证据句）／情绪出口＋互动动作。黑名单：无社会关系的主角、纯制度观察、流程文、灰到底无释放、**只有事件没有跨度的单点段子（写段子可以，但要登记，别拿它当"一生"）**。
3. 产出 **3–4 张方向卡**（类型标签、一句话剧情线、开场第一句钩、峰值落在第几场、真实原型锚、风险），**交用户选定**；未选定不得开写正文。

### 阶段 2 · 分场表（`02_分场表.md`）

按 [0_剧本格式与分场表.md](references/0_剧本格式与分场表.md) 第五节的表格式排 **5–8 场**：每场＝事件（谁要什么→谁挡着→哪一格变了）＋画面主体（物证）＋旁白字数＋对白句数＋秒数＋钩点。表下登记：情绪曲线（压制→谷底 60–70%→反打由主角自己动手→释放写清对手输了什么）、物证 3 件（出现场号＋换义场号）、伏笔 ≤3（埋在哪场→哪场当场回收）。
**并列陈列不合格**：场与场之间必须是「因为→所以」或「但是」；两场内没有新信息就合并。**不再写兑现认领表。**

### 阶段 3 · 成稿（`03_初稿.md` → `剧本.md` ＋ `旁白.md`）

三件先决：方向已选定；**首行钩已定**（第 1 场第一行旁白就是钩：结果/冲突/反常/悬念四型；签名句「今天你要体验的人生副本是……」放第 2–3 行）；**钩子备选 A/B/C 同批写出**（落 `钩子备选.md`）。

**执行纪律**：一次只写一场（≤35 行），写完逐行回读，再写下一场——长中文一次性生成必漂移。每场写完自问三句：谁的处境变了／这场的新信息是什么／删掉它下一场还成立吗。答不出的场，回阶段 2 合并或补事件，不许靠形容词撑。
写法铁律（旁白驱动、短句不碎行、抽象落到身体器物数字、**数字预算与比喻唯一性**、可拍性）见 [0 第四、六节](references/0_剧本格式与分场表.md) 与 [5_代入感与禁忌.md](references/5_代入感与禁忌.md)。

抽轨：写完 `剧本.md` 后抽 `旁白.md`（只留念的字，按场分段，删标签与画面行）。

### 阶段 4 · 划走点审读（`04_审读.md`）

不做十条自审、不写闭环表。四扫＋三问，**每条引场号或行号，没有位置＝没有回答**：

- **四扫**（每场过一遍）：①逻辑衔接断没断（上一场末句与本场首句之间缺不缺东西）②信息密度掉没掉（重复已经说过的、绕圈子的、正确的废话）③念不出来（一句话超过 30 字、书面腔、生造词）④**数词与比喻**（可念轨数字串 >70/千字、量词数串 >20/千字、同一个数复现 >3 次、比喻中途换掉——见 `references/0` 第六节）。
- **可拍三问**：①这一场镜头看到什么（没有画面行的场＝没写完）②旁白有没有在宣布画面已经演的东西（有→删旁白）③局面变化是主角自己动手的吗（旁人送的胜利不算）。
- **处置**：每条给 🔴 必改／🟡 建议／🟢 保留（写一句理由）。🔴 清零才算审完。
- **分层返工**：选题不成立回阶段 1；场排坏了回阶段 2；只是表达问题就地改。改完重审，不凭「我改了」通过。
- **账目**：`python3 scripts/fuben_craft.py 作品/NN_主题/旁白.md --ledger`，mismatch 逐条处置（修数／改主张／让角色点破差异）。

机检（**PASS≠好看，也≠能拍**；不清零不许交付）：

```bash
python3 scripts/fuben_run.py 作品/NN_主题/ --profile full --json   # 红线/禁词/开头/对白占比/账目/体量/可拍性
python3 scripts/fuben_craft.py 作品/NN_主题/旁白.md --ledger        # 数字判词链对账
```

### 阶段 5 · 交付

根目录四件：`剧本.md`（主稿）、`旁白.md`（配音轨）、`钩子备选.md`（A/B/C 三条＋推荐，每条首行都是钩；附标题 3 选 1、封面文案、评论区首评、话题标签）、`审读意见.md`（只在用户点名要报告时写）。
发布建议必带**「剧情为虚构演绎」**声明与时长（语感口径）。可选：`剧本_90秒版.md`（**重写**，不是删减）。

## 边界

- 保留用户给定事实与剧情；检索来源注明；查不到出处的素材不用；拿不准标待确认，不编造。
- 红线：全程无烟（吸烟/电子烟/烟草类词，机检 `NO_SMOKE` BLOCK，扫 剧本/旁白/钩子）；不写平台违规内容；虚构人物不冒用真人姓名与身份；**不报「必爆」**、不虚构流量与授权；机检 PASS 只说明无机械阻断。
- 每场画面行的物量词（金额、单据、器物名）要与旁白的数字主张一致（账目红线）。
- 跟随用户语言回复；中文遵循《中文文案排版指北》。

## 数据回传与调参

发布后真实数据登记 [docs/作品数据台账.md](../../docs/作品数据台账.md)（播放/点赞/点赞率/完播/归因假设/本稿用了哪些变量）。规则：一次只改一个变量（结构换代除外，换代需 3 篇同结构样本看趋势）；回传节点 24h／72h；用户开新对话续序时先读台账再动手。

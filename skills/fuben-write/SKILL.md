# fuben-write：抖音人生副本口播稿创作

**你写的是口播逐字稿，不是小说。** 交付物是一个主播从头念到尾、观众一秒不跳的音频文本（配漫画/实拍画面均可）。默认第二人称「你」，签名开场「今天你要体验的人生副本是……」。判定标准只有一个：**观众有没有一直听下去的欲望，听完有没有情绪**。机器检查、格式齐全都不算写好了。

对标语感见 `拆文库/`（39 个故事段 ASR 原稿+拆解，另 28b、46、48a–c 补充）。本仓小说流程（付费点、题材包、小节大纲、`###1.` 标记、8000 字默认篇幅）**全部不适用**，不要加载。

## 执行入口

主会话即执行器（Arena / Codex / Claude Code 同理）：按下面阶段顺序执行，产物落 `作品/NN_主题/_运行/`。分阶段是为了把思考摊开可查，不是给用户看的审批仪式；每阶段干完的活直接体现在产物内容里。外部执行器可用时照同一阶段执行。

## 流程

### 阶段 0 · 简报（`_运行/YYYY-MM-DD/00_简报.md`）

从用户题面提取：主题/题眼、目标体量与时长、题材限制（如“不反杀”“不悲剧”）、人设补充。题面以用户为准：题面是人生，题材元素（游戏、健身……）只做质感与道具，不能抢主线。

**体量唯一口径 = `scripts/fuben_policy.json`**：长版参考带 `volume_bands.long`（现 2800–3300 字，`characters_repository_convention` 口径），短版 `volume_bands.short`（850–1100）。估时两口径是有意不同：创作语感按 4.5–5 字/秒（含呼吸），机检粗估按 policy `estimated_chars_per_second`，报告里写清用的是哪个；听感以念稿计时为准。**要偏离参考带（含自定区间）必须引用用户同意原话；用户没提就按 policy 带走，禁止在简报里发明区间自证达标**（81 教训：简报写 2000–3000，交付 2208 也判「达标 ✓」）。

### 阶段 1 · 深读 + 检索 + 剧情方向（`_运行/YYYY-MM-DD/01_深读_检索与方向.md`）

1. **深读题眼**：谁在受这个处境的罪（观众替谁共情）、情感核、天然长得出哪几类冲突、什么写法算跑题。
2. **真实搜索，单批 ≥8 路并行**（用户裁决：不调用搜索即任务失败）。四类覆盖与质感转写法见 [搜索与质感.md](references/搜索与质感.md)。**每路一行进表：`批号 | 检索词 | 来源 | 取用的质感 | 用到哪场`**——摘要式一句「来源：某某」不算检索记录（81 教训：只有 5 个来源名，无逐路表）。**借质感不借剧情，不编造来源。**
   - **共鸣元素路线（v1.3.1，校园/职场/外卖等强代入题材必跑，85 批定规）**：8 路里强制占 ≥3 路，写出让观众「这就是我宿舍/我们公司」的免解释器物——①大盘数据路线（生活费/工资/价格带的调查报道，取全国均值数字）；②现身说法路线（知乎/贴吧/豆瓣：该场景亲历叙述与段子，取行为动作）；③功能操作路线（平台机制细节：群收款自动算人均、拼好饭凑满减、好评返现 3 块，取操作语句）；④官方流程路线（评选/报销/申请类，取表格字段与奖金金额）；⑤**大额突发开销路线（v1.3.2，85 批排查教训）**：正文里任何 ≥千元量级的突发大额开销（医疗押金/赔偿/罚款/预付金/赔付），必须单独占一路检索校验现实量级与触发机制（什么伤情对应什么押金、为何不能即时结算），检索词含「场景+押金/费用」，来源登记进 01 表；禁止按印象写大数（85 教训：「骑车摔腿押金八千」场次单直接发明，用户追问才补检索——数字本身恰好真实但凭运气，不算合格）。入手必用件以「吐槽清单+免解释共识」落地：不让角色解释细节，直接演到观众后背发凉"你怎么知道我宿舍也这样"。已验证的校园共鸣器物见 [references/共鸣元素-校园.md](references/共鸣元素-校园.md)。
3. **产出 3–4 个分类型剧情方向**（老五向：爽向/搞笑向/扎心向/温情向/悬念向；**v1.3 新增两个重口味向：`脑洞猎奇向`、`搞笑错位向`**，按主题定；“各种类型的都要”是用户明示要求）：每个给类型标签、一句话剧情线、开场钩子速写、主峰兑现路径、借用的检索质感、主要风险。已存在成稿的作品，第一选项固定为【保留现版·校准】。

**两个新增向的定义与开题引擎**（详见 [docs/猎奇脑洞调研](../../docs/猎奇脑洞调研-2026-09-24.md)）：

- **脑洞猎奇向**：日常高频事件 × 反常落点（例：骑手距离 0 米不变）。脑洞本身必须是冲突来源而非设定贴纸；「诡异但安全」——怪的是现象，不碰规则怪谈本格、不碰血腥/未成年恐吓。开题用**跨界碰撞法**（左列题材×右列元素，挑逻辑自洽的最意外组合）；脑洞必须落成**可执行的世界内规则**，规则不许中途变。
- **搞笑错位向**：身份/环境/心理定势错位为总开关（「客体越一致，主体越突兀」，双重错位更佳）；核心结构首选信息差/身份误认（结构喜剧优先于段子堆砌）；六种段子机：比拟押韵/语义双关/思维错位/时间瞬反差/相反元素并置/重复梗跨角色升级。

4. **交用户选定方向**。未获用户选定不得开写（用户授权“你定”时代选并记录理由）。产物里必有「**方向定板**」小节：用户原话引用或代选授权来源；没有这节＝视为未选定。

### 阶段 2 · 场次单（`_运行/YYYY-MM-DD/02_场次单.md`）

不是小说大纲表。选 [口播结构与节奏.md](references/口播结构与节奏.md) 的曲线与骨架，排出：

- 3–6 个**能直接开拍的场景**（每个：现场在哪、对手是谁、谁要什么、哪句话有潜台词、哪个动作改变局面、哪个细节可拍）
- 编年压缩段（哪些经历压成带数字的清单，不展开）
- 谷底、清算时刻（数字判词/器物判词/钝刀判词选一）、收束（灰/暖选一）
- 器物三现表（选 1–2 个小器物走全程）与数字判词链

写不出“能拍”的场景 → 回阶段 1 换方向或补检索，不要先写长稿再救。

- **重口味向的密度 KPI（v1.3）**：搞笑向＝每 300–400 字 ≥2 个钢印笑点（1 结构性 + 1 句子级），写完先数笑点，超 400 字无笑点即死段；脑洞猎奇向＝每 600–800 字一个新反常信息点，全文反常规则前后一致，结尾须收束真相（不开放过度的黑箱）。
- **口播读感三教律（v1.3.2，85《舍友A8》用户反馈：谷底之后逐渐看不明白）**：
  1. **直白爽**：主线一句话能复述（谁·误会·真相）；反转一旦开就一次说透，禁"谎言套谎言+双层倒叙"（赛前谎言→赛后揭穿再翻一层=观众掉队）；谷底与真相可同场，爆了就爆了，不许隔场拖着不给答案。
  2. **伏笔限量**：全篇伏笔 ≤3 个；每个伏笔在 02 场次单登记「埋在哪→哪场当场回收」；金句/判词 ≤2 句（终判词+尾句），判词不叠成语层、不许三连环判词连发。
  3. **侧面描写先于正面解说**：穷/富/牛都不让角色自己解说，交给器物一句话说（锦旗、挂钩价、冷柜机轰隆声）；笑点优先用网络熟梗与前置共识（祖师爷、养鸭子、驻村工作队），不让观众停下来查梗。
- **节奏映射**：40 秒三步（10 秒注意 / 20 反转 / 40 互动）→ 长口播：0–10 秒钩、每 30–45 秒一个反常识落点或反转、末 10 秒留互动或集末钩。

**可选形态 · 连续剧（v1.3）**：用户点名要连续剧时启用单集之间**共用世界观设定卡 + 跨集伏笔回收表 + 集末卡点钩（意外/悬念/威胁三型选一）**；每集仍走完整 v1.2 管线（体量带、机检、绑定一样不少），分集交付到 `作品/83x_系列名/EP01_...`、`EP02_...` 各自的 `_运行` 目录；01 阶段在方向定板里就定「一共几集 + 每集卡点」。前期集给矛盾介绍+多反转（前十集定律的口播口径），**规则一条线全系列不许改**。伏笔先埋正文再回收（zenstory craft-rules 铁律），回收表逐条记录：伏笔是什么、埋在第几集、计划第几集回收。

### 阶段 3 · 成稿（`_运行/YYYY-MM-DD/03_初稿.md` → `正文.md`）

**首稿质量是主指标**：目标是一次写对，审读（阶段 4）只做减法和补漏，不是默认兜底的大修场。开工前两件先决：开场钩子已在方向定板里选定；场次单在本阶段展开时**同批写出 3 个钩子备选（A/B/C，各自受开头铁律约束）**——钩子是正文的入口，必须在正文之前定死，不许跑完机检后再回头补。

写法纪律（防漂移与失控）：

- **分段直写**：一次只写一个场次块（≤35 行），写完当场逐行回读、确认无错字错名再继续下一块；禁止一次性生成全篇再返工找错。长中文一次性生成容易出漂移（字同音混、名字换字、标点串行），这是执行层的已知风险。
- **行宽自定**：`5–12 字一行` 是口播体裁的语感指纹，**不是机检规则，任何脚本都不设行宽上限**；你可以为求稳自行收窄（如 ≤10 字），但那是写作策略不是规范。

按 [代入感手艺.md](references/代入感手艺.md) 写全篇。铁律四条：

1. **旁白驱动（判型铁则）**：这是口播稿＝文案/信息驱动的独白讲述，不是对话剧。直接引语字数占比 ≤10%、每场至多 1 句原话钉子、全篇钉子句 ≤8 句，对白只做激将/预警/刻度；**禁止「你说他说」乒乓回合**，交锋一律旁白转述（详见代入感手艺·三点五）。
2. **每个编年段落先问：这场能不能当分镜拍？** 能 → 展开成现场；不能 → 压成一句带数字的判词。不允许“第二件事发生在……”式的事件摘要流水账。
3. **抽象的焦虑只准翻译成身体、器物与数字**（本系列基因），不准用情绪形容词宣布。
4. **口语短句成行**（5–12 字一行是语感指引而非硬约束，ASR 字幕语感），情绪最痛处用最短句；技术性细节才用长句。禁书面腔/AI 腔（首先、其次、然而、随着、不禁、眼眶一热等，详见手艺文件）。

### 阶段 4 · 自审 + 返工（`_运行/YYYY-MM-DD/04_审读与返工.md`）

按 [审读与改稿.md](references/审读与改稿.md) 执行三测 + 一账：**追看断点审读、念稿测试、反流水账复检、账目对账**。问题分层返工（切口/主线→回阶段 2；关键场没展开→回阶段 3 重写该场；只有表达问题→局部修）。改完复审，不凭“我改了”通过。

机检在这里不是可选项，是闭环工具（**PASS≠好看，但候选不清零不许交付**）：

```bash
python3 scripts/fuben_run.py 作品/NN_主题/ --profile full --json   # 含工艺门禁 craft（红线/开头/对白/账目/体量）
python3 scripts/fuben_craft.py 作品/NN_主题/正文.md --ledger       # 账目对账全表（位数/档位主张↔同段金额）
python3 scripts/fuben_run.py 作品/NN_主题/正文_3分钟版.md --profile short --json
python3 scripts/fuben_run.py 作品/NN_主题/钩子备选.md --profile full --json 2>/dev/null || true  # 钩子也扫红线与禁词
```

返工后**复跑并把 findings 差异（前 N 条→后 M 条）写进 04**；`facts`/`policy` 类与 `LEDGER_*` 的 REVIEW 必须逐条闭环（修复，或引用原句说明是机检误报+保留理由），`style` 类句式候选可批量判定但要在表里点名。对白限额、引语占比一律引用 `DIALOGUE_*` 输出数字，禁止无工具的手工自报。

创作审读之后，转 `fuben-review` 读通当前完整稿（题意、人物/物件/时间/代词/问答/序列、连接词、返工残留、账目档位、开头铁律），报告绑定 `body_path` 与 `body_text_sha256`；正文改动后旧结论失效。

### 阶段 5 · 交付

产物命名固定：一次运行一个 `_运行/YYYY-MM-DD/` 目录，文件名按 [arena.runtime.json](../../arena.runtime.json) 的 `product` 字段（`00_简报.md`…`05_机检.json`）；根目录交付 `正文.md`、`钩子备选.md`、`审核报告.md`。跑一遍产物门禁：

```bash
python3 scripts/fuben_products.py 作品/NN_主题
```

- `正文.md`（可直接朗读的逐字稿，正文）
- `钩子备选.md`（3 个开场钩子 A/B/C + 推荐；标题/封面文案建议）。钩子在阶段 3 与正文同批写出，此处只做定稿收口（选定推荐、定标题），不是启动写作。**钩子同受开头铁律：任何一条不得以定义/口径/科普开场**（81 教训：钩子 3「A 是资产，4 是位数」正是被禁的讲解腔）；每条标注吊住什么期待、靠哪场兑现。
- 可选：`正文_3分钟版.md`（短版重写，不是删减）、发布建议（话题、封面、发布时间）

估时口径以 `fuben_policy.json` 为唯一参考（两口径差异见阶段 0）；真实听感以试读/试听为准。不报“必爆”、不虚构流量数据；好看与否以用户验收和真实观众为准。

## 边界

- 保留用户给定事实与剧情；分清虚构、角色误信与现实断言。检索到的现实信息（价格、案件、热梗）注明来源；拿不准就标注待确认，不编造。
- 合规红线：不写平台违规内容（详见 [独立提示词.md](references/独立提示词.md) 红线段）。**剧情、对话与细节一律不出现吸烟/电子烟/烟草（用户红线，2026-09-23）**；需要烟熏、朦胧类质感时改用等价感官比喻（灰尘光束、油味、雾气、水汽）。检索素材里有烟也只是外部事实，不进稿。此条已有机器门禁：`fuben_run`/`fuben_craft` 对正文、短版、钩子逐文件扫 `NO_SMOKE`（BLOCK，`--profile reference` 校准除外），不靠人肉记忆。
- 账目红线：**数字判词链要能反算**——位数主张、A/B/C 档位、单价×数量、总−付=余，全部按文内定义对账（`LEDGER_*` 候选 + `fuben_craft --ledger` 全表）；对不上的要么修，要么让角色点破差异，不许留错账过审（81 教训：4700 的卡记成「四千」、2640 记成「第一笔 A5」，都过了 APPROVE）。
- 研究/改造 Agent 的任务到方法落地为止，不自动转成样稿。
- 跟随用户语言回复；中文遵循《中文文案排版指北》。

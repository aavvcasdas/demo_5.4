# 2 · 选题与结构（v4.0：门禁降级为视角，手艺保留）

> v4.0 变更：选题四关、剧本五关、情绪关从「不过即毙的硬门禁」改为**排站时问自己的问题**——不过当然还是要改，但不再有"缺一个数就回炉"的机械判罚。爽点四段、时间轴排法、物证两栏、见证链这些手艺全部保留。用户裁决不变：**混合源（虚构骨架＋真实原型锚）＋爽优先＋时长不限节奏优先**。

## 〇、选题四关（排站前问自己，不过就换）

| 关 | 要求 | 失败反例（我们自己的） |
|---|---|---|
| ① **身份关** | 主角是**一类人**（社会标签），不是一个人的习惯 | 《天天去健身房但是偷吃的人》＝一个**习惯** |
| ② **代价关** | 有**不可逆的代价或转折** | 《国庆在家躺七天》＝一段**状态** |
| ③ **数字/物证关** | 标题或开场就有**具体数字或可拍物证** | 我们的数字全埋在正文 |
| ④ **判词关** | 标题自带**态度词** | 我们的标题是中性描述 |

**一句话**：爆款卖「一类人的命」（跌、有代价），我们容易写成「一个人的日常」（平、只有状态）。**观众为「后来呢」停留，不为「我也这样」停留。**

## 〇之二、排站五问（原「剧本五关」，v4.0 改为视角）

| 问 | 怎么答 | 反例 |
|---|---|---|
| **事件** | 每站一件不可撤回的事，一句话「他____了」；事件链 ≥5 环、环环相扣 | 90：七天躺着＝七个「过着」 |
| **戏** | 每站尽量一场两人同框、有来有回的戏；**用台词演还是用动作/器物/数字演，自己选**；全篇 ≥5 场 | 91 v1：全片零对手戏，主角独自总结三分钟 |
| **悬念** | 最大底牌尽量 ≥50% 才揭；开场只给画面＋矛盾，别把唯一悬念用在第一句 | 91 v1：第一句就把「语音发给七个人」说完 |
| **代价** | 反打要付代价——**坏事的代价是被反怼/被拉黑/钱回不来；好事的代价是正向投入**（多跑三公里/多喝半桶水/多花一小时），不必硬造悲惨 | 91 v1：曝光零成本；旧版只写被拉黑，导致结尾老是否定 |
| **密度** | 每 15–25 秒（≈70–125 字）一件事发生或有人说话（口径唯一表） | 状态描写连排＝水段 |

**附加三条**：①主角**毛边 ≥1 处**（自欺/嘴硬/双标/小算计/小得意）；②结尾＝**人能说出口的一句话＋一个可拍动作**，判词 ≤2 句且至少 1 句是人话，**禁作者总结腔飘在旁白里**（「她叫的不是你，是你卡里的余额」这种聪明话要么挂到人物嘴里，要么删）；③**同一主题只收一次**（最后 15 行）＋**开场抛出的矛盾/物件必须 ≥1 次回扣**。

**情绪关（至少 1 项成立且指得到行；搞笑路线笑点必须成立）**：
深度＝一条能被观众带走的认识，从人物处境里长出来，不是旁白下的聪明结论｜笑点＝不自觉会笑的黑色幽默/错位｜共鸣＝一行让观众说"这也是我"｜爽＝一行让观众出气。配方见 `5_代入感与禁忌.md` 三·补。

**四类已入册的失败选题类型**：①习惯；②状态；③圈内梗（外人看不懂＝劝退）；④攻略（是操作不是命）。

## 一、选题三闸（一票否决，写在 01 文件里）

### 闸一 · 一句话主线
能用**一句话**说清「这是谁、他经历了什么、最后怎么了」。
- 通过：「一个被全村当成有编制的五保户，直到手术单上要填关系人。」
- 不通过：「关于五保供养政策和农村养老现状的一次展示。」

### 闸二 · 观众关系（三选一，必须命中一类，且必须写下证据）
| 类型 | 观众心里的话 | 靠什么成立 |
|---|---|---|
| **爽**（本账号当前优先级） | 「我也想这样／这口气出了」 | 主角自己动手把局面翻过来 |
| **共鸣** | 「这也是我」 | 处境可以被大部分人代入 |
| **猎奇** | 「我从没见过」 | 罕见身份/职业/命运，且真实 |

**写不出证据的选题一律毙**：共鸣要指出「哪句话让观众说这也是我」；爽要指出「哪一下让观众解气」；猎奇要指出「哪一点是真的，来源在哪」。

### 闸三 · 情绪出口＋互动动作
看完这一条，观众**想做什么**：想骂谁、想哭、想讲自己的事、想转发给谁、想@谁。**这个动作要在结尾的互动钩里被明确点名**（不写「你怎么看」这种空壳）。

### 黑名单（86 的四个死因，命中即毙或重做）
1. **主角没有社会关系**（无亲无故、无对手、无牵挂）。**变体（88 v1）**：主角有社会关系，但那些人都只活在转述里、从不与主角同框——同样判「平淡」，回阶段 2 补人。
2. **纯制度/政策观察**——观众学不到东西，也爽不到。
3. **只有流程没有阶段**——认定→公示→协议→住院，是同一件事的四道手续，不是人生。
4. **灰到底、无释放**——可以苦，但必须有出口。

## 二、爽点四段（爽优先的默认结构）

```
压制（0–30%）  →  谷底（60–70% 处）  →  反打（谷底后 1–2 站）  →  释放（结尾）
```

| 段 | 任务 | 硬要求 |
|---|---|---|
| **压制** | 让观众看见主角被什么压着，且这个「压」要**具体**：一个人、一笔账、一条规矩 | 压制者必须有名有姓／有具体的利益 |
| **谷底** | 全篇最疼的一下，落在 60–70% | 谷底由**人的反应或动作**造成（半句话没说完/沉默/放下筷子），不许旁白抒情、不许一串数字打脸 |
| **反打** | 主角**自己动手**把局面翻过来 | 旁人送的胜利不算；反打的武器必须在前文**出现过** |
| **释放** | 写清楚**对手输了什么/主角得到了什么**，不是写「你赢了」 | 释放要能被拍（一个动作、一句话、一笔账）；结尾接互动钩 |
| **释放·见证链（88 教训）** | 释放要有**在场的人**：他看见、他接住 | 至少 1 个具体的人（有称呼/固定动作）在释放那一站同框，用台词或动作接住主角。**自己在家完成、无人看见的释放只算半个** |

**打脸三要素**：①对手具体（有名有姓有利益的活人）；②代价真实（主角为反打付出了什么）；③公开兑现（在有人看着的地方完成）。**爽点不是运气**：主角赢在「他早就准备好的那件事」上，观众才会觉得值。

## 三、人生时间轴（每站四列）

把一生（或一段关键人生）切成 **5–8 站（中档加长版 6–9）**。每站四列：**事件 / 可视物证 / 一句人话 / 笑点或情绪点**（模板见 SKILL 阶段 2）。

- **每站 ≤400 字**（听众的一口气上限）；超过就说明这站塞了两件事，拆。
- **站与站之间必须是「因为→所以」或「但是」**；并列＝不合格。
- **钩点表**：每站写完标出钩点行号，两钩之间 >300 字＝大概率水段，压或删。
- **物证 2–3 件**：1 件主物证走全篇并换义（如社保卡：藏着→递不出→压枕头下），其余副物证。
- **物证两栏（89 教训）**：每件物证写满 `第一次出现＋换义点（站） | 最后一次出现（站＋正文原句）`。最后一栏必须是一句**可拍的动作原句**——**一件物证如果最后一次出现不是动作，它就只是摆设。**
- **伏笔 ≤3**，每个当场登记回收站；**判词 ≤2 句**。

## 四、混合源纪律（裁决后必守）

1. 每个方向卡与成稿必须登记 **≥1 个真实原型锚**（可回链的真实人物片段/职业细节/报道事实）。
2. 虚构人物**不许使用真实人物的姓名、单位、职务**；真实细节改写到无法反查具体个人。
3. 家庭创伤、疾病、死亡等真实经历素材，只用「事件类型」不抄具体人的叙述文本。
4. **发布建议里注明「剧情为虚构演绎」**（正文内不写）。

## 四·补 · 笑点与热评取材

- **笑点来源**：从热帖热评层借机制——反差（自曝 vs 事实）、精确（具体到动作/器物）、复现（同一个梗第二次要升级）、错位（说的和做的对不上）。**不整句抄热评。**
- **笑点红线**：笑处境不笑人——不嘲笑身材、弱者、打工人；**谷底那一站不加笑点**（疼处要干净）；同一个梗不许原地重复两遍。
- **数量**：每站尽量 1 个、全篇目标 ≥6；方向卡里写出**笑点清单 ≥3 条**（带热帖出处），不要写到一半才想。

# 代入感手艺 · 反流水账八件武器

> 从 `拆文库/` 39 篇原稿的写作手法拆解里提炼的可执行规则。原稿的技术核心三句话：
> **把抽象的焦虑翻译成身体、器物与数字；把下坠铺成清单与编年；把清算留给一个最小的单位（一碗面／半步／一秒／68块5）。**
> 手法出处见各篇 `写作手法.md` 与 `拆文库/_系列总拆书.md`。以下例句正例多为原文短引，反例为自造。

## 一、先认出流水账（诊断）

流水账的四个特征，占两个就是流水账：

1. **转场靠日历**：「第二周他们换了打法」「第三件事发生在月底」「后来你长大了」——时间词裸跳，没有现场。
2. **事件摘要化**：每段只是“发生过什么”的梗概，摄像师听完没法开拍。
3. **情绪靠宣布**：「你很难过」「大家都服了」「你很厉害」——形容词和评价代替发生。
4. **身体失声**：全篇没有温度、疼痛、声音、气味、重量，人物是纸片在表格里移动。

**总测试：把这一段读给摄像师，他能不能直接分镜？** 不能，就是流水账。另一个测试：把段落里的名词圈出来——全是抽象词（生活、压力、关系、现实）而没有具体物件、数字、身体部位，也是流水账。

流水账不是“写了编年体”的错。本文体天生是编年体（人的一生），**编年是骨架，场景是肉**。允许时间跳转，但跳转句之后 50 字内必须落一个可数量或一个现场。

## 二、八件武器

### 1. 感官锚定：给核心体验建一套身体词汇表

选一个感官主题（辣、疼、冷、吵、晕、胀），先用一组身体比喻把它钉死，后文复用并升级。原稿写辣：「舌尖上像有人摁灭了一个烟头」「灼烧感顺着舌面往舌根爬」「心跳一下一下撞在耳膜上」「校服一小块一小块贴上皮肤」；写失味：「舌头像隔了一层塑料布」「糊成一团温吞吞的东西」。

- 反例：`辣得你眼泪都出来了，很难受。`
- 正例：`第三秒舌尖上像有人摁灭了一个烟头，那种灼烧顺着舌面往舌根爬，你耳朵嗡的一下热了。`
- （上引原文含烟头意象，仅作拆解存档。**本账号新稿遵守无烟草红线**：同类灼烧感改用等价比喻，如「像有人把一小块炭按在舌尖上」。）
- 纪律：一篇建 1–2 套词汇表就够，全篇复用；高潮处换一套最轻的词（原稿结尾「米有一股很淡很淡的甜味／要含一会才出来／一闪又没了」）制造对比。

### 2. 器物三现：小器物走完全篇

选一个小到能握在手里的东西（一碗汤、一个分装瓶、一把卷尺、一副碗筷），让它出现三次，每次换义：①当下功能 → ②变义（羞耻/牵挂） → ③清算或和解。原稿的排骨汤：第一次尝不出、第二次撒谎、回忆里「能喝出萝卜和骨头是两种味道」。

- 反例：`他一直记得那碗汤。`（提一嘴就扔）
- 正例：`散局时你把没拆的代餐盒推给他，他又给你塞回来了。`（器物先干活；后文再变义）
- 纪律：器物要小；结尾器物留在画面里（原稿「这次没有再加辣」就停），不写“从此以后”。

### 3. 数字判词链：小数字判大案

判词是一个精确数字，落在全文情绪最重的一瞬。**数字的刺痛与位数成反比**：147 万（卖肾赔偿）不如「68块5」（解药的真实价格）疼。三条纪律：①判词前必须铺数字链（估价/月供/总筹码一步步来）；②小数字承担大清算时落差最大；③数字揭晓配一个冷漠的揭晓方——短信、账单、收费员、系统通知，不配感叹号。

**第四条：账要平（2026-09-24b）**。本系列把数字当判词用，观众里有的是人拿计算器听：每个显式主张都要能反算——单价×数量=总额、总−支出=余额、同一器物/欠款两次的数一致、自定档位（位数、A/B/C 级）与金额区间全篇口径一致。对不上就是错账，错账比形容词堆砌更伤信任（81 案：卡上 4700 结尾账本记「四千」没交代；实习结余两千多写「存成第一笔 A5」，按文内口径 A5=五位数——两处都滑过了旧审读）。写完跑 `python3 scripts/fuben_craft.py 正文.md --ledger` 逐条闭环；故意留差（抹零头、记情不记账）要在当场点破一句，点破=笑点，不点破=bug。

- 反例：`为了这件事，你花了很多钱。`
- 正例：`解药的价格是 68块5。`（前面先铺 4,576 的总筹码、147 万的旧账）
- 千分位与小数原样保留（48,452.31／6,000 多块），视觉精度本身是质感。

### 4. 精确锚点：分钟级时间 + 可数量

把虚构感压到最低的是细节精度：「每天下午 5:50」「凌晨 3:17」「微信步数停在 843 步」「工资条 6,000 多块」「打上 4 颗螺丝」。每次跳年后，50 字内给一个新的可数量，读者立刻知道“程度”，不需要过渡段。

- 反例：`那段时间你过得很颓废。`
- 正例：`这个月你在现实里开口说的话，一只手数得过来。`

### 5. 拆穿式旁白：主角“刚赢”之后补一刀

叙述者比「你」多知道一层，在主角刚赢的时刻用一句**不带评价词**的越位拆穿。原稿四刀：封辣王后——「没人知道那不是能扛，是你的嘴唇早就麻的没了知觉」；发誓后——「这个誓言的有效期是三天」。

- 用法：全篇 ≤3–4 次，只放在“赢”之后，一句说完，不解释。
- 这是第二人称口播的特权武器：观众和叙述者站在一起看“你”表演，代入与审视同时发生。

### 6. 信息差收拢：结尾让“你”知道读者早知道的事

前文读者 > 主角（读者看见代价，主角归为“不饿”）；高潮处信息差收拢为零，主角与读者第一次同步——这种同步本身就是情绪释放，不需要反转。原稿结尾主角终于尝出甜味，读者在 20 分钟前就知道他失味了。

- 纪律：理解眼下行动所必需的信息不许瞒读者；藏的是“这意味什么”。

### 7. 自我合理化三段式：让读者同时认同与识破

成瘾/沉沦线的辩护结构写成内心独白三连：「别人也这样」＋「权威没说死」＋「代价不值得」（原稿：「四川人顿顿吃辣，人家不也活的好好的／医生说的是少吃，又没说不能吃／再说了忌口的人生跟坐牢有什么区别」）。读者会在心里完成“认同”和“识破”双动作——这就是代入感的高级形态。

### 8. 微缩计量：判决用最小单位签发

拒绝、原谅、爱、破产，都用最小单位计量：「半步」「一秒」「微辣」「68块5」。计量越微小，判决越重。平淡重判句式优于咆哮：「做不了就提出来」「别翻了，以后也别翻了」——失望比愤怒更终审。

## 三、场景化铁律（展开与压缩）

编年事件只有两个合法形态：

**A. 展开成场景**（进“场次单”的那些）——必须凑齐四件：

1. 现场可拍：地点、器物、声音、光线至少两样；
2. 对手有利益：对方要什么、怕什么，由利益长出**转述＋至多一句原话钉子**（对白三功能与限额见「三点五」；母亲说「长身体要多喝汤」＝我给你做的才是对的）；
3. 动作改变局面：有人争取、受阻、换招，一步棋落下后关系或处境变了——**交锋用旁白写，不用对话回合写**；
4. 反应有后果：旁人改口、让位、收回东西、换称呼——**侧面是主角行动留下的影响**，脸白/震惊/沉默不算，「他原本能做什么，现在为什么不能做」才算。

**B. 压成判词**（其余经历）——一句，带精确数字或器物，不展开情绪。

```
反例（流水账）：第二周他们换了打法，不喊吃饭了，喊你凑人头。你又去了好几次。
正例（场景+判词）：麻将馆的空调冷得冒白气，你看了眼表，九点四十。说好的一圈。
        手机闹钟响了三回，被你按掉了三回。散场时窗外全黑了，老板端来一碗面。
```

**配角不许替主角爽**：配角可以施压、见证、付出代价、助攻；最难的一步必须主角自己走。全员自动鼓掌＝爽点落空。

## 三点五、旁白驱动铁律（对白限额——口播是独白，不是对话剧）

**判型先立住：人生副本是口播稿＝文案/信息驱动（kesheng #43 的通道 A），不是戏剧动作驱动的剧本（通道 B）。** 全篇是一个叙述者对观众讲「你」的一生——旁白读、画面演。原作对话占比仅约 9%（《无辣不欢》：约 290 字引语/3254 字），**对白不推剧情，只做刻度**。推剧情的一切内容，必须写成旁白转述。

1. **限额**：直接引语字数占比 **≤10%**；每场至多 1 句独立成行的原话钉子；全篇钉子句 ≤8 句。超出即压成转述。**计数用工具不用手感**：`fuben_run`/`fuben_craft` 的 `DIALOGUE_*` 按「讲，/说，」引语帧＋括号引号给出候选数与占比下限（跨行引语会低估，人工只补高不补低）；超线（候选帧 >12 或占比 >10%）在 04 逐项排除——转述疑问、账目/单据文字、微刻度不计句数，剩下的收拢。本系列「他讲，」引导的跨行长钉（如「你问，练什么手」夹在两句引语之间）就是乒乓雏形，见 `PINGPONG` 命中即改。
2. **对白三功能，只许干这三件事**：激将（「有本事你去吃变态辣啊」）／预警（「我这辣椒可辣」）／刻度（习惯确认句「还是变态辣吗」、平淡重判「输了二十七年了，不差这一回」）。不承担这三功能的引语删掉或转述。
3. **禁乒乓回合**：不得出现「你说 X。他说 Y。你说 Z。」两轮以上你来我往。交锋一律旁白转述收拢：
   - 反例（小说腔）：`他说，那就是没打上。你说，差一点。他说，差多少。你说，差个队。`
   - 正例（口播腔）：`聊到为什么没打上职业，你的理由是差一点。他追问差多少。你就说实话了——差个队。`
4. **转述句式**：用「他问/他只说/你答应回来/话到嘴边改成了」收进旁白；「你说/他说」引导的间接引语一行内说完，不分行对打。
5. 消息文字（语音房喊话、转账备注、弹窗）不是对白，是数字与器物证据，放心用：「老刀：来吗」三条弹窗，就是三下刻度。
6. 母亲、医生、老板们**零内心**，话语能少就少——留白让观众自己补，这是情绪的主要来源（原作母亲三次劝阻全靠动作）。

## 四、声音与句读（口播语感）

- 第二人称「你」是代入接口；叙述者偶尔越位拆穿；配角零内心，靠动作呈现（母亲三次劝阻全靠端汤、踢腿、撇红油）——留白让观众自己补，这是情绪主要来源。
- 逐行短句 5–12 字（ASR 字幕语感），**最痛处最短**（「腿是软的／人是飞的」）；技术性细节才用长句（配方、流程、价钱怎么算）。
- 节拍器词：找一个复用虚词（原稿的「还是」出现 6 次）串起全篇节奏。
- **禁用**：首先/其次/最后/然而/随着/不禁/值得一提的是/眼眶一热/心里五味杂陈/五雷轰顶等书面腔与 AI 腔；「你感到」「你觉得」开头的情绪宣布；连续三段以上没有数字、器物或身体部位。
- 用「你」不用「大家」；单句一般 ≤15 字；念出来必须顺口——拗口就断行，不硬撑书面完整句。

## 五、文体与曲线速查（选完再写）

十大志：寓言志（单一设定推到底）／实录志（行业地域白描）／沉沦志（坠落编年）／清算志（讨嫌人设社死）／代价志（单点决策毁灭）／孤独志／身体志／温情志（苦底带暖）／糖水志（无冲突纯甜，先天塌方）／忏悔志。

曲线：剪刀差（奖赏递减×代价递增）／堕落曲线／编年缓降／U 型救赎／暖流爬坡／糖水平台／迷因脉冲（憋屈记账+一次爆发）等。**文体税：糖水、无坠落爽文、警世通言先天缺对抗，技术再好也压在及格线**——缺对抗就用「外部危机＋清单化代价」补张力。温情必须带苦底。

收束二选一：灰收束（接受/留在过去）或暖收束（题眼追认/器物回暖）。禁说教大团圆、禁把最该演的结果欠到“下一篇”。

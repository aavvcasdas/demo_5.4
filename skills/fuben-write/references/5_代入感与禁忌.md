# 5 · 代入感与禁忌（v3.0）

> v1.3.5 的「反流水账」纪律仍然有效，但降级为**及格线**：不水是入场券，不是成绩单（86 已做到不水，仍然 1k 播放）。本文件保留仍要守的手艺与全部红线。

## 一、代入感的三条硬手艺

1. **第二人称 + 具体处境的第二秒**：不是「你是一个五保户」，而是「你手里攥着两块钱，是出来买豆腐的」——身份用动作交代，不用标签交代。
2. **抽象只准翻译成身体、器物、数字**：孤独 → 「一年到头，家里就一本空折子」；疼 → 「胸口下面，像有人拿手在里面拧」。**禁情绪形容词宣布**（心酸/孤独/感慨/五味杂陈一律不写）。
3. **侧面描写先于正面解说**：穷、富、牛、惨，都让器物和旁人的反应说，让角色自己解说＝失败。

## 二、不水四则（保留 v1.3.5 结论）

1. **禁平行陈列**：连续同类器物/遭遇/日常细节排开＝本文体最典型的「水」；只能压成一句带数字的判词（全篇 ≤15% 且不得连续两段）。
2. **每件进正文的物证必须干一次活**（被递出/被退回/被记账/被摔/被点破），只展览不干活的删。
3. **中段禁信息真空**：任何一段都不能只是「再举一例」。
4. **可删测试**：划掉这一段后文仍成立 → 它是装饰（压成判词）。

## 三、旁白驱动（判型铁则，v3.0 起可按标签行直接数）

这一支是**旁白驱动的可拍剧本**（叙述者带着观众走），不是对白剧：

- **剧本形态**：对白＝`角色名（提示）：台词` 的标签行，按字数占比直接数，**上限 25%**（机检 `VO_TRACK_OVER`；旁白轨是主体）。逐字稿形态沿用旧口径：引语占比 **≤10%**、全篇钉子句 **≤8**。
- **每场至多 1 句原话钉子**；连续三行以上「你说／他说」交替＝乒乓回合，改旁白转述。
- 对白只做三件事：激将、预警、刻度；**不推剧情**——剧情由动作与旁白推。
- 拆穿旁白 ≤3–4 次，且都放在「主角刚撑住场面」之后（86 的「其实你没打」）。
- **旁白不许复述画面**：画面行已经拍出「瓶子没接满」，旁白再念一遍＝两轨互相浪费，删旁白留画面。

## 四、禁词与禁腔（机检 BANWORD 扫描，人工也扫）

首先、其次、然而、随着、不禁、值得一提的是、眼眶一热、五味杂陈、五雷轰顶、不由得、感慨万千、心潮澎湃、不知不觉、似乎在诉说着……

**禁开场定义腔**（机检 DEFINITION_UPFRONT）：先校准、先说说、先讲讲、今天我们来聊、大家好、先来科普、名词解释、口径如下、设定如下、规则如下、先对齐、世界观设定。

## 五、红线（机检 BLOCK）

1. **无烟**：剧情、对话与细节一律不出现吸烟/电子烟/烟草/点烟/烟头/烟味（用户红线）。需要烟熏质感改用灰尘光束、油味、雾气、水汽。**外部检索素材里有烟也不进稿。**
2. **不写平台违规内容**（涉政、涉黄、血腥、未成年恐吓、规则怪谈本格等）。
3. **不冒充真人**：混合源稿件的原型锚必须去标识化；发布建议注明「剧情为虚构演绎」。
4. **不报「必爆」**，不虚构流量数据与授权。

## 六、判词纪律

- 全篇判词 **≤2 句**（终判词＋尾句），不叠成语层、不三连发。
- 判词要能**反算**：带数字的判词，数字必须来自前文铺好的链（如 991×12＝11892＝当地丧葬补助十二个月的口径）。
- 判词由**冷漠的揭晓方**说出或由动作带出，不由旁白抒情。

## 七、单集/系列

- 单集是默认形态。用户点名要连续剧时：共用人物／地点事实表 ＋ 跨集伏笔回收表 ＋ 集末卡点钩（意外/悬念/威胁三型选一）；规则一条线全系列不许改；每集仍走完整管线（检索、分场表、机检一样不少，但**不再有哈希绑定报告**）。

## 六、数词与比喻（v3.1 新增，来自作品 88 初稿的实打实退步）

1. **禁数词堆**：可念轨数字串 >70/千字 或量词数串 >20/千字＝`NUMBER_STUFFING`（REVIEW）。密度上限与基线见 [0 第六节](0_剧本格式与分场表.md)；87 只有 61.6／14.6，被批评的那篇 84／48。
2. **禁同一个数反复兑笑点**：`三百` 连用 4 次不是"呼应"，是把同一句话说四遍（`NUMBER_REPEAT`）。第 4 次起必须换成物件、单据或动作。
3. **禁装饰性时间词**：「三年／五年／这些年」用来装重量，出现 >2 次＝`DECOY_SPAN`。跨度交代一次就够，剩下让物件说话。
4. **禁把来源的上限当等号**：资料说"每串不超过 100 大卡"，就不能写成"三串＝三百千卡"。**逐项差极大的量，必须逐值引用**（罗森：萝卜 15／昆布 18／魔芋丝 13，丸子却到 127）。
5. **一篇只养一个比喻**：比喻漂移（年卡＝家电 → 健身＝赎罪券 → 前台＝战场）＝三篇稿子挤在一篇里。想换比喻，另开一篇。

# 7 · 自检与评分（v4.0：十二项视角清单，不打分）

> 用法：写完一稿，在 `04_审读与返工.md` 里按下面的**十二项视角清单**逐项判「过/返工/理由」，再按**五个自查问题**给自己的稿子要证据；有问题的返工，别带病交付。
> **v4.0 变更**：**取消 24 分制与判定线**。理由：v3.x 的教训是「22/22 与好看无关」「分数不得推翻门禁」——既然分数证明不了好看，就只保留"这项过没过、证据在哪一行"的三态判断，**不打分、不排名、不跟拆文库比分数**。对白报数（说话人标记处数/引号处数/无人开口行数）**废除**——它们是模型最好刷的指标，刷达标了稿子照旧闷。

## 一、十二项视角清单（每项判：过 / 返工 / 理由）

| # | 检查项 | 返工信号 |
|---|---|---|
| 1 | **三秒钩** | 第一行是签名/问候/背景；或前 160 字有定义腔 |
| 2 | **一句话主线** | 说不清是谁、经历了什么；缺「哪类人」或缺「不可逆代价」 |
| 3 | **观众关系** | 空；或写了类型但没有「哪一句让观众说这也是我/这口气出了」 |
| 4 | **翻面节奏** | 有 >300 字平段；或连续 30 秒纯介绍/回忆/抒情（断崖点） |
| 5 | **谷底** | 无谷底或谷底在末尾；靠旁白抒情或靠数字打脸 |
| 6 | **反打与释放** | 旁人送的胜利/没有对手；或无人看见（自己在家完成）；好事题材的反打没有正向投入的代价 |
| 7 | **物证** | 纯账单无物证；或某件只出现一次、最后一次出现不是动作 |
| 8 | **语言** | 书面腔/情绪形容词宣布/含禁词或违规词；或连续 ≥4 行无推进乒乓；或全员同腔 |
| 9 | **账目** | 正文有算式；数对不上；同一数字两处不一致 |
| 10 | **结尾** | 冷收/只输出金句；互动钩是空壳「你怎么看」；同一主题说了两遍 |
| 11 | **笑点/名场面** | 全篇无笑点；或笑点靠嘲笑身材/弱者/打工人；或谷底站混进笑点；或同一个梗原地重复 |
| 12 | **场间过渡** | 连接词硬接；接缝处重新介绍身份/时间；有一处读起来像重新开场 |

**判定**：任何一项「返工」且给不出理由，就改完再交。**没有总分，没有线。**

## 二、五个自查问题（不打分，只要证据）

| # | 问题 | 证据要求 |
|---|---|---|
| 开 | 前 3 秒/前 5 行，观众凭什么不划走？ | 引 L1–L5，说明钩的类型 |
| 拉 | 中段哪一下让人停不下来？（不是「惨」，是「想知道接下来」） | 引最疼或最想知道的那两三行 |
| 反 | 反转有几个、有没有一次说透？ | 逐个引行号，标「真反转／软反转」 |
| 节 | 有没有任何一段是「再举一例」？ | 给最长平段的起止行＋字数 |
| 尾 | 结尾凭什么让人点赞、评论、转发？ | 引判词行＋互动钩行 |

## 四、示范：87《年卡洗澡空调饮用水》自检（2026-09-30 复核，历史口径存档）

> 这是 v3.0 时期跑一遍 87 的记录，只用来校准手感（**v4.0 起不再给分数**）。

| 项 | 依据 |
|---|---|
| 三秒钩 | L1「你把健身年卡用成了三个家电」＝反常型；签名 L3 |
| 一句话主线 | 城中村租房没热水→999 年卡洗澡空调接水→贴限时通知后当众算账 |
| 观众关系 | 爽（规则之内赢）＋共鸣（租房缺设施）；兑现句 L136「天天去，肉疼的是他们」 |
| 翻面节奏 | 7 站，站 4 问答连打 4 个点；无 >300 字平段 |
| 谷底 | L93–L100 淋浴限时、瓶子没接满、脸盆擦身，落点 ≈61–65% |
| 反打与释放 | 反打是自己算账（合格），但**对手没真输什么**——店长只说了「我们会籍都没算过」 |
| 物证三件 | 水瓶／年卡／脸盆；年卡换义（买→洗澡用→算账凭证） |
| 语言 | 短句为主，无禁词无烟；「你练水压」是记忆点 |
| 账目 | 999÷320≈3.1、15×320=4800、合计 5450 可反算 |
| 结尾 | 判词＋「你办卡之后去过几次？评论区报个数」 |

**结论**：87 结构项都齐，真正的短板是**释放的强度**——「对手输了什么」没写实。改法（不追溯旧稿）：谷底线之后加半站，让店长当场承认成本账并改了规则，让「赢」落到对手身上。这正是拆文库 15《卖肾买 iPhone4》与 21《PG 电子游戏》的写法（**读手法，不比分数**）：**赢要赢在对手的账本上**。

## 五、这套自检不做什么

- 不用来预测流量，不报「必爆」。
- **不产生分数与排名**（v3.0.4 起、v4.0 重申）：只写「这项过没过、证据在哪一行、怎么修」。
- 不替代审读：清单齐了只说明要素在，好看与否以念稿、独立审读和真实观众数据为准。
- 不做机械清零：禁词命中可以「保留＋写明理由」，只要理由站得住。

## 六、旁挂：口播快检＋五维诊断（不计分，可选）

> 来源：老徐·自媒体起号方法论 skill（自然爆款 83.1/57.4/37.4/23.1 万，asOf 2026-07-31）与姜胡说口播 skill（433 条语料、盲测 90/100）。**可选的最后一遍人眼检查，不是门禁。**

**A. 口播快检 10 项（姜胡说版）**：①第 1 句是不是结论、能不能单独当标题？②前 3 句合计 ≤40 字且有「你/咱」？③有没有报数字？④有没有一个降门槛的词？⑤有没有替观众免责？⑥有没有禁用词？⑦有没有可触摸的实物类比？⑧结尾给后果/行动令而不是总结？⑨有没有今天就做得到的最小动作？⑩全篇读出来像不像一个人在说话？

**B. 五维诊断（老徐版，各一行结论）**：选题过不过四关？开场用的哪一式、够不够硬？逻辑有没有断？AI 味三忌有没有？四感全过没有？

**C. 朗读关**：出声读全篇，把拗口的行号记下来当场改——**读不顺的稿子不发。**

# 4 · 审读与改稿（v2.0：投手预演 + 返工）

> v2.0 把「审读」从「找毛病」换成 **投手预演**：假设你是这条稿子的投手，平台只给冷启动池几百次曝光，你逐条回答下面七问。**答不出的那一问，就是返工点。**

## 一、投手预演七问（落纸，每条引原句＋行号）

1. **第 1 行／第 3 秒**：观众凭什么不划走？钩是哪一型（结果/冲突/反常/悬念）？签名句是不是在第 2–3 行？
2. **第 15–25 秒**：第一个翻面在哪？（引行号）
3. **第 60 秒**：还在推进吗？**最早可能划走的那一段**（Lxx–Lxx）是哪里？
4. **谷底（60–70% 处）**：这一下最疼的是什么？是动作造成的，还是旁白抒情？
5. **反打/释放**：主角自己做了什么？对手当场输了什么？（写不出对手输了什么＝没反打）
6. **结尾**：凭什么让人点赞、评论、转发？互动钩是哪一句？金句落在哪？
7. **观众关系**（爽/共鸣/猎奇）：哪一句兑现了它？（引原句）

**没有行号＝没有回答。**（85 的教训：04 用对标表顶替审读，16% 的水段无人点名。）

## 二、平铺扫描（人工点名，不用启发式脚本）

- 找出**连续两段以上都在展示、中间没有一次局面变化**的段落；给**行号、字数、占比**。
- 逐条处置三选一：**压成判词** / **并进有对手的站** / **写明保留理由**（有独立笑点或情绪功能且不可删）。
- **可删测试**：划掉它，后文还成立吗？成立＝装饰；不成立＝剧情。
- 「这里有共鸣器物」**不是**不水的证据——共鸣是质感，推进才是剧情。

## 三、念稿测试（口播特有）

- 出声读一遍（或默读模拟配音）；拗口、换不过气的句子立刻断行；每句一般 ≤15 字。
- 两口径估时都写进报告（语感 4.5–5 字/秒含呼吸；机检 6.4 字/秒不含停顿），与目标时长差 >20% 就调体量——**调的是节奏，不是硬删句**。
- 断崖点：连续 30 秒纯介绍/回忆/抒情 → 压缩或前置半句钩。
- 禁词扫：见 [5_代入感与禁忌.md](5_代入感与禁忌.md)。

## 四、账目与兑现对表（保留）

```bash
python3 scripts/fuben_craft.py 作品/NN_主题/正文.md --ledger    # 位数/档位主张 ↔ 同段金额
python3 scripts/fuben_claims.py 作品/NN_主题                     # 兑现认领关键词是否真的落地
```

- `LEDGER_*` 的 mismatch **逐条闭环**（修数、改主张、或让角色点破差异）。
- **大钱账只报总数＋一粒记忆点**（口播账目礼仪）：分项明细不进正文，留在 04 表里对账。
- 兑现认领表里没落地的关键词，逐条处置：补戏／改关键词／写明被合并到哪一站。

## 五、结构自评（v2.0 新工具，advisory）

```bash
python3 scripts/fuben_viral.py 作品/NN_主题     # 首行是否钩 / 签名位置 / 结尾互动钩 / 物证数 / 检索路数 / 字数时长
```

**它只查结构项是否存在，不判水、不判好坏**——本仓退役过启发式质地检查器（判据失准），不要把任何脚本输出当创作结论。

## 六、分层返工（哪一步的问题退回哪一步）

| 症状 | 退回 |
|---|---|
| 选题三闸没过、观众关系为空、主线一句话说不清 | 阶段 1（重选题/重方向） |
| 站与站并列、没有谷底、反打靠旁人 | 阶段 2（重排时间轴） |
| 开场不钩、中段无翻面、结尾无互动钩、水段 | 阶段 3（重写该站） |
| 只有用词、断句、错别字问题 | 局部改 |

改完**复跑机检并把 findings 差异（前 N→后 M）写进 04**，不凭「我改了」通过。

## 七、机检闭环

```bash
python3 scripts/fuben_run.py 作品/NN_主题/ --profile full --json     # 红线/禁词/开头/对白/账目/体量
python3 scripts/fuben_run.py 作品/NN_主题/钩子备选.md --profile full --json 2>/dev/null || true
python3 scripts/fuben_products.py 作品/NN_主题                        # 阶段产物与哈希绑定
```

`BLOCK>0` 必须清零；`REVIEW` 逐条闭环（修复或引用原句说明误报并保留）；`style` 类可批量判定但要点名。**PASS 不是创作批准**，好看与否以用户验收和真实观众为准。

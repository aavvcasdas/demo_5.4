# 4 · 审读与改稿（v3.0.2：投手预演＋人工返工，脚本只兜技术）

> 审读不是「检查表是否全绿」，是**这条稿子能不能出池**。v3.0 起，结构自评、禁词、账目档位、体量这些**全部由人按提示词判**；脚本只剩输入/算术/产物/哈希（`fuben_run`、`fuben_products`）。所以这一页的自问自答就是唯一的结构关卡，写作者必须落纸。

## 一、投手预演七问（每条引原句＋行号，答不出＝返工点）

1. **第 1 行／第 3 秒**：观众凭什么不划走？钩是哪一型（结果/冲突/反常/悬念）？签名句是不是在第 2–3 行？
2. **第 15–25 秒**：第一个翻面在哪？（引行号）
3. **第 60 秒**：还在推进吗？**最早可能划走的那一段**（Lxx–Lxx）是哪里？
4. **谷底（60–70% 处）**：最疼的一下是什么？是动作造成的，还是旁白抒情？
5. **反打/释放**：主角自己做了什么？**对手当场输了什么**？（写不出对手输了什么＝没反打）**谁在场看见、谁接住**（引台词/动作＋行号）？——三项缺一，释放只算半个。
6. **结尾**：凭什么让人点赞、评论、转发？互动钩是哪一句？金句落在哪？
7. **观众关系**（爽/共鸣/猎奇）：哪一句兑现了它？（引原句）

**没有行号＝没有回答。**（85 的教训：04 用对标表顶替审读，16% 的水段无人点名。）

## 二、四道人工关卡

### 1. 平铺扫描（不看脚本，自己数）
- 找出**连续两段以上只展示、中间没有一次局面变化**的段落；给**行号、字数、占比**。
- 逐条处置三选一：**压成判词** / **并进有对手的站** / **写明保留理由**（有独立笑点或情绪功能且不可删）。
- 「这里有共鸣器物」**不是**不水的证据——共鸣是质感，推进才是剧情。

### 1b. 在场的人扫描（v3.0.2）
- 数一遍**除主角外还有几个具体的人**：给每人一行 `称呼 | 首次出现行号 | 他与主角同框的动作/台词`。
- **少于 1 人＝平淡警报**，回阶段 2 补人；有人但只出现在主角的转述里、从不与主角同框＝同样返工。
- 判据：把这个人删掉，释放那一下还成立吗？成立说明他只是装饰；不成立说明他是见证链，必须留。

### 2. 可删测试
划掉这一段，后文还成立吗？成立＝装饰；不成立＝剧情。

### 3. 念稿测试（口播特有）
- 出声读一遍；拗口、换不过气的句子立刻断行；每句一般 ≤15 字。
- 两口径估时都写进报告（语感 4.5–5 字/秒含呼吸；机检 6.4 字/秒不含停顿），与目标时长差 >20% 就调——**调的是节奏，不是硬删句**。
- 断崖点：连续 30 秒纯介绍/回忆/抒情 → 压缩或前置半句钩。
- 禁词与无烟：见 [5_代入感与禁忌.md](5_代入感与禁忌.md)，三个文件（正文/短版/钩子）各搜一遍。

### 4. 账目手算（模板）

正文里每一个数字主张，抄进表里自己反算一遍：

```markdown
| 行号 | 主张原文 | 算式 | 结果 | 与正文是否一致 |
|---|---|---|---|---|
| L24 | 十五乘三百二，四千八 | 15×320 | 4800 | ✅ |
| L110 | 九百九十九除以三百二，一次三块一 | 999/320 | 3.12 | ✅（口播取一位小数） |
```

- **正文零算式（v3.0.2）**：先在正文里搜 `＋ − × ÷ 等于 除以 乘 减 加 换算` 一类字眼；只要正文在**做运算**（而不是报数），就把算式抄进本表、正文只留结果或直接删。允许留在正文的只有四类：对比／事实（总数）／背叛／动作。
- 位数主张（「五位数」）、档位主张（A5/A8）、单价×数量、总−支出=余，逐项对。
- 同一器物/欠款的数两处必须一致；要留差异**必须有人物点破**。
- **大钱账只报总数＋一粒记忆点**（口播账目礼仪）：分项明细不进正文，留在 04 表里对账。
- 兑现认领表里没落地的关键词，逐条处置：补戏／改关键词／写明被合并到哪一站。

## 三、结构评分（取代 `fuben_viral.py`）

按 [7_自检与评分.md](7_自检与评分.md)：十项清单（满分 20）＋五维对标分（开/拉/反/节/尾，与拆文库同尺度）。
**写下分数、证据行号、返工项**；16 分以上才交付，任何一项 0 分不得交付。

## 四、分层返工（哪一步的问题退回哪一步）

| 症状 | 退回 |
|---|---|
| 选题三闸没过、观众关系为空、主线一句话说不清 | 阶段 1（重选题/重方向） |
| 站与站并列、没有谷底、反打靠旁人 | 阶段 2（重排时间轴） |
| 全篇除主角外没有具体的人／释放无人见证（只在自己家里完成） | 阶段 2（加人、加见证链） |
| 正文里在做运算／数字过密（用户 88 意见） | 阶段 3（数字四类化，算式移入本表第四节） |
| 开场不钩、中段无翻面、结尾无互动钩、水段 | 阶段 3（重写该站） |
| 只有用词、断句、错别字问题 | 局部改 |

改完**重新自检一遍并写进 04**（前稿哪几项低分 → 现在几分），不凭「我改了」通过。

## 五、技术核对（唯一还用脚本的地方，可选）

```bash
python3 scripts/fuben_run.py 作品/NN_主题/ --json          # 输入/算术/指标
python3 scripts/fuben_run.py 作品/NN_主题/正文.md --style   # 可选：AI 腔句式候选（advisory）
python3 scripts/fuben_products.py 作品/NN_主题             # 产物齐备＋审核报告哈希绑定
```

- `BLOCK` 只可能是**确定的输入或算术错误**（例如算式算错、引文字数与文字不符）：清零。
- `REVIEW/NOTE` 是描述信息，怎么处置由人判断，可以「保留＋写明理由」。
- **PASS 不是创作批准**：它只说明没有机械错误；好不好看以念稿、独立审读和真实观众数据为准。

# 审读与改稿 · 追看断点、念稿测试、分层返工

> 审的是**观众有没有继续听的欲望、期待是否兑现**，不是检查表全绿。方法吸收 short_drama_agent 的分层返工（不同问题退回不同阶段）与 drama-skills 的场景策略，去掉其机械密度评分。可独立新上下文审读；没有独立条件就自检并标注，不冒充多人会审。

## 一、追看断点审读（先做）

**本节必须先做、必须落纸（v1.3.5）**：04 的第一小节就是这六问，**每条引原句 + 行号**。85 的 04 用「三教律对标表」顶替了本节，结果 16% 篇幅的器物陈列段无人点名——**对标表回答的是"我按规矩写了吗"，断点审读回答的是"观众还在听吗"，后者不能省。**

只读当前正文、brief 与必要事实，不看作者自评。按顺序回答，**每条引用原句 + 行号**：

1. **开场使我等什么？** 观众此刻产生了什么具体疑问/期待？若只是复述题目、介绍身份、描述普通动作 → 开头失败，指出应从哪场冲突/反常后果切入。**开头 3 秒体检**（不过即退阶段 3，硬规见口播结构与节奏·开头铁律；`DEFINITION_UPFRONT`/`SYS_PROMPT_OVER`/`HEAD_OVERLOAD` 命中即不过）：①第一句须是 ≤35 字钩子句（可含签名折行）、第一个字就有抓力；②**第 10 行内出现第一个可拍动作（人物+动作+物件），系统提示笑话 ≤2 行计入开头块 ≤8 行预算**；③**开头 160 字禁定义/科普/口径/「先校准」「今天聊聊」式讲解腔**——名词解释一律后置到剧情第一次用到的地方，每次 ≤2 行；④钩子备选 3 条同受①–③约束（讲解腔钩子不得列为推荐）。
2. **哪一段开始不再推进？** 标出**最早可能划走的具体段落，必须给行号（Lxx–Lxx）**。特征：换段闲聊、经历清单、纯介绍、**连续并列的同类展示（器物/遭遇/日常细节，中间没有一次局面变化）**。刺激开头接流水账仍是失败。这一问没有行号＝没有回答。
   - **平铺扫描（人工，不设启发式脚本）**：本仓已退役过启发式质地检查器（判据失准），所以"水"由审读人点名：列出连续并列段的**行号、字数、占全篇比例**；逐条处置三选一——压成判词／并进有对手的场／写明保留理由（该段有独立情绪或笑点功能且不可删）。**"这里有共鸣器物"不是不水的证据**；共鸣是质感，推进才是剧情。
   - **可删测试**：把该段划掉，后文是否仍然成立？成立＝装饰（压成一句判词）；不成立＝它是剧情，保留并检查它是否把局面推进了一格。
3. **哪个兑现没被演出来？** 蓄势在哪、兑现是哪句哪场、兑现后谁的处境/话语权变了？只剩「众人震惊」「你终于赢了」→ 展开交锋与反应，不靠旁白宣布爽。
4. **伏笔/器物是否长出来的？** 揭示须由前面的东西支持，临时空降的答案/贵人/证据算硬伤。
5. **侧面反应改变了什么？** 谁改口、让位、收回东西、换称呼？「他原本能做什么，现在为什么不能做？」答不出＝表情包式侧面。
6. **配角是否替主角爽了？** 最难的一步若是旁人送证据/说漂亮话完成的，主角的反击被拿走了。

## 二、念稿测试（口播特有）

- **出声读一遍**（或默读模拟配音）。拗口、换不过气的长句立刻断行；每句一般 ≤15 字。
- **语速对表**：创作口径 4.5–5 字/秒（含呼吸）；机检 `fuben_run` 粗估按 policy 6.4 字/秒（不含停顿），两个数都写进报告，别互相冒充。总估时与目标时长差 >20% 就调体量，不是硬删句。
- **断崖点扫描**：连续 30 秒纯介绍/回忆/抒情 → 压缩或前置半句钩子。
- **禁词扫**：首先/其次/然而/随着/不禁/眼眶一热等书面腔 AI 腔（清单见代入感手艺·四）。

## 三、反流水账复检

对照 [代入感手艺.md](代入感手艺.md) 第一节四特征逐段过；每段问“能不能当分镜拍”。再核（**对白与账目一律引用机检数字，禁止无工具自报**）：

- [ ] **对白限额**：`DIALOGUE_*` 输出为准——引语帧候选 ≤12、估引语占比 ≤10%；超线必给逐项排除表（哪些是转述/微刻度/定义句不计钉子），剩余收拢成旁白
- [ ] **乒乓回合扫描**：`PINGPONG` 命中处改旁白转述收拢；无命中也要人工复核「你说他说」变体（如「你问，X / 他答，Y」跨段连击）
- [ ] **每场钉子句 ≤1、全篇 ≤8**：按 `DIALOGUE` 命中行逐条对号，写出排除理由
- [ ] **对白功能**：每句引语都能归入激将/预警/刻度之一，不推剧情
- [ ] 抽象焦虑都翻译成了身体/器物/数字，无情绪形容词宣布
- [ ] 器物三现表落地（1–2 个器物走完全篇且换义）
- [ ] 数字判词链成立（先铺链，判词落点有冷漠揭晓方）
- [ ] **账要平**（见下「三·五」）：`LEDGER_*` 与 `fuben_craft --ledger` 全表逐条闭环
- [ ] `BANWORD`/`NO_SMOKE` 红线扫描清零（正文+短版+钩子都扫）
- [ ] 拆穿旁白 ≤3–4 次且都在“刚赢”之后
- [ ] 每 15–20 秒有一个小起伏（兑现/新信息/坏消息/反常细节）
- [ ] 收束偿还了开头的核心期待（灰/暖其一，未说教）
- [ ] `VOLUME_OFF_BAND` NOTE 有处置：补足，或引用用户同意原话/写明接受理由

## 三·五、账目对账（数字判词链的审计，2026-09-24b 新增）

口播稿的数字是判词不是修辞：**每个显式数字主张必须能按文内口径反算**。跑

```bash
python3 scripts/fuben_craft.py 作品/NN_主题/正文.md --ledger   # 全表：CONSISTENT/ABSENT/MISMATCH
```

逐条处理 MISMATCH，另行人工核三件机检测不到的：**①单价×数量↔总额**（一天一百二×四十七天=五千六百四）；**②总−支出=余**（还账后剩多少，剩下的钱别吹成翻倍）；**③同一器物/金额两现口径一致**（卡上四千七，账本别记四千——要留差异就让人物点破，如「他抹了零头」，不点破就是错账）。79/81 案例：「只回了三个字」实为四字、「第一笔 A5」只有两千多、四千七↔四千，全部过了旧版 APPROVE——旧审读漏账，新账必须核。

## 四、分层返工（别把所有问题都拿换词处理）

| 创作问题 | 退回 | 改什么 |
|---|---|---|
| 切口平、欲望/阻力不成立、钩子无处兑现、曲线缺对抗 | 回场次单（阶段 2） | 换入场与事件组织，重连承诺与兑现；不是只换第一句 |
| 主线成立，但关键场没展开、伏笔没落正文、侧面成捧哏、配角替主角爽 | 回成稿（阶段 3）重写该场 | 补主角主动选择、有效阻力、线索与兑现后的局面变化 |
| 戏已成立，只是啰嗦、声线不顺、局部衔接 | 就地修 | 保留有效剧情与力度，不整篇重写 |

返工意见格式：**具体原句＋损失＋退回层级＋修订目标**。改完必须复审对应问题是否解决、主线是否仍成立，不凭“已修改”放行；**复跑 `fuben_run --profile full` 并把 findings 前后对比写进 04**（清了哪几条、新冒出哪几条），机检不重跑＝返工未验证。局部改动涉及器物/称呼/时间/判词数字时，检索全文直接引用与间接指代一并修，改动过的账目重过「三·五」。默认一轮成稿、一轮审读、必要时定点返工；方向仍有争议就摆出争议，不循环刷“通过”。

## 五、诚实边界

审读结论绑定当前正文（`fuben-review` 要求 `body_path` + `body_text_sha256`；正文改动后旧结论失效）。没有真实观众反馈前，不报“必爆”“胜率”，不把机检 PASS 说成好看。

# 搜索与质感 · 检索怎么变成正文里的东西

> 本系列的可信度来自现实质感：行话、价格、流程、热梗、身体感受。模型凭空写的质感是通称（“很难受”“过得很惨”），检索来的质感是**专有名词、真实数字、真实话术**。用户裁决：**阶段一不调用真实搜索即任务失败**；arena 一次并行多路，下限 8 路、单批全部并发并留批号。

## 一、四类覆盖（每类至少 2 路）

| 类 | 找什么 | 例子 |
|---|---|---|
| ① 本题现实质感 | 行话、价格、流程、工具、身体感受、行业黑话 | 练薄肌：代餐盒、三分练七分吃、充碳、线条光；网赌：首胜、流水、翻本 |
| ② 同类真实案例/事件 | 真实报道、判决、旧闻（如 2011 郴州卖肾案） | 数字判词、日期、地点从这里来 |
| ③ 相邻题材/真实事件 | 同压力不同结局的旁证，防跑题、找对位 | 写戒赌就顺手看分期/网赌沉沦的现实样本 |
| ④ 传播内容与钩子形态 | 热梗原文、评论区话术、同类爆款标题/开场 | 「耍起」母版原句、评论区神评（“哥 你那叫瘦”） |

每路记录：检索词、批序号、来源、**取用的质感**（词/数字/话术/细节）。产物写进 `_运行/YYYY-MM-DD/01_深读_检索与方向.md`，**必须是逐路表格**（81 教训：一句「来源：知乎、搜狐……」不算检索记录）：

```md
## 检索记录（批 B?-YYYY-MM-DD，N 路）
| # | 类 | 检索词 | 来源（可回链） | 取用的质感 | 用到哪场 |
|---|---|---|---|---|---|
```

同文件必有「**方向定板**」小节：3–4 张方向卡的摘要＋用户拍板原话（或代选授权来源与理由）＋一句话记录「不做什么」（如 81：换题面/换类型=否）。阶段 1 的验收看这两节，不看感想。

## 二、质感借用表（检索 → 正文的转换规则）

**借质感不借剧情。** 从来源里拿走的只有四样东西：

1. **词表**：行业/身体/器物的专有说法 → 直接进感官锚定与场景（「正经充碳」「拧花的螺丝」「滑轨后边露出一小截黄色」）。
2. **数字**：价格、工资、时长、规格 → 直接进数字判词链（原样保真：千分位、小数）。
3. **话术**：人物该说的行话、推销词、敷衍话术 → 进对话（「还是变态辣吗」这种习惯性确认句可以当刻度用）。
4. **细节**：可拍的物件与动作 → 进场景（风铃、搪瓷缸、掉瓷的勺）。

**不借的**：来源的完整事件线、人物经历、原句。搬事件＝抄袭；搬句子＝洗稿。热梗可以引原句（梗是公共资产），但要把梗**炖进因果**，不是摆进正文当展品——写完检查：删掉这个梗，剧情是否缺环？缺环就说明炖进去了；不缺环就是贴片。

## 三、防编造纪律

- 检索到的事实写明来源；ASR 转写错误不当事实；拿不准的数字/日期标「待确认」，或改成模糊量词，**不给精确假数**。
- 真实案件/报道只做质感与判词参照，不冒充纪实；角色误信与作者事实分开。
- 没有检索可用（工具不可用）时：如实降低质感预期，用生活通识写作并在产物里声明“本稿无检索支撑”，不伪造来源列表。

## 四、质感枯竭自检

写完扫一遍，命中两条以上＝检索不够，回炉：

- [ ] 全篇没有一个精确到分/秒/个位数的数字
- [ ] 没有一个行业词、品牌通用名、工具名、地名路名
- [ ] 人物对话像同学聊天，不像干这行的人说话
- [ ] 场景里放不出具体物件（说不出桌面摆着什么）
- [ ] 身体感受全是通称（难受、崩溃、麻木），没有比喻

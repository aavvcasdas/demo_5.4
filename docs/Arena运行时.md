# Arena 运行时说明 —— 本会话怎样读懂并运行本仓库的 Skill / Agent

对应机器可读配置：[arena.runtime.json](../arena.runtime.json)（路由与契约见 [AGENTS.md](../AGENTS.md)）。
v3.0 改造前后对照（脚本删了哪些、规则搬到哪、运行方式怎么变）见 [改造说明-v3.0-2026-09-30.md](改造说明-v3.0-2026-09-30.md)。

## 这是什么

本仓库的 `skills/*/SKILL.md` 是写给 agent 执行的**剧本创作提示词包**：规则（结构、节奏、语言、红线、评分）全部写在提示词与 references 里，脚本只做技术核对。
**Arena Agent Mode 主会话本身就是执行器**：按阶段实例化角色、落产物、按提示词自检，不再跑一排门禁脚本。

## 运行方式（以人生副本剧本为例）

1. **识别意图** → [AGENTS.md](../AGENTS.md) 路由表 → [fuben-write](../skills/fuben-write/SKILL.md) 管线。
2. **逐阶段执行**，每阶段先读配置指定的 references（1 检索／2 选题与结构／3 口播与节奏／4 审读与改稿／5 代入感与禁忌／6 独立提示词／7 自检与评分／8 拆文库与对标），产物写入 `作品/NN_主题/_运行/YYYY-MM-DD/`：

   | 阶段 | 角色 | 产物 | 自检依据 |
   |---|---|---|---|
   | 00 简报 | 主控 | `00_简报.md` | 一句话能说出写给谁看、为什么点赞 |
   | 01 深读+检索+选题 | 策划 ＋ 并行检索（≥8 路，四类真实骨架） | `01_深读_检索与方向.md` → **用户选定方向** | 选题三闸＋逐路表（不调用搜索即任务失败） |
   | 02 人生时间轴 | 策划 | `02_场次单.md`（5–8 站：事件/物证/一句人话；压制→谷底→反打→释放；物证 3 件；兑现认领） | references/2、7；可对标 `拆文库/` 同型样本 |
   | 03 成稿 | 主笔（首行即钩＋签名后置＋每 15–25 秒翻面） | `03_初稿.md` ＋ `正文.md` | 块级三问＋写法铁律（含无烟自搜、禁词自扫） |
   | 04 投手预演+返工 | 审读（七问/平铺扫描/念稿/账目手算）＋主笔分层返工 | `04_审读与返工.md` | references/4、7（十项清单＋五维对标分） |
   | 04b 读通专项 | `fuben-review` | `审核报告.md`（含 `body_path`/`body_text_sha256`） | 创作审查＋读通专项 |
   | 05 自检与技术核对 | 主笔 | `05_自检.md`（旧作品为 `05_机检.json`） | 自检八问落纸；再跑 `fuben_run` / `fuben_products` |

3. **调用证据不是话术而是文件**：阶段产物真实存在、内容对应职责。产物命名与齐备性由 `python3 scripts/fuben_products.py 作品/NN_主题` 核对（`OK`=完整，`PARTIAL`=定向返修，`STALE`=报告未重绑，`MISSING`=缺产物）。
4. **技术核对（可选、非创作关卡）**：

   ```bash
   python3 scripts/fuben_run.py 作品/NN_主题/ --json          # 输入/算术/指标；BLOCK=确定的输入或算术错误
   python3 scripts/fuben_run.py 作品/NN_主题/正文.md --style   # 可选：AI 腔句式候选（advisory）
   python3 scripts/fuben_products.py 作品/NN_主题             # 产物齐备＋审核报告哈希绑定
   ```

5. **创作规则不再有机检门禁**：无烟、禁词、开头铁律、对白限额、账目档位、体量、结构评分全部按提示词自检（v3.0 删除了 16 个判罚脚本）。写作与审读必须在产物里给出**行号证据**与自评分。
6. **主题边界**：以用户题面为准。题面是人生，题材元素只能做质感与道具，不能抢走主线。
7. **版本绑定**：`审核报告.md` 必须写当前 `body_path` 和 `body_text_sha256`；正文改动后旧报告只能是 `STALE/PROVISIONAL`（`fuben_products` / `fuben_loop review` 会显式报出）。

## 诚实边界

- 外部执行器（codex / Claude Code / opencode / gemini-cli）若日后在本环境安装并认证，可在 `arena.runtime.json` 里把 `executors.active` 切过去，产物协议不变。
- 独立外部审读目前不可用；04 审读由主会话以审读角色执行，产物里注明，不冒充多 Agent 会审、不虚构会话 ID。
- **机检 PASS 只说明没有检出的机械错误**；好看与否、水不水、能不能出池，一律由提示词自检、审读与真实观众数据判断。

## 问责

- **报告见用即成文**：`_运行/NN_名称.md` 的日期目录必有「00_*.md」为定向返修说明；走全管线为 `OK`，只补条目为 `PARTIAL`，报告哈希未重绑为 `STALE`。
- **复跑不假毕**：任何一次修订后，把「前次自检得分 → 本次得分／低分项 → 处置」写进 04；不凭「我改了」通过。
- **红线靠自觉也要留痕**：无烟在正文/短版/钩子三个文件里各搜一遍并把关键词与命中数写进 04；禁词逐条扫并写处置。
- **借一次真 8 路**：01 的检索表必须能回看——批号、检索词、来源、取用的真实骨架、用到哪一站。

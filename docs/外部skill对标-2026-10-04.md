# 外部 skill / 提示词对标（2026-10-04）

> **用户指令（原话）**：「skill还是不行啊，你能不能去搜索参考下抖音的所有高赞最近更新的有结果的skill或者提示词啊，感觉还不如提示词，这次10赞！那这么多次修改我为什么不直接去用别人的skill项目！」
> 本篇是这次检索的存档：找了什么、找到什么、**哪几个真有结果证据**、我们差在哪、已经移植了哪几条（v3.9.0）、以及「直接换别人的项目」这条路怎么评估。

---

## 〇 · 结论先说（三个实话）

1. **抖音站内没有「可安装的 skill」这种东西**。skill 是 Agent（Claude Code / Codex 等）的文件夹规范，生态在 GitHub 与 skills.sh 注册表；抖音上能刷到的是**教你怎么写提示词的视频**，不是可调用资产。实测在 skills 注册表里搜中文关键词——`npx skills find 抖音 / 口播 / 文案 / 脚本 / 短视频 / 起号 / 小红书` **全部返回 0 条**（2026-10-04 实测）。注册表目前以英文开发类技能为主。
2. **但「有结果的内容类 skill」确实存在，只是不在抖音上**。今天找到两个真正带结果证据的：
   - **老徐口播方法论 skill**（`chenmisss/laoxu-video-script`）：30+ 篇真稿，**四条自然爆款 83.1 万 / 57.4 万 / 37.1 万 / 23.1 万播放**（数据 asOf 2026-07-31，账号后台每日同步口径），16 轮按真实播放数据校准。
   - **姜胡说口播 skill**（`read2017/jianghushuo-oral-skill`）：从 **433 条视频、94.7 万字逐字稿**蒸馏，5 道题独立盲测 **90/100**，每条引用可回溯原片秒数（489 万粉博主）。
3. **我们差的不是「规则条数」，是三条**（§3 详表）：①**开场句式没有按真实播放排序**；②**没有「四感」这套观众视角的及格线**（新鲜/有用/有希望/参与）；③**没有口服度检测**（车轱辘话/形容词/报幕三忌＋人味五特征＋「大声读」判据）——我们的稿子是「短行金句体」，念出来反而像 AI 写的。三条已按证据移植进 **skill v3.9.0**（§4）。

## 五 · 「直接用别人的 skill 项目」这条路怎么评估

| 方案 | 可行性 | 门槛/风险 | 结论 |
|---|---|---|---|
| 整体换成老徐 skill 当主笔 | 可以装（MIT 类，方法开源） | 它面向**6–15 分钟单人知识口播**（卖课/AI 实测/月报），题材是「我拿真金白银替咱试了」；我们是**第二人称叙事剧本**，观众是看故事不是学方法；且它没有对白配额、审核绑定、我们的红线 | **不建议整体换**；建议**换主笔、保底盘**（用它的开场与四感，用我们的结构与红线） |
| 学姜胡说的口播语法 | 可以 | 强绑定他本人人设（中专生/老伙计/「就」字密度），直接套会「像别人」 | **只借快检清单**（已借） |
| 装抖音工具箱当工具 | 可以（Windows 桌面端，本地转写） | 环境是 Windows/需 ASR 模型，我们沙箱跑不了；它的价值是**竞品拆解工作流** | **借流程，不装软件**（阶段 1 步骤 2.6 已落） |
| 全部推翻、只用外部 | —— | 丢掉三次修订换来的对白配额、哈希绑定、无烟红线；而且外部 skill 也没有「发布即爆」的证据，只有单账号单题材的数据 | **不做** |

**一句话**：可以换「打法」，不能换「底盘」。v3.9.0 就是把外面有数据背书的三条打法，装进我们已有的底盘里。

**关键缺口**：我们只有「播放＋点赞」两个数，而 2026 年的算法里，**决定推流的是留存与深度互动，不是点赞**。缺的四个数：

1. **平均观看时长（avgWatchTime）**
2. **留存提示**（后台"大多数观众在第几秒停止观看"）
3. **3 秒留存 / 2 秒跳出**
4. **收藏、评论、分享、涨粉**

没有这四个数，任何"改剧情"的结论都是猜。

## 二、诊断框架（借用 GitHub 上别人验证过的分诊逻辑）

来源：`0xPabloLI/inside-china-ai` issue #259《完播率根因分诊（0:01 流失 vs 中段冗余）》（2026-09-11，公开仓库）。
它的场景和我们几乎一样：AI 生成短视频、60–80 秒、无人出镜，8/8 条数据的留存提示**全部是"大多数观众在 0:01–0:02 停止观看"**，平均观看 3.4–19 秒。

它的三条分支，我们直接照抄来判断自己：

| 分支 | 后台长什么样 | 根因 | 对策 | 对我们的含义 |
|---|---|---|---|---|
| **A** | 留存提示：**0:01–0:02 停止** | **首帧/首秒钩失败**，与时长无关 | ①第 1 帧就是核心冲击（数字/冲突/反常识），不要"问候/背景句"；②首句语音 0.5s 内进主题；③前 3 秒视觉强驱动 | **压时长没用**——观众在 0:01 就走了，剪短只是让完播率这个"分母游戏"好看，avgWatchTime 不涨，账号级指标还会变差 |
| **B** | 0:01 后平稳，某点（如 0:35）**断崖** | 断崖点之后的段落是冗余 | 删掉/重写那一段；若删完只剩 30s 的价值量，就承认它是条 30s 视频 | 我们的"翻面节奏"靠 200–250 字，换算约 40–60 秒才翻一次——**翻面太慢** |
| **C** | 无断崖但**整体平缓** | 信息密度过低／节奏平（"朗读一段文字＋换图"） | 提高信息密度：**每 3–5 秒一个新信息点** | 我们的稿子按"字"写，没有按"秒"排过信息点 |

**它的关键纪律（我们要抄）**：**不看"完播率"数字，看 avgWatchTime ＋ 留存提示**；验证口径写死在事前（例：下一轮 avgWatchTime 从 8s 抬到 15s+ 才算钩子改造生效）。

## 三、GitHub 对标（近期，逐条写清「能借什么」）

### 1. `Mr-funny/hbg-life-simulation` · 140★ · 2026-08-05 —— **同赛道生产 skill（最高价值）**

一位做「人生副本」的作者（X: @Hamburgerai）把自己的成片流程封成了 skill：统一漫画 IP、快闪开头、连续旁白、语义字幕、密集静态分镜、zoom/pan、固定 BGM、成片质检。它解决的问题和我们完全不同：**它管"成片"，我们只管"文案"**。

**可直接借的规格（它的 references/opening-system.md 与 storyboarding.md）：**

| 环节 | 它的做法 |
|---|---|
| **快闪开头** | 引导旁白几乎立刻开始 → **语音结束后 ≤0.05 秒**进快闪音效 → **约 9 张候选人生**在 **1.4–1.8 秒**内闪过 → 停留选中的那张 **0.1–0.2 秒** → 读出完整标题 → 正文第一张图只在标题读完后才出现；**不许出现进度条/计数器/"副本载入完成"/数字 HUD** |
| **画面密度** | 每个静态镜头 **4–8 秒**；8–12 秒仅在画面信息量足够时允许；**>12 秒拆镜**；**>16 秒一律视为缺图**；8–12 分钟视频配 **70–110 张**图 |
| **镜头轮换** | 六种构图轮换（远景/中景动作/双人/过肩/手部物件特写/环境象征），每四场至少一场不出现人脸 |
| **运动** | 快闪帧交替 zoom in/out（scale 1.00→1.18–1.22 再反向），**不允许连续硬切**；正片 zoom 与 pan 交替，**相邻两张不许同方向** |
| **音频** | 固定 BGM 基线、不做 ducking；可听度按 **3–4 dB 步进**调，不微调；成片留 ≥3dB True Peak 余量 |

**这一条直接暴露我们的缺口**：我们既没有开头快闪、也没有"每 4–8 秒一换图"的密度概念——如果我们的成片是"一张图＋长旁白"，无论文案多好，0:01 之后就是平坡（分支 C）或 0:01 直接走（分支 A）。

## 六、下一步：三个实验（按性价比排序，各自带判据）

> 纪律：**一次只改一个变量**；每条实验事前写死判据；**不看点赞，看 avgWatchTime 与留存提示**。

### 实验 1（先做）· 开头重建：给已发布内容做"3 秒重开版"
- **动作**：拿 88（或 90）同一篇文案：①第 1 帧＝核心冲击画面（数字/冲突/反常识），删掉一切铺垫性画面；②首句语音 0.5 秒内进主题；③前 3 秒内至少 2 次视觉推进（闪/切/推近）。
- **判据**：`avgWatchTime` 相比原版 **提升 ≥50%**；留存提示从"0:01 停止"变为"0:05 之后"。
- **成本**：只改开头 3–5 秒，正文不动。
- **一次一变量**：只改开头，不动标题、不动正文、不动发布时间。

### 实验 2 · 画面密度改造
- **动作**：按 HBG 规格重做一条：4–8 秒/镜、>12 秒必拆、镜头 6 型轮换、zoom/pan 交替、固定 BGM（3–4dB 步进法）。
- **判据**：3 秒留存 ≥55%（种子池参考线）、avgWatchTime 翻倍、收藏率 >1%。
- **成本**：一条完整重制（图量 70–110 张量级，按实际时长）。
- **风险**：这是"形式"变量，若实验 1 已经证明 0:01 是瓶颈，实验 2 要在实验 1 结论后进行。

### 实验 3 · 选题对标（换供给）
- **动作**：采同赛道近 30 天点赞 Top 50（`douyin-ingest` 式：采集→转写→拆结构），提取**选题角度/开头句/信息点节奏**（不是抄内容），据此重选 3 个选题各写 1 条。
- **判据**：新稿在冷启动池的 3 秒留存是否过线；过线后再看收藏。
- **成本**：采集中等，写稿照旧。

### 附：账号级体检（并行、零成本）
- 用 redfox 的六维框架（提示词版）扫一遍：近 10 条作品的发帖间隔、是否断更、是否单条依赖、粉丝质量、是否有违规通知（创作者中心看，**没有通知就不是限流**）。

## 七、我需要你给的四个数（决定走 A/B/C 哪条分支）

后台（创作者中心 → 作品数据 → 单条）能看到的：

1. **88 的播放量**（大约几百还是几千？）
2. **平均观看时长**（秒）
3. **留存提示原话**（"大多数观众在第 X 秒停止观看"）
4. **收藏 / 评论 / 分享 / 涨粉**各多少

＋一句话：**这条视频的画面是什么形态**（AI 生图＋配音？一张静态图？数字人？有字幕吗？有音效/转场吗？）

> 拿到这四个数，我就能判定是 **A（首秒钩）／B（断崖冗余）／C（密度平）**，然后只改那一个变量。拿不到的话，我按最坏情况（A＋C 同时成立）设计实验 1。

## 八、止损纪律（诚实版）

这不是"再试一条"的问题，是**生产线缺环节**的问题。给的承诺要可验证：

- 若按实验 1＋2 改造后（**样本 ≥3 条**），`avgWatchTime` 与 3 秒留存仍**两条都不过线** → 说明问题不在内容生产，而在**赛道选择或账号定位**，到那时应该做的是**换赛道或停更复盘**，而不是再改稿。
- 反过来说：在那之前就放弃，等于把"生产线缺环节"误判成"这条路走不通"。**这两个结论的处置完全不同。**
